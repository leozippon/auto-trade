# 验证读数里名字看不出的口径：两种回撤、换手、对照组合与噪声

`validate` 与 `test` 返回的字段含义在工具描述里，哪条登记条件读哪个字段在运行事实 `acceptance_rules.registration` 里；拿读数比较、外推或预估登记之前，先认清下面几处名字说不出来的口径。

## 两种回撤

`active.max_drawdown` 是主动序列复利路径的回撤，`book.max_drawdown` 是账户权益的回撤。登记在回撤上只比权益回撤，上限在 `acceptance_rules.registration.max_drawdown`，每次 `test` 都查；验证记录的统计量不读回撤。两种回撤给候选的排序可以相反，比哪条限就读哪个字段，不用另一种或等权组合去代。

## 换手

`book.turnover` 是整段回放的买入名义与卖出名义之和除以期初资金，整段累计、不年化：一年换几遍（双边、期初资金口径）用它除以 span 的年数，`active.excess_at_cost_stress` 加收的滑点也按它算。要按平均权益算，用 `result_ref` 记录里的 `executions` 与 `equity_curve` 自己重算；几种分母都对不上某个报告值时，先查它是不是期初资金。

## 已揭开各步与最近两年

`revealed` 与 `recent` 是什么，见 `validate` 的描述。拿它们和研究年全段比时：`revealed.active.threshold` 是那几步长度的门槛，远高于研究年的；`revealed.book.turnover` 折年时除以那几步的年数。

## 主动、账户与对照组合

主动读数赢了对照组合，账户却可能没赢基准：对照组合本身扣费后也会亏（`book.baseline_return`），赢一个亏钱的对照组合不等于账户赚钱。`active.excess` 是主动序列逐日差的年化均值，`book.excess_vs_baseline` 是两条复利收益之差，两者同号居多，但不是同一个数。

`active.market_beta` 为负说明账户持有的名字比随机副本更低 β：指数大涨的年份主动序列落后于对照组合，大跌的年份领先；`active.turnover_beta` 为正说明账户偏向近 20 个交易日平均换手率低的名字（低换手腿是前一交易日这一均值最低三成减最高三成）；残差统计量不算这四条腿能解释的部分。设了跟踪约束的实验，登记比的是策略自身收益的市场载荷与跟踪误差（`result_ref` 记录里的 `stats.benchmark.market_beta` 与 `stats.benchmark.tracking_error`，见 `acceptance_rules.registration.tracking_mandate`），不是主动序列的。

## 与策略无关的读数噪声

随机选股对照组合的种子是固定的，换名的对象是节点自己的成交骨架，一笔往返交易换成哪只股票只由种子、抽样序号与这笔交易本身（买入时点、股票、股数）决定：同一份字节在同一个 span 上重跑，只要策略本身是确定的（见 `deterministic-fit`），对照组合与读数都不变；两个 span 上相同的往返交易换到同样的名字（回放结束时仍未平仓的可能例外）；字节变了，只有成交变了的那几笔换名。训练模型的策略换一个训练种子本身就会移动读数：两个配置之差小于同一配置换种子的读数差时，这个差分不开。实测（20261115 轮）：同一配置只换种子基，研究年全段的残差信息比率相差 0.08–1.15，已揭开的十二步上记录的残差信息比率相差约 1；两个种子基同号本身不是证据，没有差别时同号的机会也有一半。
