# Fold-ready 探索计划

一折跑多轮 `batch_validate`：第一轮并列比较家族，后续轮次围绕站住的家族比合成方式、中性化与换手控制。每一步都要产出可执行候选或明确淘汰。有父本时，必须先完成一次与父本可执行逻辑不同的完整 Validation；父本对照由宿主在会话前跑好，不要自己重跑。

1. 读本轮 `data_summary.json`、`unit_reference.json`、daily/events/fundamentals/macro 的 schema 与可见日期；核对 `families.md` 用到的每个字段是否存在、单位是什么、在本折输入窗里覆盖多少股票。缺字段的家族直接记「不可测」，不要用替代字段冒充。
2. 固定不变量并写进工作区笔记：可交易性过滤（T-1 未停牌、ADV20 成交额 ≥ 3,000 万元、T-1 收盘价上限、剔除科创板/北交所或说明为何保留）、篮子 10–15 只、等额现金、持有期（5/10/20 个交易日三选一，每个家族先用 `families.md` 给的默认值）、费用缓冲 3%。这些是声明值，不是拟合参数。
3. 每个家族先做规模与 β 中性：对同截面 `log(circ_mv)`（T-1）与 60 日 β 回归取残差，再 1%/99% 截尾、截面 rank 或 z-score。原始值只作对照报告，不进候选。
4. 离线预筛（不占回测预算）：用 `python /mnt/tools/screen.py --help` 所述的筛查脚本，在 `/mnt/snapshot` 决策视图上对每个家族算 1/5/10/20 日持有期的 rank IC、ICIR、逐月符号一致性、规模中性 IC、头部十分位多头超额、换手与覆盖。预筛只看输入窗，绝不碰验证区间。符号在多数月份一致、规模中性 IC 不塌、覆盖 ≥ 60% 的家族才值得一次完整 Validation；预筛不合格的直接淘汰并记录理由。
5. 第一轮 `batch_validate`：至少三个互不相同的家族并列，各自附机制无关对照（见 `families.md` 每节的「对照」），`hypothesis` 写清方向、持有期、否证条件。等权对照的用途只有一个：证明家族边际不是篮子构造带来的。
6. 第二轮起围绕站住的家族：合成方式在 `fit(context)` 里做——固定 λ 的 ridge（λ 预先声明，例如 `1.0`，不在 Validation 上搜索）或 LightGBM/XGBoost 排序器（`num_leaves ≤ 31`、`n_estimators ≤ 300`、`learning_rate 0.05`，参数预先声明），用带清洗与禁运的时间序列验证选家族权重：训练样本只用推断时已实现的前瞻收益，训练窗与验证窗之间空出持有期长度的禁运，标签是同持有期的规模中性前瞻收益 rank。`REFIT_PERIOD="quarter"`。合成候选必须与最佳单家族同批比较。
7. 多重检验纪律：本折全部候选数事先写在 `TODO.md` 里（建议单家族 ≤ 6、合成 ≤ 3、稳健性 ≤ 3），每加一个候选就是多一次试验；读 Sharpe 时按 `candidates_evaluated` 打折。不要用同一家族的参数邻域刷候选数。
8. 每个候选按 README 的「没有边际」清单读，子窗按四个季度分别报相对对照的超额、候选数、换手、拒单、行业与规模集中度。
9. 换手控制作为独立一轮：n_drop 式部分换仓（每次只替换分数最差的 2–3 只）对照整篮重排；持有期 5/10/20 三选一在同一轮比。
10. 用 `step_rollback` 把胜出节点恢复到 `output/` 再 `finish_fold`。全部家族被证伪时以 `finish_fold(outcome="no_edge", reason=...)` 弃权（首折记为 `baseline_missing`），并留下证伪结论与下一折的不同假说。

## 组合纪律

- 家族可分离：一次 Validation 只改一个家族或一次合成。
- 不把两个高度同向（Spearman 绝对值长期 > 0.85）的信号同时放进合成。
- 不用 WorldQuant 算子、TuShare 因子菜单或前几轮的价值/反转/成长打分凑候选数。
- 不在 `generate_orders` 里重新拟合任何权重。

## Validation 否证

- 任何 `available_at`、T-1、复权锚或财务版本错误：结果无效，不讨论收益。
- 有效覆盖长期低于约 60%，或在决策间大幅塌缩：淘汰该家族，除非它本就是稀疏事件假说。
- 中性化后优势消失：否证「独立 alpha」，只有明确接受该暴露并写明限制才能保留，且不得是规模暴露。
- 四个季度子窗同号少于三个，或收益只来自单个极端日期、少数个股或单一行业：淘汰。
- 加手续费、滑点、涨跌停和手数约束后优势消失，或 2 倍滑点下超额转负：淘汰。
- 合成不优于最佳单家族，或只降收益却未改善回撤与子窗一致性：回退到单家族。
