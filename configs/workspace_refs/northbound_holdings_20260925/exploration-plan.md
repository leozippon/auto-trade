# 研究会话探索计划

目标：在本臂唯一的研究会话里，判定**北向持股这一块信息**（季度前十大股东并集里香港中央结算的那一行）作一个不训练的独立分数，能不能选出主动收益与零技能可区分的一本书；能就把它做成一本站得住的书，不能就诚实地以 `no_edge` 结束。判据、预登记与验证计划只在 `families.md`，数据与单位只在 `pit-field-map.md`，离线门的做法只在 `references/offline-screen.md`，本文只排顺序与预算。

**本臂的命题有且只有一个**：`n1` 的主动序列越过零技能。它不以赢过 `c_base` 为条件；`c_shuf` 是同批的一次零技能抽样，`c_base` 只为登记册。

## 第 0 轮：不占回放预算的核对与普查

用 `shell` 在研究期末的决策视图上跑，不启动回放。任一条不合格就在第一批的 `hypothesis` 里声明，不要硬凑。

1. **运行事实核对（最先做的一件事）**：`broker_replay.initial_cash`、**`benchmark_index`**、`acceptance_rules`（有没有跟踪授权、两个回撤上限、`freeze_gate` 的阈值与试验数口径）、`budgets`（含 `strategy_fit_timeout_seconds`）、`max_replay_years`，以及 `research_geometry.years[].input_window`。本包按 100 万元不带授权写成；不符就改登记。`benchmark_index` 与 `lib/index.py` 的 `INDEX_CODE` 不一致时**改常量去对齐运行事实**。
2. **数据核对**：`macro` 里有 `index_weight` 与 `index_daily`；`events` 里**两张**前十大股东表都在；`unit_reference.json` 对 `hold_float_ratio`（百分数）与 `hold_amount`（股）的登记；`universe` 带 `l1_name`。缺一张股东表就是本臂没有分数，**不要用一张表或别的表凑**。
3. **股东表普查（本臂特有，第一优先）**，全部在 `/mnt/snapshot` 上、按 `pit-field-map.md` 的规则：
   - 两张表的 `trade_date` 是否全空、`available_at` 是否逐行等于 `ann_date` 23:59:59；非季末 `end_date` 的行占比。
   - 名字含「香港中央结算」或「HKSCC」的全部写法与行数，按登记的规则分成北向 / 非北向，逐条看一遍分对了没有。
   - **逐季末**：沪深 300 成分里有北向行的只数——只读流通股东表、只读总股东表、并集；以及有任何报告的只数。薄期在哪几个季度、并集是否平滑。
   - 同一（公司、季末）两张表都有北向行时 `hold_float_ratio` 是否一致；北向行的公告滞后分布。
   - **逐研究年**：48 个复核日上可交易池里 `lvl` 与 `chg` 有值的份额、报告的年龄。这就是离线门的 K1，**读到明显低于八成先停下来**。
4. **账户算术表（直接对着 P3）**：本臂资金在 30 / 50 / 80 席上的座位金额、买得起的成分占比、5 元最低佣金的 bp/边、一次往返总成本（`references/capital-arithmetic.md`）。
5. **换手与活动量实测（P3 的硬要求）**：用 `smoke_backtest` 在研究期靠后的槽上跑一段跨过至少一个公告季（例如 4 月或 8 月）与两次复核的窗口，读 `turnover`、`fees_paid` 与完成回合数，扣掉首日建仓再年化。**分数一个季度才变一次，所以要确认每月完成回合数能不能到 1**（前推期的活动量门）。
6. **零技能的形状读数**：本臂池与席数上等额现金零技能能拿到什么（`references/zero-skill-panel.md`），以及离线门工具二里 200 本同池随机书的主动分位。**地板在哪里要先知道。**
7. **决策与 `fit` 成本探针**：`smoke_backtest(start = 研究期靠后的槽, days = 2)`，`n1` 读逐日 `strategy` 秒数与 `peak_memory_bytes`；若计划进第二批，再给 `c_base` / `n2` 各量一次 `fit_seconds`。**整个会话只用一个 `start` 做所有靠后窗口的探针**（`references/fit-cost.md`）。

## 第 0.5 轮：离线门 G-NB（`families.md` 的硬门，0 回放年；筛过而没提交的候选配置在下一个记下验证的批次里申报 `offline_trials`）

判据在 `families.md`，做法在 `references/offline-screen.md`，这里只排步骤。全部在 `shell` 里做，**不发起任何回放**。

1. 按时点重建每个决策日的 `lvl`、`chg`、`n1`（可见日 = 公告日 + 2 个自然日之后的第一个交易日；池 = 日期早于决策日的最新截面）。先拿第 0 轮第 3 步的覆盖读数对一遍。
2. **K2**：`/mnt/tools/screen.py`，`--horizons 20,40,60 --start 20210701 --end 20250630 --top-fraction 0.1667`，`lvl`、`chg`、`n1` 各一次，读 `ic_mean`、`t_stat`、`pos_months`、`ic_size_neutral`。
3. **K3**：48 个复核日的月度书——`n1` 前 50 只（买得起、可交易）对同池等权均值，逐研究年；`lvl`、`chg` 各自的同一张表；十分位剖面；200 本同池随机 50 只书的主动分位。
4. 判定：K1 / K2 / K3 任一命中 ⇒ 走 `families.md` 杀死条件第 1 条：第 1 轮的批次换成只有 **`c_shuf`（第一条，`control: true`）与 `n1`（`control: false`）**，8 个回放年，`offline_trials` = 2；`n1` 的主动 IR 低于 K4 那条线就以 `no_edge` 收尾，越过它才回到下面的正常路径。
5. `lvl` 与 `chg` 的单独读数是两个筛过的配置（包作者已经筛过），`n1` 提交时第一批申报 `offline_trials` = 2；会话另筛的变体各加 1。**看了分量读数改提交别的形态（轴 a）就是一次新登记**：重写 `hypothesis`，`n1` 在那一批里按筛过而没提交再加 1。

**这一步不产生提名依据。** 离线读数只有秩与方向可信；门只用来**否决**，裁决是宿主的整期批次。

## 第 1 轮：第一批完整研究期 `batch_validate`

腿与登记按 `families.md` 的验证计划：G-NB 通过时 **`c_shuf`（第一条，`control: true`）、`n1`（`control: false`）、`c_base`（`control: true`）**，12 个回放年，`offline_trials` 按表申报（2，另加会话筛过而没提交的变体）；G-NB 命中时只有 **`c_shuf` 与 `n1`**，8 个回放年，`offline_trials` 同样是 2。

`hypothesis` 必须写清：逐行引用 `families.md` 的分数表、腿表与符号预登记表；经济解释与**证伪条件**（K4 的那条线）；席数、复核节奏、保留带与换名上限；预期的主动信息比率（0.1–0.2）与逐年符号；G-NB 的三个判据量与分量诊断；P2 / P3 / P5 的判定规则；本臂的 trial 账。

**不要再加零技能对照腿**——宿主每次正式验证都会抽面板，`c_shuf` 已经是同批的那一次抽样。回放一旦开跑就计入预算，策略自身抛错的候选照样花掉，环境失败的候选退还。

第一批之后，对 `n1` 的完整期节点跑一次 `run_null_control`：不花回放年，会话时钟暂停；**它是诊断不是判据**，三个数一起报。

## 判定分支，逐条写死（判据本身见 `families.md`）

- **`n1` 主动 IR 低于 K4 那条线（约 0.64）** → Family 1 关闭。`n2` 是否还进场看 `families.md` 的第二批条件；否则以 `no_edge` 收尾。
- **`n1` 越过 K4 但过不了冻结门** → 这是本臂最可能的「有信号、不够格」结局。先读逐年与 `lvl` / `chg` 分解：增量是否集中在一两年、是否主要来自 `lvl`（风格）。可以走一轮登记过的变体轴，**每一轮都先重过 G-NB、各计一个 trial**，并且把此刻的 `trials_to_date` 与门槛写进结果笔记。
- **`n1` 的主动读数与 `c_shuf` 相近** → 与零技能分不开，按 K4 读，不要把两者之差当增量。
- **绝对超额高而主动超额低** → 赢的是池不是选名；看 `benchmark.panel_neutralized_excess`。
- **正读数主要来自 `lvl`、`size_tilt` 明显偏高** → 它是一次规模或质量押注，如实写；不以北向信息的名义提名。
- **某一年主动收益极端** → 看是不是那一年的公告季；只在一年成立的读数不是效应。
- **换手、成本或回合数越线** → 先按 `references/capital-arithmetic.md` 重算，再走轴 c；**不得改成周度复核**。
- **覆盖（P5）在回放里明显低于离线门的读数** → 数据或读取问题（多半是只读了一张表、按 `trade_date` 取窗、或把 H 股托管行算成了北向），先修实现，不算证伪。
- **实现读数不对**（座位没填满、买不起份额偏高、拒单率高）→ 先修实现再复测。

## 第二批（Family 2，只在 `families.md` 的条件满足时）

先做 `n2` 的离线否决（研究期后两年 ≥ 60 个分散决策日、按季度节拍离线拟合载体、比较 `n2` 与载体的逐日秩 IC）；过了才提交 **`c_base`（第一条，true）、`n2`（false）**，8 个回放年。`n2` 按它自己的主动 IR 对冻结门读；它比 `c_base` 多出多少只报告，不作判据——登记册已写明这个量级的增量宿主分不开。**全臂完整期验证上限 6（对照也算）**。

## 收官轮

只做两件事之一：对已经满足全部提名条件的最好候选补齐缺的读数并冻结；或者以 `finish_session(outcome="no_edge")` 携读数结束本臂，读数里包括 K1–K4、`lvl` / `chg` 分解与对登记 §2 那两行的交代。

## 计算预算

- **决策**：`n1` / `c_shuf` 每次复核读一次 200 天日线面板与一次 640 天两张股东表，容器内几秒；非复核日直接返回 `[]`。实测读数在 `sources.md`。
- **`fit`**：只有 `c_base` / `n2` 有，载体的季度重训；单次十几到六十秒量级，离 3,600 秒与 16 GiB 两条上限都很远，但进第二批前仍要在本臂自己的负载下量一遍。
- **回放年**：G-NB 与 `smoke_backtest` 都是 0 年；第一批 12 年（离线门否决之后是两腿 8 年）、第二批 8 年。按计划排满约 20 年，以运行事实 `budgets.max_replay_years` 为准。
- **余量怎么花**：变体轴在算力上都是自由的，**但每一个验证过的候选与每一个离线筛掉的候选配置都是一个 trial**，都会抬高本臂自己的去膨胀 Sharpe 门，每一条整期腿还吃掉 6 个位置里的一个，所以便宜不是理由。

## 每个候选必须汇报的读数

除标准结果块外，写进结果笔记：逐行对照 `families.md` 的分数表与腿表；经济解释与证伪条件；**主动中性化超额、主动跟踪误差、主动信息比率**与**面板自己的中性化超额**；逐年分块的主动超额与原始超额；`c_shuf` 的同批读数；`top_industry_weight`、`size_tilt` 与 `size_beta` 并排；**北向覆盖与报告年龄（逐研究年）**与离线门里 `lvl` / `chg` 的分解；**实测换手、年完成回合数、每月完成回合数、按本臂 `initial_cash` 重算的佣金账与 2 倍滑点下的超额**；拒单率与原因；平均总仓位；`pnl_concentration`；空对照的三个数；一次决策的实测平均墙钟；`trials_to_date` 与此刻的 `information_ratio_bar`。**账户面四项**也要报：每次复核的买不起份额、座位有没有填满、实际权重对目标权重的偏离、书覆盖的指数权重。缺任何一项的结果不作为提名依据。

## Validation 否证（任何一条命中，结果无效，不讨论收益）

- 股票池不是按时点读出来的：硬编码名单、用别的指数建书而仍按 `benchmark_index` 报跟踪误差、或用最新一张截面去标注历史决策日。
- 用 `trade_date` 而不是 `available_at` 判可见；股东表按 `trade_date` 取窗口；离线重建按 `available_at <= 决策时刻` 而不是公告日 + 2。
- 只读了一张股东表；把香港中央结算（代理人）/ HKSCC NOMINEES 当北向；把「报告里没有北向行」填成零；没有只留季末 `end_date`。
- 成分的 `con_code` 没有改名就去 join；`index_daily` 没有按 `ts_code` 过滤。
- `c_shuf` 的打乱依赖模块级状态或跨调用缓存（冷热 worker 不一致）；复核节奏依赖计数器。
- 买不起的**持仓**被当成离池强卖；或者买单向下取整而不是按最近整手四舍五入。
- 把拟合的东西放进 `models/`，或让 `state_dir` 里的东西跨回放存活。
- 没有第 0 轮的股东表普查、账户算术表与换手实测就开了整期回放；跳过 G-NB 直接开整期；或者把 G-NB 做成一次子跨度回放。
- `c_shuf` / `c_base` 登记成 `control: false`，候选登记成 `control: true`，或 `offline_trials` 少报了筛过而没提交的候选配置、又或把本批提交的候选重复申报。
- 看过 IC 之后改了登记符号而没有重写 `hypothesis`。
- 用绝对中性化超额或绝对信息比率去论证边际，而不看主动读数与面板。

## 收尾

冻结的是提名节点自己的不可变快照，提名前不必把它恢复到 `output/`。不要提交离线普查脚本；`models/` 只放静态资产。
