# 候选、符号预登记、离线门 G-NB、验证计划、变体轴、已关闭家族与关闭规则

本文是本臂候选定义、符号预登记、包级要求、验证计划、变体清单与关闭判据的**唯一权威表述**；`README.md` 与 `exploration-plan.md` 只指向本文，不复述。可见时点、单位与陷阱只写在 `pit-field-map.md`；文献与折扣写在 `references/northbound-holdings.md`，离线门的做法写在 `references/offline-screen.md`，读数出处写在 `sources.md`。起步包里每条腿的定义只有一处：`starter/lib/candidates.py`。

## 本轮的形状：一个不经学习器、也不叠在载体上的北向分数

本臂量的是一块本仓库从没读过的非价格信息：陆股通（北向）经香港中央结算有限公司持有的 A 股，在季度前十大股东表里露出的那一行。**它被做成一个独立的、不训练的分数，直接建书**，而不是叠在 Alpha158 + LightGBM 载体上的一块特征。理由是登记册的两条结论：

- **「特征块叠在固定载体上」已作为方法关闭**（研究教训登记 §4）：离线增量门的种子噪声底约 4 pp/年，20260923 / 20260924 两轮宿主上量到的块增量都在 −2.7…+0.5 pp/年，这个量级的增量离线门分不出真假，一次宿主批次也分不开。
- **载体自己的只做多书读不出与零技能可区分的主动收益**（登记 §3）：20260923 / 20260924 两轮的同一份 `c_base`（50 席、月度、100 万）五次宿主验证读主动 IR 0.077 / 0.094 / 0.103 / 0.132 / 0.189，差别全来自面板抽名；`learner_axis_1m_20260924` 那份略有不同的 `c_base` 读 0.262。四年主动 IR 在零技能下的抽样误差约 0.50。这些是登记册的账本读数，会话不能复核，只作先验。所以本臂**不把载体当量尺**：`n1` 的命题是「按北向持股选出的前 50 只，主动收益能与零技能区分」，由宿主每次验证自带的零技能面板直接裁决，**不以赢过 `c_base` 为条件**。

**两行登记要先说出来。** 研究教训登记 §2 把「不带授权的 100 万沪深 300 成分选名（手写 / 规则分数）」这个形状关在 `index_relative_1m_20260919` / `_1m_b_20260919` 上（旧口径；冻结的 `d2` 前推 IR −0.99 被丢弃，`_1m_b` 最优 IR 1.730 被当时的 DSR 门拒），`n1` 恰好落在这个形状上；§2 还关了「股东户数与机构持股」（DIR4，null）。本臂的开设已经对照这两行作出决定，理由是：那几个规则分数是价量、价值与低波，北向这块信息当时根本读不到（`top10_holders` 此前从没被任何一条臂选中）；DIR4 的机构持股读数只用了流通股东表（它在七个报告期缺三到五成公司），而且北向的股东类型是「一般企业」，不在它量的机构里（`pit-field-map.md`）。**这两行仍是先验**：本臂的结论要连同它们一起写进收尾笔记，一个 null 会被记成对 §2 那一行的加固，而不是一次新发现。

## 符号预登记（先于任何读数，改它就是改登记）

登记的是该量（决策日的截面值）与之后持有期收益的截面 Spearman 秩相关的符号。证据等级：**L** = 本仓库读过全文，**A** = 只读过摘要，**C** = 只有机制推断。文献全文与折扣在 `references/northbound-holdings.md`。

| 量 | 登记符号 | 等级 | 依据 | 已知的折扣 |
|---|---|---|---|---|
| `chg` | **正** | L | Liao、Tang、Xu：月度 AHVR 十分位多空 1.94 %/月（t 2.97，2017-06..2020-12，市值加权，无成本），大市值组 2.05 %/月，原始收益主要来自多头腿；换 4 / 8 / 16 个月均值窗口结论不变 | 穿透式监管（2018-08）之后北向流量的多空从 37.2 %/年 落到 8.8 %/年（He、Wang、Zhu，L）；本臂是季度、前十大截断、晚到一到四个月的代理 |
| `lvl` | **正** | C | 机制推断：外资长期偏好的那类公司（AHVR 与 ROA 同向）；**没有论文检验过持股水平**，Liao 等明说 AHVR 量的不是水平 | 与规模、质量高度相关，一个正读数可能只是风格；它是分数里先验最弱的一半 |
| `n1` | **正** | 由构造 | 两个正号分量的秩平均 | — |
| `n2` 中的 `chg` | **正** | L | 同 `chg` | 同上 |

**怎么报**：离线门的 screen（逐日秩 IC、h = 20 / 40 / 60）与月度书（逐月秩 IC）上，`lvl`、`chg`、`n1` 各报均值、t 与逐研究年的符号，写「一致 / 不一致 / 不显著（|t| < 2）」。**看过 IC 之后不得改登记符号**；要改就是一次新登记，重写 `hypothesis`，原登记与原读数照样留在结果笔记里。

**预期量级（同样先于读数登记）**：1.94 %/月 × 约 0.5（只做多、300 只里取前 50）× 约 0.25（改革后衰减）× 约 0.3（季度截断代理）≈ +1 %/年的主动超额、主动 IR 约 0.1–0.2。**冻结门在四个研究年、第一批的 N_eff = 3（宿主上的 `n1` 加申报的 2）时要主动 IR 约 1.41，即使 N_eff = 1 也要约 0.98**：本臂事先不指望冻结，它的信息价值在于把一块从没读过的非价格信息用最透明的形态量一次。

## 离线门 G-NB（北向分数版；整期批次之前必须通过，全离线，0 回放年；筛过的候选配置各计一个 trial）

登记的判据，一次写死：K1 覆盖不足，或 K2 秩 IC ≤ 0，或 K3 月度书输给同池零技能，⇒ 不进整期验证。

- control：`c_shuf` 与 `c_base` 永远写 control: true——照常花回放年、计入完整研究期验证数，但不是 trial，也永远不能提名；`n1`、`n2` 与任何变体写 control: false。把候选登记成对照，它就失去提名资格；把对照登记成候选，是白给自己加一个 trial。
- offline_trials = 本批申报前离线筛过、读数影响了本批提交什么、但本批没有提交的候选配置数；提交进本批的候选在宿主验证时按 host trial 计，不重复申报。

冻结门的试验数 M 是本臂验证过的非对照 revision 加上各批申报的 offline_trials，按 ρ̄ 折成有效试验数 N_eff = ρ̄ + (1 − ρ̄)·M；公式与阈值以运行事实 acceptance_rules.freeze_gate 为准（本轮默认 min_dsr_probability 0.975）。

| 判据 | 怎么算（做法在 `references/offline-screen.md`） | 命中 |
|---|---|---|
| **K1 覆盖** | 研究期每个复核日（自然月首个交易日，共 48 个），可交易池里 `lvl` 有值的份额，逐研究年取均值与最低 | **任一研究年的均值 < 80 %** |
| **K2 秩 IC** | `/mnt/tools/screen.py` 在 `/mnt/snapshot` 上，`--start 20210701 --end 20250630`，h = 20 的逐日秩 IC 均值（分数按「t 之后那个交易日的决策读到的分数」记在 t 上） | **`chg` 的 `ic_mean` ≤ 0，或 `n1` 的 `ic_mean` ≤ 0** |
| **K3 月度书** | 研究期每个复核日上 `n1` 的前 50 只（买得起、可交易）等额，持有到下一个复核日开盘，减同池等权均值（= 同池随机 50 只的期望）；研究期末视图里最后一个复核日（6 月）没有下一个复核日的开盘，实际 47 个月 | **四年平均 ≤ 0，或为正的研究年少于 2 个** |
| 诊断（只报不判） | `lvl`、`chg` 各自的 K2 / K3 读数；十分位剖面；200 本同池随机 50 只书的年化主动 p10 / p50 / p90 与 `n1` 所在的分位；`ic_size_neutral` | — |

**这道门能说什么、不能说什么**（研究教训登记 §4，逐条适用）：离线读数只有秩与方向可信，水平与幅度不可信（同一条检查里秩相关逐位复现，Δ 从离线 +5.54 pp/年 翻成实测 −0.63 pp/年）；离线的同池均值不是宿主面板（宿主走完整 Broker、按候选自己的成交骨架换名，实测比离线近似更严）；**门只能否决，永远不能证明边际**，裁决是宿主的整期批次。48 个月的主动均值误差很大，只有符号与逐年一致性有意义。

**`n2` 的离线否决（Family 2 才用）**：研究期后两年至少 60 个分散的决策日上，按宿主季度节拍离线拟合载体（从第三研究年第一个季度起用空状态目录连续拟合 8 个季度、调用起步包自己的 `main.fit`，每个决策日用它自己那个季度的模型打分；每次重建都把 `daily` 截在该决策日的 T-1、把宏观与事件域按可见时点截在该决策的 08:30），比较 `n2` 与载体单独的逐日秩 IC；**两个研究年里任一年 Δ 秩 IC（`n2` − 载体）≤ 0 ⇒ `n2` 不提交**。它同样只能否决，而且登记册已经写明这个量级的增量宿主分不开——所以 `n2` 若上宿主，按它自己的主动 IR 对冻结门读，不按它比 `c_base` 多了多少读。

> 子跨度验证只用来复测实现与耗时，不用来在候选之间做选择；提名依据仍必须来自完整研究期验证。

## 验证计划（先登记，再花回放年；本臂整期验证上限 6）

- **`control`**：`c_shuf`、`c_base` 永远写 `control: true`；`n1`、`n2` 与任何变体写 `control: false`。
- **`offline_trials`**：离线（包作者或会话）筛过、读数影响了提交什么、而没有提交的候选配置数；提交的配置按 host trial 计，永远不再按离线申报。每个配置只在筛过之后第一个记下验证的批次申报一次。
- **第一批的申报是 2，来历如下**：包作者在研究期末视图上筛过三个配置——只用 `lvl`、只用 `chg`、`n1`（`sources.md` 的离线门读数）；`n1` 提交，所以只用 `lvl` 与只用 `chg` 这两个筛过而没提交的配置在第一批申报，`offline_trials` = 2。会话自己再筛的任何变体（例如轴 a、轴 b 的一格）加到这个数上，在它筛过之后第一个记下验证的批次申报；看了读数改去提交某个变体，那么 `n1` 就变成筛过而没提交的配置，同样加 1。

| 批次 | 腿（按顺序，`control`） | 完整期验证 / 其中 trial / 回放年 | `offline_trials` | 进入条件 |
|---|---|---|---|---|
| 第一批 | `c_shuf`（true）、`n1`（false）、`c_base`（true） | 3 / 1 / 12 | 2（包作者筛过的只用 `lvl`、只用 `chg`）；会话另筛而没提交的变体每个加 1 | G-NB 通过 |
| 第二批（Family 2） | `c_base`（true）、`n2`（false） | 2 / 1 / 8 | 本批之前新筛而没提交的配置数 | G-NB 通过，且 `n2` 的离线否决没有命中 |
| 离线门否决之后（代替第一批） | `c_shuf`（true）、`n1`（false，本臂唯一的宿主 trial） | 2 / 1 / 8 | 2（同第一批：只用 `lvl`、只用 `chg`）；会话另筛而没提交的变体每个加 1 | K1 / K2 / K3 任一命中：以 `no_edge` 收尾本来就要本会话至少一次完整期验证，这一次花在登记的信号本身上，收尾那一行登记因此带着 `n1` 自己的宿主主动 IR、DSR 与逐年符号，旁边是它的打乱对照；之后按 K4 决定（杀死条件第 1、2 条） |
| 收官 | 冻结，或 `no_edge` | 0 | — | 见下文 |

**trial 账与它要求的 IR，事先算清**：第一批（或代替它的那一批）之后 M = 3（宿主上的 `n1` 加申报的 2），宿主上只有一个非对照 revision 时 ρ̄ 取 0，N_eff = 3，四个研究年、阈值 0.975 下过门要主动 IR 约 **1.41**；第二批之后 M = 4（`n1`、`n2` 加申报的 2），N_eff 随 `n1` 与 `n2` 的相关落在约 2.5–4，门槛约 1.35–1.5。每多申报一个离线筛过的配置，门槛就往上走一格（N_eff = 2 / 3 / 5 时约 1.24 / 1.41 / 1.58）。按预期量级（主动 IR 0.1–0.2），这张账事先说明本臂冻结的可能性很小。

## 已关闭的方向（研究教训登记 §2，本轮按当前登记重抄）

一条方向只在**它被测过的那个形状上**关闭。下表是本臂不得作为候选重开的全部家族；它们仍可作为对照腿，但**不得成为本臂的方向**。资金与授权形状是必填项。完整证据列在登记里。

| 方向 / 家族 | 关闭它的臂（资金 / 授权） | 关键读数 |

## 提名条件（冻结前逐条满足）

1. G-NB 已通过，K1 / K2 / K3 与诊断读数都写进结果笔记。
2. 完整研究期验证完成，冻结门按运行事实通过；完整期验证数达到运行事实 `min_full_span_validations`（对照也计入）。
3. **稳定性**：逐年分块的**主动**超额为正的研究年 ≥ 四分之三（四个研究年时 ≥ 3）。
4. **`c_shuf` 同批**，而且候选的主动 IR 不低于零技能第 90 百分位（下文杀死条件 K4 的那条线）。**不要求赢 `c_base`。**
5. P2 / P3 / P4 / P5 全部成立。
6. **集中度与换手**：`pnl_concentration.top5_share_of_gross_gains` ≤ 0.5；年换手 ≤ 12 倍；实测每月完成回合数 ≥ 1。
7. **实现底线**：单次复核决策 < 60 秒、容器内存峰值明显低于 16 GiB（载体腿另看 `fit` 秒数）；意图买单拒单率 ≤ 30 %；座位填满率与买不起份额逐次汇报。不成立先修实现再复测，不算证伪。

主动超额 ≤ 0、空对照分位在 0.5 附近、去膨胀 Sharpe 概率接近 0 都是普通「没有边际」读数：候选不可提名，不触发家族关闭。

## 什么会杀死它（按命中即停）

1. **G-NB 命中（K1 / K2 / K3）**——离线看不到登记方向的、落得到多头书上的秩信息。`no_edge` 需要的那一次完整期验证**花在登记的信号本身上**：唯一一批只放 `c_shuf`（`control: true`，第一条）与 `n1`（`control: false`），8 个回放年，`offline_trials` = 2（包作者筛过而没提交的只用 `lvl`、只用 `chg`，验证计划）；不加 `c_base`，Family 2 也不进场（它以 G-NB 通过为前提）。然后按 K4 判：`n1` 的主动 IR 低于那条线，以 `no_edge` 结束；越过它，回到正常路径（下面各条、变体轴与提名条件照常适用）。在这一批之前不换变体轴去追离线读数，除非命中的只是 K3 而 `chg` 本身的 K2 为正，此时允许轴 a 一轮（只用 `chg`）、重过 G-NB；仍命中就照本条提交登记的 `n1`，那一轮的变体另申报 1。
2. **K4：`n1` 在第一批完整期验证里的主动 IR 低于零技能第 90 百分位**，即 1.2816 × √(244 / T)（T 是完整研究期的交易日数；四个研究年约 **0.64**）——读数与零技能分不开。Family 1 关闭，不再为 `n1` 开任何批次。
3. 主动超额为负的研究年过半——关闭该候选。
4. 每一个可行席数上 `excess_at_2x_slippage` 都 ≤ 0，或实测每月完成回合数 < 1 且轴 c 的一轮也拉不回来——机制可能真实但这个形状不可交付，以「不可交易」关闭。
5. P2 在所有已登记构造下都不成立——关闭并写明是哪个行业带上去的。
6. `n2` 的离线否决命中，或 `n2` 在第二批里的主动 IR 同样低于 K4 那条线——Family 2 关闭。
7. 整期验证上限（6 条，对照也算）用尽而没有满足全部提名条件的候选——以 `no_edge` 携读数结束，不为了凑提名再开一批。

## 臂级终止规则

任一成立即本臂关闭：第 1 条命中且那一批里 `n1` 的主动 IR 低于 K4 那条线；第 2 条命中且 Family 2 不允许进场或已关闭；第 7 条命中；预算用尽前没有可提名候选。关闭以 `finish_session(outcome="no_edge")` 携读数结束本臂，**不换家族**，不把 `c_shuf` 或 `c_base` 改作候选。`no_edge` 是结论不是退路：它要带上 K1–K4 的读数、`lvl` 与 `chg` 的分解，以及对登记 §2 那两行的交代。
