# 北向持股独立分数参考包（northbound_holdings，20260925）

本目录是只读 refs。本包登记的是**一块本仓库从没读过的非价格信息，用最透明的形态量一次**：陆股通（北向）经香港中央结算有限公司持有的 A 股，在季度前十大股东表里露出的那一行——它占流通股的比例（`lvl`）与它相对自身过去一年均值的变化（`chg`）。两者在沪深 300 成分上取截面秩、各半平均成一个**不训练的**分数 `n1`，直接建一本 50 席、月度复核、等额现金的书，由宿主的零技能面板裁决。

## 为什么是这个形状

**不是叠在载体上的一块特征。** 研究教训登记 §4 已经把「特征块叠在固定的 Alpha158 + LightGBM 载体上」作为方法关闭：离线增量门分辨不了比约 4 pp/年 更小的增量，宿主上量到的块增量又都落在这条底之下。而且载体自己的只做多书在这个形状上读不出与零技能可区分的主动收益（同一份 `c_base` 五次宿主验证主动 IR 0.077–0.189，另一份 0.262；四年零技能抽样误差约 0.50——登记册读数，会话不能复核）。用它当量尺，量不出一块弱信息。所以 `n1` 自己建书，命题只有一个：**按北向持股选出的前 50 只，主动收益能不能与同池零技能区分**。它不以赢过 `c_base` 为条件。

**为什么是北向。** 数据湖里从没被读过、又在研究期整段有覆盖的非价格信息很少，北向这一行是其中唯一有大市值、月度 horizon 文献证据的：Liao、Tang、Xu 的月度异常北向持股（AHVR）十分位多空 1.94 %/月，大市值组 2.05 %/月，原始收益主要来自多头腿（全文读过）。它也是唯一一路在研究期、前推期与 Held-out 都连续存在的北向信息——港交所 2024-08 起不再逐日披露个股北向持股。**它从没被读到过的原因是数据**：两张前十大股东表各自有若干报告期只返回了部分公司（只读其中一张，沪深 300 里带北向行的在薄期只剩 0–18 只），只有并集完整（每季 268–291 只），而总股东表 `top10_holders` 此前从没被任何一条臂选中。

**登记在先的限制。** 文献的水平一个都搬不过来：它是 2017–2020 年、逐日持股、市值加权十分位多空、不扣成本；穿透式监管之后北向流量的多空收益从 37.2 %/年 落到 8.8 %/年；本臂读到的是季度的、前十大截断的、晚到一到四个月的代理。逐项折扣之后预期约 +1 %/年的主动超额、主动 IR 0.1–0.2，**远低于冻结门**（`families.md` 的预期量级与 trial 账）。登记册 §2 还有两行与本臂相邻——「不带授权的 100 万沪深 300 成分选名（手写 / 规则分数）」与「股东户数与机构持股」——它们为什么不挡本臂、又为什么仍是先验，写在 `families.md` 的开头。

**包作者的离线读数是否定的，而且是在登记之后才读的。** 包作者在同一张 `/mnt/snapshot` 上按登记跑过离线门 G-NB：`n1` 的逐日秩 IC 与月度书都没有越过零（K2、K3 命中），`lvl` 读出与登记相反的符号，`chg` 与登记同向但落在零技能带内（读数与先后时间在 `sources.md` 开头）。**会话要自己按 `references/offline-screen.md` 重算一遍**：一致，就按 `families.md` 杀死条件第 1 条——唯一一批只放 `c_shuf` 与 `n1`（8 个回放年、`offline_trials` = 2：包作者筛过而没提交的只用 `lvl`、只用 `chg`），`n1` 的主动 IR 低于 K4 那条线就以 `no_edge` 收尾、读数写全，越过它才回到正常路径；不一致，先查是哪一步的重建与包作者不同，再按登记走。不得因为已经知道读数而改登记。

## 按以下顺序读

1. `families.md`：分数的逐条定义、四条腿（`n1` / `c_shuf` / `c_base` / `n2`）、**符号与预期量级的预登记**、**离线门 G-NB**、**先登记的验证计划与 trial 账**、变体轴、已关闭家族表、提名条件与杀死条件（**唯一权威表述**）。
2. `pit-field-map.md`：两张股东表的列、单位与可见时点，北向行的名字规则，逐回放年的输入窗，成分截面与基准日线的读法与陷阱（唯一权威表述）。
3. `exploration-plan.md`：第 0 轮普查、离线门、批次顺序、判定分支与预算。
4. `references/`：六份自写笔记——**`northbound-holdings.md`**（文献、本仓库看得见的样子与折扣，**先读它**）、**`offline-screen.md`**（离线门的做法与能说明什么）、零技能面板、账户算术、成分面、`fit` 与决策的成本。沙箱无网络，外部出处列在 `sources.md`。
5. `sources.md`：本包在本轮种子上实测到的覆盖、秩 IC、月度书与宿主冒烟，以及诚实的限制。
6. `starter/`：合同内的最小可运行包，**就是**四条腿本身，`main.py` 的 `CANDIDATE` 在 `n1` / `c_shuf` / `c_base` / `n2` 之间切换，它们除这一行外逐字相同。**会话开始时 `output/` 就是这份代码**，`refs/starter/` 只是同一份的只读参考副本；正式回放的第一步仍然是 `smoke_backtest`。

## 你被评的是主动序列

每次正式验证结束后，**宿主**按候选自己的成交骨架随机换名重放若干份，取日收益等权均值作为**零技能面板**，再在「候选减面板」的主动序列上算全部统计量。包不设零技能对照腿的门，也不设信息比率或去膨胀 Sharpe 的门——这些是流水线的，写在运行事实里。读法写在 `references/zero-skill-panel.md`；本臂最该记住的三条：

- **绝对超额说明不了任何事。** 同一段研究期，沪深 300 成分 30 席的零技能面板读 +8.57 %/年，全市场 30 元以下 15 席读 −4.67 %/年。
- **面板对齐股票池、日历、每笔的钱与成本，但不对齐权重方案。** 本臂每条腿都是等额现金，因此不欠机制归因对照；任何非等额变体都被禁止。
- **`c_shuf` 是同批的一次零技能抽样**：同一个分数分布、同一本书、信息被打乱。它的主动 IR 落在零附近一个标准差（约 0.5）之内是正常的；`n1` 要的是越过零技能第 90 百分位（`families.md` 的 K4），不是赢过 `c_shuf` 的那一次读数。

## 本臂的执行边界

执行合同——入口与订单、允许的 import、文件 I/O、`available_at` 与 PIT 读法、不写死宿主路径、沙箱无网络——以只读 `output/README.md` 与系统提示为准，本包不复述。本包只在以下几点上更具体：

- `n1` 与 `c_shuf` **不训练**：`fit` 直接返回，每次复核读一次日线面板与一次两张股东表。`c_base` 与 `n2` 读载体，季度重训续训，booster 只经 `save_model` 写进 `context.state_dir`；**`models/` 只放随产物交付的静态资产**。
- **本臂 `gpu_count = 0`，纯 CPU**；策略容器按 **8 核 / 16 GiB** 设计，`--memory-swap` 与 `--memory` 同值：超了不是变慢，是直接 OOM 失败。
- **两张股东表缺一张、窗口里读不到可见行、或读到的列不全，起步包直接报错**——不设退路：回放失败好过悄悄交易一个缺一半公司的分数。
- 股东表**没有 `trade_date`**，窗口按 `ann_date` 取；**北向行不是 H 股托管行**；**报告里没有北向行是截断，不是零**——三条都写在 `pit-field-map.md`，任何一条弄错，分数都会安静地变成另一个东西。
- 不要把 `refs/` 里的文件拷进 `output/`：整棵包是只读的，`cp` 会把权限一起带过去。

## 账户与成本

研究期几何、预算、冻结门与毕业条件以运行事实为准。**开工第一件事是读自己的运行事实**：`broker_replay.initial_cash`、`benchmark_index`、`acceptance_rules` 里有没有跟踪授权、两个回撤上限、`budgets` 与 `max_replay_years`，以及 `research_geometry.years[].input_window`（每个回放年自己的输入窗，`pit-field-map.md`）。本包按 **100 万元、不带跟踪授权**写成：50 席时座位约 19,400 元，可负担性与最低佣金都退成舍入误差（`references/capital-arithmetic.md`），剩下的问题才是「这块信息选名选得对不对」。分数一个季度才变一次，所以换手低、成本小，但**前推期要求每月至少 1 个完成回合**——第 0 轮要把换手与回合数实测出来，不能假设。

## 「没有边际」的读法

每个候选按 `families.md` 的提名条件与杀死条件逐条读，不看整窗总收益。另外三点：

- **读主动读数**：`benchmark.active_neutralized_excess` / `active_tracking_error` / `active_information_ratio`、`benchmark.panel_neutralized_excess`、`sub_windows[].active_neutralized_excess_return`。
- **`lvl` 与 `chg` 要分开报**：离线门里各自的秩 IC 与月度书读数。`n1` 读正而全部来自 `lvl`，说明它是一个风格（规模、质量）而不是北向的增量信息，`size_tilt` 与 `size_beta` 要并排读。
- **读数会成团**：分数只在公告季集中变化，逐年、逐季的读数比整期均值更能说明它是不是一个稳定的效应。

没有候选证明边际时，不冻结是正当结果：按 `families.md` 的终止规则以 `no_edge` 携读数结束本臂。**「北向持股的季度代理在沪深 300 上与零技能分不开」本身就是登记册要的一行**。

## 本包的硬要求

跨实验的运行教训不写在参考包里（见 `inputs/skills_index.json` 的运行记忆）。本包在流水线之外只加五条，全部写在 `families.md`：预登记（P1）、行业与规模并排汇报（P2）、成本、换手与活动量（P3）、按主动读数导航（P4）、北向覆盖与分解逐年汇报（P5），外加一道必须在整期批次**之前**通过的**离线门 G-NB**——它全离线、不花回放年，但它筛过的候选配置各计一个 trial（提交的按宿主，没提交的按离线申报）。
