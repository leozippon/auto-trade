# Alpha158 风格的本地特征

Qlib `Alpha158` 是一大组日频算子（kbar、价格位置、滚动统计、量价相关等）。本包 **不要求** 原列名，也不要实现 158 列。
先核对本轮 daily 字段，再用 T-1 冻结 qfq 重算下面四组。窗口必须有足够真实观测，否则该股票该特征为空。

记 `C/O/H/L/V` 为 T-1 冻结价与成交量，`r = C/C.shift(1)-1`，`A` 为成交额（不复权）。分母为 0 则空。

## 1. kbar（OHLC 关系）

| 本地名 | 转述 |
| --- | --- |
| `k_mid` | `(C-O)/C` |
| `k_len` | `(H-L)/C` |
| `k_up` | `(H-max(O,C))/C` |
| `k_low` | `(min(O,C)-L)/C` |
| `k_body_range` | `(C-O)/(H-L)`，与 Alpha101 `#101` 同类，只留一个 |

这些是单根 K 线形状，不是未来开盘。

## 2. 滚动收益

| 本地名 | 转述 |
| --- | --- |
| `ret_5` / `ret_10` / `ret_20` | `C/C.shift(n)-1` |
| `ret_1` | 最近一根可见收益，常作短端输入而不是单独下单理由 |

不要同时把短端反转和长端动量以同一符号塞进线性组合而不做消融。

## 3. 滚动波动

| 本地名 | 转述 |
| --- | --- |
| `std_5` / `std_20` | `std(r, n)` |
| `range_20` | `max(C,20)/min(C,20)-1` |

低波动是否该得正分，必须由 Validation 决定；先验可先作风险惩罚（线性组合里给负号）。

## 4. 量比

| 本地名 | 转述 |
| --- | --- |
| `vma_ratio_5_20` | `mean(V,5)/mean(V,20)` |
| `turn_ratio_5_20` | 若有归一化换手：`mean(Turn,5)/mean(Turn,20)` |
| `amt_ratio_5_20` | `mean(A,5)/mean(A,20)` |

三选一，避免同义重复。量纲不同必须先各自截面标准化。

## 截面处理

对每个决策截面、每个特征：

1. 只保留当时已上市、未停牌、值有限的行。
2. 1%/99% 截尾（可选）。
3. `z = (x-mean)/std`；`std==0` 则该列为空。
4. 任一用于打分的特征为 NaN 则该股票不进入排名，不要填 0。

不要在全历史股票全集上算均值方差。不要用 Qlib 的 `RobustZScoreNorm` 拟合区间——那是另一套处理器；本地用**当日可见截面**的均值方差，或用截至 T-1 的滚动可见截面统计，二者选一并保持稳定。

## 标签（仅训练历史权重时）

若做 OLS/ridge，标签必须在推断时已经实现。可用的保守做法：用 t 日 T-1 特征对应随后已经走完的那一次 09:30→次日 09:30 或收盘→收盘收益，因此当天决策最多用到更早样本的系数。
Qlib 示例标签 `Ref($close,-2)/Ref($close,-1)-1` 是他们平台上对 T+1 的处理，**不能**在本策略里按字面用未来收盘。
不要把对方论文/README 的 IC 当本地标签质量。
