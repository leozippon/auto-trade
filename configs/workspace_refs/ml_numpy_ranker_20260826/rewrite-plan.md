# Fold-ready 改写计划

目标不是复现 Qlib 的 CSI300 报表，而是检验：T-1 日频截面分数 + 当场拟合的线性排序 + 受控换手，在本环境含成本 Validation 里是否站得住。
本折的 Validation 覆盖约一整个日历年（约 240 个交易日），输入窗是它之前约 24 个月，可用的完整 Validation 次数远多于候选数量（上限以本轮事实为准）。默认就要把拟合排序器跑出来，并在一折内比较多个变体，不要把它留到某个更晚的阶段。

1. 读本轮 `data_summary.json`、daily schema、单位表。确认 OHLC、成交量/额、换手列的真实名字。缺列就改映射，不要臆造 `KMID`/`ROC5` 等 Qlib 列名一定存在。
2. 固定股票池、`k`、`n_drop`、再平衡频率和现金缓冲。先用小 `k`（例如 20–50）和 `n_drop`（例如 2–5），这些是声明值，不是待拟合参数。
3. 按 `context.asof_version` 读有界 T-1 日线尾窗：给 `columns=` 和日期窗口，别整段读全历史。08:30 丢弃 `trade_date` 为今日或更晚的行。复权用 T-1 冻结锚，见因子包同一纪律。
4. 实现 `features.md` 的四组本地特征，各做截面 z-score，NaN/Inf 丢行。先跑一次**对照基线**：等权或符号加权分数 + 流动性过滤篮子。这是后面所有比较的对照，不是本折的目标产物。
5. **默认候选是当场拟合的 numpy 排序器**：在推断时可见的 PIT 窗口上解 ridge 闭式解 `w = (X'X + λI)^{-1} X'y`，或对二分类标签（前若干分位 = 1）做少量梯度步的 logistic。`λ`、拟合窗长度、标签口径全部事先声明；标签必须在推断时已经实现，绝不用未走完的收益拟合当天权重。拟合链路放在 `fit(context)`，用模块级 `REFIT_PERIOD`（如 `"quarter"`）声明重训节奏，系数 `np.save` 到 `context.state_dir`；`generate_orders` 只在 30 秒内读系数、算当日特征、出单。
6. 加上 `ranking.md` 的 top-k 与 n_drop：尽量保留与当前持仓的交集，只替换最差的 `n_drop` 只。对照「每日重排 top-k、无换手控制」。
7. 一折内至少完成三次互不相同的完整 Validation，例如：对照基线、拟合排序器、以及一个结构性变体（换特征组、换拟合窗/标签口径、或加一层深度 ≤2 的规则）。特征组不必逐折只开一组；同一次拟合就能给出各组的边际贡献，用它来决定留哪几组。
8. 稳健性按 Validation 年的两个半窗和四个子窗分别报：相对对照的超额、拟合系数符号、有效覆盖、换手、拒单。系数符号在子窗之间乱翻，或超额只出现在一个子窗，判该候选失败，即使整年合计好看。能在输入窗上离线复算的口径，也报一次逐季符号一致性。
9. 显式退化：样本不足、矩阵奇异或有效覆盖过低时退回等权/符号加权，并在订单 metadata 里标明发生了退化——不要静默切换，更不要偷偷 import sklearn。若整个 Validation 年大部分决策都在退化路径上，说明拟合口径不成立，改口径或淘汰。
10. 把最小完整胜出方案写入 `output/main.py`。不要提交训练脚本、qlib yaml、`joblib` 模型或 `models/*.pkl`。

## 明确禁止

- `import sklearn` / `lightgbm` / `qlib` / `joblib` / `torch`。
- 在推断时 `read_pickle` / 加载 `.pt`；拟合结果只经 `fit` 以 `.npy`/`.npz`/parquet 写入 `context.state_dir`。
- 把 Qlib 示例里的 CSI300 年化、IC、超额抄进注释当目标。
- 在策略内实现另一套日频回测或组合优化器。
- 用未来 `Ref($close,-2)` 标签在当日拟合。Qlib 那样做是他们平台的 T+1 处理；本环境 Broker 已经处理 T+1，策略不得偷看未实现收益。

## 对照

| 候选 | 必须比过的对照 |
| --- | --- |
| 等权/符号加权特征 | 纯流动性/市值过滤篮子 |
| ridge / logistic 拟合 | 同一特征的等权或符号加权 |
| n_drop | 每日全换 top-k |
| 规则层 | 没有规则的线性分数 |

对照胜出就保留对照。拟合版本要保留，必须在含成本收益与年内子窗一致性上都不劣，且至少一项明显更好；两者难分时看哪一个的子窗符号更稳，仍分不出才留更简单的那个。
