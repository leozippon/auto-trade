# 候选、对照、增量信息门、变体与关闭规则

本文是本臂候选定义、对照、硬门、变体轴、提名条件与关闭判据的**唯一权威表述**；`README.md` 与 `exploration-plan.md` 只指向本文，不复述。可见时点、单位与陷阱只写在 `pit-field-map.md`；算术与口径写在 `references/`，读数出处写在 `sources.md`。

**本包有一个主候选 `x1`、两条对照 `c_temporal` 与 `c_lgbm`。** 三者在 `main.py` 里只差 `CANDIDATE` 一行，其余逐字相同。会话要改的全部默认值在 `lib/knobs.py`，每一条只出现一次。

## 主候选：市场门控的截面注意力排序器（`x1`）

| 组件 | 起步定义（`starter/`） |
|---|---|
| 股票池 | 决策日可见的最新一张沪深 300 成分截面；训练用截面里的全部成分，**下单只在可交易的那一部分**（剔科创板与北交所——整手粒度不同——以及名字含 ST/退的） |
| 每个名字的输入 | 最近 `WINDOW_DAYS` 个交易日的 158 个 Alpha158 算子，每一天都在**当天成分**这个截面上逐列稳健 z 标准化（中位数 / 1.4826×MAD，缺失记 0，截断 ±3）。**与对照读的是同一份特征面**，只是对照只取最后一行 |
| 时序编码器 | Linear(158 → `HIDDEN`) → GELU → GRU(`HIDDEN` → `HIDDEN`) → 取最后一步 → LayerNorm |
| 市场门控 | 基准当天的五个数（1 / 5 / 20 日收益、20 日已实现波动、收盘离 20 日均值的距离），**按固定尺度缩放并截断 ±3，不拟合任何统计量**（拟合出来的归一化会让训练日与决策日口径不同），经两层小网络出一个门向量，`sigmoid` 后逐维缩放每个名字的状态。`MARKET_GATE` 关掉即去掉这一层 |
| 截面注意力 | 一层 `HEADS` 头自注意力，**query/key/value 都是当天成分的状态集合**（一个日期 = 一个长度为成分数的序列），残差；再接一个残差前馈混合层 |
| 头 | 线性出一个分数 |
| 标签 | 信号日 t 的前 `HORIZON` 日开盘到开盘收益，减 `β ×` 基准同窗前向收益（β = 滚动 120 日 OLS、向 1 收缩 0.7、截断 0.3–2.0），`LABEL_INDUSTRY_DEMEAN` 为真时再按申万一级去均值，最后逐日截面取秩 `(rank−1)/n − 0.5` |
| 训练 | 每季度首个决策日在 `fit` 内重训。训练日 = 最近 `TRAIN_YEARS` 年里标签在 T-1 已实现的信号日；验证 = 其中最后 `VALID_DAYS` 日，训练段在验证起点前至少 `HORIZON + 2` 个交易日结束。一日一个批次（这一天的全部成分是一个序列），损失 = −Pearson(分数, 标签秩)，Adam，验证 IC `PATIENCE` 轮不升即停并取回最好一轮 |
| **热启动** | `WARM_START` 为真时，重训先从 `state_dir` 读回上一次的权重，再以 `WARM_LEARNING_RATE` 续训 `WARM_EPOCHS` 轮；读不到（每次回放的第一次 `fit`）才冷启动 `MAX_EPOCHS` 轮 |
| 集成 | `SEEDS` 里每个种子各训一个模型，复核时对各自的截面秩取平均 |
| 设备 | CUDA；没有 CUDA 即报错，不写 CPU 路径 |
| 篮子 | `SEATS` 只等额现金；每个 ISO 周（`REVIEW`）首个决策日复核；持仓离开可排序池即卖出，名次落到 `SEATS × KEEP_BAND` 之外且有替补时卖出；每次最多换 `MAX_SWAPS` 只（被迫卖出先算）；卖出 09:30、买入 15:00，按最近整手四舍五入再按现金截断 |

## 两条对照

| 名称 | 是什么 | 身份 |
|---|---|---|
| `c_temporal` | **同一个时序编码器与头，关掉跨名字注意力**。同池、同标签、同训练日期、同种子、同热启动、同一本书；`MARKET_GATE` 仍然按 knob 生效 | **机制归因对照**：跨名字注意力本身加了什么。永远不可提名——它就是已经关闭的纯时序家族换了一套输入 |
| `c_lgbm` | **同一份特征、同一个标签、同一个池、同一组训练与验证日期**上的 LightGBM（单点参数，不是网格；参数写死在 `lib/control.py`，**不是 knob**），每季度冷重训 | **G-INC 的量尺，也是本仓库唯一毕业过的那个形状**。永远不可提名 |

`c_lgbm` 故意不热启动：热启动是候选的机制，对照也带状态会把两件事混在一起。

**两条对照加上 `MARKET_GATE` 这个 knob，正好把本臂的主张切成三块**：时序编码（`c_temporal` 且门关）、市场门控（`c_temporal` 且门开）、跨名字注意力（`x1`）。任何一次整期批次都必须能说清自己在量哪一块。

## G-INC：增量信息门（**本轮硬门，两条臂相同**）

**在花掉任何一次完整研究期验证之前**，必须先量出 `x1` 相对 `c_lgbm` 的增量，并把读数与判定写进 `hypothesis`。这一关整条在**离线**做（第 0 轮，`shell`，不启动回放、不花 replay-year、不增加 `trials`）：

| 读数 | 口径 |
|---|---|
| **ρ（相关）** | `x1` 与 `c_lgbm` 分数的**逐日截面秩相关**，在至少 60 个跨越四个研究年、互不重叠的决策日上取中位数 |
| **Δ 主动超额** | 同一形状（同池、同席数、同节奏、等额现金）下两条书的**离线主动超额**：各自减去在**同一成分侧**按同一成交骨架抽的 k = 20 份零技能面板 |
| **顶端读数** | 最好 `SEATS` 只相对同池等权的前向收益，按研究年分开 |

**判定（命中即停，不许事后改口径）：**

- **ρ > 0.7 且 Δ 主动超额 ≤ 0** → 学习器只是对照的一个更弱的版本，**不进整期批次**。换一条登记的变体轴（`WINDOW_DAYS`、`MARKET_GATE`、`HORIZON`）重新离线量一次；两次都这样就按关闭条件 1 关掉这个方向。
- **ρ > 0.7 且 Δ 主动超额 > 0** → 可以进批次，但 `hypothesis` 里必须写明「增量很可能来自同一份信息的更好排序」，并在第 1 轮同批带上 `c_lgbm`。
- **ρ ≤ 0.7** → 注意力确实在看别的东西。照常进批次，同批仍要带 `c_temporal` 与 `c_lgbm`。

**这条门的来历**：`gru_ranker` 的分数与它的 LightGBM 对照逐日秩相关 **0.74–0.88**，研究期读数低于对照的每一个种子，最好 15 只相对池均值每 10 日 **−0.03 %**（对照 +0.47 %），项目仍然花掉整条臂去跑，前推读到 **主动 IR −2.44**。**这条门就是那条臂的账单**，而本臂的架构与那条臂最近，所以它在本臂上尤其要紧。

## 本包另加的要求（流水线不检查的那部分）

| # | 要求 | 读哪里 |
|---|---|---|
| P1 **预登记** | 每一次完整研究期批次**之前**，把假设、机制、预期读数与**证伪条件**写进 `hypothesis`；同时写明本轮之后的累计 `trials`。事后改口径不算 | `hypothesis` |
| P2 **敞口预算** | `stats.benchmark.top_industry_weight` ≤ **0.30**（时间加权的单一申万一级行业权重）；字段读不到即不可提名。同时把 `size_tilt` 与 `size_beta` **并排汇报**，两者不设门 | `stats.benchmark` |
| P3 **成本** | `cost_sensitivity.excess_at_2x_slippage` > **0**，并在结果笔记里用本臂运行事实的 `initial_cash` 把佣金账重算一遍 | `stats.cost_sensitivity` + 自算 |
| P4 **导航** | 每一个验证行都按**主动读数**读：`benchmark.active_neutralized_excess` / `active_tracking_error` / `active_information_ratio`、`benchmark.panel_neutralized_excess`、`sub_windows[].active_neutralized_excess_return`、`selection_statistics` 的 `series` / `information_ratio` / `positive_years` | 每个验证行 |
| P5 **权重方案的机制归因** | 任何**不是等额现金**的加权方案，必须在**同一批**里跑一条「同一分数、等额现金」的版本。起步包用等额现金，所以默认不欠这笔账；改了就要补 | 同一批的对照行 |
| P6 **热启动要能读出来** | 每次整期批次的结果笔记里写：一次回放里发生了几次重训（订单元数据 `refits`）、热启动有没有生效（`warm_start`）、各次的验证 IC（`valid_ic`），以及 `WARM_START` 关掉之后的同批对照读数（至少做一次） | 订单元数据 + 同批对照 |
| P7 **种子差** | 提名之前必须有**两个种子**的主动信息比率之差。这个家族的方向研究在三个种子之间散开过 4 pp/年 的 alpha，**比种子差还小的优势不是证据** | 同一批的两条腿或逐种子读数 |
| P8 **门与注意力分开报** | 市场门控与跨名字注意力必须各自有一次同批对照读数（`MARKET_GATE` 开/关、`x1` 对 `c_temporal`）。**独立移植没能把门控与不加门控区分开**，本臂不能只报合起来的那个数 | 同一批的对照行 |

## 允许的变体轴（一轮只改一个可分离组件）

| 轴 | 起步值 | 允许的变体 |
|---|---|---|
| a **序列窗口** | `WINDOW_DAYS` 天 | 20–60 之间。**加长之前先量显存与 `fit` 秒数**，前向与训练步都与它成正比 |
| b **注意力** | 一层 `HEADS` 头 | `HEADS` 在 1–8 之间；`HIDDEN` 在 32–128 之间；把注意力层数加到 2（**只有在一层已经分得开 `c_temporal` 时才做**） |
| c **市场门控** | `MARKET_GATE` 开 | 关掉（P8 要求至少做一次）；换市场状态的定义（加成交额或涨跌家数之类，仍然要固定尺度、不拟合统计量） |
| d **标签** | `HORIZON` 日残差收益秩 | `HORIZON` 在 5–20 之间（**只登记一次，换了要重走 G-INC**）；`LABEL_INDUSTRY_DEMEAN` 打开 |
| e **训练窗口与节奏** | `TRAIN_YEARS` 年、季度重训 | `TRAIN_YEARS` 在 2–3 之间；`REFIT_PERIOD` 改 `"month"`（**先量 `fit` 成本**） |
| f **热启动** | `WARM_START` 开、`WARM_EPOCHS` 轮 | 关掉（冷重训，即本仓库此前的做法）；改 `WARM_EPOCHS` / `WARM_LEARNING_RATE` |
| g **构造** | `SEATS` 只等额、周度、`MAX_SWAPS` 换名上限 | `SEATS` 在 30–100 之间；`REVIEW` 改月度；`KEEP_BAND` / `MAX_SWAPS`。**非等额权重方案要补 P5** |

**禁止**：用前推期或 Held-out 的任何信息；在 `generate_orders` 里训练；把训练好的权重放进 `models/` 以跳过重训（`models/` 是只读静态资产目录，`fit` 写不了它，权重只能进 `state_dir`）；按月或更短的**增量微调**（方向研究里月度增量微调把篮子拉低约 10 个百分点/年——注意这与本包的**热启动**不是一回事：热启动仍然在完整的滚动窗口上重训，只是不丢掉初值）；把注意力的 mask 改成只在行业内（**那是同轮另一条臂的机制，不要在本臂里重做**）；为追读数改股票池的定义；在种子数之外做随机搜索。

## 提名条件（冻结前逐条满足）

1. 完整研究期验证完成，且冻结门（主动 IR、去膨胀 Sharpe 概率等）按运行事实通过。**冻结门与毕业条件全部是流水线的，本包不复述也不另设。**
2. **G-INC 已经过**，且第 1 轮同批的 `c_lgbm` 与 `c_temporal` 读数都在步骤树里。
3. **稳定性**：逐年分块的**主动**超额为正的研究年至少占四分之三（四个研究年时 ≥ 3）。
4. **回撤**：绝对回撤与主动回撤都在运行事实的两条上限之内。建在指数里面的书绝对回撤天然贴着沪深 300 自己的 39.6 %，**这一条比信息比率更可能杀掉候选**。
5. **成本**：P3 成立。
6. **敞口**：P2 成立。**主动信息比率再高，P2 不成立也不可提名。**
7. **集中度与换手**：`pnl_concentration.top5_share_of_gross_gains` 不超过 0.6；年换手不超过 12 倍。
8. **实现底线**：`phase_seconds` 里单次 `fit` 不超过 1,800 秒（上限的一半，留给卡上与主机上的争用）；容器峰值内存**明显低于 16 GiB**；显存峰值低于 12 GiB；单次复核决策低于 60 秒；意图买单拒单率 ≤ 30 %。不成立先修实现再复测，不算证伪。
9. **P6、P7 与 P8 的读数齐了。**

主动中性化超额 ≤ 0、面板分位在 0.5 附近、去膨胀 Sharpe 概率接近 0，都是普通「没有边际」读数：候选不可提名，不触发家族关闭。

## 什么会杀死这个方向（按命中即停）

1. **G-INC 连续两次（换过一条变体轴）都判「相关高且无增量」** —— 跨名字注意力在这个池子上没有可辨识的增量信息，本臂以 `no_edge` 结束。
2. **连续两轮完整研究期验证都没有满足提名条件的 `x1` 家族候选**（含各变体轴）—— 本臂以 `no_edge` 结束。
3. **`x1` 与 `c_temporal` 的主动读数在两轮里都分不开** —— 那本书里没有截面注意力，只有时序编码；而时序编码这一族已经关过一次。关闭这个方向，**不要靠加头数或加层数去追**。
4. **逐年主动超额为负的研究年连续两轮都过半** —— 研究期里就不是多数年份都在，关闭。
5. **P2 在所有已登记的构造下都不成立** —— 关闭并写明是哪一个行业把它带上去的。
6. **提名条件 8 修复一次后仍不成立**（例如某变体在卡上训练超时或显存超限）—— 该变体放弃，不算家族证伪。

## 点名禁止（四条）

1. **退回逐股学习器**：`c_lgbm` / `c_temporal` 不得被提名，也不得把注意力改成事实上只看自己。
2. **未筛的全市场池**：池必须是按时点从 `index_weight` 读出来的成分。硬编码名单、或者用别的指数建书而仍按沪深 300 报跟踪误差，都是否证条件。
3. **单一申万一级行业集中的书**：P2 不成立即不可提名。
4. **用 Held-out 或前推期的任何信息**，包括「按某一年的表现挑种子」。

## 禁止重开（继承自本轮之前各包的禁令）

下表在本包里是**禁令，不是可重开的先验**。本臂的预算只花在截面注意力这一族上；任何一条走不通时按终止规则收尾，不要绕回这里。

| 家族 | 为什么不再开 |
|---|---|
| GRU / DecompGRU 逐股序列排序器、增量微调、GBDT+GRU 集成 | `gru_ranker` 家族。研究期 +8.06 %/年、IR 0.694、4/4 年正，**前推主动 IR −2.44**。本包的 `c_temporal` 只能作对照 |
| Alpha158 + LightGBM 作**主方向** | 它是本包的对照 `c_lgbm`，不是候选。那条谱系唯一一次毕业被项目自己标成薄且未确认 |
| 按行业或相关图做消息传递 | **同轮另一条臂的机制**，不要在本臂里重做，否则两条臂不再可比 |
| 质量三柱 overlay、52 周高比、指数内 percent accrual、价值 overlay（EP/BP）、行业中性相对价值、中期残差动量、盈利 / 现金流收益率集中、20 日反转作开局 | 20260921b/c/d 各臂已关。本轮不是手写分数的轮次 |
| 风险模型事前 TE 预算、授权内有界 tilt | 已关。本臂不带跟踪授权，也不用因子协方差去压跟踪误差 |
| 事后每行业上限、行业 × 规模桶内填位、池内截底、波动目标敞口缩放 | 构造层的这几格都量过：上限 2 只 +9.70 对不设桶 +11.39；事后每行业上限 IR +0.40 → −0.45；波动目标把回撤从 39 % 压到 22 % 而超额从 +8.5 落到 +6.3 |
| 宏观择时、事件窗、分钟域、文本 | 择时类主张空对照判不了；分钟域本轮没挂；文本接口八分之七在 2026-08-13 冻结。**市场门控不是择时**：它不改仓位，只改截面排序 |
| sleeve 合成、对已知存活列做学习型合成 | 残差不够正交，增量解释不了；DIR6 的学习型合成为 null，换个随机种子读数走 7–15 个百分点 |

## 已关闭家族：先验，不是围栏

上表之外，本仓库还有一张更长的已关闭家族表（价值、质量、低波、反转、事件面、资金面、融资拥挤、分析师修正……），它们都是在**旧的裁决口径**（绝对中性化超额，没有零技能面板）、在**各包自己的股票池**上关闭的。在本包里它们的身份是**先验**：本臂不以它们作候选，但可以作为**输入特征**的来源——要加特征列时，先在 `hypothesis` 里说明它在本臂的池子与口径下与当初有什么不同。

一条必须记住的通用读数：**股票池的结构性倾斜是窗口的性质，不是研究结果。** 同一段研究期里，沪深 300 成分 30 席的零技能面板读 **+8.57 %/年**，全市场 30 元以下 15 席读 **−4.67 %/年**。所以「跑赢基准」几乎不说明任何事情；只有主动序列说明问题。

## 臂级终止规则

- 一轮里没有候选满足条件：不冻结，把每个变体轴的读数、失败的是哪一条、下一步要检验的分支写进结果笔记，再换轴。
- 同一条变体轴在两轮里都没有满足条件的候选：关闭这条轴，本臂不以同一假设重开。
- **所有已登记的变体轴都试过至少一个取值，且没有任何一次完整研究期验证在主动超额与 2 倍滑点超额上同时为正** —— 本臂以 `no_edge` 结束。
- **`no_edge` 是结论，不是退路**：只有在**没有一条还有先验的变体轴可换**或**预算已经花完**时，才以 `finish_session(outcome="no_edge")` 携读数结束本臂；不要让预算耗尽（流水线记 `deadline`）代替这个结论，也不要为了有一个交付而冻结一个不满足条件的候选。
