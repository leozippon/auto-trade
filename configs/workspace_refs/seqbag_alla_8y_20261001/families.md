# 已关闭的近邻（seqbag_alla_8y，20261001）

本页只列研究期读数：每条都是宿主在该臂研究期完整验证上的主动读数（候选减零技能面板、对基准与规模价差中性化之后），出处是各臂账本的验证节点。这里不写任何一条臂在研究期之后的事，也不写哪条臂有没有被冻结；会话也不需要这些——本臂的门只看本臂自己的节点与运行事实里的 `information_ratio_bar`。

列的含义：**IR** 整期主动信息比率；**超额** 年化主动中性化超额；**正年** 主动超额为正的研究年数；**主动回撤** 主动序列最大回撤；**逐年标准差** 八个研究年主动超额的样本标准差（本臂 F2 用的就是这个量）。

## 4. 这些近邻留给本臂的问题

单头臂一条一条地读出了「头」这一维的散布：同一份输入、标签与书上（100 万 / 30 席），原始形单头 0.60–1.51、残差形 −0.86–1.12，树对照 0.46–0.55，而同一份代码重跑就能动 0.17。本臂问的不是「哪个头最好」（那一维已经扫完、按臂关闭），而是「把结构不同的头平均起来，读数是不是更稳」：

- 如果袋的整期读数不低于它自己的一个成员（`c_single`），逐年标准差更低，换一组种子时变化也比 `c_single` 小——这是一条更稳的载体，不是新的 α；
- 如果袋落在成员之间、逐年形状不比成员平——它就是 `seed_bag_1m_20260926` 那条先验在序列配方上的复现，配方的边在输入、标签与书，头只是噪声。

两种结局都是登记册要的一行。
