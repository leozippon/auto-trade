# 低残差波动桶内选名参考包（lowvol_bucketed，20260917）

本目录是只读 refs：把**低 60 日残差波动**当排名信号，把**行业与规模的桶**当选名约束，做一个不训练的只做多季度篮子，并按预登记的对照判定「桶内选名」这件事本身在组合尺度上是否真的在承载。它不是可提交策略，也不是预期收益。

任务只有一句话：在同一个股票池里，**先按流通市值截到较大的一半、再剔掉应计最差的一成，然后按 60 日残差波动升序把篮子填到 15 只——每个申万一级行业至多 2 只、每个流通市值三分位至少 1 只——季度复核**，同批比过三个对照——**去掉桶的同分数篮子**（`c_uncapped`）、**同样的桶换成固定随机分数**（`c_rand`）、**没有分数的等权池篮子**（`c_pool`）。赢不过 `c_uncapped` 说明桶没有用；赢不过 `c_rand` 说明赢的是分散化而不是这条腿；赢不过 `c_pool` 说明两者都不在。判据只按 `families.md`。

按以下顺序读：

1. `families.md`：主候选与构造、三个对照、**提名硬门与禁止表（关闭判据的唯一权威表述）**、允许的变体轴、臂级终止规则。
2. `pit-field-map.md`：逐表可见时点、单位、去重规则与陷阱（唯一权威表述）。
3. `exploration-plan.md`：不占预算的普查、首轮批次、判定分支、后续轮次。
4. `sources.md`：构造规则的来源读数、本包自己的研究期普查读数、起步包的沙箱冒烟实测、诚实的限制。
5. `starter/`：合同内的最小可运行包（`main.py` + `lib/face.py` + `lib/trade.py`），**不是**候选本身。它通过 `validate_strategy_package`，并在沙箱镜像里以真实 as-of 布局跑通了「读取 → 波动与报表 → 打分 → 中性化 → 桶内填位 → 出单」全链路（读数见 `sources.md`）；正式回放的第一步仍然是 `smoke_backtest`。`main.py` 的 `CANDIDATE` 常量在四条腿之间切换，四者除这一行外必须逐字相同。**会话开始时 `output/` 就是这份代码**，`refs/starter/` 只是同一份的只读参考副本。

## 机制与本臂要回答的那一个问题

收益来源的经济解释是：散户主导、卖空受限的市场过度需求彩票型暴露——高近期波动、注意力、账面好看的盈利——而低估其反面。相对自身 20 日波动、规模、换手、动量与行业而言，60 日残差波动低的名字在一到三个月里挣到稳定的溢价。

但本臂要答的**不是这条腿在不在**，而是**把分数变成篮子的那一步**。裁决统计量把日度策略收益对沪深 300 与一个规模因子做二元回归，截距年化就是中性化超额——它只看得见这两件事，一个集中的行业或风格暴露在它眼里就是 alpha。整池排名会连带选中一个行业格与一个规模格，而这部分正是最可能不持续的部分。本臂登记的假说是：**把选名放进「申万一级行业 × 流通市值三分位」的桶里做，能保住截面信息、去掉这个连带。**

这件事在本仓库里第一次以这种形状被测。已经被关掉的是另一个形状——先整池排名、再按行业事后砍名，以整窗超额判定——`families.md` 的禁止表带着它的研究期读数。本臂的上限进入选名本身、计在实际要持有的篮子上（保留带留下的持仓一并计数）、并以信息比率与集中度判定，是另一个主张。判它成不成立的那一半就是 `c_uncapped`。

**必须先知道的一件事：这个构造在研究期上多半只动一两只名字。** `sources.md` 记着五个研究年首个决策日的实测：不设桶的前 15 只在其中四天已经有某个行业占到 3 只，设桶之后的篮子与它重合 14/15，三分位配额一天都没有触发。所以本臂测的是一个**小**扰动，门 2 要求严格高于 `c_uncapped` 是一条相当硬的线；把上限收紧到 1 只是 `families.md` 登记的第一条变体轴，不是临时决定。

**成形的代价必须一起报**：池底会同时压低跟踪误差、回撤和**规模暴露**，桶会再压一次。中性化超额是把规模因子除掉之后的读数，所以「去掉小市值暴露」会同时改善裁决统计量并减少实际赚到的钱。本臂的门定在中性化统计量上（流水线的冻结门与前推裁决都读它），但**每个候选都必须把原始超额与规模倾斜作为第二读数一起汇报**（`stats.benchmark.excess_return`、`stats.benchmark.size_tilt`、`stats.benchmark.beta`），说明它到底在优化哪一个。`style_analysis.json` 是宿主侧的旁文件，会话读不到它，不要去找；行业集中度从 `stats.benchmark.top_industry_weight` 读。

## 本臂的执行边界

执行合同——入口与订单、允许的 import、文件 I/O、`available_at` 与 PIT 读法、不写死宿主路径、沙箱无网络——以只读 `output/README.md` 与系统提示为准，本包不复述。本臂只在以下几点上更具体：

- **本包不训练**：没有 `fit`、没有 `REFIT_PERIOD`，每次决策是四次有界的 parquet 读取、一次 60 日滚动回归加一次最小二乘。学习型合成是禁止项（`families.md`），不是变体。本臂 `gpu_count=0`。
- `c_rand` 的随机分数是**每个代码一次永久抽签**，种子写死在 `lib/face.py`：它必须在冷 worker、热 worker 与任何后续轮次里给出同一个值，也不得随决策日重抽——重抽会把一个分散化对照变成一个高换手对照，两件事就混了。种子不得改动。
- 本臂不挂分钟域（运行事实 `execution_policy`），执行时点只有 09:30 与 15:00。
- 不要把 `refs/` 里的文件拷进 `output/`：整棵包是只读的，`cp` 会把权限一起带过去；会话开始时 `output/` 已经是 `starter/` 的内容，不必移植。

## 账户与成本

研究期几何、预算、冻结门与毕业条件以运行事实为准，会话流程见系统提示，本包不复述；本臂以 `no_edge` 结束的条件见 `families.md` 的终止规则。

账户与费率以运行事实 `broker_replay` 为准。按本臂的 15 只等额、97 % 仓位，单只预算约 6,300 元，最低佣金即 7.9 bp/边，一次往返约 25–35 bp。起步节奏是**季度复核、2 倍保留带、每次最多换 8 只**：按此上限每年约 32 次换名 ≈ 200 % 年换手 ≈ 0.5–0.6 % 的年成本拖累（第 0 轮普查用研究期实测核对；沙箱冒烟在研究首年头 68 个交易日实收 152 元）。桶会让换手略高于不设桶的同分数篮子——被上限挡住的名字要用次一档的名字补上——两条腿的换手差本身就是要汇报的读数。成本门是本臂的硬门，判据写在 `families.md`。

## 「没有边际」的读法

每个候选按 `families.md` 的提名硬门逐条读，不看整窗总收益；本文不复述判据。另外四点读法：

- **门 5 与门 6 过了不算证据。** 行业集中度与规模倾斜是本臂的机制**买来的**东西，桶一设上它们就该达标。证据只有门 1（信息比率 ≥ 0.95）与门 2（严格高于三个对照）。
- 逐年读。防御型篮子在下跌年份的原始与中性化超额都偏好看，在宽幅高波动的上涨年份又会被压到零附近；把 `stats.sub_windows` 的逐年读数与整窗读数一起读，并写明哪一年撑起了整窗。本臂的门 3 要求四个研究年全为正，这是一条比姊妹臂更硬的线，也是这条腿已知的弱点所在（`sources.md`）。
- 中性化是机制定义的一部分，不是可删的降噪：残差波动排名不对 `vol_20`、`max_20`、规模、换手、动量与**行业哑变量**中性化，本臂就退回到一个每个参考包都禁止的通用低波打分，`c_uncapped` 也就不再是只差一个桶的对照。
- `run_null_control` 只给完整研究期的决赛候选算（次数见 `budgets`），**在本臂里是诊断不是门**，理由与要一起报的两个数写在 `families.md`。研究期整窗读数好看不等于前推成立：不要把提名条件当目标函数去逼近。

没有候选证明边际时，不冻结是正当结果：按 `families.md` 的终止规则以 `no_edge` 携读数结束本臂。

## 低波腿有意重开了一个已登记的家族

每个参考包都把「低波」列进不得作候选的通用因子。本包把 60 日**残差**波动作为**排名信号**登记，并用三件事把它和已关闭的 20 日彩票/低波面区分开：中性化列里必须含 `vol_20` 与 `max_20`（否则它就是那条已关腿的换皮）、`c_rand` 对照（否则无法判断边际到底来自这条腿还是来自桶），以及本臂真正登记的是构造而不是这条腿——腿是从姊妹臂借来的固定件，不是本臂的自由度。旧臂里的 `ivol60` 腿从未被证伪：它在两个验证窗里都存活、空对照分位 0.97，只是输给了同臂的另一个冠军，那条臂整体终止时它跟着关了。

## 禁止退回通用因子

本包的候选形态只有 `families.md` 登记的主候选与变体轴；手写的价值/反转/动量/换手/`max20`/`vol20` 打分不得作为候选，只能以中性化列的身份出现。`c_uncapped`、`c_rand`、`c_pool` 是对照，**不得被提名冻结**。把排名列换掉、或把质量改回排名信号，都是别的臂的内容，在本臂里是禁止项。`families.md` 的禁止表里每一项都带着关掉它的研究期读数，不得以「再试一次」的名义重开。

## 本包的硬要求

跨实验的运行教训不写在参考包里（见 `inputs/skills_index.json` 的运行记忆）。本包只指两条硬要求：**普查面板与决策截面必须由同一个函数构建**（`starter/lib/face.py` 的 `build_cross_section`），**构造规则必须由同一个函数施加**（`starter/lib/trade.py` 的 `_shape` 与 `_book`）；四条腿都走这两个函数，只由 `SHAPES` 与 `CANDIDATES` 里的一行区分。
