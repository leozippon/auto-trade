# 主候选、对照、提名硬门与禁止表

本包有**一个主候选**、**三个对照**、**一张提名硬门**和**一张带读数的禁止表**。本文是本臂候选定义、提名与关闭判据、变体清单的**唯一权威表述**；`README.md` 与 `exploration-plan.md` 只指向本文，不复述。可见时点、单位与陷阱只写在 `pit-field-map.md`。

本臂登记的机制是**「分数 → 篮子」这一层的构造**，不是一条新的数据面。排名列与股票池都直接沿用姊妹臂 `lowvol_quality_20260916`，改的只有把分数变成篮子的那一步。

## 主候选 `s_lb`：排名是残差波动，构造是桶内填位

**排名分数**（截面百分位秩，只用推断时点已可见的数据）：

| 列 | 定义 |
|---|---|
| `ivol60` | 最近 60 个可见交易日个股日收益对沪深 300 日收益（`macro.index_daily`，`pct_chg` 百分数 ÷ 100）回归的残差标准差，两者均有值的日数 ≥ 40 |
| 分数 | `1 − rank(ivol60)` |

沪深 300 不在本轮宏观选择内时用总波动（不回归）并在每张买单的 `vol_basis` 元数据里写 `total`——这是登记的变体，不是静默回退。

**中性化**（分数层，除两条无面的对照外所有腿共用，候选不得删减任何一列）：对 `log_circ_mv`、`mom_20`、`mom_60`、`r_5`、`turn_20`、`vol_20`、`max_20`、`ep`（`1/pe_ttm`，非正记 0）、`yoy_np`（最新可见报告的归母净利润同比，累计值对同名下推四行）的截面百分位秩与**申万一级哑变量**做最小二乘残差化。`vol_20` 与 `max_20` 是这条腿的定义所在：不对它们中性化，本臂就是一个通用低波打分。哑变量也不得删：删掉它，桶就在替中性化做本来该由分数做的事，两件事混在一起本臂就答不出机制归因。

**分数层的行业中性化不等于篮子层的行业分散**，这是本臂存在的理由：残差化只把行业均值从分数里除掉，15 只名字仍然可以落在同一个行业里。`sources.md` 记着两个研究期读数——一个分数层同样残差化过的质量篮子，时间加权最大单一申万一级权重 45.4 %；一个完全无信息的等距池篮子，首个决策日就有 3 只同业。

**构造**（每个复核日，按顺序）：

1. **池底**：把可选池按 `circ_mv` 截到较大的一半（`CAP_FLOOR = 0.5`）。
2. **应计筛子**：在剩下的名字里按 `accr` 降序剔掉最差的一成（`ACCR_SCREEN = 0.1`）——盈利没有经营现金流支撑的那一端。
3. **桶内填位**：按中性化分数降序把篮子填到 15 只，一只名字只有在它的申万一级行业在**本次复核实际要持有的这个篮子**里还不足 `INDUSTRY_CAP = 2` 只时才入选。保留带留下来的持仓先就座，并给行业计数器播种。
4. **三分位配额**：填完之后，若某个流通市值三分位（`CAP_TERCILES = 3`，在第 2 步之后的筛后池上按位次三等分，0 是最小的三分之一）在篮子里没有代表，就用该三分位里分数最高、行业还有余位的名字，换掉**本次新入选**的名字里分数最低、且其三分位仍有第二个代表的那一只；保留带留下来的持仓不被替换。换不成时篮子少覆盖一个三分位，每张买单的 `tercile_cover` 元数据写实际覆盖数——这是要汇报的读数，不是可以吞掉的意外。
5. 15 只等额，100 股整手。

**上限必须计在「实际要持有的篮子」上，不能计在「新排出来的前 15」上**：保留带会留下排名在前 15 之外的持仓，而对这些持仓的行业不计数，上限就从保留带漏掉了。按本规则，上限由归纳保持——留下来的座位来自一个已经满足上限的篮子，空出来的座位在以它们播种的计数器下填，所以任何一次复核都不会把某个行业推过 2 只。

**上限是复核日的只数上限，不是权重上限**：两只同业名字在季度之内涨得多，时间加权权重会高于 2/15。提名硬门读的是时间加权量 `stats.benchmark.top_industry_weight`，两者不是同一个数。

`accr` 的定义（与姊妹臂逐字相同）：`accr = (n_income_attr_p − n_cashflow_act) / total_assets`，同一份**首版**报表的年初至今累计值；报表 = 三张表按 `(ts_code, end_date)` 内连接、`report_type = "1"`、各取最早可见版本，事件时点取三者中最晚的 `available_at`；最新报表年龄 > 130 个交易日即无信号，名字离开股票池。

**股票池**（所有腿共用，不得逐候选变动，与姊妹臂逐字相同）：非北交所、非科创板（200 股起买）、`universe.name` 不含 ST/退、上市 ≥ 120 天、T-1 收盘价 ≤ 30 元、ADV20 ≥ 3,000 万元、T-1 未停牌、最近 60 个交易日内有 ≥ 40 个可见日、最新报表年龄 ≤ 130 个交易日且 `accr`/`ocf_ta` 都有值。池必须与姊妹臂逐字相同，否则两臂的读数不可比。

**节奏**：每个自然季度的首个决策日复核一次（以及回放的第一个决策），2 倍保留带，每次最多 8 只自主换名（离池强卖不占这 8 只）；持仓只在离开成形后的池、或名次落到 15 × 2 之外时卖出。信号全年都有，没有淡季政策。

## 三个对照（每一轮都必须同批、同跨度跑）

| 腿 | 分数 | 构造 | 检验什么 |
|---|---|---|---|
| `c_uncapped` | 同一个 `1 − rank(ivol60)` | 同一个池底与应计筛子，**去掉桶** | 机制归因。候选在信息比率上不高于它 → 桶没有用，本臂登记的那件事不成立 |
| `c_rand` | 固定随机分数：每个 A 股代码一次永久抽签（种子写死，不随决策日变） | 同一个池底、应计筛子与桶 | 桶本身不是边际。候选不高于它 → 赢的是分散化，不是这条腿 |
| `c_pool` | 无分数：把可选池按 `ts_code` 排序后取 15 个等距位置上的名字 | 不成形、不设桶 | 组合尺度的底线。可选池有两三千只、这个账户买不下，所以等权池对照取的是它在组合尺度上的分层抽样 |

三个对照**不得被提名冻结**。四条腿在 `main.py` 里只差 `CANDIDATE` 一行。`c_pool` 与 `c_rand` 没有面，因此不做中性化——把等距展开或一次随机抽签残差化，会把一个无信息的篮子变成残差排名的篮子。

`c_uncapped` 与姊妹臂 `lowvol_quality_20260916` 的主候选是同一个构造，逐字相同：同一个池、同一个分数、同一套中性化列、同一个季度节奏与保留带。两臂的读数因此直接可比，姊妹臂给出的任何完整研究期读数都可以当作本臂 `c_uncapped` 的独立复核；但本臂仍必须**同批**跑自己的 `c_uncapped`，跨批次的读数不作归因依据。

### 姊妹臂结束时留下的 `c_uncapped` 先验（研究期读数）

`lowvol_quality_20260916` 已以 `no_edge` 结束，它的主候选 `s_lq` 就是上面那个逐字相同的构造。本臂的 `c_uncapped` 因此有**两份互相复核的完整研究期读数**——`s_lq` 与姊妹家族的 `c_ivol`（后者的整表在 `sources.md`）：

| 读数 | `s_lq` | `c_ivol` |
|---|---|---|
| 中性化超额 | +11.39 %/年 | +11.39 %/年 |
| 残差跟踪误差 / 信息比率 | 15.3 % / **0.745** | 15.0 % / **0.761** |
| 最大回撤 | **31.2 %** | **33.2 %** |
| 逐年中性化超额 | +32.2 / +19.0 / **−12.1** / **−6.4** | +31.8 / +18.7 / **−14.1** / **−4.7** |
| 规模倾斜 / β | 0.549 / 0.935 | 0.553 / 0.95 |
| 四年回合数 | 120 | 120 |
| 时间加权最大单一行业 | 8.4 % | 8.9 % |

两份读数同一个池、同样的 +11.39 %/年、同样 120 个回合，而且在同样的第三、第四个研究年转负——这条腿的逐年缺口不是一次抽样意外。姊妹臂的关闭理由还记着两件对本臂直接有用的事：它五条完整研究期腿的最大回撤全部落在 **29.6–38.2 %**，没有一条接近 22 %；流水线自己的去偏 Sharpe 门（0.75 @ 5 trials）**不是**卡点，卡死的是臂级的信息比率、逐年一致性与回撤。

读法，本臂的先验据此再下调一档：**门 5 在起步构造上本来就成立**（8–9 %，离 0.30 很远），桶直接作用的正是这条腿唯一不短的地方；差着的是门 1（0.75 对 0.95）、门 3（2/4 对 4/4）与门 4（31 % 对 22 %）。所以先用最便宜的方式把桶这个轴判掉，再把预算花在逐年一致性与回撤上——顺序写在 `exploration-plan.md`，门与阈值不动。

## 提名硬门（唯一权威表述）

一个候选**全部满足**下列各项才可提名冻结；任一项不成立即不可提名，读数照常写进结果笔记。

| 门 | 判据 | 读哪里 |
|---|---|---|
| 1 信息比率 | 完整研究期的中性化超额 ÷ 残差跟踪误差 ≥ **0.95** | Step 行的 `neutralized` 块 |
| 2 归因 | 在信息比率上**严格高于** `c_uncapped`、`c_rand` 与 `c_pool` 三者；同批同跨度 | 同一批的对照行 |
| 3 逐年 | 四个研究年的中性化超额**全部为正**（4/4，不是 3/4） | `stats.sub_windows` |
| 4 回撤 | 完整研究期最大回撤 ≤ **22 %** | `stats.max_drawdown` |
| 5 行业集中度 | `stats.benchmark.top_industry_weight` ≤ **0.30** | `stats.benchmark` |
| 6 规模与 β | `abs(stats.benchmark.size_tilt)` ≤ **0.30**，且 `stats.benchmark.beta` 落在 **[0.7, 1.2]** | `stats.benchmark` |
| 7 成本 | `cost_sensitivity.excess_at_2x_slippage > 0` | `stats.cost_sensitivity` |
| 8 活动量 | 完整研究期平均每年完成的回合数 ≥ **12**；意图买单拒单率 ≤ 30 %；平均总仓位 ≥ 0.5 | `stats.trade_count` ÷ 研究年数、`stats.order_count` 与执行明细、`stats.exposure.avg_gross` |
| 9 实现底线 | 每个复核日第 2 步之后可选名字 ≥ 200；每张买单的 `tercile_cover` = 3；多日回放上每次决策的**平均**墙钟 < 30 秒 | 第 0 轮普查与 `smoke_backtest` |

门 5 与门 6 是本臂的机制本身要买的东西，所以**过了它们不构成证据**：证据是门 1 与门 2。反过来，门 5 的字段在结果里读不到时，该候选不可提名——核对不了的门不得当作通过。门 9 的每次决策墙钟按多日回放的平均读，不按单日探针读：单日冷回放在宿主争用下可以读到 20 秒以上，而同一份代码在 68 日回放上的平均是 6 秒左右（`sources.md`）。

**空对照是诊断，不是门。** `run_null_control` 的 `excess_percentile` 比的是**原始**超额、只按流通市值分位给名字配替身，并且会丢掉真篮子做成的一部分回合，因此任何非规模的截面载荷都容易把它推高；本臂照常给决赛候选跑一次，并把 `excess_percentile`、`dropped_trips_mean`、`rejects_mean` 三个数一起写进结果笔记，但**不据此提名或否决**。它回答的是「在这个窗口里，赢的是名字还是择时」，仅此而已。

每个候选还必须把**原始超额与规模倾斜作为第二读数**写进结果笔记（`stats.benchmark.excess_return`、`stats.benchmark.size_tilt`、`stats.benchmark.beta`）。池底与桶都会同时压低跟踪误差与规模暴露，中性化超额是把规模除掉之后的量，所以只报中性化超额会掩盖「赚到的钱变少了」。缺这一项的结果不作为提名依据。

冻结门本身（完整研究期验证次数与去偏 Sharpe 概率）以运行事实为准，与上面的门独立：两者都过才冻结。

## 禁止表（每一项都带着关掉它的研究期读数，不得重开）

前八行的读数来自同一份组合构造研究：排的是姊妹家族的**质量**分数，跨度是研究期最后两个半研究年，口径与复现命令见 `sources.md`。它们量的是「分数 → 篮子」这一层，与排的是哪一列无关，所以在本臂同样是禁止项；本臂读到相反的方向时，写进结果笔记，但不得据此在本轮重开。

| 禁止项 | 关掉它的读数 |
|---|---|
| 篮子放宽到 20 只以上 | 同一分数、同一季度节奏：15 只中性化超额 +8.5 %/年，20 只 +1.9，30 只 −0.9。跟踪误差确实从 21.5 降到 17.3，但边际住在前 15 名里 |
| 月度复核 | 每个宽度上都不如季度：15 只 +8.5 → +7.0，30 只 −0.9 → −9.0 %/年，而年成本翻一倍 |
| **先整池排名、再按行业砍**（每行业 2–3 只的事后上限） | 同一季度 15 只：+8.5 → −8.0 %/年，信息比率 +0.40 → −0.45，换手 1.43 → 1.55，最大回撤 39.0 → 40.6。**这一行关掉的是「先排后砍、以超额判定」那个形状。本臂登记的是桶内填位——上限进入选名本身、计在实际持有的篮子上、以信息比率与集中度判定——是另一个主张，不是把这一行重开**；两者同批可比的那一半正是 `c_uncapped` |
| 按 `r_5` / `mom_20` / `turn_20` 做入场择时的二次排序 | 把前 30 名按这些列升序重排：+8.5 → −3.5 / −9.7 / +0.3 %/年 |
| 融资拥挤筛除（`rzye/circ_mv` 最高一成或两成，或其 20 日增量） | +8.5 → −0.1（最高一成）/ −3.9（最高两成）%/年，最大回撤原地不动（约 40 %） |
| 与价量分数按日再平衡混成两个 sleeve | 两条腿的 80 % 自助下界是 +8.9 与 +0.3，混合后 +6.5——混合是对「选错腿」的对冲，不是边际。两个组合的日收益相关度 0.71 |
| 分批建仓（把入场摊成 3 / 6 / 12 期） | 跟踪误差不降（21.5 → 21.7–22.9）；+8.5 → −0.2（k=3）/ +9.0（k=6）/ +2.5（k=12）%/年，换手却升到 1.9–2.9 |
| 波动目标敞口缩放 | 它是回撤工具不是超额工具：回撤 39 → 22 %、跟踪误差 21.5 → 11.5 % 的同时超额 +8.5 → +6.3 %/年 |
| 把质量改回排名信号（两条腿等权合成，或质量排名 + 波动筛子） | 姊妹家族的质量排名臂已以 `no_edge` 关闭：其主候选完整研究期中性化超额 +4.37 %/年、信息比率 0.33、最大回撤 31.7 %，低于同批两个对照 |
| 把申万一级哑变量从中性化列里删掉，让桶去承担行业中性 | 那样两件事混在一起，`c_uncapped` 就不再是只差一个桶的对照，本臂的机制归因作废 |
| 对存活列做学习型合成（LightGBM 回归器/排序器） | 本仓库已有的学习型合成研究判为 null。**那份研究读过研究期之后的行，本包因此不引用它的任何读数**；本臂不训练，这是合同不是变体 |
| 把池底收紧到前三分之一（`CAP_FLOOR = 0.33`） | 姊妹臂在同一个池、同一条 `ivol60` 腿上跑过这个变体并证伪：信息比率 0.745 → **0.561**、中性化超额 +11.4 → **+7.5 %/年**、规模倾斜 0.549 → **0.71**；最大回撤只从 31.2 降到 29.6 %，离 22 % 仍差得远。池底 0.5 因此是从姊妹臂借来的固定件，不是本臂的自由度 |

## 允许的变体轴（一轮只改一个可分离组件）

| 轴 | 起步值 | 登记的变体 |
|---|---|---|
| a 行业上限 | `INDUSTRY_CAP = 2` | `1`（更紧）。第 0 轮普查若读到上限几乎不咬（`sources.md` 的五个研究期读数上它每次只动一只名字），这是第一条要走的轴 |
| b 三分位配额 | 每个三分位至少 1 只 | 每个三分位至少 3 只；或改在池底**之前**的全池上分三分位 |
| d 应计筛子 | `ACCR_SCREEN = 0.1` | 最差的两成 |
| e 波动窗口与尺度 | `ivol60`（沪深 300 残差） | `ivol120`；总波动 `vol60`（也是宏观域缺沪深 300 时的声明回退） |
| f 保留带 | 2 倍 | 1.5 倍（篮子只数不是变体，见禁止表） |

字母 `c` 空着：池底那条轴已被姊妹臂的研究期读数关闭（见禁止表），其余字母不重排。本轮全部候选被证伪后，下一轮必须换轴而不是换阈值。

## 什么会杀死它（按命中即停）

1. 门 2 对 `c_uncapped` 不成立，且按轴 a 把上限收紧到 1 只之后仍不成立 —— 桶没有用，本臂以 `no_edge` 结束，把逐年的差写进读数，**不换家族**。
2. 门 2 对 `c_rand` 不成立 —— 同样的桶、同样的节奏、一个随机分数就能做到，这条腿没有在承载，立刻关闭。
3. 门 2 对 `c_pool` 不成立 —— 桶与腿都不在，直接以 `no_edge` 结束。
4. 门 3 在两轮里都不成立（总有一个研究年为负）—— 这条腿在研究期里就不是每年都在，关闭。
5. 门 7 不成立 —— 机制真实但在这个账户不可交易；跑完一轮保留带变体（轴 f）仍不成立即以「不可交易」关闭。
6. 门 1、4、5、6、8 不成立 —— 候选不可提名，按变体轴继续。
7. 门 9 不成立 —— 先修实现再复测。

## 臂级终止规则

任一成立即本臂关闭：上面的关闭条件 1–5 任一成立；连续两轮完整研究期验证都没有可提名的候选；登记的变体轴用尽。关闭即以 `finish_session(outcome="no_edge")` 携读数结束本臂，**不换家族**，不得回退到通用价量打分。
