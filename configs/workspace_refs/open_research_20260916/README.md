# 开放方向参考包（open_research，20260916）

本目录是只读 refs：本臂**不指定机制家族**。任务是在研究期上找到一个只做多、15–30 只的日频策略，它的边际要有经济解释、在书本尺度上成立，并且有理由在一个没人看过的前推年里继续成立；找不到就诚实地以 `no_edge` 结束。它不是可提交策略，也不是预期收益。

与上一条开放臂相比，本包改了三件事，其余照旧：

- **按什么提名**：从「整窗中性化超额高于股票池」改为**信息比率与回撤**。前推门要求年化中性化超额的 80 % 自助下界为正——大致相当于超额高于 0.84 倍的跟踪误差——并要求最大回撤不超过参数上限。一个整窗超额很高但跟踪误差 20 % 以上的候选，在研究期上好看，在一个前推年上过不了门。判据见 `standards.md`。
- **什么算候选**：**筛子与叠加规则和排序分数一样是一等候选**。本仓库的方向搜索已经把「再找一个排序分数」这条路走得很宽；「用一条已知的腿排序、用一件别的信息把书本风险砍掉」这一层几乎没有被系统地试过。
- **先离线读书本尺度**：任何方向在花回放预算之前，必须先离线读出它在 **15 只与 30 只**上的**逐研究年**读数。冻结门按本臂验证过的全部 revision 打折，所以用回放做筛选是直接把冻结门的分母变大。

按以下顺序读：

1. `standards.md`：证据标准、**已关闭家族表**、每个候选都要比的对照、提名条件与收尾规则（唯一权威表述）。
2. `pit-field-map.md`：本轮可用的数据、逐域可见时点、单位与陷阱（唯一权威表述）。
3. `exploration-plan.md`：不占预算的普查与离线筛选、首轮批次、回放预算。
4. `sources.md`：对照读数与出处、起步包的沙箱冒烟实测、诚实的限制。
5. `starter/`（候选名 `o1`）：合同内的最小可运行包（`main.py` + `lib/composite.py` + `lib/trade.py`）：四个信息家族各一条秩腿——现金流盈利质量、60 日残差低波、20 日反转、价值——等权合成、对规模中性化，月度复核的 20 只篮子。它通过 `validate_strategy_package`，并在沙箱镜像里以真实 as-of 路径跑通了「读取 → 合成 → 中性化 → 出单」（读数见 `sources.md`）。**它只是一个能跑的基线，不是推荐的机制**：可以改任何部分，也可以整个换掉；正式回放的第一步仍然是 `smoke_backtest`。**会话开始时 `output/` 就是这份代码**，`refs/starter/` 只是同一份的只读参考副本。

## 最重要的教训

这些来自本仓库此前所有研究臂的记录，每条都有过真实代价（出处见 `sources.md`）：

- **15 只的集中度会吞掉池内信号。** 研究期的方向研究里，控制后 IC t ≈ 5–6 的学习型分数做成 15 只、有价格上限的只做多篮子后可以是零甚至为负；靠广度挣钱的信号在 15 只里尤其薄。每个方向在花回放预算之前，先在书本尺度上读：池内最好 15 只与 30 只相对池均值，按研究年分开，扣掉成本线。复合分数也要拆开读：多次出现过单腿打败探针里「最强」合成的情况。
- **卡住候选的常常是构造，不是分数。** 同一个分数换一种分数到篮子的映射，跟踪误差与最大回撤可以差一半，而整窗超额只差一两个百分点；反过来，放宽篮子、加行业上限、按反转或动量择时入场、分批建仓在本仓库都被量成负的（`standards.md` 的已关闭表列出了读数）。这是本包把筛子与叠加规则列为一等候选的理由，也是提名改按信息比率与回撤的理由。
- **成本是真实的。** 10 万元账户、最低佣金 5 元：15 只时单边约 8 bp、一次往返 25–35 bp；每周换 2 只的学习型篮子一年约 6 倍换手、约 2 % 成本。10 日标签的学习型分数改成月度复核后，中性化超额落到 0 附近；月度的慢特征一年成本约 1 %，季度约三分之一。先写成本线，再谈边际。
- **下跌年份会美化每个低 β 篮子。** 研究期内沪深 300 有过一整年的大跌，防御型篮子在下跌年份的原始超额与中性化超额都偏好看；上涨的高波动年份又会把它们压到零附近。只读中性化超额，逐年读，并说明哪一年撑起了整窗读数。
- **单个窗口的裁决被行情主导。** 季度级的中性化超额噪声大且依赖路径：同一份可执行文件在同一个季度上的三次读数从 +7 % 到 −19 % 不等；一个研究年的领先或落后也不是结论。选择与关闭都要完整研究期的证据，逐年分块里多数年份同向。
- **季节性的信息流要季节性地读。** 年报、一季报集中在春季，半年报在八月，三季报在十月，十二月到一月与七月几乎没有新公告；依赖公告的腿要写清淡季怎么办，并且每个研究年都要有足够的旺季观测。
- **适应写在产物里。** 冻结之后没有人再改它：学习型模型用 `fit` 与 `REFIT_PERIOD` 在最近 2–3 年上滚动重训（季度；20 日标签且重训很快时可以月度），规则型篮子每次决策重算自己的滚动估计。在最近几周上增量微调在本仓库里是有害的。`state_dir` 在每次回放开始时为空。
- **研究期整窗读数好看不等于前推成立。** 不要把提名条件当作目标函数去逼近：逐年分块、机制归因对照与空对照分位是同等的硬门，任何一项塌了，整窗读数就不再是证据。

## 硬合同

- 正式策略写在 `output/` 包内：入口固定为 `output/main.py` 的 `generate_orders(context)`，返回严格 JSON 订单数组；可选 `fit(context)` 与 `REFIT_PERIOD`。辅助模块放在 `output/` 下并用绝对导入，每个 `.py` 受同一套静态检查。
- 正式 import 只允许：纯计算标准库、`numpy`、`pandas`、`scipy`、`sklearn`、`lightgbm`、`xgboost`、`statsmodels`、`torch` 及其子模块，以及 `output/` 内自己的模块。本臂 `gpu_count=0`：任何训练都在容器 CPU 上完成，一次 `fit` 不超过 `budgets.strategy_fit_timeout_seconds`（3,600 秒）。
- 沙箱无网络。不要写死 `/mnt/agent/workspace`。先核对本轮 `data_summary.json` 与 `unit_reference.json`，再经 `context.asof_dir` 读数，每次读取都给 `columns=`、`filters=` 与日期窗口；as-of 域读失败**不得**回退 `snapshot_dir`。
- 每一行输入必须在推断时点可见；逐域规则见 `pit-field-map.md`。执行时点只用 09:30 与 15:00。Broker 负责 T+1、费用、涨跌停与成交；策略只发订单草图。
- 会话开始时 `output/` 已经是 `starter/` 的内容，不必移植；`refs/` 是只读参考，不要再把其中任何文件拷进 `output`。

## 研究流程与账户

研究期由若干整的七月至次年六月研究年组成，本臂只有一个研究会话，在这个研究期上开发与验证；决策视图定在研究期末，输入窗口从那里往前数。精确窗口与研究年标签以运行事实为准，本包不复述。预算按臂计、跨尝试累计：**2,400 分钟推理时间、96 个回放年、6,400 次模型调用、12 次空对照**（以运行事实 `budgets` 为准；一次尝试失败后原地续跑，接着花同一份预算）。完整研究期验证带逐年分块（`sub_windows`，每个研究年一行），只有完整研究期节点可以提名冻结，冻结门按本臂验证过的全部 revision 给提名的去偏 Sharpe 打折——开放方向的臂试得越多，打折越重，对照与失败的候选同样计入试验数。

会话以 `finish_session` 的一种结局收尾：`freeze` 冻结本臂唯一的交付并结束研究，`no_edge` 按 `standards.md` 的收尾规则结束本臂；没有下一个会话可以交接，推理时间或模型调用预算先用尽时流水线记 `deadline` 结束本臂。上下文接近上限时用 `compact(summary=...)` 把对话换成自己的摘要；压掉的读数、节点编号与代码都留在只读根 `trace` 里，用 `read_file`/`grep` 读回，不要重算。冻结产物随后在研究期之后的连续前推期与 Held-out 上回放一次并由流水线裁决：那段数据没有会话看得到，也没有 Agent 参与，前推不过即本臂结束，没有第二次冻结。

账户是 10 万元真实资金：佣金万一、最低 5 元/笔，过户费 0.1 bp，卖出印花税按成交日切换，方向滑点 5 bp，整手成交、涨跌停与停牌拒单。

规模与 β 的读数只在 `stats.benchmark` 里：`size_tilt`（持仓加权的截面规模倾斜）与 `beta`（对沪深 300 的回归斜率），和 `excess_return`、`neutralized_excess_return` 同一块。`style_analysis.json` 是宿主侧的旁文件，会话读不到它，不要去找。
