# 本轮数据与 08:30 字段图

本文是本包可用数据、可见时点、单位与陷阱的**唯一权威表述**。数据集清单、行数、日期覆盖与单位以本轮 `data_summary.json`、snapshot manifest 与 `unit_reference.json` 为准：先核对它们，再写阈值或跨域组合。

**开工第一件事**：核对四件事——`macro.datasets` 里有没有 `index_weight`（没有它就没有这个臂的股票池）；`daily` 带不带 `high`、`low`、`pre_close`、`pct_chg`，`unit_reference.json` 是否把 `pct_chg` 登记为小数；`universe` 带不带 `l1_name`（行业配额与 P2）；以及运行事实里的 **`benchmark_index`** 是否为 `000905.SH`、与 `lib/index.py` 的 `INDEX_CODE` 一致。**缺任何一块都不得静默回退**到别的池子或别的列——那是另一个登记；起步包在读不到截面或日线窗口不够 160 个交易日时直接报错。

## 本臂的数据集选择（创建参数）

与 `fresh_book_1m_20260925` 完全相同：20260919 轮的基本面 10 个、宏观 20 个（含 `index_weight`）、事件 17 个、文本 `report_rc`，不挂分钟域；预建视图种子 `data/pit_views_seed_research_20260919`。**本包只读 `daily`、`universe` 与 `macro.index_weight`**，其余域不进分数。

## 每个回放年自己的输入窗（运行事实 `research_geometry.years[].input_window`）

每个研究年的回放从**它自己的**决策视图起步，那张视图从该年开始前一天往回 60 个月；会话挂的 `/mnt/snapshot` 是研究期末那一张。

| 视图 | 输入窗 | 对本臂意味着什么 |
|---|---|---|
| Y1 回放（2021-07..2022-06） | 20160701..20210630 | 分数只要 160 个交易日（约 284 个自然日的读取），任何一年都够；成分截面从 2020-01 起（数据湖本身的起点），第一个复核日已有截面 |
| Y2 / Y3 / Y4 回放 | 20170701..20220630 / 20180701..20230630 / 20190701..20240630 | 同上 |
| `/mnt/snapshot`（研究期末） | 20200701..20250630 | 离线重建研究期第一天时已有 243 个交易日，160 日窗口不被截断；成分截面从 2020-07 起 |

本臂不训练，所以没有「训练窗下限」；成分标签从 2020-01 才有这一条只意味着 2020-01 之前的日期没有池，而本臂的每个决策日都在它之后。

## 日线 `daily`（已并入 `daily_basic` 与 `stk_limit`）

| 列 | 含义 | 单位 | 用途 |
|---|---|---|---|
| `high` / `low` / `pre_close` / `close` | 当日最高、最低、昨收（已按当日除权调整）、收盘 | 元/股，未复权 | 振幅 (high − low) / pre_close；买单按 T-1 `close` 定价 |
| `pct_chg` | 当日涨跌幅，相对 `pre_close` | **小数**（0.05 = 5 %；原始层是百分数，快照 ×0.01） | `a1` / `c_mom` 的日收益 |

- **可见性**：`daily` 行按交易日 17:30 盖章，没有 `available_at` 列；as-of 视图里恰好是决策时可见的行，08:30 决策读到的最新一行是 T-1。不要按不存在的 `available_at` 过滤。
- **不需要复权因子**：振幅与 `pct_chg` 都是同一天内的比值，`pre_close` 已经是除权后的昨收（研究期末视图上 `pct_chg` 与 `close / pre_close − 1` 的差最大 5e-7）。
- **停牌**：整天停牌的名字**没有行**；`is_suspended` 只标盘中临停。窗口里缺的交易日就是无效交易日，分数按有效交易日取 70 %，有效交易日 < 140 的名字无分数（这也把上市不足约 140 个交易日的新股挡在池外）。
- **一字板**：涨跌停一字板当天 high = low，振幅为 0，按定义属于低振幅日（报告同样处理）。

## 成分截面 `macro.index_weight`（与基准日线 `macro.index_daily`）

```text
sec = pd.read_parquet(
    context.asof_dir + "/macro",
    columns=["dataset", "available_at", "index_code", "con_code", "trade_date", "weight"],
    filters=[("dataset", "=", "index_weight"), ("index_code", "=", "000905.SH"),
             ("trade_date", ">=", start)],
)
```

| 事项 | 规则 |
|---|---|
| 指数键 | `index_weight` 的指数在 `index_code`、成分在 **`con_code`**（`ts_code` 为空），跨域 join 要自己改名 |
| 可见性 | 行级 `available_at`，按自己那个交易日 17:30 盖章——08:30 决策看不到当天那张截面，读到的是上一张 |
| 频率与规模 | 每月一张，日期是当月最后一个交易日；研究期末视图 2020-07..2025-06 共 60 张、**每张正好 500 只**，权重和 99.98–100.02（`refs/sources.md`） |
| 科创板成分 | 中证 500 里的 688 / 689 名字逐年增加：研究期各复核日 5–57 只（最新一张 57 只），本书剔除它们（`refs/references/index-membership.md`） |
| `weight` | 百分数；本包只用成员资格，权重只用来报一本书覆盖了指数的多少 |
| `index_daily` | **本起步包不读它**。会话若要读基准日线，按 **`ts_code`** 过滤（`("ts_code", "=", "000905.SH")`）：它的 `index_code` 整列为空，按 `index_code` 过滤会安静地返回 0 行，不过滤则七只指数的日线混在一起 |

**只有月末截面**：两张之间的真实调整看不见，复核日拿到的是上一张的名单（`refs/references/index-membership.md`）。每一个决策日都按那一天可见的最新截面判定成分。

## `universe`

`name`（ST/退过滤）与 `l1_name`（行业配额、`a1i` 与 P2）。申万一级行业按决策日取（2021-12-13 从 SW2014 切到 SW2021，一级行业的个数与名字会变，跨决策日比较行业名单是错的）；为空的落在 `未分类`，它自己算一个行业。

## `snapshot` 只有一个时点口径

`/mnt/snapshot` 是研究期末那一天的决策视图：`universe` 里的名称、ST 状态与行业都是那一天的。离线重建（`refs/references/offline-screen.md`）因此不按 ST 过滤、行业用研究期末的分类——两处已知的小偏差；成分与日线都按日期正确。**不要拿它原样当某个历史决策日的 as-of 视图**：它的日线一直到研究期末，读「最新一行」会读到未来。

## 陷阱

- **把 `pct_chg` 当百分数**：快照里是小数，按百分数再除 100 会让分数缩小百倍——排序不变，但任何绝对阈值都错。
- **换振幅定义却不申报**：本包登记的是 (high − low) / pre_close；换成报告原式 high / low − 1 或别的定义是一个新的候选配置，筛过就要申报。
- **求和而不是求均值**：有停牌的名字有效交易日少于 160，求和会系统地压低它们；本包按有效交易日求均值。
- **把缺的交易日当 0 收益**：那是停牌，不是平盘。
- **成分的代码列是 `con_code`**；`index_daily` 按 `ts_code` 过滤。
- **一手与整手**：100 万元 50 席的座位约 19,400 元，研究期里买不起一手的池内名字 0.2–0.9 %（`refs/sources.md`）；买不起只影响买入，**已持有的名字不得因此强卖**；买单按最近整手四舍五入再按现金截断。
- **印花税在研究期内切换**（卖出 10 bp → 5 bp，2023-08-28）。
- **复核节奏不得依赖模块级计数器或跨调用缓存**：到期判断拿最新可见交易日与决策日比自然月；`c_shuf` 的打乱只用决策日做种子。
