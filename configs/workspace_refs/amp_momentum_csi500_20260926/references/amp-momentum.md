# 振幅切割动量：文献、它在本仓库看得见的样子与折扣

自写笔记。本臂的分数来自一份卖方报告；这一页写报告说了什么、哪些能搬过来、哪些不能，以及包作者在研究期末视图上看到的样子。判据只在 `refs/families.md`，读数出处在 `refs/sources.md`。沙箱无网络，外部出处只列在 `refs/sources.md`。

## 报告说了什么（开源证券 2020-07-21，「A 股市场中如何构造动量因子？」，全文读过）

- **问题**：A 股几乎没有动量。报告用 20–240 日涨跌幅做因子，20 日 IC −0.054，拉长到长端仍在 −0.02 左右，全是反转；传统的「6 个月减 1 个月」切割 IC 只有 −0.002。
- **做法**：回看 N 个交易日，按日振幅（报告用 最高 / 最低 − 1）把交易日排开，振幅低的那部分交易日的涨跌幅加总记为 A 因子，高的那部分记为 B 因子。A 在 N 变长时动量越来越强、B 的反转越来越弱；N = 160 时 A 的 IC 0.033。把 160 天按振幅分十组，低振幅的前七组呈动量，最高那组呈强反转。引入切割比例 λ，IC 与 ICIR 在 λ ≈ 70 % 时同时达到峰值：**全市场 2010-04..2020-06 月度 IC 0.036、ICIR 1.31**，五分组年化收益单调。
- **沪深 300**：IC 0.051、ICIR 1.04；五分组多头 2010-04..2020-06 年化 9.72 %（千三费率、月度调仓），同期指数 3.05 %。
- **别的切割变量**：按单笔成交金额切 IC 0.027（ICIR 0.83），按换手率切 0.015（0.45），振幅最好。
- **机制**（报告的解释，未检验）：高振幅日是交易活跃、情绪化的日子，价格事后回吐；低振幅日的价格变化更像信息，事后延续。

## 相邻证据

- **Zhang 与 Zi（2025 工作论文，1998-01..2024-06；读过摘要与主表）**：没有任何 J/K 动量组合在 90 % 水平显著，最好的 6-6 只有 0.32 %/月（t 1.32），动量效应在 2005 年股权分置改革之后消失。这是不提普通动量、而把它放进同批当对照 `c_mom` 的理由。
- **光大证券 2019（「再论动量因子」；只读过挂载索引的摘要，等级 A）**：A 股反转压过动量；「纯化」之后的动量多空收益 23.9 → 28.8 %/年，同样是样本内。
- **登记册**：中期残差动量（`resid_momentum_100k_20260921b`，60–120 日、10 万）判为动量换皮且全负；算子堆里的动量与反转是全市场旧口径；20 日反转与月度彩票反向作 10 万开局都关了。它们押的是**高振幅日的回吐**或**不切割的动量**，A 因子押的是低振幅日的延续——见 `refs/families.md` 的已关闭方向一节。

## 包作者看到的样子（研究期末视图，`refs/sources.md`）

- **秩信息在，方向对，比登记的大**：h = 10 / 20 / 40 的逐日秩 IC +0.046 / +0.053 / +0.066，规模中性化后 +0.055（h = 20）；`c_mom` 同窗口 −0.023 / −0.034 / −0.047，符号与登记一致。两者截面相关中位只有 +0.23：切割确实把动量里的另一样东西分了出来。
- **但顶端不挣钱**：月度书前 50 只对同池 −0.34 %/年、2/4 年正；十分位剖面第一组 −0.07 pp/月、第十组 −0.56 pp/月——IC 主要来自池的下半截（低 `a1` 的名字之后跑输），多头那一端是平的。登记册 §3 在载体上反复见过同一个形态；只做多、等额、前 50 只的书吃不到下半截的信息。
- **逐年不稳**：Y3 第一十分位 +1.32 pp/月，Y4 −1.58 pp/月；月度 IC Y1 +0.010、Y2 +0.071、Y3 +0.144、Y4 −0.018。
- **与 range20 有交集**：截面相关中位 +0.43（登记的同质线 0.6），逐年 +0.14 / +0.49 / +0.53 / +0.42。

## 结论该怎么写

`a1` 越过 HB、而 `c_mom` 读数接近或更高时，结论只能写成「这个窗口里的动量（或风格）」，不能写成「振幅切割」；`a1` 读正而主要来自某一年、或 `size_tilt` / 行业明显偏时，照实写成一次风格押注。`no_edge` 的读法：「振幅切割动量在中证 500 / 100 万 / 50 席 / 月度上与零技能分不开」，连同 `c_mom` 的同批读数，是登记册要的一行。
