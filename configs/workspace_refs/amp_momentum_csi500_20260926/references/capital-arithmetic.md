# 账户算术：座位、整手与成本

自写笔记，100 万元 / 50 席 / 中证 500 这个账户形状上的钱。Broker 的费率以运行事实 `broker_replay` 为准；这里的数只用来判断量级，**换手、成本与回合数必须在第 0 轮实测**（`refs/exploration-plan.md`），不引用本页的估算。

## 座位与整手

- **座位**：`book value × 0.97 / 50`，开局约 **19,400 元**。起步包的座位随账户走（`context.account`），不是常数。
- **一手买不起**：研究期 48 个复核日上，池内一手（100 股 × T-1 收盘）超过一个座位的名字占 0.2–0.9 %（逐年均值 0.9 / 0.5 / 0.2 / 0.2 %，`refs/sources.md`）；科创板一手 200 股且有投资者门槛，本书整块剔除。买不起只影响买入：已持有的名字涨过一个座位**不强卖**。
- **最近整手**：买单按 `座位 / 价格 / 100 + 0.5` 取整再按剩余现金截断，一只名字的误差最多半手；第四研究年容器探针的首日 50 笔买单实际权重 1.74–2.16 %（目标 2 %）。
- **现金**：0.97 的缓冲加卖出按 0.98 折算，开局后约 3 % 留在现金里，平均总仓位约 0.96–0.97。

## 每笔的成本（`broker_replay` 的默认值）

| 项 | 费率 | 在 19,400 元一笔上 |
|---|---|---|
| 佣金 | 1 bp 双边，**最低 5 元** | 1 bp 只有 1.94 元，最低佣金约束住：**约 2.6 bp / 边** |
| 过户费 | 0.1 bp 双边 | 0.1 bp |
| 印花税 | 卖出 10 bp，2023-08-28 起 5 bp | 5–10 bp |
| 滑点 | 5 bp 方向性（限价与竞价成交不计） | 0–5 bp / 边 |

一次往返约 **10–26 bp**（取决于是否计滑点与印花税档）。本书年单边换手的登记估计是 2–4 倍，对应成本约 0.2–1.0 %/年；**实测以冒烟与第一批的 `turnover`、`fees_paid` 为准**。成本在面板里大半对消（面板按同一骨架、同一成本重放），它影响的是 P3 的 `excess_at_2x_slippage` 与前推期的成本压力判据 F5，不是主动 IR。

## 活动量

前推与 Held-out 要求每月至少 1 个完成回合（F6）、平均总仓位 ≥ 0.5（F7）。月度复核、保留带 2.0、不设换名上限时，每次复核卖出的是名次掉出前 100 的持仓；分数窗口 160 天、每月只换约 20 个交易日，逐日秩自相关 0.994（`screen.py`），所以每月的卖出只数要实测——包作者的第四研究年冒烟读数在 `refs/sources.md`。
