# 振幅切割动量规则分数参考包（amp_momentum_csi500，20260926）

本目录是只读 refs（会话里的路径是 `refs/…`）。本包登记的是**动量家族在 A 股唯一有证据的一种形态，用最透明的形态量一次**：过去 160 个交易日里，振幅最低的 70 % 交易日的日收益均值（开源证券 2020 年的「振幅切割动量」，报告里叫 A 因子）。它在决策日在册的中证 500 成分上直接建一本 50 席、月度复核、等额现金的书，**不训练**，由宿主的零技能面板裁决；同一窗口、同一本书的普通动量 `c_mom` 作同批的机制对照。

## 为什么是这个形状

**A 股的普通动量几乎不存在。** 1998–2024 年没有一个 J/K 动量组合显著（Zhang–Zi 2025），报告自己量出 6−1 月动量 IC −0.002、20–240 日涨跌幅全是反转。报告的论点是：反转集中在高振幅的交易日，低振幅交易日的涨跌幅是延续的；把高振幅日扔掉，剩下的就是动量——全市场 2010–2020 年月度 IC 0.036、ICIR 1.31。**这是卖方研究、样本内的读数**：N = 160 与 λ = 0.7 是在同一样本上挑出来的，研究期整段在报告发表之后，没有找到独立复现（`refs/references/amp-momentum.md`）。

**不是叠在载体上的一块特征，也不是已关的彩票 / 反转形状。** 研究教训登记 §4 已把「特征块叠在固定载体上」作为方法关闭；§2 关掉的 20 日反转、月度彩票反向与 rmax 押的是**高振幅日的回吐**，中期残差动量押的是**不切割的动量**——本臂恰好是被它们扔掉的另一半，而且把「不切」放进同批当对照。逐行的对照与理由在 `refs/families.md` 的已关闭方向一节。中证 500 上已关的两条臂都是载体书；不带授权的 100 万规则分数书只在沪深 300 上关过。

**登记在先的限制。** 预期 h = 20 的逐日秩 IC +0.01…+0.02、宿主主动 IR 0.2–0.5，**低于冻结门**（第一批 N_eff = 1 时约 0.98，`refs/families.md` 的 trial 账）。本臂的价值是用一批宿主回放（12 个回放年）把登记册从没测过的一种动量形态量清楚：切割有没有东西，东西落不落得到只做多的书上。

**包作者的离线读数是否定的，而且是在登记之后才读的。** 研究期末视图上，`a1` 的秩信息在、方向对，比登记的还大（h = 20 IC +0.053，规模中性化 +0.055），但 t 只有 1.88（K2 命中）；它来自池的下半截——前 50 只的月度书对同池 −0.34 %/年、2/4 年正（K3 命中），第一十分位几乎不挣、第十十分位跑输 0.56 pp/月。普通动量 `c_mom` 读负，符号与登记一致。**会话要自己按 `refs/references/offline-screen.md` 重算一遍**；按登记，离线否决不跳过、也不改唯一的第一批（`c_shuf` + `a1` + `c_mom`，`offline_trials` 0），`a1` 的宿主主动 IR 越不过 HB（约 0.64，且 ≥ 3/4 年为正）就以 `no_edge` 收尾、读数写全；越过才回到正常路径。不得因为已经知道读数而改登记。

## 你被评的是主动序列

每次正式验证结束后，**宿主**按候选自己的成交骨架随机换名重放 20 份，取日收益等权均值作为**零技能面板**，再在「候选减面板」的主动序列上算全部统计量。包不设零技能对照腿的门，也不设信息比率或去膨胀 Sharpe 的门——那些是流水线的，写在运行事实里。本臂最该记住的三条：

- **绝对超额说明不了任何事。** 中证 500 指数研究期 −11.9 %，剔科创板的池等权 +7.0 %：对指数的原始超额大半是池的形状。
- **`c_shuf` 是同批的一次零技能抽样**：这个池 50 席上，一本随机书的年化主动散在约 ±2.2 pp/年、主动 IR 约 ±0.5；`a1` 要的是越过零技能第 90 百分位（HB），不是赢过 `c_shuf` 的那一次读数。面板自己的重抽噪声约 0.5 pp/年：两条腿的差小于约 1 pp/年 当作噪声。
- **`c_mom` 是机制对照**：`a1` 不高于它，结论只能写成「动量」而不是「振幅切割」。

## 本臂的执行边界

执行合同——入口与订单、允许的 import、文件 I/O、PIT 读法、不写死宿主路径、沙箱无网络——以只读 `output/README.md` 与系统提示为准，本包不复述。本包只在以下几点上更具体：

- **不训练**：没有 `fit`，每次复核（或补座位）读一次约 284 个自然日的日线与一张成分截面，容器内不到 1 秒；非复核日且书满时直接返回 `[]`。**`models/` 不放任何东西。**
- **本臂 `gpu_count = 0`，纯 CPU**；策略容器 8 核 / 16 GiB，实测峰值约 0.6 GiB。
- **读不到成分截面、或日线窗口不够 160 个交易日，起步包直接报错**——不设退路：回放失败好过悄悄交易一个别的池。
- `pct_chg` 在快照里是**小数**；振幅用 `pre_close`，两者都是同日比值，不需要复权；停牌日**没有行**，是无效交易日，不是 0 收益（`refs/pit-field-map.md`）。
- 不要把 `refs/` 里的文件拷进 `output/`：整棵包是只读的，`cp` 会把权限一起带过去。

## 账户与成本

研究期几何、预算、冻结门与毕业条件以运行事实为准。**开工第一件事是读自己的运行事实**：`broker_replay.initial_cash`、`benchmark_index`（应为 `000905.SH`）、`acceptance_rules`（没有跟踪授权；`max_drawdown` 0.50——中证 500 研究期自己回撤 41.8 %；`active_max_drawdown` 0.30）、`budgets` 与 `max_replay_years`，以及 `research_geometry.years[].input_window`（每个回放年自己的 60 个月输入窗）。本包按 **100 万元、不带跟踪授权**写成：50 席时座位约 19,400 元，买不起一手的池内名字不到 1 %，5 元最低佣金约 2.6 bp/边（`refs/references/capital-arithmetic.md`）。前推期要求**每月至少 1 个完成回合**与平均总仓位 ≥ 0.5：包作者三个月的宿主冒烟读每月 6.4 个回合、总仓位 0.99，但**年换手与成本以第一批完整期验证为准**——`smoke_backtest` 的窗口上限只有 5 天。

## 「没有边际」的读法

每个候选按 `refs/families.md` 的 HB、提名条件与杀死条件逐条读，不看整窗总收益。另外三点：

- **读主动读数**：`benchmark.active_neutralized_excess` / `active_tracking_error` / `active_information_ratio`、`benchmark.panel_neutralized_excess`、`sub_windows[].active_neutralized_excess_return`。
- **`a1` 与 `c_mom` 要并排报**，连同离线门里二者各自的秩 IC 与月度书；`size_tilt`、`size_beta` 与 `top_industry_weight` 一起读——动量读正而全来自一个行业或一种规模，是风格，不是切割。
- **逐年读**：包作者的离线读数里，第三与第四研究年方向相反；只在一年成立的读数不是效应。

没有候选证明边际时，不冻结是正当结果：按 `refs/families.md` 的终止规则以 `no_edge` 携读数结束本臂。**「振幅切割动量在中证 500 上与零技能分不开」本身就是登记册要的一行**。

## 本包的硬要求

跨实验的运行教训不写在参考包里（见 `inputs/skills_index.json` 的运行记忆）。本包在流水线之外只加五条，全部写在 `refs/families.md`：预登记（P1）、行业与规模并排汇报（P2）、成本、换手与活动量（P3）、按主动读数导航（P4）、池与分数的逐年汇报（P5），外加一道在第一批**之前**重算的**离线门 G-AM**——它全离线、不花回放年、只能否决；重算登记的 `a1` 与对照 `c_mom` 不计 trial，多算的任何别的配置没提交就要申报 `offline_trials`。
