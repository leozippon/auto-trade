# 候选、符号预登记、离线门 G-AM、验证计划、变体、已关闭家族与关闭规则

本文是本臂候选定义、符号与量级预登记、离线门、验证计划、变体与关闭判据的**唯一权威表述**；`refs/README.md` 与 `refs/exploration-plan.md` 只指向本文，不复述。可见时点、单位与陷阱只写在 `refs/pit-field-map.md`；文献与折扣写在 `refs/references/amp-momentum.md`，离线门的做法写在 `refs/references/offline-screen.md`，读数出处写在 `refs/sources.md`。起步包里每条腿的定义只有一处：`output/lib/candidates.py`（分数本身在 `output/lib/score.py`）。

## 本轮的形状：一条不训练的规则分数，自己建书

本轮是「广度」轮：八条事先登记的规则分数臂，各在一个登记册没测过的家族与池上，各花一批宿主回放就能证伪。本臂是**动量家族**在中证 500 上的一条：开源证券 2020 年的「振幅切割动量」（报告里叫 A 因子）。它不经学习器、不叠在 Alpha158 + LightGBM 载体上——登记册 §4 已把「特征块叠在固定载体上」作为方法关闭，§3 记着载体自己的只做多书读不出与零技能可区分的主动收益。所以 `a1` 直接建书，命题只有一个：**按振幅切割动量选出的前 50 只，主动收益能不能与同池零技能区分**。

**为什么是这个形状，而不是普通动量。** A 股的普通中长期动量几乎不存在：Zhang 与 Zi（2025 工作论文，1998-01..2024-06）的 J/K 组合没有一个在 90 % 水平显著（最好的 6-6 是 0.32 %/月、t 1.32）；开源报告自己量出 6−1 月动量 IC 只有 −0.002，20–240 日涨跌幅全部呈反转（20 日 IC −0.054，长端约 −0.02）。报告的论点是：反转集中在高振幅的交易日，低振幅交易日的涨跌幅是延续的，把两者切开，低振幅那一半就是动量。本臂把「切开」与「不切」同批放上宿主：`c_mom` 是同一窗口、同一本书的普通动量（λ = 1），登记为对照。

## 分数（起步包的唯一定义在 `output/lib/score.py` 与 `lib/candidates.py`）

| 组件 | 定义 |
|---|---|
| 振幅 | 每个交易日 (最高 − 最低) / 昨收（`daily` 的 `high`、`low`、`pre_close`）。报告原文用 最高 / 最低 − 1；两种排序几乎一致（研究期末视图 48 个复核日上两个分数的截面秩相关中位 +0.974，`refs/sources.md`），本包登记昨收形式 |
| `a1` | 最近 `knobs.WINDOW`（160）个市场交易日里，该名字有效的 n 个交易日按振幅从低到高排，取前 round(`knobs.LOW_SHARE` × n)（0.7 n）个，求它们日收益（`pct_chg`，快照里是小数）的**均值**；n < `knobs.MIN_SESSIONS`（140）则无分数；截断处并列取较早的交易日。名字 160 天全在时，它与报告的「求和」排序完全相同。越高越做多 |
| `c_mom` | 同一窗口所有有效交易日的日收益均值（λ = 1）：普通 160 日动量 |
| 池 | 决策日可见的最新中证 500 截面，剔 688 / 689（科创板）与北交所、名称含 ST/退、T-1 无日线、无分数（`refs/pit-field-map.md`） |
| 书 | **每个自然月的首个决策日复核**（空仓时任何决策日都复核）；**50 席等额现金**；离开截面、丢分数、丢 K 线或变 ST 的持仓在复核日无条件卖出；名次落到 100 名（`SEATS × KEEP_BAND`）之外的持仓卖出；**不设换名上限**；空座位按名次在「一手 ≤ 一个座位」的名字里补，**每个申万一级行业至多 ⌊`INDUSTRY_SHARE` × 50⌋ = 12 只**（算上保留的，只约束买入，从不因此卖出）；两次复核之间书不满 50 只（入场被涨停或缺价拒、现金截断）时，之后每个决策日用排名最高、合格、未持有的名字补空座位，**不卖**；卖出 09:30、买入 15:00，按 T-1 收盘**四舍五入到最近整手**再按现金截断；并列按代码的固定散列破 |
| 基准 | `lib/index.py` 的 `INDEX_CODE`，全包唯一一处；第 0 轮先读运行事实 `benchmark_index`（本臂应为 `000905.SH`），不符时改常量去对齐它，反过来不行 |

## 离线门 G-AM（整期批次之前重算，全离线，0 回放年；筛过的候选配置各计一个 trial）

登记的判据，一次写死：K0 与 range20 同质，或 K1 覆盖不足，或 K2 秩 IC 不够，或 K3 月度书输给同池零技能，⇒ 离线否决（后果见验证计划：本臂仍花唯一一批，宿主线 HB 裁决）。

- control：`c_shuf` 与 `c_mom` 永远写 control: true——照常花回放年、计入完整研究期验证数，但不是 trial，也永远不能提名；`a1`、`a1i` 与任何变体写 control: false。把候选登记成对照，它就失去提名资格；把对照登记成候选，是白给自己加一个 trial。
- offline_trials = 本批申报前离线筛过、读数影响了本批提交什么、但本批没有提交的候选配置数；提交进本批的候选在宿主验证时按 host trial 计，不重复申报。

冻结门的试验数 M 是本臂验证过的非对照 revision 加上各批申报的 offline_trials，按 ρ̄ 折成有效试验数 N_eff = ρ̄ + (1 − ρ̄)·M；公式与阈值以运行事实 acceptance_rules.freeze_gate 为准（本轮默认 min_dsr_probability 0.975）。

| 判据 | 怎么算（做法在 `refs/references/offline-screen.md`） | 命中 |
|---|---|---|
| **K0 同质** | 48 个复核日（分数记在复核日前一个交易日）上，池内 `a1` 与 range20（−过去 20 日平均振幅）的截面 Spearman 的中位数 | **> 0.6**（`a1` 只是登记册最强那条低振幅分数的换皮） |
| **K1 覆盖** | 每个复核日池里有分数、一手买得起（一手 ≤ 19,400 元）的只数，逐研究年取最小 | **任一研究年 < 100**（2 × 席数） |
| **K2 秩 IC** | `/mnt/tools/screen.py` 在 `/mnt/snapshot` 上，`--start 20210701 --end 20250630 --horizons 10,20,40 --top-fraction 0.107`，只给池内名字打分，读 h = 20 | **`ic_mean` ≤ 0，或 `t_stat` < 2.0，或 `ic_size_neutral` ≤ 0** |
| **K3 月度书** | 每个复核日 `a1` 前 50 只（买得起、按行业配额）等额，复核日收盘买、下一个复核日开盘卖，减同池等权均值；研究期末视图里 47 个月 | **四年平均 ≤ 0，或为正的研究年少于 3 个** |
| 诊断（只报不判） | h = 10 / 40；十分位剖面；200 本同池随机 50 只书的年化主动与主动 IR 的 p10 / p50 / p90；`c_mom` 的同一套读数；`a1` 与 `c_mom`、与报告原式振幅的截面相关 | — |

**包作者的读数：K2 与 K3 命中**（t 1.88 < 2.0；月度书 −0.34 %/年、2/4 年正），K0（+0.426）与 K1（最少 444 只）没有命中（`refs/sources.md`）。会话要自己重算一遍（重算登记的候选不计 trial）。

**这道门能说什么、不能说什么**（研究教训登记 §4）：离线读数只有秩与方向可信，水平与幅度不可信（同一条检查里秩相关逐位复现，Δ 从离线 +5.54 pp/年 翻成实测 −0.63 pp/年；另两次过门的离线 Δ 在宿主上一次翻号、一次高估约 23 倍），离线分辨不了比约 4 pp/年 更小的差；**门只能否决，永远不能证明边际**，裁决是宿主的整期批次。47 个月的主动均值误差很大：200 本同池随机 50 只书的年化主动 IR 散在 −0.74…+0.59（p10…p90）。

## 验证计划（先登记，再花回放年）

- **`control`**：`c_shuf`、`c_mom` 永远写 `control: true`；`a1`、`a1i` 写 `control: false`。
- **`offline_trials`**：离线（包作者或会话）筛过、读数影响了提交什么、而没有提交的候选配置数；每个配置只在筛过之后第一个记下验证的批次申报一次。**第一批的申报是 0**：包作者只筛过 `a1`（提交）与 `c_mom`（对照，永不计），报告原式振幅只做了不看收益的相关；会话另筛的任何配置每个加 1，看了读数改提交别的形态，`a1` 就变成筛过而没提交的配置，同样加 1。

| 批次 | 腿（按顺序，`control`） | 完整期验证 / 其中 trial / 回放年 | `offline_trials` | 进入条件 |
|---|---|---|---|---|
| 第一批 | `c_shuf`（true）、`a1`（false）、`c_mom`（true） | 3 / 1 / 12 | 0；会话另筛而没提交的配置每个加 1 | **无论 G-AM 读什么都跑**：`no_edge` 本来就要本会话至少一次完整期验证，这一次花在登记的信号本身上 |
| 变体批 | `a1i`（false） | 1 / 1 / 4 | 本批之前新筛而没提交的配置数 | 只在 `a1` 越过 HB、却没过冻结门时 |
| 收官 | 冻结，或 `no_edge` | 0 | — | 见下文 |

**宿主线 HB（杀死条件第 1 条）**：`a1` 在第一批的完整期主动 IR ≥ 1.2816 × √(244 / T)（零技能第 90 百分位，T 是完整研究期的交易日数，四个研究年约 **0.64**），而且主动超额为正的研究年 ≥ 3 个。任一不满足 ⇒ `finish_session(no_edge)`。**离线否决既不跳过第一批，也不改 HB**；HB 越过而 G-AM 曾否决时，照正常路径走，但结果笔记要写明离线与宿主为什么不一致。

**trial 账与它要求的 IR，事先算清**：第一批之后 M = 1（宿主上只有 `a1`），N_eff = 1，四个研究年、阈值 0.975 下过门要主动 IR 约 **0.98**；变体批之后 M = 2，N_eff 随 `a1` 与 `a1i` 的相关落在 1–2，门槛约 0.98–1.24。按预期量级（0.2–0.5）与包作者的离线读数，这张账事先说明本臂冻结的可能性很小；它的信息价值是把登记册从没读过的一种动量形态用最透明的形态量一次。**全臂 host trial ≤ 2、回放 ≤ 16 年。**

**读数的噪声，事先写明**：规则分数是确定的，没有训练种子的复本；但宿主零技能面板（20 份换名重放的均值）每次重抽都会动——登记册在沪深 300 / 50 席上量到同一本书两次读数差 0.55 pp/年，本池 50 席的离线估计是 0.49 pp/年（单本随机书的年化主动标准差 2.19 pp/年 ÷ √20，`refs/sources.md`）；`c_shuf` 只是一次抽样，它自己的读数就散在这 2.19 pp/年 上。主动 IR 在零技能下的四年抽样误差约 0.50。**两条腿的差小于约 0.1 IR 或 1 pp/年 当作面板噪声。**

## 允许的变体

只有 `a1i` 一条，只在验证计划那一格进场。**不设格点**：N = 160、λ = 0.7 是报告在同一样本上挑的最优点，再挑一次就是在研究期上多做一轮搜索；席数、保留带、复核节奏与行业配额都不在变体里。

**禁止**：用前推期或 Held-out 的任何信息；把 `a1` 做成载体的 LightGBM 特征（登记册 §4 已关闭的方法）；在分数里加别的列（估值、规模、换手、资金流等）；非等额权重（面板只对齐等额现金）；把 `c_shuf` 或 `c_mom` 改作候选；把任何东西放进 `models/`；用最新一张成分截面去标注历史决策日；改成周度复核。

| 52 周高比 overlay | `high52_overlay_1m_20260921c`（100 万 / 授权） | 同分数等额扣成本后对同池等权 −5.1 %，正年 2/4 | 关 |

**本臂为什么不是这几行。** 已关的彩票 / 反转形状押的是**短期高振幅日的回吐**（20 日反转、月度彩票反向、rmax），做成 10 万的集中开局或授权内 overlay；A 因子恰恰**把高振幅日扔掉**，押的是剩下那些低振幅日的**延续**——方向相反的一半。中期残差动量（60–120 日、10 万）是不切割的时间序列动量，残差化之后仍是动量，它的全负与本包 `c_mom` 的登记符号一致；本臂把「不切」放进同一批当对照，正是为了把切割本身量出来。算子堆是全市场、旧口径、没有这种按振幅条件化的切割。52 周高比是价格水平而不是收益的切割。不带授权的 100 万成分选名这一形状只在沪深 300 上关（登记册写明「别的指数形状不在此列」），中证 500 上的两条已关臂（`csi500_shape_1m_20260923`、`fresh_book_csi500_1m_20260925`）都是载体书，不是规则分数。**离线的同质核对**：`a1` 与 range20 的截面相关中位 +0.426（K0 线 0.6），与 `c_mom` +0.232——它与低振幅那一族有交集，但不是同一个分数。

本臂同样不得作为候选重开的其余家族（登记册 §2 全表，本轮核对过）：载体作主方向与「特征块叠在固定载体上」、授权内有界 tilt 与风险模型 TE 预算、质量 / 价值 / 低波类手写开局、盈利意外与分析师类、融资融券拥挤、披露面筛子、组合层择时、构造层格点与非等权权重、序列与图模型、元标注、预训练基础模型与 LLM 因子挖掘。它们仍可作为对照腿，但不得成为本臂的方向。

本臂收尾时由运营者按读数补写一行：振幅切割动量作不训练的规则分数，在 100 万 / 中证 500 / 50 席 / 月度上的读数，连同 `c_mom` 的同批读数。

## 提名条件（冻结前逐条满足）

1. G-AM 已重算，K0–K3 与诊断读数都写进结果笔记；否决过的要写明 HB 为什么仍越过。
2. 完整研究期验证完成，冻结门按运行事实通过；完整期验证数达到运行事实 `min_full_span_validations`（对照也计入，第一批已有 3 条）。
3. **稳定性**：逐年分块的**主动**超额为正的研究年 ≥ 3。
4. **`c_shuf` 同批**，且 `a1` 越过 HB；`c_mom` 的同批读数写明（**不要求赢 `c_mom`**，但 `a1` 不高于 `c_mom` 时结论只能写成「动量」，不能写成「振幅切割」）。
5. P2 / P3 / P4 / P5 全部成立。
6. **集中度与换手**：`pnl_concentration.top5_share_of_gross_gains` ≤ 0.5；年换手 ≤ 12 倍；实测每月完成回合数 ≥ 1。
7. **实现底线**：单次决策 < 60 秒、容器内存峰值明显低于 16 GiB；意图买单拒单率 ≤ 30 %；座位填满率与买不起份额逐次汇报。不成立先修实现再复测，不算证伪。

## 什么会杀死它（按命中即停）

1. **HB 没越过**：`a1` 第一批的主动 IR < 0.64，或主动超额为正的研究年 < 3 ⇒ `no_edge`，不再为 `a1` 开任何批次。
2. 主动超额为负的研究年过半——关闭该候选。
3. `excess_at_2x_slippage` ≤ 0，或实测每月完成回合数 < 1——机制可能真实但这个形状不可交付，以「不可交易」关闭。
4. P2 不成立——关闭并写明是哪个行业带上去的。
5. 变体批之后仍没有过冻结门的候选——以 `no_edge` 携读数结束，不为了凑提名再开一批。

## 臂级终止规则

任一成立即本臂关闭：第 1 条命中；第 5 条命中；预算用尽前没有可提名候选。关闭以 `finish_session(outcome="no_edge")` 携读数结束本臂，**不换家族**，不把 `c_shuf` 或 `c_mom` 改作候选。`no_edge` 是结论不是退路：它要带上 G-AM 的四个读数、`a1` 与 `c_mom` 的同批主动读数，以及对登记册上面那几行的交代。
