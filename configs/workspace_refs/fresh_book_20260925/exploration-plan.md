# 研究会话探索计划

目标：在本臂唯一的研究会话里，用一批同批对照在宿主上检验两件事——**H2** 跟得上分数的书（`f1`）是不是赢过月度、封顶的书（`c_base`），**H3** 赢的那一截是不是倾斜（`f2` 把倾斜拉回之后还剩多少）。顶端十分位不挣钱这件事已经量出来、写成了事实（`families.md`），不再是一道门。判据、腿与验证计划只在 `families.md`，数据与单位只在 `pit-field-map.md`，口径在 `references/`，本文只排顺序与预算。

**常见情形下第 1 批就是整条臂**：`c_base` + `f1` + `f2` 一批读完，`f1` 与 `f2` 都没过 H2 就 `no_edge`。三条腿拟合的是同一个 booster 文件，差的只有 `knobs.LEGS` 里那一行构造。

## 第 0 轮：不占回放预算的核对与成本探针

1. **运行事实核对（最先做的一件事）**：`broker_replay.initial_cash`、**`benchmark_index`**、`acceptance_rules`（有没有跟踪授权；两个回撤上限；`cost_stress_multiplier`、`min_round_trips_per_month`、`min_mean_gross`——这三条就是本臂的活动与成本规则的宿主那一半）、`budgets` 与 `max_replay_years`、`research_geometry` 的 `input_window` 与逐年 `years[].input_window`。本包按 100 万元、不带授权、50 席写成；`benchmark_index` 与 `lib/index.py` 的 `INDEX_CODE` 不一致时**改常量去对齐运行事实**。
2. **数据核对**：`index_weight` 与 `index_daily`（按 `ts_code` 过滤）在不在；`universe` 带不带 `l1_name`；`daily` 带不带 `circ_mv`。本臂不读任何别的数据集。
3. **账户算术表**：用本臂的资金，在 40 / 50 / 60 席上算座位金额、买得起的成分占比、5 元最低佣金的 bp/边、一次往返总成本，以及 3.5 / 10 / 20 倍年换手下的年成本与 F5 要扣的那一笔（公式在 `references/capital-arithmetic.md`）。
4. **换手与成本实测（P3 的硬要求）**：`smoke_backtest` 在研究期靠后的槽上跑 `c_base`、`f1`、`f2` 各一段，窗口要跨过一次季度重训、`c_base` 的两个月初与 `f1` 的至少三次复核（70 个交易日够）。读 `turnover`、`fees_paid`、平均总仓位、订单元数据里的 `review` / `exits` / `book_tc` / `refill` / `pull_deviation`，扣掉首日建仓再年化，写进结果笔记。**不得引用包里的估算**；70 天年化的换手受窗口里行情的影响很大（作包冒烟的窗口里有一周全池暴涨），只作量级。
5. **`fit` 成本探针与三路装不装得下**：同一批冒烟里读 `resources.fit_seconds` 与 `peak_memory_bytes`（`references/fit-cost.md`），并读运行事实 `budgets.batch_validate_max_concurrency`：装得下三路，`f2` 进第 1 批；装不下，第 1 批只跑 `c_base` + `f1`（`families.md` 的验证计划）。**同一个 `start` 复用**；`smoke_backtest` 不花回放年，也不计 trial。
6. **（可选）复核事实表**：`families.md` 的事实表可以用自己的普查复核（`references/stage0-census.md`）——只复核表里 `c_base` 与 `f1` 的数，**不是筛选、不计 trial、什么都不申报**；不一致写进结果笔记与第 1 批的 `hypothesis`。**不要把预算花在重新推导它们上**，不复核也可以直接开第 1 批。

## 第 1 批：`c_base` + `f1` + `f2`，一次完整研究期 `batch_validate`

腿：**`c_base`（第一条，`control: true`）** + **`f1`（`control: false`）** + **`f2`（`control: false`）**，四个研究年花 12 个回放年；装不下三路时只跑前两条（8 个回放年），`f2` 按验证计划退到第 2 批。`offline_trials` 申报 0，除非复核之外还算过别的配置。

`hypothesis` 必须写清：逐行引用 `families.md` 的载体表、事实表与腿表；H2 与 H3 的判据（数字照抄）；经济解释（`references/construction.md`）与**证伪条件**（K1–K4 的数字）；预期的 Δ 与它离可分辨线多远（以 `c_base` 为参照写成一个差，不写成一个水平）；P2 / P3 / P5 的判定规则；本臂的 trial 账；第 0 轮若复核了事实表，复核出的读数与不一致。

**不要再加零技能对照腿**——宿主每次正式验证都会抽面板。回放一旦开跑就计入预算，策略自身抛错的候选照样花掉，环境失败的候选退还；某一路因环境原因失败时不重跑、不压缩对照，把读数与待裁决的分支写进结果笔记。

第 1 批之后，对过了 H2 的那条腿（都没过就对 `f1`）的完整期节点跑一次 `run_null_control`：不花回放年，会话时钟在它运行期间暂停；**它是诊断不是判据**，三个数一起报。

## 判定分支，逐条写死（判据本身见 `families.md`）

- **`f1` 与 `f2` 都没过 H2（K1）** → 以 `no_edge` 收尾，**不开第 2 批、不换轴**。把三条腿的同批 Δ、H3 的读法与构造的形状写给登记册。
- **`f1` 过了 H2** → 看 H3：`f2` 的 Δ 不到 `f1` 的一半，就写「增益主要是倾斜」，第 2 批只跑 `f1` 的第二个种子（`f2` 不再跟进）；`f2` 的 Δ 不低于 `f1` 减 1 pp/年 且 TE 至少低 1 pp，`f2` 也过了 H2，第 2 批两个第二种子都跑。
- **只有 `f2` 过了 H2** → 拉回之后才挣钱：第 2 批跑 `f2` 的第二个种子，`f4` 不开（它的条件是 `f1` 过线）。
- **`f1` 与 `c_base` 几乎一样** → 先读形状（P5）：`f1` 的复核是不是按登记的节奏发生、每次换出多少只、复核日 TC 是不是接近 0.68、持有期是不是缩短了、补座位有没有把平均总仓位拉回 0.96 以上。形状对而收益不动，就是事实表里那件事：书跟上了分数，分数的顶端本来就不挣钱。照实写，按 K1 关闭。
- **过线的 Δ 在 +2 到 +4 pp/年 之间** → 过了 H2 的线，但落在面板重抽分不开的那一侧。第 2 批的第二个种子就是为这种读数准备的；两个种子都在这个区间就照实写成「方向对、量级不可分辨」。
- **`f1` 明显差于 `c_base`** → 看成本与拒单：复核勤了，涨停拒单、停牌拒单与整手误差都变多；补座位应当把平均总仓位保在 0.96 附近（作包冒烟读数在 `sources.md`）。实现读数不对就先修（提名条件 7），读数对就是构造在这个分数上有害。
- **绝对超额高而主动超额低** → 赢的是股票池不是跟法，看 `benchmark.panel_neutralized_excess`。
- **逐年主动 Δ 有负年** → 先看是哪一年、那一年的风格行情（低波动 / 大市值 / 红利）是不是正在书的倾斜上；主动方差分解是这个问题的答案。
- **换手或成本越线（K2 / K3）** → 那条腿不过 H2；只在另一条腿过了 H2 时，才先按 `references/capital-arithmetic.md` 重算、再走轴 a（更慢一档）或轴 b（1.5）一轮。**不得为了追读数把节奏调得比登记值更快。**
- **`f2` 拉回之后复核日 TC 掉到 `f1` 的一半以下** → 拉回替换得太多；只在 `f2` 过了 H2 时走轴 c 一轮。
- **P2 不成立** → 先看是哪个行业带上去的；`f2` 的行业拉回是登记的应对，不另开每业上限。
- **实现读数不对**（座位没填满、拒单率高、`fit` 逼近上限）→ 先修实现再复测，按提名条件 7。

## 第 2、3 批：只在第 1 批有腿过了 H2 时才开

腿按 `families.md` 的验证计划取：第 2 批 = 过了 H2 的腿的第二个种子 + 条件满足的 `f3`（装不下三路时退下来的 `f2` 也在这一批，且只在 `f1` 过线时）；第 3 批 = `f4` + 作为同批对照的 `f1`（这一批里登记 `control: true`）。候选全部 `control: false`，`offline_trials` 申报第 1 批之后新筛、本批没有提交的候选配置数。**全臂不超过 6 个 host trial、32 个回放年**（完整期验证合计含对照不超过 8 个）；变体轴只在已经过了 H2 的腿上开，而且都在这个上限之内。子跨度验证只用来复测实现与耗时，不用来在候选之间做选择。

## 收官轮

只做两件事之一：对已经满足全部提名条件的最好候选补齐缺的读数并冻结；或者以 `finish_session(outcome="no_edge")` 携读数结束本臂。**收官轮只在 K1 命中、没有过了 H2 的腿剩下、或上限用完时才开始。**

## 计算预算

- **资源边界**：16 GiB / 8 CPU / 无显卡，单次 `fit` 上限 3,600 秒（运行事实为准）。作包冒烟里载体一次季度拟合十几到几十秒、容器峰值两 GiB 出头；`f1` 的复核比 `c_base` 勤几倍，每次一两秒，补座位的日子也是一两秒（`sources.md`、`references/fit-cost.md`）。
- **复核事实表（可选）**：四年逐日还原一条分数链十几到三十分钟，书路径与分解几十秒。不做也可以。
- **回放年**：复核与 `smoke_backtest` 都是 0 年；第 1 批 12 年；排满计划 32 年。以运行事实 `budgets.max_replay_years` 为准。**宿主 trial 只花在整期上**，每一个验证过的候选与每一个离线筛掉的候选配置都会抬高本臂自己的 DSR 门，所以便宜不是理由。
- **单日探针的秒数对宿主负载极敏感**，耗时结论按多日回放的平均读。

## 每个候选必须汇报的读数

除标准结果块外，写进结果笔记：逐行对照 `families.md` 的载体表与腿表；经济解释与证伪条件；**主动中性化超额、主动跟踪误差、主动信息比率**与**面板自己的中性化超额**；逐年分块的主动超额与原始超额；**`c_base` 的同跨度读数与逐年 Δ**（`f2` / `f4` 还要同批 `f1` 的）；**构造的形状**（P5 全部）；年换手（`turnover` ÷ 4）、年完成回合数、按本臂 `initial_cash` 重算的费用账、研究期成本压力判据与 `excess_at_2x_slippage`；拒单率与原因（`daily_price_limit` 与 `missing_execution_price` 分开）；平均总仓位；`top_industry_weight`、`size_tilt` 与 `size_beta` 并排；`pnl_concentration`；空对照的三个数；两个种子的主动 IR 之差（到了第 2 批）；一次复核决策的实测墙钟、`fit` 秒数与容器内存峰值；**账户面四项**：每次复核的买不起份额、座位有没有填满、实际权重对目标权重的偏离、书覆盖的指数权重。缺任何一项的结果不作为提名依据。

## Validation 否证（任何一条命中，结果无效，不讨论收益）

- 股票池不是按时点读出来的：硬编码名单、用别的指数建书而仍按 `benchmark_index` 报跟踪误差、或用最新一张截面去标注历史训练日。
- 用 `trade_date` 而不是 `available_at` 判可见；`weight` 当成小数没有 ÷ 100；`index_daily` 不按 `ts_code` 过滤。
- **候选与 `c_base` 的差不止构造**（改了特征、参数点、种子——登记的第二个种子除外、轮数、切分、标签——`f3` 除外、池、重训节拍、下单时点或同分规则之一）。
- **复核事实表时用期末那一次拟合给全部决策日打分**，或离线重建时没有把 `daily` 截在决策日的 T-1；把 Y1 前两个季度训练不出来的那一段用别的模型或别的窗口补上；或者因为复核的读数改了登记的节奏、保留带或腿。
- `f1` 的节奏不是登记值，或为了追读数调得比登记值更快。
- as-of 域读失败后回退了 `snapshot_dir`；读多数据集的域时没有先按 `dataset` 过滤；任何读取不带日期窗口。
- 买不起的**持仓**被当成离池强卖；或者买单向下取整而不是按最近整手四舍五入。
- 复核节奏依赖模块级计数器或跨调用缓存。
- 把训练好的 booster 放进 `models/`，或让 `state_dir` 里的东西跨回放存活。
- 没有第 0 轮的换手实测与成本探针就开了整期回放；把第 2 批的腿放进第 1 批；把事实表的复核做成一次子跨度回放。
- `c_base` 登记成 `control: false`，候选登记成 `control: true`；`offline_trials` 少报了筛过而没提交的配置，或把本批提交的候选重复申报。
- 没有同批的 `c_base` 就拿 `f1` / `f2` 的读数去论证构造的增量；`f2` 没有同批的 `f1` 就论证 H3；`f4` 没有同批的 `f1` 就论证权重方案的增量；`c_base` 被打开了补座位。
- 用绝对中性化超额或绝对信息比率去论证边际，而不看主动读数与面板。

## 收尾

冻结的是提名节点自己的不可变快照，提名前不必把它恢复到 `output/`。不要提交离线普查脚本；`models/` 只放静态资产。
