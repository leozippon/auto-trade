# 新鲜书参考包（fresh_book，20260925，沪深 300）

本目录是只读 refs。本包登记的是**同一个分数、换一种跟法**：载体是 20260923 / 20260924 两轮共用的 Alpha158 + LightGBM（沪深 300 成分，β 残差 10 日标签，季度续训），它的截面秩 IC 是真的，而用它建的月度、每次最多换 8 只、保留带 2.0 的 50 席书在主动序列上与零技能分不开。本臂不动分数，只动书怎么跟分数：去掉换名上限、把保留带收到前 60 名、按分数自己的衰减定复核节奏；另有两条只在条件满足时才开的腿（敞口拉回、EPO 入场权重）。对照与候选拟合的是同一个 booster 文件，差的只有 `starter/lib/knobs.py` 里 `LEGS` 的一行。

## 已经知道的，与要检验的

**已经知道的（`families.md` 的事实表，作包时在宿主上按每个研究年自己的精确输入量出）**：分数的顶端十分位对等权池每 10 天只多挣 +0.13 %（t 0.69），秩 IC 大半落在底端；月度书对当日分数的传导系数只有 0.22、名字平均拿两三个月、每次复核都顶满换名上限；跟得上分数的书（每 3 周复核、不设上限、保留带 1.2）把传导系数拉到 0.37，离线书路径上比月度书多挣 +4.7 pp/年、四年都正——但这个 Δ 的水平不可信、恰好落在约 4 pp/年 的噪声底上，而且这本书 77 % 的主动方差是行业与风格。这些是登记在先的事实，**不是一道门**；会话可以在第 0 轮复核（不计 trial、不申报），有不一致就报，但不要把预算花在重新推导它们上。

**要检验的只有两件**：**H2** 跟得上分数的书 `f1` 在宿主上赢过同一个分数的月度封顶书 `c_base`（同批完整期 Δ 主动超额 ≥ +2 pp/年，且 ≥ 3/4 年为正）；**H3** 这份增益是倾斜带来的——`f2` 把 β、规模、波动与行业拉回池平均，与 `f1`、`c_base` 同批跑，看增益还剩多少。第 1 批就是这三条腿，**常见情形下它就是整条臂**：两条候选都没过 H2 就以 `no_edge` 收尾。

机制、每个读数的定义与杠杆的形状在 `references/construction.md`；Clarke、de Silva 与 Thorley 的传导系数、Ding 的「IR 由 IC 的时序波动而不是广度决定」、Novy-Marx 与 Velikov 的进出带，都只取方向不取水平（`sources.md` 的文献表带着置信标签）。

## 按以下顺序读

1. `families.md`：载体、**作包时已量出的事实**、登记的 H2 / H3 判据、五条腿（`c_base` / `f1` / `f2` / `f3` / `f4`）、活动与成本规则（宿主规则 + 本包从 F5 推出的 20 倍上限）、读数的顺序、先登记的验证计划、变体轴、已关闭家族、提名条件与杀死条件（**唯一权威表述**）。
2. `pit-field-map.md`：逐年的 60 个月输入窗、逐表可见时点、单位与陷阱（唯一权威表述）。
3. `exploration-plan.md`：第 0 轮核对、冒烟与可选的事实复核、第 1 批、判定分支与计算预算。
4. `references/`：六份自写笔记——**`construction.md`**（问题的形状、传导系数、四根杠杆）、**`stage0-census.md`**（在研究期末视图上复核事实表的口径）、零技能面板、账户算术（含换手的价钱）、成分面、`fit` 成本。沙箱无网络，外部出处列在 `sources.md`。
5. `sources.md`：读数出处与重算它们的命令、作包普查与冒烟的实测、诚实的限制。
6. `starter/`：合同内的最小可运行包，**就是**五条腿本身，`main.py` 的 `CANDIDATE` 在五个名字之间切换。它通过 `validate_strategy_package`，在真实宿主流水线上跑通了 `c_base` 与 `f1`；`c_base` 的 70 天冒烟与 20260924 那一包的 `c_base` 冒烟**逐笔成交相同**（`sources.md`）。**会话开始时 `output/` 就是这份代码**，`refs/starter/` 只是同一份的只读副本；`lib/book.py` 的规则是纯函数，离线普查直接调用它。

## 这条臂怎么判

**第 1 批 `c_base` + `f1` + `f2`，一次完整期验证、12 个回放年**（拟合预算装不下三路时 `f2` 退到第 2 批，且只在 `f1` 过线时才开）。`f1` 与 `f2` 都没过 H2 ⇒ `no_edge`；过了的腿才开第 2 批（第二个种子）与第 3 批（`f4`）。**全臂不超过 6 个 host trial、32 个回放年。** `c_base` 永远 `control: true`、永远是一批里的第一条腿、永远不得提名。

读数按固定的顺序读，先于任何主动 IR：**传导系数 → 新买名字的份额 → 年换手（完整期 `turnover` ÷ 4）→ 对零技能面板的主动 IR → 逐年符号**。一本换手翻了五倍而传导系数没动的书，什么都没有改变。

**事先说出来的量级**：同一份 `c_base` 两次宿主验证只因面板重抽就差 0.55 pp/年，两种构造的 Δ 四年标准误约 2.5 pp/年——**只有 ≥ 4–5 pp/年 的 Δ 是两个标准误的读数**，H2 的 +2 pp/年 线只是方向，要第二个种子才站得住。冻结还要候选自己过冻结门（四个研究年、N_eff = 1 时约要主动 IR 0.98），载体的书在这个池上读 0.077–0.262；H2 过线本身就是登记册要的那一行。

## 你被评的是主动序列

每次正式验证结束后，**宿主**按候选自己的成交骨架随机换名重放若干份，取日收益等权均值作为**零技能面板**，在「候选减面板」的主动序列上算全部统计量。包不设零技能对照腿，也不设信息比率或 DSR 的门——那些是流水线的，写在运行事实里。本臂最该记住的三条（`references/zero-skill-panel.md`）：

- **面板对齐节奏与换手**：`f1` 更勤的复核、更多的成交与费用，面板一样付。换手本身不会让主动超额变正或变负。
- **面板对不齐权重方案**：`f4` 的 EPO 权重只能对同批的 `f1` 读。
- **载体的主动 IR 是一段散布，不是一个数**：同一本月度书五次宿主验证读 0.077–0.189。

## 本臂的执行边界

执行合同——入口与订单、允许的 import、文件 I/O、`available_at` 与 PIT 读法、不写死宿主路径、沙箱无网络——以只读 `output/README.md` 与系统提示为准，本包不复述。本包只在以下几点上更具体：

- 本包声明 `fit(context)` 与季度重训；booster 只经 `save_model` 写进 `context.state_dir`。**`models/` 只放随产物交付的静态资产**；「续训」指一次回放之内跨季度的续训，每次回放开始时 `state_dir` 为空。
- **本臂 `gpu_count = 0`，纯 CPU**；策略容器按 **8 核 / 16 GiB** 设计，超了直接 OOM。线程数写死在 8。
- `fit` 样本不足、打分读不到状态、训练与决策矩阵的列名不一致时直接报错——不设退路。
- 本臂不挂分钟域，执行时点只有 09:30 与 15:00；**一列新数据都不读**，数据集选择与预建种子沿用 20260924 轮学习器轴那条臂（`pit-field-map.md`）。
- 复核节奏是无状态的：到期判断拿最新可见交易日与决策日比自然月或周桶。
- 不要把 `refs/` 里的文件拷进 `output/`：整棵包是只读的，`cp` 会把权限一起带过去。

## 账户与成本

研究期几何、预算、冻结门与毕业条件以运行事实为准。**开工第一件事是读自己的运行事实**：`broker_replay.initial_cash`、`benchmark_index`、`acceptance_rules`（跟踪授权、两个回撤上限、成本压力倍数、每月回合数与仓位下限）、`budgets` 与 `max_replay_years`。本包按 **100 万元、不带跟踪授权**写成。

100 万元 50 席：座位约 19,400 元，一手买得起收盘价 194 元以下的成分（逐年买不起 2.8–6.6 %），5 元最低佣金约 2.6 bp/边，一次往返约 20 bp。**宿主没有年换手上限**；真正按换手收钱的是前推的 F5 成本压力（多扣 5 bp × 年换手）。本包把年换手的上限定在 **20 倍**，理由与算术在 `families.md` 与 `references/capital-arithmetic.md`：20 倍时 F5 要扣 1 pp/年，年成本约 2 % 的权益。

## 「没有边际」的读法

每个候选按 `families.md` 的判据与杀死条件逐条读，不看整窗总收益。**两条候选都没过 H2 是最可能的结局之一**，它带着三条腿的同批 Δ、H3 的读法与构造的形状结束本臂，那之后本载体上不再开任何构造变体：约束（传导系数 0.68 在手）、陈旧与倾斜都量过了，都不是秩 IC 流失的地方。`f1` 过了而 `f2` 把增益拉没了，同样是一行有用的登记：跟得上分数的书多挣的是倾斜。

## 禁止退回别的家族

本包的候选只有 `families.md` 登记的五条腿及其变体轴。不得改动分数的任何一处（改了就不再是「只动构造」）；不得给 `c_base` 打开补座位；不得加任何新数据列；不得把节奏调得比规则更快；不得按市场状态改仓位、席位或节奏；`f2` 不得装优化器；`c_base` 永远不得提名。

## 本包的硬要求

跨实验的运行教训不写在参考包里（见 `inputs/skills_index.json` 的运行记忆）。本包在流水线之外只加五条，全部写在 `families.md`：预登记（P1）、敞口并排汇报（P2）、成本与换手（P3）、按主动读数导航（P4）、构造的形状逐次汇报（P5），外加一张**登记在先的事实表**与一份**先登记的验证计划**。
