## 本臂的形状：一个在别处挑出来的规则分数，搬到一个没挑过它的池上

**来历，与它带着的挑选。** `range20` 是 `index_relative_1m_b_20260919` 在沪深 300 成分上、2021-07..2025-06 这段研究期里筛过的 18 个价量信号中 h10 ICIR 最高的一个（0.439，t 4.30；另外 17 个是 maxret20、turn20、lowvol60、lowvol20、turn60、value_pb、value_pe、skew20、rev20 / 60 / 120 / 5、amihud20 / 60、mom60 / 120、volratio5_20）。那条臂用它建的等额书 `d1_range20cap` 是登记册 §3 里最强的在册读数（下表）。所以沪深 300 上的 IR 1.25 带着一次 18 选 1 的挑选，本包的预期量级把它向下收缩（`refs/references/low-volatility.md`）。

**trial 账怎么记，写死在这里。** 在中证 1000 上，`r1` 是**唯一一个登记的配置**，此前从没在这个池上筛过；包作者对它本身的离线门读数是对提交配置的读数，提交之后按宿主 trial 计，不按离线申报。所以第一批申报 **`offline_trials` = 0**，除非会话自己再筛了别的变体（每个加 1）。那 17 个兄弟信号是在另一个池上被挑下去的，本包写明它们、不申报它们；**在沪深 300 上重测这个分数就必须把它们申报进去**（N_eff 18，四年门槛约 1.9），所以本轮不跑那一格。还有一层没有任何一条臂计数的挑选：本轮的广度清单是看过沪深 300 这条在窗读数之后才选中这个分数做换池的，包作者又是看过离线门之后才交给运营者建臂的——这两层都写在这里，不进 DSR。

| 成交 | 卖出 09:30、买入 15:00；按 T-1 收盘**四舍五入到最近整手**再按剩余现金截断；`CASH_BUFFER` 0.97 |
| 基准与账户 | `knobs.INDEX` = `000852.SH`、`knobs.CAPITAL` = 100,000、`knobs.SEATS` = 12、`knobs.KEEP_BAND` = 4.0：第 0 轮先读运行事实 `benchmark_index` 与 `broker_replay.initial_cash`，不符时改常量去对齐它们，反过来不行 |

**三个形状常量是按不读收益的普查定的**（`refs/sources.md`）：保留带若照 50 席那一包取 2 倍（前 24 名），12 席的书双边年换手约 11 倍，贴着 10 万账户的 12 倍上限；取 4 倍（前 48 名，约等于 50 席孪生臂的买入深度）时约 7.4 倍，持仓的平均池内分位只从 0.8 % 退到 1.2 %。「每次最多换 席数 / 5」的上限在 47 次复核里会有 41 次顶满（保留带 2 倍时），所以不设。行业上限取 0.28，即每个申万一级 3 只（0.25）：未设上限时顶端 12 只的最大行业占比在 48 次复核里有 20 次超过 0.30（交通运输、银行）。

## 离线门 G-R20（整期批次之前必须重算，全离线，0 回放年；筛过的候选配置各计一个 trial）

登记的判据，一次写死：S1 覆盖不足，或 S2 秩 IC ≤ 0 / 不显著，或 S3 顶端对同池随机不挣，或 S4 规模中性 IC ≤ 0，或 S5 月度书输给同池等权，⇒ 命中。

- control：`c_shuf` 永远写 control: true——照常花回放年、计入完整研究期验证数，但不是 trial，也永远不能提名；`r1`、`r2` 与任何变体写 control: false。把候选登记成对照，它就失去提名资格；把对照登记成候选，是白给自己加一个 trial。
- offline_trials = 本批申报前离线筛过、读数影响了本批提交什么、但本批没有提交的候选配置数；提交进本批的候选在宿主验证时按 host trial 计，不重复申报。

冻结门的试验数 M 是本臂验证过的非对照 revision 加上各批申报的 offline_trials，按 ρ̄ 折成有效试验数 N_eff = ρ̄ + (1 − ρ̄)·M；公式与阈值以运行事实 acceptance_rules.freeze_gate 为准（本轮默认 min_dsr_probability 0.975）。

| 判据 | 怎么算（`refs/references/offline-screen.md`） | 命中 |
|---|---|---|
| **S1 覆盖** | 研究期 48 个复核日，池里可打分的只数与占可交易成分的份额 | 任一复核日 < 24 只，或任一研究年份额 < 0.90 |
| **S2 秩 IC** | `/mnt/tools/screen.py` 在 `/mnt/snapshot` 上，`--start 20210701 --end 20250630 --horizons 5,10,20,40 --top-fraction 0.0132`（12 ÷ 约 910），h = 20 | `ic_mean` ≤ 0 或 `t_stat` < 2.0 |
| **S3 顶端** | 同一命令逐研究年各跑一次，`r1` 与同池随机对照（同一批格子上逐日重抽的散列分数）的 h = 20 `top_excess_mean` 之差 | 四个研究年里有 2 个或更多 ≤ 0 |
| **S4 规模** | S2 那一次的 h = 20 `ic_size_neutral` | ≤ 0 |
| **S5 月度书** | 登记的构造（12 席、保留带前 48 名、每个行业 3 只、一手 ≤ 8,083 元、强卖）逐月建书，复核日收盘买、下一个复核日开盘卖，减同池等权；47 个月 | 四年平均 ≤ 0，或为正的研究年少于 2 个 |
| 诊断（只报不判） | h = 5 / 10 / 40 的 IC；十分位剖面（逐年顶端与底端十分位对池的月度超额）；200 本同池随机 12 只书的年化主动与主动 IR 的 p10 / p50 / p90 及 `r1` 的分位；书的行业与创业板占比 | — |

**命中了怎么办**：以 `no_edge` 收尾本来就要本会话至少一次完整期验证，所以不论命中与否，唯一一批都花在登记的 `r1` 本身上（下面的验证计划）；命中是登记好的预测，宿主读数要对着它读。**这道门只能否决，永远不能证明边际**：离线读数只有秩与方向可信，水平与 Δ 不可信（同一条检查里秩相关逐位复现，Δ 从离线 +5.54 pp/年 翻成实测 −0.63 pp/年）。

- **规则分数是确定的，没有训练种子要复现**（登记册 §4 那条「单种子的增量不是证据」在这里没有对象）。仍然适用的两条噪声：同一本书只因面板重抽就差约 0.55 pp/年（IR 差 0.1 以内按面板噪声读），离线侧的噪声底约 4 pp/年。
- 第一批之后，对 `r1` 的完整期节点跑一次 `run_null_control`：不花回放年，**是诊断不是判据**。

## 允许的变体轴

只有一格登记：**`r2`（`RANGE_DAYS` = 60）**，只在正常路径上、作为邻点检查进场。会话若要筛任何别的变体（比如按板块涨跌幅把振幅归一、换成 `rmax`、改席数或保留带），**每筛一个都计一个 trial**，在它筛过之后第一个记下验证的批次申报 `offline_trials`；改提交它就是一次新登记，重写 `hypothesis`，`r1` 按筛过而没提交再加 1。

**禁止**：用前推期或 Held-out 的任何信息；在分数里加入任何别的数据集的列（基本面、资金流、载体分数……那是另一条臂）；非等额权重；把 `c_shuf` 改作候选或把候选登记成对照；把任何东西放进 `models/`；用最新一张成分截面去标注历史决策日；用别的指数建书而仍按 `benchmark_index` 评；为了追读数改保留带、行业上限或复核节奏而不申报。

## 提名条件（冻结前逐条满足）

1. G-R20 已重算，五个判据量与诊断读数写进结果笔记。
2. 完整研究期验证完成，冻结门按运行事实通过（含 `max_drawdown` 与 `active_max_drawdown`）；完整期验证数达到运行事实 `min_full_span_validations`（对照也计入）。
3. **`r1` 越过 K4，且第二批的 `r2` 也越过同一条线**（杀死条件 K5）；两条都过冻结门时提名 `r1`（登记在先），只有一条过门就提名那一条。
4. 逐年分块的**主动**超额为正的研究年 ≥ 3 / 4。
5. P2 / P3 / P4 / P5 全部成立（含年换手 ≤ 12 倍）；`pnl_concentration.top5_share_of_gross_gains` ≤ 0.5——12 只的书上这一条更容易越线，照实报；实测每月完成回合 ≥ 1。
6. **实现底线**：单次复核决策 < 60 秒、容器内存峰值明显低于 16 GiB；意图买单拒单率 ≤ 30 %；座位填满率与买不起份额逐次汇报。不成立先修实现再复测，不算证伪。

## 什么会杀死它（命中即停）

1. **K4：第一批里 `r1` 的主动 IR 低于零技能第 90 百分位 1.2816 × √(244 / T)**（T 是完整研究期的交易日数，四个研究年约 **0.64**），**或**主动超额为正的研究年少于 3 个，**或**主动回撤 > 0.30 ⇒ 以 `no_edge` 结束，不开第二批、不换轴。
2. **K5：第二批里 `r2` 的主动 IR 低于同一条线** ⇒ `r1` 的读数在相邻窗口上站不住，以 `no_edge` 结束，即使 `r1` 自己过了冻结门也不提名。
3. P2 在已登记构造下不成立（`top_industry_weight` > 0.30）⇒ 关闭并写明是哪个行业。
4. `excess_at_2x_slippage` ≤ 0，或年换手 > 12 倍，或实测每月完成回合 < 1 ⇒ 这个形状不可交付，以「不可交易」关闭。
5. 整期验证上限（3 条，对照也算）用尽而没有满足全部提名条件的候选 ⇒ `no_edge`，不为了凑提名再开一批。
