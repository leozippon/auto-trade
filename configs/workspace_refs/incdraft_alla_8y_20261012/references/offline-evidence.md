# 离线读数与账户算术（incdraft_alla_8y，20261012）

本页是两份设计备忘（`logs/notes/round_20261012/DESIGN.md` 与 `DESIGN_2_expanded_data.md`，会话读不到）里与本臂有关的研究期离线读数，外加包作者在本臂种子的原始标题上数的事件个数。全部只用研究期数据，没有一个是宿主读数。

**怎么读这些数。** 超额是对同一天同一流通市值五分位名字等权均值的差（宿主的零技能面板按基准成分换名、再对基准与规模价差回归，两者不是一回事）；限席书每 5 个交易日按事件先后补席、不排序、不计成本、没有行业上限与一手过滤；t 是按月份的组均值算的。设计者自己的说法：水平只准到 ±0.3 IR，宿主读数可能更好（它的书比粗糙的补席更紧），也可能更差（它要付零技能面板的抽样噪声与真实成本）。

**数据源。** §0 是数据开发者在本臂种子的同一份供应商标题上重跑的事件研究；§1、§2 是设计者用湖里的副本（2020 年起）拼上公开披露网站（2017-07..2019-12）读的。网站在 2017–2019 少了供应商的 349 个草案日（345 个是员工持股计划），所以 §1、§2 的水平不要指望宿主复现。

## 1. 事件研究（进场：日期戳之后第二个交易日收盘；涨停封板当天跳过）

| 网站，2017-07..2019-12（筛选没见过） | 939 | +0.46 / +1.41 / +2.83 / +3.42 % | 3.0 / 3.1 / 3.9 / 4.6 | — / +1.30 / +2.59 / +3.16 % | +0.8 / +1.6 / +1.6 %（20 / 40 / 60 日） |

- 2020-07 之后五个研究年的 40 日超额：+0.8、+2.3、+1.5、+1.8、+2.4 %；2017–2019 三年都为正。2017–2019 的晚进场也为正，那一段读数约四成是「哪类公司会发草案」而不是公告本身——这正是 `c_late` 要量的。
- 按计划类型（40 日）：限制性股票 +2.1 %（t 3.3），员工持股计划 +0.7 %（t 1.0）。
- 第一周的反应只有 +0.1…+0.5 %；漂移在两三个月里随业绩到来。
- 不是小盘效应：同板块同五分位比照样成立；流通市值较小的一半与全部几乎一样（20 日 +1.1 对 +1.0 %）；事件的流通市值分位四分位数 0.27 / 0.55 / 0.79。
- 日历时间书（持有每个 40 日内有事件的名字，约 112 只）2020-07 起 +8.8 %/年、IR 1.54、5/5 年。

## 4. 账户算术

**竞价的深度（2024 年，每只股票每天）。** 收盘集合竞价成交额中位数约 85 万元，开盘约 39 万元；流通市值较小的一半是 57 万与 27 万，最薄的十分之一是 25 万与 9 万。一张 16,170 元的单子在中位数名字上是收盘竞价的 1.9 %、开盘的 4.1 %，在最薄的十分之一是 6.4 % 与 17.6 %。Broker 的固定 5 bp 滑点对 8,000 元的收盘单是公允的描述，对 50 万在最薄名字上的开盘卖单是乐观的——所以 50 万两条腿都放在收盘，并只买近 20 日成交额中位数不低于 4,000 万元的名字（约等于 50 万元的收盘竞价）。2018-08-20 之前上交所没有收盘集合竞价，那一段的 15:00 价格是连续竞价的收盘价。
