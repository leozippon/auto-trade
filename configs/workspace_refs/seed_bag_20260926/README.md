# 种子平均参考包（seed_bag，20260926，沪深 300）

本目录是只读 refs，会话里挂在 `refs/` 下（本包各文件的路径一律按会话一侧写，例如 `refs/families.md`、`refs/references/seed-bagging.md`）。本包登记的是**同一本书、同一个分数家族，只动训练种子**：载体是 20260923–20260925 三轮共用的 Alpha158 + LightGBM（沪深 300 成分，β 残差 10 日标签，季度续训），书是它的月度、每次最多换 8 只、保留带 2.0 的 50 席等额书。四条腿共用这一切，差的只有分数由哪几个 booster 平均而来：`c_s7`（种子 7，就是模板书）、`c_s8`（种子 8）、`b5`（种子 7–11 的秩平均）、`b10`（种子 7–16）。定义只有一处：`output/lib/knobs.py` 的 `SEEDS`。

## 已经知道的，与要检验的

**已经知道的。** 登记册 §3：这条载体的秩信息是真的，而这本书的主动收益与零技能分不开——同一本书在五条臂里验证过六次，主动 IR 0.077–0.190，并列规则不同的那一份 0.262。登记册 §4：训练种子的方差远大于面板重抽——跟得上分数的那本书只把种子 7 换成 8，主动 IR 就从 0.870 落到 0.402（3.21 pp/年），约是面板重抽 0.55 pp/年 的六倍；上面那段散布全部来自种子 7。作包时在研究期末视图上量出（`refs/families.md` 的事实表）：五个单种子的分数两两秩相关 0.893、前 50 名只重合 74 %，而它们的秩 IC 几乎一样（+0.042…+0.047）——**种子改的是顶端具体是哪几只，不是分数排对了多少**；五个种子的秩平均把种子噪声从分数方差的 11 % 压到 2 %。这些是登记在先的事实，**不是一道门**。

**要检验的是 H-bag**：对训练种子求秩平均不改变这本书主动收益的期望，只收窄它在种子之间的散布。第 1 批 `c_s7` + `c_s8` + `b5` + `b10` 同批跑完，交出四个预登记读数——这本书自己的种子差（R1）、袋落在两个单种子的哪里（R2）、会话自己的种子普查（R3）、逐年符号与换手（R4）——并按一条事先写死的冻结路径读 `b5` 与 `b10`。**常见情形下第 1 批就是整条臂。**

机制、秩平均的算法与单因子口径下平均能压下去多少，在 `refs/references/seed-bagging.md`；文献只取方向不取水平（`refs/sources.md` 的文献表带置信标签）。

## 按以下顺序读

1. `refs/families.md`：载体、**作包时已量出的事实**、H-bag、腿、预登记的读数 R1–R4 与判读带、验证计划、冻结路径与门槛、提名条件与杀死条件（**唯一权威表述**）。
2. `refs/pit-field-map.md`：逐年的 60 个月输入窗、逐表可见时点、单位与陷阱（唯一权威表述）。
3. `refs/exploration-plan.md`：第 0 轮核对、冒烟与种子普查、第 1 批、判定分支与计算预算。
4. `refs/references/`：六份自写笔记——**`seed-bagging.md`**（种子从哪里进来、秩平均、平均能做什么不能做什么）、**`seed-census.md`**（在研究期末视图上复核种子普查的口径，R3 用它）、`zero-skill-panel.md`（裁决口径、零技能面板、同一本书读两次差多少）、`capital-arithmetic.md`（账户算术与换手的价钱）、`index-membership.md`（成分面）、`fit-cost.md`（K 个种子的拟合成本）。沙箱无网络，外部出处列在 `refs/sources.md`。
5. `refs/sources.md`：读数出处与重算它们的命令、作包的普查与冒烟实测、诚实的限制。
6. `refs/starter/`：合同内的最小可运行包，**就是**这几条腿本身，`main.py` 的 `CANDIDATE` 在 `SEEDS` 的名字之间切换。它通过 `validate_strategy_package`，在真实宿主流水线上跑通了 `c_s7`、`b5` 与 `b10`；`c_s7` 的 70 天冒烟与 20260924、20260925 两包的模板书冒烟**逐笔相同**（`refs/sources.md`）。**会话开始时 `output/` 就是这份代码**，`refs/starter/` 只是同一份的只读副本；`lib/primary.py` 的 `members` 给出每个成员的百分位秩，种子普查直接调用它。

## 这条臂怎么判

**第 1 批 `c_s7` + `c_s8`（两条对照，`control: true`）+ `b5` + `b10`（候选，`control: false`），一次完整期验证、16 个回放年**（`b10` 只在第 0 轮冒烟量出它的拟合装得下时进批，规则写在 `refs/families.md`）。冻结门此刻的门槛约是主动 IR 0.98（两个高度相关的候选、N_eff ≤ 1.3）；`b5` 与 `b10` 都没过冻结门的统计条件 ⇒ `no_edge`，交出 R1–R4。有袋过了，才开第 2 批：它的不相交种子孪生（`b5x` / `b10x`），孪生也过了才提名。**全臂不超过 3 个 host trial、5 次完整期验证、20 个回放年。** 两条对照永远不得提名，`c_s7` 永远是一批里的第一条腿。

**事先说出来的量级**：这本书的七次宿主读数在 0.077–0.262，冻结要 `b5` 读到其中最好那次的近四倍；按 H-bag，本臂事先不指望它。本臂真正要交给登记册的，是 R1：这本书的读数里有多少是种子。

## 你被评的是主动序列

每次正式验证结束后，**宿主**按候选自己的成交骨架随机换名重放若干份，取日收益等权均值作为**零技能面板**，在「候选减面板」的主动序列上算全部统计量。包不设零技能对照腿，也不设信息比率或 DSR 的门——那些是流水线的，写在运行事实里。本臂最该记住的三条（`refs/references/zero-skill-panel.md`）：

- **四条腿是同一本等额现金的月度书**，差的只有分数；面板对齐了池、日历、每笔的钱与成本，所以同批腿之间的主动差只能来自分数。
- **一次宿主读数带两种噪声**：面板重抽（同一本书两次差 0.55 pp/年）与训练种子（本臂第一次在同一批里量它）。
- **载体的主动 IR 是一段散布，不是一个数。**

## 本臂的执行边界

执行合同——入口与订单、允许的 import、文件 I/O、`available_at` 与 PIT 读法、不写死宿主路径、沙箱无网络——以只读 `output/README.md` 与系统提示为准，本包不复述。本包只在以下几点上更具体：

- 本包声明 `fit(context)` 与季度重训；每个种子一个 booster，只经 `save_model` 写进 `context.state_dir`。**`models/` 只放随产物交付的静态资产**；「续训」指一次回放之内跨季度的续训，每个成员接续它自己的文件，每次回放开始时 `state_dir` 为空。
- **本臂 `gpu_count = 0`，纯 CPU**；策略容器按 **8 核 / 16 GiB** 设计，超了直接 OOM。线程数写死在 8。
- `fit` 样本不足、续训或打分时缺某个成员的 booster、训练与决策矩阵的列名不一致时直接报错——不设退路。
- 本臂不挂分钟域，执行时点只有 09:30 与 15:00；**一列新数据都不读**，数据集选择与预建种子沿用 20260925 轮新鲜书那条臂（`refs/pit-field-map.md`）。
- 复核节奏是无状态的：到期判断拿最新可见交易日与决策日比自然月。
- 不要把 `refs/` 里的文件拷进 `output/`：整棵包是只读的，`cp` 会把权限一起带过去。

## 账户与成本

研究期几何、预算、冻结门与毕业条件以运行事实为准。**开工第一件事是读自己的运行事实**：`broker_replay.initial_cash`、`benchmark_index`、`acceptance_rules`（跟踪授权、两个回撤上限、成本压力倍数、每月回合数与仓位下限、DSR 阈值）、`budgets` 与 `max_replay_years`。本包按 **100 万元、不带跟踪授权**写成。

100 万元 50 席：座位约 19,400 元，一手买得起收盘价 194 元以下的成分（逐年买不起 2.8–6.6 %），5 元最低佣金约 2.6 bp/边，一次往返约 20 bp。每次复核最多换 8 只把年换手钉在约 3.5 倍，年成本约 0.35 % 的权益（`refs/references/capital-arithmetic.md`）。换种子不改能换几只，只改换的是哪几只。

## 「没有边际」的读法

每个候选按 `refs/families.md` 的判据与杀死条件逐条读，不看整窗总收益。**`b5` 与 `b10` 都没过冻结门是预先说出来的最可能的结局**，它带着 R1–R4 结束本臂：R1 落在「种子主导」那一带，就说明登记册里这条载体的散布有一截是种子，此后任何还要用这条载体作对照的臂都该用平均过的分数；落在「分不开」那一带，就说明这本月度封顶书对种子不敏感，`f1` 的种子脆弱来自它更勤地跟着分数的顶端走。两种读法都是登记册要的那一行。
