# 研究会话探索计划

目标：在本臂唯一的研究会话里，用一批同批腿在宿主上量三件事——**同一本月度书换一个训练种子差多少**（`c_s7` 对 `c_s8`），**五个种子的秩平均分数把这本书的主动读数放在哪里**（`b5`，以及拟合预算装得下时的 `b10`），以及**这个候选过不过冻结门**。H-bag 的判据、腿、验证计划与冻结路径只在 `refs/families.md`，数据与单位只在 `refs/pit-field-map.md`，机制与普查口径在 `refs/references/`，本文只排顺序与预算。

**常见情形下第 1 批就是整条臂**：`c_s7` + `c_s8` + `b5` + `b10` 一批读完，`b5` 与 `b10` 都没过冻结门的统计条件就 `no_edge`，四条腿的读数交给登记册。

## 第 0 轮：不占回放预算的核对、冒烟与种子普查

1. **运行事实核对（最先做的一件事）**：`broker_replay.initial_cash`、**`benchmark_index`**、`acceptance_rules`（有没有跟踪授权；两个回撤上限；`min_dsr_probability`、`min_active_ir`、`min_positive_year_share`、`min_full_span_validations`）、`budgets`（`strategy_fit_timeout_seconds`、`batch_validate_max_concurrency`、`batch_validate_fit_timeout_note`）与 `max_replay_years`、`research_geometry` 的 `input_window` 与逐年 `years[].input_window`。本包按 100 万元、不带授权、50 席写成；`benchmark_index` 与 `lib/index.py` 的 `INDEX_CODE` 不一致时**改常量去对齐运行事实**。
2. **数据核对**：`index_weight` 与 `index_daily`（按 `ts_code` 过滤）在不在；`universe` 带不带 `l1_name`。本臂不读任何别的数据集。
3. **冒烟与 `fit` 成本（提名条件 7 与第 1 批装不装得下 `b10` 的依据）**：`smoke_backtest` 的窗口**上限是 5 天**，所以它量的是可跑性与一次拟合的秒数与内存，不是换手。在研究期靠后的一个槽上，对 `c_s7`、`b5`、`b10` 各跑一次（`days` ≤ 5，同一个 `start` 复用），读 `resources.fit_seconds`、`peak_memory_bytes` 与买单元数据里的 `seeds`、`refits`、`valid_metric`。第一次 `fit` 是冷启动；续训的秒数要在完整期里读（`refs/references/fit-cost.md`，作包时 70 天宿主冒烟的冷 / 续训读数在 `refs/sources.md`）。`smoke_backtest` 不花回放年，也不计 trial。**年换手与费用读完整期验证的 `turnover`（÷ 4）与 `fees_paid`**，不要试图用冒烟去量。
4. **`b10` 进不进第 1 批**：按 `refs/families.md` 验证计划下面那条规则，由第 3 步量出的 `b10` 拟合秒数决定；这是一个拟合预算的决定，不看任何收益读数。
5. **种子普查（预登记读数 R3，必做）**：按 `refs/references/seed-census.md` 在研究期末视图上还原第三、第四研究年每个交易日的五个单种子分数（`primary.members`，种子 7–11），算两两秩相关、前 50 名重合、`b5` 与各单种子的秩相关与去一相关，以及单因子口径下 K = 1 / 5 / 10 的种子噪声份额。它不读收益，**不是筛选、不计 trial、什么都不申报**。同一份视图、同一个镜像里的读数应当与 `refs/sources.md` 的普查逐位相近（多线程浮点末位除外）；有不一致就写进结果笔记与第 1 批的 `hypothesis`。可选：普查里顺带读 `b5` 与五个成员对 10 日 β 残差标签的秩 IC——只读这六个预登记的对象，是描述不是门；**对任何别的种子清单、别的 K 或别的合成方式读收益，就是筛过的配置**，照 `offline_trials` 申报。

## 第 1 批：`c_s7` + `c_s8` + `b5` + `b10`，一次完整研究期 `batch_validate`

腿按这个顺序提交：**`c_s7`（第一条，`control: true`）**、**`c_s8`（`control: true`）**、**`b5`（`control: false`）**、**`b10`（`control: false`，第 4 步装得下时）**；四个研究年花 16 个回放年（不带 `b10` 时 12 个）。`offline_trials` 申报 0，除非第 0 轮对别的配置读过收益。两条对照照常花回放年、计入完整研究期验证数，但不是 trial、永不可提名。

`hypothesis` 必须写清：逐行引用 `refs/families.md` 的载体表与腿表；H-bag 与四个预登记读数 R1–R4 的判读带（数字照抄）；冻结路径与它此刻的门槛（`selection_statistics.information_ratio_bar` 的预期值与它怎么来）；第 0 轮普查的读数与不一致；本臂的 trial 账与 `fit` 成本。

**不要再加零技能对照腿**——宿主每次正式验证都会抽面板。回放一旦开跑就计入预算，策略自身抛错的候选照样花掉，环境失败的候选退还；某一路因环境原因失败时不重跑、不压缩对照，把读数与待裁决的分支写进结果笔记。

第 1 批之后，对 `b5` 的完整期节点跑一次 `run_null_control`：不花回放年，会话时钟在它运行期间暂停；**它是诊断不是判据**，三个数一起报。

## 判定分支，逐条写死（判据本身见 `refs/families.md`）

- **`b5` 与 `b10` 都没过冻结门的统计条件（K1）** → 以 `no_edge` 收尾，不开第 2 批。R1–R4 与 `fit` 成本写给登记册。这是本臂预先说出来的最可能的结局。
- **`b5` 或 `b10` 过了** → 第 2 批只跑它的**不相交种子孪生**（`b5x` 或 `b10x`，两条都过时只跑 `b5x`），孪生也过了、其余提名条件全部成立，才冻结预登记的那一条（`b5` 优先），不在 `b5` 与孪生之间挑高的那条。孪生没过（K2）→ 第一次的读数按运气写，`no_edge`。
- **`c_s7` 与 `c_s8` 的差很大（R1 落在「种子主导」那一带）** → 这是本臂最有用的一行：登记册里载体的那段散布里有多少是种子。照实写，不因此开任何新腿。
- **`b5` 落在两个单种子之间** → H-bag 预期的样子；**`b5` 高于两者** → 仍只看冻结门，不是证据；**`b5` 低于两者** → 照实写，看逐年与每次复核的换出，不追读数。
- **`b5` 的年换手或每次复核的换出明显不同于单种子** → 上限（每次 8 只）没有每次顶满，写进 R4，它说的是平均过的分数更稳，不是 α。
- **绝对超额高而主动超额低** → 赢的是股票池不是分数，看 `benchmark.panel_neutralized_excess`。
- **实现读数不对**（`fit` 逼近上限、拒单率高、座位没填满）→ 先修实现再复测，按提名条件 7，不算证伪。

## 收官轮

只做两件事之一：对已经满足全部提名条件的候选补齐缺的读数并冻结；或者以 `finish_session(outcome="no_edge")` 携读数结束本臂。收官轮只在 K1 或 K2 命中、或上限用完时才开始。

## 计算预算

- **资源边界**：16 GiB / 8 CPU / 无显卡，单次 `fit` 上限 3,600 秒（运行事实为准；`batch_validate` 并发池存续期间按实际并发路数放大）。每条腿一次整期 16 次季度重训（4 次冷、12 次续训），`b5` / `b10` 的每次重训是五个 / 十个 booster 依次训练，面板与特征只建一次；实测秒数与内存在 `refs/sources.md`，量级与外推在 `refs/references/fit-cost.md`。
- **种子普查**：第三、第四研究年、8 次 `b5` 拟合加约 490 个交易日的打分，在 8 核容器里十来分钟；一条链串行跑，不要并行抢核。
- **回放年**：第 0 轮全部是 0 年；第 1 批 16 年（不带 `b10` 12 年）；排满计划 20 年。**全臂 host trial ≤ 3、完整期验证 ≤ 5、回放 ≤ 20 个回放年**。宿主 trial 只花在整期上，每一个验证过的候选与每一个离线筛掉的候选配置都会抬高本臂自己的 DSR 门。
- **单日探针的秒数对宿主负载极敏感**，耗时结论按多日回放的平均读。

## 每个候选必须汇报的读数

除标准结果块外，写进结果笔记：逐行对照 `refs/families.md` 的载体表与腿表；H-bag 的判读与四个预登记读数 R1–R4；**主动中性化超额、主动跟踪误差、主动信息比率**与**面板自己的中性化超额**；逐年分块的主动超额与原始超额，以及对两条对照的逐年 Δ；年换手（`turnover` ÷ 4）、年完成回合数、费用账、研究期成本压力判据与 `excess_at_2x_slippage`；每次复核的换出只数与 `book_tc`；拒单率与原因（`daily_price_limit` 与 `missing_execution_price` 分开）；平均总仓位；`top_industry_weight`、`size_tilt` 与 `size_beta` 并排；`pnl_concentration`；空对照的三个数（只对 `b5`）；`selection_statistics` 的全部字段（`information_ratio_bar`、`effective_trials`、DSR）；每次重训的 `fit` 秒数、容器内存峰值与一次复核决策的墙钟。缺任何一项的结果不作为提名依据。

## Validation 否证（任何一条命中，结果无效，不讨论收益）

- 股票池不是按时点读出来的：硬编码名单、用别的指数建书而仍按 `benchmark_index` 报跟踪误差、或用最新一张截面去标注历史训练日。
- 用 `trade_date` 而不是 `available_at` 判可见；`weight` 当成小数没有 ÷ 100；`index_daily` 不按 `ts_code` 过滤。
- **腿与腿的差不止种子**（改了特征、参数点、轮数、切分、标签、池、重训节拍、书的规则、下单时点或同分规则之一），或者种子清单不是 `knobs.SEEDS` 里登记的那一份。
- 袋里的成员不是等权的秩平均（按验证 L2、按 IC 或按任何读数加权）；或者挑了读数最好的单种子当候选。
- 普查时用期末那一次拟合给全部决策日打分，或离线重建时没有把 `daily` 截在决策日的 T-1。
- as-of 域读失败后回退了 `snapshot_dir`；读多数据集的域时没有先按 `dataset` 过滤；任何读取不带日期窗口。
- 买不起的**持仓**被当成离池强卖；或者买单向下取整而不是按最近整手四舍五入。
- 复核节奏依赖模块级计数器或跨调用缓存。
- 把训练好的 booster 放进 `models/`，或让 `state_dir` 里的东西跨回放存活。
- 没有第 0 轮的冒烟与 `fit` 成本探针就开了整期回放；把第 2 批的孪生放进第 1 批。
- `c_s7` / `c_s8` 登记成 `control: false`，候选登记成 `control: true`；`offline_trials` 少报了筛过而没提交的配置，或把本批提交的候选重复申报。
- 用绝对中性化超额或绝对信息比率去论证边际，而不看主动读数与面板。

## 收尾

冻结的是提名节点自己的不可变快照，提名前不必把它恢复到 `output/`。不要提交离线普查脚本；`models/` 只放静态资产。
