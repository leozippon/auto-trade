# 候选、增量信息门 G-INC2、变体轴、已关闭家族与关闭规则

本文是本臂候选定义、包级要求、变体清单与关闭判据的**唯一权威表述**；`README.md` 与 `exploration-plan.md` 只指向本文，不复述。可见时点、单位与陷阱只写在 `pit-field-map.md`；算术与口径写在 `references/`，读数出处写在 `sources.md`。

本包有**一个必跑对照** `c_base` 和**两个候选** `m1`、`m_int`。三者在 `main.py` 里只差候选常量一行。本包**没有**姊妹包那种「只有块、没有载体」的诊断腿，理由写在块的说明里。

## 本轮的形状：在一个已确认的载体上加一块市场状态

本轮的块臂共用同一个**载体**，因为它是本仓库唯一一条被宿主确认过、在这个池子上读出真实技能的分数：Alpha158 + LightGBM，沪深 300 成分，β 残差化的 10 日开盘到开盘秩标签，`state_dir` 续训、每第四次重训冷启动。它作必跑对照腿读到过**主动超额 +4.30 %/年、主动 IR 0.4642、TE 9.26 %、β 0.851、3/4 年正**（同期零技能面板 +2.20 %/年）。它**低于冻结门 0.75**，所以它不是一条可以直接冻结的书；它是一把**有牙的量尺**。

本臂改的**只有特征矩阵的列**：载体的 158 列之后接上一块 12 列的**市场状态**（`m1`），或者 12 列的**状态 × 个股交互**（`m_int`）。其余一切——标签、股票池、切分、轮数、种子、重训节奏、席位、复核节奏、整手规则、仓位——逐字相同。对照与候选是同一份代码，差异只可能来自那 12 列。

## 边界：这是排序器的一列输入，不是组合层的择时

这一段是本臂存在的前提，逐字适用。

研究教训登记 §2 已经把**组合层择时**（宏观状态、指数估值、期货期权基差、IC-IM 基差切换、事件窗）关掉了：`open_mechanism_20260910` 前推超额 −24.4 %、7 笔交易、0 % 胜率，它自己预登记的「不设门」对照在样本内就赢了它；`value_regime_20260914` 前推分位 0.698 → 0.472 → 0.466。同表还关了按 `r_5`/`mom_20`/`turn_20` 择时入场、时序波动目标敞口缩放、现金为零时按回撤触发的抄底 overlay 与板块广度门。它们的共同点是**状态决定这本书持有多少、什么时候动**。登记 §5 第 3 条留着的是另一件事：**状态作截面排序器的特征**——「作为特征」这一形态从未与择时区分过。

本臂就是这条区分，写成可检验的构造规则：

- **书的形状与状态无关。** 50 席等额现金、`CASH_BUFFER` 的仓位、每月首个决策日复核、每次最多换 `MAX_SWAPS` 只——三条腿逐字相同，不读任何一列状态。状态列只进 booster，只改变**哪些名字**坐进这 50 个座位。
- **可检验**：构造代码不读任何一列状态；同批三条腿的复核日与书的只数逐次相同，每张买单的目标权重都是 1/`SEATS`；平均总仓位只允许因每次换名的只数、价格漂移与整手差出一两个百分点，不得有按状态分段的差异（P6）。
- **范围之外**：任何一条按状态改总仓位、留现金、减席位、跳过或加开复核、切换池子或换基准的腿，**不是本臂的变体，是那个已关闭的家族**。本臂不登记、不跑、不提名这样的腿；想测它就是另开一个登记，并先说清楚它为什么不是登记 §2 那一行。

## 新信息块：市场状态（12 列，两种形态，`lib/market_state.py`）

**假设。** Alpha158 的每一个算子都是拿一只名字和**它自己的过去**比。它不知道那一天**整个市场**在干什么，所以 booster 只能学一条对反弹、暴跌与慢涨一视同仁的排序规则。可是哪一类名字排在前面本来就随状态变：动量在急跌后的反弹里崩掉、低波在压力期占优、离散度高时选股的回报更大。本块把市场的状态作为列交给 booster，让一次分裂可以**按状态改排序**，而书本身一点不动。

**`m1`：12 列日期级状态**（同一个 bar 上所有名字取同一个值；`s`/`l` 是 `knobs.STATE_SHORT` / `knobs.STATE_LONG`）

| 组 | 列 | 构造 |
|---|---|---|
| **基准收益** | `mkt_r1`、`mkt_r5`、`mkt_r_s`、`mkt_r_l` | 基准（`INDEX_CODE`）收盘的 1 / 5 / s / l 日收益，T-1 收盘为止 |
| **基准波动** | `mkt_vol_s`、`mkt_vol_ratio` | s 日已实现波动（日收益标准差 × √244）；`log(s 日波动 / l 日波动)`，即波动相对它自己近期的位置 |
| **基准趋势** | `mkt_ma_s`、`mkt_ma_l`、`mkt_dd_l` | 收盘对 s / l 日均线的偏离；收盘对 l 日最高收盘的回撤 |
| **成交活跃度** | `turn_z` | 基准成交额取对数，5 日均值减 l 日均值、除以 l 日标准差 |
| **成分截面** | `xs_disp_s`、`breadth_l` | 当日在册成分 s 日收益的四分位距（截面离散度）；站上自己 l 日均线的成分占比减 0.5（广度） |

**`m_int`：12 列状态 × 个股交互**（每只名字每天各不相同）：3 个个股因子——自己的 s 日收益、l 日收益、s 日已实现波动——各在当日在册成分里取秩并居中到 [−0.5, 0.5]，分别乘以 4 个状态：`mkt_r_s`、`mkt_ma_l`、`mkt_vol_ratio`、`breadth_l`。列名 `x_<因子>_<状态>`。

**为什么两种形态都要，而且是两条独立的候选。** 标签是**每个 bar 内部居中的秩**，每个 bar 的标签均值相同。一次按日期级列的分裂把整日整日地分开，两个子节点的标签均值还是那个值——**这一刀本身没有增益**；它只在先按某个个股列切过之后才有增益，那时条件均值才随状态变。所以 `m1` 的增量必然来自交互，而它的风险也在这里：`min_data_in_leaf` 200 对着一个 bar 上约 290 行，在一个已经按个股列切过的节点里，一刀日期级分裂可以圈出**两三个交易日**，把那几天的截面模式背下来。W1 调研把这一条点名为本形态特有的结构风险：日期级列的有效样本是**日期数**（三年窗口约 730 个），不是行数。`m_int` 把乘积直接交给树：它在同一个 bar 上随名字变化，一刀切在它上面切不出「那几天」。两种形态回答同一个问题，失败方式不同，所以各自单独过 G-INC2、各自对 `c_base` 定价，**不互为对照**。

**为什么没有 `m_only`。** 12 列状态单独喂给 booster 时，同一个 bar 上所有名字的输入完全相同，分数在当日是一个常数，**连排序都排不出来**；12 列交互单独喂进去，是三个个股因子按状态翻号，不是本臂要问的问题。姊妹包的「块单独有没有信息」在这里没有对应物，它的位置由 `m1` 对 `m_int` 的比较占了。

**为什么窗口不超过 60 个交易日（不是 250）。** 本轮快照里基准的日线 `index_daily` **从 2020-01-02 起**（原始层同样从 2020 年起），而载体的面板按基准的首日裁齐，第一研究年的第一根训练 bar 正好落在首日之后一个预热期（`data.WARMUP_BARS`）。实测：若按 250 日窗口算均线偏离与波动分位，状态列在四个研究年首次 `fit` 的可用训练 bar 上只覆盖 **36.9 % / 65.0 % / 79.6 % / 100 %**。一列在训练窗口前段整段缺失的特征就是一个隐蔽的时间标记——这正是 `auction` 被连续四个包从特征里排除的那条理由。所以 250 日的均线偏离、回撤与波动分位在本包里由 l 日（60）的均线偏离、l 日回撤与 `log(s 日波动 / l 日波动)` 代替，`market_state.build` 在任何一个可用 bar 上读到非有限的状态**直接报错**，不交给 LightGBM 去当缺失值路由。起步包在四个研究年首次 `fit` 的全部可用训练 bar 上实测状态列**全部有限**（`sources.md`）。

**先验：低，写在前面。** W1 调研对这一条的估计是 P(过 G-INC2) ≈ 0.2、ΔIR 0…0.1；文献证据很薄：MASTER 自己的消融里去掉市场门控 IC 不变（0.064 对 0.064），TRA 按隐状态路由在 Alpha158 上与 LightGBM 打平（IR 1.08 对 1.02），Gu–Kelly–Xiu 的「个股特征 × 宏观状态」交互帮神经网络多于帮树。本仓库另有一条反向旁证：`lgbm_meta_100k_20260922` 的轴 b 从元模型里**拿掉** 3 列日内不变的市场状态列之后，离线 Δ 从 −3.22 变成 −0.26 pp/年（仍然 FAIL）。**唯一的正向先验**是 `xs_transformer_1m_20260922` 第二轮的受控腿差：门开减门关 **+2.42 pp/年**，逐年 +10.8 / +8.9 / −9.3 / +0.9，有规律，但它的载体 `c_temporal` 按包的合同永不可提名——这是一条**没有载体的正读数**（登记 §3）。本臂的全部信息价值在于给它换一条可提名的载体、在同批对照下重测一次；它的门控是神经网络里的逐特征缩放，本臂是树里的列，**两者不是同一个机制**，读数不能直接相比。文献与读数的细节在 `references/market-state-features.md`。

## 增量信息门 G-INC2（整期批次之前必须通过，**全离线，0 回放年**；筛过的候选配置各计一个 trial）

**登记的判据，一次写死：Δ 主动超额 ≤ 0，或本块的 LightGBM 增益份额 < 5 %，⇒ 这个形态不进整期验证。** `m1` 与 `m_int` **各自**对 `c_base` 过一次门。

本门不以 ρ 判——三条腿共用 158 列基础特征，秩相关按构造就会很高，用它作判据等于用一个恒真的条件去否决。ρ 照常汇报，**只作诊断**。本门是**消融**：同一份代码、同一批决策日、只差那 12 列，每条腿各自减去同一口径的零技能面板，比它们的主动超额。

| 量 | 怎么算 |
|---|---|
| **决策日** | 研究期**后两年**里至少 **60 个分散的决策日**（每两周取一天，或等间隔取满 60）。少于 60 天的读数不作判据 |
| **三条腿** | 每一天用起步包同一份代码，在同一成分截面上分别按 `c_base`、`m1`、`m_int` 的列集训练并打分，各取前 `SEATS` 只等额，持有到下一个信号日 |
| **Δ 主动超额** | **主动** = 前向收益减一个 **k = 20 的离线零技能面板**：每一份副本在**同一成分身份侧**（在册 / 不在册与候选一致）且这笔钱买得起一手的名字里随机换名，取 20 份日收益的等权均值。Δ = 候选的主动超额 − `c_base` 的主动超额 |
| **增益份额** | 同一批 `fit` 出来的 booster 上，本块 12 列的 `gain` 重要性之和 ÷ 全部列的 `gain` 之和（`starter/lib/primary.py` 的 `gain_share`，每张买单都带着它）。**这是一个必要条件不是充分条件**：树会给任何有方差的列分一点增益 |
| **逐年符号一致性** | 把这 60 天按研究年分开，逐年报 Δ 的符号。**只有一年为正的 Δ 不是增量**；它与「哪一年的行情」不可区分——对一块描述行情的列，这一条比对任何别的块都更要紧 |
| **ρ（只报不判）** | 候选与 `c_base` 选中集合的 Jaccard 中位数，以及两条分数的逐日秩相关中位数。**预期很高**，因为基础特征共享 |
| **验证段 L2（只报不判）** | 每次 `fit` 的早停验证段 L2（`state_dir/refit_meta.npy` 的第三个数），候选对 `c_base`。**这一条是本臂特有的**：见下 |
| **Δ 的判定** | Δ ≤ 0 即「没有增量」。Δ > 0 但**不超过两个随机种子之间的差**也按没有增量算（本家族的方向研究在三个种子之间散开过 4 pp/年） |

**增益份额这一半对本块几乎必然通过，而且说明不了什么。** 起步包在第四研究年首个决策日实测 `m1` 份额 **0.32**、`m_int` **0.24**，是按列数均分（12/170 ≈ 7.1 %）的三到四倍半（`sources.md`）。对一块日期级列，高份额既可能是树在按状态改排序，也可能是它在用状态列**圈出几个交易日背答案**——两种情况的份额一样高。所以本臂的门实际上由 **Δ 与逐年符号**决定，份额只在它**低于 5 %** 时有否决力。验证段 L2 是区分这两种情况最便宜的旁证：背答案的树在它没见过的最后 60 个 bar 上不会更准；起步包那一次 `fit` 里 `m1` 的验证段 L2 比 `c_base` 低 2.7 %、`m_int` 与 `c_base` 持平——**一次 `fit` 的一个数，不是读数**，逐次汇报，不作判据。

**这道门能说什么、不能说什么**（研究教训登记 §4，逐条适用）：

- **离线读数只有秩与消融方向是可信的，水平与 Δ 的幅度不可信。** `gnn_relation_1m_20260922` 的锚定检查里秩相关逐位复现（spearman = 1.0），而 Δ 从离线 +5.54 pp/年 翻到实测 −0.63 pp/年。所以本门读的是**符号与排序**，不是那个数值有多大；结果笔记里写 Δ 的数值时必须同时写这一句。
- **离线面板与宿主面板不是一回事。** 宿主走完整 Broker 重放（结算分红、按实际价格成交、现金不足会拒单），按候选自己的成交骨架换名；离线口径**系统性偏低且更宽松**（实测同一本书骨架面板读 +4.91 %/年，离线重定价近似只读 +2.18，主动 IR 从 1.08 掉到 0.890）。
- **门只能否决，永远不能证明边际。** 它说「不够格」时可信，说「够格」时只意味着可以花那些回放年。**裁决是宿主的整期批次，不是这道门。**
- **这道门不花回放年，但不是免费的。** 它筛过的每一个候选配置都计一个 trial：提交的在宿主验证时计，筛掉或暂缓的在下一批的 `offline_trials` 里申报（下文验证计划）；去膨胀 Sharpe 概率正是本仓库多数臂真正卡住的那堵墙。它省下的是回放年与一次给不出资格的子跨度回放，不是 trial。

命中判据时允许的去处只有轴 a（窗口）与轴 b（列集）各一轮，每一轮都重跑 G-INC2；仍不成立就以 `no_edge` 结束本臂，**不把本块改写成一个择时开关去建书**（那是上面边界一节的已关家族）。

> 头包的「子跨度验证只用来复测实现与耗时，不用来在候选之间做选择」**原样保留**：本臂不用子跨度回放做这道门，也不用它在候选之间选优。提名依据仍必须来自完整研究期验证。

## 首轮验证计划、两项登记与 trial 账

冻结门的试验数 M 是本臂验证过的非对照 revision（任何跨度、任何尝试）加上各批申报的 `offline_trials`，按这些试验日度评分序列的平均两两相关 ρ̄ 折成有效试验数 N_eff = ρ̄ + (1 − ρ̄)·M；DSR 的离散度只由研究期长度决定（四个研究年约 0.5），与本臂跑了哪些对照无关。公式与阈值以运行事实 `acceptance_rules.freeze_gate` 为准（本轮默认 `min_dsr_probability` 0.975），每行 `selection_statistics.information_ratio_bar` 就是此刻过门需要的主动 IR。

- **`control`**：`c_base` 在每一批里都写 `control: true`——照常花回放年、计入完整研究期验证数，但不是 trial，也永远不能提名；`m1`、`m_int`、它们的变体（含轴 e 的全冷启动，它可能成为继续的那一条）与第二个种子写 `control: false`。把候选登记成对照，它就失去提名资格；把 `c_base` 登记成候选，是白给自己加一个 trial。
- `offline_trials` = 本批申报前离线（研究期数据）筛过、读数影响了本批提交什么、但本批**没有**提交的候选配置数；提交进本批的候选在宿主验证时按 host trial 计，不重复申报；对照永不计；每个配置只在筛过之后的第一批申报一次；没有筛过任何候选配置才填 0。G-INC2（含轴 a / 轴 b 的重筛）里跑的 `c_base` 是对照。
- **第一次整期批次**：`c_base`（第一条腿）加上**过了 G-INC2 的候选，最多两条**，`offline_trials` = 没过门、没提交的形态数（两条都提交就是 0，只提交一条就是 1）。三条腿全上是 12 个回放年、2 个宿主 trial；只有一条候选过门是 8 年、1 个宿主 trial 加 1 个离线 trial；**两条都没过就不开整期**，按终止规则结束。
- 本臂**整期验证上限 6**（对照也算）：第一批最多 3 条，剩下的最多 3 条留给变体轴与第二个种子。到上限仍没有可提名候选即以 `no_edge` 结束，不为了凑一个交付去冻结。
- **trial 账与它要求的 IR**：只开第一批时 M = 2（`m1`、`m_int` 各一次：提交的按宿主、被否决的按离线），按上限排满约 4–5（再加被否决的重筛变体）。各腿共用 158 列与标签，日度主动序列高度相关，ρ̄ 在 0.7–0.9 时 N_eff 约 1.1–2.2。四个研究年、阈值 0.975 下，N_eff = 2 / 3 / 5 时过门要主动 IR 约 1.24 / 1.41 / 1.58，N_eff = 1 也要约 0.98（正态近似）；载体自己读 0.4642，W1 的先验是 ΔIR 0…0.1，这一差距事先写在这里。
- 冻结要求至少 2 次完整研究期验证（运行事实 `min_full_span_validations`）；按上面的上限，本臂最多能给一条候选配一次第二种子复测，**不要把这次机会花在一条第一批里没赢 `c_base` 的腿上**。

## 提名条件（冻结前逐条满足）

1. G-INC2 已通过，且 Δ、增益份额、逐年符号与（只作诊断的）ρ、验证段 L2 都写进结果笔记。
2. 完整研究期验证完成，冻结门按运行事实通过；**至少 2 次完整研究期验证**（运行事实 `min_full_span_validations`）；整期验证不超过 6。
3. **稳定性**：逐年分块的**主动**超额为正的研究年 ≥ 四分之三（四个研究年时 ≥ 3）。对一块描述行情的列，**某一年独大的增量按「日期效应」处理**，不算稳定。
4. **`c_base` 同批**，且候选在整窗与至少 3 个研究年上主动读数都不低于它。**这是本臂的核心条件**：赢不了不带这块的自己，就没有这条臂。
5. **两个种子**：至少两个种子的主动信息比率之差已汇报；比种子差还小的优势不是证据。
6. P2 / P3 / P4 / P5 / P6 全部成立。
7. **集中度与换手**：`pnl_concentration.top5_share_of_gross_gains` ≤ 0.5；年换手 ≤ 12 倍。
8. **实现底线**：`phase_seconds` 里单次 `fit` ≤ 1,800 秒；容器内存峰值**明显低于 16 GiB**；单次复核决策 < 60 秒；意图买单拒单率 ≤ 30 %；**座位填满率**与买不起份额逐次汇报。不成立先修实现再复测，不算证伪。
9. **持久化已被单独定价**：轴 e 的全冷启动消融已在同批或前一轮跑过，两者的主动读数差写进结果笔记。

主动超额 ≤ 0、空对照分位在 0.5 附近、去膨胀 Sharpe 概率接近 0 都是普通「没有边际」读数：候选不可提名，不触发家族关闭。

## 什么会杀死它（按命中即停）

1. **G-INC2 在两条候选、轴 a 与轴 b 各一轮之后仍然全部命中** —— 这块在这条载体上没有增量信息。本臂以 `no_edge` 结束。
2. 连续两轮完整研究期验证里没有一条候选赢得了同批的 `c_base` —— 以 `no_edge` 结束。
3. 主动超额为负的研究年连续两轮都过半 —— 关闭。
4. 每一个可行席数上 `excess_at_2x_slippage` 都 ≤ 0 —— 机制可能真实但在这个账户上不可交易，先走轴 d 的另一端一轮，仍不成立即以「不可交易」关闭。
5. **为了追读数把复核节奏改回周度，或让仓位、席位、现金随状态变** —— 这不是一个结果，是一次违规。前者是本轮登记的构造选择（10 日标签配月度复核的错配是已知且已写明的风险），后者是边界一节的已关家族；要改任何一个都必须先重写 `hypothesis` 并另开登记，不能顺手改一行常量。
6. P2 在所有已登记构造下都不成立 —— 关闭并写明是哪个行业带上去的。
7. 提名条件 8 修复一次后仍不成立 —— 该变体放弃，不算家族证伪。
8. **整期验证用到 6 个仍没有可提名候选** —— 以 `no_edge` 结束。

## 臂级终止规则

任一成立即本臂关闭：上面第 1、2、3、8 条命中；预算用尽前没有可提名候选。关闭以 `finish_session(outcome="no_edge")` 携读数结束本臂，**不换家族**，不把 `c_base` 改作候选，不把本块改写成择时开关。`no_edge` 是结论不是退路：只有在没有还有先验的变体轴可换、或预算已经花完时才用它，不要让预算耗尽（流水线记 `deadline`）代替这个结论，也不要为了有一个交付而冻结一个不满足条件的候选。
