# 研究会话探索计划

目标：在本臂唯一的研究会话里，判定**市场状态作为排序器的列**是否让那条已确认的载体分数在主动序列上变好；变好就把它做成一本站得住的书，没有就诚实地以 `no_edge` 结束。判据只在 `families.md`，数据与单位只在 `pit-field-map.md`，本文只排顺序与预算。

**本臂的命题有且只有一个**：`m1` 或 `m_int` 要赢同批的 `c_base`，而书的形状一点不动。三条腿用同一份代码、同一个标签、同一个股票池、同一组席位、节奏与仓位，只差特征矩阵的最后 12 列。所以**没有 `c_base` 的任何读数都不算数**；而一块描述行情的列，最容易读出来的是「某一年的行情」，不是增量——逐年读数比整窗读数更要紧。

## 第 0 轮：不占回放预算的普查与离线筛选

用 `shell` 在研究期末的决策视图上跑，不启动回放。任一条不合格就在第 1 轮的 `hypothesis` 里声明，不要硬凑。

1. **运行事实核对（最先做的一件事）**：`broker_replay.initial_cash`、**`benchmark_index`**、`acceptance_rules` 里有没有跟踪授权及其上限与区间、两个回撤上限、`budgets`（含 `strategy_fit_timeout_seconds`）与 `max_replay_years`。本包按 100 万元不带授权写成，50 席；不符就改登记，不要静默沿用。`benchmark_index` 与 `lib/index.py` 的 `INDEX_CODE` 不一致时**改常量去对齐运行事实**——本块的基准列跟着这个常量走。
2. **数据核对**：`index_weight`、`index_daily` 在不在；**`index_daily` 里这只基准最早一行是哪一天**；`universe` 带不带 `l1_name`。起点晚于 2020-01-02 时，先算它允许的最长窗口再动 `knobs.STATE_LONG`。
3. **块的密度普查（本轮特有，第一优先）**：逐研究年、在该年每一次季度重训的训练窗口上，报状态列在可用 bar 上**全部有限**的占比（应为 100 %，否则 `fit` 会报错），以及 `m_int` 的覆盖度（有个股因子窗口的成分占比）。参考读数：四个研究年首次 `fit` 上状态列 100 % 有限，`m_int` 覆盖均值 0.995–0.998、最低 0.987（`sources.md`）。**再逐年数一遍「状态越出该年首次 `fit` 训练窗口范围」的交易日占比**：起步包量到 Y1 27 %、Y2 7 %、Y3 7 %、Y4 43 %，Y4 集中在 2024 年 10–12 月与 2025 年 5–6 月（`sources.md`）。这就是那一年的读数最可能是外推或日期效应的地方，先记下来。
4. **账户算术表（直接对着 P3）**：用本臂的资金，在 30 / 50 / 80 席上算座位金额、买得起的成分占比、5 元最低佣金的 bp/边、一次往返总成本，以及在 `cost_stress_multiplier` 下 α 要付掉多少（公式在 `references/capital-arithmetic.md`）。
5. **换手实测（P3 的硬要求）**：**用 `smoke_backtest` 在研究期靠后的槽上跑一段跨过至少两次复核的窗口，读 `turnover` 与 `fees_paid`，扣掉首日建仓再年化**，写进结果笔记。`c_base` 与至少一条候选都要量：状态列可以让排序随行情整体换向，候选的换手不一定等于载体的。不得引用包里的估算。
6. **股票池普查，按研究年分别列**：在册成分只数、可交易只数、买得起的占比、申万一级行业个数、价格分布。
7. **零技能的形状读数**：本臂的池与席数上等额现金零技能能拿到什么（`references/zero-skill-panel.md`：100 万 / 50 席沪深 300 的零技能 IR 中位 0.602、标准差 0.37）。**地板在哪里要先知道。**
8. **`fit` 成本探针**：在研究期靠后的槽上跑 `smoke_backtest(days=2)`，读 `resources.fit_seconds` 与 `peak_memory_bytes`，确认离 16 GiB 有明确余量（`references/fit-cost.md`）。**`smoke_backtest` 不花回放年，也不计 trial。****同一个 `start` 复用给后面所有靠后窗口的探针**：`window_build_seconds` 是一次性的，付一次，后面同一个 `start` 的探针直接复用，永远不要乘以天数。

## 第 0.5 轮：增量信息门 G-INC2（`families.md` 的硬门，**0 回放年**；筛过而没提交的候选配置在下一批的 `offline_trials` 里申报）

判据在 `families.md`，这里只排步骤。全部在 `shell` 里做，**不发起任何回放**。

1. 在研究期**后两年**里取**至少 60 个分散的决策日**（每两周一天，或等间隔取满 60）。
2. 每一天用起步包同一份代码、同一个成分截面，分别按 `c_base`、`m1`、`m_int` 的列集训练并打分，各取前 `SEATS` 只等额，持有到下一个信号日。离线重建每一天都要取**那一天的 as-of 视图**，不得拿期末的 `snapshot` 去重建（`pit-field-map.md` 的单一时点一节）。
3. 同一批日子上各抽一个 **k = 20 的离线零技能面板**（在同一成分身份侧、且这笔钱买得起一手的名字里换名，取 20 份的等权均值）；每条候选与 `c_base` 的主动超额之差得各自的 **Δ**。
4. 从同一批 `fit` 出来的 booster 上读 **`block_gain_share`**（12 列的 `gain` 之和 ÷ 全部列的 `gain` 之和；起步包每张买单都带着它），以及每次 `fit` 的**验证段 L2**（`state_dir/refit_meta.npy` 的第三个数）。
5. 判定（每条候选各自判）：**Δ ≤ 0，或增益份额 < 5 %，⇒ 这条候选不进整期。** Δ > 0 但不超过种子差也按没有增量算。
6. 逐年分开看一遍 Δ 的符号：**只有一年为正的 Δ 不是增量**。对本块这一条尤其要紧——把第 0 轮第 3 步记下的「分布异常年」与 Δ 的逐年符号放在一起读。
7. **ρ 与验证段 L2 照常算、照常报，但不判**。增益份额对本块几乎必然过门（起步包实测 `m1` 0.32、`m_int` 0.24），所以本门实际由 Δ 与逐年符号决定。

**这一步不产生提名依据。** 离线面板比宿主面板宽松且偏低，而且离线的 Δ **幅度**已经被证明不可信（同一条检查里秩相关逐位复现，Δ 从 +5.54 pp/年 翻成 −0.63 pp/年）。门只用来**否决**，裁决是宿主的整期批次。

## 第 1 轮：一次完整研究期 `batch_validate`，`c_base` 是第一条腿

腿：**`c_base`（第一条）** 加上**过了 G-INC2 的候选，最多两条**。三条腿一次完整研究期验证在四个研究年时花 12 个回放年，两条腿 8 年。登记：`c_base` 写 `control: true`，候选写 `control: false`；`offline_trials` 申报 G-INC2 筛过而本批没有提交的形态数（两条都提交就是 0，只提交一条就是 1），`m1`、`m_int` 因此各恰好计一个 trial。**两条候选都没过门就不开这一批**。本臂整期验证上限 6（`families.md`）。

`hypothesis` 必须写清：逐行引用 `families.md` 的载体表与块表、**边界一节的原文**、经济解释与**证伪条件**、席数与复核节奏、保留带与换名上限、预期的主动信息比率与逐年符号（W1 的先验是 ΔIR 0…0.1，写进去，不要写一个更好看的数）、G-INC2 的三个量、以及 P2 / P3 / P5 / P6 的判定规则。

**不要再加零技能对照腿**——宿主每次正式验证都会抽面板。回放一旦开跑就计入预算，策略自身抛错的候选照样花掉，环境失败的候选退还。某一路因环境原因失败时不重跑、不压缩对照：把读数与待裁决的分支写进结果笔记。

第 1 轮之后，对领先的完整研究期节点跑一次 `run_null_control`：不花回放年，会话时钟在它运行期间暂停。**它是诊断不是判据**；三个数一起报。

## 判定分支，逐条写死（判据本身见 `families.md`）

- **候选与 `c_base` 读数几乎一样** → 状态被 158 列吸收了，或树没学到可迁移的条件。先看验证段 L2：候选不比 `c_base` 更准，说明高增益份额来自按日期圈样本，走轴 c（粗化）或换到 `m_int`；更准而书不动，说明条件模式存在但落不到前 50 名，走轴 a（窗口）。
- **候选明显差于 `c_base`** → 先看是哪一年、那一年的状态是否落在训练窗口没见过的区间（第 0 轮第 3 步）。是，就是外推失败，这正是这块列最可能的失败方式，如实写；不是，走轴 b 把列集砍掉一组。
- **`m1` 赢而 `m_int` 不赢** → 树自己找到的交互比预设的 3 × 4 更好；**但也是最需要怀疑按日期圈样本的形态**，提名前必须有两个种子与逐年读数。
- **`m_int` 赢而 `m1` 不赢** → 增量来自那几个预设的交互，这是可以说清机制的结果；把 12 列逐列的增益份额写进结果笔记。
- **只有一年赢** → 按日期效应处理，不作增量（提名条件 3）。**xs_transformer 那条 +2.42 pp/年 正是 +10.8 / +8.9 / −9.3 / +0.9 这种形态**，本臂要比它更稳才算把那条读数坐实。
- **绝对超额高而主动超额低** → 赢的是股票池不是选名。看 `benchmark.panel_neutralized_excess`。**这正是这条载体的校准臂当年掉进去的那个坑。**
- **复核日或书的只数与 `c_base` 不齐，或平均总仓位出现按状态分段的差异（P6 不成立）** → 状态漏进了构造，读数作废，先修实现。
- **换手或成本越线** → 先按 `references/capital-arithmetic.md` 重算，再走轴 d 的席位或换名上限。**不得把复核节奏改回周度，也不得按状态降仓**（`families.md` 杀死条件第 5 条）。
- **持久化腿（轴 e）输给全冷启动** → 续训在本臂被证伪。按更好的那个继续，并写进结果笔记。
- **P2 不成立** → 先看是哪个行业带上去的，再走轴 d 收紧席位分布。
- **实现读数不对**（座位没填满、买不起份额偏高、拒单率高、`fit` 逼近上限）→ 先修实现再复测，按提名条件 8。

## 第 2 轮起：一次只改一个可分离组件

按 `families.md` 的变体轴取，每轮一个，与当轮基准同批比较，整期验证合计不超过 6；每批照 `families.md` 登记 `control` 与 `offline_trials`（重筛后没有提交的轴 a / 轴 b 变体按个数申报）。一条轴在两轮里都没有满足条件的候选就关闭它。子跨度验证只用来复测实现与耗时，不用来在候选之间做选择——G-INC2 不用回放，这条规则因此原样保留。

## 收官轮

只做两件事之一：对已经满足全部提名条件的最好候选补齐缺的读数并冻结；或者以 `finish_session(outcome="no_edge")` 携读数结束本臂。**收官轮只在没有轴可换、整期验证用到上限、或预算见底时才开始**。

## 计算预算

- **容器**：8 核 / 16 GiB（`--memory-swap` 同值，超了直接 OOM），`gpu_count = 0`；单次 `fit` 上限 3,600 秒（运行事实 `budgets.strategy_fit_timeout_seconds`，按批宽度放大）。
- **`fit`**：起步包在沙箱镜像与真实宿主流水线上都实测过（口径与读数见 `sources.md`），离两条上限都有两个数量级的余量；本块不读数据，比载体单独只多约一到两成秒数。
- **推断**：非复核日在确认最新可见交易日之后直接返回 `[]`；月度复核每年只有 12 个真正建书的决策日。
- **余量怎么花**：轴 a（窗口）与轴 b（列集）在预算上都是自由的。**但每一个验证过的候选与每一个离线筛掉的候选配置都是一个 trial，都会抬高本臂自己的去膨胀 Sharpe 门**，而本臂还有 6 个整期验证的硬上限，所以便宜不是理由。
- **单日探针的秒数对宿主负载极敏感**（同一条腿轻载与重载可以差三四倍），耗时结论按多日回放的**平均**读。
- **回放年**：G-INC2 与 `smoke_backtest` 都是 0 年（G-INC2 筛过而没提交的候选配置按 `offline_trials` 计 trial，`smoke_backtest` 不计）；每次整期两腿批次 8 年、三腿 12 年，候选各计 1 个 trial、`c_base` 不计。以运行事实 `budgets.max_replay_years` 为准。**宿主 trial 只花在整期上。**

## 每个候选必须汇报的读数

除标准结果块外，写进结果笔记：逐行对照 `families.md` 的载体表与块表；经济解释与证伪条件；**主动中性化超额、主动跟踪误差、主动信息比率**与**面板自己的中性化超额**；逐年分块的主动超额与原始超额；`top_industry_weight`、`size_tilt` 与 `size_beta` 并排；**`c_base` 的同跨度读数与逐年差**；**块的覆盖度与增益份额，逐研究年分开**，以及逐列的增益份额（12 列里是哪几列在拿增益）；验证段 L2 与 `c_base` 的差；两个种子的主动信息比率之差；**实测换手、年完成回合数、按本臂 `initial_cash` 重算的佣金账与 2 倍滑点下的超额**；**P6 的对齐读数**（复核日、书的只数、平均总仓位，与 `c_base` 并排）；拒单率与原因；`pnl_concentration`；空对照的三个数；一次决策的实测平均墙钟；`fit` 秒数与容器内存峰值；以及**这次回放里冷启动与续训各发生了几次**。**账户面四项**也要报：每次复核的买不起份额与整期均值、座位有没有填满（没填满时如实报缺几个与原因）、实际权重对目标权重的偏离、书覆盖的指数权重。缺任何一项的结果不作为提名依据。

## Validation 否证（任何一条命中，结果无效，不讨论收益）

- 股票池不是按时点读出来的：硬编码名单、用别的指数建书而仍按 `benchmark_index` 报跟踪误差、或用最新一张截面去标注历史训练日。
- 用 `trade_date` 而不是 `available_at` 判可见；`weight` 当成小数没有 ÷ 100。
- 成分的 `con_code` 没有改名就去 join，得到一张空表却按「池太小」处理。
- **状态列用了含未来日期的窗口**：整段研究期的均值、分位、阈值，或任何「先看全窗再定切点」的粗化。
- **状态列被做成了截面 z 分数**（整列归零），或交互列被做了截面 z 分数（只剩符号）。
- **任何一条腿的仓位、席位、复核日或现金随状态变化**——那不是本臂的腿，是登记 §2 的已关家族。
- **训练矩阵与决策矩阵的列顺序不是同一处定义的**，或 `c_base` 与候选的差不止那 12 列（改了参数、种子、轮数、切分、标签、池或重训节奏之一）。
- 截面 z 分数不是只在当天的成分集合上做的。
- 标签用了整段研究期算出来的 β，或标签横跨决策时刻（信号日 t 的标签要求 t+11 ≤ T-1）。
- as-of 域读失败后回退了 `snapshot_dir`；读多数据集的域时没有先按 `dataset` 过滤；任何读取不带日期窗口。
- 买不起的**持仓**被当成离池强卖；或者买单向下取整而不是按最近整手四舍五入。
- 复核节奏依赖模块级计数器或跨调用缓存；或者为了追读数把复核节奏改回周度而没有重写 `hypothesis`。
- 把训练好的 booster 放进 `models/`，或让 `state_dir` 里的东西跨回放存活。
- 没有第 0 轮的密度普查、账户算术表与换手实测就开了整期回放；跳过 G-INC2 直接开整期；或者把 G-INC2 做成一次子跨度回放（那白花回放年、给不出资格，还照样计 trial）。
- `c_base` 登记成 `control: false`（白加 trial），候选登记成 `control: true`（失去提名资格），或 `offline_trials` 少报了筛过而没提交的候选配置、又或把本批提交的候选重复申报。
- 没有同批的 `c_base` 就拿候选的读数去论证增量。
- 用绝对中性化超额或绝对信息比率去论证边际，而不看主动读数与面板。

## 收尾

冻结的是提名节点自己的不可变快照，提名前不必把它恢复到 `output/`。不要提交离线普查脚本；`models/` 只放静态资产。
