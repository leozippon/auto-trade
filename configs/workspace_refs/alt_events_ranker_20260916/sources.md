## 1. 本包自己实测的数据事实

以下全部由本地原始湖（`data/raw/`）实测，PIT 约束为**只读取日期 ≤ 2025-12-31 的行**。原始湖的 `daily.amount` 是**千元**，快照里的 `daily.amount` 已归一为**元**——离线普查用错这一点会把整个可选池筛成空集。

### 可见边界（`contracts.event_dataset_visible_cutoff` 实测）

2025-03-05（周三）08:30 与 2025-03-03（周一）08:30 的九张表可见截止逐表列在 `pit-field-map.md`。关键结论两条：`stk_holdertrade`（19:00 盖章）是 T-1，而 `stk_holdernumber` 与 `top10_floatholders`（23:59:59 盖章）赶不上 23:05 的 `cn_nightly_disclosure_full` 节点，**是 T-2**；披露节点走自然日（周一早上截止是周日 23:05，周末公告已可见），晚间节点走交易日（周一早上截止是上周五 23:35）。这修正了 `logs/notes/review_20260909/D1_directions_from_data_20260916.md` 表里把这三张表并列写成 T-1 的粗读法。

### `share_float_complete`（`float_date` 2021-10..2025-12，6,204,580 行）

`available_at_rule` 99.99% 是 `conservative_date_eod`，553 行是 `fallback_conservative_from:float_date`；`available_at` 全部落在 23 时。`float_date − ann_date` 的 p05 = 7 天、中位 **189 天**、p95 = 198 天，零行的 `float_date` 早于 `ann_date` → 解禁日历在公告时就完全可见，前瞻特征 PIT 合法。`share_type` 以 `首发股`（6,077,552 行）为主，其后是 `首发原始股`、`定增股份`、`首发战略配售股份`。

**聚合规则的实测推导**（本包最重要的一条新事实）：这张表是逐持有人的行，同一次解禁被多个 `ann_date` 反复重述——1,588 个 `(ts_code, float_date)` 只有一个版本，260 组有两个、120 组三个、31 组四个、6 组五个。按 `(ts_code, float_date)` 直接对 `float_ratio` 求和得到中位 13.4%、p75 50.3%、**最大 371%**（不可能）；只在版本内求和（先 `drop_duplicates()`，再对每个 `(ts_code, float_date)` 取可见的最大 `ann_date`）得到 2022–2025 共 11,689 个事件，比例中位 **7.84%**、p25 1.50%、p75 24.63%、p95 66.59%、p99 76.87%，最大仍有 193.92%（不同公告版的持有人清单只部分重叠的残余噪声）→ **截到 100 并汇报被截比例**。抽样验证：`603285.SH` 2025-01-06 的 `首发股` 版有 6,635 个不同持有人、119 个不同 `float_share`、逐行 `float_ratio` 均为 0.0001% 级、版本内合计 0.58%——逐持有人求和是正确的，跨版本求和不是。逐年事件数 3,071 / 3,420 / 3,190 / 2,008，覆盖股票数 1,886 / 1,892 / 1,818 / 1,261。

## 4. 运行教训（只指路，不复述）

- `experiments/explore_github_strategies_20260910/artifacts/skills/` 的 `fit-state-pitfalls`：booster 跨容器持久化的正确形态（`model_to_string()` + `np.save`，加载处自检），`lgb.Booster(path)` 位置传参在 LightGBM 4.7 会把路径当 `params` 并抛出与「文件缺失」逐字相同的 `TypeError`，以及静默退化的指纹诊断——某候选整窗指标与无模型对照**逐位相同**（`vs_parent` 全零）就是决策期每次退化，不是巧合。同一 skill 还记着 macro 域跨 dataset 的 `ts_code` 歧义：读 `events`/`macro` 必须 pin `dataset` 并把它列进 `columns`，本包的八张表共用一个 `events` 域，这条直接适用。
- 同目录的 `panel-semantics-parity`：「最新可见」有跨数据集 union 与分数据集各自最新两种不等价读法，预登记文本必须显式固定一种，且候选代码与本地核对面板**共用同一个构造函数**。本包八个族分属八个数据集，是这条教训的最大适用面：本包声明的语义是**分数据集各自最新可见**。
- 这两条与其他跨实验经验都在工作区 `memory/<来源>/` 下只读挂载，索引见 `inputs/skills_index.json`。

## 5. 前几轮已被证伪、本包不再单独重测的方向

下列结论来自 `logs/notes/review_20260909/` 的 T1–T7 与 D1/D2。本包允许它们**作为特征集里的一列**出现，但不得作为独立候选或独立机制主张重开：

| 方向 | 状态 |
|---|---|
| 筹码获利盘（`cyq_perf.winner_rate`）单因子 | 动量/波动换皮：控制后 t = −1.66（H=5）/ −1.46（H=20），2025 年 H=20 符号翻转 |
| 股东人数集中度单因子 | 只控规模那一步就是空的（IC +0.008、t +1.03） |
| 单因子解禁事件族 | `explore_platform` 已关闭 |
| 两融余额变化单因子 | 空头腿携带信号，本环境不可表达；可交易的多头腿控制后 t = +0.76 |
| 大宗折价单因子 | H=20 控制后 IC +0.016（t +2.17），但多头腿只有 +0.15%/20d，低于本账户的成本线 |
