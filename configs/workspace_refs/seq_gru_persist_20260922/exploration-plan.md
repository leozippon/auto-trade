# 研究会话探索计划

目标：在本臂唯一的研究会话里，判定**在沪深 300 成分内、带残差标签、持久化热启动的序列排序器**在主动序列上是否有可辨识的技能；有就把它做成一本站得住的书，没有就诚实地以 `no_edge` 结束。判据只在 `families.md`，数据与单位只在 `pit-field-map.md`，本文只排顺序与预算。

**本臂最大的风险不是门太严，是把整期预算花在一个「树模型的弱化版本」上。** 上一条 GRU 臂正是这样死的：方向研究在开跑之前就量出它输给同门的 LightGBM、两者日度秩相关 0.74，臂仍然跑完了整期。所以本轮把那次判断前移成 `families.md` 的**增量信息门 G-INC**，它在第 1 轮之前、**全离线，0 个回放年、0 个 trial**。

## 第 0 轮：不占回放预算的普查与离线筛选

用 `shell` 在研究期末的决策视图上跑，不启动回放。任一条不合格就在第 1 轮的 `hypothesis` 里声明，不要硬凑。

1. **运行事实核对（最先做的一件事）**：`broker_replay.initial_cash`、`acceptance_rules` 里有没有跟踪授权及其上限与区间、两个回撤上限、`budgets`（含 `strategy_fit_timeout_seconds`）与 `max_replay_years`、`gpu_count`。本包按 100 万元不带授权写成；不符就改登记，不要静默沿用起步包的 30 席。
2. **数据核对**：`index_weight`、`index_daily`、`margin_detail` 在不在，`universe` 带不带 `l1_name`。逐列覆盖率按 `pit-field-map.md` 的表自己重量一遍——包里的数字是在某一个决策视图上测的，不是承诺。
3. **账户算术表**：用本臂的资金，在 20 / 30 / 40 席上算座位金额、买得起的成分占比、佣金地板 bp/边、一次往返成本、按预期换手算的年成本，以及在 `cost_stress_multiplier` 下 α 要付掉多少（公式在 `references/capital-arithmetic.md`）。
4. **股票池普查，按研究年分别列**：在册成分只数、可交易只数、剔掉科创板与 ST 之后剩多少、申万一级行业个数、最薄成分的 20 日均成交额、价格分布，以及**序列完整（窗口内 ≥ 60 根 K 线）的只数**。
5. **零技能的形状读数**：本臂的池与席数上，等额现金零技能能拿到什么（`references/zero-skill-panel.md` 给了几种已量过的形状；30 席沪深 300 的面板读 +8.57 %/年）。**地板在哪里要先知道，否则第一批的读数没法解释。**
6. **`fit` 成本探针**：在研究期靠后的槽上跑 `smoke_backtest(days=2)`，读 `resources.fit_seconds`、`peak_memory_bytes` 与卡上显存峰值，确认离 16 GiB 与 12 GiB 都有明确余量（`references/fit-cost.md`）。**`smoke_backtest` 不花回放年，也不计 trial。****同一个 `start` 复用给后面所有靠后窗口的探针**：`window_build_seconds` 是一次性的，重开一次 `start` 是白花时间。

## 第 0.5 轮：增量信息门 G-INC（`families.md` 的硬门，**0 回放年、0 trial**）

判据在 `families.md`，这里只排步骤。全部在 `shell` 里做，**不发起任何回放**——每一次完成的验证不分跨度都会把 `trials` 加一，而去膨胀 Sharpe 是本仓库多数臂真正卡住的那堵墙。

1. 在研究期后两年里取**至少 60 个分散的决策日**（每两周一天，或等间隔取满 60）。
2. 每一天用起步包同一份代码在**同一成分截面**上打出 `g1` 与 `c_lgbm` 的分数，算 Spearman 秩相关；取中位数得 **ρ**。
3. 同一批日子上，把两条分数各做成同一形状的前向持有（30 席、等额现金、与复核节奏同长），并各抽一个 **k = 20 的离线零技能面板**（在同一成分身份侧、且这笔钱买得起一手的名字里换名，取 20 份的等权均值）；两者的主动超额之差得 **Δ**。
4. 判定：**ρ > 0.7 且 Δ ≤ 0 ⇒ 不进整期**。Δ > 0 但不超过种子差也按没有增量算。唯一允许的去处是 `g1r`，它也先过同一道门；仍不成立就以 `no_edge` 结束本臂。
5. 逐年分开看一遍 ρ 与 Δ：只有一年成立的增量不是增量。

**这一步不产生提名依据**，离线面板比宿主面板宽松且偏低，所以它**只用来否决**。它也不用来在候选之间选优。

## 第 1 轮：一次完整研究期 `batch_validate`

主候选是通过第 0.5 轮的那一条（`g1` 或 `g1r`），同批必须有 `c_lgbm`。第三条腿按第 0.5 轮的结果选：通常是**差异 4 的消融**（全冷启动的同一份代码），因为热启动是本臂五条差异里唯一一条既没有先例、也没有任何本仓库读数的。一次三候选完整研究期验证在四个研究年时花 12 个回放年。

`hypothesis` 必须写清：逐行引用 `families.md` 的差异表、经济解释与**证伪条件**、席数、复核节奏、保留带与换名上限、预期的主动信息比率与逐年符号、以及 P2 / P3 的判定规则。

**不要再加零技能对照腿**——宿主每次正式验证都会抽面板，主动读数直接出现在结果行里。回放一旦开跑就计入预算，策略自身抛错的候选照样花掉，环境失败的候选退还。某一路因环境原因失败时不重跑、不压缩对照：把读数与待裁决的分支写进结果笔记。

第 1 轮之后，对领先的完整研究期节点跑一次 `run_null_control`：不花回放年，会话时钟在它运行期间暂停。**它是诊断不是判据**——它比的是原始超额、按流通市值分位配替身，和裁决用的那个面板不是一回事；三个数一起报。

## 判定分支，逐条写死（判据本身见 `families.md`）

- **主动信息比率远低于预登记的目标** → 先看它是不是只是 `c_lgbm` 的影子（第 0.5 轮的 ρ 已经答过一半）；是就按门关闭，不是就走轴 c（标签）或轴 a（通道）。
- **绝对超额高而主动超额低** → 赢的是股票池不是选名。看 `benchmark.panel_neutralized_excess`。改池或改权重方案不会解决它。
- **逐年主动超额有负年** → 先看是哪一年、是不是那一年的行情，再决定走哪一轴。两轮都有多数负年即关闭。
- **热启动腿输给全冷启动腿** → 差异 4 被证伪。按更好的那个继续，并把它写进结果笔记；**不要把它藏起来**。
- **通道消融（轴 a）显示去掉六条新通道读数不变** → 差异 3 被证伪，本臂只剩差异 1 / 2 / 4；如果此时增量信息门也贴着线，按门关闭。
- **两条两融通道单独解释了大部分增量** → 这不是发现，是重开一条已关闭家族。按 `families.md` 的禁止条关闭这一支，不得把它做成独立分数。
- **P2（行业集中度）不成立** → 先看是哪个行业、哪条腿把它带上去的，再走轴 e（席数）。
- **P3（成本）不成立** → 在 100 万元账户上这几乎不可能；真出现先查换手与拒单率，多半是实现问题。
- **实现读数不对**（座位没填满、实际权重离目标太远、拒单率高、`fit` 逼近上限）→ 先修实现再复测，按提名条件 7。

## 第 2 轮起：一次只改一个可分离组件

按 `families.md` 的变体轴取，每轮一个，与当轮基准同批比较。一条轴在两轮里都没有满足条件的候选就关闭它。子跨度验证只用来复测实现与耗时，不用来在候选之间做选择——G-INC 不用回放，这条规则因此原样保留。

## 收官轮

只做两件事之一：对已经满足全部提名条件的最好候选补齐缺的读数并冻结；或者以 `finish_session(outcome="no_edge")` 携读数结束本臂。**收官轮只在没有轴可换、或预算见底时才开始**；预算见底时不开新轴，也不要让预算耗尽代替这个结论。

## 计算预算

- **`fit`**：起步包在研究期靠后的决策视图上实测——GRU 三种子冷启动 **59.0 秒**、热启动 **53.0 秒**，`c_lgbm` 冷 **8.1 秒**、热 **7.5 秒**，`g1r`（两者都训）冷 **56.4 秒**、热 **50.8 秒**；卡上峰值 **0.65 GiB**，容器峰值 **1.7–2.5 GiB**（口径与限制见 `sources.md`）。上限是 3,600 秒、16 GiB、12 GiB 显存，**都有一到两个数量级的余量**，所以轴 b（序列长度）与轴 d（热启动强度）在预算上是自由的；真正的限制是提名条件 7 的 1,800 秒，以及三路并发时同一张卡上的争用。
- **推断**：单次复核实测 **0.4–0.7 秒**，上限 360 秒。非复核日在确认最新可见交易日之后直接返回 `[]`。
- **单日探针的秒数对宿主负载极敏感**（同一条腿轻载与重载可以差三四倍），耗时结论按多日回放的**平均**读。
- **回放年**：G-INC 与 `smoke_backtest` 都是 0 年、0 trial；每次整期三候选批次 12 年、3 个 trial。以运行事实 `budgets.max_replay_years` 为准。**trial 只能花在整期上。**

## 每个候选必须汇报的读数

除标准结果块外，写进结果笔记：逐行对照 `families.md` 的差异表；经济解释与证伪条件；**主动中性化超额、主动跟踪误差、主动信息比率**与**面板自己的中性化超额**；逐年分块的主动超额与原始超额；`top_industry_weight`、`size_tilt` 与 `size_beta` 并排；`c_lgbm` 的同跨度读数与逐年差；**与 `c_lgbm` 的分数秩相关**；两个种子的主动信息比率之差；换手、年完成回合数、按本臂 `initial_cash` 重算的佣金账与 2 倍滑点下的超额；拒单率与原因；平均总仓位；`pnl_concentration`；空对照的三个数；一次决策的实测平均墙钟；**`fit` 秒数、容器内存峰值与显存峰值**；以及**这次回放里冷启动与热启动各发生了几次**。缺任何一项的结果不作为提名依据。

## Validation 否证（任何一条命中，结果无效，不讨论收益）

- 股票池不是按时点读出来的：硬编码名单、用别的指数建书而仍按沪深 300 报跟踪误差、或用最新一张截面去标注历史训练日。
- 用 `ann_date`/`trade_date` 而不是 `available_at` 判可见；把成分截面的日期当作调整生效日；`weight` 当成小数没有 ÷ 100；两融按交易日当天可见。
- 成分的 `con_code` 没有改名就去 join，得到一张空表却按「池太小」处理。
- 标签用了整段研究期算出来的 β，或标签横跨决策时刻（信号日 t 的标签要求 t+11 ≤ T-1）。
- 训练面板与决策截面不是同一个函数构建的，或两条路径的归一化不同。
- as-of 域读失败后回退了 `snapshot_dir`；读多数据集的域时没有先按 `dataset` 过滤；任何读取不带日期窗口。
- 复核节奏依赖模块级计数器或跨调用缓存。
- 把训练好的权重放进 `models/` 以绕过重训，或让 `state_dir` 里的东西跨回放存活。
- 没有第 0 轮的账户算术表与 `fit` 成本探针就开了整期回放；跳过 G-INC 直接开整期；或者把 G-INC 做成一次子跨度回放（那会白花一个 trial 去抬高自己的冻结门）。
- 用绝对中性化超额或绝对信息比率去论证边际，而不看主动读数与面板。
- 把任何一条输入通道抽出来做成独立分数或筛子。

## 收尾

冻结的是提名节点自己的不可变快照，提名前不必把它恢复到 `output/`。不要提交离线普查脚本；`models/` 只放静态资产。
