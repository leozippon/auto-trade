# 候选、与上一条 GRU 臂的差异、增量信息门、变体轴与关闭规则

本文是本臂候选定义、包级要求、变体清单与关闭判据的**唯一权威表述**；`README.md` 与 `exploration-plan.md` 只指向本文，不复述。可见时点、单位与陷阱只写在 `pit-field-map.md`；算术与口径写在 `references/`，读数出处写在 `sources.md`。

本包有**一个主候选** `g1`、**一个必跑对照** `c_lgbm` 和**一个登记变体** `g1r`。三者在 `main.py` 里只差候选常量一行。

## 主候选：持久化序列排序器（`g1`）

| 组件 | 起步定义（`starter/`） |
|---|---|
| 股票池 | **决策日可见的沪深 300 成分**（`macro.index_weight` 最新一张不晚于决策日的截面），剔科创板与北交所、名称含 ST/退、T-1 无日线、窗口内不足 60 根 K 线。训练与打分用**同一条**规则，训练日按**那一天在册的成分**判定 |
| 输入 | 每个名字最近 60 个交易日的 **14 维**序列：复权开高低收与成交均价（各除以窗口末日复权收盘后取对数）、拆分一致成交量（除窗口均值后 `log1p`）、换手率与自由流通换手率（百分数 `log1p`）、量比（`log1p`）、当日最高价触涨停标记、最低价触跌停标记、融资余额 / 流通市值、（融资买入 − 融资偿还）/ 流通市值、有无日线标记。每个（滞后, 通道）在当日截面上 z 标准化并截断在 ±3 |
| 标签 | 信号日 t 的 **10 日残差收益**：`O[t+11]/O[t+1] − 1` 减去该名字滚动 120 日、向 1 收缩 0.7、截断在 [0.3, 2.0] 的 β 乘以同两个开盘之间的沪深 300 收益；再在**当日成分截面**上取秩 `(rank−1)/n − 0.5`。行业去均值是登记开关，默认关 |
| 模型 | GRU(14 → 64) → LayerNorm → 线性输出一个分数 |
| 训练 | 每季度首个决策日在 `fit` 内重训；训练日 = 最近 3 年里标签在 T-1 已实现的信号日；验证 = 其中最后 60 日，训练段在验证起点前至少 10 日结束；一日一个批次，损失 = −Pearson(分数, 标签秩)，Adam |
| **持久化与热启动** | 每个种子的权重写进 `context.state_dir`。一次回放的第 1 次 `fit` 冷启动（40 轮、1e-3）；此后每次**读回上一次的权重接着训**（10 轮、3e-4），并以「载入权重在新窗口上的验证 IC」为早停起点——**新窗口上训不过旧权重时保留旧权重**；每第 4 次重训冷启动一次。对照按**同样的节拍**冷热切换 |
| 集成 | 三个固定种子（1000、1001、1002）各训一个模型，复核时对三者的截面秩取平均 |
| 篮子 | 每个 ISO 周的首个决策日复核（空仓时任何决策日都复核）；**30 席等额现金**；离开最新成分截面、丢分数或丢 K 线的持仓无条件卖出；名次落到 60 名之外才可被替换；每次复核最多换 4 只（被迫卖出先算）；卖出 09:30、买入 15:00，按 T-1 收盘**四舍五入到最近整手**再按现金截断 |
| 设备 | CUDA；没有 CUDA 即报错，不写 CPU 路径 |

## 与 `gru_ranker_20260921` 的逐条差异（本臂存在的全部理由）

上一条臂按现在的面板口径重算，主动信息比率 **−2.44**。**只有下表这五行是新的**；第一轮的 `hypothesis` 必须逐行说明本臂在哪一行上与它不同、为什么这一行能解释它的失败。任何一行被拿掉，本臂就退化成一次重开，按臂级终止规则关闭。

| # | 上一条臂 | 本臂 | 为什么这一处重要 |
|---|---|---|---|
| 1 **股票池** | 全市场、1 元 < 收盘 ≤ 30 元、ADV ≥ 3,000 万元，2,400–3,500 只，15 席 | 决策日在册的沪深 300 成分，约 280–300 只，30 席 | 那个池子的零技能面板在同一段研究期读 **−4.67 %/年**，而沪深 300 成分 30 席读 **+8.57 %/年**：旧臂的绝对读数里有一大块是股票池的方向，而它在前推窗里变号。更要紧的是 X1 教训 4：一个没有筛过的池子曾把 67 % 的持仓送进北交所微盘股 |
| 2 **标签** | 原始 10 日开盘到开盘收益的截面秩 | 同一收益**减去自身 β × 基准同期收益**后的截面秩，可选行业去均值 | 旧臂在研究期里学到的是一条持续的小盘/高 β 倾斜（规模载荷 0.37–0.80），前推窗的规模反转直接把它打穿。残差标签不保证有 alpha，但它保证模型**不会因为买 β 而得分** |
| 3 **输入** | 8 条纯价量通道 | 14 条：加自由流通换手、量比、触涨停 / 触跌停、融资余额与融资净买入 | 旧臂与同门 LightGBM 的日度秩相关 **0.74**，两者是同一份价量信息的强弱两版。新增的六条是**交易约束与杠杆资金**的痕迹，树模型的 5–60 日算子里没有它们；它们是否真的带来正交信息，正是 G-INC 要判的 |
| 4 **持久化** | 每季度冷启动重训，`models/` 全空 | 权重写 `state_dir`，季度重训热启动，每四次冷启一次 | 本仓库**每一次 fit 都是冷启动**。冷重训等于每季度用三年数据重新发现一遍同一件事，把学到的东西扔掉；热启动让模型跨季度累积，并且在新窗口训不过旧权重时保留旧权重 |
| 5 **门** | LightGBM 对照只汇报、不设门；方向研究已量出它领先，臂仍按运营者决定开跑 | **G-INC 是硬门，且在整期批次之前**（下一节） | 旧臂最贵的一课不是模型选错，是**明知道它是对照的弱化版本还是花了整期预算**。本轮把那次判断前移成一道**不花回放年、也不计 trial** 就能失败的门 |

## 增量信息门 G-INC（整期批次之前必须通过，**全离线，0 回放年、0 trial**）

**登记的判据，一次写死：ρ(`g1`, `c_lgbm`) > 0.7 且 Δ 主动超额 ≤ 0 ⇒ 这个形态不进整期验证。**

这道门**完全在 `shell` 里做，不发起任何回放**。理由是可计量的：每一次完成的验证——**不分跨度**——都会把本臂的 `trials` 加一，而去膨胀 Sharpe 概率正是本仓库多数臂真正卡住的那堵墙。用 3 个回放年和 3 个 trial 去买一个「够不够格」的判断，等于先给自己抬高冻结门再去撞它。

| 量 | 怎么算 |
|---|---|
| **ρ** | 在**至少 60 个分散的决策日**上（研究期后两年里每两周取一天，或等间隔取满 60 天），用同一份起步包代码在**同一成分截面**上分别打出 `g1` 与 `c_lgbm` 的分数，逐日算 Spearman 秩相关，取**中位数** |
| **Δ 主动超额** | 同一批决策日、同一形状（同池、30 席、等额现金、同复核节奏）下，`g1` 的主动超额减 `c_lgbm` 的主动超额。**主动** = 候选的前向收益减一个 **k = 20 的离线零技能面板**：每一份副本在**同一成分身份侧**（在册 / 不在册与候选一致）且这笔钱买得起一手的名字里随机换名，取 20 份日收益的等权均值 |
| **Δ 的判定** | Δ ≤ 0 即「没有增量」。Δ > 0 但**不超过两个种子之间的差**也按没有增量算（`references/fit-cost.md`：本家族三个种子之间曾散开 4 pp/年） |

离线面板与宿主面板不是一回事：宿主走完整 Broker 重放、按候选自己的成交骨架换名，离线口径**系统性偏低且更宽松**（`sources.md` 的口径差）。所以 G-INC 只用来**否决**，永远不用来论证边际——它说「不够格」时可信，说「够格」时只意味着可以花那 12 个回放年。

**`fit` 成本单独量，也不花回放年**：`smoke_backtest(start=研究期靠后的槽, days=2)`，读 `resources.fit_seconds`、`peak_memory_bytes` 与显存峰值。**同一个 `start` 复用给后面所有靠后窗口的探针**（`window_build_seconds` 是一次性的）。

**起步包原样的 ρ 已经量过：41 个分散决策日上中位 0.7713**（p10 0.22、p90 0.84，`sources.md`）。它越过了 ρ 这一半，这是设计使然——`c_lgbm` 读的是同一个 `window()` 张量的展平版本。所以第 0.5 轮大概率在原样起步包上命中，第一件真正要做的事是轴 a（通道消融）、轴 c（标签）或直接走 `g1r`，**而不是拿原样起步包去花 12 个回放年**。

命中判据时允许的唯一去处是 `g1r`（把对照的分数从 GRU 分数里回归掉之后再排序），它同样先过 G-INC；`g1r` 也不成立时，本臂以 `no_edge` 结束，不换家族。

> 头包 `exploration-plan.md` 的「子跨度验证只用来复测实现与耗时，不用来在候选之间做选择」**原样保留**：本臂不用子跨度回放做这道门，也不用它在候选之间选优。任何提名依据仍必须来自完整研究期验证。

| 名称 | 分数 | 身份 | 用途 |

## 提名条件（冻结前逐条满足）

1. G-INC 已通过，且 ρ 与 Δ 主动超额（逐年分开）都写进结果笔记。
2. 完整研究期验证完成，冻结门（完整研究期验证次数与去膨胀 Sharpe 概率）按运行事实通过。
3. **稳定性**：逐年分块的**主动**超额为正的研究年 ≥ 四分之三（四个研究年时 ≥ 3）。
4. **两个种子**：至少两个种子的主动信息比率之差已汇报；比种子差还小的优势不是证据。
5. P2 / P3 / P4 成立，P5 在非等额方案下成立。
6. **集中度与换手**：`pnl_concentration.top5_share_of_gross_gains` ≤ 0.6；年换手 ≤ 12 倍。
7. **实现底线**：`phase_seconds` 里单次 `fit` ≤ 1,800 秒（上限一半，留给卡上争用）；显存峰值 < 12 GiB；容器内存峰值**明显低于 16 GiB**；单次复核决策 < 60 秒；意图买单拒单率 ≤ 30 %。不成立先修实现再复测，不算证伪。
8. **热启动已被单独定价**：差异 4 的全冷启动消融（轴 d）已在同批跑过，两者的主动读数差写进结果笔记。热启动更差时，按更好的那个提名，并在笔记里说明。

主动超额 ≤ 0、空对照分位在 0.5 附近、去膨胀 Sharpe 概率接近 0 都是普通「没有边际」读数：候选不可提名，不触发家族关闭。

## 什么会杀死它（按命中即停）

1. **G-INC 在 `g1` 与 `g1r` 上都命中** —— 序列模型在这个股票池上只是树模型的一个弱化版本。本臂以 `no_edge` 结束。
2. 连续两轮完整研究期验证都没有满足提名条件的候选 —— 以 `no_edge` 结束。
3. 五条变体轴都至少试过一个变体，且没有任何一次完整研究期验证在主动超额与 2 倍滑点超额上同时为正 —— 以 `no_edge` 结束。
4. 主动超额为负的研究年连续两轮都过半 —— 关闭。
5. P2 在所有已登记构造下都不成立 —— 关闭并写明是哪个行业、哪条通道把它带上去的。
6. 提名条件 7 修复一次后仍不成立（例如某变体在卡上训练超时或显存超限）—— 该变体放弃，不算家族证伪。

## 臂级终止规则

任一成立即本臂关闭：上面第 1、2、3 条命中；预算用尽前没有可提名候选。关闭以 `finish_session(outcome="no_edge")` 携读数结束本臂，**不换家族**，不把 `c_lgbm` 或任何手写因子改作候选。`no_edge` 是结论不是退路：只有在没有还有先验的变体轴可换、或预算已经花完时才用它，不要让预算耗尽（流水线记 `deadline`）代替这个结论，也不要为了有一个交付而冻结一个不满足条件的候选。
