# 开放方向参考包（open_research，20260917）

本目录是只读 refs：本臂**不指定机制家族**。任务是在研究期上找到一个只做多、15–30 只的日频策略，它的边际要有经济解释、在组合尺度上成立，并且有理由在一个没人看过的前推年里继续成立；找不到就诚实地以 `no_edge` 结束。它不是可提交策略，也不是预期收益。

按以下顺序读：

1. `standards.md`：证据标准、**已关闭家族表**、对照、**敞口预算**、提名条件与收尾规则（唯一权威表述）。
2. `pit-field-map.md`：本轮可用的数据、逐域可见时点、单位与陷阱（唯一权威表述）。
3. `exploration-plan.md`：不占预算的普查与离线筛选、首轮批次、回放预算。
4. `sources.md`：对照与教训的读数出处、起步包的沙箱冒烟实测、诚实的限制。
5. `starter/`（候选名 `o1`）：合同内的最小可运行包（`main.py` + `lib/composite.py` + `lib/trade.py`）：四个信息家族各一条秩腿——现金流盈利质量、60 日残差低波、20 日反转、价值——等权合成、对规模中性化，月度复核的 20 只篮子；截面上带一列申万一级行业，`trade.INDUSTRY_CAP` 默认关闭。它通过 `validate_strategy_package`，并在沙箱镜像里以真实 as-of 路径跑通了「读取 → 合成 → 中性化 → 出单」（读数见 `sources.md`）。**它只是一个能跑的基线，不是推荐的机制**：可以改任何部分，也可以整个换掉；正式回放的第一步仍然是 `smoke_backtest`。**会话开始时 `output/` 就是这份代码**，`refs/starter/` 只是同一份的只读参考副本。

## 与上一个开放包相比改了什么

其余照旧，改的是证据标准这一层：

- **提名的信息比率门从 0.8 抬到 0.95，逐年一致性从 3/4 抬到 4/4。** 冻结门本身现在已经大致要求 IR ≥ 0.76，包的门必须是更严的那一条；而被冻结的书与最近关闭的两条臂都栽在逐年一致性上。
- **新增敞口预算**：单一申万一级行业的时间加权权重 ≤ 0.30，`|size_tilt|` ≤ 0.70，β ≤ 1.2，作为硬门。理由是本仓库唯一一次高分冻结的篮子把 82.5 % 的权重压在一个行业上，而裁决统计量看不见这件事。
- **空对照降为诊断**，不再是硬门；照报三个数。
- **已关闭家族表刷新**，含此后每一条关闭的臂、「单一行业集中篮子」这条禁止项，以及一节从已有读数里学到的方向性指引。

判据本身只以 `standards.md` 为准，本文不复述。

## 最重要的教训

每一条都有过真实代价，出处见 `sources.md`：

- **裁决统计量会把集中度记成 alpha。** 中性化只对沪深 300 与一条规模价差回归，行业、价值、换手它都看不见。本仓库唯一一次满足了全部预登记条件的冻结，研究期 IR 1.29、回撤 15.3 %，而它的篮子 82.5 % 压在单一申万一级行业上；另一条腿在分数层已经对行业哑变量残差化过，篮子层仍然压到 45.4 %。**分数层的行业中性化不阻止篮子层的行业集中**，敞口预算就是为这件事加的。
- **15 只的集中度会吞掉池内信号。** 控制后 IC t ≈ 5–6 的学习型分数做成 15 只、有价格上限的只做多篮子后可以是零甚至为负；靠广度挣钱的信号在 15 只里尤其薄。花回放预算之前先在组合尺度上读：池内最好 15 只与 30 只相对池均值，按研究年分开，扣掉成本线。复合分数也要拆开读——单腿打败「最强」合成的情况出现过多次。
- **卡住候选的常常是构造，不是分数。** 同一个分数换一种分数到篮子的映射，跟踪误差与最大回撤可以差一半，而整窗超额只差一两个百分点；反过来，放宽篮子、事后加行业上限、按反转或动量择时入场、分批建仓在本仓库都被量成负的。这是本包把筛子与构造列为一等候选、并按信息比率与回撤提名的理由。
- **回撤是本包最难的一条门。** 除了那条单行业集中的臂与周频价量书，本仓库记录在案的完整研究期腿回撤是 25.5–47.7 %，绝大多数落在 29–41 %。一个只做 alpha、不对回撤做任何动作的候选过不了 22 % 这条线；最近关闭的一条臂，死结正是这个。
- **成本是真实的。** 10 万元账户、最低佣金 5 元：15 只时单边约 8 bp、一次往返 25–35 bp；每周换 2 只的学习型篮子一年约 6 倍换手、约 2 % 成本。10 日标签的分数改成月度复核后中性化超额落到 0 附近；月度的慢特征一年成本约 1 %，季度约三分之一。先写成本线，再谈边际。
- **下跌年份会美化每个低 β 篮子。** 研究期内沪深 300 有过一整年的大跌，防御型篮子在下跌年的原始与中性化超额都偏好看，上涨的高波动年又会把它们压到零附近。只读中性化超额，逐年读，并说明哪一年撑起了整窗读数。
- **单个窗口的裁决被行情主导。** 同一份可执行文件在同一个季度上的三次读数从 +7 % 到 −19 % 不等；一个研究年的领先或落后也不是结论。选择与关闭都要完整研究期的证据，逐年分块里多数年份同向。
- **季节性的信息流要季节性地读。** 年报与一季报集中在春季，半年报在八月，三季报在十月，十二月到一月与七月几乎没有新公告；依赖公告的腿要写清淡季怎么办，每个研究年都要有足够的旺季观测。
- **适应写在产物里。** 冻结之后没有人再改它：学习型模型用 `fit` 与 `REFIT_PERIOD` 在最近 2–3 年上滚动重训，规则型篮子每次决策重算自己的滚动估计。在最近几周上增量微调在本仓库里是有害的。`state_dir` 在每次回放开始时为空。
- **研究期整窗读数好看不等于前推成立。** 不要把提名条件当作目标函数去逼近：逐年分块、机制归因对照与敞口预算是同等的硬门，任何一项塌了，整窗读数就不再是证据。

## 本臂的执行边界

执行合同——入口与订单、允许的 import、文件 I/O、`available_at` 与 PIT 读法、不写死宿主路径、沙箱无网络——以只读 `output/README.md` 与系统提示为准，本包不复述。本臂只在以下几点上更具体：

- 本臂 `gpu_count=0`：任何训练都在容器 CPU 上完成，一次 `fit` 不超过 `budgets.strategy_fit_timeout_seconds`。
- 本臂不挂分钟域（运行事实 `execution_policy`），执行时点只有 09:30 与 15:00。
- 不要把 `refs/` 里的文件拷进 `output/`：整棵包是只读的，`cp` 会把权限一起带过去；会话开始时 `output/` 已经是 `starter/` 的内容，不必移植。
