# 研究会话探索计划

目标：在本臂唯一的研究会话里，判定那条确认过的载体放到**中证 500 成分**上、按中证 500 裁决，能不能在主动序列上读出边；读得出就把它做成一本站得住的书，读不出就诚实地以 `no_edge` 结束，并把中证 500 的零技能地板与跨指数离散度诊断留给登记册。判据只在 `families.md`，数据与单位只在 `pit-field-map.md`，本文只排顺序与预算。

**本臂只动一件事：池。** 载体、标签、参数、持久化节拍全部是 20260922 的那一份，一个字不改。所以任何「我们顺手改了一下模型 / 标签 / 特征」的分支都不是本臂——那是另一条臂的轴或者一条已关的方向。

## 第 0 轮：不占回放预算的普查

用 `shell` 在研究期末的决策视图上跑，不启动回放。

1. **`benchmark_index` 一致性检查，最先做，先于一切。** 读运行事实里的 `experiment_facts.benchmark_index`，与 `starter/lib/index.py` 的 `INDEX_CODE` 逐字比对。策略容器自己读不到运行事实（`context` 只给目录与决策时刻，合同也不允许读 JSON），所以这次比对只能由会话做。
   - 相等且为 `000905.SH`：继续。把读到的值抄进第 1 轮的 `hypothesis`。
   - 不相等，或这个键**不存在**：按 `families.md` 点名禁止第 1、2 条**立即停**。写清读到的两个值与它们的来源，`report_issue`，然后 `finish_session(outcome="no_edge")`。**不要改代码去迁就参数，不要改参数，也不要「先跑起来看看」**——那会得到一本按另一个指数评的书，而本仓库上一轮的四个包都点名禁止这件事。
2. **运行事实核对**：`broker_replay.initial_cash`（本包按 100 万写成）、`acceptance_rules` 里有没有跟踪授权（本包按**不带**写成）、两个回撤上限、`budgets`（含 `strategy_fit_timeout_seconds`）与 `max_replay_years`。不符就改登记。
3. **数据核对**：`index_weight` 里 `000905.SH` 的截面在不在、每张多少只、`index_daily` 里有没有 `000905.SH` 的行、`universe` 带不带 `l1_name`。
4. **中证 500 的零技能地板（本臂最重要的一个数，本仓库从未量过）**：在本臂的池与席数上，按 `references/zero-skill-panel.md` 的口径抽 k = 20 的离线面板，量等额现金零技能能拿到的中性化超额与信息比率，**逐年分开**。沪深 300 上的那张表（10 万 / 30 席 IR 中位 0.986，100 万 / 50 席 +0.602）**不可以直接搬过来**：它是另一个指数的读数。**在这个数出来之前，本臂任何一个绝对读数都不许被解释。**
5. **股票池普查，按研究年分别列**：在册成分只数（应为 500）、可交易只数、剔掉科创板损失的指数权重、申万一级行业个数与最大行业占比、最薄成分的 20 日均成交额、价格分布、买得起的占比。起步包在某个决策日实测到的那一组数在 `sources.md`，**要自己按研究年重量一遍**。
6. **账户算术表（直接对着 P3）**：用本臂的资金，在 40 / 50 / 60 席上算座位金额、买得起的占比、5 元最低佣金的 bp/边、一次往返总成本、按**月度**节奏的预期换手算的年成本，以及在 `cost_stress_multiplier` 下 α 要付掉多少（公式在 `references/capital-arithmetic.md`）。
7. **`fit` 成本探针**：在研究期靠后的槽上跑 `smoke_backtest(days = 2)`，读 `resources.fit_seconds` 与 `peak_memory_bytes`，确认离 16 GiB 有明确余量。**`smoke_backtest` 不花回放年，也不计 trial。****同一个 `start` 复用给后面所有靠后窗口的探针。**

## 第 0.5 轮：离线门与跨指数离散度诊断（`families.md` 的硬门，**0 回放年、0 trial**）

判据在 `families.md`，这里只排步骤。全部在 `shell` 里做，**不发起任何回放**。

1. 在研究期后两年里取**至少 60 个分散的决策日**（每两周一天，或等间隔取满 60）。
2. 每一天用起步包同一份代码、同一张中证 500 截面建一本 50 席等额现金的书，前向持有到下一个复核间隔。
3. 每一天抽一个 **k = 20 的离线零技能面板**（同一成分身份侧、买得起一手的名字里换名，取 20 份的等权均值），得主动超额。
4. 判定：**主动超额 ≤ 0，或前后两半有一半 ≤ 0 ⇒ 不进整期。** 逐年也分开看一遍。
5. **同一批日子上一起做跨指数离散度诊断**（只读秩，不读水平）：同一份代码分别在 `000300.SH` 与 `000905.SH` 的成员资格上，算载体分数对标签的截面秩 IC（均值、t、逐年）、当日标签的截面离散度（标准差与四分位距）、当日分数的离散度与可打分只数。**这三组数不构成通过条件**，它们是本臂留给登记册的东西：门过了而宿主读不出边时，要能说清是「离散度更大但选不出来」还是「离散度根本没更大」。
6. 门命中：按 `families.md` 的杀死条件 2，本臂以 `no_edge` 结束，**把第 4 条的地板与第 5 条的诊断一起写进结果笔记**。

**这一步不产生提名依据。** 离线面板比宿主面板宽松且偏低，离线的水平与 Δ 在本仓库已经被量出会翻符号（同一条腿离线 +5.54 pp/年 实测 −0.63）；它**只用来否决**。

## 第 1 轮：一次完整研究期 `batch_validate`

两条腿：`s1` 与 `c_cold`。一次两候选完整研究期验证在四个研究年时花 8 个回放年、2 个 trial，同时满足「至少两次完整研究期验证」的提名计数。

`hypothesis` 必须写清：读到的 `benchmark_index`；逐行引用 `families.md` 的候选表；**与 `index_relative_*_20260919` 三条已关闭臂的差异**（那三条是手写分数 + 沪深 300 + 旧口径，本臂是确认过的学习型载体 + 中证 500 + 主动序列口径）；经济解释与**证伪条件**；席数、复核节奏、保留带与换名上限；预期的主动信息比率与逐年符号；P2 / P3 / P5 的判定规则。

**不要再加零技能对照腿**——宿主每次正式验证都会抽面板。回放一旦开跑就计入预算，策略自身抛错的候选照样花掉，环境失败的候选退还。某一路因环境原因失败时不重跑、不压缩对照。

**验证一回来，第一件事是 P5**：从 `result.json` / `style_analysis.json` 里确认基准序列、面板成员侧与中性化腿三者都是 `000905.SH`，把字段原样抄进结果笔记。读出别的指数就按杀死条件 4 立即停。

第 1 轮之后，对领先的完整研究期节点跑一次 `run_null_control`：不花回放年，会话时钟在它运行期间暂停。**它是诊断不是判据**；三个数一起报。

## 判定分支，逐条写死（判据本身见 `families.md`）

- **`s1` 主动 IR ≥ 0.75 且 ≥ 3/4 年正** → 走提名条件逐条补齐，第 2 轮补第二次完整期验证与种子差。**先不要去调构造**：本臂的命题是池，调构造会把「换指数带来的」和「调参带来的」搅在一起。
- **`s1` 主动 IR 在 0.4–0.75 之间** → 与沪深 300 上同载体的 0.4642 / 0.18 并排写，**注明那不是同批对照**。这是「换指数没有质变」的读数，第 2 轮只值得花在一条轴上（按第 0.5 轮诊断指向的那条），花完仍不过就关。
- **`s1` 主动 IR ≤ 0** → 中证 500 上这条载体选不出名字。看第 0.5 轮的离散度诊断：离散度确实更大而选不出来，是一条比 `no_edge` 更强的结论（**离散度不等于可预测性**），要单独写一段。关闭。
- **绝对超额高而主动超额低** → 赢的是股票池不是选名。看 `benchmark.panel_neutralized_excess` 与第 0 轮量的地板。**中证 500 的零技能地板可能比沪深 300 高得多，这正是本臂最需要防的一种自欺。**
- **`c_cold` 赢过 `s1`** → 续训被证伪（本仓库第四次同向读数）。按 `c_cold` 继续，如实写，并把 `COLD_EVERY = 1` 登记成后续腿的默认。
- **`size_tilt` 大幅低于沪深 300 那几条臂** → 那是池子不是书。**跨指数比较 `size_tilt` 没有意义**，只能在本臂内部逐腿比较。
- **`top_industry_weight` > 0.30** → 走轴 c 加每业上限（≤ 4 / 50 席）一轮，并写明是哪个行业带上去的。
- **月完成回合数 < 1.0** → 先按轴 b 把 `MAX_SWAPS` 往上调一档并复测；仍不成立即按「不可交易」关闭。**不要靠加快复核节奏去解决它**：成分只在月末截面上动，更快的复核只是用同一张截面多交易几次。
- **买不起份额显著大于 0** → 与第 0 轮的普查对不上，先查实现（座位金额、整手、现金缓冲），不是研究结论。
- **实现读数不对**（座位没填满、拒单率高、`fit` 逼近上限）→ 先修实现再复测，按提名条件 8。

## 第 2 轮起：一次只改一个可分离组件

按 `families.md` 的变体轴取，每轮一个，与当轮基准同批比较。一条轴在两轮里都没有满足条件的候选就关闭它。子跨度验证只用来复测实现与耗时，**不用来在候选之间做选择**。

## 收官轮

只做两件事之一：对已经满足全部提名条件的最好候选补齐缺的读数并冻结；或者以 `finish_session(outcome="no_edge")` 携读数结束本臂。**收官轮只在没有轴可换、或预算见底时才开始。**

**无论结局如何，结果笔记必须留下三件给登记册的东西**：中证 500 在本臂形状上的**零技能地板**（第 0 轮第 4 条）、**跨指数离散度诊断**的三组数（第 0.5 轮第 5 条）、以及本臂读到的主动 IR 与沪深 300 上同载体的 0.4642 / 0.18 并排（并注明后者不是同批对照）。本仓库为这三个数付了一条臂的钱。

## 计算预算

- **`fit`**：起步包在研究期靠后的决策视图上、按正式容器边界实测（读数与口径见 `sources.md`、`references/fit-cost.md`）。中证 500 的可打分截面约 450 只、比沪深 300 的约 280 只大六成，`fit` 也按这个比例贵一些，但仍是 3,600 秒上限的百分之一二。
- **推断**：单次复核实测约 1 秒，上限 360 秒。非复核日在确认最新可见交易日之后直接返回 `[]`。
- **余量怎么花**：**不要用来多带腿。** 每一个被完整验证过的 revision 都会抬高本臂自己的去膨胀 Sharpe 门。本臂计划 2 + 2 个 trial，上限 5 个。
- **单日探针的秒数对宿主负载极敏感**（本包实测**同一份代码、同一个决策日、同一次冷启动**在不同时刻读到 31.1 秒与 54.3 秒），耗时结论按多日回放的**平均**读。
- **回放年**：离线门与 `smoke_backtest` 都是 0 年、0 trial；第 1 轮两候选整期 8 年、2 个 trial。以运行事实 `budgets.max_replay_years` 为准。**trial 只能花在整期上。**

## 每个候选必须汇报的读数

除标准结果块外，写进结果笔记：**P5 的三个字段原样**（基准序列、面板成员侧、中性化腿）；经济解释与证伪条件；**主动中性化超额、主动跟踪误差、主动信息比率**与**面板自己的中性化超额**；逐年分块的主动超额与原始超额；`top_industry_weight`、`size_tilt` 与 `size_beta` 并排；**`c_cold` 的同跨度读数与逐年差**；两个种子的主动信息比率之差；换手、**年完成回合数与月完成回合数**、按本臂 `initial_cash` 重算的佣金账与 2 倍滑点下的超额；拒单率与原因；平均总仓位；`pnl_concentration`；空对照的三个数；一次决策的实测平均墙钟；`fit` 秒数与容器内存峰值；以及**这次回放里冷启动与续训各发生了几次**（订单元数据里的 `refits` / `cold_refits` / `last_refit_cold`）。**账户面四项**也要报：每次复核的买不起份额与整期均值、座位有没有填满、实际权重对目标权重的偏离、书覆盖的指数权重。缺任何一项的结果不作为提名依据。

## Validation 否证（任何一条命中，结果无效，不讨论收益）

- `benchmark_index` 没有在第 0 轮核对过，或核对出不一致却继续跑了。
- 结果里的基准序列 / 面板成员侧 / 中性化腿有任何一个不是 `000905.SH`，却把读数当成中证 500 的读数在解释。
- `index_daily` 的过滤还留在 `000300.SH`，而成分已经换成中证 500（标签里就留着整条中盘减大盘的价差）。
- 股票池不是按时点读出来的：硬编码名单、或用最新一张截面去标注历史训练日。
- 用 `trade_date` 而不是 `available_at` 判成分可见；把成分截面的日期当作调整生效日；`weight` 当成小数没有 ÷ 100。
- 成分的 `con_code` 没有改名就去 join，得到一张空表却按「池太小」处理。
- 标签用了整段研究期算出来的 β，或标签横跨决策时刻（信号日 t 的标签要求 t + 11 ≤ T-1）；隔离带不等于 `labels.HOLD`。
- 截面 z 分数或标签的秩不是只在当天的成分集合上做的。
- as-of 域读失败后回退了 `snapshot_dir`；读多数据集的域时没有先按 `dataset` 过滤；任何读取不带日期窗口。
- 买不起的**持仓**被当成离池强卖；或者买单向下取整而不是按最近整手四舍五入。
- 复核节奏依赖模块级计数器或跨调用缓存。
- 把训练好的 booster 放进 `models/`，或让 `state_dir` 里的东西跨回放存活。
- 没有第 0 轮的零技能地板与账户算术表就开了整期回放；跳过离线门直接开整期；把离线门做成一次子跨度回放。
- 没有同批的 `c_cold` 就把 `s1` 的读数当成一本定过价的书。
- **把沪深 300 上的 0.4642 / 0.18 当成同批对照去算 Δ**，或把沪深 300 的零技能地板搬来解释中证 500 的绝对超额。
- 用绝对中性化超额或绝对信息比率去论证边际，而不看主动读数与面板。

## 收尾

冻结的是提名节点自己的不可变快照，提名前不必把它恢复到 `output/`。不要提交离线普查脚本；`models/` 只放静态资产。
