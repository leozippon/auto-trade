# 研究会话探索计划

目标：在本臂唯一的研究会话里，判定 `range20` 这个在沪深 300 上挑出来的规则分数，搬到**中证 1000 成分**上、做成 100 万 / 50 席的等额月度书，主动序列能不能越过零技能；能就把它做成一本站得住的书，不能就以 `no_edge` 带着读数结束。判据、预登记与验证计划只在 `refs/families.md`，数据与单位只在 `refs/pit-field-map.md`，离线门的做法只在 `refs/references/offline-screen.md`，本文只排顺序与预算。

**常见情形下第一批就是整条臂**：`c_shuf` + `r1` 一批读完，`r1` 过不了 K4 就 `no_edge`。

## 第 0 轮：不占回放预算的核对

用 `shell` 在研究期末的决策视图上做，不启动回放。任一条不合格就在第一批的 `hypothesis` 里声明，不要硬凑。

0. **两个常量对齐运行事实，先于一切。** 读 `benchmark_index` 与 `broker_replay.initial_cash`：必须是 `000852.SH` 与 1,000,000，并与 `output/lib/knobs.py` 的 `INDEX`、`CAPITAL` 逐字相同。不同就改常量去对齐运行事实；`benchmark_index` 不是 `000852.SH` 说明建错了臂，`report_issue` 后停，不发起任何回放。
1. **运行事实核对**：`acceptance_rules`（两个回撤上限——本臂按创建参数 0.55 / 0.30；`freeze_gate` 的阈值与试验数口径；`graduation` 里的成本压力、回合数与总仓位）、`budgets`（`max_replay_years`、`batch_validate` 并发）、`research_geometry.years[].input_window`（每个回放年自己的 60 个月输入窗，`refs/pit-field-map.md`）。
2. **数据核对**：`macro` 里 `index_weight` 的 `000852.SH` 截面在不在、每张是不是 1000 只；`daily` 有 `high` / `low` / `pre_close` / `close`；`universe` 有 `name` 与 `l1_name`。
3. **账户算术与池普查（不读收益）**：按研究年列在册、可交易、科创板只数与权重、价格分布、买不起的份额、行业个数与最大占比；未设上限时顶端 50 只的最大行业占比；月与月之间分数的秩相关。`refs/sources.md` 有作包时的一组，要自己重量，不一致就报。
4. **离线门 G-R20 重算（`refs/families.md` 的硬门，0 回放年）**：照 `refs/references/offline-screen.md` 建分数与同池随机对照，跑工具一（整期 + 四个研究年）与工具二（月度书、200 本随机书、十分位）。S1–S5 逐条写「命中 / 未命中」与读数。**重算 `r1` 与跑对照不计 trial**；看了读数又去筛别的变体，每个都计一个。
5. **决策成本探针**：`smoke_backtest(start=研究期靠后的一天, days=5)`——**这个工具的窗口上限是 5 天**，所以它只用来读逐日 `strategy` 秒数、`peak_memory_bytes`、订单是否合法与买单元数据（`pool`、`seat_cash`、`unbuyable_share`、`book_size`、`exits_*`）；**换手与回合数改读第一批完整期验证的 `turnover` 与成交记录**，不要试图在冒烟里量。整个会话只用一个 `start` 做所有探针。

## 第 1 轮：唯一一批完整研究期 `batch_validate`

腿：**`c_shuf`（第一条，`control: true`）** + **`r1`（`control: false`）**，四个研究年花 8 个回放年；`offline_trials` = 0，另加会话筛过而没提交的变体数。两条腿只差 `lib/knobs.py` 的 `SHUFFLE` 一行。

`hypothesis` 必须写清：读到的 `benchmark_index` 与 `initial_cash`；逐行引用 `refs/families.md` 的分数表、腿表与预登记表；经济解释与**证伪条件**（K4 的三条）；预期的主动 IR（0.3–0.8）与逐年符号；G-R20 的五个判据量；P2 / P3 / P5 的判定规则；本臂的 trial 账（包括写明那 17 个兄弟信号不申报的理由）。

**不要再加零技能对照腿**——宿主每次正式验证都会抽面板，`c_shuf` 已经是同批的那一次抽样。回放一旦开跑就计入预算，策略自身抛错的候选照样花掉，环境失败的候选退还。

第一批之后，对 `r1` 的完整期节点跑一次 `run_null_control`：不花回放年，会话时钟暂停；**它是诊断不是判据**，三个数一起报。

## 判定分支，逐条写死（判据本身见 `refs/families.md`）

- **K4 命中**（`r1` 主动 IR 低于约 0.64，或正年少于 3，或主动回撤 > 0.30）→ 以 `no_edge` 收尾，不开第二批、不换轴。把 `r1` 与 `c_shuf` 的主动读数、逐年符号、创业板占比与 G-R20 一起写进 `reason`。
- **`r1` 的主动读数与 `c_shuf` 相近** → 与零技能分不开，按 K4 读；两者之差不是增量。
- **K4 没命中** → 第二批只跑 `r2`（`RANGE_DAYS` = 60，`control: false`），4 个回放年。`r2` 也越过那条线且有一条过冻结门，按提名条件提名；`r2` 低于那条线（K5）就 `no_edge`，即使 `r1` 自己过了冻结门。
- **绝对超额高而主动超额低** → 赢的是池不是选名，看 `benchmark.panel_neutralized_excess`。中证 1000 的回撤与反弹都大，这是本臂最容易自欺的地方。
- **某一年主动收益极端** → 先看那一年创业板对主板的差（`refs/sources.md`：第三研究年 −10.1、第四研究年 +18.9 %/年）；主要来自板块倾斜的读数照实写，不当成选名。
- **β 或 `size_tilt` 偏离很大** → 并排报 `size_tilt`、`size_beta`、β；这个分数在沪深 300 上本质是规模 / β 押注，在这里也要先排除这一条。
- **实现读数不对**（座位没填满、拒单率高、平均总仓位掉到 0.95 以下）→ 先修实现再复测，不算证伪。

## 收官

只做两件事之一：对已经满足全部提名条件的候选补齐读数并冻结；或者以 `finish_session(outcome="no_edge")` 携读数结束本臂——G-R20 的五个量、`r1` / `c_shuf`（以及进场了的 `r2`）的主动 IR、DSR、逐年符号、板块占比，以及对登记册 §3 那一行的交代。

## 计算预算

- **决策**：非复核日在确认最新可见交易日之后直接返回 `[]`（持仓不满 50 只时例外，那一天要补座位）；复核日读一次截面、一次 200 个自然日的日线窗与一次 `universe`，宿主冒烟里每次决策平均约 0.8 秒、容器峰值约 0.55 GiB。
- **没有 `fit`**：离 3,600 秒与 16 GiB 两条上限都很远。
- **回放年**：G-R20 与 `smoke_backtest` 都是 0 年；第一批 8 年，第二批 4 年，全臂最多 12 年、完整期验证最多 3 条、host trial 最多 2 个。
- **余量怎么花**：不花。每一个验证过的候选与每一个离线筛掉的配置都是一个 trial，抬高本臂自己的 DSR 门；这条臂的价值在于用最少的回放年把一个登记好的问题问干净。

## 每个候选必须汇报的读数

除标准结果块外：主动中性化超额、主动跟踪误差、主动信息比率与面板自己的中性化超额；逐年主动超额与原始超额；`c_shuf` 的同批读数；`top_industry_weight`、`size_tilt`、`size_beta`、β；书与池的创业板占比；实测年换手（`turnover` ÷ 4）、年完成回合、每月完成回合、`fees_paid` 与 `excess_at_2x_slippage`；拒单率与原因；平均总仓位；`pnl_concentration`；空对照的三个数；`trials_to_date` 与此刻的 `information_ratio_bar`。缺任何一项的结果不作为提名依据。

## Validation 否证（任何一条命中，结果无效，不讨论收益）

- 股票池不是按时点读出来的：硬编码名单、用最新一张截面标注历史决策日、或用别的指数建书而仍按 `benchmark_index` 评。
- 振幅窗口按日历取（把停牌日当成振幅为零），或用了 T 日（决策当天）的日线。
- `c_shuf` 的打乱依赖模块级状态或跨调用缓存；复核节奏依赖计数器。
- 买不起的**持仓**被强卖；或者买单向下取整而不是按最近整手四舍五入。
- 没有第 0 轮的核对与 G-R20 重算就开了整期回放；或者把 G-R20 做成一次子跨度回放。
- `c_shuf` 登记成 `control: false`，候选登记成 `control: true`，或 `offline_trials` 少报了筛过而没提交的配置。
- 看过读数之后改了登记的符号、预期、杀死数字或构造而没有重写 `hypothesis`。
- 用绝对中性化超额或绝对信息比率去论证边际，而不看主动读数与面板。
