# 研究会话探索计划

目标不是复现方向研究的某个数字，而是回答一件事：**这条已知谱系的学习型排序器，按本流程的滚动训练与周度篮子，在研究期上是否满足 `families.md` 的提名条件；满足时冻结最简单的那个形态，交给流水线做基线前推。** 判据与变体清单只在 `families.md`；可见时点与单位只在 `pit-field-map.md`；本文只排顺序与预算。

## 第 0 轮：不占回测预算的离线普查

用 `shell` 在研究期末的决策视图上跑，不启动回测。任一条不合格就在第 1 轮的 `hypothesis` 里声明，不要硬凑。

1. **数据集是否真的选进来了**：`data_summary.json` 列出 `fina_indicator_vip`、`forecast_vip`、`express_vip`、`income_vip` 与 `moneyflow`；分别报 `snapshot` view 与 `valid` view 的行数与日期覆盖（**不得由前者推断后者**）。
2. **单位核对**：`unit_reference.json` 里增速列是百分数、预告净利润是万元、快报净利润是元、资金流金额是万元、日线 `amount` 是元。参照实测（研究期第一个决策视图、上半年公告的行）：`or_yoy / 100` 的中位数约 0.18、10%/90% 分位 −0.19 / +0.94；`mf_amt_20`（20 日主力净流入 ÷ 流通市值）的绝对值中位数约 0.014。差 100 倍或 1 万倍就是单位错了。
3. **数据下限**：按研究年报每个研究年第一个复核日的 `vipf2` 与 `mfflow` 非空率，以及第一个研究年 `fit` 训练日里这两组有值的比例（`pit-field-map.md` 的「数据下限」）。
4. **可选池**：每个研究年各取两个复核日，报池大小与被各条规则剔除的名字数；参照实测见 `sources.md`。
5. **耗时与内存**：先跑 `smoke_backtest`（它包含一次 `fit`），读 `phase_seconds.fit` 与 `strategy`；参照 `sources.md` 的沙箱实测。`fit` 超过 2,700 秒或一次复核超过 120 秒时先修实现。

## 第 1 轮：起步包与两个最有信息量的变体，一次完整研究期 `batch_validate`

| 候选 | 改动 | 回答什么 |
|---|---|---|
| `l1` | 无（起步包） | 谱系本身 |
| `v_a158` | `data.FEATURE_GROUPS = ()` | 成长、预告、资金流与年龄列有没有增量；也是方向研究量过的列集 |
| `v_2y` | `data.TRAIN_YEARS = 2` | 训练窗口 2 年对 3 年 |

三者共用同一股票池、同一周度复核、同一篮子与成本，每个只差一个常量。`hypothesis` 必须写清特征组、训练窗口、网格、篮子规则，以及 `families.md` 的提名条件。

判定分支（判据本身见 `families.md`）：

- **`l1` 与 `v_a158` 都命中「什么会杀死它」第 1 条** → 这个谱系在本流程的研究期上没有边际 → 以 `no_edge` 携读数结束本臂，不换家族。
- **至少一个候选满足提名条件** → 已有 3 个完整研究期验证，冻结门的验证次数条件已满足；按「差距小于 4 个百分点/年时提名更简单的」选一个，读它的去偏 Sharpe 概率；门通过即冻结。不要为了「再看看」继续加试验：每多一个验证过的 revision，冻结门的打折就更重。
- **有候选整窗为正但逐年不足 3 年为正，或 2 倍滑点下 ≤ 0** → 不可提名；第 2 轮只走换手轴（`families.md` 轴 d）或树参数轴（轴 c），一次一个。
- **任一候选 `fit` 或复核超时** → 先修实现，修完用子跨度（一个研究年）复测耗时，再重跑完整研究期。

## 第 2 轮：一个轴，一次完整研究期 `batch_validate`

按第 1 轮的结果取一个轴、最多三个候选：换手不足以覆盖成本时取轴 d（`TOP_N = 20`、`MAX_SWAPS = 3`、`KEEP_BAND = 1.5` 里最多两个，加当轮基准）；否则取轴 c（单点网格 (31, 0.05)、`min_data_in_leaf = 500`，加当轮基准）。之后每轮只换一个轴；本轮全部候选被证伪后下一轮必须换轴而不是换阈值，轴用尽即以 `no_edge` 结束。

## 回放预算与墙钟

本臂只有一个研究会话，预算按臂计：2,400 分钟推理时间、96 个 replay-year、6,400 次模型调用、12 次空对照（以运行事实 `budgets` 为准；一次尝试失败后原地续跑，接着花同一份预算）。一个四年完整研究期验证占 4 个 replay-year：第 1 轮与第 2 轮各 12。回放一旦开跑就计入预算，失败不退还；某一路因环境原因失败时不压缩对照，把读数与待裁决的分支写进结果笔记，下一轮据此推进。

这是训练重的臂。按沙箱冒烟（`sources.md`）估算，一个研究年约 4 次季度重训（每次 6–9 分钟）、约 50 次复核（每次约 45 秒）与约 190 个非复核日（每次不到 1 秒），合计约 1.2 小时；一个四年完整研究期验证约 4–5 小时，三路并行的一批约 5–6 小时墙钟，宿主有争用时更长。回放期间推理时钟暂停，但模型调用与推理时间照常计入本臂预算：一批开跑后用它的等待时间写结果笔记，不要空转。

子跨度验证（一个研究年，每个候选 1 个 replay-year）只用来复测实现与耗时，不用来在变体之间做选择：单个研究年的读数会被那一年的行情主导。

## 每个候选必须汇报的读数

除标准结果块外，写进结果笔记：逐年分块的中性化超额与原始超额；换手、年成本与 2 倍滑点下的超额；拒单率与拒单原因；规模倾斜（`style_analysis.json`）；`pnl_concentration`；每次 `fit` 的秒数（`phase_seconds.fit` ÷ 重训次数）与一次复核的秒数；第一个研究年的读数单列并注明数据下限。缺任何一项的结果不作为提名依据。

## Validation 否证（任何一条命中，结果无效，不讨论收益）

- 训练面板与决策截面不是同一套函数构建的；标签用到了 T-1 之后才实现的开盘价。
- 用 `ann_date`/`trade_date` 而不是 `available_at` 判财务或资金流行的可见；增速没有 ÷ 100；万元与元混用。
- as-of 域读失败后回退了 `snapshot_dir`；读财务或事件域时没有先按 `dataset` 过滤；任何读取不带日期窗口。
- 复核节奏依赖模块级计数器或跨调用缓存（冷热 worker 出单不同）。

## 收尾

冻结的是提名节点自己的不可变快照，提名前不必把它恢复到 `output/`。不要提交训练脚本；`fit` 在每次回放里重训，`models/` 不放任何训练产物。
