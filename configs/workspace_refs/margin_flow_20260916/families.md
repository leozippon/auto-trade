# 四个可提名家族、一个诊断家族与一个对照家族

记号。决策日为 T，`inference_time=08:30`。日线 `daily` 用归一化单位：`C/O/A/V` 为截至 T-1 的收盘、开盘、成交额（元）、成交量（股），`qfq` 为按 T-1 冻结锚前复权的价格（`anchor = adj_factor(T-1)`，`qfq(t) = raw(t) × adj_factor(t) / anchor`），`circ_mv` 为元，`turnover_rate` 为小数。名册 `R_d` 为 `events` 域 `dataset == "margin_secs"` 且 `trade_date == d` 的 `ts_code` 集合；**08:30 只能取到 `R_{T-1}` 与更早**。融资明细 `M_d` 为 `dataset == "margin_detail"` 且 `trade_date == d` 的行；**08:30 只能取到 `M_{T-2}` 与更早**，`rzye`/`rqye`/`rzmre`/`rzche`/`rzrqye` 是元，`rqyl`/`rqmcl`/`rqchl` 是股。缺值、零分母、无穷值保持为空，不填 0。「方向」是合成前乘号，使高分做多。

## 共同底座

### 事件定义与四道声明过滤

```text
raw_add_d  = R_d \ R_{d-1}                      # d 与 d-1 是相邻的两个可见名册日
raw_drop_d = R_{d-1} \ R_d
```

一次事件在决策日 T 可用的条件是 `d = T-1`（`R_{T-1}` 与 `R_{T-2}` 都已可见），入场价是 T 日 09:30 开盘价。四道过滤全部是声明规则，不得在验证区间上调参：

```text
F1 宇宙        s ∈ universe.ts_code 且 s 不以 ".BJ" 结尾        # 名册含 ETF/LOF 与北交所；2,705 次原始新增里只有 1,375 次是 A 股非北交所股票
F2 往返        过去 60 个交易日内 s 未出现在任何 raw_drop（对 add 而言）或 raw_add（对 drop 而言）
F3 上市年龄    T-1 − universe.list_date ≥ 120 个自然日          # 排除新股上市当日入册：549 次常规腿新增里 379 次发生在上市首日
F4 明细确认    add：s 在 M_{T-2}、M_{T-3}、M_{T-4} 三天里都没有行
               drop：s 在这三天里至少有一行
共同排除       2024-04-01 ≤ T-1 ≤ 2024-05-31 的全部名册事件（上交所切片反复截断，见 README）
```

F4 是本包最有价值的一条：它用另一张表证伪名册差分。真实纳入里只有 4.7% 在事件日前三天已有 `margin_detail` 行，而 2024-04/05 的假新增里有 50.8%。它同时是 PIT 安全的——`M_{T-2}` 在 T 08:30 可见。

### 可交易性不变量（声明值，全部家族共用）

```text
T-1 未停牌；universe.name 不含 "ST"；剔除 688/689 与 .BJ；ADV20 = mean(A, 20) ≥ 3,000 万元；T-1 收盘 ≤ 40 元
```

老股纳入队列（524 次事件）剔除 STAR 与 ST 后剩 495 次，叠加 ADV20 与价格过滤后剩 420 次（84.8%）。ADV20 门槛在这个队列上几乎不筛掉任何东西（3,000 万元与 1,000 万元只差 1–5 次），因为交易所入册标准本身就是流动性标准；真正起作用的是 40 元价格线。放宽到 60 元（451 次）或 80 元（471 次）必须在预登记里写明并与 40 元同批比较。

### 中性化顺序

有限值 → 方向统一 → 1%/99% 截尾 → 对同截面 `log(circ_mv)`、`mom20 = qfq_C/qfq_C.shift(20) − 1`、`turn20 = mean(turnover_rate, 20)`、`vol20 = std(pct_chg, 20)` 四项联合回归取残差 → rank（`2*(rank(pct=True) − 0.5)`）。原始值只作对照报告。事件家族的「中性化」体现在匹配对照的抽取维度上，不对事件本身打分。

### 对照

每个候选同批带三个对照，缺一不可：

```text
对照 A（匹配）    同日、同规模十分位、同申万一级行业（universe.l1_code）、ADV20 最接近、当期未发生同类事件的等权篮子；每次调仓重抽
对照 B（名册内随机） 同一事件日，在 R_{T-1} ∩ 可交易过滤后的全集里随机抽同样只数、同样时点入场、同样持有期；固定种子写进 hypothesis
对照 C（机制无关）  第 6 家族的一项
```

对照 B 是本包相对宿主 `run_null_control` 的补充：宿主按全宇宙同市值分位重抽名字，而本臂的候选池是「已在名册内」这个窄集合，全宇宙抽样会把「名册成分股本身的风格」误算成边际。两个都要报。

## 1. 老股纳入事件：外生的杠杆约束放松（主家族）

机制：交易所把一只老股放进两融名册，等于同时放松它的买方杠杆约束（可融资买入、可作担保品）和卖方约束（可融券卖出）。这是监管驱动、与公司当期基本面正交的外生冲击。文献一致预期买方效应占优（需求曲线上移、流动性改善、定价效率提升），A 股融券极难借券、成本高，卖方效应被制度性压制，因此先验方向为正——但这是**先验不是事实**，符号由本折普查在输入窗上确定后才写进 `hypothesis`。

```text
cohort_incl(T) = {s ∈ raw_add_{T-1} : F1..F4 通过 且 可交易性不变量通过}
入场            T 日 09:30 开盘，等权，篮子上限 12 只（事件数超过 12 时按 ADV20 降序取前 12）
持有            40 个交易日后于 09:30 平仓；同一名字重复入册时只认第一次
无事件日        持币（不用任何替代信号填仓）                                方向 +（先验）
```

**同批变体（必须一起登记、一起跑）**：同一 cohort 的 20 个交易日持有。两者的差是本家族关于「效应衰减速度」的唯一读数；只有 20 日为正而 40 日为负，说明效应集中在纳入后一个月内，成本余量随之减半，要按 `README` 的成本算术重新判定是否值得。

**分层（同批登记，不新增家族）**：`批量腿` = 单日事件数 ≥ 50 的批次（本地只有 2022-10-24 一天，399 次事件），`常规腿` = 其余 15 个批次日的 125 次事件。两腿必须分开报：前者是一次性扩容、日期高度集中，后者是定期复核。整窗汇总把两者混在一起会让 2022Q4 一个批次决定整个结论。

**容量与换手**：40 日持有下 12 只上限的篮子平均只持有 4.0 只、中位 1 只，40% 的交易日空仓（60 日持有时空仓日降到 16%，20 日持有升到 69%）。年换手因此远低于 300%，成本拖累约 1.6–1.9%/年。10 万元账户无容量约束：队列流通市值中位数 61 亿元（批量腿）/ 90 亿元（常规腿），ADV20 中位数 1.3 亿元 / 4.9 亿元。

**否证（写进 `hypothesis`，看到结果之前定死）**：
- 相对对照 A 的中性化超额在 20 日与 40 日两个持有期上都 ≤ 0；
- 相对对照 B（名册内随机入场）的超额 ≤ 0——边际只是「在批次日买了这批中盘股」；
- 加入 `mom20` 对照后归零（纳入常伴随近期活跃度上升，这是必检项）；
- 四个季度子窗同号 < 3，其中**事件数 < 8 或空仓日 > 60% 的子窗记「无证据」，不计入分子也不计入分母**；
- 2 倍滑点下超额转负；
- `top5_share_of_gross_gains` 过高，或整个边际来自 2022-10-24 一个批次。

**失效模式**：队列只有 16 个批次日，四季子窗里常有两个子窗一个事件都没有，符号一致性检验的统计力天然很弱——这是已接受的限制，必须在候选论证里写明，不得靠把 20 日窗口拉长到 60 日、或把上市年龄门槛从 120 天降到 20 天来凑事件数（后者会把新股放回来）。定期复核批次通常伴随指数成分调整与季末再平衡，同日的市场结构效应可能被误读成纳入效应，匹配对照必须同日抽取。

## 2. 剔除镜像：符号诊断（诊断家族，不得提名）

机制：如果纳入放松约束、抬升价格，那么剔除应当收紧约束、压低价格。本环境只做多，「应当下跌」无法直接表达，因此这条腿的唯一用途是**给家族 1 的符号做独立检验**：两个方向都为正，或都为负，说明测到的不是约束变化而是别的东西。

```text
cohort_excl(T) = {s ∈ raw_drop_{T-1} : F1..F4 通过 且 可交易性不变量通过}
读数            该 cohort 相对对照 A 的 20 日与 40 日前瞻收益差（在输入窗上算，不占回测预算）
方向            与家族 1 相反                                              诊断，不可提名
```

**否证与门槛**：全样本 102 次事件、55 个日期，其中 45% 是当前名称带 ST 的股票。因此：先按 `universe.name` 是否含 ST 分成两层报，只有**非 ST 层**的读数算证据；非 ST 层某个子窗事件数 < 8 时该子窗记「无证据」。如果非 ST 层的符号与家族 1 同向，家族 1 直接被证伪（约束松紧两个方向给出同一个符号，只可能是共同的风格暴露）。

**明确不做**：不把剔除 cohort 做成「事件后反弹」的多头候选。102 次事件里没有足够的非 ST 样本支撑一个可提名策略，硬做只会把 ST 退市风险当成 alpha。

## 3. 融资余额拥挤度，5 日持有（第二主家族）

机制：融资盘是有负债约束的顺周期资金。一只股票 20 日融资余额的暴涨，度量的是它最近的涨幅里有多少是借来的钱买的；这部分买盘在维持担保比例与利息压力下会回吐，因此高融资增速一端随后跑输。它与换手率的区别在于杠杆是带负债的存量，不是流量——这一点必须靠 `turn20` 中性化来证明。

```text
chg20(T) = rzye(T-2) / rzye(T-22) − 1                # 两个端点都取 margin_detail 的可见行，T-2 是 08:30 能看到的最新一天
候选池   = s ∈ R_{T-1}（名册内）且 可交易性不变量通过 且 rzye(T-22) > 0
score    = −chg20 的截面 rank，四项联合中性化后                        方向 +（低融资增速为多头端）
篮子     = 前 15 只等权，持有 5 个交易日，每 5 日整篮换
```

**必检的第二条腿（同批登记）**：把候选池从「名册内」换成「全 ADV 过滤宇宙」再跑一遍。方向评审明确写了这条否证：如果效应在限制到名册成分股后消失，它就是资格/规模的假象而不是杠杆机制。

**本地复算**：`rzye` 20 日变化的规模中性 rank IC 为 H=5 −0.0358（t −7.39，202 个非重叠周，平均 2,798 只）、H=20 −0.0313（t −3.64，47 个月）；加 `mom20` 后 H=5 为 −0.0270（t −6.46）。方向评审在全套控制（规模＋mom20＋mom60＋turn20＋vol20）下报 H=5 −0.011（t −3.29，四年全为负）、H=20 −0.003（t −0.54）。**可交易的多头端（低融资增速五分位）在全套控制下只有 +0.03%/5d（t = +0.76）**，这是本家族唯一的真实风险。

**容量与换手**：5 日整篮换 ≈ 每年 48 次往返 ≈ 13–15%/年成本；每 5 日换半篮 ≈ 6.5–7.5%/年。候选池约 2,750–3,100 只，15 只篮子毫无容量压力，成本才是全部问题。

**否证**：
- 多头腿（低 `chg20` 端）相对对照 A 的中性化超额在 5 日持有上 ≤ 0 **在扣除上面的成本之后**——这是第一折的硬门，不过就直接关；
- 全套控制后的 IC 在四个季度子窗里为负的少于 3 个；
- 把候选池限制到名册内后效应消失（= 资格/规模假象）；
- 被同批的 5 日反转对照（家族 6）完全吸收；
- 空对照 `excess_percentile` ≤ 0.5，或相对对照 B 的超额 ≤ 0。

**失效模式**：`rzye` 的分母在小余额名字上极不稳定（`rzye` 的 p05 是 3,400 万元），20 日比值容易被几百万元的绝对变化放大；必须同批报一个用绝对变化除以流通市值的变体（`(rzye(T-2) − rzye(T-22)) / circ_mv(T-1)`）来交叉核对，两者符号不一致即证伪。2024-07 融券保证金比例上调与转融券暂停之后，融资端的行为发生过一次制度性变化，2024Q3 之后的子窗要单独看。

## 4. 拥挤度衰减检查：10 日与 20 日持有

机制：家族 3 的机制本身不指定衰减速度。方向评审的数字里 H=5 的控制后 IC 是 −0.011（t −3.29）而 H=20 只有 −0.003（t −0.54），意味着效应可能只活在一周内——而一周持有在这个账户上要付 6.5–15%/年。这个家族的存在只有一个目的：**在花掉全部预算之前，先把「机制真实但不可交易」和「机制不存在」分开**。

```text
同 chg20 信号、同候选池、同中性化、同 15 只篮子
腿 A：持有 10 个交易日，每 10 日整篮换            成本 ≈ 每年 24 次往返 ≈ 6.5–7.7%/年
腿 B：持有 20 个交易日，每 10 日换半篮            成本 ≈ 每年 12 次往返 ≈ 3.2–3.8%/年
读数：两腿与家族 3 的多头端中性化超额、rank IC 与 IC 的持有期曲线，一起报
```

**否证 / 判决规则**：如果腿 A 与腿 B 的多头端在成本后都 ≤ 0 而家族 3 的 5 日腿为正，本臂对拥挤度方向的结论是**「机制真实但在 10 万元账户上不可交易」**，按 `finish_fold(outcome="no_edge")` 弃权并把成本算术写进 `reason`；不得把滑点假设调低、不得忽略 5 元最低佣金、不得把篮子扩大到 40 只来摊薄最低佣金后声称可交易（那是另一个策略，不是本家族）。

## 5. `rqyl` 消歧腿：名册口径歧义能不能被消解

机制：`margin_secs` 不区分担保品、融资买入与融券卖出资格（数据文档 §1.7 明写），因此纳入事件的符号天然有歧义——放松买方约束应当推高价格，放松卖方约束应当压低价格。唯一的本地消歧手段是看纳入之后有没有真的出现融券余量。

```text
shortable(s, T) = 存在 d ∈ {事件日, ..., 事件日 + 5 个交易日} 使 M_d 中 s 的 rqyl > 0
                  该判定在事件日 + 7 个交易日的决策上才完整可见（rqyl 到 T-2），因此这条腿第 8 日入场、持有 40 日
两个子腿          shortable = True 与 shortable = False，方向分别声明、同批比较
```

**覆盖门（先跑，不过就判「不可测」）**：本折验证区间内，两个子腿各自的事件数都 ≥ 8。实测新纳入名字 5 日内 `rqyl > 0` 的比例逐年为 52.4%（2022，n=563）、28.0%（2023，n=143）、10.6%（2024，n=104）、0.7%（2025，n=138）；同时名册内**已有**成分股的 `rqyl > 0` 比例常年 66%–91%。也就是说：2022–2023 的折能分出两个非空子腿，**从 2024Q3 起 `shortable = True` 子腿几乎为空，必须在笔记里记「不可测」并给出这些数字**，不得把窗口从 5 日拉到 20 日、也不得改用 `rqye > 0` 之类的替代口径来凑样本。

**否证**：两个子腿方向相反且都不显著 → 名册口径歧义在本地无法消解 → **家族 1 与本家族一起关闭**，这是方向评审预先写好的关闭条件。两个子腿方向相同 → 歧义不是主要矛盾，家族 1 用合并样本继续，本家族不再单独占预算。

**失效模式**：`rqyl` 为 0 既可能是「不可融券」，也可能是「可融券但券源为零、没人借」。这两件事在本地数据里分不开，因此这条腿只能证伪、不能证实：它可以关掉家族 1，但它自己站住不构成本臂的边际。

## 6. 对照家族（只作对照，不得提名）

```text
6a  名册内随机入场      同事件日、同只数、同持有期，从 R_{T-1} ∩ 可交易全集里按固定种子随机抽        家族 1、2、5 的对照 B
6b  同日匹配篮子        同规模十分位、同申万一级、ADV20 最接近、当期无事件                          全部家族的对照 A
6c  5 日反转            rev_5 = −(qfq_C / qfq_C.shift(5) − 1)，四项中性化，15 只，持有 5 日          家族 3、4 的对照 C
6d  20 日动量           mom20 = qfq_C / qfq_C.shift(20) − 1，四项中性化                              家族 1 的对照 C
6e  EP 与规模腿         EP = 1/pe_ttm（来自 daily），规模 = −log(circ_mv)，各自规模/EP 互不中性化    家族 3、4 的价值/规模对照
```

每一轮 `batch_validate` 必须至少带 6c–6e 中的一项，`hypothesis` 里写明「对照」。它们的节点不得被 `finish_fold` 提名，落败或胜出都只用于读主家族的边际。6e 回答的问题很具体：低融资增速的一端天然偏低估值、偏小盘，如果 EP 或规模腿单独就能复制这条腿的超额，家族 3 就是价值/规模换皮。

## 明确不做

- 用 `R_T`（当日名册）或 `M_{T-1}`（T-1 的融资明细）——两者在 08:30 都不可见，是本方向最容易犯的前视。
- 用 `trade_date` 而不是 `available_at` 判可见；把 `margin_secs` 的名册差分算在两个**不相邻**的可见名册日之间而不声明。
- 把 ETF/LOF 代码、`.BJ` 代码、新股上市日入册、2024-04/05 的名册振荡当成事件。
- 用 `margin`（交易所汇总表）的 `rzye` 做择时闸门或市场状态门控。
- 把 `rqyl == 0` 读成「不可融券」而不说明它也可能是「无券源」。
- 价值、反转、动量、低波、成长、规模的通用打分作为候选；WorldQuant 101、TuShare 因子菜单。
- 把本目录或任何 vendor 树拷进 `output`。
