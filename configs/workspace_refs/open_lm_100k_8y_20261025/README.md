# 开放研究·日线、财务、公告标题与进程内模型·10 万 / 八年（open_lm_100k_8y，20261025）

本目录是只读参考包，会话里挂在 `refs/`。包里没有起步策略：`output/` 开局是合同模板自带的最小基线（`output/README.md` 的「Default strategy」）。`refs/families.md` 记着这份记录上已经关闭与占用的方向，作信息用。

## 问题

所有者的问题：在八年研究期上设计一个新颖的选股策略，让它相对零技能面板有真实的边。沙箱里的一切都可以用：日线、财务、种子里的公告标题，以及进程内的 `Qwen3.8-27B-FP8`、`Qwen3.5-2B` 与 `Qwen3-Embedding-0.6B`。

所有者长期关心持续学习与记忆、检索相似的历史案例、让语言模型在上下文里读证据；这些是背景，不是任务。下面只写会话自己发现不了的事实。

## 卡

本臂在 ZGCA 实例上认领一张 A100-SXM4-80GB（`nvidia-smi` 报 81,920 MiB）。会话容器与每次回放的策略容器都只挂这一张：一批里并排回放的候选（至多 `budgets.batch_validate_max_concurrency` 个）共用它，会话里起的进程（例如 `vllm serve`）也占着它。一条腿（一个候选的拟合容器与推断容器）只能指望自己放上去的东西；只有一张卡，没有张量并行。

本包的计时除标明 A100 的以外都量在本地的 L20（每卡约 44.4 GiB 可用）上，用到之前在自己的卡上重新量一遍。

## 模型

策略能加载的预训练权重只有本臂钉住的库：会话里 `/mnt/pretrained`、策略里 `context.pretrained_dir`，三个 Hugging Face 布局的目录，只读。库在建臂时按清单摘要钉住，每个容器启动前核对。策略容器没有网络，够不到任何托管模型，也够不到会话里起的服务：模型只能在本腿的进程里、本腿的卡上推断。

| 目录 | 类型 | 大小 | 发布 |
|---|---|---|---|
| `Qwen3.8-27B-FP8` | 生成，270 亿参数，64 层（48 层 Gated DeltaNet 线性注意力 + 16 层门控注意力），块式 FP8 权重；多模态检查点，按纯文本用 | 28.8 GiB | 2026-08 |
| `Qwen3.5-2B` | 生成，24 层（18 层 Gated DeltaNet + 6 层全注意力），bf16 | 4.3 GiB | 2026-02 |
| `Qwen3-Embedding-0.6B` | 文本嵌入，28 层，最后一个 token 池化，1024 维；前缀截断再归一化仍是嵌入 | 1.1 GiB | 2025-06 |

发布月份取自各目录的 README 与发布页；没有一份写明训练数据的截止日期。

进程内的 vLLM（0.27.1）怎样写、怎样才可重现，以 `output/README.md` 的「Pretrained models」为准。那里没有的几件事：

- **显存份额。** `gpu_memory_utilization` 是整张卡的份额（默认 0.9）；引擎启动时卡上空闲显存少于这个份额就拒绝启动。80 GB 的卡上 0.9 约 72 GiB，0.45 约 36 GiB。20261022 轮在 L20 上的 27B 例子（`enforce_eager=True`、`max_model_len` 8192、`max_num_seqs` 32、bf16 KV，份额 0.80）占 36 GiB，权重之外的 KV 缓存 6.19 GiB、75,483 个 token；同样的引擎在这张卡上约是 0.45 的份额（按卡的大小推算，A100 上没量）。份额之外还要放下本腿进程自己的张量，以及同批并排的其他腿。
- **随回放增长的状态。** 三天的冒烟看不到它：20261022 轮一条带 27B 的腿，三天冒烟的显存峰值 38.7 GiB，整期随案例记忆长到 44.2–44.3 GiB。整期行的 `resources` 给出峰值。
- **开局与吞吐**（L20）。`Qwen3.8-27B-FP8` 不编译开局约 2–3 分钟、编译约 6.5 分钟，冷磁盘再加约 1 分钟读权重；提示吞吐不编译约 2,300–2,600 token/s、编译约 3,050–3,200。它的线性注意力状态在一张 L20 上（默认份额）约容 180 个并发序列，默认的 `max_num_seqs=256` 起不来。`Qwen3-Embedding-0.6B` 编码短标题约每秒 1,770 条。
- **可重现。** `output/README.md` 写的逐位相同（不编译、温度 0、固定的批与次序）是在 L20 上核对的，A100 上没核过。
- **Paper。** Paper 账户每天早上新开 worker：到期的 `fit` 在新的拟合 worker 里跑，引擎随之重新加载；推断 worker 把此前每一次决策按原顺序重发一遍来恢复模块状态。在 `generate_orders` 里调模型，每天早上就要把此前的每一次调用重做一遍。

## 时点、文本与匿名化

- **模型知道研究期。** 研究期是 2017-07..2025-06：27B 与 2B 发布时它早已过去，嵌入模型发布于它的最后一个月。研究期上任何经模型读出的东西，都可能来自模型对那段行情的记忆。按发布月份算，确定落在训练数据之外的只有 27B 的 2026-08 之后、2B 的 2026-02 之后、嵌入模型的 2025-06 之后。
- **什么认得出发行人。** 标题第一个冒号之前的简称、六位代码、`universe` 里的名称、「……有限公司」式的全称，以及日期、年份、价格水平、书名号与引号里的产品、项目与合同名。这些都去掉，模型仍可能从措辞认出事件。
- **标题在哪里。** `context.asof_dir + "/text_index"` 是 parquet 分片目录，列 `text_id, dataset, ts_codes, title, available_at, library_file`，只有 `dataset == "anns_d"`；研究期每个交易日约 2,700–3,600 行，2025 年上半年约 1,700 行（见下面的副本）。`text_library` 里每行只是标题加一条 PDF 链接，没有正文；PDF 不在种子里，容器也没有网络。
- **何时可见。** `available_at` 是供应商的接收时刻（与公告日相差 −1..+3 天时），否则是公告日当天 23:59:59。回放在每晚 23:15 的文本节点放行标题，T 日 08:30 的决策看到的是前一晚的节点：盖在 (T−1) 23:15 及之前的行才可见。所以只有日期、日期为 D 的标题最早用于 D+2 起第一个交易日的决策（周四、周五的标题都是下周一）。例外是视图自己的：每个研究年的第一个决策读的是截在年锚点（前一日 23:59:59）的视图而不是节点，锚点那天的标题早一个节点就在。研究期的行几乎都只有日期（带可信接收时刻的只有 0.19 %，集中在 2025 年 4–6 月）；研究期之后的标题带接收时刻，比同类标题早一到两天可见，依赖标题时点的策略在研究期上看到的是偏晚的那一种。
- **副本。** 2025 年之前供应商把多数公告送了两份（普通标题，和前面加了公司简称的一份；上交所 2021–2024 年另有第二个链接），`text_index` 没有合并它们：每份公告在 2024 年及以前有 1.3–2.0 行，2025-01 起约 1 行，按条数计的标题特征因此在 2025-01 掉约 30 %。去掉简称前缀后按（股票、决策日、标题）去重，副本就并成一行。

## 一条整期腿的时间

整期约 1,941 个决策日。这台实例在 20261019b 轮的读数（那时一张卡上并排两到三条腿）：墙钟时间是全部 `fit` 的时间再加约 50–80 分钟，后者是 `fit` 之外的部分（宿主建每天的视图、决策与 Broker）。每天 `fit` 约 1 s 的腿整期约 2.1 小时，约 4 s 的 2.9–3.5 小时，约 6.5 s 的 4.4 小时。自己的策略用 `smoke_backtest` 量几天的单日耗时；`batch_validate` 的每一行带墙钟秒数与 `resources.fit_seconds_summary`，一个研究年的 span 只花 1 个回放年。

## 种子

`pit_views_seed_research_8y_fundanns_20261024`，每个决策视图回看 108 个月：日线（同一行并入每日指标、复权因子与涨跌停价）、逐研究年的 `universe`（名称、交易所、上市日、申万一级）、四张宏观表（`index_daily`、`index_dailybasic`、`index_weight`、`sw_daily`）、财务域十个数据集（`income_vip`、`balancesheet_vip`、`cashflow_vip`、`fina_indicator_vip`、`forecast_vip`、`express_vip`、`dividend`、`fina_audit`、`fina_mainbz_vip`、`disclosure_date`）与公告标题 `anns_d`。没有事件域（资金流、两融、龙虎榜、股东与质押）与分钟线；竞价只从 2025-01-16 起、每天 09:29 才可见，08:30 的决策看不到当天的。
