# 盈利意外漂移参考包（earnings_surprise，20260918）

> 状态：为已退役的研究臂 `earnings_surprise_20260918` 编写；该臂在旧流程下停在开发中途，没有裁决。下文按研究会话流程写。

本目录是只读 refs：把**公司实际业绩相对事前预期的缺口**收成一个特征面，交给一个不训练的只做多截面篮子，并按预登记的归因对照判定它是否真的挣到了「成长腿」与「刚披露」之外的边际。它不是可提交策略，也不是预期收益。

任务只有一句话：用两条意外腿——年度归母净利润相对卖方一致预期（`income_vip`/`express_vip` × `report_rc.np`）的缺口，和单季归母净利润相对去年同季的变化——按公告后的新鲜度加权，做 08:30 决策的截面信号，并且必须同批比过两个对照：**同一骨架只用同一份报告的同比增速**（`explore_github` 冻结产物里的 `vipF2` 成长轴），以及**同一骨架只按公告新鲜度排序**（`analyst_revision` 臂那条胜出的安慰剂形态）。比不过第一个对照说明一致预期缺口只是成长的另一种写法；何时据此关闭本机制只按 `families.md` 的门 1。

按以下顺序读：

1. `families.md`：主候选面、两个对照面、**硬门（关闭判据的唯一权威表述）**、允许的变体、臂级终止规则。
2. `pit-field-map.md`：逐表可见时点、单位、去重规则与陷阱（唯一权威表述）。
3. `exploration-plan.md`：不占预算的普查、首轮批次、判定分支、后续轮次。
4. `sources.md`：本地探针的读数与复现命令、冒烟实测、诚实的限制。
5. `starter/`：合同内的最小可运行包（`main.py` + `lib/surprise.py` + `lib/trade.py`），**不是**候选本身。它通过 `validate_strategy_package`，并在沙箱镜像里以真实 as-of 布局跑通了「读取 → 事件 → 一致预期 → 中性化 → 出单」全链路（读数见 `sources.md`）；正式回放的第一步仍然是 `smoke_backtest`。`main.py` 的 `CANDIDATE` 常量在三条腿之间切换，三者除这一行外必须逐字相同。

## 为什么这是一个新机制家族

信息生产者是**两条流的配对**：公司自己的实际业绩（`income_vip`、`express_vip`）与卖方的事前预测（`report_rc.np`）。本仓库把两者分别用过——成长同比与预告方向在 `explore_github` 里、预测的*修正*在两个 `analyst_revision` 臂里——但从未度量过**实际减预期**这个量。按研究协议的家族定义（收益来源的经济解释），这是「公告后对意外的反应不足」，与「成长」「修正」不同源。

本地探针（方法与全部读数见 `sources.md`）：年度一致预期意外在控制规模、动量、反转、换手、波动、彩票、两条已消耗的资金流腿、行业、EP、**同一份报告的同比增速**与**公告时点**之后，5 日 rank-IC 仍为 +0.039（t +6.4、IR 0.64），10 日 +0.038（t +4.2），20 日 +0.028（t +3.1），逐年全部为正；只做多顶档十分位在新鲜事件上 +0.47%/5 日（t +2.3），旺季篮子 +1.15–1.55%/20 日。这是本项目历次方向研究里控制后最强的读数，而且它是**控制后变强**的——非价格信号的指纹。季度腿是无券商输入的十日效应（5 日 t +4.7），全年都有。

反过来也要诚实。**三分之二的效应落在公告后前十个交易日**；信息流是季节性的——年报季与快报季在春季，季报在春末、盛夏与秋末，**12–1 月与 7 月没有新公告**；只做多的那条腿比本环境做不了的空头腿薄。所以本包把新鲜度、淡季政策与成本线都写成硬合同，而不是留给会话内发挥。

## 硬合同

- 正式策略写在 `output/` 包内：入口固定为 `output/main.py` 的 `generate_orders(context)`，返回严格 JSON 订单数组；辅助模块放在 `output/` 下并用绝对导入，每个 `.py` 受同一套静态检查，文件数与总字节数以运行事实为准。
- 正式 import 只允许：纯计算标准库、`numpy`、`pandas`、`scipy`、`sklearn`、`lightgbm`、`xgboost`、`statsmodels`、`torch` 及其子模块，以及 `output/` 内自己的模块。本臂 `gpu_count=0`。
- **本包的主线不训练**：没有 `fit`、没有 `REFIT_PERIOD`，每次决策是两次有界的 parquet 读取加一次最小二乘。登记学习器变体时才加 `fit(context)`，结果写 `context.state_dir`。
- 沙箱无网络。不要写死 `/mnt/agent/workspace`。先核对本轮 `data_summary.json` 与 `unit_reference.json`，再经 `context.asof_dir` 读数，每次读取都给 `columns=`、`filters=` 与日期窗口；as-of 域读失败**不得**回退 `snapshot_dir`。
- 每一行输入必须 `available_at <= context.inference_at`；判可见只看 `available_at`。逐表规则见 `pit-field-map.md`。
- 执行时点只用 09:30 与 15:00（本臂不挂分钟域）。Broker 负责 T+1、费用、涨跌停与成交；策略只发订单草图。
- 不要把 refs 拷进 `output`。

## 研究流程与账户

研究期由若干整的七月至次年六月研究年组成，本臂的全部研究会话都在这同一个研究期上开发与验证；决策视图定在研究期末，输入窗口从那里往前数。精确窗口、研究年标签、预算、冻结门与毕业条件以运行事实为准，本包不复述。完整研究期验证带逐年分块（`sub_windows`，每个研究年一行），只有完整研究期节点可以提名冻结，冻结门按本臂验证过的全部 revision 给提名的去偏 Sharpe 打折。每个会话以 `finish_session` 的一种结局收尾：`freeze` 冻结本臂唯一的交付并结束研究；`continue` 把读数与待检验的分支经 PRIOR 交给下一个会话（最后一个会话没有这个结局）；`no_edge` 按 `families.md` 的终止规则结束本臂。冻结产物随后在研究期之后的连续前推期与 Held-out 上回放一次并裁决：那段数据没有会话看得到，也没有 Agent 参与，前推不过即本臂结束，没有第二次冻结。

账户是 10 万元真实资金：佣金万一、最低 5 元/笔，过户费 0.1 bp，卖出印花税按成交日切换，方向滑点 5 bp。15 只等权、97% 仓位时单只预算约 6,300 元，最低佣金即 7.9 bp/边，一次往返约 25–35 bp。起步节奏是半月复核、每次最多换 8 只：一年约 208 次换名 ≈ 1,300% 年换手、**3.3–4.5% 的年成本拖累**；月度变体约 600% 换手、1.5–2.2%/年。探针的旺季多头腿折年化约 +10–12%，但一年只有约四成的周有新鲜信号，所以起步篮子的毛期望大约在 +5–7%/年——高于成本线，余量不宽。**成本门是硬合同**，判据写在 `families.md`。

## 「没有边际」的读法

每个候选按 `families.md` 的「硬门」与「什么会杀死它」逐条读，不看整窗总收益；本文不复述判据。另外三点读法：

- 整窗数字与逐年分块 `sub_windows` 一起读；每个研究年都含旺季与淡季，逐年读法见 `families.md` 门 4。
- `benchmark.neutralized_excess_return` 与原始超额一起读；本包的原始 SUE 秩在 20 日上是负的，中性化是机制的一部分。
- `null_control.excess_percentile` 用 `run_null_control(node_id)` 只给决赛候选算；`selection_statistics.deflated_sharpe_probability` 是冻结门此刻对该节点的读数，已按本臂的试验数 `trials` 打折。

没有候选证明边际时，不冻结是正当结果：以 `continue` 带证据交给下一个会话，或按 `families.md` 的终止规则以 `no_edge` 结束本臂。

## 禁止退回通用因子

本包的候选形态只有 `families.md` 登记的意外面及其变体；手写的价值/反转/动量/低波/彩票打分不得作为候选，只能以中性化列的身份出现；`c_growth`、`c_timing` 与任何机制无关对照不得被提名冻结。
