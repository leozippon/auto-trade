# 消融怎么做才算数：离线门、增益份额、覆盖度

自写笔记。本臂的全部内容是一次消融——同一份代码、同一条载体，只差特征矩阵最后那一块列。消融看起来是这个仓库里最简单的一种实验，实际上它有三个特有的失败模式，这一页把它们写死。

## 一、消融的第一条规则：差必须只有一处

`c_base` 与 `f1` 的差**只能是列集**。参数点、种子、轮数、早停、切分、隔离带、标签、股票池、重训节奏、席位、复核节奏、整手规则，全部逐字相同。起步包把这件事做成了结构上的保证：`lib/primary.py` 只有一个 `fit`，`lib/knobs.py` 里每个默认值只出现一次，`main.py` 的候选常量只改 `data.feature_names(candidate)` 返回哪几列。

**为什么这条要写成规则而不是习惯**：上一轮有一条臂的对照参数与候选不同（叶数从 31 调到 15），那是一次有理由的选择，但它的代价是那条臂后来所有的「候选减对照」都同时含着一个参数差。本臂承担不起这个代价——**它要量的差本来就很小**。

一个具体的坑：LightGBM 的 `feature_fraction = 0.8` 在列数从 158 变成 172 时，每棵树看到的列数也跟着变。这不是一个需要修的东西（两条腿的抽样比例相同，就是同一个机制），但它意味着**列数本身也是差的一部分**：加 14 列既加了信息也加了噪声维度。所以「`f1` 没赢」永远有两种读法，而分开它们的办法只有一个——**看增益份额**。

## 二、增益份额：一个必要条件，不是一个成绩

`block_gain_share` = 这一块列的 `gain` 重要性之和 ÷ 全部列的 `gain` 之和（`starter/lib/primary.py` 的 `gain_share`，每张买单都带着它，`fit` 时也写进 `state_dir`）。

**怎么读它：**

- **它的基准线是「按列数均分」**。14 列加在 158 列上，均分是 14/172 ≈ 8.1 %。读到明显低于这个数，说明树在同样的抽样机会下**主动少用**这一块；读到明显高于它，说明树在抢着用。
- **它低就一定没有增量；它高不代表有增量。**（本包起步包实测 15.0–15.1 %，落在「高」这一侧，所以这道门对本臂大概率不会命中——**这不是好消息，只是门没有挡住它**。） 树会给任何有方差的列分到一点增益，包括纯噪声列。这是 `families.md` 把 5 % 写成**门槛**而不是**目标**的理由：低于它就不必再花回放年，高于它只意味着可以花。
- **它必须和 Δ 一起判，不能替代 Δ。** 一块列可以拿到 15 % 的增益而把模型推向过拟合，也可以拿到 3 % 的增益却正好补上载体的盲区。两个量测的是不同的东西：份额测「模型用不用它」，Δ 测「用了之后书有没有更好」。
- **逐年报。** 某一年份额突然塌掉，多半是那一年这块的覆盖塌了，不是机制变了。

## 三、覆盖度：先读它，再读任何消融结论

一块列在训练窗口里大部分为空，会同时造成两件事，而回放里一件都不会报错：

1. **模型学到的是日期。** 缺失被填成一个常数（截面 z 分数把 NaN 归零），于是「这一列等于 0」就成了「这是 2023 年之前」的完美指示变量，而研究期内不同年份的收益分布本来就不同。这正是 `auction` 被连续四个包从特征里排除的理由（它 2025-01-16 才有精确数据，「把一条 90 % 以上训练日为空的通道喂进模型是一次隐蔽的时间标记」）。
2. **读数无法归因。** 消融的 Δ 变成「有这块数据的那几年 vs 没有的那几年」，而不是「有这块信息 vs 没有」。

所以 `families.md` 的 P5 要求**每一次验证都逐研究年报覆盖度**，第 0 轮的第一件事也是覆盖度普查而不是别的。起步包把这个数做成了买单元数据里的 `block_coverage`，不用另写脚本。

**两种「空」要分开处理，起步包也是这样做的：**

- **整段没有行**（数据集没被选进快照，或者已经到了该数据集的覆盖终点）：`lib/events.py` 在窗口里读不到任何可见行时**直接报错**。这不是一个可以继续的状态。
- **单日缺失**（这一天这只名字没有行）：按 NaN 进滚动窗口，窗口自己跳过它，最后由截面 z 分数归零。这是正常的稀疏。

**事件条件型的数据集是第三种情况**，本包不涉及但姊妹包涉及：一张表只在事件发生时才有行（涨跌停、龙虎榜），这时「没有行」是**最常见的真实观测**而不是缺失，正确的编码是显式的 0 加一列「这段时间里到底有没有过事件」的指示列，**而这时「非空占比」这个指标会恒等于 1、什么也说明不了**，要报的是「非零占比」。两种设计各自成立，但**不能混用**：把事件条件型的零当成缺失会扔掉大部分信号，把连续型的缺失当成零会伪造一个观测。

## 四、离线门能说什么

| 问题 | 离线能不能答 | 依据 |
|---|---|---|
| 这块列的排序与载体差多少 | **能** | 秩相关在锚定检查里逐位复现（spearman = 1.0） |
| 加上这块之后书变好还是变差（方向） | **能，但只当否决用** | 四条臂的 G-INC 全部在 0 回放年下算出；三次否决都被独立诊断证实是真零信息 |
| 好多少（Δ 的幅度） | **不能** | 同一条检查里 Δ 从离线 +5.54 pp/年 翻成实测 −0.63 pp/年 |
| 绝对水平（年化超额、IR） | **不能** | 离线重定价近似读 +2.18 %/年，同一本书的骨架面板读 +4.91；主动 IR 从 1.08 掉到 0.890 |

**离线面板系统性偏低且更宽松**：宿主走完整 Broker 重放（结算分红、按实际价格成交、现金不足会拒单），按候选自己的成交骨架换名；离线口径用未复权收盘价估值、不结算、不拒单。**真实裁决比离线严。**

一条推论：**离线读到 Δ 略正不要当成好消息**。它落在离线口径自己的误差里。真正可用的离线信号只有两个——Δ 明显为负（否决），以及增益份额明显偏低（否决）。

## 五、种子差是这个家族的噪声底

同一族的三个随机种子之间整窗读数相差**约 4 个百分点/年**，比通常要争的那点信息比率还大。所以：

- **Δ 小于种子差就不是 Δ。** `families.md` 把这一条写进了门的判定。
- **提名之前必须有两个种子的主动信息比率之差。** 比种子差还小的优势不是证据。
- 种子只改 `knobs.PARAMS["seed"]`，**对照与候选用同一个种子**：两条腿分别换种子跑出来的差里混着两份噪声。

## 六、一份消融结果笔记至少要有的六行

1. `c_base` 与 `f1` 的完整研究期主动读数，以及它们的差（整窗与逐年）。
2. 两条腿的 `block_gain_share`（`c_base` 恒为 0，这是一致性检查）与 `f1` 的逐年份额。
3. 逐研究年的块覆盖度。
4. ρ（选中集合重合度与分数秩相关），**标明它是诊断不是判据**。
5. 两个种子的主动 IR 之差。
6. 实测换手、按本臂资金重算的年成本、2 倍滑点下的超额。

缺任何一行，这次消融都不作为提名依据。
