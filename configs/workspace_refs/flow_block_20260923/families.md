# 候选、增量信息门 G-INC2、变体轴、已关闭家族与关闭规则

本文是本臂候选定义、包级要求、变体清单与关闭判据的**唯一权威表述**；`README.md` 与 `exploration-plan.md` 只指向本文，不复述。可见时点、单位与陷阱只写在 `pit-field-map.md`；算术与口径写在 `references/`，读数出处写在 `sources.md`。

本包有**一个必跑对照** `c_base`、**一个主候选** `f1` 和**一个诊断腿** `f_only`。三者在 `main.py` 里只差候选常量一行。

## 本轮的形状：在一个已确认的载体上加一块新信息

本轮四条臂共用同一个**载体**，因为它是本仓库唯一一条被宿主确认过、在这个池子上读出真实技能的分数：Alpha158 + LightGBM，沪深 300 成分，β 残差化的 10 日开盘到开盘秩标签，`state_dir` 续训、每第四次重训冷启动。上一轮它作必跑对照腿读到**主动超额 +4.30 %/年、主动 IR 0.4642、TE 9.26 %、β 0.851、3/4 年正**（同期零技能面板 +2.20 %/年）。它**低于冻结门 0.75**，所以它不是一条可以直接冻结的书；它是一把**有牙的量尺**。

本臂改的**只有特征矩阵的列**：载体的 158 列之后接上一块 14 列的带符号订单流。其余一切——标签、股票池、切分、轮数、种子、重训节奏、席位、复核节奏、整手规则——逐字相同。这就是消融臂的全部设计：**对照与候选是同一份代码**，差异只可能来自那 14 列。

## 新信息块：带符号订单流（14 列，`lib/flow.py`）

**假设。** Alpha158 读四条价格线、一条成交量和一条成交均价。它看得见**成交了多少**与**价格停在哪里**，看不见**哪一边在主动成交**。两个收盘、振幅与成交量完全相同的股票日在 158 个算子眼里一模一样，而它们的意图可以相反：一个是整个下午在向上吃单，另一个是在向买盘里派发。本块就是这个缺掉的符号，取自两个**方法不同因而会互相分歧**的来源。

| 组 | 列 | 来源与构造 |
|---|---|---|
| **水平** | `ofi_1`、`ofi_s`、`ofi_l`、`ofi_z`、`ofia_s` | `intraday_flow.ofi_1d` / `ofi_amt_1d`：本地由分钟 Bar 按相邻分钟收盘的 tick 规则算出的带符号失衡，除以全天合计，取值在 [−1, 1]。当日值、5 日与 20 日均值、相对 20 日自身的标准化偏离，以及成交额加权的 5 日均值 |
| **质量** | `ofi_std`、`zero_l` | 20 日失衡的标准差；20 日零成交分钟占比。这一组不是 alpha，是**这条通道当天可不可信** |
| **资金** | `mf_1`、`mf_s`、`mf_l`、`lg_share_l`、`elg_net_l` | `moneyflow` 的分档买卖金额：净流入对当日成交额、5 日与 20 日的比值，20 日大单与特大单占全部资金流的份额，20 日特大单净额对成交额 |
| **分歧** | `disagree_l`、`agree_s` | 两个来源的**截面秩之差**（20 日口径），以及 20 日内两者符号一致的天数占比 |

**为什么这两个来源的分歧是信息而不是噪声。** `intraday_flow` 是**微观结构**口径：它数的是分钟，按成交量或成交额加权，完全不知道一笔单子多大。`moneyflow` 是**订单规模**口径：它按每一笔成交的金额分档，完全不知道这笔成交发生在开盘还是尾盘。同一个「净买入」在两个口径下可以一个为正一个为负——一只被大单在尾盘一次性吃掉的票，tick 规则读到的是几乎整天的负失衡加最后几分钟的强正号，而资金流读到的是干净的特大单净流入。**这个差本身从来没有被任何一条臂算过。**

**两个来源各自作独立分数已经被关过，这一块不是重开它们。** 分钟 OFI 作独立排序分数关在 `order_flow_ranker_20260917`（截面 IC 活、组合尺度上没有多头腿），供应商 `moneyflow` 作主信号关在一条更早的线上（它现在是某个价量参考分数里的一个特征组）。**本臂问的不是「它们能不能自己选股」，而是「符号、它的持续性、以及两种测法之间的分歧，能不能给一条已经在读价格与成交量的分数添上它没有的东西」。** 这是一次消融，不是一次重开：`f_only` 那条腿存在的理由就是把这两个问题分开，而 `families.md` 禁止提名它。

**厂商变体资金流不在本块里，理由是实测覆盖。** 五个 `moneyflow_*` 变体在本轮研究期（2021-07..2025-06）里的覆盖是：`moneyflow_dc` 从 **2023-12-01** 起才有行（沪深 300 成分上逐年覆盖 0 / 0 / 0.63 / 1.00），`moneyflow_ths`、`moneyflow_ind_ths`、`moneyflow_cnt_ths` 从 **2025-01-02** 起（0 / 0 / 0 / 0.49）。把一条在训练窗口里一多半为空的列喂进 LightGBM，学到的是**日期**而不是资金流——这与 `auction` 被连续四个包拒绝的理由是同一条。所以「跨厂商分歧」在本包里由 `intraday_flow` 对 `moneyflow` 实现，两者在同一段研究期上实测覆盖 **99.9–100 %**。变体资金流留在变体轴 c 上，并且**只有在研究几何整体后移之后才允许打开**。

## 增量信息门 G-INC2（整期批次之前必须通过，**全离线，0 回放年**；筛过的候选配置各计一个 trial）

**登记的判据，一次写死：Δ 主动超额 ≤ 0，或本块的 LightGBM 增益份额 < 5 %，⇒ 这个形态不进整期验证。**

这道门与上一轮的 G-INC 有一处**关键区别**：上一轮门的第一项是 ρ（两条腿的秩相关或选中集合重合度），命中高 ρ 即否决。**本轮不以 ρ 判**——`c_base` 与 `f1` 共用 158 列基础特征，秩相关按构造就会很高，用它作判据等于用一个恒真的条件去否决。ρ 照常汇报，**只作诊断**。本轮的门是**消融**：同一份代码、同一批决策日、只差那 14 列，两条腿各自减去同一口径的零技能面板，比它们的主动超额。

| 量 | 怎么算 |
|---|---|
| **决策日** | 研究期**后两年**里至少 **60 个分散的决策日**（每两周取一天，或等间隔取满 60）。少于 60 天的读数不作判据 |
| **两条腿** | 每一天用起步包同一份代码，在同一成分截面上分别按 `c_base` 与 `f1` 的列集训练并打分，各取前 `SEATS` 只等额，持有到下一个信号日 |
| **Δ 主动超额** | **主动** = 前向收益减一个 **k = 20 的离线零技能面板**：每一份副本在**同一成分身份侧**（在册 / 不在册与候选一致）且这笔钱买得起一手的名字里随机换名，取 20 份日收益的等权均值。Δ = `f1` 的主动超额 − `c_base` 的主动超额 |
| **增益份额** | 同一批 `fit` 出来的 booster 上，14 列本块的 `gain` 重要性之和 ÷ 全部列的 `gain` 之和（`starter/lib/primary.py` 的 `gain_share`，每张买单都带着它）。**这是一个必要条件不是充分条件**：树会给任何有方差的列分一点增益 |
| **逐年符号一致性** | 把这 60 天按研究年分开，逐年报 Δ 的符号。**只有一年为正的 Δ 不是增量**；它与「哪一年的行情」不可区分 |
| **ρ（只报不判）** | 两条腿选中集合的 Jaccard 中位数，以及两条分数的逐日秩相关中位数。**预期很高**，因为基础特征共享。高 ρ 加正 Δ 是本臂最好的结果形态，不是矛盾 |
| **Δ 的判定** | Δ ≤ 0 即「没有增量」。Δ > 0 但**不超过两个随机种子之间的差**也按没有增量算（本家族的方向研究在三个种子之间散开过 4 pp/年） |

**这道门能说什么、不能说什么**（研究教训登记 §4，逐条适用）：

- **离线读数只有秩与消融方向是可信的，水平与 Δ 的幅度不可信。** `gnn_relation_1m_20260922` 的锚定检查里秩相关逐位复现（spearman = 1.0），而 Δ 从离线 +5.54 pp/年 翻到实测 −0.63 pp/年。所以本门读的是**符号与排序**，不是那个数值有多大；结果笔记里写 Δ 的数值时必须同时写这一句。
- **离线面板与宿主面板不是一回事。** 宿主走完整 Broker 重放（结算分红、按实际价格成交、现金不足会拒单），按候选自己的成交骨架换名；离线口径**系统性偏低且更宽松**（实测同一本书骨架面板读 +4.91 %/年，离线重定价近似只读 +2.18，主动 IR 从 1.08 掉到 0.890）。
- **门只能否决，永远不能证明边际。** 它说「不够格」时可信，说「够格」时只意味着可以花那些回放年。**裁决是宿主的整期批次，不是这道门。**
- **这道门不花回放年，但不是免费的。** 它筛过的每一个候选配置都计一个 trial：提交的在宿主验证时计，筛掉或暂缓的在下一批的 `offline_trials` 里申报（下文「两项登记」）；去膨胀 Sharpe 概率正是本仓库多数臂真正卡住的那堵墙。它省下的是回放年与一次给不出资格的子跨度回放，不是 trial。

命中判据时允许的去处只有轴 a（块的窗口）与轴 b（列集）各一轮，每一轮都重跑 G-INC2；仍不成立就以 `no_edge` 结束本臂，**不把本块单独做成一个排序分数去建书**。

> 头包的「子跨度验证只用来复测实现与耗时，不用来在候选之间做选择」**原样保留**：本臂不用子跨度回放做这道门，也不用它在候选之间选优。提名依据仍必须来自完整研究期验证。

## 对照与诊断腿

| 名称 | 定义 | 身份 | 用途 |
|---|---|---|---|
| `c_base` | 载体单独：158 列 Alpha158，同标签、同池、同切分、同轮数、同种子、同重训节奏、同席位与节奏 | **必跑对照（`control: true`），永远不得提名，永远是一批里的第一条腿** | 本臂命题的另一半；G-INC2 与整期消融的分母 |
| `f1` | `c_base` 的列集后面接上 14 列本块 | **主候选，可提名**（`control: false`） | 本臂的命题 |
| `f_only` | 只有 14 列本块，没有 Alpha158 | **诊断腿（`control: true`），永远不得提名** | 分开「这块自己有没有信息」与「它加不加得上」。它读到正的主动超额而 `f1` 读不到，说明信息与载体重叠；它读到零而 `f1` 读到正，说明增量来自交互——两种都要如实写进结果笔记 |

**两项登记（`batch_validate`）。** 冻结门的试验数是本臂验证过的非对照 revision（任何跨度）加上各批申报的 `offline_trials`，按这些试验的平均相关折成有效试验数；对照不是 trial、永远不能提名，但照常花回放年、计入完整研究期验证数；公式与阈值以运行事实 `acceptance_rules.freeze_gate` 为准（现行默认 `min_dsr_probability` 0.975），每行 `selection_statistics.information_ratio_bar` 是此刻过门需要的主动 IR。所以 `c_base` 与 `f_only` 永远写 `control: true`，`f1` 与它的变体写 `control: false`；`offline_trials` = 本批申报前离线（研究期数据）筛过、读数影响了本批提交什么、但本批**没有**提交的候选配置数；提交进本批的候选在宿主验证时按 host trial 计，不重复申报；对照永不计；每个配置只在筛过之后的第一批申报一次；没有筛过任何候选配置才填 0。（`f1` 过门并提交时第一批申报 0）本包其余文件里「计 N 个 trial」「0 trial」的说法以这里为准。在跑的 20260923 臂用的是本包早先的副本与旧代码，按旧口径（对照也计 trial、√V 取本臂完整期 IR 的样本标准差、DSR 阈值 0.90）运行，不受这里影响；这里写的是从本包新建的臂。

## 已关闭的方向（研究教训登记 §2 的表，本轮扩充）

| 方向 / 家族 | 关闭它的臂（资金 / 授权） | 关键读数 |
|---|---|---|
| 日频价量算子堆作**主方向**（Alpha158/360、WQ101、GTJA191、反转、动量、换手、Amihud、彩票、隔夜拆分） | 多条臂，旧口径 | 中性化超额 +9.6…+13.6 %/年、IR 0.83–1.21；**本臂只把它当载体与对照，不当主方向** |
| Alpha158 + LightGBM 作**主方向**（现行口径） | `alpha158_lgbm_20260921`（10 万 / 无，冻结后丢弃） | 前推原始超额 +5.22 %/年，按池面板重读主动 IR **−0.30**——赢的是池不是模型 |

## 提名条件（冻结前逐条满足）

1. G-INC2 已通过，且 Δ、增益份额、逐年符号与（只作诊断的）ρ 都写进结果笔记。
2. 完整研究期验证完成，冻结门按运行事实通过；**至少 2 次完整研究期验证**（运行事实 `min_full_span_validations`）。
3. **稳定性**：逐年分块的**主动**超额为正的研究年 ≥ 四分之三（四个研究年时 ≥ 3）。
4. **`c_base` 同批**，且候选在整窗与至少 3 个研究年上主动读数都不低于它。**这是本臂的核心条件**：赢不了不带这块的自己，就没有这条臂。
5. **两个种子**：至少两个种子的主动信息比率之差已汇报；比种子差还小的优势不是证据。
6. P2 / P3 / P4 / P5 全部成立。
7. **集中度与换手**：`pnl_concentration.top5_share_of_gross_gains` ≤ 0.5；年换手 ≤ 12 倍（上一轮同谱系在周度复核下实测 14.2×/年 越线，本轮改月度正是为此）。
8. **实现底线**：`phase_seconds` 里单次 `fit` ≤ 1,800 秒；容器内存峰值**明显低于 16 GiB**；单次复核决策 < 60 秒；意图买单拒单率 ≤ 30 %；**座位填满率**与买不起份额逐次汇报。不成立先修实现再复测，不算证伪。
9. **持久化已被单独定价**：轴 f 的全冷启动消融已在同批或前一轮跑过，两者的主动读数差写进结果笔记。

主动超额 ≤ 0、空对照分位在 0.5 附近、去膨胀 Sharpe 概率接近 0 都是普通「没有边际」读数：候选不可提名，不触发家族关闭。

## 什么会杀死它（按命中即停）

1. **G-INC2 在 `f1`、轴 a 与轴 b 各一轮之后仍然命中** —— 这块没有增量信息。本臂以 `no_edge` 结束。
2. 连续两轮完整研究期验证里 `f1` 都赢不了同批的 `c_base` —— 以 `no_edge` 结束。
3. 主动超额为负的研究年连续两轮都过半 —— 关闭。
4. 每一个可行席数上 `excess_at_2x_slippage` 都 ≤ 0 —— 机制可能真实但在这个账户上不可交易，先走轴 e 的另一端一轮，仍不成立即以「不可交易」关闭。
5. **为了追读数把复核节奏改回周度** —— 这不是一个结果，是一次违规。月度复核是本轮登记的构造选择；10 日标签配月度复核的错配是本臂已知且已写明的风险（`README.md`），**要改它必须先在结果笔记里把换手与成本重算一遍并重写 `hypothesis`**，不能顺手改一行常量。
6. P2 在所有已登记构造下都不成立 —— 关闭并写明是哪个行业带上去的。
7. 提名条件 8 修复一次后仍不成立 —— 该变体放弃，不算家族证伪。

## 臂级终止规则

任一成立即本臂关闭：上面第 1、2、3 条命中；预算用尽前没有可提名候选。关闭以 `finish_session(outcome="no_edge")` 携读数结束本臂，**不换家族**，不把 `c_base` 或 `f_only` 改作候选。`no_edge` 是结论不是退路：只有在没有还有先验的变体轴可换、或预算已经花完时才用它，不要让预算耗尽（流水线记 `deadline`）代替这个结论，也不要为了有一个交付而冻结一个不满足条件的候选。
