# Fold-ready 探索计划

一折跑多轮 `batch_validate`，轮与轮之间互不重叠：第一轮只比选股腿，第二轮只比合成与状态层。每一步都要产出可执行候选或明确淘汰。有父本时，必须先完成一次与父本可执行逻辑不同的完整 Validation；父本对照由宿主在会话前跑好，不要自己重跑。

## 普查先行

在跑任何回测之前，先用 `shell` 在决策视图上把下面几件事做完并写进工作区笔记。普查只看输入窗，绝不碰验证区间。

1. 读本轮 `data_summary.json`、`unit_reference.json` 与 daily/fundamentals/macro 的 schema 与可见日期。逐个确认 `families.md` 用到的字段存在、单位是什么、在输入窗里覆盖多少股票：`pe_ttm`、`pb`、`dv_ttm`、`dv_ratio`、`total_mv`、`circ_mv` 在 `daily`；`roe`、`debt_to_assets`、`eps` 在 `fina_indicator_vip`；`div_proc`、`cash_div_tax`、`imp_ann_date` 在 `dividend`。缺字段的家族直接记「不可测」，不要用替代字段冒充。
2. 确认 `fut_daily`/`fut_mapping`/`fut_basic`/`opt_daily`/`opt_basic` 在本折 macro 域非空，且 IM 与 `OP000852.SH` 的覆盖起点（均为 2022-07-22）落在输入窗之内。不满足时家族 5 只用 IC、家族 6 只用 `OP000300.SH`，并把降级写进 `hypothesis`。
3. 状态层的功率普查（决定家族 5、6 跑不跑）：先在输入窗上把 `b_adj` 与 `q` 整条算出来，数一下若把同一规则搬到本折验证区间会触发多少天、多少段。触发日少于 20 个交易日或多于 60%、独立段少于 3 段时，本折记「不可测」并跳过家族 5、6，把预算全部留给选股腿——这是本包最容易白跑的一轮。
4. 离线预筛（不占回测预算）：用 `python /mnt/tools/screen.py --help` 所述的脚本，对四条选股腿算 20/60 日持有期的 rank IC、ICIR、逐月符号一致性、规模中性 IC、头部分位多头超额、换手与覆盖。慢因子的单期 IC 本来就小，判据是规模中性 IC 的符号在多数月份一致、20 日到 60 日之间不塌，且覆盖 ≥ 60%；不达标的腿直接淘汰并记录理由。

## 不变量

固定并写进工作区笔记，这些是声明值不是拟合参数：宇宙 `U`（见 `families.md` 公共约定）、篮子 30 只等权、持有 60 个交易日、每 15 个交易日换分数最差的 1/4、费用缓冲 3%、`REFIT_PERIOD="quarter"`、状态基准窗 `W=min(250, 可见观测数)`、状态阈值 20% 分位。任何一项要改，改动本身就是一个候选，与原配置同批比较。

## 轮次

1. 第一轮：四条选股腿并列，各自附机制无关对照。候选是 EP(a)、EP(b)、股息率（含派现一致性过滤）、BP+质量，加上同 `U` 同持有期的等权篮子作为共同对照。`hypothesis` 写清方向、持有期、篮子规则、对照与否证条件。这一轮不碰复合，也不碰状态层。
2. 第二轮：合成与状态层，与第一轮胜者同批。等权复合、收缩复合、基差切换、期权偏度切换，每个候选只相对第一轮胜者改一件事。状态类候选必须带伪门控对照，否则整批无效。
3. 家族切换而不是参数邻域。第一轮四条腿的中性化超额都 ≤ 0 时，不要在第二轮继续调价值腿的截尾分位、持有期或篮子大小——那只是刷候选数。直接切到状态层，把它当作「同一等权篮子的条件化」来测，并把价值腿被证伪的结论写进笔记；状态层也判「不可测」时，以 `finish_fold(outcome="no_edge", reason=...)` 弃权，并留下下一折的不同假说。
4. 多重检验纪律：本折全部候选数事先写在 `TODO.md` 里（建议选股腿 ≤ 6、合成 ≤ 3、状态 ≤ 3），每加一个候选就是多一次试验；读 Sharpe 时按 `candidates_evaluated` 打折。
5. 每个候选按 README 的「没有边际」清单读，四个季度子窗分别报相对对照的超额、有效覆盖、换手、拒单、欠配现金比例、行业与规模集中度；状态类候选另报触发日数与独立段数。
6. 用 `step_rollback` 把胜出节点恢复到 `output/` 再 `finish_fold`。

## 新季度裁决

`sub_windows` 的最后一行是本折唯一真正的样本外季度，父本对照也只在这一段上是样本外。裁决顺序固定：先看新季度的相对父本超额，再看四个子窗的符号一致性，最后才看整窗。新季度为负而候选没有转正的，不提名；整窗好看但新季度为负的候选，写进笔记作为「风格在本折末尾翻转」的证据，不作为提名理由。

## 组合纪律

- 家族可分离：一次 Validation 只改一个家族或一次合成。
- `ep` 与 `dy` 的截面 Spearman 实测 0.681，两者不得作为两个独立成分进等权复合，只能先合成「盈利/派现」一类再与其他类等权。
- 复合权重只在 `fit(context)` 里拟合，且必须向等权收缩；不在 `generate_orders` 里重新拟合任何权重，也不在 Validation 结果上调 λ 或收缩系数。
- 不用通用快因子（反转、动量、低波、换手、成长）凑候选数。

## Validation 否证

- 任何 `available_at`、T-1、复权锚或财务版本错误：结果无效，不讨论收益。
- 用未实现的收益拟合复合权重（标签窗越过推断时点，或训练与验证之间没有 60 日禁运）：结果无效。
- 中性化后优势消失：否证「独立 alpha」。本包的规模风险是大盘方向——`style_analysis.json` 显示规模倾斜显著为正且中性化超额塌掉时，判定为「买了银行和大盘低波」，与前几轮的小市值暴露同样淘汰。
- 四个季度子窗同号少于三个，或收益只来自单个极端日期、少数个股或单一行业。
- 加手续费、滑点、涨跌停和手数约束后优势消失，或 2 倍滑点下超额转负。60 日持有的年成本拖累约 1.4–1.8%，超额必须显著大于它。
- 状态类候选：触发日数或独立段数不达标；或伪门控与真门控无法区分；或家族 5 与家族 6 的两个状态读数给出相反结论——最后一种情况两条一起淘汰，不挑好的那条（家族 5 内部 IC 与 IM 不一致时以 IM 为准，见 `families.md`）。
- 合成不优于最佳单腿，或收缩版不优于等权版：回退到更简单的那个。

## 失效模式（贯穿全折）

- 风格择时：12 个月验证窗可能整段落在一个风格里（2022–2023 的价值负年，2024 的红利大年）。整窗汇总不作论据，四个季度子窗才是。
- 与规模/低波共线：EP 与 `log(circ_mv)` 的截面 Spearman 实测 +0.248、`dv_ttm` +0.149、BP −0.036。EP 与股息率天然偏大盘、偏低波，不中性化的超额几乎一定是暴露；BP 几乎与规模正交，中性化前后的差别本身就是可读的证据。
- 分红季（4–6 月）：`dv_ttm` 的单日跳变与基差的季节性都集中在这几个月（IC 月度均值从 1 月 −3.9% 走到 4 月 −8.3%，IM 从 −7.0% 走到 −11.4%）。同一个子窗会同时被两件事污染，判读时把 Q2 单独拎出来看。
- 状态段太少：家族 5 的底部五分位在 2023 年整年零触发、在 2025 年超过半数交易日触发。去膨胀 Sharpe 会诚实地惩罚这种候选，不要用邻域阈值把它救回来。
