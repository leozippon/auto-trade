# 研究会话探索计划

目标：在本臂唯一的研究会话里，在**本臂自己的账户与授权之下**，把本臂指令点名的那个预登记方向做成一本站得住的书，或者证伪后换 `families.md` 里下一个预登记方向；都没有了再以 `no_edge` 结束。判据只在 `families.md`，数据与单位只在 `pit-field-map.md`，本文只排顺序与预算。

**开局方向以本臂指令为准**，四个预登记方向与对应的 `BOOK` 只在 `families.md`。一半 10 万、一半 100 万；`cma_overlay` / `cashdiv_pool` 是创新性探索，证伪条件必须在进回放之前写进 `hypothesis`（`cma_overlay` 的证伪已经写死：与已关质量书的投资柱秩相关 > 0.85 且主动 IR 同档）。起步包用 `BOOK` 切换四种形状，改常量即可，不要从空白重写读法。21c 已关的质量三柱、52 周高比、percent accrual，以及此前全部禁令，禁止重开。`lottery_reverse` / `rmax_overlay` / `net_issuance` 仍在跑，不要另开一条同方向。

**本臂最大的风险不是门太严，而是把回放预算花在筛选上，或把研究期主动 IR 当成毕业。** 账户一旦读出来，可行的形状就被算术收窄了一大半；筛选在离线做，回放只用来确认。研究期主动 IR 过 1 的冻结书已经在共享前推窗上被 F2 杀掉过。

## 第 0 轮：不占回放预算的普查与离线筛选

用 `shell` 在研究期末的决策视图上跑，不启动回放。任一条不合格就在第 1 轮的 `hypothesis` 里声明，不要硬凑。

1. **运行事实核对（最先做的一件事）**：本臂的 `broker_replay.initial_cash` 是多少；`acceptance_rules` 里有没有跟踪授权，上限与区间各是多少；两个回撤上限；`budgets` 与 `max_replay_years`。**这四件事决定后面每一步**，不要从包里或别的臂去推。
2. **账户算术表（直接对着 P3）**：用本臂的资金，在若干个候选座位数上算——座位金额、买得起的价格上限、池里买得起的名字占多少、5 元最低佣金的 bp/边、一次往返总成本、按预期换手算的年成本、以及在当前 `cost_stress_multiplier` 下 α 要付掉多少。**这张表决定本臂真正可行的座位区间，必须在第 1 轮之前有**（公式在 `references/capital-arithmetic.md`）。
3. **股票池普查，按研究年分别列**（跨决策日比较行业名单是错的）：可交易名字数、按买得起筛完剩多少、申万一级行业个数、最薄名字的 20 日均成交额、流通市值与价格的分布。带授权时另加：成分只数、权重求和、科创板剔掉几只与多少指数权重、书能覆盖多少指数权重。
4. **零技能的形状读数**：本臂打算用的池与座位数上，等权（或计划的权重方案）零技能能拿到什么——`references/zero-skill-panel.md` 给了几种已量过的形状，本臂的形状如果不在表上，就自己在离线截面上算一遍。**地板在哪里要先知道，否则第一批的读数没法解释。**
5. **离线筛选，先做本臂指令点名的那个方向。** 写一句话的经济解释（`families.md`「一个方向算什么」），再用同一个函数构建历史截面读组合尺度的读数。10 万侧两条开局（`noa_index` / `cashdiv_pool`）必须先按主动回撤 30% 预筛。创新性探索还要先读与已关闭家族的逐日秩相关：`cma_overlay` 对已关质量书的投资柱，`cashdiv_pool` 对盈利收益率与 OCF 收益率。下面这张表是进入回放的前置条件，缺一格就不进回放：

   | 读数 | 口径 |
   |---|---|
   | 最好 N 只相对**同池等权**的前向收益 | 在可行座位区间的两端各读一次，与复核节奏同长，**按研究年分开**。基准是同池等权（零技能的近似），不是零 |
   | 成本线 | 按复核节奏与换名数、用本臂自己的资金算出来的年成本，从上一行里扣掉 |
   | 跟踪误差与回撤的先验 | 两端各一个。带授权时这一格是硬前置：先验跟踪误差已经超过上限的方向不进回放 |
   | **敞口先验** | 篮子里最大的单一申万一级行业占多少只、占多少权重。整窗集中度先验超过 0.30 的方向要么改构造，要么不进回放 |
   | 单腿与合成分开读 | 合成方向必做 |
   | 与已关闭家族的逐日秩相关 | 相关度高说明它不是新信息。`cma_overlay` 这一格对着开局表的证伪条件 |

   筛子类方向的同一张表要读两遍——筛与不筛；构造类方向读成形与不成形。扣掉成本线后不高于同池等权、只在一个研究年里为正、或两端方向相反且说不出理由的方向，不进入回放。
6. **起步包跑一次 `smoke_backtest`**，读每次决策的秒数、订单、拒单、实际权重、仓位、β 与跟踪误差。本包起步包尚未在本包下做过沙箱计时；同类规则型、同域读取的上一包实测每次决策 0.26–1.04 秒、峰值 1.3 GiB 以内，只作预算量级参考。

## 第 1 轮：一次完整研究期 `batch_validate`

主候选是本臂指令点名的那个预登记方向，座位数取第 0 轮第 2 条算出来可行的那一端（`noa_index` 与 `cashdiv_pool` 钉 12 席）。**不要再加零技能对照腿**——宿主每次正式验证都会抽面板，主动读数直接出现在结果行里。**要加的是机制归因对照**：同一份代码去掉被声称的那一个机制、其余逐字相同。带授权的权重方案还必须满足 P5：同批跑同一分数等额；overlay 方向再加一条纯基准权重。一批里几条腿，由预算与要分离的机制数决定。近满仓 overlay 的第一件读数是仓位、β、跟踪误差，不是主动 IR。

`hypothesis` 必须写清：方向的经济解释与**证伪条件**、座位数、复核节奏、保留带与换名上限、预期的主动信息比率与逐年符号、以及 P2/P3 的判定规则。

一次三候选的完整研究期验证在四个研究年时花 12 个回放年。预算按臂计（以运行事实 `budgets` 为准）。回放一旦开跑就计入预算，策略自身抛错的候选照样花掉，环境失败的候选退还。某一路因环境原因失败时不重跑、不压缩对照：把读数与待裁决的分支写进结果笔记。

第 1 轮之后，对领先的完整研究期节点跑一次 `run_null_control`：不花回放年，会话时钟在它运行期间暂停。**它是诊断不是判据**——它比的是原始超额、按流通市值分位配替身，和裁决用的那个面板不是一回事；三个数一起报。

## 判定分支，逐条写死（判据本身见 `families.md`）

- **主动信息比率远低于预登记的目标** → 这个方向在本账户上没有可辨识的技能。换离线筛选里第二强的方向，不要先去调阈值。
- **绝对超额高而主动超额低** → 赢的是股票池不是选名。看 `benchmark.panel_neutralized_excess`：它就是零技能在这本书的形状上拿到的那部分。改池或改权重方案不会解决它，只会换一个零技能地板。
- **逐年主动超额有负年** → 先看是哪一年、是不是那一年的行情，再决定走哪一轴。两轮都有多数负年即关闭这个方向。
- **P2（行业集中度）不成立** → 先看是哪一个行业、哪一条腿把它带上去的，再走轴 f（构造）；**不要**把它解释成「池子本来就这样」。两轮都不成立即按关闭条件 4 关掉这个方向。
- **P3（成本）在每个可行座位数上都不成立** → 先走轴 c 的另一端一轮；仍不成立即以「不可交易」关闭。第 0 轮第 2 条就应该给出预判。
- **带授权而跟踪误差或 β 出界** → 先看仓位：跟踪书必须接近满仓、β 留余量。再看权重方案：等权在任何座位数上都有 4.48 %/年 的底，要压到 4–6 % 得靠按指数权重倾斜（`references/zero-skill-panel.md`）。两轮压不进即按关闭条件 5 换方向。
- **`cma_overlay` 与已关质量书投资柱秩相关 > 0.85 且主动 IR 同档** → 按开局表证伪，关这个方向。
- **主动信息比率只差一点、其余都过** → 走轴 d（权重方案）或轴 e（节奏），一轮一个。
- **活动量不足或平均仓位偏低** → 放宽保留带或换名上限，只在这一条不成立时开。
- **实现读数不对**（座位没填满、实际权重离目标太远、拒单率高） → 先修实现再复测。

## 第 2 轮起：一次只改一个可分离组件

按 `families.md` 的变体轴取，每轮一个，与当轮基准同批比较。一个方向在两轮里都没有满足条件的候选就关闭它，**换下一个预登记方向而不是换阈值**——新方向不限于第 0 轮筛过的那三个，照样先离线筛选、再进回放。不要换到禁止重开表，也不要另开仍在跑的同方向。子跨度验证（一个研究年，每个候选 1 个回放年）只用来复测实现与耗时，不用来在候选之间做选择。

## 收官轮

只做两件事之一：对已经满足全部条件的最好候选补齐缺的读数并冻结；或者以 `finish_session(outcome="no_edge")` 携读数结束本臂。**收官轮只在没有方向可换、或预算见底时才开始**；预算见底时不开新方向，也不要让预算耗尽（流水线记 `deadline`）代替这个结论。

## 计算预算

- 起步包形态（规则型、不训练；overlay 与指数内书月度，与成分截面同频）：本包尚未自测墙钟。同类规则型、同域读取的上一包实测每次决策 0.26–1.04 秒、容器峰值 1.3 GiB 以内，一个完整研究年的回放在两分钟量级，整期在十分钟量级。以本臂自己的 `smoke_backtest` 为准。
- 学习型候选：容器按 **8 核 / 8 GiB** 算，线程数写死在 8 以内，一次 `fit` 的墙钟控制在 10 分钟量级、峰值内存**明显低于 8 GiB**；整期批次之前先在研究期靠后的槽上量一次（`references/fit-cost.md`）。本臂 `gpu_count = 0`。
- 读取：每次读取都带 `columns=`、`filters=` 与日期窗口；成分截面读 120 个自然日，日线读到最长算子喂得满为止；非复核日在确认最新可见交易日之后直接返回 `[]`；不引入跨调用缓存，冷 worker 与热 worker 出单一致。
- 单日探针的秒数对宿主负载极敏感（同一条腿轻载与重载可以差三四倍），耗时结论按多日回放的**平均**读。

## 每个候选必须汇报的读数

除标准结果块外，写进结果笔记：经济解释与证伪条件；**主动中性化超额、主动跟踪误差、主动信息比率**与**面板自己的中性化超额**；逐年分块的主动超额与原始超额；`top_industry_weight`、`size_tilt` 与 `size_beta` 并排；机制归因对照的同批读数；单腿读数（合成时）；换手、平均每年完成的回合数、**按本臂 `initial_cash` 重算的佣金账**与 2 倍滑点下的超额；拒单率与原因；平均总仓位；`pnl_concentration`；空对照的三个数；一次决策的实测平均墙钟。**以及账户面的四项**：(1) 每次复核的买不起份额与整期均值；(2) 每次复核座位填满没有，没填满时如实报缺几个与原因；(3) 实际权重对目标权重的偏离；(4) 带授权时书覆盖的指数权重与被剔除掉的指数权重。缺任何一项的结果不作为提名依据。

## Validation 否证（任何一条命中，结果无效，不讨论收益）

- 股票池不是按时点读出来的：硬编码名单、或用别的指数建书而仍按沪深 300 报跟踪误差。
- 用 `ann_date`/`trade_date` 而不是 `available_at` 判可见；把成分截面的日期当作调整生效日；`weight` 当成小数没有 ÷ 100。
- 成分的 `con_code` 没有改名就去 join，得到一张空表却按「池太小」处理。
- 买不起的**持仓**被当成离池强卖；或者买单向下取整而不是按最近整手四舍五入。
- 机制归因对照没有同批跑，或与候选用了不同的读法、不同的复核日历、不同的整手规则。
- as-of 域读失败后回退了 `snapshot_dir`；读多数据集的域时没有先按 `dataset` 过滤；任何读取不带日期窗口。
- 复核节奏依赖模块级计数器或跨调用缓存。
- 没有第 0 轮的账户算术表与逐研究年离线读数就开了回放。
- 把 `size_tilt` 当成中性化回归的规模载荷来论证，或者在 `stats.benchmark` 缺字段时仍然按「大概达标」提名。
- 用绝对中性化超额或绝对信息比率去论证边际，而不看主动读数与面板。
- 把质量三柱、52 周高比或 percent accrual 再做成可开的书。
- `cma_overlay` 叠了盈利或应计，或 `cashdiv_pool` 做成了盈利收益率 / OCF 收益率。

## 收尾

冻结的是提名节点自己的不可变快照，提名前不必把它恢复到 `output/`。不要提交离线普查脚本；`models/` 只放静态资产。
