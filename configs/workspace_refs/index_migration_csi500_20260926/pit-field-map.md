# 本轮数据与 08:30 字段图

本文是本包可用数据、可见时点、单位与陷阱的**唯一权威表述**。数据集清单、行数、日期覆盖与单位以本轮 `data_summary.json`、snapshot manifest 与 `unit_reference.json` 为准：先核对它们，再写阈值；`snapshot` view 与回放 view 分别核对，不得由前者推断后者。

**开工第一件事**：核对四件事——`macro.datasets` 里有 `index_weight`，而且**中证 500（`000905.SH`）与沪深 300（`000300.SH`）两只指数的截面都在**（前者是池，后者是纳入规则的在位名单）；`daily` 带 `amount`、`total_mv`、`close`、`is_suspended`；`universe` 带 `list_date`、`name`、`l1_name`；实验事实里的 **`benchmark_index`** 与 `lib/knobs.py` 的 `INDEX` 一致。缺任何一块都不得静默回退到别的池、别的指数或别的规模口径——那是另一个登记。起步包读不到可见截面时直接报错。

## 本臂的数据集选择（创建参数）

与 `fresh_book_1m_20260925` 完全相同：20260919 轮的四个域列表（`macro` 里含 `index_weight`），种子 `data/pit_views_seed_research_20260919`，`include_intraday` False。**本臂只读 `daily`、`universe` 与 `macro.index_weight`**，不读基本面、事件、文本与 `index_daily`。

## 每个回放年自己的输入窗（运行事实 `research_geometry.years[].input_window`）

每个研究年的回放从它自己的决策视图起步，那张视图从该年开始前一天往回 60 个月；会话挂的 `/mnt/snapshot` 是研究期末那一张。

| 视图 | 日线输入窗 | `index_weight` 最早的截面 | 对本臂意味着什么 |
|---|---|---|---|
| Y1 回放（2021-07..2022-06） | 20160701..20210630 | 2020-01（数据湖的下限） | 纳入规则只要一年窗口与当时的两张截面，第一个决策日就完整 |
| Y2 / Y3 / Y4 回放 | 20170701.. / 20180701.. / 20190701..（各到该年开始前一天） | 2020-01 | 同上 |
| `/mnt/snapshot`（研究期末） | 20200701..20250630 | 2020-07-31 | 研究期每个决策日的一年窗口都完整，K0 与 S1–S4 可以在它上面原样重算（`refs/references/offline-screen.md`） |

## 成分截面 `macro.index_weight`（两只指数）

```text
sec = pd.read_parquet(
    context.asof_dir + "/macro",
    columns=["dataset", "available_at", "index_code", "con_code", "trade_date", "weight"],
    filters=[("dataset", "=", "index_weight"), ("index_code", "=", code), ("trade_date", ">=", start)],
)
```

| 事项 | 规则 |
|---|---|
| 键 | 指数在 `index_code`，成分在 **`con_code`**（`ts_code` 为空）；跨域 join 要自己改名。`index_daily` 恰好相反（指数在 `ts_code`、`index_code` 全空），本包不读它 |
| 频率 | 每指数每月一张，日期是当月最后一个交易日；研究期末视图 2020-07..2025-06 共 60 张、每张中证 500 恒为 500 只、沪深 300 恒为 300 只 |
| 可见性 | 行级 `available_at` = 截面日 17:30（`contract_1730_from:trade_date`），所以 08:30 的决策读到的是**日期早于决策日**的最新一张 |
| **定期调整何时变得可见** | 沪深 300 与中证 500 同一天生效：6 月、12 月第二个星期五的下一交易日。公告在生效前约两周（5 月、11 月下旬），**但数据里没有公告**；调整后的名单只出现在生效当月的月末截面里，那一张在生效之后约两周才可见。于是生效日到月末之间，书读到的仍是上一张截面：已经升入沪深 300 的名字还在中证 500 的名单里，下个月首个决策日才被强卖 |
| **绝不读未来截面** | 回放容器里的 as-of 视图只含可见行，策略按 `available_at` 过滤、取日期早于决策日的最新一张，结构上读不到未来截面；**危险在离线重建**：`/mnt/snapshot` 含到 2025-06-30 的全部截面，给历史决策日取成分、取在位名单时必须只用日期早于该决策日的截面，拿生效当月月末那张去标注月初的决策就是前视 |
| `weight` | 百分数，一张截面求和 100 ± 0.05；本包只用成员资格与覆盖度报告，不进分数也不进权重 |
| 回填 | 供应商每个开市日重取当年分区，改写的权重带着原来的 `available_at` 进入历史快照；成员资格很少受影响，幅度没有量化过 |

## 本臂要读的列

| 域 | 列 | 单位 | 可见 | 用途 |
|---|---|---|---|---|
| `daily` | `amount` | 元（已从原始湖的千元归一） | 无列，最新一行 = T-1（`daily` 17:30 盖章） | 纳入规则的流动性（日均成交额） |
| `daily` | `total_mv` | 元（已从原始湖的万元归一） | 同上（来自 `daily_basic`，18:00 盖章，T+1 可用） | 纳入规则的规模（日均总市值） |
| `daily` | `close`、`is_suspended` | 元/股未复权；布尔 | 同上 | 池（T-1 有行且未停牌）、买单定价 |
| `macro.index_weight` | `index_code`、`con_code`、`trade_date`、`weight` | 百分数 | 行级，17:30 | 池（中证 500）、在位名单（沪深 300）、覆盖度 |
| `universe` | `list_date`、`name`、`l1_name` | — | 无列，整表按回放槽锚点口径 | 上市时长、ST/退、P2 |

排名只用相对大小，单位不影响分数；但任何阈值都要按上表换算，不要把 `total_mv` 当万元。

## 读法与可见性（通则）

- `asof_dir` 下每个域是 parquet parts 目录（传目录名，不加 `.parquet`），`snapshot_dir` 下是平铺文件；读失败**不得**回退 `snapshot_dir`。
- `daily` 与 `universe` 没有 `available_at` 列：as-of 视图只含决策时刻可见的行，最新一行就是 T-1。`index_weight` 判可见只看它自己的 `available_at`（`pd.to_datetime(..., utc=True)` 后与 `context.inference_at` 比）。
- 起步包每次读取都带 `columns=`、`filters=` 与日期窗口；纳入规则一次读全部 A 股一年的两列（约 120 万行），只在复核日与补座日读。
- `universe` 的名称与 ST 状态是回放槽锚点那一天的：年中新戴帽的名字要到下一个回放年才被剔出样本空间。`l1_name` 按决策日取，2021-12-13 从 SW2014 切到 SW2021。

## `/mnt/snapshot` 只有一个时点口径

研究期末那一天的视图：`universe` 的名称、ST 与行业都是 2025-06-30 的，离线重建历史决策时这是一处已接受的偏差（ST 灌回过去）；日线与截面都按日期取，取法见 `refs/references/offline-screen.md`。包作者用它与各研究年自己的视图各重建过一次，逐项结果在 `refs/sources.md`。

## 陷阱

- **拿研究期末的截面标注历史决策日**（见上表「绝不读未来截面」）。
- **把中证 500 当作沪深 300 纳入者的来源**：K0 量出，每次审核的 7–28 只纳入者里只有 3–9 只预判日在中证 500 里（其中可交易的 2–7 只），其余 4–23 只几乎全部按日均总市值早已进了全样本前 300，而中证 500 的编制先剔除总市值前 300（`refs/references/migration-rule.md`）。
- **成分的代码列是 `con_code`**；`index_daily` 的指数在 `ts_code`。
- **`is_suspended` 只标盘中临停**，整天停牌的名字在 `daily` 里常常没有行；起步包用「T-1 有行且未停牌」判断可交易。
- **一手与整手**：100 万元 30 席上座位约 32,000 元，中证 500 可交易成分里一手买不起的通常只有 0–1 %；买不起只影响买入，已持有的名字不得因此强卖；买单按最近整手四舍五入再按现金截断。
- **科创板一手 200 股**，起步包把 688/689 剔出池（2024-06-28 那张截面上是 53 只、8.22 个百分点的指数权重，`refs/references/index-membership.md`）；它们仍然参与纳入规则的排名（它们与别的名字争沪深 300 的名额）。
- **印花税在研究期内切换**（卖出 10 bp → 5 bp，2023-08-28）。
- **复核节奏不得依赖模块级计数器或跨调用缓存**：到期判断拿最新可见交易日与决策日比自然月；`c_shuf` 的打乱只用决策日做种子。
