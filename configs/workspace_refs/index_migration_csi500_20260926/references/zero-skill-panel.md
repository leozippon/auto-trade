# 裁决口径：零技能面板、本池的地板与 `c_shuf` 怎么读

自写笔记。口径的权威在运行事实 `acceptance_rules.graded_series` 与 Pipeline 设计 §2.3；这里只写本臂读它时要记住的几件事。

## 被评的是主动序列

每次正式验证结束后，宿主按候选自己的**成交骨架**（同样的进出时点、每笔同样的钱、同一 Broker 与成本）随机换名重放 20 份，取日收益等权均值作为面板 `p_t`；换名规则是「与原名字同在或同不在中证 500 成分内（读早于进场日的最近一张截面），且这笔钱买得起一手」。被评的是 `a_t = r_t − p_t`：结果里读 `benchmark.active_neutralized_excess` / `active_tracking_error` / `active_information_ratio`，面板自己的是 `benchmark.panel_neutralized_excess`。中性化只回归基准与规模价差，看不见行业（P2 补这块盲区）。

对本臂的两个直接后果：

- **面板对齐池、日历、每笔的钱与成本**，所以 `m1` 与 `c_shuf` 的换手差（约 2 对约 20 倍/年，`capital-arithmetic.md`）不会让主动读数偏向哪一边：各自的面板付各自的成本。
- **书离开中证 500 之后仍持有到下一个复核日的那几天**（升入沪深 300 的名字，生效日到月初），面板那一侧的替身在进场日按「同在中证 500」抽，所以这几天被正常评分，不是豁免。

## 本池的地板（登记册与本包的读数）

- 同池、同账户、50 席月度等额书上，宿主面板自己的中性化超额读 **+3.12 / +3.16 %/年**（`csi500_shape_1m_20260923` 两条腿，登记册 §2）：本臂任何绝对读数先减掉约三个点才轮到技能。本臂 30 席，地板没有量过，**第一批每一行自己的 `panel_neutralized_excess` 才是有裁决效力的那一个**。
- 四年主动 IR 在零技能下的抽样误差约 **0.50**（√(244/T)，Pipeline 设计 §2.3）；同一份书只因面板重抽就能差约 0.1 的 IR、0.55 pp/年（登记册 §4）。
- 包作者离线抽的 200 本同池随机 30 只月度书：年化「书 − 池」p10 / p50 / p90 = −3.70 / +0.05 / +4.52 %/年，IR −0.62 / +0.01 / +0.68（`refs/sources.md`）。离线比宿主松（不走 Broker、不对齐骨架），只作量级。

## `c_shuf` 是同批的一次零技能抽样

同一个分数分布、同一本书、信息被打乱。它的主动 IR 落在零附近一个标准差（约 0.5）之内是正常的；**`m1` 要越过的是登记的宿主线 H（`refs/families.md`），不是赢过 `c_shuf` 的那一次读数**。两者的差只是两次抽样之差，不作增量读。

## 空对照只是诊断

`run_null_control` 比的是原始超额、按同样的规则换名、20 份；给 `m1` 的完整期节点跑一次，三个数一起报，不据此提名或否决。
