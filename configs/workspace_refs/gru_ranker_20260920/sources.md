# 读数、出处与复现命令

本臂的方向研究只读研究期末及以前的行：面板、标签、训练与回放都截止在研究期末，沪深 300 取自研究种子的决策视图与研究年回放槽，没有打开前推期或 Held-out 的任何分区，也没有读任何前推或 Held-out 结果。它是选方向时的证据，不是研究期内的正式验证。研究全文：`logs/notes/review_20260915/NA1_next_arm_research.md`；脚本与小输出：`logs/notes/review_20260915/na1/`。

诚实写明的污染面：`c_lgbm` 的 Alpha158 代码逐字取自旧流程的一个冻结产物，那条谱系的选择用到过比研究期末更晚的数据；它只作对照，不作候选。写包的人读过旧流程下几份方向研究的摘要，其中含研究期之后的读数；本包的每个数字都不来自那些读数。

## 沙箱冒烟实测（真实路径，`gpu_count=1`）

命令（仓库根）：`logs/notes/review_20260915/na1/na1_smoke.py <研究年> <天数> <CANDIDATE>`。脚本把本轮的 arm 参数送进控制台同一个创建前检查（`_round.normalize`）与 `resolve_worker_options`，用 `worker._strategy_sandbox_from_spec` 得到策略容器的边界，因此 `gpu_count=1` 与正式回放一样到达执行器的选卡器；视图经 `ResearchPITSnapshotProvider` 从研究种子硬链接进临时缓存，再由 `PITDailyEvaluationBackend.evaluate(request, max_days=N)` 在沙箱镜像里回放（滚动 as-of 视图、真实账户快照、推断容器与 fit worker）。冒烟专用的一处绕行：临时实验被钉在种子构建时的 release 上（见研究全文第二阶段说明）。

## 已知的口径限制（诚实记录）

- 研究期读数来自方向研究的模拟器，不是流水线的 Broker：持仓按复权收盘估值、股息留在持仓里；复核规则是每 5 个决策日一次，本包是每个 ISO 周的首个决策日，两者只在节假日附近不同。
- `c_lgbm` 与方向研究的 LightGBM 都是那个冻结产物的简化版（见 `families.md`），不是冻结产物本身。
- 四个研究年、96 个 IC 日；GRU 只试了三个设计。空结果只覆盖这一个标准 GRU 在这个节奏与账户上的读数，不覆盖所有网络。
- cuDNN 的 GRU 在重复回放之间可能有细小差异，逐位复现不保证。
- 业界读数来自卖方，设计带有事后选择且大多不计成本；本表只取研究期末及以前的年份。
