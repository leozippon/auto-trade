# Fold-ready 探索计划

目标不是复现 Qlib 的 CSI300 报表，而是检验：T-1 日频算子 + 当场拟合的树模型排序器 + 受控换手，在本环境含成本 Validation 里是否站得住，以及哪一个预登记改动能在它之上挣到边际。一折跑多轮 `batch_validate`。有父本时，必须先完成一次与父本可执行逻辑不同的完整 Validation；父本对照由宿主在会话前跑好，不要自己重跑。

1. 读本轮 `data_summary.json`、`unit_reference.json` 与 daily schema。确认 OHLC、`vol`、`amount`、`turnover_rate`、`adj_factor`、`circ_mv`、`up_limit`/`down_limit`、`is_suspended` 的真实列名；缺列就改映射，不要臆造 Qlib 列名一定存在。`vwap = amount / vol`（元、股）。
2. 固定不变量并写进工作区笔记：可交易性过滤（T-1 未停牌、ADV20 成交额 ≥ 3,000 万元、T-1 收盘价上限、剔除科创板/北交所或说明为何保留）、`topk=12`、`n_drop=2`、每 5 个交易日再平衡、等额现金、费用缓冲 3%、`REFIT_PERIOD="quarter"`、训练窗 = 输入窗全部可见历史、标签持有期 `h=10`。这些是声明值，不是待拟合参数。
3. 把 `alpha158.md` 的算子按股票尾窗计算（最长窗 60 日 + 预热），每个决策截面按当日可见截面做 RobustZScore（中位数/MAD，截 ±3）并把缺失填 0——这是 Qlib 的推断处理器；训练标签按 `alpha158.md` 的 T+1 规则构造并做截面 rank 标准化。先在输入窗上用 `python /mnt/tools/screen.py --help` 所述的筛查脚本看一眼几个代表算子的 rank IC，确认符号与覆盖，但不要把 158 个算子逐个筛成手工因子菜单。
4. 第一轮 `batch_validate` 三个候选：(a) 等权符号打分对照（取 `alpha158.md` 里标注了先验方向的十来个算子，rank 后等权）；(b) LightGBM 复现（参数见 `alpha158.md`，早停用带禁运的时间序列验证，在 `fit` 里完成）；(c) 同一特征、同一标签的 ridge（固定 λ）——证明非线性有没有信息。三者共用同一过滤、同一篮子规则。`hypothesis` 写清标签口径、训练窗、参数、否证条件。
5. 第二轮起，每轮从 `families.md` 取一个家族，与第一轮的胜者同批比较：标签口径（家族 A）、特征中性化（家族 B）、跨重训日集成（家族 C）、算子族扩展（家族 D）。一次只改一个组件；家族内部的两三个变体可以同批。
6. 超参纪律：LightGBM 的网格事先写死（≤ 4 个点：`num_leaves ∈ {31, 63}` × `learning_rate ∈ {0.05, 0.1}`，其余固定），在 `fit` 内用带禁运的时间序列验证选点并把选中的点写进 `context.state_dir` 与订单 metadata；不在 Validation 结果上调参。每个网格点都是一次试验，读 Sharpe 时按 `candidates_evaluated` 打折。
7. 决策时只算最新截面：从 `asof_dir/daily` 读约 100 个交易日的尾窗，算最后一天的 158 个算子，加载 booster 打分，出单。模块级缓存只键控 `context.asof_version`；冷启动必须得到相同订单；`fit` 的墙钟先在会话沙箱里用输入窗实测并留 2 倍余量（`batch_validate` 三路并发时三个 fit worker 会争抢宿主 CPU）。
8. 每个候选按 README 的「没有边际」清单读，四个季度子窗分别报相对基线的超额、有效覆盖、换手、拒单、规模倾斜；拟合出的 booster 特征重要性前十要写进结果笔记，重要性集中在市值代理（`amount`、`vol` 量级类算子）时视为规模暴露的警告。
9. 显式退化：样本不足、booster 训练失败或有效覆盖过低时退回等权符号打分，并在订单 metadata 里标明退化——不要静默切换，也不要在退化路径里换成另一个未登记的模型。整个 Validation 大部分决策都在退化路径上时判该候选失败。
10. 用 `step_rollback` 把胜出节点恢复到 `output/` 再 `finish_fold`。不要提交训练脚本、qlib yaml、`joblib` 模型或 `models/*.pkl`。

## 对照

| 候选 | 必须比过的对照 |
| --- | --- |
| LightGBM 基线 | 等权符号打分；同特征同标签 ridge |
| 标签口径变体 | 基线标签（10 日开盘到开盘截面 rank） |
| 特征中性化 | 未中性化的基线；只做分数中性化的版本 |
| 跨重训日集成 | 单个最新 booster |
| 算子族扩展 | 只用 158 个算子的基线 |
| n_drop | 每次再平衡全换 topk |

对照相同或更好就保留对照。拟合版本要保留，必须在含成本收益与四个季度子窗一致性上都不劣，且至少一项明显更好；难分时看中性化超额与规模倾斜，仍分不出才留更简单的那个。

## Validation 否证

- 任何 `available_at`、T-1、复权锚或标签前视错误：结果无效，不讨论收益。
- 用未实现的收益拟合当天权重（标签窗越过推断时点，或训练/验证之间没有禁运）：结果无效。
- 中性化超额 ≈ 0 或规模倾斜显著为负（小市值）：排序器学到的是规模，淘汰或改用家族 B。
- 四个季度子窗同号少于三个，或超额只来自单个季度：淘汰。
- 加手续费、滑点、涨跌停与手数约束后优势消失，或 2 倍滑点下超额转负：淘汰。
- `fit` 超预算或决策超时：不是策略结果，先把计算压回预算再谈收益。
