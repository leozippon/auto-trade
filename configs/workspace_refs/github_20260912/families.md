# 四个创新家族

每个家族与第一轮的 LightGBM 基线节点同批比较，一次只改一个组件。每节的「预登记检验」是候选 `hypothesis` 的最小内容。

## A. 标签口径

基线标签是 10 日开盘到开盘的截面 rank（见 `alpha158.md`）。要检验的是排序器学的目标与我们真正交易的东西是否对齐。

| 变体 | 定义 | 检验什么 |
| --- | --- | --- |
| `h=5` / `h=20` | 持有期换成 5 或 20 日，再平衡节奏同步换成 5 或 20 日 | 信号衰减速度与换手成本的权衡 |
| 基准超额 | `excess = label_h - 同期沪深 300 开盘到开盘收益`（`macro.index_daily`，注意百分数） | 去掉市场项后排序是否更稳 |
| 规模中性标签 | `excess` 先对同截面 `log(circ_mv)` 回归取残差再 rank | 直接阻止排序器学规模 |
| 二值化 | 前 20% 为 1、其余 0，`objective=binary` | 只学头部是否更稳 |

预登记检验：每个变体一个候选，其余全部同基线。否证：相对基线的中性化超额 ≤ 0，或子窗一致性变差。失效模式：更短持有期的往返成本约 30 bp/次，5 日换一次一年付六成，超额必须显著大于它；规模中性标签可能把信号也一并抹掉。

## B. 特征中性化

排序器最容易学到的是规模与行业。要检验的是在特征层做中性化是否比在分数层做更好，或者根本不需要。

| 变体 | 定义 |
| --- | --- |
| 特征中性化 | 每个决策截面，每列对 `log(circ_mv)` 与行业哑变量（`universe.l1_code`）回归取残差，再 RobustZScore |
| 分数中性化 | 特征不动，booster 分数对同样的回归变量取残差后再排序 |
| 只规模 | 只对 `log(circ_mv)` 中性化，不做行业 |

预登记检验：三个变体各一个候选。否证：相对基线的中性化超额 ≤ 0；若基线的规模倾斜本就接近 0，判「无需中性化」并记录。失效模式：行业哑变量在小行业里样本极少，残差噪声大；申万口径在 2021-12-13 切换，输入窗跨越时行业只按决策日冻结的 `universe`。

## C. 跨重训日集成

`REFIT_PERIOD="quarter"` 下每季重训一次，`context.state_dir` 在一次回放内跨重训保留，所以 `fit` 可以读回自己上一季写的 booster。要检验的是集成能否降低单次拟合的方差。

| 变体 | 定义 |
| --- | --- |
| 最近 k 个 booster | 每次 `fit` 训练新 booster 并保留最近 `k=3` 个（`lgb_0.txt`…），`generate_orders` 对各 booster 的截面 rank 取平均 |
| 多训练窗 | 同一次 `fit` 用 12/18/24 个月三个训练窗各训一个 booster，分数取平均（不依赖重训历史，首个季度就可用） |
| 多种子 | 同一训练窗三个 `seed` 的 booster 平均（对照：证明方差来自数据窗还是随机性） |

预登记检验：三个变体各一个候选，`k` 与窗口长度事先声明。否证：相对单 booster 基线的中性化超额与子窗一致性都没有改善。失效模式：首个季度只有一个 booster，集成在验证区间前四分之一无效；训练窗短于 12 个月时样本不足。

## D. 算子族扩展

在 158 个算子之外加入一小组公开算子作为特征（不是手工打分），检验树模型能否从它们里挣到边际。只转述公式；不要 vendor 任何仓库。

WorldQuant 101（Kakushadze 2016，[arXiv:1601.00991](https://arxiv.org/abs/1601.00991)），选与前几轮用过的 `#1/#6/#12/#101` 不同的六个：

| 编号 | 公式（`rank` 为截面 rank，`corr/delta/ts_*` 为时间序列算子） |
| --- | --- |
| `#2` | `-corr(rank(delta(log(V), 2)), rank((C-O)/O), 6)` |
| `#3` | `-corr(rank(O), rank(V), 10)` |
| `#14` | `-rank(delta(returns, 3)) * corr(O, V, 10)` |
| `#33` | `rank(-(1 - O/C))` |
| `#42` | `rank(VWAP - C) / rank(VWAP + C)` |
| `#53` | `-delta(((C-L)-(H-C))/(C-L), 9)` |

国泰君安 191（《基于短周期价量特征的多因子选股体系》，2017，公开研报；GitHub 上有多份社区复现可作公式核对，不得 import）：

| 编号 | 公式 |
| --- | --- |
| `Alpha1` | `-corr(rank(delta(log(V), 1)), rank((C-O)/O), 6)` |
| `Alpha2` | `-delta(((C-L)-(H-C))/(H-L), 1)` |
| `Alpha34` | `mean(C, 12)/C` |
| `Alpha42` | `-rank(std(H, 10)) * corr(H, V, 10)` |
| `Alpha46` | `(mean(C,3)+mean(C,6)+mean(C,12)+mean(C,24))/(4C)` |
| `Alpha53` | `count(C > C.shift(1), 12)/12` |

预登记检验：`158 + 六个 WQ101` 与 `158 + 六个 GTJA191` 各一个候选；可选第三个候选 `Alpha360` 序列特征换掉 158（只在前两个都站住或都落败后）。否证：相对基线的中性化超额 ≤ 0，或新增算子的特征重要性合计 < 5%（等于没用上）。失效模式：这些算子与 158 里的 `CORR`/`KMID` 高度同义，树模型只是多了几列噪声；`#14` 的 `returns` 用 qfq 日收益。

## 明确不做

- 用手写价值/反转/动量/低波打分替代排序器（只能作对照）。
- 在 `generate_orders` 里训练或更新任何模型。
- 用 Qlib 的 `Ref($close,-2)` 字面标签，或任何越过推断时点的收益。
- 复制 Qlib 示例的 CSI300 回测表当作已达到的成绩。
