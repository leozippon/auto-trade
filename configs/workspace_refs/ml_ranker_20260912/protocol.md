# 反过拟合协议

排序器的每个自由度都是一次试验。本协议是硬纪律，写进每个候选的 `hypothesis`，不是可选优化。

## 1. 标签禁运

- 特征日 `T` 的标签用 `O_{T+1}` 到 `O_{T+1+h}` 的开盘到开盘收益；拟合日 `D` 只用 `T + 1 + h <= D - 1` 的样本。
- 训练集与验证集按时间切分，中间空出 `h` 个交易日；验证集的最后一个样本同样满足标签已实现。
- 不用收盘到收盘标签（08:30 决策买不到前收盘价），不用 Qlib 的 `Ref($close,-2)` 字面标签。

## 2. 清洗时间序列验证（purged CV）

- 输入窗按时间切成 3 段：前两段扩展训练、第三段验证；或滚动 2 折（训练 12 个月 → 验证 3 个月，再训练 15 个月 → 验证 3 个月）。每折训练与验证之间禁运 `h` 日。
- 选择指标：验证集逐日 rank IC 的均值与 ICIR，以及头部十分位相对截面均值的超额；不看验证集上的组合收益（那会把换手与手数混进模型选择）。
- 网格 ≤ 4 个点，事先写死在代码常量里；在 `fit` 内按验证指标选一点，用全部训练数据重训，把选中的点、验证 IC/ICIR、样本数写进 `context.state_dir`（`np.savez`）与订单 metadata。
- 验证 IC ≤ 0 时不得硬上：退回等权符号打分并在 metadata 标明退化。

## 3. 滚动重训

- `REFIT_PERIOD="quarter"`（变体：`"month"`，训练成本 ×3，先实测预算）。训练窗 = 输入窗内全部可见历史（首折约两年），随回放增长；不做「只用最近 6 个月」的短窗，样本太少。
- 每次重训重新做第 2 节的选点，不沿用上一季的网格点；上一季的模型文件保留在 `context.state_dir`（一次回放内不清空），供集成家族使用。

## 4. 集成

- 跨重训日：保留最近 `k=3` 个季度的模型，分数取各模型截面 rank 的平均；首个季度只有一个模型。
- 多训练窗：同一次 `fit` 用 12/18/24 个月三个窗各训一个，rank 平均。
- 多种子：同窗三个种子平均——用于证明方差来自数据窗还是随机性。
- 跨模型族：树模型与网络的 rank 平均，只在两者单独都站住之后作为一轮候选。

## 5. 换手与执行

- `topk=12`、`n_drop=2`、每 5 个交易日再平衡是声明值；对照是全换 topk。持有期与标签 `h` 一致时信号衰减最可控，不一致要在假说里说明。
- 拒单（涨停买不进、跌停卖不出、停牌、买不起一手）是结果，逐季汇报；规模倾斜（`style_analysis.json`）逐候选汇报。

## 6. 读结果

- 候选数：每个模型族、网格点、种子、标签变体都计入本折的试验数；`finish_fold` 后宿主按 `candidates_evaluated` 算去膨胀 Sharpe 概率，接近 0 就是「N 次里的最大噪声」。不要用参数邻域刷候选。
- 空对照分位 0.5 附近 = 与同规模随机组合无法区分。
- 相对基线与父本对照的中性化超额、四个季度子窗一致性、2 倍滑点压力、盈亏集中度一起读；任何一项判「没有边际」就淘汰，不用整窗总收益翻案。
- 深度模型只有在含成本收益与子窗一致性上都不劣于树模型、且至少一项明显更好时才保留；「更复杂」不是理由。

## 7. 失效模式清单

- 排序器学到规模：特征重要性或梯度集中在 `amount`/`vol` 量级类与 `log(circ_mv)`，中性化超额 ≈ 0。处理：中性化家族，不是换模型。
- 训练/验证泄漏：同一股票的重叠标签跨越切分边界。处理：禁运。
- 重训后分布漂移：每季模型换一次导致整篮换仓。处理：跨重训日集成，或换仓只按 n_drop。
- `fit` 超预算：三路并发时争抢 CPU；`gpu_count>0` 时三个 fit worker 与会话容器还共享同一批卡，显存与算力都不是独占。处理：以预算一半为上限、样本抽样、网格缩点，并按正式回放实际使用的设备实测。
- 决策超时：全历史重算。处理：尾窗读取、只算最新截面。
- 空 `state_dir`：`fit` 失败时 `generate_orders` 读不到模型。处理：`fit` 必须写出完整状态或显式退化标记，`generate_orders` 读到退化标记走对照并写 metadata，不得静默返回空单冒充无信号。
