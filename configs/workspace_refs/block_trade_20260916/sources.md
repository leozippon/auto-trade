# 来源、实测与诚实边界

这些材料只提供机制先验与本地水位。下面所有数字都是**探针级读数，不是本折 Validation 预期**，而且它们是在**验证窗自己的窗口上**（2022-01..2025-12）算出来的，因此不构成样本外证据；它们的唯一用途是决定哪些家族值得一个 Fold 槽位、门槛该定在哪里。不要粘贴第三方源码，只引用并转述机制。

## 一处必须先说清楚的冲突

D2（`logs/notes/review_20260909/D2_directions_from_literature_20260916.md` §0）把 `block_trade`/`top_list`/`top_inst` 整族记为**已关闭**，出处是 explore_github A2 与 open_mechanism fold3 P6「龙虎榜/大宗整族反转签名关闭」，并给出一条一般规则：DEFAULT 数据面已被扫空，任何再从 DEFAULT 面提的候选都会被判成已关族重开。

D1（同目录 `D1_directions_from_data_20260916.md` §4 推荐 3）的判断相反，理由是：被关闭的是**成交量与净买入统计**的反转签名，而本臂用的是**两个具名对手方谈出来的一个价格**——它是一个协商量，不是价格或成交量的函数，此前没有任何 PRIOR 或策略代码读过它。

本包按 D1 的口径开臂，并把边界写死在 `README.md` 与 `families.md` 里：**任何以龙虎榜净买入、席位金额、上榜次数、大宗成交量强度为排序键的候选都属于重开已关家族，不得提名**；`top_list`/`top_inst` 只能作排除性诊断。这个取舍是本轮设计者做的，不是 Fold 会话可以重新打开的问题。第一折要做的是在这条窄边界内如实裁决，而不是论证边界本身。

顺带的实测支持：2022–2025 年 68,349 个大宗名称-日里，**同日也上龙虎榜的只有 1.91%**，±3 个交易日内 6.19%。两个信息面的重叠很小，做完这个诊断就够了，不必反复论证。

## 机制先验

- **折价即流动性与信息的价格。** 大宗折价的标准解释有两层：接盘方为承担存量与短期价格风险索取的**流动性补偿**，以及卖方通过折价幅度泄露的**私有信息**。国际文献（block trade / upstairs market 一支）普遍报告卖方发起的大宗带负的公告后漂移、买方发起的带正漂移，且效应随折价幅度与相对成交量放大。A 股的制度形态不同：大宗是场外协商、场内过户，成交价被限制在前收盘价的涨跌幅区间内，且必须当晚披露买卖席位，因此「折价」在这里是一个被制度截断、当晚公开的量。
- **A 股的特殊性在于减持通道。** 大股东、董监高与解禁股东的减持在很大程度上通过大宗完成，接盘方常是专业的过桥资金。因此折价既是议价，也是**减持压力的计量**。这条解释支持「深折价 → 尚未消化的抛压 → 后续弱」的方向，也是本包给折价家族登记 `+` 方向（浅折价更好）的依据。
- **不作数值预期。** 上述文献的样本、股票池、持有期与本环境（10 万元账户、long-only、T+1、20 日持有、5 bp 滑点、最低 5 元佣金）都不同，收益数字一律不搬运。

## D2 对注意力/资金流家族的告诫，逐条落到本臂

D2 在评估注意力与资金流方向时给出的四条要求，本包全部当硬要求执行：

1. 信息源必须是**行为本身**，不是行为的价格后果。折价是协商价格；成交量强度是价格后果——所以第 4 家族腿 A 只能作条件腿，不能作独立打分。
2. **方向不得预设**，两腿必须同批登记。第 3 家族（溢价）与第 4 家族腿 B（事后反转）的方向都由输入窗普查确定。
3. 对照必须是**同日、同规模、按换手排序的等量匹配篮子**，证明边际不是换手换皮。本包的第 6 家族（池内中位折价）在此基础上再加一层：对照要从**同样有大宗交易**的池子里抽。
4. 与已关家族重叠的部分必须在 `hypothesis` 里逐字写清差异。

## 已知不可实现与已被排除

- **减持原因不可知**：表里没有分类字段，也没有到 `stk_holdertrade` 的关联键；公告原文不在快照里，`context.nl` 在本臂没有可查载体。

- **大宗成交量强度侧已有两次近零读数**（D1 P5b、本包 F4A），不得作为独立打分家族重刷。

## 本仓库

- `block_trade` 是 `DEFAULT_DATASETS["events"]` 的成员（与 `top_list`/`top_inst` 一样），本臂**不需要任何 opt-in 数据集**，因此可以直接硬链接现有的 PIT 视图种子，不必冷建。
- 唯一总闸是 `available_at <= inference_at`；可见时间规则见 `docs/data-documentation.md §3.3`，结构性重复业务键见同文档 §4，单位见 `docs/units-reference.md`（沙箱里以 `unit_reference.json` 为准）。
- 正式 ABI、允许的库、`fit(context)`/`context.state_dir`、`models/` 只读挂载见只读 `output/README.md`。
- 离线筛查脚本 `/mnt/tools/screen.py`（只经 `shell` 运行）给 rank IC、ICIR、衰减、规模中性 IC、头部十分位超额、换手与可交易性；它只读 `/mnt/snapshot` 决策视图，不替代 Validation。cohort 型家族（第 4 家族腿 B）的匹配对照普查要用自己的脚本，同样只在输入窗上做。
- `starter/` 是本包提供的最小合同锚点（主家族 + 池内对照腿开关），只用来演示读法、单位换算与订单形状；它没有跑过任何回测，不是基线，**不得拷进 `output/`**。
