# 大宗交易折价参考包（20260916）

本目录是只读 refs：只提供可证伪假说、家族公式和 PIT 检查，不是可提交策略，也不是预期收益。

任务只有一句话：在「决策时可见的最近 20 个交易日里有过大宗交易」这个约 580 只的股票池上，把**协议成交价相对当日收盘价的折溢价**做成能在 08:30 决策的截面信号，检验本包登记的五个大宗家族，每个候选都同批带**池内中位折价对照**与机制无关对照，并按本包的「没有边际」读法如实淘汰。前几批的臂要么在日频价量表上做函数变换，要么用公司被动披露的事件；本臂用的是**两个具名对手方谈出来的一个价格**——它不是成交量统计，也不是价格的函数。

按以下顺序读：

1. `exploration-plan.md`：普查、预登记轮次、切换纪律与验收口径。
2. `families.md`：五个候选家族与两个对照家族的精确公式、门槛与失效模式。
3. `pit-field-map.md`：每个字段的域、单位、可见时间与陷阱。
4. `sources.md`：机制先验、本地实测命令与已关闭家族的边界；对方数字不作本折预期。
5. `starter/`：主家族的最小合同锚点实现，读法、单位换算与对照腿开关的参考，不是提交物。

## 机制

大宗交易是场外协商、场内过户的一笔转让：卖方要一次性出掉一个二级市场吃不下的量，买方要一个折扣来补偿接货风险与解禁前的锁定成本，成交价由两个具名席位谈定并当晚披露。这个价格是**信息，不是统计量**：

- **折价 = 卖方的急迫程度。** 减持、质押平仓、解禁后套现都要通过大宗走，折价越深，说明卖方越愿意用价格换确定性，也说明市场要吸收的存量压力越大。实测（2021-04 至 2025-12，非北交所，逐笔）折价中位数 −6.17%、均值 −6.48%，53.8% 的笔折价深于 5%。
- **溢价 = 买方主动付出。** 5.16% 的笔成交在收盘价之上，通常对应战略入股、协议受让或明确的接盘意愿。溢价笔逐年萎缩：2023Q3 6.3% → 2025Q4 1.9%。
- **方向不是「折价越深越好」。** D1 的探针给出的是相反方向：20 日金额加权折价越浅，后续 20 日收益越高（规模中性 rank-IC +0.030 / t +3.66；加动量、换手、波动控制后 +0.016 / t +2.17 / IR 0.32；逐年符号 + 0 + +）。读法是：深折价是**尚未消化的抛压**，浅折价是**卖方不急、接盘方愿意按市价接**。本包按这个方向登记，但每个折价家族都必须同批报出反向腿，方向由验证窗自己裁决。

三件事必须先摆正，否则这个机制会被做成别的东西：

1. **折价不是纯粹的谈判结果，它里面装着当天的行情。** 交易所把大宗成交价限制在**前收盘价**的涨跌幅区间内（实测 `price/pre_close-1` 有 83.7% 落在 ±10%、99.4% 落在 ±20%，1% 分位恰为 −20.000%、99% 分位恰为 +10.007%）。因此 `price/close-1` 在代数上等于 `(1+相对前收的议价)/(1+当日涨跌幅)-1`：当天大涨的股票机械地显示深折价。实测 `price/close-1` 与当日 `pct_chg` 的 Spearman 相关为 **−0.349**，而 `price/pre_close-1` 与之只有 +0.108。**主家族必须同批跑「对前收盘」的变体**；如果只有对收盘的版本成立，测到的是一天反转，不是议价。
2. **业务键结构性重复，必须两级聚合。** 19.3 万行只对应 10.7 万个 (股票, 交易日)：一个名称-日平均 1.80 笔、P95 5 笔、最多 340 笔，59.3% 的行落在多笔的名称-日里；2.00% 的行连 (价格, 数量, 买方, 卖方) 都完全相同。**先聚成事件（名称-日），再聚成窗口**，直接对行做加权等于按「今天拆了几笔」排序。
3. **可选池比一个市值十分位窄，而且明显偏大盘。** 20 日窗内通过可交易性过滤的股票平均 585 只（48 个月末调仓实测，最少 318、最多 772），而同期可交易全池平均 4,279 只、一个市值十分位约 430–480 只。可选池的流通市值中位数 95.0 亿元，全池是 52.0 亿元；可选池的市值分位中位数 0.690，23.4% 落在最大的一个十分位里，只有 32.4% 在下半区。**环境自带的同市值随机对照因此偏松**：它回答「比同样大小的随机股票好吗」，而诚实的问题是「比同样有大宗交易的随机股票好吗」。池内对照不是稳健性附加项，是硬要求。

## 数据能表达什么、不能表达什么

能表达：谁在什么日子、按什么价格、转让了多少金额与股数，以及买卖双方的**席位字符串**。

不能表达，任何依赖以下内容的假说在本环境都不可实现：

- **减持原因**。表里没有「大股东减持 / 司法划转 / 员工持股解锁 / 战略引入」的分类字段，也没有关联到 `stk_holdertrade` 的键。不要用自然语言猜测原因。
- **对手方身份**。`buyer`/`seller` 是自由文本营业部名，7,357 / 7,232 个不同取值，没有版本化的身份表。唯一可靠的用法是**精确字符串匹配**：`机构专用` 占买方 20.61%、卖方 7.76%。它是席位**类型**标志，不是机构身份——同一个「机构专用」可能是公募、险资或通道。不要做实体归并、不要按券商名推断客户类型。
- **过桥与自我转让**。9.44% 的行买卖席位完全相同，这不是两方之间的知情转让，做信息流读法时必须显式剔除或单列汇报。
- **收盘价**。`block_trade` 表**没有** `close`/`pre_close` 列（快照 `events` 域里这两列对大宗行恒为空），折溢价的分母只能从 `daily` 域按同一 `trade_date` 关联。实测 2021-04 至 2025-12 的非北交所行关联成功率 100%。

## 对照

每个候选同批带两个对照，缺一不可：

- **池内中位折价对照（强制）**：同一调仓日、同一可交易性过滤、同一可选池内，取中性化折价分数最接近截面中位的 15 只等权篮子（尽量匹配规模分位与申万一级）。候选相对它的中性化超额才是「折价有信息」的证据。
- **机制无关对照**：同池同过滤的 20 日动量或 20 日换手打分（`families.md` 第 7 家族）。它回答「这个池子本身是不是一个大盘动量池」。

环境自带的同市值随机 null（`run_null_control`）仍然要跑，但它在本臂只是**次要读数**：可选池只占可交易全池的约 13.7% 且偏大盘，null 会系统性地偏向候选。分位在 0.5 附近仍然是坏消息，分位很高不构成好消息。

## 硬合同

- 正式策略写在 `output/` 包内：入口固定为 `output/main.py` 的 `generate_orders(context)`，返回严格 JSON 订单数组；辅助模块放在 `output/` 下并用绝对导入（如 `from lib.blocks import window_discount`），每个 `.py` 都受同一套静态检查。
- 正式 import 只允许：纯计算标准库（`__future__`、`collections`、`dataclasses`、`datetime`、`decimal`、`functools`、`itertools`、`math`、`statistics`、`typing`）、`numpy`、`pandas`、`scipy`、`sklearn`、`lightgbm`、`xgboost`、`statsmodels`、`torch`（本臂 `gpu_count` 为 0，只跑 CPU）及其子模块，以及 `output/` 内自己的模块。`pickle`/`joblib`/`read_pickle`/`to_pickle` 一律拒绝。
- 本包的主家族**不需要拟合**：折价是声明式构造，等权篮子没有可拟合参数。只有做多家族合成时才需要 `fit(context)` 与 `context.state_dir`，权重强制向等权收缩，训练窗与验证窗之间留出持有期长度的禁运。
- 沙箱无网络；大宗交易的公告原文不在快照里，`context.nl` 对本臂没有可查的载体，不要用它猜减持原因。
- 每一行必须 `available_at <= context.inference_at`。大宗行的 `available_at` 是 `trade_date` 当日 21:00（规则名 `official_21_from:trade_date`），随晚间落库节点放行，因此 08:30 决策看到的最新大宗日是 **T-1**，与日线同步。
- 不要写死 `/mnt/agent/workspace`。先核对本轮 `data_summary.json` 与单位表，再经 `context.asof_dir` 读数，每次读取都给 `columns=` 与日期窗口；`asof_dir` 下每个域是 parquet parts 目录，读失败不得回退 `snapshot_dir`。
- 不要把 refs 拷进 `output`，`starter/` 也不行——它是读法示例，正式产物必须自己写。
- Broker 负责 T+1、费用、涨跌停、停牌与成交；策略只发订单草图。

## 本轮几何、账户与执行

开发窗口按季度步进切成常规 Fold：每折的验证区间是截至本折季度的连续四个季度（滚动四季窗），相邻两折只相差一个季度，因此只有最后一个季度是父本没见过的新数据段；本折输入窗是验证区间之前约 24 个月。`block_trade` 自 2020-01-02 起逐日无空分区，`development_first_period=2022Q1` 的第一折输入窗（2020Q1–2021Q4）已被完整覆盖，本臂**没有日历例外**。

账户是 10 万元真实资金：佣金万一、最低 5 元/笔，过户费 0.1 bp，卖出印花税按成交日切换（2023-08-28 前万十、之后万五），方向滑点 5 bp。15 只等权即单只约 6,700 元，最低佣金就是 5–7 bp/边，一次完整往返约 25–35 bp；默认持有 20 个交易日、每 10 个交易日重排一次目标集，年换手约 12 倍，成本拖累 1.8–2.2%/年。**这是本臂最关键的一条数字**：D1 探针里主家族的中性化多头腿只有 +0.15%/20 日 ≈ +1.8%/年，恰好压在成本线上，规模中性版本 +0.41%/20 日才有余量。因此第一折的主要工作不是「找出更强的分数」，而是**判定这条边际在扣费之后到底是正是负**，并如实汇报。

可交易性：T-1 未停牌、ADV20 ≥ 3,000 万元、上市 > 250 日、T-1 收盘 ≤ 40 元（一手 4,000 元 ≤ 单只预算）、`universe.name` 不含 ST、`universe.market` 排除科创板（200 股起，单只预算买不起）与北交所。大宗表里北交所有 434 只、6,529 行（占全窗 3.4%），代码后缀是规范的 `.BJ`，与 `daily` 能对上——**这与 `stk_surv` 的旧编码问题不同，不要照抄那条映射**；剔除北交所的理由是账户容量，不是编码。15 只是可选池的 2.6%，集中度必须逐折汇报。

## 「没有边际」的读法

每个候选都按下面的清单读，不看整窗总收益：

- **对前收盘的变体不成立**：折价家族只在 `price/close` 口径下成立、在 `price/pre_close` 口径下消失或翻转，说明测到的是当日反转的机械投影（两者对当日 `pct_chg` 的相关是 −0.349 与 +0.108），直接淘汰。
- 候选相对**池内中位折价对照**的中性化超额 ≤ 0：折价本身没有信息，剩下的只是「有大宗交易的股票」这个池子。
- `benchmark.neutralized_excess_return` ≈ 0 或为负，或 `style_analysis.json` 显示收益由规模倾斜解释：可选池的市值分位中位数是 0.690，中性化前的超额没有解释力。
- 四个季度子窗的超额符号同号少于三个；每个子窗还要报**可选股票数、事件数与折价恰为零的股票数**（19.1% 的笔成交在收盘价，2024Q1 高达 39.8%，排名会出现大量并列）。
- 效应被**制度性水位漂移**解释：折价中位数逐季从 2024Q1 的 −0.99% 走到 2025Q4 的 −9.98%，同期收盘价成交笔占比从 39.8% 掉到 8.9%。截面 rank 大部分抵消掉共同成分，但跨折的水平比较毫无意义，子窗读数必须连同水位一起报。
- `cost_sensitivity.excess_at_2x_slippage` ≤ 0：毕业按 2 倍滑点压力裁决。
- `pnl_concentration.top5_share_of_gross_gains` 或单票占比过高：15 只占可选池 2.6%，靠一两只票撑起的收益不算。
- `null_control.excess_percentile` 在 0.5 附近即与同规模随机组合无法区分（本臂里高分位不构成正面证据，见「对照」）；`selection_statistics.deflated_sharpe_probability` 接近 0 即 N 次尝试里的最大噪声。

没有候选证明边际时，用 `finish_fold(outcome="no_edge", reason=...)` 明确弃权是正当结果，`reason` 里引用普查与子窗数字。

## 禁止退回通用因子与已关闭的邻居

价值、反转、动量、低波、成长、规模等通用截面打分不得作为候选，除非在 `batch_validate` 的 `hypothesis` 里明确写成第 7 家族的「机制无关对照」。

另有一条本臂特有的边界：**龙虎榜家族（`top_list`/`top_inst`）已被前几轮关闭**（explore_github A2；open_mechanism fold3 P6「龙虎榜/大宗整族反转签名」）。本臂重开的不是那个家族，而是它当时没有测的那一个量——**协商价格**，而不是成交量与净买入统计。因此：`top_list`/`top_inst` 在本臂**只能作为排除性诊断**（把同期上榜的名称单列，证明折价的边际不是上榜反转的换皮），不得作为打分输入。任何以龙虎榜净买入、席位金额、上榜次数为排序键的候选都属于重开已关家族。

同理，`block_trade` 的**成交量/金额强度**这一侧在 D1 探针里已经测过并接近零（20 日金额/流通市值，IC −0.007、t −0.84）。第 4 家族因此不是无条件的强度打分，而是「压力 × 折价」的条件腿与事后反转腿，登记时必须写明这条已知的零结果。
