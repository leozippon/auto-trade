# 候选、本包另加的要求、已关闭家族与终止规则

本文是本臂候选形态、包级要求、变体清单与关闭判据的**唯一权威表述**；`README.md` 与 `exploration-plan.md` 只指向本文，不复述。可见时点、单位与陷阱只写在 `pit-field-map.md`；算术与口径写在 `references/`，读数出处写在 `sources.md`。

**本包登记的是「书的形状由账户决定」，不是某一族信息。** 资金与跟踪授权是本臂运行事实里的两个独立设定；除此之外——股票池、用哪一族信息打分、筛不筛、怎么成形、怎么加权、多久复核、几个座位——全是自由度，本包不指定机制家族，也不指定开局方向。

## 一个方向算什么

方向 = 一句话能说清的收益来源：谁在错误定价、为什么、持续多久，以及它在**本臂的账户与（如果有的话）跟踪授权**之下如何变成一个篮子。候选登记前在 `hypothesis` 里写明五件事：信息源与所用字段；经济解释；预期持有期与复核节奏；按复核节奏与换名数、用本臂自己的资金算出来的年成本线；**以及证伪条件**——什么读数出现就判这个方向不成立。说不清错误定价来源、只是「这些因子组合回测好看」的候选不登记。

**三类东西都是一等候选：**

1. **排序分数**——给池里每个名字打一个分，取前 N。
2. **筛子**——不改排序，只把一类名字拿掉。机制归因对照就是「不筛」。
3. **构造与叠加规则**——分数到篮子那一层：二次排序、保留带、复核节奏、**权重方案**、座位数、**股票池的几何**。机制归因对照是「同一个分数、不成形」。

第 3 类在本包里和前两类同等重要，因为账户正是通过这一层决定这本书的：座位数、买得起的价格上限、整手粒度与最低佣金都落在这里（`references/capital-arithmetic.md`）。

## 裁决由流水线做，本包不复制它

冻结门与毕业条件——主动信息比率、去膨胀 Sharpe 概率、逐年为正的比例、两个回撤上限、跟踪授权、成本压力、活动量——**全部是流水线的，生效值写在本臂运行事实的 `acceptance_rules` 里**。本包既不复述这些数，也不另设自己的版本。

尤其不要做两件事：

- **不要在产物里自建零技能对照腿。** 宿主在每次正式验证之后按候选自己的成交骨架抽一整组零技能副本并取合成，统计量算在「候选减合成」的主动序列上。自建一条对照腿只是用回放年去重测一个宿主已经在算的数，而且**单条腿的信息比率在种子之间标准差 0.37–0.44**，比任何能预登记的裕度都大（`references/zero-skill-panel.md`）。
- **不要设自己的信息比率或去膨胀 Sharpe 门槛。** 它们是流水线常量，会随运行事实发布。

## 本包另加的四条要求（流水线不检查的那部分）

| # | 要求 | 读哪里 |
|---|---|---|
| P1 **预登记** | 每一次完整研究期批次**之前**，把假设、机制、预期读数与**证伪条件**写进 `hypothesis`。事后改口径不算 | `hypothesis` |
| P2 **敞口预算** | `stats.benchmark.top_industry_weight` ≤ **0.30**（时间加权的单一申万一级行业权重）；字段读不到即不可提名。同时把 `size_tilt` 与 `size_beta` **并排汇报**，两者不设门 | `stats.benchmark` |
| P3 **成本** | `cost_sensitivity.excess_at_2x_slippage` > **0**，并在结果笔记里用本臂运行事实的 `initial_cash` 把佣金账重算一遍（座位、佣金地板 bp/边、按实测换手算的年成本） | `stats.cost_sensitivity` + 自算 |
| P4 **导航** | 每一个验证行都按**主动读数**读，不按绝对超额：`benchmark.active_neutralized_excess` / `active_tracking_error` / `active_information_ratio`、`benchmark.panel_neutralized_excess`（零技能在这本书的形状上拿到多少）、`sub_windows[].active_neutralized_excess_return`（逐年）、`selection_statistics` 的 `series` / `information_ratio` / `positive_years` | 每个验证行 |

**P2 为什么留着**：裁决的中性化只回归沪深 300 与全市场规模价差，看不见行业，所以一本压在单一行业上的书会把行业押注算成 alpha。本仓库唯一一次满足了自己那份包全部预登记条件的冻结，研究期信息比率 1.29、回撤 15.3 %，而它 **82.5 %** 的时间加权权重压在一个行业上。`size_beta` 是中性化真正除掉的那个载荷，与 `size_tilt` 方向相反（十九本书上 `size_beta ≈ 0.626 − 0.472 × size_tilt`，r = −0.90），所以「规模到底有没有被买进来」只有两个量一起看才读得出来——但本仓库还没有量过 `size_beta` 的合理界，所以它只报不判。

**P3 为什么留着**：成本是账户的性质，流水线只在前推期按成本压力判一次，而在小账户上它是**研究期就该淘汰候选**的那条线。年换手 17–18 倍时 5 元最低佣金吃掉 1.05–2.32 %/年的权益，低换手的书只付 0.15–0.41 %；同样的换手在大账户上只有 0.03–0.07 %。

## 点名禁止（三条）

1. **GPU 上的序列网络**——本臂 `gpu_count = 0`。
2. **单一申万一级行业集中的书**：P2 不成立即不可提名，**主动信息比率再高也不可提名**。
3. **把股票池写死**：硬编码名单、或者用 `index_weight` 里别的指数建书而仍按沪深 300 报跟踪误差。池必须是按时点读出来的（`pit-field-map.md`）。

三条读法：

- **绝对信息比率最高的那本（1.192）在主动口径下最低（0.690）**，因为它站在一个零技能就值 +7.83 %/年 的形状上；而绝对读数最低的几本反而最高，因为它们站在一个零技能为负的形状上。
- **统计量能认出真正的零技能腿**：0.11–0.23、1/4 年正。
- **约束会独立地拒掉书**。上表第二行那本在主动统计上站得住，但它的跟踪误差 11.4 %、β 0.708——**带跟踪授权的臂上它当场出局**。带授权时要找的是「β 接近 1、跟踪误差压在上限之内，同时主动超额为正」的书，而上面每一本带正主动 IR 的成分书都是低 β 的。**这条线上还没有任何一本书做到过。**

## 从已有读数里学到的东西（方向性先验，不是门）

- **股票池的结构性倾斜是窗口的性质，不是研究结果。** 同一段研究期里，沪深 300 成分 30 席的零技能面板读 **+8.57 %/年**，全市场 30 元以下 15 席读 **−4.67 %/年**。所以「跑赢基准」几乎不说明任何事情，而「跑输基准」也未必是坏事。
- **广度与深度的取舍随账户变。** 座位少、座位小的账户按买得起去筛，池子会缩到市场便宜的那一半；座位多、座位大的账户买得起几乎所有名字，但每个位置的钱多、可选名字的边际信息少。
- **最大的那一段回撤是一次规模事件，`size_tilt` 看不见它。** 危机窗 26 个交易日里规模价差 −29.11 %；最差的一本书 −12.50 % 里有 −17.63 pp 来自规模载荷，残差反而是 +5.61 pp，而它的 `size_tilt` 读 −0.014。写在 `size_tilt` 上的界不是回撤的防线。
- **单个窗口的裁决被行情主导。** 同一份可执行文件在同一个季度上的三次读数从 +7 % 到 −19 % 不等。选择与关闭都要完整研究期的证据，逐年分块里多数年份同向。
- **适应写在产物里。** 冻结之后没有人再改它：学习型模型用 `fit` 与 `REFIT_PERIOD` 在最近 2–3 年上滚动重训，规则型篮子每次决策重算自己的滚动估计。`state_dir` 在每次回放开始时为空。

| a 信息家族 | 任何一族：价值、质量、低波、动量、反转、日频量价算子、事件面、资金面…… | 主自由度。已关闭表是旧口径的先验不是围栏 |
| b 股票池的几何 | 全市场 / 指数成分 / 池内按某一面截底；价格与成交额下限 | 账户通过买得起这条筛子直接作用在这一层；**注意池的选择本身会被面板扣掉**（面板按同在或同不在沪深 300 内、且这笔钱买得起来配替身），所以它不再是免费的超额来源 |
| c 座位数 | 在账户算得出来的可行区间内 | 同时对着成本（佣金地板 ∝ 1/座位）与分散（跟踪误差随席数下降），两条相反的力各量一次 |
| d 权重方案 | 等额现金、截面逆波动、按分数递减、按指数权重倾斜 | 带授权时它是压跟踪误差的主要手段；不带授权时逆波动本身是一次零技能押注 |
| e 复核节奏 | 周、自然月、季 | 在小账户上它直接决定成本线 |
| f 筛子与构造 | 在池内部按某一面剔一类名字；行业/规模配额、保留带宽度、换名上限 | 直接对着 P2 |

**这六条是建议不是围栏。** 列表之外的构造是允许的，条件有三条，缺一不可：(1) 在跑完整研究期批次**之前**把它连同证伪条件写进 `hypothesis`；(2) 一轮仍然只改一个可分离组件，并与当轮基准同批比较；(3) P2/P3 与点名禁止照常适用。

## 什么会杀死一个方向（按命中即停）

1. **连续两轮完整研究期验证里，没有一个候选的主动信息比率接近它预登记的目标** —— 这个方向在本账户上没有可辨识的技能。以这条关闭，把读数写清。
2. **每一个可行座位数上 `excess_at_2x_slippage` 都 ≤ 0** —— 机制可能真实但在这个账户上不可交易。先走轴 c 的另一端一轮，仍不成立即以「不可交易」关闭。
3. **主动超额为负的研究年连续两轮都过半** —— 在研究期里就不是多数年份都在，关闭。
4. **P2 在所有已登记的构造下都不成立** —— 集中度压不下来，关闭并写明是哪一个行业、哪一族分数把它带上去的。
5. **带跟踪授权时，两轮都压不进跟踪误差上限或 β 区间** —— 这一族做不成这本书，换方向；不要靠降仓位或降 β 去换回撤。

## 臂级终止规则

- 一轮里没有候选满足条件：不冻结，把每个方向的读数、失败的是哪一条、下一步要检验的分支写进结果笔记，再换轴或换方向。
- 同一个方向在两轮里都没有满足条件的候选：关闭这个方向，本臂不以同一假设重开。
- **一个方向关闭而预算还有余量：换下一个预登记方向**——先离线筛选，再一次完整研究期批次，不要就此收尾。
- **`no_edge` 是结论，不是退路**：只有在**没有一个还有先验的方向可换**或**预算已经花完**时，才以 `finish_session(outcome="no_edge")` 携读数结束本臂；不要让预算耗尽（流水线记 `deadline`）代替这个结论，也不要为了有一个交付而冻结一个不满足条件的候选。
