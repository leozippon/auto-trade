# 开放臂·持有结构与剔除·全 A / 10 万 / 五年（open_chips_100k_5y，20261015）

本目录是只读参考包，会话里挂在 `refs/`；`output/` 开局就是 `refs/starter/` 的一份可写副本。

按顺序读：本文（方向、研究几何与数据）；`refs/references/open-rules.md`（六条开放臂共同的规则：账户、标准对照、预算与提名，与本文同为合同）；`refs/families.md`（这份记录上已经占用与关闭了什么）；`refs/starter/`（`lib/events.py` 是事件域的按时点读取，`lib/controls.py` 是标准对照）。运行记忆 `research-8y-data-surface` 写的是八年几何、没有事件域的臂：它关于日线、universe、宏观、财务与标题的单位与可见时间对本臂都成立，关于研究期、窗口与「没有事件域」的几句不成立，以本文为准。

## 方向

事件域里记的是谁持有、谁在交易：股东户数的变化与集中度（`stk_holdernumber`、`top10_holders`、`top10_floatholders`）、筹码分布（`cyq_perf`）、限售股解禁（`share_float_complete`）、两融余额与拥挤（`margin_detail`）、龙虎榜与机构、游资席位（`top_list`、`top_inst`、`hm_detail`）、涨跌停与炸板（`limit_list_d`、`kpl_list`，以及日线的 `up_limit` / `down_limit`）、停牌。证据支持时作做多的信号；否则作剔除层，叠在一个真的核心上。

先说清楚这条臂面对的是什么：这份记录只在空头一侧从这些表里读出过信息。上龙虎榜的名字无论谁买 20 日 −4.0 %（t −9.4），小单净买入多的 −1.0 %，质押比例高的 60 日 −0.9 %，解禁代理每年都负；两融拥挤、股东户数、机构持股、调研、基金加仓都平；把负的一端翻过来从来不赚。冻结门的主动 IR 下限 0.75 是对整本书的：20261014 轮在占位核心上叠的彩票跳过层，对同数随机跳过三处都高，书级增量约每年 3 pp，整本只读 0.631。一个剔除层单独从没过过这条线。所以本臂要么找到这些表里的做多信息，要么给剔除层一个自己有边、自己带对照的核心。

核心不能是起步包的 `p0_placeholder`（哈希顺序的固定篮子），也不能是被占用的两本草案书（`open-rules.md` §3 第 5 条：叠在 `b30` 或 `esop60` 上的剔除层就是那个家族）。核心本身是一个声明过的构造：它有自己的一句话主张与标准对照，剔除层再对同数随机跳过（`random_skip`）给出增量。

## 研究几何

五年：研究期 2020-07..2025-06（Y1..Y5），就是八年臂的 Y4..Y8；湖里的事件表从 2020-01 起，更早的年份覆盖不到。窗口 72 个月。冻结门的正年数要 4/5，主动 IR 下限 0.75 不变，去膨胀门槛按五年的天数算。两半是 Y1–Y2 与 Y3–Y5，最后两年是 Y4–Y5；探针与离线筛选只用 Y1–Y2（`open-rules.md` §4、§5）。

## 值得一看的（建议，不是菜单）

外部研究，不是宿主读数，都要在研究期上自己核对。

- **股东户数下降（筹码集中）。** A 股从业者与一些学术研究读到股东户数持续减少的公司随后跑赢，解释是「主力」在收集筹码；它与小盘、低关注度相关，要对规模与行业控制。户数按报告期披露、公告滞后，事件日是公告日而不是报告期末。
- **解禁前的供给压力。** 大比例的限售股解禁之前与当周常有负的超额（文献多在解禁日前后几周），首发原股东与定增解禁不同。作剔除层时，按解禁占流通股的比例与股东类型分开。
- **两融与做空约束。** 融券余额上升在美股文献里预示负收益；A 股融券规模小、2023 年以后受限，信息可能在融资一侧（拥挤的融资余额之后走弱）。这一侧记录已经读负过一次。
- **涨停后的打板资金。** 首板、连板、炸板之后的走势在 A 股实务里被大量交易；10 万账户在涨停价买不进（整单被拒），能做的只有在开盘或收盘、非涨停时进出。

## 血缘

没有。五年臂的研究期与此前任何一条臂都不同，宿主的 lineage 只能并入研究期相同的臂；要重开 `refs/families.md` 里的一行（例如事件与资金表作做多信号那一行、或回避作书那一行），在第一次提交它的那一批照那一行申报（那些读数是四年或八年研究期上的，五年是其中的一段）。

## 本方向的对照要点

- 截面的做多或剔除信号（按户数变化、获利比例、拥挤度挑名字）：`shuffled_assignment`，同样的日子、同样多的名字从可买池里抽。
- 剔除层：`random_skip`，同一张候选单上随机跳过同样多的名字；核心本身另有它的主张与对照，两层的读数都报。
- 事件书（户数公告、解禁、上榜之后进出）：`late_entry`，同一批事件晚进场。
- 五年上的探针更吵：两年的主动 IR 零技能抽样误差约 0.7，探针只能淘汰。
