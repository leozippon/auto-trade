# 候选、符号预登记、增量信息门 G-INC2、验证计划、变体轴、已关闭家族与关闭规则

本文是本臂候选定义、符号预登记、包级要求、验证计划、变体清单与关闭判据的**唯一权威表述**；`README.md` 与 `exploration-plan.md` 只指向本文，不复述。可见时点、单位与陷阱只写在 `pit-field-map.md`；文献证据写在 `references/intraday-moments.md`，算术与口径写在 `references/` 其余各篇，读数出处写在 `sources.md`。

本包有**一个必跑对照** `c_base`、**一个主候选** `s1` 和**一个诊断腿** `s_only`。三者在 `main.py` 里只差候选常量一行。

## 本轮的形状：在一个已确认的载体上加一块新信息

本臂的载体是本仓库唯一一条被宿主确认过、在这个池子上读出真实技能的分数：Alpha158 + LightGBM，沪深 300 成分，β 残差化的 10 日开盘到开盘秩标签，`state_dir` 续训、每第四次重训冷启动。它作必跑对照腿读到**主动超额 +4.30 %/年、主动 IR 0.4642、TE 9.26 %、β 0.851、3/4 年正**（同期零技能面板 +2.20 %/年）；另一条臂的同一条腿读 +1.59 %/年、IR 0.18。它**低于冻结门 0.75**，所以它不是一条可以直接冻结的书；它是一把**有牙的量尺**。

本臂改的**只有特征矩阵的列**：载体的 158 列之后接上一块 15 列的分钟价格路径统计。其余一切——标签、股票池、切分、轮数、种子、重训节奏、席位、复核节奏、整手规则——逐字相同。**对照与候选是同一份代码**，差异只可能来自那 15 列。

## 新信息块：分钟价格路径统计（15 列，`lib/istats.py`）

**假设。** Alpha158 用开、高、低、收、量、成交均价六个数读一个股票日。它看得见**这一天停在哪里、走过多宽**，看不见**这一天是怎么走过来的**。两个六个数完全相同的股票日，一个全天小步上行，另一个横盘、三分钟内闪崩再拉回，在 158 个算子眼里一模一样。文献给出的机制是：市场对大幅、突然的价格跳动**过度反应**（尤其是下跳），而跳跃的**符号不对称**在随后几周里被纠正。本块就是这条路径的形状，全部取自 `intraday_stats` 一张表。

| 组 | 列 | 来源与构造（`intraday_stats` 的日值，窗口统计都是**日值的均值**） |
|---|---|---|
| **不对称** | `rsj_1`、`rsj_s`、`rsj_l`、`sj_rel` | RSJ = `sjv / rv`，即（上行半方差 − 下行半方差）/ 已实现方差，取值 [−1, 1]：当日值、短窗与长窗均值；`sj_rel` = 当日 `sjv` ÷ 长窗平均 `rv`，把「一次大的带符号跳跃」与「一个方差很小、恰好落在一侧的安静日」分开 |
| **高阶矩** | `rsk_s`、`rsk_l`、`rku_l` | 已实现偏度的短窗与长窗均值，已实现峰度的长窗均值 |
| **剖面** | `ro30_s`、`rmid_l`、`rc30_s`、`rc30_l`、`vwd_s` | 开盘 30 分钟收益的短窗均值、盘中收益的长窗均值、尾盘 30 分钟收益的短窗与长窗均值、收盘相对全天成交均价偏离的短窗均值 |
| **成交量** | `vo30_l`、`vc30_l`、`vc30_z` | 开盘与尾盘 30 分钟成交量占全天份额的长窗均值；尾盘份额相对自身长窗均值与标准差的偏离 |

短窗与长窗是 `knobs.ISTATS_SHORT` / `knobs.ISTATS_LONG`（起步 5 / 20 个交易日：前者是跳跃证据的周频，后者约一个月，是中国已实现偏度证据的月频）。`n_bars` 不足 `knobs.ISTATS_MIN_BARS` 或 `rv` 不为正的股票日在**所有列**上先改成 NaN 再进窗口。

**有意不进块的四样东西。** `rv_down_share` 与 RSJ 是精确的一一变换（RSJ = 1 − 2 × `rv_down_share`，逐日与窗口均值都成立），再放一列只是一条共线列；它留在第 0 轮的**恒等式核对**里（`exploration-plan.md`）。单日 `vwap_dev` 就是 Alpha158 的 `VWAP0`（全天成交均价按分钟加总还是成交额除以成交量），只有它的短窗均值是新的。`rv` 的水平与 Alpha158 的 `STD` 各列读的是同一件事（变差有多大），本块只关心变差的**形状**，`rv` 只作 `sj_rel` 的分母。`n_bars` 是质量掩码，不是特征。

**这块不是在重开已关的家族。** 分钟 OFI 作独立排序分数关在 `order_flow_ranker_20260917`（截面 IC 活、组合尺度上没有多头腿）——那是带符号**成交量**，本块是价格路径的**分布矩**。日频价量算子堆作主方向已关（下文已关闭表的第一行）——本块只作载体上的一块列。成分内反彩票 overlay（`rmax_overlay_1m_20260921c`，关的是授权形状）与月度彩票反向（`lottery_reverse_100k_20260921c`）与偏度同族（文献里 RSJ 与最大日收益的截面相关 0.24）——本块不把任何一列单独做成分数，也不带授权。**本臂问的不是「这些矩能不能自己选股」，而是「一条已经在读日线价量的分数，加上日内路径的形状之后会不会更好」**；`s_only` 那条腿存在的理由就是把这两个问题分开，而它永不可提名。

**与那条已关臂共享的风险，先说出来。** 偏度与跳跃类效应在文献里主要落在**空头腿**：高 RSJ、高偏度的名字跑输。一本只做多的书需要的是低 RSJ 名字**跑赢**，而这在大市值池里是更弱的一侧。G-INC2 的 Δ 量的就是前 `SEATS` 只的等额书，它本身就是这条多头腿检查：**截面 IC 为正而 Δ ≤ 0，正是 `order_flow_ranker` 的死法，按门判不通过。**

## 符号预登记（先于任何读数，改它就是改登记）

下表是本块每一列在文献与机制下**预期的边际符号**：该列（进 booster 之前的截面 z 分数）与载体标签（10 日 β 残差秩）在当日可交易成分上的截面 Spearman IC 的符号。证据等级：**L** = 本仓库读过全文的论文读数，**A** = 只读过摘要，**C** = 只有机制推断、没有读过出处，**—** = 不登记符号。证据全文与折扣在 `references/intraday-moments.md`。

| 列 | 登记符号 | 等级 | 依据 | 已知的折扣 |
|---|---|---|---|---|
| `rsj_1`、`rsj_s`、`rsj_l` | **负** | L / A | Bollerslev、Li、Zhao（JFQA 2020）：周度 RSJ 五分位多空市值加权 −29.35 bp/周（t −5.83）、等权 −38.54；标普 500 子样本仍显著。中国月频：已实现偏度的负预测在控制 RSJ 后消失（FRL 2023，A） | 大市值股上约为小市值的一半（四因子 α −26.67 对 −59.16 bp/周）；**月度 horizon 上消散**；RSJ 与上周收益截面相关 0.37，一部分与 Alpha158 的短期反转重叠。预期 `rsj_s` 的 \|IC\| 不低于 `rsj_l` |
| `sj_rel` | **负** | C | 同一机制按跳跃幅度加权 | 无独立出处 |
| （`rv_down_share`，不进块） | **正** | L | 恒等于 (1 − RSJ) / 2 | 只作恒等式核对 |
| `rsk_s`、`rsk_l` | **负**（边际） | L / A | 单排序市值加权 −18.14 bp/周（t −4.35）、等权 −31.09；中国 2004–2022 月频负向（FRL 2023，A） | **控制 RSJ 后反号为正**（Bollerslev 双排序）。booster 里两者同在，偏度的偏效应可以是正的；登记的只是边际 IC |
| `rku_l` | — | L | 市值加权不显著（−0.88 bp/周，t −0.24），等权弱正（+7.32，t 2.29） | 1 分钟采样加 0.01 元最小价位，低价股的峰度被离散化抬高：它部分是一个**价格水平**代理（普查要量它与对数价格的相关） |
| `rc30_s`、`rc30_l` | **负** | C | 尾盘（含收盘集合竞价）的价格压力随后回吐 | 没有在本仓库读过出处 |
| `vwd_s` | **负** | C | 收盘高于全天均价 = 尾段买压，同上 | 同上；单日值已在 Alpha158 里 |
| `ro30_s`、`rmid_l`、`vo30_l`、`vc30_l`、`vc30_z` | — | — | 机制方向不确定 | 报测得的符号，不声称一致或不一致 |

**怎么报**：在 G-INC2 的同一批决策日上，逐列逐日算上面那个 Spearman IC，报均值、`t = 均值 / 标准差 × √天数`、逐研究年的均值符号；每一列有登记符号的都写「一致 / 不一致 / 不显著（\|t\| < 2）」。**一致性是诊断，不是门**：它回答的是「这块如果有用，是不是因为文献说的那个原因」。两条规则：

- **L 级列全部以 \|t\| ≥ 2 读出反号时，先停下来查数据定义**（第 0 轮的恒等式核对、收益窗口的起止），再读任何消融结论。
- **看过 IC 之后不得改登记符号。** 要改就是一次新的登记：重写 `hypothesis`，原登记与原读数照样留在结果笔记里。

## 增量信息门 G-INC2（整期批次之前必须通过，**全离线，0 回放年**；筛过的候选配置各计一个 trial）

**登记的判据，一次写死：Δ 主动超额 ≤ 0，或本块的 LightGBM 增益份额 < 5 %，⇒ 这个形态不进整期验证。**

这道门与更早一轮的 G-INC 有一处**关键区别**：那一轮门的第一项是 ρ（两条腿的秩相关或选中集合重合度），命中高 ρ 即否决。**本门不以 ρ 判**——`c_base` 与 `s1` 共用 158 列基础特征，秩相关按构造就会很高，用它作判据等于用一个恒真的条件去否决。ρ 照常汇报，**只作诊断**。本门是**消融**：同一份代码、同一批决策日、只差那 15 列，两条腿各自减去同一口径的零技能面板，比它们的主动超额。

| 量 | 怎么算 |
|---|---|
| **决策日** | 研究期**后两年**里至少 **60 个分散的决策日**（每两周取一天，或等间隔取满 60）。少于 60 天的读数不作判据 |
| **两条腿** | 每一天用起步包同一份代码，在同一成分截面上分别按 `c_base` 与 `s1` 的列集训练并打分，各取前 `SEATS` 只等额，持有到下一个信号日 |
| **Δ 主动超额** | **主动** = 前向收益减一个 **k = 20 的离线零技能面板**：每一份副本在**同一成分身份侧**（在册 / 不在册与候选一致）且这笔钱买得起一手的名字里随机换名，取 20 份日收益的等权均值。Δ = `s1` 的主动超额 − `c_base` 的主动超额。**它量的是前 `SEATS` 只的书，所以它就是多头腿检查** |
| **增益份额** | 同一批 `fit` 出来的 booster 上，15 列本块的 `gain` 重要性之和 ÷ 全部列的 `gain` 之和（`starter/lib/primary.py` 的 `gain_share`，每张买单都带着它）。**这是一个必要条件不是充分条件**：树会给任何有方差的列分一点增益 |
| **逐年符号一致性** | 把这 60 天按研究年分开，逐年报 Δ 的符号。**只有一年为正的 Δ 不是增量**；它与「哪一年的行情」不可区分 |
| **ρ（只报不判）** | 两条腿选中集合的 Jaccard 中位数，以及两条分数的逐日秩相关中位数。**预期很高**，因为基础特征共享。高 ρ 加正 Δ 是本臂最好的结果形态，不是矛盾 |
| **符号一致性（只报不判）** | 上一节的逐列 IC 表 |
| **Δ 的判定** | Δ ≤ 0 即「没有增量」。Δ > 0 但**不超过两个随机种子之间的差**也按没有增量算（本家族的方向研究在三个种子之间散开过 4 pp/年） |

**这道门能说什么、不能说什么**（研究教训登记 §4，逐条适用）：

- **离线读数只有秩与消融方向是可信的，水平与 Δ 的幅度不可信。** `gnn_relation_1m_20260922` 的锚定检查里秩相关逐位复现（spearman = 1.0），而 Δ 从离线 +5.54 pp/年 翻到实测 −0.63 pp/年。所以本门读的是**符号与排序**，不是那个数值有多大；结果笔记里写 Δ 的数值时必须同时写这一句。
- **离线面板与宿主面板不是一回事。** 宿主走完整 Broker 重放（结算分红、按实际价格成交、现金不足会拒单），按候选自己的成交骨架换名；离线口径**系统性偏低且更宽松**（实测同一本书骨架面板读 +4.91 %/年，离线重定价近似只读 +2.18，主动 IR 从 1.08 掉到 0.890）。
- **门只能否决，永远不能证明边际。** 它说「不够格」时可信，说「够格」时只意味着可以花那些回放年。**裁决是宿主的整期批次，不是这道门。**
- **这道门不花回放年，但不是免费的。** 它筛过的每一个候选配置都计一个 trial：提交的在宿主验证时计，筛掉或暂缓的在下一批的 `offline_trials` 里申报（下文验证计划）；去膨胀 Sharpe 概率正是本仓库多数臂真正卡住的那堵墙。它省下的是回放年与一次给不出资格的子跨度回放，不是 trial。

命中判据时允许的去处只有轴 a（块的窗口）与轴 b（列集）各一轮，每一轮都重跑 G-INC2；仍不成立就以 `no_edge` 结束本臂，**不把本块单独做成一个排序分数去建书**。

> 头包的「子跨度验证只用来复测实现与耗时，不用来在候选之间做选择」**原样保留**：本臂不用子跨度回放做这道门，也不用它在候选之间选优。提名依据仍必须来自完整研究期验证。

## 验证计划（两项登记、trial 账，本臂整期验证上限 6）

冻结门的试验数 M 是本臂验证过的非对照 revision（任何跨度、任何尝试）加上各批申报的 `offline_trials`，按这些试验日度评分序列的平均两两相关 ρ̄ 折成有效试验数 N_eff = ρ̄ + (1 − ρ̄)·M；DSR 的离散度只由研究期长度决定（四个研究年约 0.5），与本臂跑了哪些对照无关。公式与阈值以运行事实 `acceptance_rules.freeze_gate` 为准（本轮默认 `min_dsr_probability` 0.975），结果里的 `trials_to_date` 与每行 `selection_statistics.information_ratio_bar` 是此刻的 M 与过门需要的主动 IR。

- **`control`**：`c_base`（含它的第二个种子）与 `s_only` 写 `control: true`——照常花回放年、计入完整研究期验证数，但不是 trial，也永远不能提名；`s1`、它的轴 a / 轴 b 变体、第二个种子与全冷启动（轴 e，它可能成为继续的那一条）写 `control: false`。把候选登记成对照，它就失去提名资格；把对照登记成候选，是白给自己加一个 trial。
- `offline_trials` = 本批申报前离线（研究期数据）筛过、读数影响了本批提交什么、但本批**没有**提交的候选配置数；提交进本批的候选在宿主验证时按 host trial 计，不重复申报；对照永不计；每个配置只在筛过之后的第一批申报一次；没有筛过任何候选配置才填 0。G-INC2（含轴 a / 轴 b 的重筛）里跑的 `c_base` 是对照。
- **上限**：本臂全部完整期验证（对照也算）合计不超过 6 条。一次两腿完整期批次在四个研究年时花 8 个回放年，三腿 12 年、四腿 16 年。

| 批次 | 腿（按顺序，`control`） | 完整期验证 / 其中 trial | `offline_trials` | 进入条件 |
|---|---|---|---|---|
| 第一批 | `c_base`（true）、`s1`（false），**至多再加 1 条**已单独通过 G-INC2 的轴 a 或轴 b 变体（false） | 2–3 / 1–2 | 筛过而本批没有提交的候选配置数：`s1` 与提交的变体不算，被否决的重筛变体每个算 1 | G-INC2 通过 |
| 第二批 | `c_base` 第二个种子（true）、领先候选第二个种子（false）、领先候选的**全冷启动**（轴 e，false）；若第一批只有两条腿，末尾再加 `s_only`（true） | 3–4 / 2 | 第一批之后新筛、本批没有提交的候选配置数，没有就 0 | 第一批里领先候选在整窗与至少 3 个研究年上主动读数不低于 `c_base` |

**trial 账与它要求的 IR**：按表排满，M 约 3–4（宿主候选 3–4，再加被否决的重筛变体）。各腿共用 158 列与标签，日度主动序列高度相关，ρ̄ 在 0.7–0.9 时 N_eff 约 1.2–1.9。四个研究年、阈值 0.975 下，N_eff = 2 / 3 / 5 时过门要主动 IR 约 1.24 / 1.41 / 1.58，N_eff = 1 也要约 0.98（正态近似）；载体自己读 0.4642，这一差距事先写在这里。

## 提名条件（冻结前逐条满足）

1. G-INC2 已通过，且 Δ、增益份额、逐年符号与（只作诊断的）ρ、符号一致性表都写进结果笔记。
2. 完整研究期验证完成，冻结门按运行事实通过；**至少 2 次完整研究期验证**（运行事实 `min_full_span_validations`）。
3. **稳定性**：逐年分块的**主动**超额为正的研究年 ≥ 四分之三（四个研究年时 ≥ 3）。
4. **`c_base` 同批**，且候选在整窗与至少 3 个研究年上主动读数都不低于它。**这是本臂的核心条件**：赢不了不带这块的自己，就没有这条臂。
5. **两个种子**：至少两个种子的主动信息比率之差已汇报；比种子差还小的优势不是证据。
6. P2 / P3 / P4 / P5 全部成立。
7. **集中度与换手**：`pnl_concentration.top5_share_of_gross_gains` ≤ 0.5；年换手 ≤ 12 倍。
8. **实现底线**：`phase_seconds` 里单次 `fit` ≤ 1,800 秒；容器内存峰值**明显低于 16 GiB**；单次复核决策 < 60 秒；意图买单拒单率 ≤ 30 %；**座位填满率**与买不起份额逐次汇报。不成立先修实现再复测，不算证伪。
9. **持久化已被单独定价**：轴 e 的全冷启动消融已在同批或前一批跑过，两者的主动读数差写进结果笔记。
10. **整期验证上限未越过**：提名时 `selection_statistics.full_span_validations` ≤ 6（对照也算）。

主动超额 ≤ 0、空对照分位在 0.5 附近、去膨胀 Sharpe 概率接近 0 都是普通「没有边际」读数：候选不可提名，不触发家族关闭。

## 什么会杀死它（按命中即停）

1. **G-INC2 在 `s1`、轴 a 与轴 b 各一轮之后仍然命中** —— 这块没有增量信息。本臂以 `no_edge` 结束。
2. 连续两批完整研究期验证里 `s1`（或领先变体）都赢不了同批的 `c_base` —— 以 `no_edge` 结束。
3. 主动超额为负的研究年连续两批都过半 —— 关闭。
4. 每一个可行席数上 `excess_at_2x_slippage` 都 ≤ 0 —— 机制可能真实但在这个账户上不可交易，先走轴 d 的另一端一轮，仍不成立即以「不可交易」关闭。
5. **为了追读数把复核节奏改回周度** —— 这不是一个结果，是一次违规。月度复核是本轮登记的构造选择；10 日标签配月度复核、以及跳跃效应在月度 horizon 上消散，是本臂已知且已写明的风险（`README.md`），**要改它必须先在结果笔记里把换手与成本重算一遍并重写 `hypothesis`**，不能顺手改一行常量。
6. P2 在所有已登记构造下都不成立 —— 关闭并写明是哪个行业带上去的。
7. 提名条件 8 修复一次后仍不成立 —— 该变体放弃，不算家族证伪。
8. **整期验证上限用尽**而没有满足全部提名条件的候选 —— 以 `no_edge` 携读数结束，不为了凑提名再开一批。

## 臂级终止规则

任一成立即本臂关闭：上面第 1、2、3、8 条命中；预算用尽前没有可提名候选。关闭以 `finish_session(outcome="no_edge")` 携读数结束本臂，**不换家族**，不把 `c_base` 或 `s_only` 改作候选。`no_edge` 是结论不是退路：只有在没有还有先验的变体轴可换、整期验证已到上限、或预算已经花完时才用它，不要让预算耗尽（流水线记 `deadline`）代替这个结论，也不要为了有一个交付而冻结一个不满足条件的候选。
