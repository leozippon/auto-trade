# 研究会话探索计划

目标：在本臂唯一的研究会话里，判定**分钟价格路径统计这一块列**是否让那条已确认的载体分数在主动序列上变好；变好就把它做成一本站得住的书，没有就诚实地以 `no_edge` 结束。判据、符号预登记与验证计划只在 `families.md`，数据与单位只在 `pit-field-map.md`，本文只排顺序与预算。

**本臂的命题有且只有一个**：`s1` 要赢同批的 `c_base`。两者用同一份代码、同一个标签、同一个股票池、同一组席位与节奏，只差特征矩阵的最后 15 列。所以**没有 `c_base` 的任何读数都不算数**，而「整窗超额好看」在本臂上尤其不说明问题——载体自己在这个池上就读主动 IR 0.4642。

## 第 0 轮：不占回放预算的普查与离线筛选

用 `shell` 在研究期末的决策视图上跑，不启动回放。任一条不合格就在第 1 轮的 `hypothesis` 里声明，不要硬凑。

1. **运行事实核对（最先做的一件事）**：`broker_replay.initial_cash`、**`benchmark_index`**、`acceptance_rules` 里有没有跟踪授权及其上限与区间、两个回撤上限、`budgets`（含 `strategy_fit_timeout_seconds`）与 `max_replay_years`。本包按 100 万元不带授权写成，50 席；不符就改登记，不要静默沿用。`benchmark_index` 与 `lib/index.py` 的 `INDEX_CODE` 不一致时**改常量去对齐运行事实**。
2. **数据核对**：`index_weight`、`index_daily` 在不在；**`events` 里有没有 `intraday_stats`**；`unit_reference.json` 对它每一列登记的定义与单位（与 `pit-field-map.md` 的表逐列对）；`universe` 带不带 `l1_name`。缺 `intraday_stats` 就是本臂没有块，这时**不要用 `intraday_flow` 或别的表凑一块继续跑**——那是另一个登记。
3. **块的普查（本臂特有，第一优先）**，逐研究年报：
   - `intraday_stats` 在本臂池子上的非空占比，`n_bars` 的分布（分位数）与被掩码掩掉的股票日占比，以及**15 列全部有限**的股票日占比。**读到明显低于九成的数就先停下来**——一块大部分为空的列，任何后续的消融读数都是关于日期的，不是关于机制的。
   - `pit-field-map.md` 的**三条恒等式**，逐条报违反的股票日占比。
   - `rku_l` 与 `rsk_l` 各自与对数收盘价的截面 Spearman 相关（中位数）。它高，就说明这一列学到的是价格水平而不是尾部，写进 `hypothesis`。
   - 15 列之间与它们对 Alpha158 最接近的几列（`ROC_5`、`STD_20`、`VWAP0`、`KMID`）的截面秩相关中位数：一列与某个 Alpha158 算子几乎同秩，它就没有新东西。
4. **账户算术表（直接对着 P3）**：用本臂的资金，在 30 / 50 / 80 席上算座位金额、买得起的成分占比、5 元最低佣金的 bp/边、一次往返总成本，以及在 `cost_stress_multiplier` 下 α 要付掉多少（公式在 `references/capital-arithmetic.md`）。
5. **换手实测（P3 的硬要求）**：用 `smoke_backtest` 在研究期靠后的槽上跑一段跨过至少两次复核的窗口，读 `turnover` 与 `fees_paid`，扣掉首日建仓再年化，写进结果笔记。不得引用包里的估算。
6. **股票池普查，按研究年分别列**：在册成分只数、可交易只数、买得起的占比、申万一级行业个数、价格分布。
7. **零技能的形状读数**：本臂的池与席数上等额现金零技能能拿到什么（`references/zero-skill-panel.md`：100 万 / 50 席沪深 300 的零技能 IR 中位 0.602、标准差 0.37）。**地板在哪里要先知道。**
8. **`fit` 成本探针**：在研究期靠后的槽上跑 `smoke_backtest(days=2)`，读 `resources.fit_seconds` 与 `peak_memory_bytes`，确认离 16 GiB 有明确余量（`references/fit-cost.md`）。`smoke_backtest` 不花回放年，也不计 trial。**整个会话只用一个 `start` 做所有靠后窗口的探针**：`window_build_seconds` 是一次性的开窗成本，付一次，后面同一个 `start` 的探针直接复用，永远不要乘以天数。

## 第 0.5 轮：增量信息门 G-INC2（`families.md` 的硬门，**0 回放年**；筛过而没提交的候选配置在下一批的 `offline_trials` 里申报）

判据在 `families.md`，这里只排步骤。全部在 `shell` 里做，**不发起任何回放**。

1. 在研究期**后两年**里取**至少 60 个分散的决策日**（每两周一天，或等间隔取满 60）。每一天都用**那一天的 as-of 视图**，不用 `snapshot`（`pit-field-map.md` 的单一时点那一节）。
2. 每一天用起步包同一份代码、同一个成分截面，分别按 `c_base` 与 `s1` 的列集训练并打分，各取前 `SEATS` 只等额，持有到下一个信号日。
3. 同一批日子上各抽一个 **k = 20 的离线零技能面板**（在同一成分身份侧、且这笔钱买得起一手的名字里换名，取 20 份的等权均值）；两者的主动超额之差得 **Δ**。
4. 从同一批 `fit` 出来的 booster 上读 **`block_gain_share`**（15 列的 `gain` 之和 ÷ 全部列的 `gain` 之和；起步包每张买单都带着它）。
5. 判定：**Δ ≤ 0，或增益份额 < 5 %，⇒ 不进整期。** Δ > 0 但不超过种子差也按没有增量算。
6. 逐年分开看一遍 Δ 的符号：**只有一年为正的 Δ 不是增量**。
7. **ρ 照常算、照常报，但不判**：两条腿共用 158 列基础特征，秩相关与选中集合重合度按构造就高。
8. **符号一致性表照常算、照常报，但不判**：同一批日子上逐列的截面 IC、t 与逐年符号，对照 `families.md` 的登记。

**这一步不产生提名依据。** 离线面板比宿主面板宽松且偏低，而且离线的 Δ **幅度**已经被证明不可信（同一条检查里秩相关逐位复现，Δ 从 +5.54 pp/年 翻成 −0.63 pp/年）。门只用来**否决**，裁决是宿主的整期批次。

## 第 1 轮：第一批完整研究期 `batch_validate`，`c_base` 是第一条腿

腿与 trial 按 `families.md` 的验证计划：**`c_base`（第一条）**、`s1`，至多再加一条已单独通过 G-INC2 的轴 a 或轴 b 变体。登记：`c_base` 写 `control: true`，`s1` 与变体写 `control: false`；`offline_trials` 申报 G-INC2 筛过而本批没有提交的候选配置数（`s1` 提交了就不算，被否决的重筛变体每个算 1）。

`hypothesis` 必须写清：逐行引用 `families.md` 的载体表、块表与符号预登记表，经济解释与**证伪条件**，席数与复核节奏、保留带与换名上限，预期的主动信息比率与逐年符号，G-INC2 的三个判据量，以及 P2 / P3 / P5 的判定规则。**写明本块的先验不高**：跳跃效应在大市值与月度 horizon 上最弱，而本臂两样都占（`references/intraday-moments.md`）。

**不要再加零技能对照腿**——宿主每次正式验证都会抽面板。回放一旦开跑就计入预算，策略自身抛错的候选照样花掉，环境失败的候选退还。某一路因环境原因失败时不重跑、不压缩对照：把读数与待裁决的分支写进结果笔记。

第 1 轮之后，对领先的完整研究期节点跑一次 `run_null_control`：不花回放年，会话时钟在它运行期间暂停。**它是诊断不是判据**；三个数一起报。

## 判定分支，逐条写死（判据本身见 `families.md`）

- **`s1` 与 `c_base` 读数几乎一样** → 这块被 158 列吸收了。先看 `block_gain_share`：份额本身就低（< 5 %）说明树几乎没在用它，走轴 b（换列集）；份额不低而读数不动，说明它用了但用在一个与 Alpha158 同向的方向上（第 0 轮那张与 `ROC_5` / `STD_20` 的秩相关表会告诉你是哪一列），走轴 a（换窗口）。
- **`s1` 明显差于 `c_base`** → 这块在加噪声。先看覆盖度与 `n_bars` 掩码的逐年表：某一年覆盖塌掉就是数据问题不是机制问题；覆盖平稳而读数更差，走轴 b，先砍没有证据的两组（剖面、成交量）。
- **符号一致性表里 L 级列读反号** → 先查恒等式与收益窗口定义；定义没错，就如实写「文献符号在本池本 horizon 上不成立」，这本身是一条关于先验的读数。
- **`s_only` 读出正的主动超额而 `s1` 没有** → 信息真实但与载体重叠。**如实写**：那是一个关于重叠的发现，不是一个可交付的候选，因为 `s_only` 不可提名。
- **`s_only` 读近零而 `s1` 为正** → 增量来自交互而不是这块的边际信息。这是好结果，但必须在结果笔记里说清楚，不要记成「日内矩有 alpha」。
- **绝对超额高而主动超额低** → 赢的是股票池不是选名。看 `benchmark.panel_neutralized_excess`。
- **逐年主动超额有负年** → 先看是哪一年、是不是那一年的行情，再决定走哪一轴。两批都有多数负年即关闭。
- **换手或成本越线** → 先按 `references/capital-arithmetic.md` 重算，再走轴 d 的席位或换名上限。**不得把复核节奏改回周度**（`families.md` 杀死条件第 5 条）。
- **全冷启动腿（轴 e）赢了续训** → 续训在本臂被证伪。按更好的那个继续，并写进结果笔记。
- **P2 不成立** → 先看是哪个行业带上去的，再走轴 d 收紧席位分布。
- **实现读数不对**（座位没填满、买不起份额偏高、拒单率高、`fit` 逼近上限）→ 先修实现再复测，按提名条件 8。

## 第 2 批起：一次只改一个可分离组件

按 `families.md` 的验证计划与变体轴取，每批与当批的 `c_base` 同批比较。一条轴在两批里都没有满足条件的候选就关闭它。**本臂完整期验证上限 6（对照也算）**，候选各计一个 trial、对照不计：排批次之前先把剩下的验证数与此刻的 `trials_to_date` 写进结果笔记，每批照 `families.md` 登记 `control` 与 `offline_trials`。子跨度验证只用来复测实现与耗时，不用来在候选之间做选择。

## 收官轮

只做两件事之一：对已经满足全部提名条件的最好候选补齐缺的读数并冻结；或者以 `finish_session(outcome="no_edge")` 携读数结束本臂。**收官轮只在没有轴可换、整期验证已到上限、或预算见底时才开始**。

## 计算预算

- **`fit`**：上限是 3,600 秒（按批宽度放大）与 16 GiB，8 核、无显卡。同载体的流块起步包在真实宿主回放上实测单次 `fit` 20–34 秒、容器峰值 2.9 GiB；本块多一张全市场事件表的读取，列数相近，量级应相同——**第 0 轮的探针把它量出来，不要引用这句**。
- **推断**：非复核日在确认最新可见交易日之后直接返回 `[]`；月度复核每年只有 12 个真正建书的决策日。
- **余量怎么花**：轴 a（窗口）与轴 b（列集）在算力上都是自由的，**但每一个验证过的候选与每一个离线筛掉的候选配置都是一个 trial，都会抬高本臂自己的去膨胀 Sharpe 门，每一条整期腿还吃掉 6 个位置里的一个**，所以便宜不是理由。
- **单日探针的秒数对宿主负载极敏感**（同一条腿轻载与重载可以差三四倍），耗时结论按多日回放的**平均**读。
- **回放年**：G-INC2 与 `smoke_backtest` 都是 0 年（G-INC2 筛过而没提交的候选配置按 `offline_trials` 计 trial，`smoke_backtest` 不计）；每次整期两腿批次 8 年、三腿 12 年、四腿 16 年，候选各计 1 个 trial、对照不计。按验证计划排满也只到 24 年左右；以运行事实 `budgets.max_replay_years` 为准。

## 每个候选必须汇报的读数

除标准结果块外，写进结果笔记：逐行对照 `families.md` 的载体表与块表；经济解释与证伪条件；**主动中性化超额、主动跟踪误差、主动信息比率**与**面板自己的中性化超额**；逐年分块的主动超额与原始超额；`top_industry_weight`、`size_tilt` 与 `size_beta` 并排；**`c_base` 的同跨度读数与逐年差**；**块的覆盖度、增益份额与符号一致性表，逐研究年分开**；两个种子的主动信息比率之差；**实测换手、年完成回合数、按本臂 `initial_cash` 重算的佣金账与 2 倍滑点下的超额**；拒单率与原因；平均总仓位；`pnl_concentration`；空对照的三个数；一次决策的实测平均墙钟；`fit` 秒数与容器内存峰值；**这次回放里冷启动与续训各发生了几次**；`trials_to_date`。**账户面四项**也要报：每次复核的买不起份额与整期均值、座位有没有填满（没填满时如实报缺几个与原因）、实际权重对目标权重的偏离、书覆盖的指数权重。缺任何一项的结果不作为提名依据。

## Validation 否证（任何一条命中，结果无效，不讨论收益）

- 股票池不是按时点读出来的：硬编码名单、用别的指数建书而仍按 `benchmark_index` 报跟踪误差、或用最新一张截面去标注历史训练日。
- 用 `trade_date` 而不是 `available_at` 判可见；`weight` 当成小数没有 ÷ 100。
- 成分的 `con_code` 没有改名就去 join，得到一张空表却按「池太小」处理。
- **读事件域时没有先按 `dataset` 过滤**，或把 `intraday_flow` 的任何一列带进了本块。
- **块的缺失被当成零填进原始值**，而不是 NaN 交给截面 z 分数处理；或者反过来，把「整段没有行」当成「当天没有波动」。
- **在 `fit` 或 `generate_orders` 里读分钟行自己重算这些统计**，或者挂了分钟域。
- **训练矩阵与决策矩阵的列顺序不是同一处定义的**，或 `c_base` 与 `s1` 的差不止那 15 列（改了参数、种子、轮数、切分、标签、池或重训节奏之一）。
- 截面 z 分数不是只在当天的成分集合上做的。
- 标签用了整段研究期算出来的 β，或标签横跨决策时刻（信号日 t 的标签要求 t+11 ≤ T-1）。
- as-of 域读失败后回退了 `snapshot_dir`；任何读取不带日期窗口。
- 买不起的**持仓**被当成离池强卖；或者买单向下取整而不是按最近整手四舍五入。
- 复核节奏依赖模块级计数器或跨调用缓存；或者为了追读数把复核节奏改回周度而没有重写 `hypothesis`。
- 把训练好的 booster 放进 `models/`，或让 `state_dir` 里的东西跨回放存活。
- 没有第 0 轮的块普查（含恒等式）、账户算术表与换手实测就开了整期回放；跳过 G-INC2 直接开整期；或者把 G-INC2 做成一次子跨度回放。
- `c_base` 或 `s_only` 登记成 `control: false`（白加 trial），候选登记成 `control: true`（失去提名资格），或 `offline_trials` 少报了筛过而没提交的候选配置、又或把本批提交的候选重复申报。
- 看过 IC 之后改了登记符号而没有重写 `hypothesis`。
- 没有同批的 `c_base` 就拿 `s1` 的读数去论证增量；或者拿 `s_only` 去提名；或者完整期验证越过 6 条仍在提名。
- 用绝对中性化超额或绝对信息比率去论证边际，而不看主动读数与面板。

## 收尾

冻结的是提名节点自己的不可变快照，提名前不必把它恢复到 `output/`。不要提交离线普查脚本；`models/` 只放静态资产。
