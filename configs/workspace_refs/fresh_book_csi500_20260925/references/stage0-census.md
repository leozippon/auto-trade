# 复核事实表：在研究期末的决策视图上还原分数与书，怎么做才算数

自写笔记。`families.md` 的事实表是作包时在宿主上按每个研究年自己的精确输入量出的；会话**可以**在第 0 轮用这一页的口径复核它——只复核表里 `c_base` 与 `f1` 的读数，不是筛选、不计 trial、什么都不申报，读出的不一致写进结果笔记。**这不是必做的一步，不要把预算花在重新推导上。** 复核之外再算任何别的配置（别的节奏、保留带、`f2` 的书路径），就是筛过的配置，照 `offline_trials` 申报。全部在 `shell` 里做，0 回放年。

## 一、要还原的是什么

每个研究年、每个交易日 d：载体在 d 的 08:30 会打出的分数（最新可见 K 线是 T-1 = d 的前一个交易日），以及 d 起的前向开盘到开盘收益。分数必须来自**它自己那个季度的模型**：按宿主节拍，每个自然季度的首个决策日重训一次（第一个决策日也训），一个研究年一个状态目录——完整期验证里状态目录贯穿四年、每第四次重训冷启，恰好每个研究年的第一次重训是冷的，所以逐年分开还原不改变冷热节拍。**直接调用起步包自己的 `main.fit`、`data.wide`、`primary.score`**，不要另写一份训练或打分代码；书的规则调用 `lib/book.py` 的 `exits` / `entrants` / `transfer`，它们是纯函数，不碰 `context`。

## 二、截断：三件事做错任何一件，读数就不是这条腿的

1. **`daily` 截在 T-1。** `daily` 没有 `available_at` 列，起步包的读取也没有日期上界（宿主的 as-of 视图本身就是上界）。离线时必须自己保证 d 的读取只看到 `trade_date < d` 的行。最省事的做法是在普查进程里把 `pandas.read_parquet` 换成一个从内存表按同样 `columns=` / `filters=` 语义返回、并先按决策时刻截断的函数，这样起步包一行不改就能跑；宏观域按行级 `available_at ≤ d 08:30` 截。
2. **标签与前向收益只用于评估。** 已实现的秩 IC 与持有期收益要用 d 之后的价格，这是评估的正当用法；它们绝不能流进任何一次 `fit`——每次拟合的训练窗截在那次重训的决策日之前。前向窗口越过研究期末的决策日直接丢掉。
3. **每个研究年有它自己的 60 个月输入窗。** 运行事实的 `research_geometry.years[].input_window` 给出每一年回放起点那份决策视图的窗口（止于该年开始前一天）；而会话手里只有研究期末那一份（`/mnt/snapshot`，它的 `input_window` 也在运行事实里）。起步包的 `fit` 只回看 3 年 + 120 个自然日，第四研究年的重训完全落在研究期末视图之内；**第一到第三研究年的重训会被左截断**：宿主上它们的训练行从 `index_daily` / `index_weight` 的数据下限（2020-01）起，研究期末视图的 `daily` 却从它自己窗口的起点起，第一研究年少掉约三分之一的训练 bar。`universe` 也只有研究期末那一个口径（名称、ST、行业是那一天的）。所以 Y1–Y3 的离线读数偏保守、带幸存者偏差，**只读符号与排序，不读水平**；`sources.md` 那一组数是作包时在宿主上按逐年精确视图算的，与你的读数在 Y1–Y3 上不会逐位相同。

## 三、事实表里的几个量，各自怎么算

「池」= 当日可打分、有前向收益的成分；超额一律对池的等权均值。t 统计量沿用信号筛选脚本的重叠口径：均值 ÷ 标准差 × √(天数 ÷ h)。

| 量 | 算法 | 用途 |
|---|---|---|
| **秩 IC 随 horizon**（h = 1 / 5 / 10 / 20 / 40） | 分数对 d 起 h 日 β 残差收益（`O[d+h]/O[d] − 1` 减 T-1 的收缩 β × 同两个开盘之间的基准收益，基准只取 `index_daily` 里 `ts_code = INDEX_CODE` 的行）的截面 Spearman，逐日取均值；另报原始收益版与边际 IC | 登记 |
| **陈旧分数的 IC**（滞后 L = 0 / 2 / 5 / 10 / 15 / 20 / 30 / 40 / 60 个交易日） | d − L 日的分数对 d 起 10 日 β 残差收益的秩 IC；半衰期 H = IC 降到 L = 0 时一半的滞后（相邻两点线性插值） | `f1` 的登记节奏从它来 |
| **顶端十分位超额**（每 10 日） | 按分数取前 ⌈10 % × 池⌉ 只，10 日原始收益的等权均值减池均值；逐年与四年合并各报一次；同时报第二个十分位、前 `SEATS` 只与底端十分位 | 事实表 |
| **残差化之后的顶端十分位** | 每日把分数的秩正态值对 β、对数流通市值、60 日波动（池内标准化）与申万一级哑变量做截面 OLS，取残差再算上一行 | 事实表：顶端的超额是不是暴露 |
| **书路径** | 从研究期第一天起，逐日按腿的规则走 `book.exits` / `book.entrants`（买得起 = T-1 一手 ≤ 19,400 元，不算整手与现金），持仓价值按日开盘到开盘收益漂移，卖出与新买都记成交额 | 事实表：年换手、TC、新鲜份额、持有期、上限触顶率、离线 Δ |
| **主动方差分解** | 书减池的日收益 a = Σ(w − 1/N)·r；同日 r 对 [行业哑变量, β, 规模, 波动] 截面 OLS 得因子收益 f 与残差 u；系统性 = (w − 1/N)·X f，个股 = (w − 1/N)·u；份额 = var(系统性) ÷ [var(系统性) + var(个股)] | 事实表：顶端的超额是不是暴露 |

**年换手**按宿主的口径算：成交额 ÷ 初始资金，双边；报逐年与扣掉首次建仓的四年均值。**TC** 逐日算（`book.transfer`，不只在复核日），取四年均值；复核日的 TC 另报一列，它说的是「刚换完时书有多像分数」，逐日均值说的是「书平均有多像分数」，事实表用后者。

## 四、信号筛选脚本能替你做哪一半

`/mnt/tools/screen.py` 按原始复权开盘到开盘收益给出逐 horizon 的秩 IC、边际 IC 与 t，一分钟以内。把普查写出的逐日分数表交给它（`compute_signal` 读你自己的分数表返回宽表），得到的原始收益 IC 应当与你自算的原始版一致——这是一次独立路径的核对。它**不能**替你做三件事：β 残差化的标签口径、池相对的超额（它的 `top_excess` 减的是视图里全部有行情的名字的均值，混进了池本身的规模溢价；要池相对就再用一个「池内恒为常数」的信号、`--top-fraction 1.0` 跑一次，拿两次的 `top_excess_mean` 相减）、以及书路径。

## 五、会话里的成本

每个研究年 4 次季度拟合、约 242 次打分；拟合每次十几到几十秒，打分每天约半秒到一秒（主机负载决定），四年一条链合计十几到三十分钟；书路径与分解在已有的分数表上几十秒。会话容器与策略容器是同一个 8 核 / 16 GiB 边界，一条链串行跑，不要并行抢核。
