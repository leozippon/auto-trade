# 读数、出处与诚实的限制

## 这一页最重要的一句话

**本包有实测支撑的是覆盖度、成本与可跑性，不是「打板与龙虎榜在这个池子上有增量」。** 这一族在本仓库从来没有被任何一行策略代码读过——这是它值一条臂的理由，也是它没有任何先验收益读数的原因。**第 0.5 轮的 G-INC2 是本臂第一个真正的读数**，而本页已经给出了一个**负面的先兆**：起步包在真实回放里量到这 17 列只拿到 4.17 %–4.47 % 的 LightGBM 增益份额，低于 `families.md` 的 5 % 门槛。

本页结构性读数都测在研究期 2021-07-01..2025-06-30 之内，没有任何研究期之后的行。

## 「从来没有人读过」是怎么量出来的

两条互相印证的口径（数据盘点笔记的方法，本包只引结论）：

- **选择层**：当前纪元 `experiments/*/hitl/params.json` 全部 46 条臂，把空选择按 `DEFAULT_DATASETS` 展开。`top_list`、`top_inst`、`limit_list_d`、`kpl_list` **在 46/46 条臂的快照里都加载了**。
- **代码层**：对每一个冻结策略修订的 `output/` 树与每一个参考包的 `starter/` 树做 `grep`。四张表的名字与它们的特征列名（`fd_amount`、`open_times`、`l_buy` 等）**命中文件数全部为 0**。

也就是说：这是**已知的、有文档的、默认加载的、单位已核验的数据，而从来没有任何一条策略读过它的任何一列**。它们每一次回放都在付快照构建的时间与内存，什么也没换回来。

## 覆盖度实测（本包自己量的，**本臂最重要的一张表**）

在本轮固定的研究发布原始层上，按沪深 300 月末截面判定成分，每个研究年等间隔取 8 个交易日：

| 口径 | Y1 | Y2 | Y3 | Y4 |
|---|---|---|---|---|
| 逐日：成分里当天有 `limit_list_d` 行 | **1.17 %** | 0.83 % | **0.21 %** | 0.29 % |
| 逐日：当天有 `top_list` 行 | 0.29 % | 0.42 % | 0.21 % | **0.00 %** |
| 逐日：当天有 `top_inst` 行 | 0.29 % | 0.42 % | 0.21 % | 0.00 % |
| 逐日：当天有 `kpl_list` 行（五池合计） | 6.25 % | 4.50 % | 2.71 % | 4.29 % |
| 20 日窗口：至少一次触板 / 龙虎榜 / `kpl_list` | 16.0 / 8.4 / 35.3 % | 5.8 / 2.9 / 28.9 % | 3.6 / 2.1 / 15.6 % | 3.8 / 2.0 / 22.7 % |
| **60 日窗口：至少一次触板 / 龙虎榜 / `kpl_list`** | **34.8 / 19.4 / 57.0 %** | 20.3 / 12.3 / 49.9 % | **12.0 / 7.7 / 35.4 %** | 31.9 / 10.4 / 46.4 % |
| 整年：至少一次触板 / 龙虎榜 / `kpl_list` | 60.3 / 47.0 / 80.7 % | 49.7 / 35.3 / 83.0 % | 33.7 / 25.0 / 57.7 % | 64.3 / 29.7 / 74.3 % |

**三条读法。**

1. **逐日口径下这块 99 % 以上的格子是零。** 这不是缺陷，是「涨停」这件事在沪深 300 上的真实频率；但它决定了这块的窗口不能短：20 日窗口下触板的非零占比只剩 3.6–16 %。**60 日是这块的主窗口**，起步包因此把稀有事件那几列放在 60 日上。
2. **逐年摆动很大。** 触板的 60 日非零占比从 Y3 的 12.0 % 到 Y1 的 34.8 %，接近三倍。这意味着**「加上这块之后好了」有一半可能是「有事件的那些年好了」**，所以 `families.md` 的 P5 要求逐年报，判定分支也把「某一年占比塌掉」单独列了出来。
3. **龙虎榜是这块里最薄的一组。** 60 日窗口 7.7–19.4 %，Y4 采样日里逐日占比读到 0.00 %。它是变体轴 b 第一个该被砍掉的组。

起步包在真实宿主回放里量到的整块非零占比（`board_any_x` 为 1 的成分比例，第四研究年四次复核）：**28.4 % / 30.9 % / 34.4 % / 40.4 %**，与上表的 60 日并集一致。

## 起步包在沙箱镜像里的实测（容器边界内，纯离线探针）

**这不是宿主回放的读数**，是一次容器内探针：同一个沙箱镜像、`--network none`、只读根文件系统、**8 核 / 16 GiB**（`--memory-swap` 同值）、2 GiB `/tmp` 与 `/dev/shm`、**无 GPU**，把第四研究年首个决策日（2024-07-01，锚点 2024-06-30）的决策视图当作一次 08:30 决策的 as-of 视图，账户 100 万元、空仓起步，依次调用 `fit` → `generate_orders` → 再一次 `fit`（续训）→ `generate_orders`。

| 腿 | 冷 `fit` | 续训 `fit` | 单次复核 | 进程峰值 RSS | 出单 | 块增益份额 | 块非零占比 |
|---|---|---|---|---|---|---|---|
| `c_base`（158 列） | **30.7 秒** | 24.7 秒 | 0.87 秒 | **1.49 GiB** | 50 张买单，权重和 1.0000 | 0.0（一致性检查） | —（无块） |
| `b1`（158 + 17 列） | **18.0 秒** | 16.5 秒 | 1.10 秒 | **1.64 GiB** | **49 张买单**，权重和 0.9888 | **0.04469 / 0.04383** | **0.4037** |
| `b_only`（17 列） | 3.6 秒 | 3.4 秒 | 0.92 秒 | 1.39 GiB | 50 张买单，权重和 0.9980 | 1.0（一致性检查） | 0.4037 |

同一次探针里量到的形状与构造读数：可打分成分 **283 / 300**（差额是科创板与 ST）、座位金额 **19,400 元**、买不起的成分 **2.83 %**、书覆盖的指数权重 **15.8 %–18.2 %**、成分截面 `20240628`。

**四条读法，都要一起读：**

- **`b1` 少填了一个座位。** 49 张买单、权重和 0.9888：最后一个座位在按最近整手四舍五入之后剩余现金不够，被截断成 0 手。这是 `references/capital-arithmetic.md` 写过的已知后果，**必须逐次如实报缺几个座位与原因**，不要当成噪声。
- **`b1` 的 `fit` 比 `c_base` 快。** 18.0 秒对 30.7 秒——多了 17 列却更快，是因为早停提前触发。**这本身是一条信号**：加了这块之后验证 L2 更早停止改善。
- **增益份额 4.17–4.47 % 低于按列数均分的 9.7 %（17/175）**，也低于 `families.md` 的 5 % 门槛。树在同样的抽样机会下**主动少用**这一块。
- **探针不是回放读数。** 它没有 Broker、没有成本、没有零技能面板、只有一次决策日；它量的是成本、可跑性与构造完整性。**正式回放的第一步仍然是 `smoke_backtest`。**

## 宿主流水线实测（正式回放路径，非探针）

同一个起步包，走**真实宿主流水线**：控制台的创建前检查（`_round.normalize`）→ `resolve_worker_options` → `worker._strategy_sandbox_from_spec`（断言 `gpu_count=0`、`memory="16g"`、`cpus=8`）→ 研究种子硬链接进 `ResearchPITSnapshotProvider` → `PITDailyEvaluationBackend.evaluate` 在沙箱镜像里回放，滚动 as-of 视图、真实 `AccountSnapshot`、真实 Broker 与成本。账户 100 万元，槽为第四研究年，**回放 70 个决策日（2024-07-01 起），跨过一次季度重训边界**。

| 跑法 | 墙钟 | `fit_seconds` | 容器内存峰值 | 订单（成交 / 拒） | 换手 | 平均总仓位 |
|---|---|---|---|---|---|---|
| `b1`，Y4 起 70 个交易日 | **293.0 秒** | **[18.3, 33.9]**（上限 3,600） | **2.30 GiB / 16** | 98（**98 / 0**） | 2.021（70 天，含建仓） | 0.966 |
| `b1`，Y4 起 3 天 | 52.6 秒 | [18.0] | 1.50 GiB | 49（49 / 0） | 0.970（全是建仓） | 0.970 |

**视图是硬链接来的，`prepare` 实测 0.0 秒**：本臂的四张表都在本轮固定的那棵预建种子的快照契约里，不需要新建种子。

**没有一次 OOM、没有一次超时、没有一次 loader 拒绝、没有一次拒单。** `fit` 用掉上限的 0.5–0.9 %，容器峰值用掉 16 GiB 的 14 %。

**续训在真实执行器下被走通并且可读**：订单元数据里 `refits` 1 → 2，两次 `fit` 分别 18.3 秒（冷）与 33.9 秒（续训）——**续训更慢，理由是模型连续性不是速度**，与同谱系上一轮的结论一致。

**月度复核被确认**：70 个交易日里 **4 个买入日 / 3 个卖出日**（2024-07-01、08-01、09-02、10-08），成分截面逐月滚动四张（`20240628` / `0731` / `0830` / `0930`）。**这正是本轮构造的主张**：同谱系上一轮周度复核实测年换手 14.2 倍、越过 12 倍上限；本轮 70 天里扣掉首日建仓的 0.970 之后换手 1.05，年化约 **3.7 倍（双边）**，离上限有三倍余量。

**订单流是正常的**：买单全是 100 股整手，单笔 200–13,300 股，实际权重 0.0184–0.0239（目标 1/50 = 0.02，偏差来自最近整手四舍五入），书恒为 50 席，可打分池 281–283 只，买不起的成分 2.13–2.85 %，书覆盖指数权重 15.4 %–18.6 %。

**块的读数在真实回放上复现**：两次 `fit` 的增益份额 **0.04171 / 0.04469**，非零占比 **0.284 / 0.309 / 0.344 / 0.404**——与容器探针逐位同档。

**这 70 天的收益读数不可用于裁决**：`max_days` 路径不抽零技能面板，所以**没有任何主动统计量**。方向性的实现检查读数（不是成绩）：中性化超额 +3.73 %、跟踪误差 5.09 %、β 0.884、`size_tilt` 0.934、`top_industry_weight` 0.239（P2 的 0.30 之内）。

## 诚实的限制

- **「打板与龙虎榜在这个池子上有增量」没有实测支撑。** 本包只有覆盖度、成本与形状，没有任何收益读数。
- **已有一个负面先兆**：增益份额 4.2–4.5 %，低于按列数均分的 9.7 %，也低于门槛 5 %。这不是结论（一个决策日锚点、一个研究年），但它是本臂第一个该被解释的数。
- **沪深 300 是这一族最不利的池子。** 触板与游资上榜是小盘与题材股的现象；这块数据真正活跃的地方是中证 1000 与更小的池子，而本轮的裁决口径钉在一个指数上。**这是本臂最大的先验不确定性**，而它不可能在本臂内部解决。
- **重复业务键的归约是一个登记的选择。** `top_list` / `top_inst` 的多行里混着多日口径的列示，本包按均值归约，把多次列示当作同一件事的多次重述。换一种归约会得到不同的数，它在变体轴 c 上。
- **`kpl_list` 的可见时点正好落在决策时刻上**（次日 08:30 对 `inference_time` 08:30）。按合同它可见，但这是一条刀刃；运行事实里的 `inference_time` 不是 08:30 时本块少掉最近一天，要如实报。
- **`limit_list_d.limit_amount` 不在快照里**（供应商回写历史为空、早期分区量级异常），所以「板上成交金额」这个量本臂拿不到。
- **`kpl_list` 的 `bid_*` 四列单位未登记**，起步包只用它们所在池的**上榜次数**，不用它们的水平值。
- **月末成分截面**是股票池这一面最大的限制，两张之间的真实调整看不见（`references/index-membership.md`），供应商会回填历史权重，幅度未量化。
- **科创板与北交所整族被起步包从下单池里剔除**（一手粒度不同），训练仍然用它们；代价是逐年 1.7–4.8 pp 的指数权重。
- **10 日标签配月度复核是一处已登记的错配**（`README.md`）。它是本轮构造侧的主要风险，不是一个可以顺手改掉的常量。
- **本包不假设本臂的账户与授权。** 起步包按 100 万元不带授权写成（50 席）；运行事实不符时按 `families.md` 改登记。

## 外部出处

沙箱无网络，`references/` 下的五份笔记都是自写的，不含任何论文或受版权文本的转载。查证过的公开来源：

- 沪深 300 的编制与定期/临时调整规则：中证指数公司的指数编制方案与调整公告页（<https://www.csindex.com.cn>）。
- 涨跌停制度、龙虎榜的披露规则与「机构专用」席位的含义：上海证券交易所与深圳证券交易所的交易规则与信息披露业务指引公开页（<http://www.sse.com.cn>、<http://www.szse.cn>）。
- 信息比率 = 主动收益 ÷ 跟踪误差：Wikipedia 的 Information ratio 与 Tracking error 条目。
- Alpha158 是 Microsoft Qlib 的公开算子集合（<https://github.com/microsoft/qlib>）；本包的 `starter/lib/features.py` 是本仓库自己的向量化实现，逐字沿用同族上一个包里的那一份，不转载任何外部文本。
