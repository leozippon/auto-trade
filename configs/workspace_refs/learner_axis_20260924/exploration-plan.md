# 研究会话探索计划

目标：在本臂唯一的研究会话里，判定**换学习器**（DoubleEnsemble 或顶部加权的排序目标）是否让那条已确认的载体分数在主动序列上变好；变好就把它做成一本站得住的书，没有就诚实地以 `no_edge` 结束。判据、验证计划与腿的定义只在 `families.md`，数据与单位只在 `pit-field-map.md`，本文只排顺序与预算。

**本臂的命题有且只有一个**：候选要赢同批的 `c_base`。几条腿用同一份代码、同样的 158 列、同一个标签、同一个参数点，只差学习器。所以**没有 `c_base` 的任何读数都不算数**；`de1` 还欠一条 `c_cold`，因为它每个季度都冷启动而载体续训。

## 第 0 轮：不占回放预算的普查与成本探针

用 `shell` 在研究期末的决策视图上跑，不启动回放。任一条不合格就在第 1 批的 `hypothesis` 里声明，不要硬凑。

1. **运行事实核对（最先做的一件事）**：`broker_replay.initial_cash`、**`benchmark_index`**、`acceptance_rules` 里有没有跟踪授权及其上限与区间、两个回撤上限、`budgets`（含 `strategy_fit_timeout_seconds`、`strategy_cpus`、`batch_validate_max_concurrency`）与 `max_replay_years`。本包按 100 万元不带授权写成，50 席；不符就改登记，不要静默沿用。`benchmark_index` 与 `lib/index.py` 的 `INDEX_CODE` 不一致时**改常量去对齐运行事实**。
2. **数据核对**：`index_weight`、`index_daily` 在不在；`universe` 带不带 `l1_name`。本臂不读任何别的数据集。
3. **账户算术表（直接对着 P3）**：用本臂的资金，在 30 / 50 / 80 席上算座位金额、买得起的成分占比、5 元最低佣金的 bp/边、一次往返总成本（公式在 `references/capital-arithmetic.md`）。
4. **换手实测（P3 的硬要求）**：用 `smoke_backtest` 在研究期靠后的槽上跑一段跨过至少两次复核的窗口，读 `turnover` 与 `fees_paid`，扣掉首日建仓再年化，写进结果笔记。不得引用包里的估算。
5. **股票池普查，按研究年分别列**：在册成分只数、可交易只数、买得起的占比、申万一级行业个数、价格分布。
6. **零技能的形状读数**：本臂的池与席数上等额现金零技能能拿到什么（`references/zero-skill-panel.md`：100 万 / 50 席沪深 300 的零技能 IR 中位 0.602、标准差 0.37）。**地板在哪里要先知道。**
7. **`fit` 成本探针，每条要进批次的腿各一次**：`smoke_backtest(start = 研究期靠后的槽, days = 2)`，读 `resources.fit_seconds` 与 `peak_memory_bytes`（`references/fit-cost.md`）。**同一个 `start` 复用给后面所有靠后窗口的探针**：`window_build_seconds` 是一次性的，付一次，永远不要乘以天数。`smoke_backtest` 不花回放年，也不计 trial。
8. **学习器的形状（P5）**：从同一批探针的买单元数据里读 `valid_metric`、`subset_sizes`、`refits` / `cold_refits`；再在 `shell` 里对同一个训练窗确认每个子模型的树数与决策日的不同分数占比，与 `sources.md` 的起步包读数对一遍。

## 第 0.5 轮：离线门 G-INC2（`families.md` 的硬门，**0 回放年**；筛过而没提交的候选配置在下一批的 `offline_trials` 里申报）

判据在 `families.md`，口径与离线重建的做法在 `references/learner-ablation.md`，这里只排步骤。全部在 `shell` 里做，**不发起任何回放**。

1. 在研究期**后两年**里取**至少 60 个分散的决策日**。
2. 按宿主节拍离线拟合：从第三研究年第一个季度起，用一个空状态目录连续拟合 8 个季度，每条腿各一条链（`c_base`、`de1`、`lr1`、`c_cold`；`de_lr` 只在前两个候选都过门之后）。每个域都截在那一次重训的决策日；**每个决策日用它自己那个季度的模型打分**。
3. 每一天各取前 `SEATS` 只等额，持有到下一个信号日；同一批日子上对每条腿抽一个 **k = 20 的离线零技能面板**（同一组随机种子），得 **Δ 主动超额**。
4. 同一批日子上算每条腿对已实现载体标签的截面秩 IC，得 **Δ 秩 IC**；再用第二个种子把 `c_base` 重跑一遍，得 `c_base` 自己的秩 IC 种子差。
5. 判定：每个候选的两半逐年都要为正，Δ 秩 IC 够到登记下限，Δ 主动超额超过种子差。**`de1` 同时报 `c_cold − c_base` 与 `de1 − c_cold`。**
6. **ρ 照常算、照常报，但不判。**

**这一步不产生提名依据。** 离线面板比宿主面板宽松且偏低，离线的 Δ **幅度**已经被证明不可信。门只用来**否决**，裁决是宿主的整期批次。

## 第 1 批：一次完整研究期 `batch_validate`，`c_base` 是第一条腿

腿：**`c_base`（第一条）** 加过了门的 `de1` / `lr1`（最多两条）。一次三腿完整研究期验证在四个研究年时花 12 个回放年。登记：`c_base` 写 `control: true`，候选写 `control: false`；`offline_trials` 按 `families.md` 验证计划申报（`de1` 与 `lr1` 都过门并提交就是 0，只提交一条就是 1；已筛而暂缓的 `de_lr` 再加 1），`de1`、`lr1` 因此各恰好计一个 trial。两条候选都没过门就不开这一批。

`hypothesis` 必须写清：逐行引用 `families.md` 的载体表、两件事的登记表与腿表；经济解释与**证伪条件**；席数与复核节奏、保留带与换名上限；预期的主动信息比率与逐年符号（**以 `c_base` 为参照写成一个差，不写成一个水平**）；离线门的两半与 `de1` 的拆分；P2 / P3 / P5 的判定规则；以及本臂的 trial 账（`families.md` 的验证计划）。

**不要再加零技能对照腿**——宿主每次正式验证都会抽面板。回放一旦开跑就计入预算，策略自身抛错的候选照样花掉，环境失败的候选退还。某一路因环境原因失败时不重跑、不压缩对照：把读数与待裁决的分支写进结果笔记。

第 1 批之后，对领先的完整研究期节点跑一次 `run_null_control`：不花回放年，会话时钟在它运行期间暂停。**它是诊断不是判据**；三个数一起报。

## 判定分支，逐条写死（判据本身见 `families.md`）

- **候选与 `c_base` 读数几乎一样** → 先读 P5：`de1` 后面的子模型是不是没在干活（列数、树数正常，但对子模型 1 的秩相关接近 1）；`lr1` 是不是只有几棵树、分数大面积并列。是，就是学习器在这个载体上退化了，走该候选登记的那条变体轴一轮（`de1` 走轴 a 或 b，`lr1` 走轴 c）；不是，就是学习器改了排序却没改书，照实写。
- **`de1` 赢 `c_base`，但 `c_cold` 同样赢** → 增益来自不续训，不来自集成。如实写进结果笔记与登记册的那一行，`de1` 不以 DoubleEnsemble 的名义提名（`families.md` 提名条件 5）。
- **`lr1` 的秩 IC 更差而主动超额更好** → 顶部加权正在起作用，这是 `lr1` 的设计意图；但它要在逐年与两种子上都站住，不要把一次顶部的好运气记成机制。
- **候选明显差于 `c_base`** → 学习器在加噪声。`de1` 看 SR 的权重离散度与 FS 的列数；`lr1` 看树数与并列占比。
- **绝对超额高而主动超额低** → 赢的是股票池不是选名。看 `benchmark.panel_neutralized_excess`。**这正是这条载体的校准臂当年掉进去的那个坑。**
- **逐年主动超额有负年** → 先看是哪一年、是不是那一年的行情，再决定走哪一轴。两批都有多数负年即关闭。
- **换手或成本越线** → 先按 `references/capital-arithmetic.md` 重算，再走轴 d 的席位或换名上限。**不得把复核节奏改回周度。**
- **P2 不成立** → 先看是哪个行业带上去的，再走轴 d 收紧席位分布。
- **实现读数不对**（座位没填满、买不起份额偏高、拒单率高、`fit` 逼近上限）→ 先修实现再复测，按提名条件 9。

## 第 2 批：只在第 1 批有候选赢过 `c_base` 时才开

腿按 `families.md` 的验证计划取：领先候选的第二个种子；领先的是 DoubleEnsemble 时加 `c_cold`；两个候选都赢过 `c_base` 且 `de_lr` 过了离线门时加 `de_lr`；第二个种子与 `de_lr` 写 `control: false`，`c_cold` 写 `control: true`，`offline_trials` 申报第 1 批之后新筛、本批没有提交的候选配置数。**全臂不超过 6 个完整期验证**；变体轴只能在这个上限之内替换第 2 批的一条腿，而且先要重过离线门。子跨度验证只用来复测实现与耗时，不用来在候选之间做选择。

## 收官轮

只做两件事之一：对已经满足全部提名条件的最好候选补齐缺的读数并冻结；或者以 `finish_session(outcome="no_edge")` 携读数结束本臂。**收官轮只在没有轴可换、或完整期验证的上限已经用完时才开始**。

## 计算预算

- **资源边界**：16 GiB / 8 CPU / 无显卡，单次 `fit` 上限 3,600 秒（运行事实为准）。本包在沙箱镜像与真实宿主流水线上实测的每条腿秒数与内存在 `sources.md`：载体一次拟合十几到三十秒，`de1` 在重负载与三路并发下实测不到 200 秒，**全部腿的内存峰值不到 1.7 GiB**。纪律在 `references/fit-cost.md`。
- **DoubleEnsemble 每季度冷启动，这是构造决定的，而且要付钱**：四年整期 16 次重训，`de1` 的拟合合计比 `c_base` 多出十几分钟到四十分钟（按主机负载）。它不影响回放年，只影响墙钟。
- **推断**：非复核日在确认最新可见交易日之后直接返回 `[]`；月度复核每年只有 12 个真正建书的决策日，每次一两秒。
- **余量怎么花**：变体轴在预算上都是自由的，**但每一个验证过的候选与每一个离线筛掉的候选配置都是一个 trial，都会抬高本臂自己的去膨胀 Sharpe 门**，所以便宜不是理由。
- **单日探针的秒数对宿主负载极敏感**（同一条腿、同一个窗口，两个时刻读 16.1 与 29.6 秒），耗时结论按多日回放的**平均**读。
- **回放年**：离线门与 `smoke_backtest` 都是 0 年（离线门筛过而没提交的候选配置按 `offline_trials` 计 trial，`smoke_backtest` 不计）；每条完整期腿 4 年，候选计 1 个 trial、对照不计。以运行事实 `budgets.max_replay_years` 为准。**宿主 trial 只花在整期上。**

## 每个候选必须汇报的读数

除标准结果块外，写进结果笔记：逐行对照 `families.md` 的载体表与登记表；经济解释与证伪条件；**主动中性化超额、主动跟踪误差、主动信息比率**与**面板自己的中性化超额**；逐年分块的主动超额与原始超额；`top_industry_weight`、`size_tilt` 与 `size_beta` 并排；**`c_base` 的同跨度读数与逐年差**（`de1` 还要 `c_cold` 的）；**学习器的形状**（每次拟合的树数、子模型列数、验证读数、冷热重训次数、不同分数占比）；两个种子的主动信息比率之差；**实测换手、年完成回合数、按本臂 `initial_cash` 重算的佣金账与 2 倍滑点下的超额**；拒单率与原因；平均总仓位；`pnl_concentration`；空对照的三个数；一次决策的实测平均墙钟；`fit` 秒数与容器内存峰值。**账户面四项**也要报：每次复核的买不起份额与整期均值、座位有没有填满（没填满时如实报缺几个与原因）、实际权重对目标权重的偏离、书覆盖的指数权重。缺任何一项的结果不作为提名依据。

## Validation 否证（任何一条命中，结果无效，不讨论收益）

- 股票池不是按时点读出来的：硬编码名单、用别的指数建书而仍按 `benchmark_index` 报跟踪误差、或用最新一张截面去标注历史训练日。
- 用 `trade_date` 而不是 `available_at` 判可见；`weight` 当成小数没有 ÷ 100。
- 成分的 `con_code` 没有改名就去 join，得到一张空表却按「池太小」处理。
- **候选与 `c_base` 的差不止学习器**（改了特征、参数点、种子、轮数、切分、标签、池、重训节奏或同分规则之一），或排序腿单独换了参数点。
- **离线门里用期末那一次拟合给全部决策日打分**，或离线重建时没有把 `daily` 截在决策日的 T-1。
- 截面 z 分数不是只在当天的成分集合上做的。
- 标签用了整段研究期算出来的 β，或标签横跨决策时刻（信号日 t 的标签要求 t+11 ≤ T-1）。
- 排序目标的查询组不是决策 bar，或训练行没有按 bar 连续排好。
- as-of 域读失败后回退了 `snapshot_dir`；读多数据集的域时没有先按 `dataset` 过滤；任何读取不带日期窗口。
- 买不起的**持仓**被当成离池强卖；或者买单向下取整而不是按最近整手四舍五入。
- 复核节奏依赖模块级计数器或跨调用缓存；或者为了追读数把复核节奏改回周度而没有重写 `hypothesis`。
- 把训练好的 booster 放进 `models/`，或让 `state_dir` 里的东西跨回放存活。
- 没有第 0 轮的账户算术表、换手实测与成本探针就开了整期回放；跳过离线门直接开整期；或者把离线门做成一次子跨度回放（那白花回放年、给不出资格，还照样计 trial）。
- `c_base` / `c_cold` 登记成 `control: false`（白加 trial），候选登记成 `control: true`（失去提名资格），或 `offline_trials` 少报了筛过而没提交的候选配置、又或把本批提交的候选重复申报。
- 没有同批的 `c_base` 就拿候选的读数去论证增量；`de1` 没有 `c_cold` 就论证「集成有增量」。
- 用绝对中性化超额或绝对信息比率去论证边际，而不看主动读数与面板。

## 收尾

冻结的是提名节点自己的不可变快照，提名前不必把它恢复到 `output/`。不要提交离线普查脚本；`models/` 只放静态资产。
