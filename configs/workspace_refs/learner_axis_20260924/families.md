# 候选、离线门 G-INC2（学习器版）、验证计划、变体轴、已关闭家族与关闭规则

本文是本臂候选定义、离线门、验证计划、包级要求、变体清单与关闭判据的**唯一权威表述**；`README.md` 与 `exploration-plan.md` 只指向本文，不复述。可见时点、单位与陷阱只写在 `pit-field-map.md`；算法与口径写在 `references/`，读数出处写在 `sources.md`。起步包里每条腿的定义只有一处：`starter/lib/primary.py` 的 `LEGS`。

## 本轮的形状：在一个已确认的载体上换学习器

本轮的臂共用同一个**载体**，因为它是本仓库唯一一条被宿主确认过、在这个池子上读出真实技能的分数：Alpha158 + LightGBM，沪深 300 成分，β 残差化的 10 日开盘到开盘秩标签，`state_dir` 续训、每第四次重训冷启动。它作必跑对照腿读到过**主动超额 +4.30 %/年、主动 IR 0.4642、TE 9.26 %、β 0.851、3/4 年正**（同期零技能面板 +2.20 %/年），另一条臂上读 +1.59 %/年、IR 0.18。两者都**低于冻结门 0.75**，所以它不是一条可以直接冻结的书；它是一把**有牙的量尺**。

本臂改的**只有学习器**：同样的 158 列、同样的标签、同样的参数点，换一种训练方式（DoubleEnsemble）或换一个损失（顶部加权的排序目标）。其余一切——特征、标签、股票池、切分、轮数上限、早停、种子、重训节奏、席位、复核节奏、整手规则——逐字相同。

**为什么是学习器而不是再加一块信息。** 登记册 §2 关掉的四种「换模型」（序列 GRU、关系图、截面注意力、元标注）换的都是**特征的组织方式或整条架构**；在这 158 列上，**GBDT 本身的训练方式与损失函数从来没有动过**。而文献里最一致的一条学习器侧改进恰好就在这里：DoubleEnsemble 在三次独立复跑里都在同一套 Alpha158 特征上赢过普通 LightGBM（IR +0.23…+0.57，`references/double-ensemble.md`）；顶部加权的排序损失则是这个仓库从没试过的一轴。两件事都不需要新数据、不需要新种子，成本是几十秒到几分钟的拟合。**它的风险也写在这里**：能从文献搬过来的只有「同特征比较的方向」，水平一个都搬不过来（`README.md`）。

## 载体（所有腿共用，一个字都不改）

| 组件 | 定义（`starter/`） |
|---|---|
| 股票池 | **决策日可见的沪深 300 成分**（`macro.index_weight` 最新一张不晚于决策日的截面），剔科创板与北交所、名称含 ST/退、T-1 无日线、窗口内不足 60 根 K 线。训练日按**那一天在册的成分**判定 |

| 标签 | 信号日 t 的 **10 日残差收益**：`O[t+11]/O[t+1] − 1` 减去该名字滚动 120 日、向 1 收缩 0.7、截断 [0.3, 2.0] 的 β 乘以同两个开盘之间的基准收益；再在当日成分截面上取秩 `(rank−1)/n − 0.5`。**本轮全轮固定**；排序目标的相关度等级从它切出来，不是新标签 |
| 参数点 | LightGBM **单点参数**（31 叶、学习率 0.05、`feature_fraction` 0.8、`bagging` 0.8/1、`min_data_in_leaf` 200、`lambda_l2` 10、`num_threads` 8、种子 7），冷启动 600 轮 / 早停 50，续训 +150 轮，验证 = 最后 60 个训练 bar、之前隔 10 日 |
| 持久化 | booster 写进 `context.state_dir`；一次回放的第 1 次 `fit` 冷启动，此后 `init_model` 续训，**每第 4 次重训冷启动一次**。哪条腿续训写在 `LEGS` 里 |
| 篮子 | **每个自然月的首个决策日复核**（空仓时任何决策日都复核）；**50 席等额现金**；离开最新成分截面、丢分数或丢 K 线的持仓无条件卖出；名次落到 100 名（`SEATS × KEEP_BAND`）之外才可被替换；每次复核最多换 8 只（被迫卖出先算）；一手买得起才可填空座，**已持有的名字不因买不起被强卖**；卖出 09:30、买入 15:00，按 T-1 收盘**四舍五入到最近整手**再按现金截断 |
| 同分 | 分数并列时按**代码的固定散列**排先后（头包按代码本身，那在并列多的分数上是一次板块倾斜）。`c_base` 的分数没有并列，实测它的书与头包逐字节相同 |

## 本臂动的两件事

### DoubleEnsemble（`de1`，`lib/double_ensemble.py`）

算法、出处与证据在 `references/double-ensemble.md`，这里只登记形状：

| 项 | 登记值 | 理由 |
|---|---|---|
| 子模型数 K | 3 | Qlib 的 Alpha158 配置，正是给出可搬运证据的那组；论文用 6。K 是成本的杠杆（`sources.md`） |
| SR | α1 = α2 = 1、10 箱、decay 0.5 | Qlib 配置 |
| FS | 5 箱、保留 0.8 / 0.7 / 0.6 / 0.5 / 0.4 | Qlib 配置；**每个子模型都从全部 158 列里选** |
| 子模型的树参数 | 载体的参数点 | 不取 Qlib 的树参数（学习率 0.2、210 叶、λ1 205、λ2 581），否则同时改了两件事 |
| 子模型的树数 | 第 1 个按载体规则早停；第 2…K 个不早停，训练同样多的树 | 它们优化的是重加权后的损失，按不加权的验证损失早停会在 3–4 棵树时就停下，集成退化成 `c_cold`（实测）；Qlib 报出读数的配置本来就是固定轮数 |
| 持久化 | **每次重训冷启动，构造决定** | 权重与列子集每次重算，booster 不能在另一组列上续训 |
| 集成 | K 个子模型的简单平均 | 论文与 Qlib |

### 顶部加权的排序目标（`lr1`）

| 项 | 登记值 | 理由 |
|---|---|---|
| 目标 | LightGBM `lambdarank`，**一个决策 bar 一个查询组** | 损失只关心同一天里谁排前面，这正是一本 50 席的书在做的事 |
| 相关度 | 同一个秩标签按等宽切成 **20 个整数等级**（`labels.grades`） | 每级约 5 % 的名字；不引入新标签 |
| 增益 | **线性**（增益 = 等级） | 实测：LightGBM 默认的指数增益 `2^g − 1` 在本载体上学成了一次**离散度押注**——验证 bar 上对标签的秩 IC −0.113、对标签绝对值的秩 IC +0.251，它在挑两头的名字；线性增益读 +0.091 与 −0.043，与载体（+0.083 / −0.133）同向。这是一次非退化检查，不是在验证集上挑参数（`sources.md`） |
| 顶部加权 | NDCG 的位置折扣，外加 `lambdarank_truncation_level` = 100（登记席数的两倍） | 顶部加权来自位置，不来自增益 |
| 早停 | 验证 bar 上的 NDCG@`SEATS` | 书的深度 |
| 持久化 | 与载体相同的续训节拍 | 只差目标函数，不欠冷启动对照 |

**一个必须事先说出的读数**：在载体的参数点上，`lr1` 在第四研究年的训练窗里**只长 2 棵树就早停**（把学习率降到 0.005 也只长到 8 棵，验证 NDCG 在前十轮之内见顶），决策日可打分成分里只有约 23 % 的分数互不相同。这就是「同参数点、只换损失」在这个载体上的样子，本包不为它改参数点；并列由上表的「同分」规则处理，结果笔记要报不同分数占比。它意味着 `lr1` 很可能过不了离线门——那是一个读数，不是一个要修的 bug。

## 腿

| 名称 | 定义（`LEGS`） | 身份 | 用途 |
|---|---|---|---|
| `c_base` | 单 booster、L2、续训 | **必跑对照（`control: true`），永远不得提名，永远是一批里的第一条腿** | 本臂命题的另一半；离线门与整期消融的分母 |
| `de1` | DoubleEnsemble、L2、每次冷启 | **主候选，可提名**（`control: false`） | 命题（i）：学习器侧的集成 |
| `lr1` | 单 booster、lambdarank、续训 | **主候选，可提名**（`control: false`） | 命题（ii）：顶部加权的损失 |
| `de_lr` | DoubleEnsemble、lambdarank、每次冷启 | **组合候选，可提名**（`control: false`），但只在 `de1` 与 `lr1` 各自赢过 `c_base` 之后才进整期 | 两件事叠加。SR/FS 的逐样本损失在排序目标下是本包的登记改写（`references/double-ensemble.md`） |
| `c_cold` | 单 booster、L2、每次冷启 | **诊断对照（`control: true`），永远不得提名** | 把 `de1 − c_base` 拆成「不续训的价值」`c_cold − c_base` 与「集成的价值」`de1 − c_cold`。离线门里必算；`de1` 领先时进第 2 批整期 |

## 离线门 G-INC2（学习器版；整期批次之前必须通过，**全离线，0 回放年**；筛过的候选配置各计一个 trial）

**登记的判据，一次写死：对每个候选 X，Δ 主动超额（X − `c_base`）≤ 0，或 Δ 秩 IC（X − `c_base`）够不到登记下限，⇒ X 不进整期验证。**

与头包的门一样，**不以 ρ 判**：几条腿共用 158 列与同一个标签，秩相关按构造就高，ρ 照常汇报、只作诊断。与头包的门不一样的是后一半：换学习器没有「新的一块列」，增益份额无从谈起，所以换成**预登记的最低 Δ 秩 IC**。口径、门槛的来历与离线重建的做法在 `references/learner-ablation.md`。

| 量 | 怎么算 |
|---|---|
| **决策日** | 研究期**后两年**里至少 **60 个分散的决策日**（每两周取一天，或等间隔取满 60）。少于 60 天的读数不作判据 |
| **拟合节拍** | 按宿主的季度重训节拍，从第三研究年第一个季度起用空状态目录连续拟合 8 个季度，**每个决策日用它自己那个季度的模型打分**；调用起步包自己的 `main.fit` |
| **两条腿的书** | 每一天在同一成分截面上，各取前 `SEATS` 只等额，持有到下一个信号日 |
| **Δ 主动超额** | **主动** = 前向收益减一个 **k = 20 的离线零技能面板**：每一份副本在**同一成分身份侧**且这笔钱买得起一手的名字里随机换名，取 20 份日收益的等权均值；**面板对每条腿各抽一次、用同一组随机种子**。Δ = X 的主动超额 − `c_base` 的主动超额 |
| **Δ 秩 IC** | 每个决策日，候选分数与**已实现的载体标签**在可打分成分上的 Spearman 相关，取均值；Δ = X − `c_base`。**登记下限：Δ 秩 IC ≥ +0.005，且大于 `c_base` 自己两个种子之间的秩 IC 差**（取两者中较大的那个） |
| **逐年符号一致性** | 两个研究年分开读，**Δ 主动超额与 Δ 秩 IC 在两年里都必须为正**。只有一年为正的 Δ 不是增量；它与「哪一年的行情」不可区分 |
| **Δ 的判定** | Δ 主动超额 ≤ 0 即没有增量；Δ > 0 但**不超过两个随机种子之间的差**也按没有增量算（本家族的方向研究在三个种子之间散开过 4 pp/年） |
| **`de1` 的拆分（只报不判，但必算）** | `c_cold − c_base` 与 `de1 − c_cold`，两半各算。**`de1` 过门而 `de1 − c_cold` ≤ 0**：增益来自不续训而不是集成——`de1` 仍可进整期，但 `hypothesis` 必须改写成这个读数，而且 `c_cold` 必须同批 |
| **ρ（只报不判）** | 选中集合 Jaccard 的中位数与分数逐日秩相关的中位数 |
| **`de_lr`** | 只在 `de1` 与 `lr1` 都过门之后才算；对 `c_base` 用同一张表判 |

**这道门能说什么、不能说什么**（研究教训登记 §4，逐条适用）：

- **离线读数只有秩与消融方向是可信的，水平与 Δ 的幅度不可信。** `gnn_relation_1m_20260922` 的锚定检查里秩相关逐位复现（spearman = 1.0），而 Δ 从离线 +5.54 pp/年 翻到实测 −0.63 pp/年。所以本门读的是**符号与排序**，不是那个数值有多大；结果笔记里写 Δ 的数值时必须同时写这一句。
- **离线面板与宿主面板不是一回事。** 宿主走完整 Broker 重放（结算分红、按实际价格成交、现金不足会拒单），按候选自己的成交骨架换名；离线口径**系统性偏低且更宽松**（实测同一本书骨架面板读 +4.91 %/年，离线重定价近似只读 +2.18，主动 IR 从 1.08 掉到 0.890）。
- **门只能否决，永远不能证明边际。** 它说「不够格」时可信，说「够格」时只意味着可以花那些回放年。**裁决是宿主的整期批次，不是这道门。**
- **这道门不花回放年，但不是免费的。** 它筛过的每一个候选配置都计一个 trial：提交的在宿主验证时计，筛掉或暂缓的在下一批的 `offline_trials` 里申报（下文验证计划）；去膨胀 Sharpe 概率正是本仓库多数臂真正卡住的那堵墙。它省下的是回放年与一次给不出资格的子跨度回放，不是 trial。

命中判据时允许的去处只有一轮变体：`de1` 走轴 a 或轴 b 之一，`lr1` 走轴 c，每一轮都重跑本门；仍不成立就放弃该候选。两个主候选都放弃，本臂以 `no_edge` 结束。

> 头包的「子跨度验证只用来复测实现与耗时，不用来在候选之间做选择」**原样保留**：本门不用子跨度回放，提名依据仍必须来自完整研究期验证。

## 验证计划（先登记，再花回放年）

冻结门的试验数 M 是本臂验证过的非对照 revision（任何跨度、任何尝试）加上各批申报的 `offline_trials`，按这些试验日度评分序列的平均两两相关 ρ̄ 折成有效试验数 N_eff = ρ̄ + (1 − ρ̄)·M；DSR 的离散度只由研究期长度决定（四个研究年约 0.5），与本臂跑了哪些对照无关。公式与阈值以运行事实 `acceptance_rules.freeze_gate` 为准（本轮默认 `min_dsr_probability` 0.975），每行 `selection_statistics.information_ratio_bar` 就是此刻过门需要的主动 IR。本臂的两项登记因此一次写死：

- **`control`**：`c_base` 与 `c_cold` 永远写 `control: true`——照常花回放年、计入完整研究期验证数，但不是 trial，也永远不能提名；`de1`、`lr1`、`de_lr` 与领先候选的第二个种子写 `control: false`。把候选登记成对照，它就失去提名资格；把对照登记成候选，是白给自己加一个 trial。
- `offline_trials` = 本批申报前离线（研究期数据）筛过、读数影响了本批提交什么、但本批**没有**提交的候选配置数；提交进本批的候选在宿主验证时按 host trial 计，不重复申报；对照永不计；每个配置只在筛过之后的第一批申报一次；没有筛过任何候选配置才填 0。离线门（含变体轴的重筛）里跑的 `c_base`、`c_cold` 与 `c_base` 的第二个种子都是对照。

| 批次 | 腿（`control`） | 条件 | 完整期验证 / 其中 trial / 回放年 | `offline_trials` |
|---|---|---|---|---|
| 第 1 批 | **`c_base`（第一条，true）** + 过了离线门的 `de1` / `lr1`（false，**最多 2 条**） | 至少一条候选过门；两条都没过就不开，以 `no_edge` 结束 | ≤ 3 / ≤ 2 / ≤ 12 | `de1` / `lr1` 里没过门、没提交的条数（0–1），加已筛而暂缓的 `de_lr`（0–1） |
| 第 2 批 | 领先候选的**第二个种子**（false）；领先的是 `de1`（或 `de_lr`）时加 **`c_cold`**（true）；`de1` 与 `lr1` 在第 1 批**都**赢过 `c_base` 且 `de_lr` 过了离线门时加 **`de_lr`**（false） | 第 1 批里有候选在整窗与至少 3 个研究年上主动读数不低于 `c_base` | ≤ 3 / ≤ 2 / ≤ 12 | 第 1 批之后新筛、本批没有提交的候选配置数（被否决的 `de_lr` 或变体轴重筛），没有就 0 |
| 收官 | 补齐缺的读数并冻结，或 `no_edge` | 见下文提名条件 | 0 | — |

**上限写死：本臂在任何情况下不超过 6 个完整期验证（对照也算）、24 个回放年。** 一条变体轴（下表）只能在不越过这个上限的前提下替换第 2 批里的某一条腿，而且它先要重过离线门、在那一批申报。子跨度验证不在计划里：非对照 revision 在任何跨度上验证都计 trial，却不给资格。

**trial 账与它要求的 IR，事先算清。** 每个筛过的候选配置恰好计一次（提交的按宿主、没提交的按离线），所以第 1 批之后 M = 2（`de1`、`lr1` 各一次；已筛而暂缓的 `de_lr` 再加 1）；按计划排满（不换轴），M = 宿主 4 个候选（`de1`、`lr1`、第二个种子、`de_lr`），暂缓过的 `de_lr` 多计一次时为 5。几条腿共用载体、158 列与标签，日度主动序列高度相关，ρ̄ 在 0.7–0.9 时 N_eff 约 1.1–2.2。四个研究年、阈值 0.975 下，N_eff = 2 / 3 / 5 时过门要主动 IR 约 1.24 / 1.41 / 1.58，N_eff = 1 也要约 0.98（正态近似）。载体自己读 0.4642，文献给学习器的预期增量是零点零几到零点一几：**冻结需要学习器把载体的主动 IR 抬到两倍以上，本臂事先不指望它**，它的信息价值在消融读数本身（`README.md`）。

## 提名条件（冻结前逐条满足）

1. 离线门已通过，两半读数与 `de1` 的拆分都写进结果笔记。
2. 完整研究期验证完成，冻结门按运行事实通过；至少达到运行事实 `min_full_span_validations`。
3. **稳定性**：逐年分块的**主动**超额为正的研究年 ≥ 四分之三（四个研究年时 ≥ 3）。
4. **`c_base` 同批**，且候选在整窗与至少 3 个研究年上主动读数都不低于它。**这是本臂的核心条件**：赢不了原来的学习器，就没有这条臂。
5. **`de1` 或 `de_lr` 提名时，`c_cold` 同批**，且 `de1 − c_cold` 在整窗上为正。否则那份增益属于「不续训」而不属于 DoubleEnsemble，候选按 `c_cold` 的读数改写 `hypothesis`，不以 DoubleEnsemble 的名义提名。
6. **两个种子**：至少两个种子的主动信息比率之差已汇报；比种子差还小的优势不是证据。
7. P2 / P3 / P4 / P5 全部成立。
8. **集中度与换手**：`pnl_concentration.top5_share_of_gross_gains` ≤ 0.5；年换手 ≤ 12 倍。
9. **实现底线**：`phase_seconds` 里单次 `fit` ≤ 1,800 秒；容器内存峰值**明显低于 16 GiB**；单次复核决策 < 60 秒；意图买单拒单率 ≤ 30 %；**座位填满率**与买不起份额逐次汇报。不成立先修实现再复测，不算证伪。

主动超额 ≤ 0、空对照分位在 0.5 附近、去膨胀 Sharpe 概率接近 0 都是普通「没有边际」读数：候选不可提名，不触发家族关闭。

## 什么会杀死它（按命中即停）

1. **离线门在 `de1` 与 `lr1` 上都命中，且各自的一轮变体轴之后仍命中** —— 这两个学习器在这个载体上没有增量。本臂以 `no_edge` 结束。
2. 连续两批完整研究期验证里没有一条候选赢过同批的 `c_base` —— 以 `no_edge` 结束。
3. 主动超额为负的研究年连续两批都过半 —— 关闭。
4. 每一个可行席数上 `excess_at_2x_slippage` 都 ≤ 0 —— 机制可能真实但在这个账户上不可交易，先走轴 d 的另一端一轮，仍不成立即以「不可交易」关闭。
5. **为了追读数把复核节奏改回周度，或给排序腿单换参数点** —— 这不是一个结果，是一次违规。
6. P2 在所有已登记构造下都不成立 —— 关闭并写明是哪个行业带上去的。
7. 提名条件 9 修复一次后仍不成立 —— 该变体放弃，不算家族证伪。
8. 验证计划的 6 个完整期验证用完而没有可提名候选 —— 以 `no_edge` 结束。

## 臂级终止规则

任一成立即本臂关闭：上面第 1、2、3、8 条命中；预算用尽前没有可提名候选。关闭以 `finish_session(outcome="no_edge")` 携读数结束本臂，**不换家族**，不把 `c_base` 或 `c_cold` 改作候选。`no_edge` 是结论不是退路：只有在没有还有先验的变体轴可换、或完整期验证的上限已经用完时才用它，不要让预算耗尽（流水线记 `deadline`）代替这个结论，也不要为了有一个交付而冻结一个不满足条件的候选。**两个学习器都赢不了 `c_base`，本身就是登记册最想要的一行**：它说明这个载体的短板不在学习器。
