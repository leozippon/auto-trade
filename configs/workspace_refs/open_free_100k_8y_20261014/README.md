## 方向

为这个账户找一条只做多的选股边，数据面是日线与每日指标、指数与申万行业、财务报表（连同业绩预告、快报、分红、审计意见、主营构成与披露计划）和公告标题。合同之内什么都可以：规则或学习、截面或事件时间、一个机制或几个合起来、任何持有期与复核节奏。本包不写定方向之内的任何东西。

- **财务域单独挂的时候也关了。** 开放、事件、行业周期与学习四条线，最好的整期非对照行离门槛很远。

## 本方向的对照要点

两类信息合起来的书，增量要对只用其中一类的同一本书成立（例如报表加标题的书对只用标题的同一本书，同席位、同骨架），否则多出来的可能只是容量而不是信息：序列袋上的财务塔，早融合多出来的就是容量（它自己的打乱对照比基线还高）。其余对照照 `open-rules.md` §3。
