## 方向

日线的开、高、低、收、量、额，在排了序的价量因子之外还说了什么。要找的是写得出来、带安慰剂的机制，而不是又一个学出来的排序：

- 把收益拆成隔夜（前一日收盘到今日开盘）与日内（今日开盘到收盘）两段，看哪一段、在什么名字上带着下一段的信息；
- 涨跌停的动力学：涨停之后的延续、跌停之后的反转、开板与回封，都能从收盘价对 `up_limit` / `down_limit` 推出来；
- 公告前后的开盘跳空：标题挂在本臂上，跳空可以按「前一天有没有公告」分开看；
- 以成交量为条件的反转与延续：放量下跌与缩量下跌、放量上涨与缩量上涨之后走得不一样；
- 振幅、上下影线与收盘位置这一类日内形态。

学出来的价量排序在这份记录上是关闭的（`refs/families.md` 前两行）：它们在冻结门上过得便宜，之后没有一本站得住。这条臂的每个候选都是一条能用一句话写清的规则，带它自己的标准对照。

## 值得一看的（建议，不是菜单）

下面是外部文献与市场规则，不是宿主读数，都要在研究期上自己核对。

- **A 股的隔夜与日内。** T+1 让开盘买入的人当天卖不出，国内研究普遍读到隔夜收益平均为负、日内为正（与美股相反，例如 Qiao 与 Dam 2020 年关于 T+1 与隔夜收益之谜的工作）；美股上动量的收益落在隔夜、其余异象落在日内（Lou、Polk 与 Skouras 2019）。值得问的是截面：近期隔夜收益偏高（多是注意力驱动的跳空）与日内收益偏高的名字，之后各走哪边；A 股上前者常被读作散户注意力。
- **涨跌停规则。** 主板 ±10 %；创业板 2020-08-24 起 ±20 %（之前 ±10 %）；ST ±5 %；注册制新股上市前五个交易日不设涨跌幅。收盘涨停可以用 `close >= up_limit − 0.005` 判断，跌停同理；一字板（`high == low` 且在涨停）买不进。
- **成交约束决定了哪些想法能实现。** 策略 08:30 只看到 T-1；09:30 按开盘价、15:00 按收盘价成交；涨停的买单整单被拒。所以「涨停次日延续」在 10 万账户上多半买不到，「跌停后的反转」只能在开盘或收盘买；任何基于当天开盘价的条件都只能在 15:00 执行。
- **以成交量为条件。** 放量伴随的价格变化更可能是信息、缩量的更可能是流动性冲击（Llorente、Michaely、Saar 与 Wang 2002 的框架）；在 A 股短周期上它常表现为缩量下跌后反弹、放量上涨后回落。普查的成交量族全负，提醒你这一边的读数多半在剔除侧。

## 成本是这条臂的头号敌人

日线微结构的信号多半是几天的周期，换手高。按 `open-rules.md` §2 的表，30 席一个完整回合约 0.5 个百分点，20 席约 0.4；一本每周整本换一遍的 20 席书一年要付约 20 个百分点，冻结门的成本压力（滑点翻倍）下必死。估一个候选之前先估它的年换手与回合成本，按 `graduation_activity` 与成本压力下的原始超额读整期行；能把持有期拉长、只换掉分数掉出保留带的名字，往往比更准的信号值钱。

## 本方向的对照要点

- 截面规则（按某个形态或分数在池里挑名字）：`lib/controls.py` 的 `shuffled_assignment`，同样的日子、同样多的名字从可买池里抽。
- 事件式规则（涨停、跌停、公告后的跳空之后进场）：`late_entry`，同一批事件晚进场。
- 剔除式规则：`random_skip`，同一张候选单上随机跳过同样多的名字，核心本身是声明过的构造。
- 所有离线读数先去掉涨停买不进、停牌卖不出的成交：离线收益里最大的伪读数就是它们。
