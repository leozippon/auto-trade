# 风险成形的现金流质量参考包（quality_lowrisk，20260916）

本目录是只读 refs：把**现金流支撑的盈利**当排名信号，把**规模与残差波动**当构造，做一个不训练的只做多季度篮子，并按预登记的对照判定这条腿在组合尺度上是否真的在承载。它不是可提交策略，也不是预期收益。

任务只有一句话：在同一个股票池里，**先按流通市值截到较大的一半，再在现金流质量前 30 名里持有 60 日残差波动最低的 15 只，季度复核**，同批比过三个对照——**不成形的质量 15 只**（`c_q15`）、**同一构造去掉质量排名**（`c_ivol`，只剩残差波动）、**没有分数的等权池篮子**（`c_pool`）。赢不过 `c_q15` 说明成形没有用；赢不过 `c_ivol` 说明质量腿没有在承载，边际其实来自低波；赢不过 `c_pool` 说明两者都不在。判据只按 `families.md`。

按以下顺序读：

1. `families.md`：主候选与构造、三个对照、**提名硬门与禁止表（关闭判据的唯一权威表述）**、允许的变体轴、臂级终止规则。
2. `pit-field-map.md`：逐表可见时点、单位、去重规则与陷阱（唯一权威表述）。
3. `exploration-plan.md`：不占预算的普查、首轮批次、判定分支、后续轮次。
4. `sources.md`：构造规则的来源读数与复现命令、起步包的沙箱冒烟实测、诚实的限制。
5. `starter/`：合同内的最小可运行包（`main.py` + `lib/face.py` + `lib/trade.py`），**不是**候选本身。它通过 `validate_strategy_package`，并在沙箱镜像里以真实 as-of 布局跑通了「读取 → 波动与报表 → 打分 → 中性化 → 成形 → 出单」全链路（读数见 `sources.md`）；正式回放的第一步仍然是 `smoke_backtest`。`main.py` 的 `CANDIDATE` 常量在四条腿之间切换，四者除这一行外必须逐字相同。**会话开始时 `output/` 就是这份代码**，`refs/starter/` 只是同一份的只读参考副本。

## 机制与这一次改的是什么

收益来源的经济解释是应计异象的一个形态：没有经营现金流支撑的盈利（高应计）被外推、随后修正，现金流支撑的盈利者在一到三个月里向上漂移。这条腿在本仓库的方向研究里是少数几个在受控截面上稳定为正的非价量信号之一。

**这个包改的不是分数，是分数到篮子的映射。** 同一条腿以「15 只、月度复核、不做风险约束」的形状交易时，跟踪误差 20 % 以上、最大回撤接近 40 %，而流水线的前推门要求年化中性化超额的 80 % 自助下界为正——大致相当于超额要高于 0.84 倍的跟踪误差——并要求最大回撤不超过参数上限。也就是说，**卡住这条腿的是构造的风险，不是信号的有无**。`sources.md` 记的研究期离线读数是：把池截到较大的一半、再在质量前 30 名里取残差波动最低的 15 只，跟踪误差 21.5 → 13.5 %、最大回撤 39.0 → 24.4 %、信息比率 0.40 → 0.54、下界 −1.1 → +1.8，代价是 1.2 pp/年的中性化超额。

必须同时写明这次成形的**代价**：同一个动作把持仓的规模倾斜从 0.80 压到 0.24，把同一窗口的原始净收益从 +89 % 压到 +38 %。中性化超额是把规模因子除掉之后的读数，所以「去掉小市值暴露」会同时改善裁决统计量并减少实际赚到的钱。本臂的门定在中性化统计量上（流水线的冻结门与前推裁决都读它），但**每个候选都必须把原始超额与规模倾斜作为第二读数一起汇报**（`stats.benchmark.excess_return`、`stats.benchmark.size_tilt`、`stats.benchmark.beta`），说明它到底在优化哪一个。`style_analysis.json` 是宿主侧的旁文件，会话读不到它，不要去找。

同样必须写明：这条构造规则是在 36 个组合配置里唯一一个下界为正的配置。它应当被当作「值得预登记的构造规则」，不是「已经量到的边际」；本臂在研究期上是否成立，只由自己的完整研究期验证与 `families.md` 的硬门回答。

## 本臂的执行边界

执行合同——入口与订单、允许的 import、文件 I/O、`available_at` 与 PIT 读法、不写死宿主路径、沙箱无网络——以只读 `output/README.md` 与系统提示为准，本包不复述。本臂只在以下几点上更具体：

- **本包不训练**：没有 `fit`、没有 `REFIT_PERIOD`，每次决策是四次有界的 parquet 读取、一次 60 日滚动回归加一次最小二乘。学习型合成是禁止项（`families.md`），不是变体。本臂 `gpu_count=0`。
- 本臂不挂分钟域（运行事实 `execution_policy`），执行时点只有 09:30 与 15:00。
- 不要把 `refs/` 里的文件拷进 `output/`：整棵包是只读的，`cp` 会把权限一起带过去；会话开始时 `output/` 已经是 `starter/` 的内容，不必移植。

## 账户与成本

研究期几何、预算、冻结门与毕业条件以运行事实为准，会话流程见系统提示，本包不复述；本臂以 `no_edge` 结束的条件见 `families.md` 的终止规则。

账户与费率以运行事实 `broker_replay` 为准。按本臂的 15 只等权、97 % 仓位，单只预算约 6,300 元，最低佣金即 7.9 bp/边，一次往返约 25–35 bp。起步节奏是**季度复核、2 倍保留带、每次最多换 8 只**：按此上限每年约 32 次换名 ≈ 200 % 年换手 ≈ 0.5–0.6 % 的年成本拖累（第 0 轮普查用研究期实测核对）。成本门是本臂的硬门，判据写在 `families.md`。

## 「没有边际」的读法

每个候选按 `families.md` 的提名硬门逐条读，不看整窗总收益；本文不复述判据。另外三点读法：

- 逐年读。一个整体落在宽幅高波动上涨行情里的研究年上，防御型篮子的原始超额天然接近零；把 `stats.sub_windows` 的中性化超额与整窗读数一起读，不要让一个研究年决定裁决。
- 中性化是机制定义的一部分，不是可删的降噪：质量腿不对 `ep` 与 `yoy_np` 中性化就不再是本包登记的那条腿，残差波动列不对 `vol_20`、`max_20` 中性化就退回已关闭的 20 日彩票面。
- `run_null_control` 只给完整研究期的决赛候选算（次数见 `budgets`）；`selection_statistics.deflated_sharpe_probability` 是冻结门此刻对该节点的读数，已按本臂的试验数打折。研究期整窗读数好看不等于前推成立：不要把提名条件当目标函数去逼近，逐年分块与空对照分位是同等的硬门。

没有候选证明边际时，不冻结是正当结果：按 `families.md` 的终止规则以 `no_edge` 携读数结束本臂。

## 禁止退回通用因子

本包的候选形态只有 `families.md` 登记的主候选与变体轴；手写的价值/反转/动量/换手/`max20`/`vol20` 打分不得作为候选，只能以中性化列的身份出现。`c_q15`、`c_ivol`、`c_pool` 是对照，**不得被提名冻结**。`families.md` 的禁止表里每一项都带着关掉它的研究期读数，不得以「再试一次」的名义重开。

## 本包的硬要求

跨实验的运行教训不写在参考包里（见 `inputs/skills_index.json` 的运行记忆）。本包只指一条硬要求：**普查面板与决策截面必须由同一个函数构建**（`starter/lib/face.py` 的 `build_cross_section`），构造规则必须由同一个函数施加（`starter/lib/trade.py` 的 `_shape`）。
