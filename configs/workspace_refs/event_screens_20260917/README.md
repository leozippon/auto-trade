# 事件面筛子参考包（event_screens，20260917）

本目录是只读 refs：把**三个从来没有被读过的点内事件面**——审计意见、限售股解禁、分部收入构成——当**排除筛子**登记，装在一条借来的、不训练的只做多季度篮子上，并按预登记的对照判定「把这些名字剔出股票池」这件事本身在组合尺度上是否真的在承载。它不是可提交策略，也不是预期收益。

任务只有一句话：在姊妹臂 `lowvol_bucketed_20260917` 逐字相同的池、分数与构造上，**先剔掉最新审计意见不是无保留意见的名字、剔掉未来 90 个自然日内已公告解禁量合计 ≥ 3 %（占总股本）的名字、再剔掉收入最集中的一成，然后照原样按 60 日残差波动在行业与规模桶里填出 15 只、季度复核**，同批比过三个对照——**不筛的同一个篮子**（`c_noscreen`）、**筛子换成同样大小的永久随机排除**（`c_placebo`）、**没有分数的等距池篮子**（`c_pool`）。赢不过 `c_noscreen` 说明筛子没有用；赢不过 `c_placebo` 说明赢的是「选择集小了一点」而不是「这些名字该走」；赢不过 `c_pool` 说明两者都不在。判据只按 `families.md`。

按以下顺序读：

1. `families.md`：主候选与三个筛子的定义、三个对照、**提名硬门与禁止表（关闭判据的唯一权威表述）**、允许的变体轴、臂级终止规则。
2. `pit-field-map.md`：逐表可见时点、单位、去重规则与陷阱（唯一权威表述）。三个新面每一个都带着一条会静默把筛子改成别的东西的陷阱。
3. `exploration-plan.md`：不占预算的普查、首轮批次、判定分支、后续轮次。
4. `sources.md`：借来那条腿的研究期读数、三个面的**反向证据**、本包自己的研究期普查读数、起步包的沙箱冒烟实测、诚实的限制。
5. `starter/`：合同内的最小可运行包（`main.py` + `lib/face.py` + `lib/screens.py` + `lib/trade.py`），**不是**候选本身。它通过 `validate_strategy_package`，并在沙箱镜像里以真实 as-of 布局跑通了「读取 → 波动与报表 → 打分 → 中性化 → 三个筛子 → 桶内填位 → 出单」全链路（读数见 `sources.md`）；正式回放的第一步仍然是 `smoke_backtest`。`main.py` 的 `CANDIDATE` 常量在四条腿之间切换，四者除这一行外必须逐字相同。**会话开始时 `output/` 就是这份代码**，`refs/starter/` 只是同一份的只读参考副本。

## 机制与本臂要回答的那一个问题

假说是关于**风险**的，不是关于 alpha 的：池子的左尾里有一部分名字，风险是**提前披露过、而本仓库任何一条臂从来没有读过**的——一份非无保留意见的审计报告、一笔马上要落地的大额解禁、一个压在单一产品上的收入基础。如果这条尾巴承担的风险没有被补偿，那么把它剔掉应该**通过分母和回撤、而不是通过分子**抬高信息比率，并且应该托住最弱的那个研究年。

登记的层次是**股票池的成员资格**，不是一条新的排序分数。三个面只回答「这个名字在不在池子里」，进池之后的排序、中性化、桶与节奏全部是姊妹臂的固定件，一个字都不改。这样本臂只有一个自由变量，而 `c_noscreen` 就是把这个变量关掉的那条腿——它与并行在跑的 `lowvol_bucketed_20260917` 的主候选 `s_lb` 是同一个篮子，所以两条臂互为复核。

## 必须先知道的三件事

**一、诚实的先验是弱的，而且反向证据是本仓库自己量过的。** `sources.md` 逐条记着：DIR4 §8 把这三个面全都考虑过并且**决定不探**（审计意见「只是约 3 % 公司上的一个空头标记」，分部集中度「没有能扛住规模与行业控制的经济故事」）；股票池本来就剔除 ST，已经吸收掉大部分财务造假的尾部；而本仓库唯一量过的**同形状**东西——融资拥挤排除筛子——在超额与回撤两头都是空的（同一个季度 15 只篮子：中性化超额 +8.5 → **−0.1** %/年剔掉最拥挤一成、**−3.9** %/年剔掉两成，最大回撤原地不动在 40 % 附近）。本臂仍然值得跑的理由只有一条：这三个面是本仓库挂载着、全覆盖、带点内时间戳、**从来没有人读过**的数据，而它们只能以筛子的形式被读一次。

**二、这个构造只动两三只名字，而审计意见这一个筛子一只都不动。** `sources.md` 记着五个研究年首个决策日的实测：三个筛子合起来剔掉筛后池的 **12.0–14.9 %**，但篮子与不筛的篮子重合 **12/15 或 13/15**；单独跑时，审计筛子在五天里**每一天**都给出与不筛完全相同的 15 只（15/15），解禁筛子换 0–2 只，分部筛子换 1–3 只。所以「审计意见有没有用」这个问题在组合尺度上很可能**答不出来**，这一点必须写进第 1 轮的 `hypothesis`，而不是等读数出来再解释。

**三、要抬的那三个数，借来的这条腿一个都不够。** `c_noscreen` 这条腿的等价物已经有两份互相复核的完整研究期读数（`sources.md`）：信息比率 **0.75**、四个研究年里只有 **2 个**为正、最大回撤 **31–33 %**。本臂的门要的是 0.95、4/4、≤ 22 %。也就是说，本臂押的是「剔掉一成多的名字能同时把这三个数搬过去」，而它每次只换两三只名字。门 2（严格高于三个对照）与门 4（回撤 ≤ 22 % 且严格低于 `c_noscreen`）因此是极硬的线，不是形式要求。

## 回撤这条门为什么定在 22 % 而不是 25 %

流水线自己硬拒的线是研究期最大回撤 > 0.25（运行事实 `max_drawdown`），比本包的 22 % 松。本包仍然取 22 %，因为**本臂登记的机制直接作用在回撤上**：筛子声称剔掉的是不被补偿的左尾，如果它成立，回撤就该是最先动的那个读数；如果 22 % 压不下来，那正是这个机制不成立的证据，而不是门定错了。同理，门 4 要求**严格低于 `c_noscreen`**——绝对值达标但不比不筛的篮子低，说明压下回撤的是市场而不是筛子。轴用尽后仍压不到 22 % 时，正确的结论是按臂级终止规则以 `no_edge` 结束并把读数写清，**不是**把门 4 调松。

## 本臂的执行边界

执行合同——入口与订单、允许的 import、文件 I/O、`available_at` 与 PIT 读法、不写死宿主路径、沙箱无网络——以只读 `output/README.md` 与系统提示为准，本包不复述。本臂只在以下几点上更具体：

- **本包不训练**：没有 `fit`、没有 `REFIT_PERIOD`。每次决策是四次有界的 parquet 读取、一次 60 日滚动回归加一次最小二乘；**只有在季度复核那一天**再多三次有界读取（筛子在 `_shape` 里，非复核日不会走到）。学习型合成是禁止项（`families.md`），不是变体。本臂 `gpu_count=0`。
- **筛子只排除，不准入**。三个面都不得写成「只留下有干净读数的名字」：读不到一行审计意见通常意味着这一行没有被定过时点，读不到解禁记录可能只是数据文档仍然标着触顶风险的来源缺口。把「没读到」当成「不合格」，筛的就是数据覆盖率而不是风险。这条写在 `pit-field-map.md` 与 `lib/screens.py` 的模块注释里，是合同。
- `c_placebo` 的随机排除是**每个代码一次永久抽签**，种子与比例写死在 `lib/screens.py`：它必须在冷 worker、热 worker 与任何后续轮次里给出同一批被排除的名字，也不得随决策日重抽——重抽会把一个「选择集」对照变成一个高换手对照，两件事就混了。种子与比例不得改动（比例是按本包普查实测的三筛并集比例定的，见 `sources.md`）。
- 本臂不挂分钟域（运行事实 `execution_policy`），执行时点只有 09:30 与 15:00。
- 不要把 `refs/` 里的文件拷进 `output/`：整棵包是只读的，`cp` 会把权限一起带过去；会话开始时 `output/` 已经是 `starter/` 的内容，不必移植。

## 账户与成本

研究期几何、预算、冻结门与毕业条件以运行事实为准，会话流程见系统提示，本包不复述；本臂以 `no_edge` 结束的条件见 `families.md` 的终止规则。

账户与费率以运行事实 `broker_replay` 为准。按本臂的 15 只等额、97 % 仓位，单只预算约 6,300 元，最低佣金即 7.9 bp/边，一次往返约 25–35 bp。起步节奏是**季度复核、2 倍保留带、每次最多换 8 只**：按此上限每年约 32 次换名 ≈ 200 % 年换手 ≈ 0.5–0.6 % 的年成本拖累（第 0 轮普查用研究期实测核对）。筛子会让换手略高于不筛的同一个篮子——被剔掉的持仓要用次一档的名字补上，而且**筛子命中持仓时是离池强卖，不占每次 8 只的自主换名上限**——两条腿的换手差本身就是要汇报的读数。成本门是本臂的硬门，判据写在 `families.md`。

## 「没有边际」的读法

每个候选按 `families.md` 的提名硬门逐条读，不看整窗总收益；本文不复述判据。另外四点读法：

- **门 2 的三个对照不是同一件事。** 输给 `c_noscreen` 是「筛子没用」；输给 `c_placebo` 是更重的结论——「被剔掉的是哪些名字不重要，重要的只是选择集小了一点」，这一条命中即刻关闭本臂。输给 `c_pool` 说明腿和筛子都不在。
- **逐年读，并且盯住最弱的那一年。** 本臂假说的一半就是「托住最弱的研究年」，所以 `stats.sub_windows` 的逐年读数与整窗读数必须一起读，并写明哪一年撑起了整窗、哪一年被托住了或者没有。门 3 要求四个研究年全为正，而借来那条腿的两份先验都在第三、第四个研究年转负。
- **每个筛子剔掉多少人，是读数不是细节。** 每张买单都带 `screen_hits`，形如 `pool=1158 audit=8 unlock=56 segment=133`：筛前池的大小与每个筛子的命中数。一个剔掉池子一大块的筛子不是在筛尾巴，是换了一个构造——门 9 因此把「单个筛子每次复核剔除 < 15 %」写成硬线。
- `run_null_control` 只给完整研究期的决赛候选算（次数见 `budgets`），**在本臂里是诊断不是门**，理由与要一起报的两个数写在 `families.md`。研究期整窗读数好看不等于前推成立：不要把提名条件当目标函数去逼近。

没有候选证明边际时，不冻结是正当结果：按 `families.md` 的终止规则以 `no_edge` 携读数结束本臂。

## 本臂借走了另一条臂的整条腿，这是有意的

池、`ivol60` 排名列、中性化列、行业与规模桶、季度节奏与保留带，全部是 `lowvol_bucketed_20260917` 的，一个参数都不动。理由是本臂只想要一个自由变量：**筛子**。三件事把它和那条臂区分开——本臂登记的层次是池的成员资格（那条臂登记的是分数到篮子的映射）、本臂读三个从未被读过的数据面（那条臂不读任何新面）、本臂的 `c_noscreen` 就是那条臂的主候选。因此「把排名列换掉」「把池底或应计筛子调一调」「把桶收紧或放开」在本臂里都是**禁止项**，不是变体：那些是另一条臂的自由度，动了它，两条臂的读数就不再可比，本臂也就答不出筛子归因。

## 禁止退回通用因子

本包的候选形态只有 `families.md` 登记的主候选与变体轴；手写的价值/反转/动量/换手/`max20`/`vol20` 打分不得作为候选，只能以中性化列的身份出现。**把三个面改造成排序分数同样是禁止项**：它们登记的形态就是筛子，改成打分就是去和已关闭的基本面家族撞车。`c_noscreen`、`c_placebo`、`c_pool` 是对照，**不得被提名冻结**。`families.md` 的禁止表里每一项都带着关掉它的研究期读数，不得以「再试一次」的名义重开。

## 本包的硬要求

跨实验的运行教训不写在参考包里（见 `inputs/skills_index.json` 的运行记忆）。本包只指三条硬要求：**普查面板与决策截面必须由同一个函数构建**（`starter/lib/face.py` 的 `build_cross_section`），**筛子必须由同一个模块施加**（`starter/lib/screens.py`，四条腿都走 `screens.excluded`），**构造规则必须由同一个函数施加**（`starter/lib/trade.py` 的 `_shape` 与 `_book`）；四条腿都走这三处，只由 `SCREENS` 与 `SHAPES` 里的一行区分。
