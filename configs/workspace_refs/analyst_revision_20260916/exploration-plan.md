# Fold-ready 探索计划

一折跑多轮 `batch_validate`：第一轮并列比较家族，后续轮次围绕站住的家族比条件、持有期与换手控制。每一步都要产出可执行候选或明确淘汰。有父本时，必须先完成一次与父本可执行逻辑不同的完整 Validation；父本对照由宿主在会话前跑好，不要自己重跑。**一折至少跑完两轮互不相同的预登记候选**，除非预算确实用尽或普查判定本折不可测。

## 步骤

1. **数据合同核对（第一道生死门）。** 读本轮 `data_summary.json`、`unit_reference.json` 与 events/daily/universe 的 schema，逐条确认：`report_rc` 出现在本轮 `events.datasets` 里（它默认不加载，靠 `events_datasets` 选入；只在 text 域出现说明本实验没选中它）；`eps`/`max_price`/`min_price` 登记为 `CNY_per_share`，`op_rt`/`op_pr`/`tp`/`np` 为 `10k_CNY`，`pe`/`ev_ebitda` 为 `multiple`，`rd`/`roe` 为 `percent`；`available_at_rule` 的取值是 `source:create_time` 与 `conservative_from:report_date` 两种。**events 域没有 `report_rc`**，整臂判「不可测」，立即 `finish_fold(outcome="no_edge", reason=...)`。不要用文本域的标题做退化版本。

2. **修正普查（census-first，不占回测预算，只用输入窗，绝不碰验证区间）。** 在 `/mnt/snapshot` 决策视图上用自己的脚本经 `shell` 一次跑完，把数字写进工作区笔记：
   - 输入窗内 `report_rc` 总行数、逐月行数与覆盖股票数、零行日（若有）；
   - `quarter` 的取值分布，确认 `Q4` 占比 ≈ 98.8%，并数出裸 `"Q"` 等异常值的行数；
   - `quarter` 年份减 `report_date` 年份的分布，确认当前财年/+1/+2 三层都在；
   - `available_at_rule` 逐年占比（本折输入窗落在 2020–2021 时应接近 100% 保守盖章）；
   - 业务键 `(ts_code, report_date, org_name, author_name, quarter)` 的重复率，以及其中 `eps` 真的变过的键组占比（去重必须取 `create_time` 最大的一条）；
   - 每个决策日的可选股票数曲线：家族 1（两窗各 ≥2 家券商）、变体 1b（各 ≥1）、家族 2（配对 ≥1）、家族 4（90 日 ≥3 家券商），**每条都分别报「只过流动性」与「再加股价上限」两个版本**；
   - 20 日窗口内每股覆盖券商数的中位与 P90，逐季给出；
   - 同券商相邻两次预测的不变/上调/下调比例，逐季给出。

   **门槛（不满足即判「不可测」并弃权）**：输入窗内数值切片行数为零；或家族 1 的全过滤可选股票数在多数决策日不足 300；或 `quarter` 的 `Q4` 占比显著偏离 98.8%（说明切片改写了这一列的语义）；或业务键去重后行数与去重前差异远超实测的 0.919%。弃权用 `finish_fold(outcome="no_edge", reason=...)`，`reason` 引用具体数字。

3. **固定不变量并写进笔记。** 可交易性过滤、等额现金、缩放下限 0.05、中性化变量集合（`log(circ_mv)`、`mom20`、`mom60`、`turn20`、`vol20`），以及 `README.md`「执行假设」给出的篮子规模、换仓节奏与费用缓冲。**股价上限在这一步一次性定死**：按第 2 步的曲线在 40 元与 60 元之间选一个，写明选择理由与它带来的可选股票数，本折之后不再改。这些是声明值，不在 Validation 上搜索。

4. **离线预筛（同样只用输入窗）。** 对家族 1、1b、2、3、4 各算 5/10/20 日持有期的 rank IC、ICIR、逐月符号一致性、**只做规模中性**与**做全套控制**两种口径的 IC、头部十分位多头超额、覆盖率与换手。截面型家族可用 `python /mnt/tools/screen.py --help` 所述的筛查脚本；匹配对照的普查用自己的脚本。**本方向的判据与别的臂相反**：D1 的证据是这个信号在全控之后**变强**，所以「规模中性 IC 强、全控后塌掉」的家族要直接淘汰，那是动量/换手换皮；只有全控后 IC 不塌、逐月符号多数一致、覆盖 ≥ 300 只的家族才值得一次完整 Validation。

5. **第一轮 `batch_validate`。** 至少三个互不相同的候选并列：家族 1、家族 2（构成免疫孪生，**必须同批**）、家族 4，并且整批必须包含家族 5 或家族 6 的一个对照。`hypothesis` 写清信号定义、财年切片、窗口、方向、持有期、篮子、匹配对照与否证条件，且必须在看到任何结果之前写定（每条 ≤ 500 字符）。匹配对照的用途只有一个：证明边际不是「被覆盖」这个选择效应带来的。

6. **第二轮起围绕站住的家族。** 一次只改一个组件：券商家数门槛（≥1 / ≥2 / ≥3）、财年切片（当前财年 → FY+1）、窗口长度（20/40 日 vs 20/60 日）、持有期（10/20 日）、换手控制（部分换仓对照整篮重排）、股价上限。需要拟合的合成放在 `fit(context)` 里：固定 λ 的 ridge（λ 预先声明）或 LightGBM/XGBoost 排序器（`num_leaves <= 31`、`n_estimators <= 300`、`learning_rate 0.05`，参数预先声明），训练窗与验证窗之间空出持有期长度的禁运，标签是同持有期的规模中性前瞻收益 rank，`REFIT_PERIOD="quarter"`。合成候选必须与最佳单家族同批比较。

7. **家族被证伪后的切换纪律。** 一个家族在带匹配对照的完整 Validation 上落败，就不要用参数邻域重刷它（不同的券商家数门槛、不同的窗口长度都算同一个家族）；换到本包登记的**另一个**家族。家族 1 与家族 2 都落败即触发 README 的臂级终止裁决，剩余预算只能用于家族 3、4，不得改成价量打分。

8. **新季度裁决。** 每个候选按 README 的「没有边际」清单读；`sub_windows` 的四行分别报相对匹配对照的超额、可选股票数、平均覆盖券商数、成交笔数、拒单率、旺季/淡季分层读数。**本折验证区间里只有最后一个季度是父本没见过的新数据段**，父本对照也只在这一行上真正是样本外。新季度为负而候选也没有转正的，不提名。

9. **收尾。** 用 `step_rollback` 把胜出节点恢复到 `output/` 再 `finish_fold`。全部家族被证伪时以 `finish_fold(outcome="no_edge", reason=...)` 弃权（首折记为 `baseline_missing`），并留下证伪结论与下一折的不同假说。

## 回测预算分配（每折 24 次回测的建议切分）

普查与离线预筛不占回测预算。24 次的建议分配：

| 用途 | 次数 |
|---|---|
| 第一轮：家族 1 + 家族 2 + 家族 4 + 各自匹配对照 + 一个机制无关对照 | 8 |
| 第二轮：胜出家族的一个组件变更 + 家族 3 或变体 1b + 对照 | 7 |
| 第三轮：合成或条件叠加，与最佳单家族同批 | 4 |
| 稳健性（持有期、股价上限、旺淡季分层） | 3 |
| 留白（普查发现意外时的重做） | 2 |

第一轮用掉三分之一是刻意的：本臂的核心问题「家族 1 与家族 2 是否同号」必须在第一轮就有答案，它决定后面十几次回测测的是什么。若第一轮就得到两者反号，直接关闭家族 1、把预算移到家族 2 的组件变更上。

## 写进 PRIOR 的内容

无论本折结果如何，给 Meta 的 PRIOR 至少要能回答四件事，每件都带数字：

1. **切片是否被选入**：`report_rc` 是否出现在本折 `events.datasets` 里、`quarter` 的 `Q4` 占比、业务键重复率。这是后续所有折的前提，只需确认一次。
2. **覆盖是否够用**：家族 1 在本折每个决策日的全过滤可选股票数（最小/中位/最大）与所选股价上限。若本折因淡季覆盖不足而弃权，写明具体月份与只数，让后续折知道这是季节性而不是机制失效。
3. **家族 1 vs 家族 2 是否同号**：这条结论跨折有效。同号说明修正内容有信息；反号说明一致预期只是券商构成的影子，后续折不必再测家族 1。
4. **对照腿是否吸收**：加入 EP 腿与覆盖度腿后超额的变化幅度。被吸收就是价值/注意力换皮，整条线可以提前关闭，这对后续折的价值大于任何一个通过的候选。

不要把持有期、篮子大小、截尾分位这类邻域参数的比较结果写进 PRIOR。

## 组合纪律

- 家族可分离：一次 Validation 只改一个家族或一个组件。
- 不把两个高度同向（Spearman 绝对值长期 > 0.85）的信号同时放进合成；`rev_c`、`rev_m` 与 `breadth` 首先要查这一条。
- 每一轮都带家族 5 或家族 6 的一个对照；不用它凑候选数，也不提名它。
- 不在 `generate_orders` 里重新拟合任何权重。
- 本折全部候选数事先写在 `TODO.md` 里（建议单家族 ≤ 6、条件/合成 ≤ 3、稳健性 ≤ 3），读 Sharpe 时按 `candidates_evaluated` 打折。

## Validation 否证

- 任何 `available_at`、财年切片、去重、复权锚或单位错误：结果无效，不讨论收益。用 `report_date` 判可见、不按财年切片、把 `tp` 当目标价，都属于这一类。
- 家族 1 与家族 2 符号不一致：家族 1 淘汰。
- 候选相对匹配对照的中性化超额 ≤ 0，或只在一个季度子窗为正：淘汰。
- 加入 EP 腿或覆盖度腿后超额消失：价值/注意力换皮，家族关闭。
- 全控后 IC 明显弱于只做规模中性时的 IC：这是动量/换手换皮，与本方向的证据指纹相反，淘汰。
- 效应按研报旺季（4/5 月、8–11 月）与淡季（1/2/6/7/12 月）分层后消失：测到的是研报日历，淘汰。
- 有效覆盖长期低于 300 只，或某个子窗可选股票数 < 300：判「不可执行」而不是「有边际」。
- 收益集中在少数个股或单一行业；2 倍滑点下超额转负。
- 合成或条件叠加不优于最佳单家族：回退到更简单的一方。

## 本方向已知的失效模式

1. **覆盖的季节性伸缩。** 家族 1 的全过滤可选股票数在 48 个月末实测 180–807 只（中位 408），11 个月末跌破 300，全部落在 1/2/6/7/12 月。这不是数据缺口而是研报日历，剔除不掉。处理方式是在第 3 步一次性定死股价上限并接受某些子窗功效低，而不是在结果不好时回头放宽门槛。
2. **一致预期只有两个数。** 20 日窗口内中位覆盖 1–2 家券商，`mu1` 与 `mu0` 各自只是一两个数的平均。家族 2 是唯一能把「券商换人」与「分析师改看法」分开的构造，因此它不是稳健性附加项，是第一轮的必选项。
3. **预测陈旧。** 31.23% 的相邻预测完全不变，相邻间隔中位 54 天。20 日窗口里有大量「旧数字重发」，会把真实修正稀释成零。家族 3 的 `flat` 计数量出它；若某个子窗 `flat` 比例超过一半，该子窗的读数功效很低，要连同读数一起报。
4. **2020–2021 输入窗没有日内分辨率。** 那两年 100% 是 22:00 保守盖章。输入窗落在这一段的折不要做任何日内分层，也不要把「盖章时刻集中在 22:00」读成发布行为的变化。
5. **成本余量极薄。** D1 实测控制后的多头前五分位超额 +0.20%/20d（t +1.08），而这条换仓节奏的成本拖累是 1.8–2.2%/年 ≈ 0.15%/20d。这意味着**任何一点执行摩擦（拒单、整手偏离、股价上限造成的权重扭曲）都可能把边际吃光**。每个候选都要把拒单率与实际成交笔数当作一等读数汇报，不是附注。
6. **覆盖偏斜与 null control。** 分析师覆盖偏向大市值、高价、活跃的名字，同市值十分位的随机抽名对照回答不了「是不是只要被覆盖就行」。必须补一条**已覆盖股票内部、修正值处于中位区间**的匹配对照，这条比 `run_null_control` 的分位更能决定结论。
