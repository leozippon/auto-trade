# Fold-ready 探索计划

一折先做一次不花回测的普查，再跑至少两轮互斥的预登记 `batch_validate`：第一轮并列比较家族，第二轮围绕站住的家族比变体，或在全部落败后换另一个登记家族。每一步都要产出可执行候选或明确淘汰。有父本时，必须先完成一次与父本可执行逻辑不同的完整 Validation；父本对照由宿主在会话前跑好，不要自己重跑。

1. 读本轮 `data_summary.json`、`unit_reference.json` 与 `macro`/`daily`/`universe` 的 schema：确认 `macro.datasets` 含 `cb_daily`、`cb_basic`、`cb_call`，三张表在本折输入窗里的行数、`cb_daily` 逐季在市转债数、`cb_call` 逐季各状态行数；核对 `pit-field-map.md` 的每个字段与单位。缺表或整折为空时全部家族记「不可测」，直接以 `no_edge` 弃权，不要改用正股字段冒充。
2. 固定不变量并写进工作区笔记：发行人映射规则（剔除 EB、多券取成交额最大）、可交易过滤（T-1 未停牌、非 ST、剔除科创板或说明、ADV20 ≥ 3,000 万元、T-1 收盘 ≤ 40 元）、共同排除（近 60 日有强赎/到期赎回公告）、篮子 12–15 只、等额现金、持有期（各家族先用 `families.md` 的默认值）、费用缓冲 3%、无信号日持币。这些是声明值，不是拟合参数。
3. 第 0 轮离线普查（不占回测预算，只用输入窗，绝不碰验证区间）：在 `/mnt/snapshot` 决策视图上建「发行人—转债」面板，对每个家族算 1/5/10/20 日持有期「次日开盘→持有期末开盘」的前瞻收益，报三层数字——(a) 等权发行人池相对匹配无转债篮子的收益差（池子效应），(b) 家族头部篮子相对等权池的收益差与规模中性 rank IC、逐月符号一致性、覆盖（信号效应），(c) 事件家族的逐季事件数与 cohort 相对匹配对照的收益差。匹配对照按同日、同规模十分位、同申万一级行业、成交额最接近抽取，每次调仓重抽。截面家族可用 `python /mnt/tools/screen.py --help` 所述的筛查脚本（若它的 frames 不含 `macro` 域，就自己写普查脚本）。符号在多数月份一致、规模中性 IC 不塌、覆盖 ≥ 60%、事件家族逐季事件数 ≥ 30 的家族才值得一次完整 Validation；不合格的直接淘汰并记录理由。
4. 第一轮 `batch_validate`：至少三个互不相同的家族并列（默认家族 1、2、4；家族 3a 与 5 视普查而定），外加两个对照候选——同池等权篮子与第 6 家族的正股 5 日反转，`hypothesis` 里写明「对照」。每条 `hypothesis` 写清信号、股票池、持有期、对照与否证条件。对照节点只用于读家族的边际，不得提名。
5. 第二轮与第一轮预登记互斥：围绕站住的家族比变体——`omega` 平价法对 `beta_60` 经验法、持有期 5/10/20、按 `Prem` 分层门控、n_drop 式部分换仓——一次只改一个组件；若第一轮全部落败，第二轮必须换成本包登记但尚未测的家族（3a、5，或 2 的 `prem_z_60` 变体），不得用参数邻域刷候选数，更不得换成通用因子。合成（固定 λ 的 ridge 或 `num_leaves ≤ 31`、`n_estimators ≤ 300`、`learning_rate 0.05` 的排序器，参数预先声明，在 `fit(context)` 里做，`REFIT_PERIOD="quarter"`，训练窗与验证窗之间空出持有期长度的禁运）只在两个家族都单独站住之后才允许，且必须与最佳单家族同批比较。
6. 多重检验纪律：本折全部候选数事先写在 `TODO.md` 里（建议第一轮 ≤ 5 含对照、第二轮 ≤ 5、稳健性 ≤ 3），每加一个候选就是多一次试验；读 Sharpe 时按 `trials_so_far` 打折。回测预算至少留三分之一给第二轮。
7. 每个候选按 README 的「没有边际」清单读，四个季度子窗分别报相对等权池对照的超额、相对匹配对照的超额、候选数、事件数、换手、拒单率、行业与规模集中度。拒单率是本方向的一等公民：转债领先的信号在正股涨停日最强，买不进的路径要写清。
8. 在本折新季度（`sub_windows` 最后一行）上裁决：候选在新季度相对父本对照与等权池对照都为正才算通过；父本在新季度为负而候选也没有转正时不提名。决赛候选用 `run_null_control(node_id)`（每折默认 3 次）。
9. 用 `step_rollback` 把胜出节点恢复到 `output/` 再 `finish_fold`。全部家族被证伪时以 `finish_fold(outcome="no_edge", reason=...)` 弃权（首折记为 `baseline_missing`），并留下证伪结论与下一折的不同假说。

## 组合纪律

- 家族可分离：一次 Validation 只改一个家族或一次合成。
- 家族 1 与家族 4 的 `signed_surge`、家族 1 与 `prem_chg_5` 高度同向（Spearman 绝对值长期 > 0.85 时）不同时放进合成。
- 不用 MA 过滤、指数择时或任何未登记的过滤器救一个落败的家族。
- 不在 `generate_orders` 里重新拟合任何权重。

## Validation 否证

- 任何 `available_at`、T-1、复权锚、单位或发行人映射错误：结果无效，不讨论收益。
- 有效覆盖长期低于约 60%（相对过滤后的发行人池），或在决策间大幅塌缩：淘汰该家族，除非它本就是稀疏事件假说。
- 中性化后优势消失：否证「独立 alpha」，只有明确接受该暴露并写明限制才能保留，且不得是规模暴露。
- 等权池相对匹配对照为正而家族相对等权池不为正：只有池子效应，家族淘汰；池子效应本身不是可提名的策略。
- 四个季度子窗同号少于三个，或收益只来自单个极端日期、少数个股、单一行业或 `Prem > 80` 的投机券：淘汰。
- 加手续费、滑点、涨跌停和手数约束后优势消失，或 2 倍滑点下超额转负：淘汰。
- 拒单率 > 30% 或空信号日占比使年内成交数不足 20 笔：判「不可执行」而不是「有边际」。
- 合成不优于最佳单家族，或只降收益却未改善回撤与子窗一致性：回退到单家族。

## 失效模式与预算提示

- 池子薄：过滤后 250–400 只，篮子 12–15 只已是 3–6% 的池子，头部分位噪声大；事件家族每季常不足 30 个事件，不足的子窗只能记「无证据」。
- 转债市场自身的 regime：2022 年小盘转债炒作与 2022-08 的 ±20% 限幅、投资者适当性新规，2023 年首例转债违约，2023-08 再融资收紧导致新券枯竭、池子从 2023Q4 的 558 只缩到 2025Q4 的 387 只与 2026Q2 的 314 只，2024-08 转债信用集体杀跌。残差、溢价率、债底在这些季度分别变成投机因子或信用因子，按季度子窗与 `Prem`/`BPrem` 分层看一致性，不做跨 regime 的整窗平均。
- 退市与转股：强赎后转债退市、正股离开池子，留在池子里的是没涨够的发行人——等权池篮子有结构性倾斜，匹配对照每次调仓重抽；持仓不因转债退市强制平仓。
- `cb_basic` 的幸存者问题：它是每晚刷新的当前状态表，历史退市券仍在表里（1,163 只中 346 只无 `delist_date` 原值），但无 `list_date` 的 24 行不可见，`stk_code` 可能反映代码变更后的现状；存续只能按 `cb_daily` 行判断，评级只用发行时 `issue_rating`。
- 预算：普查 0 次回测；第一轮 ≤ 5、第二轮 ≤ 5、稳健性 ≤ 3；空对照 ≤ 3 只给决赛候选；`fit` 只在合成候选里出现，单次预算以 `budgets.strategy_fit_timeout_seconds` 为准。
