# 五个假说家族与一个对照家族

记号。正股 s 用归一化 `daily`：`C/O/A/V` 为截至 T-1 的收盘、开盘、成交额（元）、成交量（股），`qfq` 为按 T-1 冻结锚前复权的价格，`r_s = qfq_C/qfq_C.shift(1) − 1`，`circ_mv` 为元，`turnover_rate` 为小数。转债 k 取截至 T-1 的最近可见行（与日线同步，见 README 的可见边界一条），用 `macro` 域 `dataset == "cb_daily"` 的来源单位：`P = close`（元/100 面值）、`g = pct_chg / 100`（源是百分数）、`Amt = amount × 1e4`（源是万元）、`Par = cb_value`（转股价值，元/100 面值）、`Prem = cb_over_rate`（转股溢价率，%）、`BPrem = bond_over_rate`（纯债溢价率，%）。`r_m` 为沪深 300（`index_daily` 的 `000300.SH`，`pct_chg` 是百分数）。缺值、零分母、无穷值保持为空，不填 0。「方向」是合成前乘号，使高分做多。

基础恒等式（对 2024 年逐行核对，误差 < 0.01 个百分点）：

```text
Par_t        = 100 × 正股close_t / conv_price_t      TuShare 定义，正股 close 为未复权收盘
conv_price_t = 100 × 正股close_t / Par_t             快照剔除了 conv_price，历史转股价只能这样反推
Prem_t       = (P_t / Par_t − 1) × 100
BPrem_t      = (P_t / bond_value_t − 1) × 100
Amt_t        ≈ vol_t × 10 × P_t                       1 手 = 10 张 = 1,000 元面值
M_t          = Par_t / 100 = 正股close_t / conv_price_t  价内程度；强赎触发「收盘 ≥ 130% 转股价」⇔ Par_t ≥ 130
```

## 发行人映射、股票池与共同排除

```text
basic  = macro[dataset == "cb_basic"][["ts_code", "stk_code", "cb_type", "issue_size", "list_date", "conv_start_date", "issue_rating"]]
basic  = basic[basic.cb_type == "CB"]           # 剔除可交换债 EB（27 只，stk_code 不是发行人自身）
alive  = k 在 T-1（停牌时放宽到最近 5 个交易日）有 cb_daily 行   # 不用被剔除的 delist_date
pool   = {stk_code : 存在 alive 的 k} ∩ 可交易过滤；一只正股多只转债时取 T-1 Amt 最大的一只
```

可交易过滤是声明值，不是拟合参数：T-1 未停牌、`universe.name` 不含 ST、剔除 688/689（或说明保留）、ADV20 ≥ 3,000 万元、T-1 收盘 ≤ 40 元。按 20 日均成交额、收盘价、科创板与 ST 联合过滤后，2024-06 基准日 519 只发行人剩 340 只，2022-06 的 407 只剩 300 只。

共同排除：近 60 个交易日内有 `is_call ∈ {公告实施强赎, 公告提示强赎, 公告到期赎回}` 的券及其正股在家族 1、2、4、5 中排除（家族 3 专门处理它们）；`amount == 0` 的转债行（约 0.5%）置空。

中性化顺序：有限值 → 方向统一 → 1%/99% 截尾 → 对同截面 `log(circ_mv)` 与 60 日 β 回归取残差 → 家族 2、3、5 再对 20 日动量（`qfq_C/qfq_C.shift(20) − 1`）取残差，因为它们与近期正股涨幅机械相关 → rank（`2*(rank(pct=True)−0.5)`）。原始值只作对照报告。

每节的「预登记检验」是候选写进 `hypothesis` 的最小内容：信号、持有期、篮子、对照、否证条件，每条不超过 500 字符。

## 1. 转债残差动量（转债先于正股定价）

机制：转债 T+0、无 ±10% 限幅、机构主导，正股被涨跌停截断或 T+1 锁定的那部分信息先进入转债价格；把转债收益中能被正股收益解释的部分剥掉，剩下的残差就是转债市场对正股的「超前定价」。这是本包的主家族。

```text
omega_t     = clip(Par_t / P_t, 0, 1)             # = 1/(1 + Prem_t/100)，平价法的价格弹性近似
resid_t     = g_t − omega_{t−1} × r_s,t            # 用滞后一日的 omega，避免同日机械相关
cb_resid_5  = sum(resid, 5)                        方向 +
beta_60     = OLS(g ~ r_s, 60 日，≥ 40 个观测) 的斜率
cb_resid_5b = sum(g − beta_60.shift(1) × r_s, 5)   变体：经验弹性
prem_chg_5  = Prem_t − Prem_{t−5}                  变体：≈ (1 + Prem/100) × (g − r_s) 的累积，不是独立家族
```

预登记检验：规模与 β 中性后的 `cb_resid_5` rank，篮子前 12 只，持有 5 日、每日换 1/5（或每 5 日整篮换，二选一先声明）。对照：同池同过滤的等权篮子；机制无关对照：第 6 家族的正股 5 日反转（证明边际不是反转换皮）。否证：输入窗内规模中性 IC 逐月符号不一致；候选相对等权对照的中性化超额 ≤ 0；剔除 `Prem > 80` 的高投机券后优势消失；四子窗同号 < 3；2 倍滑点转负；意图买单拒单率 > 30%。

失效模式：深度价外时 `omega` 高估真实 delta，残差里混进正股的负收益、家族退化成反转（用 `beta_60` 变体交叉核对）；转债付息日 `g` 有约 −1% 的跳变；2022 年小盘转债炒作期残差是转债自身的投机而非关于正股的信息，2024-08 转债信用集体杀跌期残差是信用因子——按 `Prem` 分层与按季度子窗看一致性；信号最强的日子正股常以涨停开盘，买不进。

## 2. 转股溢价率状态（股性与转股套利压力）

机制：低溢价率意味着转债已是纯粹的正股替身，转债持有人对正股的定价与正股市场一致且被机构持续监督；负溢价率则意味着「买转债、转股、次日卖正股」的套利在给正股制造供给（转债 T 日买入当日可转股、T+1 卖出股票，压力恰好落在我们成交的次日开盘）。高溢价率意味着转债与正股脱钩，正股信息在转债里没有痕迹。

```text
in_conv     = T-1 ≥ conv_start_date                           # cb_basic 静态条款，上市即知
score       = −Prem_t 的截面 rank，只在 in_conv 且 Par_t ∈ [80, 130) 的券内打分   方向 +（低溢价为多头端）
arb_days_5  = sum(Prem < 0, 5)；≥ 3 的正股从多头端剔除（转股套利正在卖正股）
prem_z_60   = (Prem_t − mean(Prem, 60)) / std(Prem, 60)         变体：相对自身历史的低位
```

预登记检验：规模、β 与 20 日动量三重中性后的 `score`，篮子前 15 只，持有 20 日、每 20 日换。对照：同池等权；机制无关对照：同池规模/β 中性的 20 日动量（低溢价机械上跟随正股上涨，必须证明溢价率有动量之外的信息）。否证：动量中性后超额 ≤ 0；`Par < 100` 与 `Par ≥ 100` 两个子样本方向相反；2024 年后子窗同号 < 3。

失效模式：2024 年转债信用风险事件后，低溢价率同时代表股性强与违约担忧（`BPrem` 可作分层）；`arb_days_5` 在 T+0/T+1 时序上可能已经把压力释放完，剔除规则要在普查里先看事件后 1/3/5 日的正股收益再定。

## 3. 强赎条款：触发前的正股与公告后的供给冲击

机制：发行人有动机在触发线附近维持正股价格（转股消灭债务），触发计数逼近 15/30 时的正股是发行人「有动机的多头」；`公告实施强赎` 之后转债持有人集中转股卖出，正股在转股登记日前承受供给冲击，登记日后冲击结束。前者是多头假说，后者主要是排除规则。

```text
hit_30   = rolling(30).sum(Par ≥ 130)                        # 用 Par 自算，不用 is_call == "已满足强赎条件"
cohort_a = in_conv 且 hit_30 ∈ [8, 14] 且近 180 个交易日无 公告不强赎/公告实施强赎/公告提示强赎
           入场次日开盘，持有至 hit_30 ≥ 15 或满 20 个交易日，先到者为准             方向 +
event_b  = is_call == "公告实施强赎" 且 call_type == "强赎"（T-2 公告，T 08:30 可见，T 09:30 是可见后首个可成交价）
           排除窗：ann_date 次日至 call_reg_date（缺则 ann_date + 25 个交易日；call_date − ann_date 中位 24 天）
post_b   = call_reg_date 次日起持有 20 日                       变体，方向 +（供给冲击结束后的回补）
```

预登记检验：`cohort_a` 等权、篮子上限 12 只、无信号日持币。对照：同日同规模十分位同行业无转债匹配股，以及同池中 `Par ∈ [100, 120)` 的正股等权（证明不是单纯的正股涨幅延续）。否证：cohort 相对匹配对照的 5/10/20 日超额 ≤ 0；20 日动量中性后归零；任一季度事件数 < 30 的子窗不算证据。`post_b` 只在普查显示每季 ≥ 30 个事件时才登记；本地核对 `公告实施强赎` 2020–2025 年各 72/68/53/41/55/133 条，每季 10–35 条，多数季度达不到，因此 `event_b` 首先是家族 1、2、4、5 的排除规则。

失效模式：触发前的 run-up 定义上就是动量，动量中性是硬检验；条款参数因券而异（有 20/30、130% 等变体），本包用声明常数 15/30 与 130，不解析 `call_clause` 文本；`已满足强赎条件` 状态在 2020 与 2024 年整年为 0 行，是供应商覆盖缺口，不得作信号；`公告不强赎`（896 条）只作诊断，不登记为独立家族。

## 4. 转债相对正股的成交额异动（知情交易）

机制：知情者在约束更少、冲击成本更低的转债市场交易，转债放量而正股没有放量是「信息在转债里」的痕迹；符号由家族 1 的残差给出。

```text
ratio_t      = Amt_t / A_t                                  # 两者都是元；2024-06 中位 0.43，p90 2.96
abn_cb_5     = log(mean(Amt, 5) / mean(Amt, 60))
abn_stk_5    = log(mean(A, 5) / mean(A, 60))
rel_surge_5  = abn_cb_5 − abn_stk_5                         # 转债放量而正股没有
signed_surge = sign(cb_resid_5) × max(rel_surge_5, 0)       方向 +
```

预登记检验：规模与 β 中性后的 `signed_surge` rank，篮子前 12 只，持有 10 日、每 5 日错峰换一半。对照：同池等权；机制无关对照：正股自身 `sign(cb_resid_5) × max(abn_stk_5, 0)`（证明是转债的量而不是股票的量）。否证：控制 `cb_resid_5` 后 IC ≈ 0（只是家族 1 的换皮）；`rel_surge_5` 的头部集中在 `Prem > 80` 的券（转债自身炒作）；四子窗同号 < 3。

失效模式：2022 年小盘转债炒作期转债日成交额可达正股数倍，放量是转债内部的投机而非关于正股的信息；转债 2022-08 起有 ±20% 限幅与临停，被限幅的日子成交额失真。

## 5. 纯债溢价率：债底缓冲的价值信号

机制：转债贴近债底（`BPrem` 低但不为负）且平价很低，说明机构持有人把正股期权定价接近零，而发行人有下修转股价、恢复转股价值的动机（`reset_clause`）——正股是带发行人侧催化的深度价值。它必须与通用价值分开：对照就是 BP。

```text
候选池   = Par_t < 90 且 BPrem_t ∈ [0, 15] 且 issue_rating ∈ {AA-, AA, AA+, AAA}    # 剔除跌破债底（信用定价）与低评级/无评级
score    = −BPrem_t 的截面 rank                                                方向 +
```

预登记检验：规模、β 与 20 日动量中性后的 `score`，篮子前 15 只，持有 20 日、每 20 日换。对照：同池等权；机制无关对照：同池规模中性的 BP（`1/pb`，来自 `daily`）rank——通用价值只以对照身份出现。否证：BP 中性后超额 ≤ 0；2024Q1 与 2024Q3（转债信用压力季度）子窗为负且整窗只靠其他子窗；收益集中在少数券。

失效模式：`bond_value` 是供应商按评级折现曲线算的，口径未知，只能在数据集内排序；2024 年 `BPrem` 的 p05 是 −7.4，跌破债底的券很多，「债底」本身在信用压力期不可信；低平价发行人常是弱基本面小盘股，规模中性后可能什么都不剩。

## 6. 对照家族：正股 5 日反转（只作对照，不得提名）

```text
rev_5 = −(qfq_C / qfq_C.shift(5) − 1)，规模与 β 中性，同池同过滤，篮子前 12 只，持有 5 日
```

它是家族 1 与家族 4 的机制无关对照，`hypothesis` 里必须写明「对照」；它的节点不得被 `finish_fold` 提名，落败或胜出都只用于读家族 1、4 的边际。同理，20 日动量与 BP 只以家族 2、3、5 的对照身份出现在 `hypothesis` 里。

## 明确不做

- 交易转债、转债套利、任何多空或对冲。
- 用 `cb_basic.conv_price`/`remain_size`/`newest_rating`/`delist_date`（快照已剔除）；用 `已满足强赎条件` 状态；解析 `call_clause` 文本替代声明常数。
- 用当日 `cb_daily`/`cb_call` 行、当日日线、当日 `daily_basic`、当日复权因子。
- 价值、反转、动量、低波、成长、规模的通用打分作为候选；WorldQuant 101、TuShare 因子菜单。
- 把本目录或任何 vendor 树拷进 `output`。
