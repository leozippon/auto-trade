# 防御型质量参考包（defensive_quality，20260918）

> 状态：为研究臂 `defensive_quality_20260918` 编写，该臂在旧流程下停在开发中途、没有裁决；本包原样沿用为研究会话流程下的 `defensive_quality_20260921`，下文按研究会话流程写。
>
> 本包的研究证据来自旧流程下的方向研究（DIR4 与 DIR6），那些研究读过的行一直延伸到研究期之后的前推期末。因此本臂的前推裁决在运营方层面已被部分污染：它是流水线的一次读数，不是这个家族在未见数据上的独立证据。

本目录是只读 refs：把**「无聊的股票」**——现金流支撑的盈利与低的 60 日特质波动——收成一个两腿的特征面，交给一个不训练的只做多月度篮子，并按预登记的归因对照判定它是否真的挣到了已关闭的 20 日彩票腿、成长腿与盈利意外面之外的边际。它不是可提交策略，也不是预期收益。

任务只有一句话：用两条腿——**现金流盈利质量**（低应计：(归母净利润 − 经营现金流)/总资产，与高经营现金流/总资产，取首版报表）和**低 60 日残差波动**（个股日收益对沪深 300 回归的残差标准差）——各自截面百分位秩等权合成，做 08:30 决策的月度截面信号，同批比过三个对照：**同一骨架只用 20 日波动**（`factor_cs` 已关闭的彩票/低波面 `c_vol20`）、**只用同一份报告的同比增速**（`c_growth`）、**只用盈利意外包的复合分数**（`c_es`，规则见 `starter/lib/surprise_control.py`）。输给 `c_vol20` 说明低波腿是 20 日腿的换皮，输给 `c_growth` 或 `c_es` 说明质量腿在成长与意外之上没有增量；何时据此关闭一条腿或本臂，只按 `families.md` 的门 1 与门 2。

按以下顺序读：

1. `families.md`：主候选、两条可提名的消融腿、三个对照面、**硬门（关闭判据的唯一权威表述）**、允许的变体、臂级终止规则。
2. `pit-field-map.md`：逐表可见时点、单位、去重规则与陷阱（唯一权威表述）。
3. `exploration-plan.md`：不占预算的普查、首轮批次、判定分支、后续轮次。
4. `sources.md`：本地探针的方法、研究期末以前的逐年读数与复现命令、冒烟实测、诚实的限制。
5. `starter/`：合同内的最小可运行包（`main.py` + `lib/face.py` + `lib/surprise_control.py` + `lib/trade.py`），**不是**候选本身。它通过 `validate_strategy_package`，并在沙箱镜像里以真实 as-of 布局跑通了「读取 → 波动与报表 → 合成 → 中性化 → 出单」全链路（读数见 `sources.md`）；正式回放的第一步仍然是 `smoke_backtest`。`main.py` 的 `CANDIDATE` 常量在六条腿之间切换，六者除这一行外必须逐字相同。**会话开始时 `output/` 就是这份代码**，`refs/starter/` 只是同一份的只读参考副本。

## 为什么这是一个新机制家族，以及它有意重开了什么

收益来源的经济解释是同一个：散户主导、卖空受限的市场**过度需求彩票型暴露**——高近期波动、注意力、账面好看的盈利——而**低估其反面**。两个互相独立的「无聊」度量在一到三个月里系统性地被低估：(a) 没有经营现金流支撑的盈利（高应计）被外推、随后修正，现金流支撑的盈利者向上漂移（Sloan 形态的应计异象，按首版报表度量）；(b) 相对自身 20 日波动、规模、换手、动量与行业而言 60 日残差波动低的名字挣到稳定溢价，而 20 日彩票腿（`max20`、`vol20`）捕捉不到它，它也不是 β。

本地探针（方法见 `sources.md`；方向研究全文 `logs/notes/review_20260912/DIR4_more_arms.md`）在控制规模、动量、反转、换手、`vol20`、`max20`、两条已消耗的资金流腿、行业、EP、同比增速与**盈利意外复合分数**之后选中了这两条腿。探针的样本延伸到研究期末之后，所以本包不引用它的整段读数，只保留研究期末以前日历年的逐年读数（`sources.md`）；两腿在研究期上是否挣到边际，只由本臂的研究期验证与 `families.md` 的硬门回答。

反过来必须写明：**低波腿有意重开了一个已登记的家族。** `factor_cs` 家族 2 登记过 `max_20`/`ivol_60`/`vol_20`；其 `f2_ivol60` 在那条臂的第一个验证窗存活（中性化超额 +0.169）、第二个窗 +0.106、空对照分位 0.97，但输给了同臂的 `tug20` 冠军——它**从未被证伪**，那条臂是在三次弃权后整体终止的。本包重开它，是因为方向研究在含 `vol20`/`max20` 的更强控制集下仍选中了它。每个参考包都把「低波」列进不得作候选的通用因子；本包把它作为**一条腿**登记，并用 `c_vol20` 硬门保证它不是那条已关腿的换皮。质量腿则是本仓库从未测过的信息源：没有任何包碰过应计或经营现金流/资产。

## 本臂的执行边界

执行合同——入口与订单、允许的 import、文件 I/O、`available_at` 与 PIT 读法、不写死宿主路径、沙箱无网络——以只读 `output/README.md` 与系统提示为准，本包不复述。本臂只在以下几点上更具体：

- **本包的主线不训练**：没有 `fit`、没有 `REFIT_PERIOD`，每次决策是四次有界的 parquet 读取、一次 60 日滚动回归加一次最小二乘。登记学习器变体时才加 `fit(context)`，结果写 `context.state_dir`。本臂 `gpu_count=0`。
- 本臂不挂分钟域（运行事实 `execution_policy`），执行时点只有 09:30 与 15:00。
- 不要把 `refs/` 里的文件拷进 `output/`：整棵包是只读的，`cp` 会把权限一起带过去；会话开始时 `output/` 已经是 `starter/` 的内容，不必移植。

## 账户与成本

研究期几何、预算、冻结门与毕业条件以运行事实为准，会话流程见系统提示，本包不复述；本臂以 `no_edge` 结束的条件见 `families.md` 的终止规则。

账户与费率以运行事实 `broker_replay` 为准。按本臂的 15 只等权、97% 仓位，单只预算约 6,300 元，最低佣金即 7.9 bp/边，一次往返约 25–35 bp。起步节奏是**月度复核、2 倍保留带、每次最多换 8 只**：两条腿都是慢特征，按设计估计 15 只篮子每月约换 3–5 只 ≈ 每年 40–60 次换名 ≈ 250–400% 年换手、**0.6–1.3% 的年成本拖累**（第 0 轮普查用研究期实测核对）；季度变体约三分之一。**成本门是本臂的硬门**，判据写在 `families.md`。

## 「没有边际」的读法

每个候选按 `families.md` 的「硬门」与「什么会杀死它」逐条读，不看整窗总收益；本文不复述判据。另外三点读法：

- 本臂的原始超额在宽幅高波动的上涨年份（探针里 2021 形态）会接近零，这是防御型篮子的构造性质：读 `benchmark.neutralized_excess_return` 与 `benchmark.size_tilt` 一起读，不把这类研究年单独当作证伪或证据。
- 中性化是机制定义的一部分，不是可删的降噪：低波腿不对规模、`vol_20`、`max_20` 中性化就不再是本包登记的那条腿。
- `run_null_control` 只给完整研究期的决赛候选算（次数见 `budgets`）；`selection_statistics.deflated_sharpe_probability` 是冻结门此刻对该节点的读数，已按本臂的试验数打折。

没有候选证明边际时，不冻结是正当结果：按 `families.md` 的终止规则以 `no_edge` 携读数结束本臂。

## 禁止退回通用因子

本包的候选形态只有 `families.md` 登记的两腿合成、两条消融腿及其变体；手写的价值/反转/动量/换手/`max20`/`vol20` 打分不得作为候选，只能以中性化列或 `c_vol20` 对照的身份出现；`c_vol20`、`c_growth`、`c_es` 与任何机制无关对照不得被提名冻结。
