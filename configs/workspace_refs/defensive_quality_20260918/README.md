本目录是只读 refs：把**「无聊的股票」**——现金流支撑的盈利与低的 60 日特质波动——收成一个两腿的特征面，交给一个不训练的只做多月度篮子，并按预登记的归因对照判定它是否真的挣到了已关闭的 20 日彩票腿、成长腿与盈利意外面之外的边际。它不是可提交策略，也不是预期收益。

任务只有一句话：用两条腿——**现金流盈利质量**（低应计：(归母净利润 − 经营现金流)/总资产，与高经营现金流/总资产，取首版报表）和**低 60 日残差波动**（个股日收益对沪深 300 回归的残差标准差）——各自截面百分位秩等权合成，做 08:30 决策的月度截面信号，同批比过三个对照：**同一骨架只用 20 日波动**（`factor_cs` 已关闭的彩票/低波面 `c_vol20`）、**只用同一份报告的同比增速**（`c_growth`）、**只用盈利意外包的复合分数**（`c_es`，按 `earnings_surprise_20260918/starter/lib/surprise.py` 的规则重建）。输给 `c_vol20` 说明低波腿是 20 日腿的换皮，输给 `c_growth` 或 `c_es` 说明质量腿在成长与意外之上没有增量；何时据此关闭一条腿或本臂，只按 `families.md` 的门 1 与门 2。

按以下顺序读：

1. `families.md`：主候选、两条可提名的消融腿、三个对照面、**硬门（关闭判据的唯一权威表述）**、允许的变体、臂级终止规则。
2. `pit-field-map.md`：逐表可见时点、单位、去重规则与陷阱（唯一权威表述）。
3. `exploration-plan.md`：不占预算的普查、首轮批次、判定分支、后续轮次。
4. `sources.md`：本地探针的方法、研究期末以前的逐年读数与复现命令、冒烟实测、诚实的限制。
5. `starter/`：合同内的最小可运行包（`main.py` + `lib/face.py` + `lib/surprise_control.py` + `lib/trade.py`），**不是**候选本身。它通过 `validate_strategy_package`，并在沙箱镜像里以真实 as-of 布局跑通了「读取 → 波动与报表 → 合成 → 中性化 → 出单」全链路（读数见 `sources.md`）；正式回放的第一步仍然是 `smoke_backtest`。`main.py` 的 `CANDIDATE` 常量在六条腿之间切换，六者除这一行外必须逐字相同。

## 为什么这是一个新机制家族，以及它有意重开了什么

收益来源的经济解释是同一个：散户主导、卖空受限的市场**过度需求彩票型暴露**——高近期波动、注意力、账面好看的盈利——而**低估其反面**。两个互相独立的「无聊」度量在一到三个月里系统性地被低估：(a) 没有经营现金流支撑的盈利（高应计）被外推、随后修正，现金流支撑的盈利者向上漂移（Sloan 形态的应计异象，按首版报表度量）；(b) 相对自身 20 日波动、规模、换手、动量与行业而言 60 日残差波动低的名字挣到稳定溢价，而 20 日彩票腿（`max20`、`vol20`）捕捉不到它，它也不是 β。

本地探针（方法见 `sources.md`；方向研究全文 `logs/notes/review_20260912/DIR4_more_arms.md`）在控制规模、动量、反转、换手、`vol20`、`max20`、两条已消耗的资金流腿、行业、EP、同比增速与**盈利意外复合分数**之后选中了这两条腿。探针的样本延伸到研究期末之后，所以本包不引用它的整段读数，只保留研究期末以前日历年的逐年读数（`sources.md`）；两腿在研究期上是否挣到边际，只由本臂的研究期验证与 `families.md` 的硬门回答。

反过来必须写明：**低波腿有意重开了一个已登记的家族。** `factor_cs` 家族 2 登记过 `max_20`/`ivol_60`/`vol_20`；其 `f2_ivol60` 在那条臂的第一个验证窗存活（中性化超额 +0.169）、第二个窗 +0.106、空对照分位 0.97，但输给了同臂的 `tug20` 冠军——它**从未被证伪**，那条臂是在三次弃权后整体终止的。本包重开它，是因为方向研究在含 `vol20`/`max20` 的更强控制集下仍选中了它。每个参考包都把「低波」列进不得作候选的通用因子；本包把它作为**一条腿**登记，并用 `c_vol20` 硬门保证它不是那条已关腿的换皮。质量腿则是本仓库从未测过的信息源：没有任何包碰过应计或经营现金流/资产。

## 硬合同

- 正式策略写在 `output/` 包内：入口固定为 `output/main.py` 的 `generate_orders(context)`，返回严格 JSON 订单数组；辅助模块放在 `output/` 下并用绝对导入，每个 `.py` 受同一套静态检查，文件数与总字节数以运行事实为准。
- 正式 import 只允许：纯计算标准库、`numpy`、`pandas`、`scipy`、`sklearn`、`lightgbm`、`xgboost`、`statsmodels`、`torch` 及其子模块，以及 `output/` 内自己的模块。本臂 `gpu_count=0`。
- **本包的主线不训练**：没有 `fit`、没有 `REFIT_PERIOD`，每次决策是四次有界的 parquet 读取、一次 60 日滚动回归加一次最小二乘。登记学习器变体时才加 `fit(context)`，结果写 `context.state_dir`。
- 沙箱无网络。不要写死 `/mnt/agent/workspace`。先核对本轮 `data_summary.json` 与 `unit_reference.json`，再经 `context.asof_dir` 读数，每次读取都给 `columns=`、`filters=` 与日期窗口；as-of 域读失败**不得**回退 `snapshot_dir`。
- 每一行输入必须 `available_at <= context.inference_at`；判可见只看 `available_at`。逐表规则见 `pit-field-map.md`。
- 执行时点只用 09:30 与 15:00（本臂不挂分钟域）。Broker 负责 T+1、费用、涨跌停与成交；策略只发订单草图。
- 不要把 refs 拷进 `output`。

## 研究流程与账户

研究期由若干整的七月至次年六月研究年组成，本臂只有一个研究会话，在这个研究期上开发与验证；决策视图定在研究期末，输入窗口从那里往前数。精确窗口、研究年标签、预算、冻结门与毕业条件以运行事实为准，本包不复述。完整研究期验证带逐年分块（`sub_windows`，每个研究年一行），只有完整研究期节点可以提名冻结，冻结门按本臂验证过的全部 revision 给提名的去偏 Sharpe 打折。会话以 `finish_session` 的一种结局收尾：`freeze` 冻结本臂唯一的交付并结束研究，`no_edge` 按 `families.md` 的终止规则结束本臂；没有下一个会话可以交接，推理时间或模型调用预算先用尽时流水线记 `deadline` 结束本臂。上下文接近上限时用 `compact(summary=...)` 把对话换成自己的摘要；压掉的读数、节点编号与代码都留在只读根 `trace` 里，用 `read_file`/`grep` 读回，不要重算。冻结产物随后在研究期之后的连续前推期与 Held-out 上回放一次并裁决：那段数据没有会话看得到，也没有 Agent 参与，前推不过即本臂结束，没有第二次冻结。

账户是 10 万元真实资金：佣金万一、最低 5 元/笔，过户费 0.1 bp，卖出印花税按成交日切换，方向滑点 5 bp。15 只等权、97% 仓位时单只预算约 6,300 元，最低佣金即 7.9 bp/边，一次往返约 25–35 bp。起步节奏是**月度复核、2 倍保留带、每次最多换 8 只**：两条腿都是慢特征，按设计估计 15 只篮子每月约换 3–5 只 ≈ 每年 40–60 次换名 ≈ 250–400% 年换手、**0.6–1.3% 的年成本拖累**（第 0 轮普查用研究期实测核对）；季度变体约三分之一。**成本门是硬合同**，判据写在 `families.md`。

## 「没有边际」的读法

每个候选按 `families.md` 的「硬门」与「什么会杀死它」逐条读，不看整窗总收益；本文不复述判据。另外三点读法：

- 本臂的原始超额在宽幅高波动的上涨年份（探针里 2021 形态）会接近零，这是防御型篮子的构造性质：读 `benchmark.neutralized_excess_return` 与 `style_analysis.json` 的规模倾斜一起读，不把这类研究年单独当作证伪或证据。
- 中性化是机制定义的一部分，不是可删的降噪：低波腿不对规模、`vol_20`、`max_20` 中性化就不再是本包登记的那条腿。
- `null_control.excess_percentile` 用 `run_null_control(node_id)` 只给决赛候选算；`selection_statistics.deflated_sharpe_probability` 是冻结门此刻对该节点的读数，已按本臂的试验数 `trials` 打折。

没有候选证明边际时，不冻结是正当结果：按 `families.md` 的终止规则以 `no_edge` 携读数结束本臂。

## 禁止退回通用因子

本包的候选形态只有 `families.md` 登记的两腿合成、两条消融腿及其变体；手写的价值/反转/动量/换手/`max20`/`vol20` 打分不得作为候选，只能以中性化列或 `c_vol20` 对照的身份出现；`c_vol20`、`c_growth`、`c_es` 与任何机制无关对照不得被提名冻结。
