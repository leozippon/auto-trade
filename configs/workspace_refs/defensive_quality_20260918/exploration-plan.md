# Fold-ready 探索计划

目标不是复现任何单列读数，而是检验一件事：**现金流支撑的盈利与低 60 日残差波动这两个「无聊」度量，能否让一个只做多的月度截面篮子挣到已关闭的 20 日彩票腿、成长腿与盈利意外臂之外的边际。** 判据与变体清单只在 `families.md`；可见时点与单位只在 `pit-field-map.md`；本文只排顺序。有父本时，必须先完成一次与父本可执行逻辑不同的完整 Validation；父本对照由宿主在会话前跑好，不要自己重跑。

## 第 0 轮：不占回测预算的离线普查

用 `shell` 在输入窗上跑，不启动回测。任一条不合格就在第 1 轮的 `hypothesis` 里声明，不要硬凑。

1. **四张表是否真的选进来了**：`data_summary.json` 的 `fundamentals.datasets` 列出 `income_vip`、`cashflow_vip`、`balancesheet_vip`，`macro.datasets` 列出 `index_daily`；分别报 `snapshot` view 与 `valid` view 的行数与日期覆盖（**不得由前者推断后者**）。沪深 300 缺失即声明本折按变体 c 用总波动。
2. **单位核对**：`unit_reference.json` 里 `fundamentals.income_vip.n_income_attr_p`、`fundamentals.cashflow_vip.n_cashflow_act`、`fundamentals.balancesheet_vip.total_assets`（元）、`daily.circ_mv`（元）、`macro.index_daily.pct_chg`（百分数）。实测 `accr` 的中位数应在 0 附近、1%/99% 分位在 ±0.2 量级；`ivol60` 中位数应在 0.015–0.025；量级不对就是单位错了。
3. **版本与去重**：抽 20 个 `(ts_code, end_date)` 核对三张表各自只取到了最早版本、事件时点是三者中最晚的 `available_at`；抽 20 个名字核对年龄按可见交易日历计。
4. **可选池与覆盖**：在四个季度的月度复核日上报可选池大小、两腿各自的非空率、波动窗口日数 ≥ 40 的比例、最新报表年龄的分布。参照实测（一个春季决策日）：池 2,907；一个盛夏决策日：池 2,873。
5. **一次决策的实测墙钟与内存**：参照 `sources.md`（沙箱实测）。

## 第 1 轮：四条腿，一次 `batch_validate`

| 候选 | 分数 | 身份 |
|---|---|---|
| `s1` | `rank(cfq2)` + `lowvol` 等权 | **主候选** |
| `s_cfq` | 现金流质量单腿 | **消融，可提名** |
| `s_lowvol` | 低 60 日残差波动单腿 | **消融，可提名** |
| `c_vol20` | 20 日低波（已关面） | **门 1 对照** |

四者共用同一股票池、同一月度复核与保留带、同一 `topk=15`、同一换手上限、同一执行时点，`main.py` 只差 `CANDIDATE` 一行。`hypothesis` 必须写清：两腿的定义与年龄上限、波动窗口与最少日数、沪深 300 是否可用、中性化列清单（含对照去掉自己的面），以及 `families.md` 门 1–6 的判定规则。

## 第 2 轮：两个归因对照与节奏变体，一次 `batch_validate`

| 候选 | 分数 | 身份 |
|---|---|---|
| `c_growth` | 同比增速 | **门 2 对照** |
| `c_es` | 盈利意外臂复合分数 | **门 2 对照** |
| `s1_q` | `s1` 的季度复核变体（轴 a） | 变体 |

第 1 轮的读数与第 2 轮一起裁决门 1、门 2、门 3。宿主每折最多 24 次回测，两轮共 7 次，余量留给第 3 轮起的单轴变体。

判定分支，逐条写死（判据本身见 `families.md`）：

- **门 1 不成立**（`s_lowvol` 没有同时在两项上高于 `c_vol20`）→ 低波腿是 20 日腿的换皮 → **低波腿关闭**，`s1` 改为 `s_cfq`；折内记录写明 `s_lowvol` 与 `c_vol20` 的中性化超额与空对照分位。
- **门 2 不成立**（`s_cfq` 输给 `c_growth` 或 `c_es`）→ 质量腿在成长或意外之上没有增量 → **质量腿关闭**，`s1` 改为 `s_lowvol`。
- **门 1 与门 2 同折都不成立** → **本臂关闭**。按基线锚点规则提名过硬门的最好节点（很可能是一条对照腿），折内记录逐字写明六条腿的中性化超额与空对照分位，并写明「锚点不是本臂的机制」；下一折若不重新登记即终止本臂。
- **两门成立、门 3 不成立**（`s1` 不同时高于两条消融腿）→ 提名更好的那条消融腿；下一折 `s1` 仍同批带两腿复测一次，再不成立即以单腿为主线。
- **两门成立、门 4 不成立** → 机制真实但在 10 万元账户不可交易。第 3 轮只登记节奏变体（轴 a），不扩腿；仍不成立即以「不可交易」关闭。
- **门 5 使本折全是盲区子窗**（四个季度都是宽幅高波动上涨）→ 本折不可裁决，如实 `no_edge`，不算臂级终止的一次。
- **门 6 不成立** → 先修实现，修完重跑一次仍不成立则如实弃权。

## 第 3 轮起：一次只改一个可分离组件

按 `families.md` 的变体轴顺序，每轮取一个，与当轮基准同批比较：a 节奏 → c 波动窗口与尺度 → d 质量腿组成（消融，产出「腿 → 相对 `c_growth`/`c_es` 的落差 → 子窗同号数 → 覆盖率」表）→ b 腿权重 → e 保留带与篮子 → g 价格上限 → f 学习器（最后，且 `s1` 作它的对照）。本轮全部候选被证伪后，下一轮必须换轴而不是换阈值；轴用尽即以 `no_edge` 弃权，不得回退到通用价量打分。

## 计算预算

主线不训练。沙箱实测（见 `sources.md`）一次决策约 5–10 秒、峰值内存 ≈ 1–2 GB，远在 30 秒推断上限与 32 GB 容器上限之内，也没有任何 `fit` 容器。护栏：`daily` 读取窗口 150 个自然日（60 日波动窗加 `mom_60`），`fundamentals` 700 个自然日（`yoy_np` 对照的去年同期），`macro` 150 个自然日；非复核日在建好截面后直接返回 `[]`（截面本身只需几秒），不引入跨调用缓存——冷 worker 与热 worker 逐字节相同。登记学习器变体时 `num_threads` 不得超过 5（三路 `batch_validate` 共享 16 核）。

## 每个候选必须汇报的读数

除标准结果块外，逐折写进结果笔记：四个季度子窗分别的中性化超额与盲区标记；每个复核日的可选池、两腿非空率与波动窗口日数；换手、拒单率、规模倾斜（`style_analysis.json`，低波腿天然偏大、偏安静）；`pnl_concentration`；`vol_basis` 是残差还是总波动；一次决策的实测墙钟。缺任何一项的结果不作为提名依据。

## Validation 否证（任何一条命中，结果无效，不讨论收益）

- 用 `ann_date`/`trade_date` 而不是 `available_at` 判可见；用了重述版财报；三张表没有各取最早版本。
- `macro.index_daily.pct_chg` 没有除以 100；用了 `n_income` 而不是 `n_income_attr_p`；年初至今流量没有按季度序号年化。
- 候选的中性化列被删减；对照对自己的面做了中性化；普查面板与决策截面不是同一个函数构建的。
- as-of 域读失败后回退了 `snapshot_dir`；读财务/宏观域时没有先按 `dataset` 过滤。
- 单次决策超时或读取整段 `fundamentals`/`macro` 不带窗口。

## 收尾

用 `step_rollback` 把胜出节点恢复到 `output/` 再 `finish_fold`；对照节点不得被提名——**唯一例外是首折的基线锚点规则**，那时必须在折内记录里写明锚点不是本臂的机制。不要提交训练脚本；`models/` 只放跨折继承的静态资产。
