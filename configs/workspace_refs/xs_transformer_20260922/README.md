# 截面注意力排序器参考包（xs_transformer，20260922）

本目录是只读 refs。本包登记的是**一个在沪深 300 成分截面上做「跨名字注意力」的学习型排序器**：先用一个小的时序编码器把每个名字最近 `WINDOW_DAYS` 天的 Alpha158 算子面压成一个状态，再用基准自己的当日状态做一次门控（MASTER 的市场引导，只留它真正承重的那一部分），然后在**同一决策日的全部成分之间**跑一层多头注意力，最后出分。它在 GPU 上按季度滚动重训，**并把权重跨重训热启动**。它不是可提交策略，也不是预期收益。

**先把最重要的三件事写在前面。**

1. **本仓库跑过的两条学习型臂都没活下来。** Alpha158 + LightGBM 那条谱系是唯一一个毕业产物，但毕业被项目自己标成「薄且未确认」；同族的校准臂前推点超额为正而自举下界为负，按主动口径重读真实主动 IR 是 **−0.30**。GRU 序列排序器研究期读 +8.06 %/年、4/4 年正，前推 **主动 IR −2.44**，是五条冻结书里最差的一条。
2. **GRU 是纯时序的：它只看自己那一根序列。** 它输掉之前，分数与 LightGBM 对照的逐日秩相关是 0.74–0.88——学到的是同一份价量信息，只是排序顶端更弱。**本臂要测的正是它缺的那一半：同一天别的名字在发生什么。** 但「缺的那一半」是一个假设，不是结论，所以本轮所有臂共用一条硬门：整期验证之前先量增量信息（`families.md` 的 G-INC）。
3. **MASTER 的市场门控没有被独立复现过。** 一份公开的独立移植在标普 500 上**无法把市场门控与不加门控区分开**。所以本包把「跨名字注意力」与「市场门控」拆成两个可分离的开关（`MARKET_GATE` 与 `c_temporal`），**分别量**，而不是照搬论文里的那一对。

按以下顺序读：

1. `families.md`：主候选 `x1`、两条对照、**G-INC 增量信息门**、本包另加的要求、允许的变体轴、提名条件、禁止重开表与臂级终止规则（**唯一权威表述**）。
2. `pit-field-map.md`：逐表可见时点、单位、成分截面的读法与陷阱（唯一权威表述）。
3. `exploration-plan.md`：不占预算的普查与离线筛选、`fit` 成本探针、首轮批次、判定分支、预登记的验证计划与预算。
4. `references/`：四份技术笔记——账户算术、零技能面板、成分面、学习型候选的 `fit` 成本纪律。沙箱无网络，四份都是自写的，外部出处列在 `sources.md`。
5. `sources.md`：读数出处、本包在沙箱镜像里实测到的 `fit` 成本，以及诚实的限制。
6. `starter/`：合同内的最小可运行包，**就是**本包的三条腿。它通过 `validate_strategy_package`，并在沙箱镜像里以 `gpu_count=1`、16 GiB 边界跑通了「读取 → 训练 → 打分 → 出单 → 热启动重训」（读数见 `sources.md`）；正式回放的第一步仍然是 `smoke_backtest`。**会话开始时 `output/` 就是这份代码**，`refs/starter/` 只是同一份的只读参考副本。

## 本轮合同：七条，本臂与同轮另一条臂逐条相同

本轮叫「在指数形状上做学习型排序器」。两条臂的机制不同，其余七件事必须一样，否则两条臂的读数不可比。

| # | 合同 | 本包怎么落地 |
|---|---|---|
| 1 | **股票池是成分形状** | `macro.index_weight` 的沪深 300 成分（`000300.SH`）。宿主的零技能面板按「与原名字同在或同不在沪深 300 成分内」换名，所以面板与本书是同一个形状。**不得回退到未筛的全市场池**——那是 `ml_ranker` 把 67 % 的 Held-out 持仓放进北交所微盘股的那条路 |
| 2 | **标签是残差化的前向收益** | 信号日 t 的前 `HORIZON` 日开盘到开盘收益，减去 `β × 基准同窗前向收益`（β 是滚动 120 日 OLS、向 1 收缩、截断在 0.3–2.0），可选再按申万一级去均值，最后逐日截面取秩。`HORIZON` 在第一批之前登记，5–20 日 |
| 3 | **同特征同标签同池的 LightGBM 对照** | `c_lgbm`，起步包自带，训练日期与候选逐字相同。它是 **G-INC 的量尺**，永远不可提名 |
| 4 | **持久化与热启动** | 每次重训从 `state_dir` 读回上一轮权重继续训，而不是冷启动。**本仓库历史上每一次 `fit` 都是冷重训**，这是第一次做滚动热启动 |
| 5 | **`fit` 成本先量后花** | 整期批次之前先用一次 `smoke_backtest(start=研究期靠后的一天)` 量 `fit` 秒数、容器峰值内存与显存，**同一个 `start` 复用**（`window_build_seconds` 是一次性的） |
| 6 | **验证计划预登记** | 至少两次完整研究期验证，试验数（`trials`）在第 0 轮就写进 `hypothesis` 并逐轮记账 |
| 7 | **纯 torch** | 白名单只有 numpy / pandas / scipy / sklearn / lightgbm / xgboost / statsmodels / torch。几百到约一千个名字的稠密注意力在 46 GB 卡上完全放得下，不需要 `transformers` 或任何别的库 |

**第 4 条的一个合同细节**：`models/` 是随产物交付的**只读**静态资产目录，`fit` 不能写它。回放期拟合出来的权重只能写 `context.state_dir`。`state_dir` 在每次回放开始时为空，所以**一次回放里的第一次 `fit` 永远是冷的，之后每一次重训才是热的**——这正是要测的那件事，也是可以在结果里读出来的（每张买单带 `refits` / `warm_start` / `valid_ic`）。

## 机制与它为什么可能有增量

一个逐股模型（树模型、GRU）对每个名字算一个分，名字之间只通过**事后的截面标准化**发生关系。**跨名字注意力把这件事放进模型里**：同一天每个名字的表示由它自己的历史**和它与当天其他名字的相似度**共同决定。在一个每天只有 300 个名字、且这 300 个名字同涨同跌程度很高的池子里，这一层理论上能做三件逐股模型做不到的事：把共同因子从个股信号里分离出来；让相似名字互相借统计强度（每个截面只有 300 个样本，这一条尤其要紧）；让同一个分数在不同的截面结构下有不同的含义。

**市场门控**（MASTER 的那一半）是另一件事：基准当天的状态（1/5/20 日收益、20 日波动、离 20 日均值的距离，全部按固定尺度缩放、不拟合任何统计量）经一个小网络变成一个门向量，逐维缩放每个名字的状态。它的主张是「同一个横截面形态在高波动与低波动的日子里值不同的钱」。**这一半是本包最不确定的部分**，所以它是一个可分离的开关。

反面同样写清（推断与已记录的证据）：特征与对照是同一份 Alpha158，**与对照高度重叠是默认假设而不是意外**；注意力在 300 个 token 上极容易过拟合；独立移植没能把市场门控与不加门控区分开；GRU 那条臂的教训是「池内 IC 存活而顶端为负」，注意力不会自动修好这件事。G-INC 就是为这一条写的。

## 你被评的是主动序列

每次正式验证结束后，**宿主**按候选自己的成交骨架随机换名重放若干份，取日收益等权均值作为**零技能面板**，再在「候选减面板」的主动序列上算全部统计量。**包不设零技能对照腿，也不设信息比率或去膨胀 Sharpe 的门**——这些是流水线的，写在运行事实里。

由此推出最重要的一条读法：**下面这些东西零技能就能拿到，所以它们本身一分不值**（研究期读数，出处 `references/zero-skill-panel.md`）：

- **持有成分股本身**：等权持有沪深 300 全部成分零技能读中性化超额 **+3.2…+3.5 %/年、TE 约 4 %、信息比率 0.87**。
- **在市值加权的指数里等权**：等权是一次小市值 + 低价 + 再平衡的组合押注；按股票池抽的面板上，50 / 80 席等权读 **+2.60 / +3.62 %/年**。
- **逆波动加权**：在同样的面板上值 **+5.03 到 +6.26 %/年**、信息比率最高读到 1.32。**面板对不齐权重方案**，所以任何非等额方案都必须同批跑一条「同一分数、等额现金」的对照（`families.md` 的 P5）。**起步包用等额现金正是为了不欠这笔账。**

面板取**若干份的合成**而不是一条对照腿：单条固定种子的零技能腿，它自己的信息比率在种子之间的标准差是 **0.37–0.44**。不要在产物里自建对照腿去重测一个宿主已经在算的数。

## 本臂的执行边界

执行合同——入口与订单、允许的 import、文件 I/O、`available_at` 与 PIT 读法、不写死宿主路径、沙箱无网络——以只读 `output/README.md` 与系统提示为准，本包不复述。本包只在以下几点上更具体：

- **本臂 `gpu_count = 1`，主候选与机制对照必须在 CUDA 上训练和打分，不写 CPU 路径**；没有 CUDA 时 `fit` 与复核直接报错，而不是悄悄换成另一种计算。`c_lgbm` 在容器 CPU 上训练。
- **策略容器按 8 核 / 16 GiB 设计**：`--memory-swap` 与 `--memory` 同值，**超了不是变慢，是直接 OOM 杀掉**。`/tmp` 与 `/dev/shm` 各 2 GiB，都算在这 16 GiB 里。线程数写死在 8 以内。
- **显存**：执行器只把空闲显存不低于 12 GiB 的卡分给容器；低于这条线的 CUDA 显存不足记为环境失败，高于这条线仍不足就是策略自己的错误。**卡在批次内共享**：`batch_validate` 最多三路并发，可能落在同一张卡上，每路都不能假定独占整卡。起步包三条腿实测卡上峰值 **0.23 GiB**（`sources.md`），离 12 GiB 极远——`WINDOW_DAYS` 加到 60、`HIDDEN` 或 `HEADS` 加倍都还有余量，但每次加完先量。
- **`fit` 墙钟**：一次 `fit` 受运行事实 `budgets.strategy_fit_timeout_seconds` 约束（基准 3,600 秒）；`batch_validate` 的并发池按本批并发路数放大这个上限，**但只补偿本批自己引入的争用**，跨实验的争用不在补偿之内。起步包实测一次冷重训 **47 秒**、热重训 43–46 秒（`references/fit-cost.md`）。
- 本臂不挂分钟域（运行事实 `execution_policy`），执行时点只有 09:30 与 15:00。
- 固定种子写死在 `lib/knobs.py`。cuDNN 的 GRU/注意力内核在重复回放之间仍可能有细小差异，逐位复现不保证，读数以同批比较为准。
- 不要把 `refs/` 里的文件拷进 `output/`：整棵包是只读的，`cp` 会把权限一起带过去；会话开始时 `output/` 已经是 `starter/` 的内容。

## 账户与成本

资金与跟踪授权是本臂运行事实里的两个独立设定，本包既不知道也不假设它们的取值——**第一件事是读自己的运行事实**（`broker_replay.initial_cash`、`acceptance_rules` 里有没有跟踪授权）。起步包按 **50 席等额现金**成形，这个档位的算术在 `references/capital-arithmetic.md`：100 万元 50 席时一个座位约 2 万元、买得起 95–96 % 的成分、佣金地板约 2.6 bp/边。**在这个账户上成本是舍入误差，不是一等参数**——这正是把学习器放在这一档而不是 10 万档的理由：小账户上「买得起」这条筛子本身就值 +6 到 +9 %/年 的零技能 α，学习器的增量会被它淹掉。

起步节奏是每个 ISO 周首个决策日复核、2 倍保留带、每次最多换 5 只（被迫卖出先算），年换手约 5 倍量级、年成本 1 % 量级。**成分名单只在月末截面更新**，把复核改快并不会让成分更新，只会用同一张截面多交易几次（`references/index-membership.md`）。

**真正咬人的是绝对回撤**：沪深 300 自己在研究期回撤 **39.6 %**，一本建在指数里面的书的绝对回撤天然贴着这个数，而不带授权时的绝对回撤上限是 0.45、主动回撤上限 0.30。**第一批的第一件读数是两个回撤，不是主动 IR。**

## 「没有边际」的读法

每个候选按 `families.md` 的提名条件与「什么会杀死它」逐条读，不看整窗总收益。另外几点：

- 读 `benchmark.active_neutralized_excess` / `active_information_ratio` 与逐年分块，不读原始超额，也不读绝对中性化超额。
- 同批汇报 `c_lgbm` 与 `c_temporal` 的同跨度读数，并写出主候选与它们的逐年差。**落后不触发关闭，但不得在结果笔记里省略。**
- 池内 IC 高不等于 50 只篮子挣钱：GRU 那条臂控制后 IC 的 t 值是 +5.0，而它最好 15 只相对池均值每 10 日是 **−0.03 %**。每个候选都要汇报最好 N 只的读数。
- `run_null_control` 只给完整研究期的领先候选算：它比的是原始超额、按流通市值分位配替身，**和裁决用的那个面板不是一回事**，三个数一起报，不据此提名或否决。

没有候选证明边际时，不冻结是正当结果：按 `families.md` 的终止规则以 `no_edge` 携读数结束本臂。

## 禁止退回别的家族

本包的候选形态只有 `families.md` 登记的截面注意力排序器及其变体。手写的价值 / 反转 / 动量 / 低波 / 质量打分不得作为候选；`c_lgbm` 与 `c_temporal` 只能作对照，**不得被提名冻结**——`c_temporal` 尤其不行，它就是已经关闭的那个纯时序家族换了一套输入。

## 本包的硬要求

跨实验的运行教训不写在参考包里（见 `inputs/skills_index.json` 的运行记忆）。本包只指一条硬要求：**训练面板与决策截面必须由同一个函数构建**（`starter/lib/panel.py` 的 `build`），三条腿共用这份面板、同一组训练与验证日期（`panel.fit_dates`）、同一个股票池与同一本书；市场状态也只由一个函数产生（`starter/lib/model.py` 的 `market_state`），训练日与决策日走同一条路径。
