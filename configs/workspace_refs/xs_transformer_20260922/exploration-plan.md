# 研究会话探索计划

目标不是复现任何文献读数，而是检验一件事：**在沪深 300 成分截面上，让一层跨名字注意力（外加基准状态的门控）架在一个小时序编码器之上，能不能在主动序列上拿到逐股学习器拿不到的增量。** 判据、对照与 G-INC 只在 `families.md`；数据与单位只在 `pit-field-map.md`；本文只排顺序与预算。

**本臂最大的风险不是门太严，而是把回放预算花在筛选上。** `gru_ranker` 的账单摆在那里：方向研究已经量出它与对照秩相关 0.74–0.88、顶端读数为负，整条臂还是跑完了，前推主动 IR −2.44。本臂的时序编码器与那条臂最近，**所以本臂的第 0 轮比第 1 轮重要**：G-INC 不过，就不该有第 1 轮。

## 第 0 轮：不占回放预算的普查、离线筛选与成本探针

用 `shell` 在研究期的决策视图上跑，不启动回放（`smoke_backtest` 例外，它也不占 replay-year）。任一条不合格就在第 1 轮的 `hypothesis` 里声明，不要硬凑。

1. **运行事实核对（最先做的一件事）**：`broker_replay.initial_cash`；`acceptance_rules` 里有没有跟踪授权（有就按它的 TE 与 β 区间办，本包不假设）；两个回撤上限；`budgets` 里的 `max_replay_years`、`strategy_fit_timeout_seconds`、`strategy_gpu_count`、`strategy_memory_bytes` 与 `strategy_cpus`。**这些决定后面每一步**，不要从包里或别的臂去推。
2. **数据核对**：`index_weight` 与 `index_daily` 在不在，`universe.l1_name` 在不在，`torch.cuda.is_available()` 是不是 True（`pit-field-map.md` 开头两条）。
3. **截面与市场状态的普查，按研究年分别列**（跨决策日比较行业名单是错的）：每个研究年取一个决策日，报成分只数、可交易成分只数、有完整 `WINDOW_DAYS` 特征窗口的名字数、成分之间的**平均逐日收益相关**（注意力有没有东西可看，取决于这个截面到底有多同质）、以及五个市场状态数的逐年分布与是否被固定尺度截断得太狠（大量值贴在 ±3 上说明尺度选错了）。
4. **账户算术表**（`references/capital-arithmetic.md`）：用本臂的资金在若干个候选席数上算座位金额、买得起的成分比例、佣金地板、按预期换手算的年成本，以及在当前 `cost_stress_multiplier` 下 α 要付掉多少。
5. **零技能的形状读数**：本臂打算用的池与席数上，等额现金零技能能拿到什么（`references/zero-skill-panel.md` 给了几种已量过的形状；不在表上的自己在离线截面上按同一成分侧抽一遍）。**地板在哪里要先知道，否则第一批的读数没法解释。**
6. **G-INC（`families.md`，本轮硬门）**：离线把 `x1` 与 `c_lgbm` 都训出来、在至少 60 个跨越四个研究年的互不重叠决策日上打分，量 ρ、Δ 主动超额与顶端读数，按 `families.md` 的三条判定走。**顺手把 `c_temporal` 与 `MARKET_GATE` 关掉的两条也离线量一遍**（P8 的第一批读数），这一步整条在离线做，不花 replay-year、不增加 `trials`。
7. **`fit` 成本探针**：`smoke_backtest(start=研究期靠后的一天, days=2)`。它在真实回放路径上跑一次完整 `fit`，返回 `phase_seconds`、`resources`（容器峰值内存对着 16 GiB、每次 `fit` 秒数对着当时生效的上限、GPU 显存）与 `seconds_per_day.strategy`，**不占回放预算、不建 revision、不计 `trials`**。三条纪律：
   - **必须在研究期靠后的槽上量**：训练窗口随跨度长大，研究首年的读数会骗人（那时窗口有一半落在数据下限之外）。
   - **同一个 `start` 复用**：`window_build_seconds` 几乎全是那个窗口一次性的开窗成本，**付一次，后面同一个 `start` 的探针直接复用，不要乘以天数**；整期批次从研究期开头开窗，根本不付这一笔。
   - **单日/三日的墙钟不要当上限读**：它同时是「这份代码能跑通」与「当时那个负载下要多久」两件事，只有前者可以外推。
8. **离线筛选的前置条件表**（缺一格就不进回放）：

   | 读数 | 口径 |
   |---|---|
   | 最好 `SEATS` 只相对**同池等权**的前向收益 | 在可行席数区间的两端各读一次，与复核节奏同长，**按研究年分开** |
   | 成本线 | 按复核节奏与换名数、用本臂自己的资金算出来的年成本，从上一行里扣掉 |
   | 回撤先验 | 绝对回撤与主动回撤各一个。**建在指数里面的书绝对回撤贴着沪深 300 自己的 39.6 %**，这一格是硬前置 |
   | 敞口先验 | 篮子里最大的单一申万一级行业占多少只、多少权重。整窗集中度先验超过 0.30 的构造要么改，要么不进回放 |
   | G-INC 三个数 | 第 6 条 |
   | 门与注意力分开的两个读数 | 第 6 条（P8） |
   | 两个种子的差 | 同一配置换种子重训一次，读主动超额之差。**比种子差还小的优势不是证据** |

## 第 1 轮：三条腿，一次完整研究期 `batch_validate`

| 候选 | `CANDIDATE` | 身份 |
|---|---|---|
| `x1` | 市场门控 + 截面注意力 | **主候选** |
| `c_temporal` | 关掉截面注意力 | **机制归因对照**（不得提名） |
| `c_lgbm` | 同特征同标签的 LightGBM | **汇报用对照**（不得提名） |

三者共用同一面板函数、同一组训练日期、同一个池与同一本书，`main.py` 只差 `CANDIDATE` 一行。**一批三条腿、四个研究年 = 12 个回放年、3 个 `trials`。** 先对 `x1` 跑一次 `smoke_backtest`。

`hypothesis` 必须写清：机制与经济解释、**证伪条件**、`HORIZON`、`WINDOW_DAYS`、`HEADS`、`MARKET_GATE` 的取值、训练窗口与验证切分、热启动的设定、种子、席数、复核节奏、保留带与换名上限、预期的主动信息比率与逐年符号、P2/P3 的判定规则，以及**本轮之后的累计 `trials`**。

第 1 轮之后，对领先的完整研究期节点跑一次 `run_null_control`：不花回放年，会话时钟在它运行期间暂停。**它是诊断不是判据**——它比的是原始超额、按流通市值分位配替身，和裁决用的那个面板不是一回事；三个数一起报。

## 预登记的验证计划与 `trials` 记账

**在第 1 轮之前写进 `hypothesis`，之后逐轮更新：**

| 轮次 | 内容 | 回放年 | `trials` |
|---|---|---|---|
| 第 0 轮 | 离线普查、G-INC、P8 的离线读数、`smoke_backtest` 探针 | 0 | 0 |
| 第 1 轮 | `x1` + `c_temporal` + `c_lgbm`，完整研究期 | 12 | 3 |
| 第 2 轮 | 一条变体轴的两个取值 + 当轮最好的基准 | 12 | 2–3 |
| 第 3 轮（如果还有方向） | 同上 | 12 | 2–3 |
| 收官 | 补齐缺的读数（`MARKET_GATE` 的整期对照多半落在这里） | 0–4 | 0–1 |

**两件必须记住的记账事实：**

- 冻结门要求至少 `min_full_span_validations`（默认 2）次可测量的完整研究期验证，**本计划第 1 轮就满足它**。
- **去膨胀 Sharpe 的试验数 `trials` 数的是本臂里完成过验证的每一个不同 revision，不分跨度**；离散度 √V 只取完整研究期主动 IR 的标准差。所以**子跨度验证也会抬高门槛而不降低它**：子跨度验证只用来复测实现与耗时，**不用来在候选之间做选择**，选择在离线做（第 0 轮）。按上表走，收官时 `trials` 在 7–10 之间；每多开一轮，同一个主动 IR 要过 0.90 的去膨胀概率就更难。**这就是为什么第 0 轮的离线筛选是本臂最省钱的一步。**

## 判定分支，逐条写死（判据本身见 `families.md`）

- **G-INC 判「相关高且无增量」** → 不进批次。换一条登记的变体轴（轴 a 序列窗口 → 轴 c 市场门控 → 轴 d 标签）重新离线量；两次都这样就关掉这个方向。
- **`x1` 与 `c_temporal` 分不开** → 那本书里没有截面注意力。先看第 0 轮第 3 条的平均截面相关：这个池子太同质时，注意力能加的东西本来就少。换 `HEADS` / `HIDDEN` 一轮；仍然分不开就按关闭条件 3 关掉这个方向，**不要靠加层数去追**。
- **门开与门关分不开** → 如实写进结果笔记（这与那份独立移植的结论一致），把 `MARKET_GATE` 关掉继续跑。**这本身是一个可发表的本地读数**，不要当成失败。
- **绝对超额高而主动超额低** → 赢的是成分池不是选名。看 `benchmark.panel_neutralized_excess`：它就是零技能在这本书的形状上拿到的那部分。改池或改权重方案不会解决它，只会换一个零技能地板。
- **逐年主动超额有负年** → 先看是哪一年、是不是那一年的行情（2024 年初的小盘踩踏杀过一批学习型信号），再决定走哪一轴。两轮都有多数负年即关闭。
- **回撤越界** → 先看是绝对回撤还是主动回撤。绝对回撤越界时**不要靠降仓位去换**（那只是把书变成一半现金的指数），走席数或换一条更分散的构造。
- **P2（行业集中度）不成立** → 先看是哪一个行业把它带上去的。注意力很容易学成「押住当期最强的那一行业」，这时优先动轴 d（标签按行业去均值），而不是事后加行业上限（那一格量过，IR +0.40 → −0.45）。
- **热启动没有效果或有害**（P6 的同批对照里 `WARM_START` 关掉更好） → 如实写进结果笔记，把热启动关掉继续跑。**这也是一个结论**：本仓库第一次测它。
- **实现底线不成立**（训练超时、显存超限、决策超 60 秒、容器内存逼近 16 GiB） → 先修实现，修完重跑一次仍不成立则放弃该变体。
- **`c_lgbm` 领先 `x1`** → 预期之内，写明整窗与逐年差，不触发关闭，也不把 `c_lgbm` 改作候选。

## 第 2 轮起：一次只改一个可分离组件

按 `families.md` 的变体轴取，每轮一个，与当轮基准同批比较。轴的顺序：**a 序列窗口 → b 注意力 → c 市场门控 → d 标签 → f 热启动 → e 训练窗口与节奏 → g 构造**。一条轴在两轮里都没有满足条件的候选就关闭这条轴。每加一次容量（窗口、头数、隐藏维、层数）都要重新量一次 `fit` 成本与显存，**用第 0 轮那个 `start`**。

## 每个候选必须汇报的读数

除标准结果块外，写进结果笔记：机制与证伪条件；**主动中性化超额、主动跟踪误差、主动信息比率**与**面板自己的中性化超额**；逐年分块的主动超额与原始超额；绝对回撤与主动回撤；`top_industry_weight`、`size_tilt` 与 `size_beta` 并排；`c_temporal` 与 `c_lgbm` 的同批同跨度读数与逐年差；G-INC 的三个数；**门开与门关的对照读数（P8）**；**每次回放里的重训次数、热启动是否生效、各次验证 IC（订单元数据 `refits` / `warm_start` / `valid_ic`）**；两个种子的主动 IR 之差；年换手、按本臂 `initial_cash` 重算的佣金账与 2 倍滑点下的超额；拒单率与原因；平均总仓位；`pnl_concentration`；每次 `fit` 的墙钟（`phase_seconds.fit` ÷ 重训次数）、容器峰值内存与显存峰值；一次复核决策的实测平均墙钟。缺任何一项的结果不作为提名依据。

## Validation 否证（任何一条命中，结果无效，不讨论收益）

- 股票池不是按时点读出来的：硬编码名单、或用别的指数建书而仍按沪深 300 报跟踪误差。
- 用 `ann_date`/`trade_date` 而不是 `available_at` 判可见；把成分截面的日期当作调整生效日；`weight` 当成小数没有 ÷ 100。
- 成分的 `con_code` 没有改名就去 join，得到一张空表却按「池太小」处理。
- 训练用了标签尚未实现的信号日；训练段与验证段之间没有隔离带；市场状态或特征的归一化用到了 t 之后的行（**固定尺度就是为了堵这个口子，改它的时候不要改回拟合式的归一化**）。
- 在 `generate_orders` 里训练或更新权重；把训练好的权重放进 `models/` 以跳过重训。
- 训练面板与决策截面不是同一个函数构建的；三条腿之间的股票池、篮子、标签或训练日期不一致。
- 写了 CPU 回退路径，或在没有 CUDA 时静默继续。
- as-of 域读失败后回退了 `snapshot_dir`；读多数据集的域时没有先按 `dataset` 过滤；任何读取不带日期窗口。
- 复核节奏依赖模块级计数器或跨调用缓存。
- 没有第 0 轮的 G-INC、账户算术表与逐研究年离线读数就开了回放。
- 用绝对中性化超额或绝对信息比率去论证边际，而不看主动读数与面板。
- 把 `size_tilt` 当成中性化回归的规模载荷来论证，或者在 `stats.benchmark` 缺字段时仍然按「大概达标」提名。

## 收官轮

只做两件事之一：对已经满足全部条件的最好候选补齐缺的读数并冻结；或者以 `finish_session(outcome="no_edge")` 携读数结束本臂。**收官轮只在没有轴可换、或预算见底时才开始**；预算见底时不开新轴，也不要让预算耗尽（流水线记 `deadline`）代替这个结论。

冻结的是提名节点自己的不可变快照，提名前不必把它恢复到 `output/`。不要提交离线普查脚本；`models/` 只放静态资产，权重不进产物。
