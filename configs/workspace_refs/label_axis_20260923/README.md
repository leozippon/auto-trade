# 标签轴参考包（label_axis，20260923）

本目录是只读 refs。本包登记的是**在那条唯一被确认过的载体上，把标签当成一个杠杆去拉**：Alpha158 + LightGBM 一个字不改，池、席位、成本、持久化节拍一个字不改，只换模型被要求去预测的那个东西。它不是可提交策略，也不是预期收益。

**为什么是这一条。** 本仓库四条学习型臂用的是同一个标签——β 残差化的 10 日前向开盘到开盘收益秩——而**没有一条臂的关闭理由提到过标签，也没有一条臂走到过标签轴**。同时，那条载体在沪深 300 成分池里作对照腿是全轮唯一读出真实技能的腿（主动超额 +4.30 %/年、**主动 IR 0.4642**、3/4 年正；另一条臂上读 +1.59 %/年、IR 0.18），**两者都低于冻结门 0.75**。载体是真的，边是不够的，而标签是这条载体上唯一一个从未被动过、且不需要新数据、不需要新架构、不需要放开镜像白名单的部件。

**本包顺手修掉的一件事**：在位标签是开盘到开盘的，而这本书**买在收盘、卖在开盘**。一只在复核日 D 进书的名字买在 `C[D]`、卖在 `O[D+N]`，所以在位标签把 D 当天的开盘到收盘那一段算成了书赚到的，而书那一整段还是空仓。误差是 N 天里的一个半场，从来没有被量过。`c_base` 保留这个错误（对照必须是未经改动的在位标签），`l_exec` 是把它改对的那条腿。

按以下顺序读：

1. `families.md`：标签家族、七条腿、与 20260922 载体的逐条差异、离线增量信息门 G-INC2、**试验计数与 DSR 算术**、构造与换手的两头、允许的变体轴、禁止重开表、提名条件与臂级终止规则（**唯一权威表述**）。
2. `pit-field-map.md`：逐表可见时点、单位、标签这一面新增的可见性要求与陷阱（唯一权威表述）。
3. `exploration-plan.md`：不占预算的普查、**全离线的 G-INC2**、首轮批次、判定分支与预算。
4. `references/`：四份技术笔记——零技能面板、账户算术（含换手两头的算术）、成分面、学习型候选的 `fit` 成本纪律与持久化口径。沙箱无网络，四份都是自写的，外部出处列在 `sources.md`。
5. `sources.md`：读数出处、本包在沙箱镜像里与真实宿主流水线上实测到的成本与构造读数、诚实的限制。
6. `starter/`：合同内的最小可运行包，**就是**七条腿本身，`main.py` 的候选常量在 `c_base` / `l_h20` / `l_h40` / `l_exec` / `l_cc` / `l_ind` / `l_vol` 之间切换，七者除这一行外逐字相同。它通过 `validate_strategy_package`，并在沙箱镜像里按正式容器边界跑通了七条腿的「读取 → 训练 → 出单 → 续训」，也在真实宿主流水线上跑通了跨季度边界的多日回放（读数见 `sources.md`）。**会话开始时 `output/` 就是这份代码**，`refs/starter/` 只是同一份的只读参考副本；正式回放的第一步仍然是 `smoke_backtest`。

## 机制

**载体（不动）**：158 个 Alpha158 日频价量算子（5/10/20/30/60 日窗口，前复权价、成交量与成交均价），逐截面稳健 z 分数，LightGBM 回归单点参数，季度重训、`init_model` 续训、每第 4 次冷启动。股票池是**决策日在册的沪深 300 成分**，12 席等额现金、每申万一级行业最多 3 只、保留带 2×、每次复核最多换 2 只。

**变量（唯一）**：标签的四个部件——

- **horizon** 10 / 20 / 40 个交易日。在位是 10，而本书**月度**复核：一个 10 日的分数被一本 20 多个交易日才动一次的书使用，视野与节奏本来就不匹配。
- **timing** 开到开 / 收到收 / **收到开**。第三个是本书真正赚到的那一段（见上）。
- **residual** 不减 / β × 基准同段 / 当日行业均值 / 两者都减。在位是 β。
- **scaling** 截面秩 / 先除以自身滚动波动再取秩。在位是前者。

七条腿：`c_base`（在位标签，**必跑对照，永远不得提名**）加六条变体，**每条只移动一个部件**。判据、变体轴与禁止重开表全部只写在 `families.md`。

**本包相对 20260922 那一版只改了两处构造，而且第二处是第一处逼出来的。** 第一处是复核节奏周度改月度：同一本 12 席的书在周度上实测年换手 **14.06 倍**（带门的那条腿 14.2 倍）、越过它自己包的 12 倍上限，而 10 万元账户上 17–18 倍的换手要吃掉 1.05–2.32 %/年的权益。节奏是唯一不碰分数就能动换手的杠杆，而且没人试过。

代价在另一头：前推要求**月完成回合数 ≥ 1.0**，本仓库有一条臂在别的门全过的情况下死在 0.1/月。月度 + 载体包的 `MAX_SWAPS = 2` 实测只拿到 **1.27 回合/月**，离下限太近，所以第二处改动是 **`MAX_SWAPS` 2 → 3**：同一段窗口重测读 **2.29 回合/月**、年换手 **4.60 倍**，两头都有 2.3–2.6 倍余量。两头都写成了提名条件。

## 这个包不做什么

- **不改载体。** 参数、特征族、折数、单点配置都不动。改了就说不清赢的是谁。
- **不改池，不改指数。** `benchmark_index` 是 `000300.SH`；本轮另有一条臂在换指数，两条臂同时动同一个杠杆就谁也说不清。
- **不把新数据拉进标签。** 标签只能由本包已有的价格、基准与行业列构成。引入资金流、事件、一致预期或分钟数据的「标签」不是标签工程，是换家族。
- **不一次把四条变体送进同一个整期批次。** `families.md` 的 DSR 表说明了为什么：多塞一条腿同时花 4 个回放年、加 1 个 trial、并把 √V 撑大，而标签轴恰恰是最容易把 √V 撑大的轴。离线先筛、**最多两条**进批次。
- **不拿离线读数论证边际。** 离线只有秩可信；同一条腿的离线 Δ 在本仓库翻过符号（+5.54 pp/年 → −0.63）。宿主批次是裁决。

## 一句话的验收

某条 `l_*` 在同一批里、在整窗与至少 3 个研究年上主动读数都不低于 `c_base`，且冻结门按运行事实通过——这才是一个发现。**秩 IC 更高而书没有更好**也是一个发现，而且是本仓库从来没有量过的那一个，如实写进结果笔记。
