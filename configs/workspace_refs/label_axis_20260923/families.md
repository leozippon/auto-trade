# 候选、标签家族、增量信息门、变体轴与关闭规则

本文是本臂候选定义、包级要求、变体清单与关闭判据的**唯一权威表述**；`README.md` 与 `exploration-plan.md` 只指向本文，不复述。可见时点、单位与陷阱只写在 `pit-field-map.md`；算术与口径写在 `references/`，读数出处写在 `sources.md`。

本包有**一个对照腿** `c_base` 和**六个登记的标签变体**。七者在 `main.py` 里只差候选常量一行，`lib/labels.py` 里只差一行家族表。**除标签之外，没有任何一个部件在腿之间不同。**

## 本臂为什么是标签轴

本仓库四条学习型臂全部用同一个标签——β 残差化的 10 日前向**开盘到开盘**收益秩——而**没有一条臂的关闭理由提到过标签，也没有一条臂走到过标签轴**（X2 §5.1 第 5 条：「untested as a lever, not confirmed or falsified」）。登记册把「标签工程」列在开放假设空间第 2 位，阻碍一栏写的是「无」。

同时，唯一被宿主确认过有技能的载体读数很薄：同一条 Alpha158 + LightGBM 分数在沪深 300 成分池里作对照腿读主动 IR **0.4642**（`seq_gru_persist_1m_20260922` 的 `c_lgbm`，主动超额 +4.30 %/年、3/4 年正）与 **0.18**（`xs_transformer_1m_20260922` 第一轮），两者都低于冻结门 0.75。**载体是确认过的，边是不够的**——而标签是这条载体上唯一一个从未被动过、且不需要新数据、不需要新架构、不需要放开镜像白名单的部件。

所以本臂的命题只有一句：**在同一条载体、同一个池、同一本书上，换一个标签能不能把主动读数抬过它自己的对照。**

## 标签家族（登记一次，写死）

四个部件，`lib/labels.py` 的 `Label` 逐字校验，越界即报错：

| 部件 | 取值 | 含义 |
|---|---|---|
| horizon | 10 / 20 / 40 个交易日 | 前向持有的交易日数 N |
| timing | `oo` / `cc` / `co` | 这 N 天用哪两个价格量：开到开 / 收到收 / **收到开** |
| residual | `none` / `beta` / `ind` / `both` | 排序之前减掉什么：不减 / β × 基准同段收益 / 当日申万一级行业均值 / 先 β 再行业 |
| scaling | `rank` / `volrank` | 直接取截面秩 / 先除以该名字自身的滚动已实现波动再取秩 |

**timing 这一项有事实上的对错，而在位的那个是错的，差一个半场。** 信号 bar t 是下一个交易日 D 的 08:30 决策所能看到的最新一根；本书在 D 的 **09:30 开盘卖出、15:00 收盘买入**（`lib/trade.py`，也是全仓库 08:30 盘前决策的统一成交口径）。所以一只在复核日 D 进书的名字，买在 **C[D]**，在 N 个交易日之后的那次复核卖在 **O[D+N]**：

- `co` = `O[t+1+N] / C[t+1] − 1` —— **本书真正赚到的那一段**；
- `oo` = `O[t+1+N] / O[t+1] − 1` —— 在位的那个标签，把 D 当天的开盘到收盘那一段当成书赚到了，而书那一整段还是空仓；
- `cc` = `C[t+1+N] / C[t+1] − 1` —— 把卖出日的开盘到收盘那一段算进来，而书那一段已经走了。

误差是 N 天里的一个半场，不是灾难；但它是一个错误，而且**从来没有被量过**。`c_base` 保留 `oo`，因为本轮的对照必须是未经改动的在位标签；`l_exec` 是把它改对的那一个变体。基准腿**永远用与股票腿相同的那两个时刻**，所以换 timing 不会出现「股票收到开、基准开到开」的静默错配。

**每一个变体只移动一个部件**，这是离线筛能被当作消融读的前提。组合腿（例如 20 日 + `co`）**不在本轮登记之内**：它要等第一轮读数出来之后按 P1 重写 `hypothesis` 另行登记，并且照样计入 trial。

`residual = none` 与 `residual = ind`（不带 β）在代码里可用但**不在登记表里**：前者是毕业谱系的原始标签，在一个基准相对的池子里它教模型去买 β（这正是 20260922 换成残差标签的理由）；后者拿掉 β 只留行业，是一个没有先验的角落。要用其中任何一个，先按 P1 登记。

## 增量信息门 G-INC2（整期批次之前必须通过，**全离线，0 回放年、0 trial**）

**登记的判据，一次写死：一个变体在离线上对 `c_base` 的主动超额差 Δ ≤ 0 ⇒ 这个标签不进整期验证。**

这道门**完全在 `shell` 里做，不发起任何回放**。理由是可计量的：每一次完成的验证——**不分跨度**——都会把本臂的 `trials` 加一，而 trial 数直接抬高本臂自己的冻结门（下一节的算术）。用回放年和 trial 去买一个「够不够格」的判断，等于先给自己抬高门再去撞它。

| 量 | 怎么算 |
|---|---|
| 决策日 | 研究期**后两年**里至少 **60 个分散的决策日**（每两周取一天，或等间隔取满 60）。逐年分开再看一遍：只有一年成立的增量不是增量 |
| 每一天怎么建 | 用起步包同一份代码，在同一张成分截面上、同一 12 席 / 每业 3 只 / 等额现金 / 同一整手规则下，分别按 `c_base` 与该变体各建一本书 |
| **主动**超额 | 前向持有收益减一个 **k = 20 的离线零技能面板**：每一份副本在**同一成分身份侧**（在册 / 不在册与候选一致）且这笔钱买得起一手的名字里随机换名，取 20 份日收益的等权均值。**面板必须对每条腿各抽一次，且用同一组随机种子**，否则两条腿的差里混进面板噪声 |
| **Δ** | 该变体的主动超额减 `c_base` 的主动超额，同一批决策日、同一形状 |
| 判定 | **Δ ≤ 0 即没有增量。** Δ > 0 但**不超过两个随机种子之间的差**也按没有增量算（本家族的方向研究在三个种子之间散开过 **4 pp/年**） |
| 秩 IC | 同一批日子上另报每条腿的**截面秩 IC**（分数对该腿自己标签的秩相关）与**对 `c_base` 标签的秩 IC**。秩 IC 只用来解释 Δ，不单独构成通过条件——一个标签可以更好预测它自己而更差地选出书 |

**离线的水平与 Δ 都不可信，只有秩可信**：`gnn_relation` 的锚定检查里秩相关逐位复现（spearman = 1.0），而 Δ 从离线 **+5.54 pp/年** 翻到实测 **−0.63 pp/年**，符号都变了。所以 G-INC2 只用来**否决与排序**，永远不用来论证边际；它说「不够格」时可信，说「够格」时只意味着可以花那 12 个回放年。宿主批次是裁决。

`fit` 成本单独量，也不花回放年：`smoke_backtest(start = 研究期靠后的槽, days = 2)`，读 `resources.fit_seconds` 与 `peak_memory_bytes`。**同一个 `start` 复用给后面所有靠后窗口的探针**（`window_build_seconds` 是一次性的）。

## 试验计数与 DSR 算术（先算，再决定带几条腿进批次）

去膨胀 Sharpe 概率的 trial 数 N = **本臂验证过的每一个不同 revision，不分跨度**；离散度 √V = **完整研究期主动 IR 的标准差**。用本仓库自己的 `deflated_sharpe` 实现、4 个研究年（976 个交易日）、正态收益反解出来的门（DSR ≥ 0.90 所需的主动 IR）：

| √V ＼ trials | 3 | 5 | 8 |
|---|---|---|---|
| 0.11 | **0.735** | 0.773 | 0.802 |
| 0.13 | **0.752** | 0.797 | 0.831 |
| 0.30 | 0.90 | 1.00 | 1.08 |
| 0.50 | 1.07 | 1.24 | 1.37 |
| 0.80 | 1.32 | 1.60 | 1.81 |

两条读法，本臂的整个批次计划建立在它们之上：

1. **腿读得越接近，DSR 越不是瓶颈。** 各腿完整期主动 IR 挤在一起时（√V 0.11–0.13，与流水线文档的标定一致），3 个 trial 的门只有约 **0.74**，低于冻结门 0.75 本身——这时候真正卡人的是 IR 与逐年符号，不是 DSR。登记册里「DSR ≥ 0.90 需要主动 IR 1.8–2.0」那句话是**某些臂自己的 √V 很大**时的反解（√V ≈ 0.8、8 个 trial 就正好落在 1.81），不是一个普适常数。
2. **标签轴正是最容易把 √V 撑大的那种轴。** 40 日标签与 10 日标签可以读得很开，一次把四条变体全塞进同一个整期批次，既花 20 个回放年，又把自己的 DSR 门从 0.74 抬到 1 以上。**所以「离线先筛、最多两条进批次」不是省预算，它是本臂能过 DSR 的前提。**

**计划的 trial 账**：第 1 轮 = `c_base` + 离线筛出的**最多 2 条**变体 = 3 个 trial、**12 个回放年**。第 2 轮（只在第 1 轮有腿赢过 `c_base` 时才开）= 领先腿 + 它的一个变体（或轴 f 的冷启动对照）= 再 2 个 trial、8 个回放年，**全臂 5 个 trial、20 个回放年**，门约 0.77–0.80。**上限写死：本臂在任何情况下不超过 6 个完整期 trial。**

**一条已登记、未解决的张力**（登记册 §4）：为省 trial 而做的离线预筛，机制上**削弱**了 DSR 的多重性校正，因为 √V 是按观察到的完整期 IR 离散度算的，不是按真实搜索空间（本臂真实搜索的是 7 个标签，而 DSR 只会看见 3 个）。本臂不假装解决它，只**如实在结果笔记里写出离线筛过几个标签**，并且不把「DSR 过了」当成比「赢过同批 `c_base`」更强的证据。

## 构造：10 万元账户上的整手算术

账户规则、佣金地板与整手误差的公式在 `references/capital-arithmetic.md`，这里只写本臂写死的那几条与它们的算术。

| 量 | 值 | 怎么来的 |
|---|---|---|
| 席数 `trade.SEATS` | **12** | 载体包同形状，不动 |
| 每业上限 `trade.INDUSTRY_CAP` | **3** | 3 / 12 = 0.25 < P2 的 0.30，按构造满足（时间加权仍要逐次读） |
| 保留带 `trade.KEEP_BAND` | **2.0** | 名次落到 24 名之外才可被替换 |
| 每次复核换名上限 `trade.MAX_SWAPS` | **3** | 被迫卖出先算。**比载体包的 2 大一档**，理由是下面那条实测：2 只换来 1.27 回合/月，离 F6 的 1.0 太近 |
| 复核节奏 | **每个自然月首个决策**（空仓时任何决策日） | 差异 2 |
| 座位金额 | 权益 × 0.97 / 12 ≈ **8,083 元**（10 万元满仓） | 一手买得起 T-1 收盘约 **80.8 元**以下的成分 |
| 买不起的成分占比 | 起步包实测 **8.48 %** | 只影响买入；已持有的名字涨过一个座位**不得强卖** |
| 佣金地板 | 5 元 / 8,083 元 = **6.2 bp/边** | 一次往返约 17 bp + 印花税 |
| **年换手（构造上限 / 实测）** | 构造 2 × 12 × `MAX_SWAPS` / `SEATS` = **6.0 倍** + 建仓；**宿主实测 4.60 倍/年** | 同一形状同一窗口，周度那一版实测约 17 倍/年、越界。对 12 倍上限仍有 2.6 倍余量 |
| **月完成回合数（构造上限 / 实测）** | 构造 **3**；**宿主实测 2.29** | 对前推 F6 的下限 1.0 有 2.3 倍余量。`MAX_SWAPS = 2` 时同一段窗口只读到 **1.27**，这就是本包把它调到 3 的原因 |

**换手这件事两头都会咬人**，本臂两头都写成提名条件：上限来自 10 万元账户的佣金地板（同一本书周度实测 14.06 倍、越界），下限来自前推 F6——`capital_aware_1m_riskmodel_20260921` **授权全过、IR 与逐年都在，最后死在 round-trips 0.1/月**。

**本包把节奏改成月度之后，上面那一头解决了，而下面那一头一度贴了上来**：先按载体包的 `MAX_SWAPS = 2` 跑了一次 80 天宿主冒烟，`turnover` 读 1.809（周度那一版同窗口读 6.54），但只拿到 **5 个完成回合 / 3.93 个月 = 1.27 回合/月**，对着 1.0 的下限。原因是保留带（名次落到 24 名之外才可被替换）在多数月份只放行一两只，而月度复核一年只有 12 次机会。

**起步包因此把 `MAX_SWAPS` 定在 3**（不是载体包的 2）。同一段 80 天窗口重跑读到 **9 个完成回合 = 2.29 回合/月**、`turnover` **2.445**（扣建仓年化 **4.60 倍**），30 张订单全部成交——下限有 2.3 倍余量，上限有 2.6 倍余量。

三条因此写死：

1. **月完成回合数是第一必报读数**，第 0 轮的账户算术要按 **2.29** 这个实测重算，不是按构造上限的 3。
2. 低于 1.0 时唯一许可的应对是**轴 c 把 `MAX_SWAPS` 再调一档到 4**（构造上限 4 回合/月，按实测比例年换手约 6 倍，仍在 12 倍之内）。
3. **不允许**把复核节奏改回周度或更快去解决它——那会把换手推回 17 倍那一侧，而那一侧已经实测越界。

## 点名禁止（五条）

1. **`c_base` 不得被提名。** 它是分母。赢不过它的标签不是一个发现。
2. **`lib/index.py` 的 `INDEX_CODE` 必须等于运行事实 `experiment_facts.benchmark_index`**（本臂是 `000300.SH`）。两者不一致、或这个键不存在，**立即停**：写清读到的两个值，按终止规则结束本臂，不要改代码去迁就参数，也不要改参数。策略容器读不到运行事实，所以这次比对只能由会话在第 0 轮做（`exploration-plan.md` 第 0 轮第 1 条）。
3. **未筛的全市场池。** 池必须是按时点从 `index_weight` 读出来的沪深 300 成分；硬编码名单、或用别的指数建书而仍按沪深 300 报跟踪误差，都是否证条件。
4. **单一申万一级行业集中的书**：P2 不成立即不可提名。
5. **把标签改成一个新的 alpha。** 标签只能由本包已有的价格、基准与行业列构成。任何引入新数据域的标签（资金流、事件、一致预期、分钟）都不是标签工程，是换家族，本轮不开。

## 提名条件（冻结前逐条满足）

1. G-INC2 已通过，且 Δ（逐年分开）与两条腿的秩 IC 都写进结果笔记。
2. 完整研究期验证完成，冻结门按运行事实通过；**trial 数与 √V 一起报**，并对照上面的 DSR 表说明门落在哪里。
3. **稳定性**：逐年分块的**主动**超额为正的研究年 ≥ 四分之三（四个研究年时 ≥ 3）。
4. **`c_base` 同批**，且候选在整窗与至少 3 个研究年上主动读数都不低于它。**这是本臂的核心条件**：赢不了在位的标签，就没有这条臂。
5. **两个种子**：至少两个种子的主动信息比率之差已汇报；比种子差（本家族实测约 4 pp/年）还小的优势不是证据。
6. P2 / P3 / P4 / P5 全部成立。
7. **集中度**：`pnl_concentration.top5_share_of_gross_gains` ≤ 0.5。
8. **实现底线**：`phase_seconds` 里单次 `fit` ≤ 1,800 秒；容器内存峰值**明显低于 16 GiB**；单次复核决策 < 60 秒；意图买单拒单率 ≤ 30 %；**座位填满率**与买不起份额逐次汇报。不成立先修实现再复测，不算证伪。
9. **持久化已被单独定价**：轴 f 的全冷启动消融（`COLD_EVERY = 1`）已在同批或前一轮跑过，两者的主动读数差写进结果笔记。本仓库已三次读出热启动不占优、零次反向。

主动超额 ≤ 0、空对照分位在 0.5 附近、去膨胀 Sharpe 概率接近 0 都是普通「没有边际」读数：候选不可提名，不触发家族关闭。

## 什么会杀死它（按命中即停）

1. **六条变体在 G-INC2 上全部 Δ ≤ 0** —— 标签轴在这条载体上没有增量。本臂以 `no_edge` 结束，**不去改载体、不去改池、不去加特征**。
2. **连续两轮完整研究期验证里没有任何一条变体赢过同批的 `c_base`** —— 以 `no_edge` 结束。
3. **主动超额为负的研究年连续两轮都过半** —— 关闭。
4. **`excess_at_2x_slippage` 在每一个可行席数上都 ≤ 0**，或**月完成回合数在每一个可行 `MAX_SWAPS` 上都 < 1.0** —— 机制可能真实但在这个账户与这个节奏上不可交付，先走轴 c 的另一端一轮，仍不成立即以「不可交易」关闭。
5. **P2 在所有已登记构造下都不成立** —— 关闭并写明是哪个行业带上去的。
6. 提名条件 8 修复一次后仍不成立 —— 该变体放弃，不算家族证伪。
7. **本臂用满 6 个完整期 trial** —— 收官，按当时最好的读数收尾。

## 臂级终止规则

任一成立即本臂关闭：上面第 1、2、3、7 条命中；预算用尽前没有可提名候选。关闭以 `finish_session(outcome="no_edge")` 携读数结束本臂，**不换家族**，不把 `c_base` 改作候选，也不把「某个标签的秩 IC 更高」写成一个发现——秩 IC 更高而书没有更好，本身就是本臂最有价值的一条负结论，如实写进结果笔记即可。
