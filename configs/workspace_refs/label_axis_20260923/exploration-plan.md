# 研究会话探索计划

目标：在本臂唯一的研究会话里，判定**换一个标签**能不能让那条确认过的载体在主动序列上变好；变好就把它做成一本站得住的书，没有就诚实地以 `no_edge` 结束。判据只在 `families.md`，数据与单位只在 `pit-field-map.md`，本文只排顺序与预算。

**本臂的命题有且只有一个**：某条 `l_*` 要赢同批的 `c_base`。七条腿用同一个载体、同一个股票池、同一组席位与节奏，只差一个标签。所以**没有 `c_base` 的任何读数都不算数**，而「整窗超额好看」这件事在本臂上尤其不说明问题——同一条载体的校准臂前推原始超额是正的（+5.22 %/年），按面板重算的主动信息比率却是 −0.30。

## 第 0 轮：不占回放预算的普查

用 `shell` 在研究期末的决策视图上跑，不启动回放。任一条不合格就在第 1 轮的 `hypothesis` 里声明，不要硬凑。

1. **运行事实核对（最先做的一件事）**：读 `experiment_facts.benchmark_index`，与 `starter/lib/index.py` 的 `INDEX_CODE` **逐字比对**——这个参数同时决定裁决中性化的基准腿、零技能面板换名看的成员资格与跟踪统计量，策略容器读不到它（`context` 只给目录与决策时刻，合同也不允许读 JSON），所以这次比对是会话的责任。两者不一致、或这个键不存在，按 `families.md` 的点名禁止第 2 条**立即停**，不要改代码去迁就参数，也不要改参数。然后核对 `broker_replay.initial_cash`、`acceptance_rules` 里有没有跟踪授权及其上限与区间、两个回撤上限、`budgets`（含 `strategy_fit_timeout_seconds`）与 `max_replay_years`。本包按 10 万元、不带授权、沪深 300 写成；不符就改登记，不要静默沿用 12 席。
2. **数据核对**：`index_weight`、`index_daily` 在不在，`universe` 带不带 `l1_name`（`l_ind` 要它）。
3. **账户算术表（直接对着 P3）**：用本臂的资金，在 10 / 12 / 15 席上算座位金额、买得起的成分占比、5 元最低佣金的 bp/边、一次往返总成本、按**月度**节奏的预期换手算的年成本，以及在 `cost_stress_multiplier` 下 α 要付掉多少（公式在 `references/capital-arithmetic.md`）。**这张表决定本臂真正可行的座位区间，必须在第 1 轮之前有。**
4. **股票池普查，按研究年分别列**：在册成分只数、可交易只数、买得起的占比、申万一级行业个数、最薄成分的 20 日均成交额、价格分布。
5. **零技能的形状读数**：本臂的池与席数上等额现金零技能能拿到什么（`references/zero-skill-panel.md`：10 万元 / 30 席沪深 300 的零技能信息比率中位 0.986，15 席 0.654）。**地板在哪里要先知道。**
6. **标签面的离线体检**（本轮特有，不花回放年）：在最后一个完整研究年上，对七条腿各算一次——(a) 标签本身的截面分布（离散度、缺失率、可用 bar 数，长视野腿在窗口两端少多少）；(b) 同一份载体分数对**每一条标签**的秩 IC；(c) 七条标签**两两之间**的截面秩相关。第三项是最省事的一个筛子：与 `c_base` 秩相关接近 1 的标签不可能给出不同的书，**它可以在 G-INC2 之前就被划掉，一分钱不花**。
7. **`fit` 成本探针**：在研究期靠后的槽上跑 `smoke_backtest(days = 2)`，读 `resources.fit_seconds` 与 `peak_memory_bytes`，确认离 16 GiB 有明确余量（`references/fit-cost.md`）。**`smoke_backtest` 不花回放年，也不计 trial。****同一个 `start` 复用给后面所有靠后窗口的探针**：`window_build_seconds` 是一次性的。

## 第 0.5 轮：增量信息门 G-INC2（`families.md` 的硬门，**0 回放年、0 trial**）

判据在 `families.md`，这里只排步骤。全部在 `shell` 里做，**不发起任何回放**——每一次完成的验证不分跨度都会把 `trials` 加一，而 trial 直接抬高本臂自己的冻结门。

1. 在研究期后两年里取**至少 60 个分散的决策日**（每两周一天，或等间隔取满 60）。
2. 每一天用起步包同一份代码、同一张成分截面、同一 12 席 / 每业 3 只 / 等额现金 / 同一整手规则，分别按 `c_base` 与每条待筛的变体各建一本书。**第 0 轮第 6 条已经划掉的腿不必再建。**
3. 同一批日子上，每条腿各抽一个 **k = 20 的离线零技能面板**（同一成分身份侧、这笔钱买得起一手的名字里换名，取 20 份的等权均值），**所有腿用同一组随机种子**；各自的主动超额之差得 **Δ**。
4. 判定：**Δ ≤ 0 即没有增量**；Δ > 0 但不超过种子差也按没有增量算。逐年与前后两半分开再看一遍：只有一年成立的增量不是增量。
5. 把幸存的腿按 Δ 排序，**最多取前两条**进第 1 轮。这不是省钱，是 `families.md` 那张 DSR 表的要求：多塞一条腿同时花 4 个回放年、加 1 个 trial、并且把 √V 撑大。
6. 如果六条全部 Δ ≤ 0：按 `families.md` 的杀死条件 1，本臂以 `no_edge` 结束，**不去改载体、不去改池、不去加特征**。

**这一步不产生提名依据。** 离线面板比宿主面板宽松且偏低，而且离线的水平与 Δ 在本仓库已经被量出会翻符号；它**只用来否决与排序**。

## 第 1 轮：一次完整研究期 `batch_validate`

三条腿：`c_base` 加第 0.5 轮选出的**最多两条**变体。一次三候选完整研究期验证在四个研究年时花 12 个回放年、3 个 trial。

`hypothesis` 必须写清：逐行引用 `families.md` 的家族表与差异表、经济解释与**证伪条件**、席数与每业上限、复核节奏、保留带与换名上限、预期的主动信息比率与逐年符号、P2 / P3 的判定规则，以及**这一轮之前离线筛掉了几条标签**（DSR 那条已登记的张力）。

**不要再加零技能对照腿**——宿主每次正式验证都会抽面板。回放一旦开跑就计入预算，策略自身抛错的候选照样花掉，环境失败的候选退还。某一路因环境原因失败时不重跑、不压缩对照：把读数与待裁决的分支写进结果笔记。

第 1 轮之后，对领先的完整研究期节点跑一次 `run_null_control`：不花回放年，会话时钟在它运行期间暂停。**它是诊断不是判据**；三个数一起报。

## 判定分支，逐条写死（判据本身见 `families.md`）

- **某条变体与 `c_base` 读数几乎一样** → 这个部件在这条载体上不带信息。看该腿与 `c_base` 的**标签秩相关**：接近 1 就是第 0 轮第 6 条该划掉而没划掉，如实写；不接近 1 而书一样，那是一个真结论——**载体把不同的标签学成了同一个分数**，比一个 `no_edge` 值钱，要单独写一段。
- **某条变体明显差于 `c_base`** → 看它的秩 IC：IC 也更差就是标签更难学；**IC 更好而书更差**是本臂最有价值的一种读数（模型更会预测那个标签，而那个标签不是本书赚的东西），必须在结果笔记里点名。
- **`l_exec` 赢** → 在位标签那半场错配是真的。**这是本臂最干净的一种胜利**，但要先排除它只是 `l_cc` 的镜像噪声：两条 timing 腿的方向必须一起读，一正一负才算机制，同号或同为零就是噪声。
- **`l_h20` / `l_h40` 赢** → 视野与节奏的匹配是真的。**必须同时报换手与月完成回合数**：长视野腿的分数更稳，可能把换手压到 F6 的下限以下，那时赢的是读数、输的是可交付性。
- **`l_ind` 赢** → 行业均值是噪声源。检查它的 `top_industry_weight` 与 `size_tilt`：如果行业敞口同时掉下来，那是构造效果不是标签效果，要在第 2 轮用同一标签、放宽每业上限的一条腿去分离。
- **`l_vol` 赢** → 模型更会排序风险调整后的一段。检查书的实测波动与最大回撤：如果只是买了更低波的名字，那是一个已关闭家族（低波作排名）的换皮，**如实写并停**。
- **绝对超额高而主动超额低** → 赢的是股票池不是选名。看 `benchmark.panel_neutralized_excess`。**这正是校准臂当年掉进去的那个坑。**
- **逐年主动超额有负年** → 先看是哪一年、是不是那一年的行情，再决定走哪一轴。两轮都有多数负年即关闭。
- **月完成回合数 < 1.0** → 先按轴 c 把 `MAX_SWAPS` 往上调一档并复测；仍不成立即按「不可交易」关闭。**不要靠加快复核节奏去解决它**——那会把换手推回周度那一侧，而周度已经实测越界。
- **持久化腿（轴 f）赢过续训** → 续训被证伪。按更好的那个继续，并写进结果笔记。
- **实现读数不对**（座位没填满、买不起份额偏高、拒单率高、`fit` 逼近上限）→ 先修实现再复测，按提名条件 8。

## 第 2 轮起：一次只改一个可分离组件

按 `families.md` 的变体轴取，每轮一个，与当轮基准同批比较。一条轴在两轮里都没有满足条件的候选就关闭它。子跨度验证只用来复测实现与耗时，**不用来在候选之间做选择**——G-INC2 不用回放，这条规则因此原样保留。

**第 2 轮最可能的形状**是：领先腿 + 它的一条组合腿（例如「领先的 timing + 领先的 horizon」，按 P1 另行登记）或轴 f 的全冷启动对照。两条腿、8 个回放年、2 个 trial，全臂 5 个 trial。

## 收官轮

只做两件事之一：对已经满足全部提名条件的最好候选补齐缺的读数并冻结；或者以 `finish_session(outcome="no_edge")` 携读数结束本臂。**收官轮只在没有轴可换、或预算见底时才开始。**

无论结局如何，结果笔记必须留下给登记册的东西：**七条标签的秩 IC 与两两秩相关矩阵**、进了批次的那几条的宿主主动读数、以及「秩 IC 与书的好坏之间有没有关系」这一条的答案。本仓库从来没有量过标签轴，这几个数比 `no_edge` 三个字值钱。

## 计算预算

- **`fit`**：起步包在研究期靠后的决策视图上、按正式容器边界实测（读数与口径见 `sources.md`、`references/fit-cost.md`）。七条腿的差别在噪声之内，长视野腿并不更贵——训练行数少一点，列数完全一样。
- **推断**：单次复核实测不到 1 秒，上限 360 秒。非复核日在确认最新可见交易日之后直接返回 `[]`。
- **余量怎么花**：**不要用来多带腿**。`fit` 的墙钟与内存都离上限有一到两个数量级，但每一个被完整验证过的 revision 都会抬高本臂自己的去膨胀 Sharpe 门，而门是按**观察到的全期主动 IR 离散度**算的——标签轴恰恰是最容易把那个离散度撑大的轴。便宜不是理由，`families.md` 的 DSR 表才是。
- **单日探针的秒数对宿主负载极敏感**（本包实测同一份代码、同一个决策日、同一次冷启动在不同时刻读到 31.1 秒与 54.3 秒），耗时结论按多日回放的**平均**读。
- **回放年**：G-INC2 与 `smoke_backtest` 都是 0 年、0 trial；每次整期三候选批次 12 年、3 个 trial。以运行事实 `budgets.max_replay_years` 为准。**trial 只能花在整期上。**

## 每个候选必须汇报的读数

除标准结果块外，写进结果笔记：该腿的标签四元组与它相对 `c_base` 移动的那一个部件；经济解释与证伪条件；**主动中性化超额、主动跟踪误差、主动信息比率**与**面板自己的中性化超额**；逐年分块的主动超额与原始超额；`top_industry_weight`、`size_tilt` 与 `size_beta` 并排；**`c_base` 的同跨度读数与逐年差**；该腿与 `c_base` 的**标签秩相关**与各自的**秩 IC**；两个种子的主动信息比率之差；换手、**年完成回合数与月完成回合数**、按本臂 `initial_cash` 重算的佣金账与 2 倍滑点下的超额；拒单率与原因；平均总仓位；`pnl_concentration`；空对照的三个数；一次决策的实测平均墙钟；`fit` 秒数与容器内存峰值；以及**这次回放里冷启动与续训各发生了几次**（订单元数据里的 `refits` / `cold_refits` / `last_refit_cold`）。**账户面四项**也要报：每次复核的买不起份额与整期均值、座位有没有填满（没填满时如实报缺几个与原因）、实际权重对目标权重的偏离、书覆盖的指数权重。缺任何一项的结果不作为提名依据。

## Validation 否证（任何一条命中，结果无效，不讨论收益）

- 股票池不是按时点读出来的：硬编码名单、用别的指数建书而仍按沪深 300 报跟踪误差、或用最新一张截面去标注历史训练日。
- 用 `trade_date` 而不是 `available_at` 判成分可见；把成分截面的日期当作调整生效日；`weight` 当成小数没有 ÷ 100。
- 成分的 `con_code` 没有改名就去 join，得到一张空表却按「池太小」处理。
- **隔离带不等于该腿标签自己的 horizon**，或者七条腿用了同一个常数隔离带。
- **标签的两条腿用了不同的时刻**（例如股票收到开、基准开到开），或者基准腿没跟着 timing 一起换。
- 标签用了整段研究期算出来的 β，或标签横跨决策时刻（信号日 t 的标签要求 t + 1 + N ≤ T-1）。
- 截面 z 分数或标签的秩不是只在当天的成分集合上做的。
- as-of 域读失败后回退了 `snapshot_dir`；读多数据集的域时没有先按 `dataset` 过滤；任何读取不带日期窗口。
- 买不起的**持仓**被当成离池强卖；或者买单向下取整而不是按最近整手四舍五入。
- 复核节奏依赖模块级计数器或跨调用缓存。
- 把训练好的 booster 放进 `models/`，或让 `state_dir` 里的东西跨回放存活。
- 没有第 0 轮的账户算术表与 `fit` 成本探针就开了整期回放；跳过 G-INC2 直接开整期；把 G-INC2 做成一次子跨度回放；或者一次把三条以上变体送进同一个整期批次。
- 没有同批的 `c_base` 就拿某条变体的读数去论证增量。
- 用绝对中性化超额或绝对信息比率去论证边际，而不看主动读数与面板。
- 用**离线**的 Δ 或水平去论证边际（只有秩可信）。

## 收尾

冻结的是提名节点自己的不可变快照，提名前不必把它恢复到 `output/`。不要提交离线普查脚本；`models/` 只放静态资产。
