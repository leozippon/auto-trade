# 低残差波动 + 质量筛子参考包（lowvol_quality，20260916）

本目录是只读 refs：把**低 60 日残差波动**当排名信号，把**规模与现金流质量**当筛子，做一个不训练的只做多季度篮子，并按预登记的对照判定这条腿在书本尺度上是否真的在承载。它不是可提交策略，也不是预期收益。

任务只有一句话：在同一个股票池里，**先按流通市值截到较大的一半，再剔掉应计最差的一成，然后持有 60 日残差波动最低的 15 只，季度复核**，同批比过三个对照——**不成形的低波 15 只**（`c_v15`）、**同一构造去掉波动排名**（`c_qual`，只剩现金流质量）、**没有分数的等权池篮子**（`c_pool`）。赢不过 `c_v15` 说明成形没有用；赢不过 `c_qual` 说明低波腿没有在承载，边际其实来自质量；赢不过 `c_pool` 说明两者都不在。判据只按 `families.md`。

按以下顺序读：

1. `families.md`：主候选与构造、三个对照、**提名硬门与禁止表（关闭判据的唯一权威表述）**、允许的变体轴、臂级终止规则。
2. `pit-field-map.md`：逐表可见时点、单位、去重规则与陷阱（唯一权威表述）。
3. `exploration-plan.md`：不占预算的普查、首轮批次、判定分支、后续轮次。
4. `sources.md`：构造规则与这条腿的来源读数、起步包的沙箱冒烟实测、诚实的限制。
5. `starter/`：合同内的最小可运行包（`main.py` + `lib/face.py` + `lib/trade.py`），**不是**候选本身。它通过 `validate_strategy_package`，并在沙箱镜像里以真实 as-of 布局跑通了「读取 → 波动与报表 → 打分 → 中性化 → 成形 → 出单」全链路（读数见 `sources.md`）；正式回放的第一步仍然是 `smoke_backtest`。`main.py` 的 `CANDIDATE` 常量在四条腿之间切换，四者除这一行外必须逐字相同。

## 机制与本臂要回答的那一个问题

收益来源的经济解释是：散户主导、卖空受限的市场过度需求彩票型暴露——高近期波动、注意力、账面好看的盈利——而低估其反面。相对自身 20 日波动、规模、换手、动量与行业而言，60 日残差波动低的名字在一到三个月里挣到稳定的溢价；这不是 β，20 日彩票腿也捕捉不到它。现金流支撑的盈利是同一句话的基本面版本：没有经营现金流支撑的盈利（高应计）被外推、随后修正。

这两条腿在本仓库的旧臂里一直**合成**在一起用：一个分数、两条腿等权。那个形状既没有回答哪条腿在承载，也没有解决篮子的风险——15 只、20 % 以上跟踪误差、接近 40 % 回撤，前推门要求年化中性化超额的 80 % 自助下界为正（大致相当于超额高于 0.84 倍跟踪误差）和回撤不超过参数上限，那个形状清不过。

**本臂与它的姊妹臂（质量排名 + 波动筛子）是同一份信息的两种顺序。** 两者用同一个池、同一个季度节奏、同一个 15 只篮子、同一套硬门，只差谁排名谁做筛子，所以这一对读完之后，「在书本尺度上是哪条腿在承载」这个问题第一次有答案。本臂不得把质量改回排名信号——那是姊妹臂，在本臂里做就把这一对毁掉了。

**成形的代价必须一起报**：把池截到较大的一半会同时压低跟踪误差、回撤和**规模暴露**。中性化超额是把规模因子除掉之后的读数，所以「去掉小市值暴露」会同时改善裁决统计量并减少实际赚到的钱。本臂的门定在中性化统计量上（流水线的冻结门与前推裁决都读它），但**每个候选都必须把原始超额与规模倾斜作为第二读数一起汇报**（`stats.benchmark.excess_return`、`stats.benchmark.size_tilt`、`stats.benchmark.beta`），说明它到底在优化哪一个。`style_analysis.json` 是宿主侧的旁文件，会话读不到它，不要去找。

同样必须写明：**这个构造在本臂的排名列上没有量过。** 池底与二次排序的研究期读数是在姊妹臂的质量分数上测的（`sources.md`），应计筛子这一步没有任何书本读数。本包把它当作「值得预登记的构造规则」，不当作「已量到的边际」。

## 硬合同

- 正式策略写在 `output/` 包内：入口固定为 `output/main.py` 的 `generate_orders(context)`，返回严格 JSON 订单数组；辅助模块放在 `output/` 下并用绝对导入，每个 `.py` 受同一套静态检查，文件数与总字节数以运行事实为准。
- 正式 import 只允许：纯计算标准库、`numpy`、`pandas`、`scipy`、`sklearn`、`lightgbm`、`xgboost`、`statsmodels`、`torch` 及其子模块，以及 `output/` 内自己的模块。本臂 `gpu_count=0`。
- **本包不训练**：没有 `fit`、没有 `REFIT_PERIOD`，每次决策是四次有界的 parquet 读取、一次 60 日滚动回归加一次最小二乘。学习型合成是禁止项（`families.md`），不是变体。
- 沙箱无网络。不要写死 `/mnt/agent/workspace`。先核对本轮 `data_summary.json` 与 `unit_reference.json`，再经 `context.asof_dir` 读数，每次读取都给 `columns=`、`filters=` 与日期窗口；as-of 域读失败**不得**回退 `snapshot_dir`。
- 每一行输入必须 `available_at <= context.inference_at`；判可见只看 `available_at`。逐表规则见 `pit-field-map.md`。
- 执行时点只用 09:30 与 15:00（本臂不挂分钟域）。Broker 负责 T+1、费用、涨跌停与成交；策略只发订单草图。
- 不要把 refs 拷进 `output`。

## 研究流程与账户

研究期由若干整的七月至次年六月研究年组成，本臂只有一个研究会话，在这个研究期上开发与验证；决策视图定在研究期末，输入窗口从那里往前数。精确窗口与研究年标签以运行事实为准，本包不复述。预算按臂计、跨尝试累计：**2,400 分钟推理时间、96 个回放年、6,400 次模型调用、12 次空对照**（以运行事实 `budgets` 为准，一次尝试失败后原地续跑，接着花同一份预算）。完整研究期验证带逐年分块（`sub_windows`，每个研究年一行），只有完整研究期节点可以提名冻结，冻结门按本臂验证过的全部 revision 给提名的去偏 Sharpe 打折——对照与失败的候选同样计入试验数。

会话以 `finish_session` 的一种结局收尾：`freeze` 冻结本臂唯一的交付并结束研究，`no_edge` 按 `families.md` 的终止规则结束本臂；没有下一个会话可以交接，推理时间或模型调用预算先用尽时流水线记 `deadline` 结束本臂。上下文接近上限时用 `compact(summary=...)` 把对话换成自己的摘要；压掉的读数、节点编号与代码都留在只读根 `trace` 里，用 `read_file`/`grep` 读回，不要重算。冻结产物随后在研究期之后的连续前推期与 Held-out 上回放一次并裁决：那段数据没有会话看得到，也没有 Agent 参与，前推不过即本臂结束，没有第二次冻结。

账户是 10 万元真实资金：佣金万一、最低 5 元/笔，过户费 0.1 bp，卖出印花税按成交日切换，方向滑点 5 bp。15 只等权、97 % 仓位时单只预算约 6,300 元，最低佣金即 7.9 bp/边，一次往返约 25–35 bp。起步节奏是**季度复核、2 倍保留带、每次最多换 8 只**：按此上限每年约 32 次换名 ≈ 200 % 年换手 ≈ 0.5–0.6 % 的年成本拖累（第 0 轮普查用研究期实测核对）。低波腿的自然换手比质量腿低，实测低于这个上限是正常的，但门 6 的每年 ≥ 20 回合是硬的。成本门也是硬合同，判据写在 `families.md`。

## 「没有边际」的读法

每个候选按 `families.md` 的提名硬门逐条读，不看整窗总收益；本文不复述判据。另外三点读法：

- 逐年读。防御型篮子在下跌年份的原始与中性化超额都偏好看，在宽幅高波动的上涨年份又会被压到零附近；把 `stats.sub_windows` 的逐年读数与整窗读数一起读，并写明哪一年撑起了整窗。
- 中性化是机制定义的一部分，不是可删的降噪：残差波动排名不对 `vol_20`、`max_20`、规模、换手与动量中性化，本臂就退回到一个每个参考包都禁止的通用低波打分，而不是本包登记的那条腿。
- `null_control.excess_percentile` 用 `run_null_control(node_id)` 只给完整研究期的决赛候选算（本臂至多 12 次，不花回放年）；`selection_statistics.deflated_sharpe_probability` 是冻结门此刻对该节点的读数，已按本臂的试验数 `trials` 打折。研究期整窗读数好看不等于前推成立：不要把提名条件当目标函数去逼近，逐年分块与空对照分位是同等的硬门。

没有候选证明边际时，不冻结是正当结果：按 `families.md` 的终止规则以 `no_edge` 携读数结束本臂。

## 低波腿有意重开了一个已登记的家族

每个参考包都把「低波」列进不得作候选的通用因子。本包把 60 日**残差**波动作为**排名信号**登记，并用两件事把它和已关闭的 20 日彩票/低波面区分开：中性化列里必须含 `vol_20` 与 `max_20`（否则它就是那条已关腿的换皮），以及 `c_qual` 对照（否则无法判断边际到底来自波动还是来自质量筛子）。旧臂里的 `ivol60` 腿从未被证伪——它在两个验证窗里都存活、空对照分位 0.97，只是输给了同臂的另一个冠军，那条臂整体终止时它跟着关了。本包重开它，是因为它从来没有以**主排名信号**的身份、在成形过的篮子上被测过。

## 禁止退回通用因子

本包的候选形态只有 `families.md` 登记的主候选与变体轴；手写的价值/反转/动量/换手/`max20`/`vol20` 打分不得作为候选，只能以中性化列的身份出现。`c_v15`、`c_qual`、`c_pool` 是对照，**不得被提名冻结**。把质量改回排名信号是姊妹臂的内容，在本臂里是禁止项。`families.md` 的禁止表里每一项都带着关掉它的研究期读数，不得以「再试一次」的名义重开。

## 运行教训与反馈通道

跨实验的运行教训不重复写在参考包里：默认挂载的运行记忆在工作区 `memory/<来源>/` 下只读可读，索引见 `inputs/skills_index.json` 的 `operating_memory` 一节。挂载条目与本轮实测冲突时用 `skill_feedback(skill, claim, evidence)` 报告（只收 `outdated`/`wrong`，必须带证据，同一条目每次 run 只受理一条）；工具与数据本身的缺陷用 `report_issue`。

本包只指一条硬要求：**普查面板与决策截面必须由同一个函数构建**（`starter/lib/face.py` 的 `build_cross_section`），构造规则必须由同一个函数施加（`starter/lib/trade.py` 的 `_shape`）。
