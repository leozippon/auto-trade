# 研究会话探索计划

目标不是复现任何单列读数，而是检验一件事：**以低 60 日残差波动为排名、以规模与现金流质量为筛子的季度 15 只篮子，能不能在研究期上挣到高于不成形版本、高于把两条腿顺序对调的版本、也高于无信息池篮子的边际，并且清得过流水线的前推门形状。** 判据与变体清单只在 `families.md`；可见时点与单位只在 `pit-field-map.md`；本文只排顺序与预算。

## 第 0 轮：不占回放预算的离线普查

用 `shell` 在输入窗上跑，不启动回放。任一条不合格就在第 1 轮的 `hypothesis` 里声明，不要硬凑。

1. **指数与三张表是否真的选进来了**：`data_summary.json` 的 `macro.datasets` 列出 `index_daily`，`fundamentals.datasets` 列出三张报表；分别报 `snapshot` view 与 `valid` view 的行数与日期覆盖（**不得由前者推断后者**）。沪深 300 缺失即声明排名列退为总波动，并写明本臂排的已不是残差波动。
2. **单位核对**：`unit_reference.json` 里 `macro.index_daily.pct_chg`（百分数）、`daily.circ_mv`（元，池底排的就是它）、`n_income_attr_p`/`n_cashflow_act`/`total_assets`（元）。实测 `ivol60` 中位数应在 0.015–0.025，`accr` 中位数应在 0 附近、1 %/99 % 分位在 ±0.2 量级；量级不对就是单位错了。另外核对 `ivol60` 与 `vol_20` 的截面秩相关：它应该高但不是 1，等于 1 说明残差化没有生效。
3. **版本与去重**：抽 20 个 `(ts_code, end_date)` 核对三张表各自只取到了最早版本、事件时点是三者中最晚的 `available_at`；抽 20 个名字核对报表年龄按可见交易日历计。
4. **成形前后的池与覆盖**：在每个研究年的四个季度复核日上报——可选池大小、池底之后的名字数、筛子之后的名字数（门 8 要求 ≥ 200）、`ivol60` 非空率、报表年龄分布，以及**成形前后两个 15 只名单的重合度**与各自的 `circ_mv`/`accr` 中位数。重合度接近 1 说明筛子在这份数据上没有实际作用，要在第 1 轮的 `hypothesis` 里写明。
5. **换手的先验**：在同样的复核日上离线算一次「按本规则连续持有时每季度会换几只」。低于每季度 5 只就意味着门 6 的每年 20 回合有风险，第 1 轮的 `hypothesis` 要写明并在结果里核对。
6. **一次决策的实测墙钟与内存**：参照 `sources.md` 的沙箱实测。

## 第 1 轮：主候选与三个对照，一次完整研究期 `batch_validate`

| 候选 | 是什么 | 身份 |
|---|---|---|
| `s_lq` | 池底 + 应计最差一成剔除 + `ivol60` 最低的 15 只，季度 | **主候选** |
| `c_v15` | 同一分数，不成形 | 对照，不得提名 |
| `c_qual` | 同一构造，排名列换成质量 | 对照，不得提名 |
| `c_pool` | 无分数的等距池篮子 | 对照，不得提名 |

四条腿共用同一股票池、同一季度复核与保留带、同一 `topk=15`、同一换手上限、同一执行时点，`main.py` 只差 `CANDIDATE` 一行。`hypothesis` 必须写清：三步构造的顺序与参数、`ivol60` 的窗口与最少日数、沪深 300 是否可用、中性化列清单（必须含 `vol_20` 与 `max_20`），以及 `families.md` 门 1–8 的判定规则。

一次四候选的完整研究期验证在四个研究年时花 16 个回放年。本臂只有一个研究会话，预算按臂计：**2,400 分钟推理时间、96 个回放年、6,400 次模型调用、12 次空对照**（以运行事实 `budgets` 为准；一次尝试失败后原地续跑，接着花同一份预算）。回放一旦开跑就计入预算，策略自身抛错的候选照样花掉，环境失败的候选退还。某一路因环境原因失败时不重跑、不压缩对照：把读数与待裁决的分支写进结果笔记，下一轮据此推进。

第 1 轮之后，对领先的完整研究期节点跑一次 `run_null_control`（门 7），它不花回放年。

## 判定分支，逐条写死（判据本身见 `families.md`）

- **候选在信息比率上不高于 `c_qual`** → 低波腿没有在承载。逐年分块里也不高于（至少两个研究年）→ 本臂以 `no_edge` 结束，读数里写清两条腿逐年的差；只在一个研究年落后 → 候选不可提名，按变体轴 a/b 再试一轮，仍不成立即终止。**不得**据此把本臂改成质量排名——那是姊妹臂。
- **候选在信息比率上不高于 `c_v15`** → 成形没有用。按轴 a（池底）与轴 b（筛子）各试一轮；仍不成立即关闭。
- **候选不高于 `c_pool`** → 两条腿都不在，直接以 `no_edge` 结束。
- **门 6 的回合数不足** → 先按轴 c 放宽保留带（1.5 倍）重测一次；仍不足即关闭：这条腿在这个节奏上换手太低，前推期同样过不了活动量条件。
- **门 1/3/4 不成立** → 不可提名，逐年分块与回撤路径写进结果笔记，按变体轴继续。
- **门 5 不成立** → 只登记与成本相关的变体（保留带、筛子宽度），仍不成立即以「不可交易」关闭。
- **门 7 不成立**（空对照分位 < 0.9）→ 同样的择时与仓位换一批名字也能做到，候选不可提名。
- **门 8 不成立** → 先修实现，修完重跑一次仍不成立则如实弃权。

## 第 2 轮起：一次只改一个可分离组件

按 `families.md` 的变体轴顺序，每轮取一个，与当轮基准同批比较：a 池底 → b 质量筛子 → d 波动窗口与尺度 → c 保留带 → e 价格上限。子跨度（单个研究年）的验证只用来复测实现与耗时，不用来在候选之间做选择：单个研究年的领先或落后被行情主导，不是结论。本轮全部候选被证伪后，下一轮必须换轴而不是换阈值；轴用尽即以 `no_edge` 弃权。

## 收官轮

只做两件事之一：对已经满足全部提名硬门的最好候选补齐缺的读数（空对照、原始超额与规模倾斜、2 倍滑点）并冻结；或者以 `finish_session(outcome="no_edge")` 携读数结束本臂。预算见底时不开新轴，也不要让预算耗尽（流水线记 `deadline`）代替这个结论。

## 计算预算

本臂不训练。沙箱实测（见 `sources.md`）一次决策约 4–5 秒、容器峰值内存约 1.3 GiB，远在单次推断上限（运行事实 `budgets`）与容器上限之内，也没有任何 `fit` 容器；一个研究年约 244 次决策，策略段约 18 分钟。护栏：`daily` 读取窗口 220 个自然日（窗口必须长于 130 个交易日的报表年龄上限），`fundamentals` 700 个自然日，`macro` 220 个自然日；非复核日在建好截面后直接返回 `[]`，不引入跨调用缓存——冷 worker 与热 worker 逐字节相同。

## 每个候选必须汇报的读数

除标准结果块外，写进结果笔记：逐年分块的**中性化超额与原始超额**；`stats.benchmark.size_tilt` 与 `beta`（池底压低规模暴露是本包的已知代价，必须显式读）；最大回撤与回撤发生的时段；换手、**平均每年完成的回合数**、年成本与 2 倍滑点下的超额；拒单率及原因；每个复核日成形前后的可选名字数；`pnl_concentration`；`vol_basis` 是残差还是总波动；一次决策的实测墙钟。缺任何一项的结果不作为提名依据。

## Validation 否证（任何一条命中，结果无效，不讨论收益）

- 中性化列里缺 `vol_20` 或 `max_20`：那样排的是通用低波，不是本包登记的 60 日残差腿。
- 用 `ann_date`/`trade_date` 而不是 `available_at` 判可见；用了重述版财报；三张表没有各取最早版本。
- `macro.index_daily.pct_chg` 没有除以 100；用了 `n_income` 而不是 `n_income_attr_p`；`circ_mv` 用了原始湖的万元口径。
- 候选的中性化列被删减；`c_pool` 被中性化；对照和候选用了不同的股票池；普查面板与决策截面不是同一个函数构建的。
- 三步构造的顺序被改动，或成形只施加在候选而没有施加在 `c_qual` 上。
- as-of 域读失败后回退了 `snapshot_dir`；读财务/宏观域时没有先按 `dataset` 过滤；任何读取不带日期窗口。
- 复核节奏依赖模块级计数器或跨调用缓存。

## 收尾

冻结的是提名节点自己的不可变快照，提名前不必把它恢复到 `output/`；对照节点不得被提名。不要提交离线普查脚本；`models/` 只放静态资产。
