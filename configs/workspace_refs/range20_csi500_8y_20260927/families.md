## 本臂的形状：一个在 2021–2025 上挑出来的规则分数，拉长到八年再量一次

**来历，与它带着的挑选。** `range20` 是 `index_relative_1m_b_20260919` 在沪深 300 成分上、2021-07..2025-06 这段研究期里筛过的 18 个价量信号中 h10 ICIR 最高的一个（0.439，t 4.30；另外 17 个是 maxret20、turn20、lowvol60、lowvol20、turn60、value_pb、value_pe、skew20、rev20 / 60 / 120 / 5、amihud20 / 60、mom60 / 120、volratio5_20）。所以 2021-07..2025-06 这四年（本臂的 Y5–Y8）带着一次 18 选 1 的挑选，**2017-07..2021-06 这四年（Y1–Y4）是时间上的样本外**。中证 500 与沪深 300 成分互斥，所以 Y1–Y4 在本池上是名字与时间两重的样本外。

**trial 账怎么记，写死在这里。** 在中证 500上，`r1` 是**唯一一个登记的配置**；包作者对它本身的离线读数是对提交配置的读数，提交之后按宿主 trial 计，不按离线申报。所以第一批申报 **`offline_trials` = 0**，除非会话自己再筛了别的变体（每个加 1）。那 17 个兄弟信号是在另一个池上被挑下去的，本包写明它们、不申报它们（与 20260926 轮相同的口径）。于是第一批 M = 1、N_eff = 1，八年的 DSR 门槛是主动 IR 0.695，起作用的是运行事实的下限 0.75；第二批加入 `r2` 后 M = 2、N_eff = ρ̄ + (1 − ρ̄)·2，两条腿高度相关（ρ̄ ≥ 0.8）时门槛仍是 0.695。还有两层没有任何一条臂计数的挑选：本轮的清单是看过四年读数之后才选中这个分数拉长的，包作者又是读过样本外半段之后才交给运营者建臂的（读数见 `refs/sources.md`，它没有改变任何登记）——这两层都写在这里，不进 DSR。

## 分数与书（起步包的唯一定义在 `refs/starter/lib/`）

与 20260926 轮的三个 `range20` 包逐字相同，一个常量都没改。

| 组件 | 定义 |
|---|---|
| 一根日线的振幅 | (`high` − `low`) ÷ `pre_close`；`pre_close` 缺失或 ≤ 0 的那一根不计入，不当成安静的一天 |
| `range20` | 这只股票**自己**最近 `knobs.RANGE_DAYS`（20）根可见日线（都 ≤ T-1、都在决策日前 200 个自然日的读取窗内）的振幅均值；停牌日没有日线，不进窗口；不足 20 根不打分 |
| `r1` 的分数 | −`range20`：越安静越靠前；并列按代码的固定散列破 |
| 池 | 决策日可见的最新一张 `knobs.INDEX` 截面的成分（中证 500，每张 500 只），去掉科创板（688 / 689）、北交所、名称含 ST / 退（回放槽锚点那一天的名称）、T-1 无日线、不足 20 根日线的名字 |
| 书 | **每个自然月首个决策日复核**（空仓时任何决策日都复核）；**50 席等额现金**；持仓排名 ≥ `SEATS × KEEP_BAND`（100 名）就卖；离开池（出截面、丢日线、丢分数、变 ST）无条件卖；**不设换名上限**；每个申万一级最多 floor(0.28 × 50) = **14** 只（持仓与买入合计，重分类造成的超额在复核日按排名从差到好卖掉）；只买一手（100 股 × T-1 收盘）不超过一个座位的名字，已持有的不因买不起被卖 |
| 补座位 | 两次复核之间，只要持仓少于 50 只（买单被涨停、缺价或现金不足拒掉），之后每个决策日按当天的排名从上往下补买，受同样的行业上限与可负担性约束；不卖、不重排 |
| 成交 | 卖出 09:30、买入 15:00；座位 = 账面价值 ÷ 50（账面价值 = (现金 + 0.98 × 卖出所得) × 0.97 + 保留持仓按 T-1 收盘）；按 T-1 收盘**四舍五入到最近整手**再按剩余现金截断 |
| 基准与账户 | `knobs.INDEX` = `000905.SH`、`knobs.CAPITAL` = 1,000,000：第 0 轮先读运行事实 `benchmark_index` 与 `broker_replay.initial_cash`，不符时改常量去对齐它们，反过来不行 |

**ST 过滤的数据源在本臂的选择里。** 起步包按 `universe.name` 过滤 ST / 退；这一列不是宏观或事件数据集，是快照按 `namechange` 取的「决策日生效的名称」，`namechange` 是每张视图都带的核心原始表，与本臂只挂四张宏观表的选择无关。回放槽用它自己锚点那天的 `universe`，所以一只年内才变 ST 的名字要到下一个研究年才被滤掉——与四年包相同的已知限制。

**行业上限在本池上的分量**（不读收益的普查，`refs/sources.md`）：未设上限时顶端 50 只的最大申万一级占比逐年平均 0.16–0.23、最高 0.34，96 次复核里 5 次超过 0.28（非银金融 4、公用事业 1）；按排名模拟的书第一大行业按只数最高 0.28，上限只偶尔起作用。

## 离线门 G-R20（整期批次之前必须重算，全离线，0 回放年；筛过的候选配置各计一个 trial）

登记的判据，一次写死：S1 覆盖不足，或 S2 秩 IC ≤ 0 / 不显著，或 S3 顶端对同池不挣，或 S4 规模中性 IC ≤ 0，或 S5 登记构造的书输给同池，⇒ 命中。**命中不改变第一批**：以 `no_edge` 收尾本来就要本会话至少一次完整期验证，所以不论命中与否，唯一一批都花在登记的 `r1` 本身上；命中是登记好的预测，宿主读数要对着它读。这些判据是 20260926 轮的五条原样按八年换算（「半数年份」从 2 / 4 变成 4 / 8），写于包作者读过样本外半段之后，所以它们只作预测、不作门。

- control：`c_shuf` 永远写 control: true——照常花回放年、计入完整研究期验证数，但不是 trial，也永远不能提名；`r1`、`r2` 与任何变体写 control: false。把候选登记成对照，它就失去提名资格；把对照登记成候选，是白给自己加一个 trial。
- offline_trials = 本批申报前离线筛过、读数影响了本批提交什么、但本批没有提交的候选配置数；提交进本批的候选在宿主验证时按 host trial 计，不重复申报。

冻结门的试验数 M 是本臂验证过的非对照 revision 加上各批申报的 offline_trials，按 ρ̄ 折成有效试验数 N_eff = ρ̄ + (1 − ρ̄)·M；公式与阈值以运行事实 acceptance_rules.freeze_gate 为准（本轮默认 min_dsr_probability 0.975）。

| 判据 | 怎么算（`refs/references/offline-screen.md`） | 命中 |
|---|---|---|
| **S1 覆盖** | 研究期 96 个复核日，池里可打分的只数与占可交易成分的份额 | 任一复核日 < 100 只，或任一研究年份额 < 0.90 |
| **S2 秩 IC** | `/mnt/tools/screen.py` 在 `/mnt/snapshot` 上，`--start 20170701 --end 20250630 --horizons 5,10,20,40 --top-fraction 0.105`（50 ÷ 每日可打分池的均值），h = 20 | `ic_mean` ≤ 0 或 `t_stat` < 2.0 |
| **S3 顶端** | 同一命令逐研究年各跑一次，h = 20 的 `top_excess_mean`（顶端对**当日被打分的池**的等权，`refs/references/offline-screen.md`） | 八个研究年里有 4 个或更多 ≤ 0 |
| **S4 规模** | S2 那一次的 h = 20 `ic_size_neutral` | ≤ 0 |
| **S5 书** | 登记的构造（保留带、行业上限按保留名字计、按账面价值定座位、可负担性、强卖、持仓随价格漂移）逐月建书，减同池等权；95 个月 | 八年平均 ≤ 0，或为正的研究年少于 4 个 |
| 诊断（只报不判） | 上面每一项都按两半（Y1–Y4 / Y5–Y8）分开报；h = 5 / 10 / 40 的 IC；十分位剖面；书的行业与创业板占比 | — |

**这道门只能否决，永远不能证明边际**：离线读数只有秩与方向可信；书级的离线读数只有跑的就是登记的构造、又用宿主的量尺时才可信，也只是一次有噪声的抽样（± 3.5–4 pp/年，登记册 §4）。

## 验证计划（先登记，再花回放年；本臂整期验证上限 3）

| 批次 | 腿（按顺序，`control`） | 完整期验证 / 其中 trial / 回放年 | `offline_trials` | 进入条件 |
|---|---|---|---|---|
| 第一批 | `c_shuf`（true）、`r1`（false） | 2 / 1 / 16 | **0**；会话另筛而没提交的变体每个加 1 | 第 0 轮核对完、G-R20 已重算（命中与否都进） |
| 第二批（正常路径） | `r2`（false） | 1 / 1 / 8 | 本批之前新筛而没提交的配置数 | `r1` 没有命中 K4 的任何一条 |
| 收官 | 冻结，或 `no_edge` | 0 | — | 见下文 |

- 全臂最多 **24 个回放年**、3 条完整期验证、2 个 host trial；不拟合，没有 `fit` 的秒数要算。
- **规则分数是确定的，没有训练种子要复现**。仍然适用的两条噪声：同一本书只因面板重抽就差约 0.55 pp/年（IR 差 0.1 以内按面板噪声读），离线侧的噪声底约 4 pp/年。
- 第一批之后，对 `r1` 的完整期节点跑一次 `run_null_control`：不花回放年，**是诊断不是判据**。

## 允许的变体轴

只有一格登记：**`r2`（`RANGE_DAYS` = 60）**，只在正常路径上进场。会话若要筛任何别的变体（比如按板块涨跌幅把振幅归一、换成 `rmax`、改席数或保留带、只在某一半上用），**每筛一个都计一个 trial**，在它筛过之后第一个记下验证的批次申报 `offline_trials`；改提交它就是一次新登记，重写 `hypothesis`，`r1` 按筛过而没提交再加 1。

**禁止**：用研究期之后的任何信息；在分数里加入任何别的数据集的列（本臂只挂四张宏观表，别的列本来也读不到）；非等额权重；把 `c_shuf` 改作候选或把候选登记成对照；把任何东西放进 `models/`；用最新一张成分截面去标注历史决策日；用别的指数建书而仍按 `benchmark_index` 评；为了追读数改保留带、行业上限或复核节奏而不申报；按年份或行情条件开关这个分数（那是一次对 Y1–Y4 读数的拟合）。

## 提名条件（冻结前逐条满足）

1. G-R20 已重算，五个判据量（分两半）与诊断读数写进结果笔记。
2. 完整研究期验证完成，冻结门按运行事实通过（主动 IR ≥ 0.75、DSR ≥ 0.975、≥ 6 / 8 年正、`max_drawdown` 与 `active_max_drawdown`）；完整期验证数达到运行事实 `min_full_span_validations`（对照也计入）。
3. `r1` 没有命中 K4 的任何一条，而且第二批的 `r2` 与 `r1` 同号；两条都过冻结门时提名 `r1`（登记在先），只有一条过门就提名那一条。
4. P2 / P3 / P4 / P5 全部成立；`pnl_concentration.top5_share_of_gross_gains` ≤ 0.5。
5. **实现底线**：单次复核决策 < 60 秒、容器内存峰值明显低于 16 GiB；意图买单拒单率 ≤ 30 %；座位填满率与买不起份额逐次汇报。不成立先修实现再复测，不算证伪。

## 什么会杀死它（命中即停）

第一批（`c_shuf` + `r1`）之后，任一条命中 ⇒ 以 `no_edge` 结束，不开第二批、不换轴：

1. **K4a 样本外半段不为正**：Y1–Y4 四个 `sub_windows[].active_neutralized_excess_return` 的均值 ≤ 0。
2. **K4b 整期低于零技能线**：`r1` 整期主动 IR < 1.2816 × √(244 / T)，T 是完整研究期的交易日数（八年 1941 天，**0.4544**）。
3. **K4c 正年不够**：主动超额为正的研究年少于 **6 / 8**（冻结门自己的条数）。
4. **K4d 主动回撤**：主动回撤 > 0.30（冻结门自己的上限）。

之后：

5. **`r2` 与 `r1` 符号相反**（`r2` 整期主动中性化超额 ≤ 0）⇒ 不提名，以 `no_edge` 结束；`r2` 同号而低一些只是一条读数，照实报告，不否决。
6. P2 在已登记构造下不成立（`top_industry_weight` > 0.30）⇒ 关闭并写明是哪个行业。
7. `excess_at_2x_slippage` ≤ 0，或实测每月完成回合 < 1 ⇒ 这个形状不可交付，以「不可交易」关闭。
8. 整期验证上限（3 条，对照也算）用尽而没有满足全部提名条件的候选 ⇒ `no_edge`，不为了凑提名再开一批。

**臂级终止**：任一条命中即关闭，以 `finish_session(outcome="no_edge")` 携读数结束本臂，**不换家族**，不把 `c_shuf` 改作候选。`no_edge` 要带上 G-R20 的五个量（分两半）、`r1` 与 `c_shuf` 的主动 IR / DSR / 两半的均值与逐年符号、板块占比，以及对登记册 §3 与 §5 第 9 条的交代。
