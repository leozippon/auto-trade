# 裁决口径：零技能面板，以及本池八年的地板（中证 500）

自写笔记：流水线怎么算主动序列、宿主的零技能面板在本池上是什么、哪些东西零技能就拿得到。**别的池上量的零技能数字一个都不能拿来解释本臂**：池、价格分布与板块构成都不同。全部读数测在研究期 2017-07-01..2025-06-30 之内。

## 两层统计量

第一层，**中性化**：日收益对两条腿做 OLS，`r_t = α + β · r_基准,t + γ · r_规模,t + ε_t`，基准就是本臂的 `benchmark_index`（`000905.SH`），规模腿是全市场按前一日流通市值最小 30 % 等权减最大 30 % 等权。中性化超额 = α 年化（× 244），残差跟踪误差 = ε 的标准差年化。它看不见行业、板块、估值——P2 与 P5 补的是这块盲区。逐年的读数是在那一年自己的日子上重跑同一个回归。

第二层，**面板**：每次正式验证之后，宿主按候选自己的**成交骨架**（同样的进出时点、每笔同样的钱、同一 Broker 与成本）随机换名重放 20 份，取日收益等权均值 `p_t`；换名规则是「与原名字同在或同不在中证 500 成分内（读进场日之前最近一张截面）、这笔钱买得起一手（科创板按 200 股）、进出两天都有行情」。**被评的是 `a_t = r_t − p_t`**，全部统计量——中性化超额、跟踪误差、信息比率、逐年分块、回撤、DSR——都算在它上面。结果里读 `benchmark.active_neutralized_excess` / `active_tracking_error` / `active_information_ratio`，面板自己的读数是 `benchmark.panel_neutralized_excess`；逐年读 `sub_windows[].active_neutralized_excess_return`。

## 八年的抽样误差与这条臂的线

零技能下年化主动 IR 的抽样标准误是 √(244 / T)：八年 T = 1941 个交易日，**0.355**；每一半约 973 天，**0.50**。所以：

- `refs/families.md` 的 K4b 线 **0.4544** 是八年零技能的第 90 百分位（1.2816 × 0.3546）；
- 一半四年的读数单独看，第 90 百分位约 0.64——Y1–Y4 的一半即使读 0.5，也还在零技能的带里；K4a 只要求它为正，是一条弱得多的线；
- 冻结门在 N_eff 1 时要主动 IR 0.695，运行事实的下限 0.75 更高，起作用的是后者。

包作者用同一套规则离线量过本池的零技能带（`refs/sources.md`：把 `r1` 的分数在每个决策日的池里打乱、同一本书、对它自己的换名面板，40 次）：八年主动 IR 的 p10 / p50 / p90 = **−0.56 / −0.07 / +0.41**，Y1–Y4 **−0.76 / +0.02 / +0.62**、Y5–Y8 **−0.61 / −0.14 / +0.92**——中心在零附近、散布与 √(244 / T) 一致。

## 面板拿得到、而本书拿不到的东西（`refs/sources.md`）

- **科创板**：面板从全部买得起的成分里换名，包括本书剔掉的科创板；本池 2019-07 起才有科创板成分（Y4 起，份额 0.005 / 0.019 / 0.045 / 0.090 / 0.107）。「去掉科创板的等权」减「全部成分的等权」逐年 Y4 −0.13 / Y5 +0.95 / Y6 +0.15 / Y7 +2.42 / Y8 −1.38 %/年，八年 +0.25 %/年。八年里可以忽略，单年不行。
- **创业板**：面板按池里的份额抽到创业板（约 7–13 %），本书因为振幅天然大几乎不持有（约 0.9 %）。本池创业板对主板的等权差逐年 −12.6 / −16.5 / +27.3 / −5.9 / −12.1 / +2.0 / −18.6 / +22.2 %/年、八年 −1.8 %/年——解释不了八年的均值，但解释得了**逐年的形状**；2020-08-24 之前创业板与主板同为 ±10 %，这一截倾斜主要在 Y4 之后。它是分数自己选出来的，算进主动收益是对的，但要在结果笔记里写出来（P5）。

## 面板对不齐权重方案

面板按骨架换名，对齐了**股票池、日历、每个座位的钱与成本**，但**不对齐加权方案**：同一个分数从等额改成逆波动，面板跟着换名却不跟着换权重，那一档提升就整个记成技能（登记册 §2：逆波动的优势被量出是它自身的零技能溢价）。本臂每条腿都是等额现金，所以不欠这条对照；任何离开等额现金的变体都要同批带上同分数等额的腿。

## `c_shuf` 是什么，不是什么

`c_shuf` 是同批的一次零技能抽样：同一个分数分布、同一本书、信息被打乱。它的主动 IR 落在零附近一个标准差（八年约 0.35）之内是正常的；`r1` 要的是越过零技能第 90 百分位，不是赢过 `c_shuf` 的那一次读数。它每月重抽排名，所以几乎每次复核都换掉大部分座位，换手远高于 `r1`；这部分成本在它自己的面板里对消。同一本书只因面板重抽，主动超额就会差约 0.55 pp/年（IR 差 0.1 以内），两次读数之差小于这个量不要解读。

## `size_tilt` 与 `size_beta`

`size_tilt` 是持仓加权的截面市值秩位置（这本书站在哪一档市值上），`size_beta` 是中性化回归里的 γ（中性化真正除掉的规模载荷）；两者方向常相反，都要汇报，都不设门。`size_tilt` 的绝对值量的往往是池不是书：中证 500 成分按定义是中盘，跨指数比较 `size_tilt` 没有意义。

## 空对照只是诊断

`run_null_control` 比的是原始超额、按流通市值分位配对替身，而且会丢掉一部分回合；它和裁决用的面板不是同一件事。照常给领先节点跑一次，三个数一起报，不据此提名或否决。
