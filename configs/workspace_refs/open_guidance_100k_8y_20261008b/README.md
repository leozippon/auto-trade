## 方向

做多的信息在这份记录上只出现在一种地方：公司按一个披露出来的价格或数字押上自己。本臂看的是数字那一面：公司先给自己的业绩一个区间（业绩预告），后来又用自己披露的数字（业绩快报或定期报告）检验它。区间是公司的承诺；后来的数字落在区间上沿之上、之中还是下沿之下，是承诺有没有兑现、有多保守；公司在正式数字之前自己改区间（预告修正），是它主动更新承诺。

为什么不是「业绩预告之后的漂移」：那件事已经测过、关了（`refs/families.md` 财务域一行）。八年财务面上，每个报告期第一份预告按预告净利变动幅度的中值排、为正才进、持 20 日的书整期主动 IR 0.326、5/8、主动回撤 0.346；业绩快报作事件书在 Y1–Y4 探针即死；预告幅度在截面上没有边；标准化盈利意外（相对历史）与披露时点也关了。没测过的是**结果相对公司自己给的区间**——超出自己的承诺、落在承诺里、没达到承诺——以及**公司自己的修正**（那本书只取每期第一份预告，修正一律没看）。

可以用的形状（建议，不是菜单）：

- **兑现的承诺**：快报或定期报告里的归母净利高于本期预告区间的上沿（或按区间宽度标准化的超出量）。事件日是结果可见的那一天，不是预告日。
- **主动修正**：同一报告期的后一份预告把区间整体上调或下调（新的上下沿相对旧的），尤其是在法定披露期限之前、公司本可以不说的时候。
- **承诺的类型**：法定必须预告的（净利变动超过 50 %、扭亏、首亏）与自愿预告的（略增、续盈）不同；自愿给区间、后来又兑现的公司，在承诺的意义上最强。
- **反面对照**：没达到自己下沿的公司，同一骨架应该读负；读不负，说明书测的是「发预告的公司」而不是承诺。

用预告自己的方向或幅度、快报的同比增速、盈利意外或披露时点作选名信号，就是重开财务域那一行（申报 114）；在兑现或修正的书上再叠这些条件，也是。

## 研究几何

八年：研究期 2017-07..2025-06（Y1..Y8），窗口 108 个月。冻结门的正年数要 6/8，主动 IR 下限 0.75。两半是 Y1–Y4 与 Y5–Y8，最后两年是 Y7–Y8；探针与离线筛选只用 Y1–Y4（`open-rules.md` §4、§5）。

本方向的表与陷阱：

- `forecast_vip`：每行一个（公司、报告期 `end_date`、公告日 `ann_date`）版本；`type` 是预增、略增、续盈、扭亏、预减、略减、首亏、续亏、不确定；`p_change_min` / `p_change_max` 是净利变动的百分数区间，`net_profit_min` / `net_profit_max` 是归母净利的区间，**单位万元**；`last_parent_net` 是上年同期（万元）；`first_ann_date` 是这一期第一份预告的日子。同一（公司、报告期、公告日）常有 `update_flag` 0 与 1 两行，取 1；同一报告期有不止一个公告日的才是修正，八年里约 4,700 个报告期（每年约五百）。
- `express_vip`：快报，`n_income` 是净利润（元），`revenue`、`operate_profit`、`total_profit`、`diluted_eps`、`diluted_roe`；`yoy_net_profit` 是**去年同期的净利润金额**，不是增长率。快报是自愿的，不是每家都发。
- `income_vip`：定期报告的利润表，`n_income_attr_p` 是归母净利（元），可见时刻按实际公告日；同一期有更正版本时每个版本按自己的公告日可见。与预告比，单位换算成万元。
- `disclosure_date`：`pre_date` 是首次预约的披露日，`modify_date` 是改期，`actual_date` 是事后回填的实际披露日，只在早于决策日时可用。它告诉你结果大约何时出来，以及一份预告离法定期限还有多远。
- 法定预告的口径在板块与年份之间不同（沪市主板主要是年度预告，深市曾要求季度与半年度预告），自愿预告的比例也随之不同：按年份与板块分开数事件，再决定能不能并成一本书。

## 值得一看的（建议，不是菜单）

外部研究，不是宿主读数，都要在研究期上自己核对。

- **管理层指引的保守与兑现。** 美股文献里，管理层倾向给出可以超过的指引（「指引—超出」的博弈），超出自己指引的公司随后的漂移与只超出分析师预期的不同；A 股的业绩预告是监管强制与自愿的混合，强制部分的区间宽、语言模板化，自愿部分更像信号。
- **修正的方向与时点。** 上调修正在 A 股研究里常读到正的短期反应；问题是它在可交易的时点（标题可见之后、10 万账户能买到的名字里）是否还剩下漂移，以及修正是否只是「结果快出来了」的提前泄露。
- **事件之间的时间。** 兑现事件发生在定期报告或快报的公告日，与年报季、半年报季重叠，同一周里很多公司同时披露；席位要按每年可买的事件数定，不要按全样本平均。

## 本方向的对照要点

- 事件书（兑现或修正可见之后进场）：`late_entry`，同一批事件晚进场，k 至少是持有期（持 20–60 日的书用 60 或 120），书的其余部分不变。
- 按兑现程度挑出的子集：要胜过同一批结果事件里随机抽出的同样大小的子集（`shuffled_assignment` 用在事件上），不只胜过全体结果事件；再带反面对照（没达到下沿的同骨架书），它应该读负。
- 每条对照的年换手要在候选的 ±25 % 以内（`open-rules.md` §3），两个都报。
- 事件集中在披露季：先离线数清每年、每季有多少个能买进的事件，读探针之前先看平均总仓位。
