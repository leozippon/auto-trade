## 值得一看的（建议，不是菜单）

运营者做过一次外部文献调查（`logs/notes/review_20261007/survey/strategy_survey.md` 第 7 条；会话读不到，要点抄在这里）。它对这个方向的提醒是负面的：

- **只按预告类型做书已经关了。** 一份券商研究（中邮证券《业绩之锚 6》，样本是 FY2019–FY2024 的年报业绩预告）发现，按类型（预增、扭亏、略增……）分的 30 / 60 日相对万得全 A 胜率都在 50 % 上下；加上相对分析师一致预期的意外，略增且超预期的一档才升到 58 % / 66 %、平均超额 +2.0 % / +4.3 %，扭亏仍只有 46–47 %。一致预期不在这个数据湖里，连同登记册里业绩预告 0.326、快报在探针被杀，只看类型标签的预告书不必再测。业绩预增在一、二月的绝对收益多是季节性的（申万宏源 2025-02），零技能面板复制书的时点，季节性它也一起拿到。
- **还开着的**：用带时点的报表自己定义的意外（对公司自己的历史、而不是对一致预期）；分红政策的变化（第一次分红、提高派息率、中期分红），读数必须在计税之后成立；以及它们与承诺类公告的组合（例如报表在改善的公司发出的激励草案）。调查的横向结论也适用于这里：披露了价格、内部人持有不可撤回仓位的公告读数为正且持续，只记录别的投资者行为的公告之后为负。

## 本方向的对照要点

- 事件书：同一批事件把事件日平移（挪到同一只股票两次相邻事件的正中，或在同一个月内跨股票打乱），以及晚进场。
- 一个报表分数在日线估值列里有近亲（`pe_ttm`、`pb`、`ps_ttm`、`dv_ttm`）时，同批带一条换成那一列的同书对照：主张是报表比派生列多出来的那部分。
- 学习型：同一学习器只用日线特征的对照，与训练标签在每个训练日截面内打乱的对照。
- 定期报告集中在四、八、十月，年报预告集中在一月：空窗期握现金的书要看 `graduation_activity` 的平均仓位。
