# CH-3 两特征合成规则分数参考包·中证 500 / 八年研究期（ch3_csi500_8y，20260927）

本目录是只读 refs（会话里挂在 `refs/`）。本包登记的是**一个不训练的规则分数，在八个研究年上量一次**：`ch3`——每只股票在池内两个百分位秩的等权平均：盈利收益率 `ep`（1 ÷ `pe_ttm`，滚动亏损排最后）与一个月异常换手 `abturn`（−近 20 日 ÷ 近 250 日平均换手率）——在**决策日在册的中证 500 成分**里建一本 50 席、等额现金、月度复核的书，由宿主的零技能面板裁决。研究期是 2017-07..2025-06 的八个研究年 Y1..Y8；宿主的基准、面板的换名侧与中性化基准腿都键在 `000905.SH` 上。起步包与本轮另外三个价值 / 换手八年包（`ep_csi500_8y_20260927`、`dvy_csi300_8y_20260927`、`abturn_csi500_8y_20260927`）逐字相同，只差 `lib/knobs.py` 的两行：`INDEX = "000905.SH"` 与 `SCORE = "ch3"`。

## 为什么是这个分数、这个池、这八年

**CH-3 是定价模型，一本只做多、指数内、等额的书用得上的只有它的两个个股特征。** Liu、Stambaugh、Yuan（2019）的 CH-3 是市场、规模与 EP 价值三个因子，CH-4 再加上按异常换手构造的情绪因子；在中证 500 成分里，规模被指数截断、市场就是基准，剩下的是 EP（价值因子每月 1.14 %，t 4.34）与异常换手（CH-3 α 每月 1.28 %，t 2.86，`refs/references/literature.md`）。两者在本池上的截面秩相关逐年 −0.08…+0.18，近乎独立：都真时合成的 IR 约为单个的 √2 倍，只有一个真时约为一半。

**这是一个登记的配置，不是一次搜索。** 等权、池内百分位秩、两个输入的定义与另外两个包（`ep_csi500_8y_20260927`、`abturn_csi500_8y_20260927`）逐字相同，写于任何读数之前；改权重、去掉一个输入或换合成方式都是新登记。两个输入各自对应的登记册先验见那两个包：价值书都在沪深 300 与 2021–2025 上关的，异常换手在创业板指上读过一次零。本臂的八年、中证 500 与 2017–2021 这四年对两者都是新的。

**八年研究期与门槛。** 研究期拉长到 2017-07..2025-06 之后，Y1–Y4（2017-07..2021-06）是本仓库**任何一条臂都没跑过**的四年：登记册里所有价值、红利与换手的读数都落在 2021-07..2025-06（本臂的 Y5–Y8），运营者选这条臂时知道那几条四年关闭，也知道 2021–2025 的行情——这是本臂的挑选风险，所以 **Y1–Y4 是检验的那一半**。冻结门在八年上的算术：√V = √(244 / 1941) = 0.355，有效试验数 1 时 DSR 门槛是主动 IR **0.695**，所以起作用的是运行事实里的主动 IR 下限 **0.75**；正年门是 ceil(0.75 × 8) = **6 / 8**。

**要检验的只有一件事**：`ch3`（这个分数）在八年的主动序列上能不能越过零技能，而且前四年这一半本身为正。`c_shuf`（同一分数在同一决策日内打乱）是同批的一次零技能抽样。

## 你被评的是主动序列

宿主每次正式验证后按候选自己的成交骨架随机换名重放若干份，取等权均值作为零技能面板，全部统计量都在「候选减面板」的主动序列上算，再对基准与规模价差做两因子中性化（`refs/references/zero-skill-panel.md`）。本臂最该记住的四条：

- **绝对超额说明不了事**：中证 500 在研究期最大回撤 −41.8 %、八年 −3.6 %，逐年 −15.0 / −5.1 / +18.5 / +16.1 / −5.2 / −7.1 / −17.6 / +19.7 %。
- **中性化会改写逐年的形状**：冒烟里这本书的 β 0.74–0.85（70 天，只作量级），未中性化的主动收益在单边大涨或大跌的年份里有一截是 β 差；登记与裁决都读中性化之后的主动读数。
- **面板对齐股票池、日历、每笔的钱与成本，不对齐权重方案**：本臂每条腿都是等额现金。
- **面板会抽到本书剔掉的科创板**（Y4 起才有）：八年 +0.25 %/年，单年 ±2 pp 以内。

## 本臂的执行边界

执行合同以只读 `output/README.md` 为准，本包不复述。本包只在以下几点更具体：

- **不训练**：没有 `fit`、没有 `REFIT_PERIOD`；规则分数是确定的，**没有训练种子这一层方差**，剩下面板重抽（同一本书约 0.55 pp/年）与离线侧约 4 pp/年 的噪声底（登记册 §4）。
- **`gpu_count = 0`，纯 CPU**；策略容器 8 核 / 16 GiB。
- **三个常量由会话对齐**：`knobs.INDEX` 对 `benchmark_index`（必须是 `000905.SH`），`knobs.CAPITAL` 对 `broker_replay.initial_cash`（1,000,000），`knobs.SCORE` 必须是 `ch3`。空仓时账户现金不在 `CAPITAL` 的一半到两倍之间，起步包直接报错。**批次里不许有别的指数或别的分数的腿**：一条臂只有一个 `benchmark_index`、一个登记的分数；`SCORE = "range20"` 只是标明了的诊断，永远不是腿。
- **截面缺失、日线窗为空、可打分成分不足两倍席数，起步包直接报错**，不回退。
- 本臂的数据集选择只挂四张宏观表（`index_daily`、`index_dailybasic`、`sw_daily`、`index_weight`），没有基本面、事件与文本域；分数只读 `daily` 里供应商的 `daily_basic` 列（`pe_ttm` 与 `turnover_rate`；邻居读 `pe`），加进任何别的列就是另一条臂。
- 不要把 `refs/` 里的文件拷进 `output/`。

## 账户与回撤

开工第一件事是读自己的运行事实：`broker_replay.initial_cash`、`benchmark_index`、`acceptance_rules`、`budgets` 与 `max_replay_years`、`research_geometry.years[].input_window`。

**回撤上限是创建参数，不是本包的规则**：本臂按 `max_drawdown` 0.50、`active_max_drawdown` 0.30 建臂，因为中证 500 自己在这八年里回撤 −41.8 %，默认的 0.45 离它太近或低于它。冻结之后的裁决规则只由运行事实 `acceptance_rules.graduation` 给出，本包不复述；会话在研究期里要量的只有其中能在研究期量的几项（成本压力、每月完成回合、平均总仓位，`refs/families.md` 的 P3）。
