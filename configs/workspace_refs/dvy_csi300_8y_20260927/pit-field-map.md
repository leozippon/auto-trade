# 本轮数据与 08:30 字段图

本文是本包可用数据、可见时点、单位与陷阱的**唯一权威表述**。数据集清单、行数、日期覆盖与单位以本轮 `data_summary.json`、snapshot manifest 与 `unit_reference.json` 为准：先核对它们，再写阈值；`snapshot` view 与 `valid` view 分别核对，**不得由前者推断后者**。

**开工第一件事**：核对五件事——`macro.datasets` 里有没有 `index_weight`（没有它就没有这个臂的股票池），其中 `index_code = 000300.SH` 的截面在不在、每张是不是 300 只、2016-07 起逐月不缺；`daily` 带不带 `dv_ttm`、`dv_ratio`、`total_mv` 与 `close`；`universe` 带不带 `name` 与 `l1_name`；`unit_reference.json` 里 `dv_ttm` / `dv_ratio` 是小数（不是百分数）；以及运行事实里的 **`benchmark_index`** 与 `lib/knobs.py` 的 `INDEX` 是否一致（必须是 `000300.SH`）。**缺任何一块都不得静默回退**到别的池子、别的指数或别的列——那是另一个登记；起步包在读不到可见截面或读不到列时直接报错，就是为了让这种情况在第一次 `smoke_backtest` 就暴露。

## 本臂的数据集选择（创建参数）

八年研究期的专用选择：**不挂基本面、事件与文本域**，宏观域只挂 `index_daily`、`index_dailybasic`、`sw_daily` 与 `index_weight` 四张表，视图种子 `data/pit_views_seed_research_8y_div_20260924`（发布 `55fc7fd8…`，输入窗 108 个月；除息表从 2016-01 的分红事件重建，Y1 槽含现金分红），不挂分钟域。行情侧是每张视图都带的核心原始表：`daily` 文件按 (`trade_date`, `ts_code`) 合并了 `daily`、`daily_basic` 与 `stk_limit`，另有 `adj_factor`、`suspend_d`、`namechange`。**本臂只读 `daily`、`macro.index_weight` 与 `universe` 三处。** 挂着而本臂不读的三张：

- `index_daily`（宿主的基准腿用它）：会话若为别的目的读它，**必须按 `ts_code` 过滤**——这张表的 `index_code` 整列为空，按 `index_code` 读安静地返回 0 行，不过滤则七只指数的日线混在一起。
- `sw_daily`：2021-12-13 之前的行是按 SW2021 口径回算的，行业归属带后视；不要拿它做分数或行业口径。
- `index_dailybasic`：指数的估值与换手，本臂不读；它同样按 `ts_code` 过滤。

**本臂不能用财报**：基本面域没挂，所以「盈利 ÷ 市值」只能读供应商在 `daily_basic` 里逐日给的比率，不能自己从利润表算。下文「`daily_basic` 的列是不是按时点的」一节就是为此写的。

## 日线 `daily`

| 列 | 含义 | 单位（快照里） |
|---|---|---|
| `close` | 当日收盘 | 元 / 股，**未复权** |
| `pe_ttm` | 供应商的滚动市盈率：总市值 ÷ 近四个季度归母净利润；**滚动亏损时为空**（从不 ≤ 0） | 倍 |
| `pe` | 静态市盈率：总市值 ÷ 最近一个会计年度的净利润；亏损时为空 | 倍 |
| `dv_ttm` | 滚动股息率：近 12 个月除权的每股现金分红 ÷ 收盘；近 12 个月没有现金分红时为空 | **小数**（0.05 = 5 %） |
| `dv_ratio` | 股息率：上一个自然年里除权的每股现金分红 ÷ 收盘，每年第一个交易日换基数 | **小数** |
| `turnover_rate` | 当日换手率 = 成交量 ÷ 流通股本 | **小数** |
| `total_mv` | 总市值；这一行带不带它就是这一行有没有 `daily_basic` | 元 |
| `high` / `low` / `pre_close` | 当日最高 / 最低 / 交易所给的昨收（只有 `range20` 诊断读） | 元 / 股 |
| `up_limit` / `down_limit` | 当日涨跌停价 | 元 / 股 |
| `adj_factor` | 累计复权因子（离线门算收益要用，起步包不用） | — |
| `is_suspended` | **只标盘中临停**；整天停牌的名字当天在 `daily` 里没有行 | — |

- **可见性**：`daily` 没有 `available_at` 列；`daily` 行按 17:30、`daily_basic` 列按 18:00 盖章，as-of 视图里只有决策时可见的行，所以 08:30 决策读到的最新一行是 **T-1**。离线重建里「日期 t 的分数」就是 t 之后那个交易日的决策读到的分数，`/mnt/tools/screen.py` 从 t+1 的开盘算前向收益，正好对上。
- **单位**：快照已把百分数列（`dv_ttm`、`dv_ratio`、`turnover_rate`）换成小数、把市值换成元；`unit_reference.json` 是准。比率是无量纲的，本臂的分数只用它们的秩，单位换算不影响排序，但写阈值时要按小数写。

## `daily_basic` 的列是不是按时点的（包作者在八年种子上核对过，`refs/sources.md`）

供应商逐日给这些比率，本仓库在 2026 年整段回填，所以要问的是：历史上某一天的值，是不是只用了那一天已经公布的东西。核对的办法是看比率里隐含的量什么时候变（不读任何收益），结论如下：

| 列 | 本臂怎么用 | 核对 | 结论 |
|---|---|---|---|
| `turnover_rate` | `abturn` / `ch3` | 与 `vol ÷ float_share` 逐行相等（中位比 1.00000，全部落在 ±1 % 内，1–99 分位在 ±0.03 % 内） | 当天自己的成交量与股本，**按时点** |
| `pe_ttm` | `ep` / `ch3` | 隐含的滚动盈利 `total_mv ÷ pe_ttm` 的 33,642 次变动里 98.5 % 落在一份定期报告或业绩快报公告的那个交易日，99.2 % 在公告后 5 个交易日内，只有 0.1 % 在公告之前 5 天内而离上一份公告又超过 5 天（噪声量级）；年报之后那一段窗口里，隐含盈利与首次公布的年报数对得上，38 个后来被更正超过 1 % 的年报里 23 个对首版、2 个对更正版；年报亏损的窗口里 95.4 % 的日子 `pe_ttm` 为空，盈利的窗口里 1.5 % | **按时点**：随公告更新，用的是当时公布的版本，不是后来的更正；空值就是滚动亏损 |
| `dv_ttm` | `dvy` | 隐含的滚动分红 `dv_ttm × total_mv` 的 8,588 次上升里 93.9 % 落在一次现金分红的除权日，其余 89 % 与股本变动同日 | **按时点**：分红在除权日进入，除权日晚于实施公告 |
| `pe` | 邻居（`ep` / `ch3`） | 9,598 次变动里 97.9 % 落在公告日 | **按时点** |
| `dv_ratio` | `dvy` 的补位与邻居 | 上升几乎全在每年第一个交易日（5,210 / 5,499），换成上一个自然年里已经除权的分红 | **按时点**（只用已经付过的分红），但一年只换一次、最陈旧可达近 18 个月 |

两条诚实的限定：一是供应商的计算细节（归母还是含少数股东、是否扣非）文档没写，核对只证明了**时点**，没有证明口径与论文一致（论文用扣非净利润，`refs/references/literature.md`）；二是公告日那一行可能包含当晚才公布的报告，而本仓库按 18:00 盖章——对 08:30 的次日决策这无所谓（报告此时已公开），但不能拿它做同日盘中的决策。

## 2017 年这一段数据的特点（八年种子上实测，`refs/sources.md`）

- **长期停牌多**：Y1 每个复核日平均有 14.7 只成分在 T-1 没有日线（Y2 5.2，Y3 起不到 3 只）。它们不进池；已持有的一只停牌后若离开池，09:30 的卖单以 `missing_execution_price` 被拒，书里多出第 51 个名字，下一个复核日再卖；还可能连带一笔买单因预算把没卖出的钱算了进去而 `insufficient_cash`——照实报，不是缺陷。
- **Y1 的行业标签有一截是空的**：Y1 回放槽的 `universe` 锚在 2017-06-30，正好是申万 2014 版那一次重分类的边界（旧行 `out_date` 20170630、新行 `in_date` 20170703），这一天两边都对不上，Y1 全年约 4–5 % 的成分落在 `未分类`（本池池内最多 12 只）；`未分类` 在行业上限与 `top_industry_weight` 里都算一个行业。Y5 回放槽（锚 2021-06-30，还用冻结的 2014 版表）缺 2019–2021 年新上市的名字，多数是科创板，池里影响最多 2 只。
- **没有别的缺口**：96 个复核日里本池没有一只成分的 T-1 行缺 `daily_basic`（`total_mv`），没有一只 T-1 有日线的成分缺涨跌停价（中证 1000 里那只 2017–2019 缺涨跌停价的名字不在本池），每张截面恰为 300 只。

## 成分截面 `macro.index_weight`

```text
sec = pd.read_parquet(
    context.asof_dir + "/macro",
    columns=["dataset", "available_at", "index_code", "con_code", "trade_date", "weight"],
    filters=[("dataset", "=", "index_weight"), ("index_code", "=", "000300.SH"),
             ("trade_date", ">=", start)],
)
```

| 事项 | 规则 |
|---|---|
| 指数键 | `index_weight` 的指数在 `index_code`、成分在 `con_code`，`ts_code` 为空。**`index_daily` 正相反**：指数在 `ts_code`、`index_code` 整列为空 |
| 成分的代码列 | `con_code`，跨域 join 要自己改名 |
| 可见性 | 行级 `available_at`，`contract_1730_from:trade_date`——按自己那个交易日 17:30 盖章，08:30 决策看不到当天那张 |
| 频率 | 每指数每月一张，日期是当月最后一个交易日，2016-07 起在 `/mnt/snapshot` 里逐月不缺；每张恒为 300 只 |
| `weight` | 百分数，一张截面求和 100 ± 0.05；本包只用成员资格，权重只用来报书覆盖了多少指数 |
| 基准 | 裁决的中性化、β、跟踪误差与零技能面板的成员侧都对 `benchmark_index` 做；用别的指数建书而仍按它报是 `refs/families.md` 的点名禁止 |

**只有月末截面**：两张之间的真实调整看不见，复核日拿到的是上一张的名单（`refs/references/index-membership.md`）。**每一个决策日都按那一天可见的最新截面判定成分**；离线重建也一样，不能用最新一张去标注历史。

## `universe`

`name`（ST / 退 过滤）与 `l1_name`（申万一级，行业上限与 P2）。回放里它是回放槽锚点那一天的表：名称按 `namechange` 取锚点那天生效的名称，行业在 2021-12-13 之前取申万 2014 版（Y1–Y5 回放槽，28 个一级），之后取 2021 版（Y6–Y8，31 个一级）——跨研究年比较行业名单是错的；为空的名字落在 `未分类`（也算一个行业）。宿主的 `top_industry_weight` 按时间加权读，P2 要逐次读。

## 本轮要读的列

| 域 | 列 | 单位 | 行级 `available_at` | 用途 |
|---|---|---|---|---|
| `daily` | `ts_code`、`trade_date`、`close`、`total_mv`、`dv_ttm`、`dv_ratio`（起步包还读 `high` / `low` / `pre_close` 与邻居的列，都只在别的 `SCORE` 或邻居里用） | 见上表 | 无列，最新一行 = T-1 | 分数、池、买单定价、持仓估值 |
| `macro.index_weight` | `con_code`、`trade_date`、`weight` | 百分数 | 有，17:30 | 成员资格、覆盖度报告 |
| `universe` | `name` / `l1_name` | — | 无列，按回放槽锚点口径 | ST / 退过滤、行业上限、P2 |

## 读法与可见性（通则）

- `asof_dir` 下每个域是 parquet parts 目录（传目录名，不加 `.parquet`），`snapshot_dir` 下是平铺文件；读失败**不得**回退 `snapshot_dir`。
- 带行级 `available_at` 的域判可见只看它（`pd.to_datetime(..., utc=True)` 后与 `context.inference_at` 比），不从 `trade_date` 推；`daily` 与 `universe` 没有 `available_at` 列，按不存在的列过滤会报错。
- 起步包每次读取都带 `columns=`、`filters=` 与日期窗口，不引入跨调用缓存，冷 worker 与热 worker 出单一致。

## `snapshot` 只有一个时点口径

`/mnt/snapshot` 是研究期末那一天的决策视图：`universe.parquet` 里的名称、ST 状态、`l1_name` 都是 2025-06-30 的，行业是申万 2021 版。离线重建 2017–2021 的决策时，名称与行业会被灌回过去——所以离线门不按名称过滤 ST（研究期末的 ST 名单与 2017 年的无关），行业读数只作相对参考；宿主回放用的是逐年锚点的表，两边在 Y1–Y5 的行业口径不同。日线里的 `daily_basic` 各列是逐日的，不受这一条影响。

## 陷阱

- **成分的代码列是 `con_code`**；**`index_daily` 按 `ts_code` 过滤**，它的 `index_code` 为空。
- **用最新一张截面标注历史决策日**：八年里沪深 300 在册过 568 个名字，漏掉的历史成分多半是跌出去的（或升进了上一级指数）。
- **把 `dv_ttm` 为空当成不分红**：它也可能是一年一次的派息人在两次除权日之间的断档（普查平均 10.9 只、最多 40 只），登记的规则按 (`dv_ttm`, `dv_ratio`) 取第一个正值；只看 `dv_ttm` 会在除权前几周卖掉银行。
- **`dv_ratio` 一年只换一次**（每年第一个交易日换成上一个自然年的分红）：停止分红的公司当年还带着旧的股息率——陈旧而不是前视。
- **按百分数写阈值**：快照里是小数（0.05 = 5 %）；本臂只用秩。
- **一手与整手**：100 万元 50 席上一手买不起的成分逐年 0.4–5.6 %（沪深 300 成分贵）；买不起只影响买入，**已持有的名字不得因此强卖**；买单按最近整手四舍五入再按现金截断。
- **印花税在研究期内切换**（卖出 10 bp → 5 bp，2023-08-28）。
- **复核节奏不得依赖模块级计数器或跨调用缓存**：到期判断拿最新可见交易日与决策日比自然月；`c_shuf` 的打乱只用决策日做种子。
