## 本臂的形状：沪深 300 的滚动股息率，2021–2025 的红利行情是挑选风险

**来历。** 股息率在本仓库只以沪深 300 / 10 万 / 12 席的「可见现金分红率」开局出现过（`cashdiv_pool_100k_20260921d`，`no_deliverable`），从没有在 100 万 / 50 席等额、也从没有在 2017–2021 这四年上跑过。两半的地位：**Y1–Y4 是检验**；Y5–Y8 带着运营者对 2021–2025 红利与国企行情的知识。

**补位规则是登记的一部分，写在读数之前。** 供应商的 `dv_ttm` 只数近 12 个月除权的分红：一年一次的派息人今年的除权日只要比去年晚几周，这几周里 `dv_ttm` 就是空的。只用 `dv_ttm`，按排名模拟的书八年 183 次卖出里有 79 次卖的是这种「断档」的派息人（多半是银行，恰在除权前几周卖掉、再买回来）；按 (`dv_ttm`, `dv_ratio`) 的次序取第一个正值，183 次变成 107 次、断档卖出只剩 1 次（不读收益的普查，`refs/sources.md`）。代价是一家停止分红的公司在当年剩下的月份里还带着上一年的股息率——陈旧，但只用已经付过的分红，不是前视。

**trial 账怎么记，写死在这里。** `dvy` 是本臂**唯一一个登记的配置**，登记写于任何一次读前向收益之前；包作者对它的离线读数是对提交配置的读数，提交之后按宿主 trial 计，不按离线申报。所以第一批申报 **`offline_trials` = 0**，除非会话自己再筛了别的变体（每个加 1）。只用 `dv_ttm` 的定义没有被筛过（补位规则是按不读收益的普查定的），不申报；本轮另外三个包（`ep`、`abturn`、`ch3`）是各自独立登记的臂，不在本池上。于是第一批 M = 1、N_eff = 1，八年的 DSR 门槛是主动 IR 0.695，起作用的是运行事实的下限 0.75；第二批加入邻居 `dvy_ratio` 后 M = 2、N_eff = ρ̄ + (1 − ρ̄)·2，两条腿高度相关（ρ̄ ≥ 0.8）时门槛仍是 0.695。还有一层没有任何一条臂计数的挑选：本轮的四个价值 / 换手分数是在知道登记册里那些四年关闭（下表）之后才选的，包作者又是读过四个分数的离线读数之后才交给运营者排队的（读数见 `refs/sources.md`，它们没有改变任何登记）——这一层写在这里，不进 DSR。

## 分数与书（起步包的唯一定义在 `refs/starter/lib/`）

书与本轮 `range20` 八年包逐字相同，只换了分数。

| 组件 | 定义 |
|---|---|
| `dvy` | T-1 那一行 (`dv_ttm`, `dv_ratio`) 里第一个正值：近 12 个月的现金股息率，滚动窗断档时取上一个自然年的；两者都不为正 = 没有现金分红 ⇒ **排最后**（−inf），仍在池里；T-1 行没有 `daily_basic` ⇒ 不可打分、出池（研究期里本池一次都没发生） |
| 排名 | 分数从高到低；并列（全部不分红的名字）按代码的固定散列破 |
| 池 | 决策日可见的最新一张 `knobs.INDEX` 截面的成分（沪深 300，每张 300 只），去掉科创板（688 / 689）、北交所、名称含 ST / 退（回放槽锚点那一天的名称）、T-1 无日线、分数无定义的名字 |
| 书 | **每个自然月首个决策日复核**（空仓时任何决策日都复核）；**50 席等额现金**；持仓排名 ≥ `SEATS × KEEP_BAND`（100 名）就卖；离开池（出截面、丢日线、分数无定义、变 ST）无条件卖；**不设换名上限**；每个申万一级最多 floor(0.28 × 50) = **14** 只（持仓与买入合计，重分类造成的超额在复核日按排名从差到好卖掉）；只买一手（100 股 × T-1 收盘）不超过一个座位的名字，已持有的不因买不起被卖 |
| 补座位 | 两次复核之间，只要持仓少于 50 只（买单被涨停、缺价或现金不足拒掉），之后每个决策日按当天的排名从上往下补买，受同样的行业上限与可负担性约束；不卖、不重排 |
| 成交 | 卖出 09:30、买入 15:00；座位 = 账面价值 ÷ 50（账面价值 = (现金 + 0.98 × 卖出所得) × 0.97 + 保留持仓按 T-1 收盘）；按 T-1 收盘**四舍五入到最近整手**再按剩余现金截断 |
| 基准与账户 | `knobs.INDEX` = `000300.SH`、`knobs.CAPITAL` = 1,000,000、`knobs.SCORE` = `"dvy"`：第 0 轮先读运行事实 `benchmark_index` 与 `broker_replay.initial_cash`，不符时改常量去对齐它们，反过来不行 |

**ST 过滤的数据源在本臂的选择里。** 起步包按 `universe.name` 过滤 ST / 退；这一列不是宏观或事件数据集，是快照按 `namechange` 取的「决策日生效的名称」，`namechange` 是每张视图都带的核心原始表，与本臂只挂四张宏观表的选择无关。回放槽用它自己锚点那天的 `universe`，所以一只年内才变 ST 的名字要到下一个研究年才被滤掉——已知限制。

**本池上的分量**（不读收益的普查，`refs/sources.md`）：可交易成分逐年平均 281–300 只，全部可打分；有正股息率的份额逐年 0.93–0.97（排最后的不分红名字逐年平均 10–19 只）；`dv_ttm` 断档而由 `dv_ratio` 补位的平均 10.9 只（最多 40）；相邻两次复核分数的秩相关 0.97–0.98（很慢）；未设上限时顶端 50 只的最大申万一级占比逐年平均 0.20–0.39，96 次复核里 **62 次超过 0.28，全是银行**，按排名模拟的书第一大行业按只数Y3 起一直顶在 0.28（14 只）；与低波动的秩相关逐年 +0.40…+0.56，与市值 +0.01…+0.34。

**冻结门在这张预期面前的位置，事先算清**（T = 1941 个交易日，√V = √(244 / T) = 0.3546）：零技能的第 90 百分位 1.2816 × 0.3546 = **0.4544**；第一批 M = 1、N_eff = 1 时 DSR 门槛 0.695，运行事实的主动 IR 下限 **0.75** 更高，起作用的是它；第二批加邻居后两条腿相关 ρ̄ ≥ 0.8 时 N_eff ≤ 1.2，门槛仍是 0.695。按登记的八年预期 0.2–0.7，`dvy` 越过 0.75 的可能性不大；本臂的信息价值首先在 Y1–Y4 的符号：它为正，才说明 2021–2025 的红利读数不全是那段行情。

## 离线门 G-V8（整期批次之前必须重算，全离线，0 回放年；筛过的候选配置各计一个 trial）

登记的判据，一次写死：S1 覆盖不足，或 S2 秩 IC ≤ 0 / 不显著，或 S3 顶端对同池不挣，或 S4 规模中性 IC ≤ 0，或 S5 登记构造的书输给零技能面板，⇒ 命中。**命中不改变第一批**：以 `no_edge` 收尾本来就要本会话至少一次完整期验证，所以不论命中与否，唯一一批都花在登记的 `dvy` 本身上；命中是登记好的预测，宿主读数要对着它读。判据与 `range20` 八年包的五条同一口径，只把「可打分」换成本分数的规则。

- control：`c_shuf` 永远写 control: true——照常花回放年、计入完整研究期验证数，但不是 trial，也永远不能提名；`dvy`、`dvy_ratio` 与任何变体写 control: false。把候选登记成对照，它就失去提名资格；把对照登记成候选，是白给自己加一个 trial。
- offline_trials = 本批申报前离线筛过、读数影响了本批提交什么、但本批没有提交的候选配置数；提交进本批的候选在宿主验证时按 host trial 计，不重复申报。

冻结门的试验数 M 是本臂验证过的非对照 revision 加上各批申报的 offline_trials，按 ρ̄ 折成有效试验数 N_eff = ρ̄ + (1 − ρ̄)·M；公式与阈值以运行事实 acceptance_rules.freeze_gate 为准（本轮默认 min_dsr_probability 0.975）。

| 判据 | 怎么算（`refs/references/offline-screen.md`） | 命中 |
|---|---|---|
| **S1 覆盖** | 研究期 96 个复核日，池里可打分的只数与占可交易成分的份额 | 任一复核日 < 100 只，或任一研究年份额的均值 < 0.90 |
| **S2 秩 IC** | `/mnt/tools/screen.py` 在 `/mnt/snapshot` 上，`--start 20170701 --end 20250630 --horizons 5,10,20,40 --top-fraction 0.1725`（50 ÷ 每日可打分池的均值），h = 20 | `ic_mean` ≤ 0 或 `t_stat` < 2.0 |
| **S3 顶端** | 同一命令逐研究年各跑一次，h = 20 的 `top_excess_mean`（顶端对**当日被打分的池**的等权） | 八个研究年里有 4 个或更多 ≤ 0 |
| **S4 规模** | S2 那一次的 h = 20 `ic_size_neutral` | ≤ 0 |
| **S5 书** | 登记的构造（保留带、行业上限按保留名字计、按账面价值定座位、可负担性、强卖、ST 过滤、补座位、持仓随价格漂移）逐日重放，减同骨架的换名面板，再对基准与规模中性化 | 八年中性化主动 ≤ 0，或为正的研究年少于 4 个 |
| 诊断（只报不判） | 上面每一项都按两半（Y1–Y4 / Y5–Y8）分开报；h = 5 / 10 / 40 的 IC；十分位剖面；书的行业与创业板占比；不分红名字的份额与补位名字的份额 | — |

**这道门只能否决，永远不能证明边际**：离线读数只有秩与方向可信；书级的离线读数只有跑的就是登记的构造、又用宿主的量尺时才可信，也只是一次有噪声的抽样（± 3.5–4 pp/年，登记册 §4）。

## 验证计划（先登记，再花回放年；本臂整期验证上限 3）

| 批次 | 腿（按顺序，`control`） | 完整期验证 / 其中 trial / 回放年 | `offline_trials` | 进入条件 |
|---|---|---|---|---|
| 第一批 | `c_shuf`（true）、`dvy`（false） | 2 / 1 / 16 | **0**；会话另筛而没提交的变体每个加 1 | 第 0 轮核对完、G-V8 已重算（命中与否都进） |
| 第二批（正常路径） | `dvy_ratio`（false） | 1 / 1 / 8 | 本批之前新筛而没提交的配置数 | `dvy` 没有命中 K4 的任何一条 |
| 收官 | 冻结，或 `no_edge` | 0 | — | 见下文 |

- 全臂最多 **24 个回放年**、3 条完整期验证、2 个 host trial；不拟合，没有 `fit` 的秒数要算。
- **规则分数是确定的，没有训练种子要复现**。仍然适用的两条噪声：同一本书只因面板重抽就差约 0.55 pp/年（IR 差 0.1 以内按面板噪声读），离线侧的噪声底约 4 pp/年。
- 第一批之后，对 `dvy` 的完整期节点跑一次 `run_null_control`：不花回放年，**是诊断不是判据**。

## 允许的变体轴

只有一格登记：**`dvy_ratio`（`DV_COLUMNS = ("dv_ratio",)`：只用上一个自然年的股息率）**，只在正常路径上进场。只用 `dv_ttm`（不补位）不是登记的变体：它的问题是在普查里量出来的，会话若要筛它，照常计一个 trial。会话若要筛任何别的变体（换输入列、换窗口、改席数或保留带、行业内排序、只在某一半上用），**每筛一个都计一个 trial**，在它筛过之后第一个记下验证的批次申报 `offline_trials`；改提交它就是一次新登记，重写 `hypothesis`，`dvy` 按筛过而没提交再加 1。

**禁止**：用研究期之后的任何信息；在分数里加入任何别的数据集的列（本臂只挂四张宏观表，基本面、事件与文本本来也读不到）；把 `SCORE` 换成别的分数（包括 `range20`，它在起步包里只是标明了的诊断）；非等额权重；把 `c_shuf` 改作候选或把候选登记成对照；把任何东西放进 `models/`；用最新一张成分截面去标注历史决策日；用别的指数建书而仍按 `benchmark_index` 评；为了追读数改保留带、行业上限或复核节奏而不申报；按年份或行情条件开关这个分数（那是一次对 Y1–Y4 读数的拟合）。

## 提名条件（冻结前逐条满足）

1. G-V8 已重算，五个判据量（分两半）与诊断读数写进结果笔记。
2. 完整研究期验证完成，冻结门按运行事实通过（主动 IR ≥ 0.75、DSR ≥ 0.975、≥ 6 / 8 年正、`max_drawdown` 与 `active_max_drawdown`）；完整期验证数达到运行事实 `min_full_span_validations`（对照也计入）。
3. `dvy` 没有命中 K4 的任何一条，而且第二批的 `dvy_ratio` 与它同号；两条都过冻结门时提名 `dvy`（登记在先），只有一条过门就提名那一条。
4. P2 / P3 / P4 / P5 全部成立；`pnl_concentration.top5_share_of_gross_gains` ≤ 0.5。
5. **实现底线**：单次复核决策 < 60 秒、容器内存峰值明显低于 16 GiB；意图买单拒单率 ≤ 30 %；座位填满率、买不起份额与分数覆盖率（买单元数据的 `score_coverage`）逐次汇报。不成立先修实现再复测，不算证伪。

## 什么会杀死它（命中即停）

第一批（`c_shuf` + `dvy`）之后，任一条命中 ⇒ 以 `no_edge` 结束，不开第二批、不换轴：

1. **K4a 检验的一半不为正**：Y1–Y4 四个 `sub_windows[].active_neutralized_excess_return` 的均值 ≤ 0。
2. **K4b 整期低于零技能线**：`dvy` 整期主动 IR < 1.2816 × √(244 / T)，T 是完整研究期的交易日数（八年 1941 天，**0.4544**）。
3. **K4c 正年不够**：主动超额为正的研究年少于 **6 / 8**（冻结门自己的条数）。
4. **K4d 主动回撤**：主动回撤 > 0.30（冻结门自己的上限）。

之后：

5. **`dvy_ratio` 与 `dvy` 符号相反**（邻居整期主动中性化超额 ≤ 0）⇒ 不提名，以 `no_edge` 结束；同号而低一些只是一条读数，照实报告，不否决。
6. P2 在已登记构造下不成立（`top_industry_weight` > 0.30）⇒ 关闭并写明是哪个行业。
7. `excess_at_2x_slippage` ≤ 0，或实测每月完成回合 < 1 ⇒ 这个形状不可交付，以「不可交易」关闭。
8. 整期验证上限（3 条，对照也算）用尽而没有满足全部提名条件的候选 ⇒ `no_edge`，不为了凑提名再开一批。

**臂级终止**：任一条命中即关闭，以 `finish_session(outcome="no_edge")` 携读数结束本臂，**不换家族**，不把 `c_shuf` 改作候选。`no_edge` 要带上 G-V8 的五个量（分两半）、`dvy` 与 `c_shuf` 的主动 IR / DSR / 两半的均值与逐年符号、板块与行业占比，以及对登记册相关行（上表）的交代。
