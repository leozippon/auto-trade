# 股息率规则分数参考包·沪深 300 / 八年研究期（dvy_csi300_8y，20260927）

本目录是只读 refs（会话里挂在 `refs/`）。本包登记的是**一个不训练的规则分数，在八个研究年上量一次**：`dvy`——每只股票 T-1 那一行供应商给的滚动股息率 `dv_ttm`（近 12 个月除权的现金分红 ÷ 收盘，越高排得越前；一年一次的派息人在两次除权日之间滚动窗断档、`dv_ttm` 为空时，取上一个自然年的股息率 `dv_ratio`；两者都没有就是不分红，排最后）——在**决策日在册的沪深 300 成分**里建一本 50 席、等额现金、月度复核的书，由宿主的零技能面板裁决。研究期是 2017-07..2025-06 的八个研究年 Y1..Y8；宿主的基准、面板的换名侧与中性化基准腿都键在 `000300.SH` 上。起步包与本轮另外三个价值 / 换手八年包（`ep_csi500_8y_20260927`、`abturn_csi500_8y_20260927`、`ch3_csi500_8y_20260927`）逐字相同，只差 `lib/knobs.py` 的两行：`INDEX = "000300.SH"` 与 `SCORE = "dvy"`。

## 为什么是这个分数、这个池、这八年

**股息率是价值的另一种量法，在沪深 300 上首先是一次低波动 / 大盘 / 银行的倾斜。** 本仓库没有测 A 股股息率的论文，先验只到机制（`refs/references/literature.md`）；普查量出它与低波动的秩相关 +0.40…+0.56，顶端 50 只里银行在 96 次复核中 62 次超过 0.28，每个申万一级至多 14 只的上限几乎一直顶着。

**挑选风险写在最前面。** 2021–2025 是高股息与国企标的的强势段，运营者选这条臂时知道这段行情；本仓库自己的红利读数只有沪深 300 / 10 万的「可见现金分红率」开局（`cashdiv_pool_100k_20260921d`，`no_deliverable`）与「分红与除权后漂移」（DIR4，读零），毕业过的唯一一条谱系是 Alpha158 + LightGBM（登记册 §3），与红利无关。所以 **Y5–Y8 的读数不是检验，Y1–Y4（2017-07..2021-06）才是**——那一半里有 2019-07..2020-06 成长股的单边行情，正是低波动与红利最难受的一年。八年给的是这一半，外加把门槛从四年的约 0.98 降到 0.75 的 T。

**八年研究期与门槛。** 研究期拉长到 2017-07..2025-06 之后，Y1–Y4（2017-07..2021-06）是本仓库**任何一条臂都没跑过**的四年：登记册里所有价值、红利与换手的读数都落在 2021-07..2025-06（本臂的 Y5–Y8），运营者选这条臂时知道那几条四年关闭，也知道 2021–2025 的行情——这是本臂的挑选风险，所以 **Y1–Y4 是检验的那一半**。冻结门在八年上的算术：√V = √(244 / 1941) = 0.355，有效试验数 1 时 DSR 门槛是主动 IR **0.695**，所以起作用的是运行事实里的主动 IR 下限 **0.75**；正年门是 ceil(0.75 × 8) = **6 / 8**。

**要检验的只有一件事**：`dvy`（这个分数）在八年的主动序列上能不能越过零技能，而且前四年这一半本身为正。`c_shuf`（同一分数在同一决策日内打乱）是同批的一次零技能抽样。

## 你被评的是主动序列

宿主每次正式验证后按候选自己的成交骨架随机换名重放若干份，取等权均值作为零技能面板，全部统计量都在「候选减面板」的主动序列上算，再对基准与规模价差做两因子中性化（`refs/references/zero-skill-panel.md`）。本臂最该记住的四条：

- **绝对超额说明不了事**：沪深 300 在研究期最大回撤 −45.6 %、八年 +7.3 %，逐年 −4.2 / +9.0 / +8.8 / +25.5 / −14.1 / −14.3 / −9.9 / +13.7 %。
- **中性化会改写逐年的形状**：冒烟里这本书的 β 0.86–0.89（70 天，只作量级），未中性化的主动收益在单边大涨或大跌的年份里有一截是 β 差与银行；登记与裁决都读中性化之后的主动读数。
- **面板对齐股票池、日历、每笔的钱与成本，不对齐权重方案**：本臂每条腿都是等额现金。
- **面板会抽到本书剔掉的科创板**（Y4 起才有）：八年 +0.09 %/年，单年 ±2 pp 以内。

## 本臂的执行边界

执行合同以只读 `output/README.md` 为准，本包不复述。本包只在以下几点更具体：

- **不训练**：没有 `fit`、没有 `REFIT_PERIOD`；规则分数是确定的，**没有训练种子这一层方差**，剩下面板重抽（同一本书约 0.55 pp/年）与离线侧约 4 pp/年 的噪声底（登记册 §4）。
- **`gpu_count = 0`，纯 CPU**；策略容器 8 核 / 16 GiB。
- **三个常量由会话对齐**：`knobs.INDEX` 对 `benchmark_index`（必须是 `000300.SH`），`knobs.CAPITAL` 对 `broker_replay.initial_cash`（1,000,000），`knobs.SCORE` 必须是 `dvy`。空仓时账户现金不在 `CAPITAL` 的一半到两倍之间，起步包直接报错。**批次里不许有别的指数或别的分数的腿**：一条臂只有一个 `benchmark_index`、一个登记的分数；`SCORE = "range20"` 只是标明了的诊断，永远不是腿。
- **截面缺失、日线窗为空、可打分成分不足两倍席数，起步包直接报错**，不回退。
- 本臂的数据集选择只挂四张宏观表（`index_daily`、`index_dailybasic`、`sw_daily`、`index_weight`），没有基本面、事件与文本域；分数只读 `daily` 里供应商的 `daily_basic` 列（`dv_ttm`，断档时 `dv_ratio`；邻居只读 `dv_ratio`），加进任何别的列就是另一条臂。
- 不要把 `refs/` 里的文件拷进 `output/`。

## 账户与回撤

开工第一件事是读自己的运行事实：`broker_replay.initial_cash`、`benchmark_index`、`acceptance_rules`、`budgets` 与 `max_replay_years`、`research_geometry.years[].input_window`。

**回撤上限是创建参数，不是本包的规则**：本臂按 `max_drawdown` 0.50、`active_max_drawdown` 0.30 建臂，因为沪深 300 自己在这八年里回撤 −45.6 %，默认的 0.45 离它太近或低于它。冻结之后的裁决规则只由运行事实 `acceptance_rules.graduation` 给出，本包不复述；会话在研究期里要量的只有其中能在研究期量的几项（成本压力、每月完成回合、平均总仓位，`refs/families.md` 的 P3）。

## 「没有边际」的读法

没有候选证明边际时，按 `refs/families.md` 的终止规则以 `no_edge` 携读数结束。**「沪深 300 的股息率在它没被挑过的 2017–2021 上与零技能分不开」本身就是登记册要的一行**：它回答 2021–2025 的红利读数是这个分数的，还是那段行情的。另一种收尾同样要照实写：两半都正、八年过了 K4 却没过 0.75，那是「有符号、缺量级」，不是边。
