# 指数内相对基准参考包（index_relative，20260919）

本目录是只读 refs：**把书建在基准里面**——股票池就是决策日当天的沪深 300 成分，按时点从宏观域读出来。这是一个**开放方向**的臂：成分股里哪一族信息带 alpha 没有人量过，本包不指定机制家族，只把已经量过的读数作为先验交给会话。它不是可提交策略，也不是预期收益。

任务是在研究期上找到一个只做多、在指数成分内选名、有经济解释并在组合尺度上成立的日频策略，它在信息比率上要**按预登记的裕度赢过同批的零技能对照**；找不到就诚实地以 `no_edge` 结束。判据只按 `families.md`。

按以下顺序读：

1. `families.md`：候选的三种形态、两个必跑对照、**提名硬门与已关闭家族表（关闭判据的唯一权威表述）**、方向性先验、臂级终止规则。
2. `pit-field-map.md`：逐表可见时点、单位、成分截面的读法与陷阱（唯一权威表述）。
3. `exploration-plan.md`：不占预算的普查、首轮批次、判定分支、后续轮次、预算。
4. `references/`：四份技术笔记——成分面的口径与月末截面的代价、跟踪误差的底与门落在哪里、整手与佣金在本账户上的算术、中性化口径与零技能对照。沙箱无网络，四份都是自写的，外部出处列在 `sources.md`。
5. `sources.md`：结构性读数与已关闭家族读数的出处、起步包的离线普查与沙箱冒烟实测、诚实的限制。
6. `starter/`：合同内的最小可运行包，**不是**推荐的机制。它通过 `validate_strategy_package`，并在沙箱镜像里以真实 as-of 布局跑通了「读成分 → 打分 → 成形 → 出单」（读数见 `sources.md`）；正式回放的第一步仍然是 `smoke_backtest`。`main.py` 的 `CANDIDATE` 常量在主候选与两个对照之间切换，三者只差这一行。**会话开始时 `output/` 就是这份代码**，`refs/starter/` 只是同一份的只读参考副本。

## 为什么把书建在基准里面

本仓库到目前为止每一本书都建在同一形状的股票池上（非北交所与科创板、1 元 < 收盘 ≤ 30 元、20 日均成交额 ≥ 3,000 万元），再去和沪深 300 加一条规模价差比。结构性复核把这件事量了出来：

- 从这个池里**随机抽 15 只、零技能**，对沪深 300 加规模中性化的残差跟踪误差就有 **15.3 %/年**；只数再多也降不下来（30 只 13.3、50 只 12.6、100 只 12.0、300 只 11.6），拟合 `TE² = a + b/N` 得到的共同底是 **11.3 %/年**。也就是说 15 只书的残差方差里约四分之三是「池与基准不是一回事」，与持有哪些名字无关。
- 于是 IR ≥ 0.95 在任何可行的只数上都要求 **12.7–14.6 %/年**的中性化超额，而本仓库量到过的非价量上限约 **8.5 %/年**。门不是太严，是这个形状的书够不着。
- 同一批随机书改从**沪深 300 真实成分**里抽，同一口径读 **8.94 / 6.91 / 5.82 / 4.76 %**（15 / 30 / 50 / 100 只，β 1.01），IR 0.95 因此只要 **8.5 / 6.6 / 5.5 / 4.5 %/年**——门第一次落进已经量到过的 alpha 区间。

**能动这条底的参数只有一个：书建在什么里面、又拿什么去量它。** 换中性化的基准常数也能把跟踪误差压到 11.9 %，但同一批零技能书的 alpha 会从 −3.5 %/年 变成 +1.9——那是给每本书白送约 5 pp/年，是变相松门，已被否决。合法的那一版就是本包：**不动基准，动股票池**。

**代价与必须一起记住的那句话：等权持有沪深 300 成分这件事本身，零技能就值 +2.5 %/年、IR 0.29（15 只）到 0.57（100 只）。** 所以本臂的每一条主张都要对着**零技能对照**量，不是对着零量。这就是 `families.md` 里两个对照是硬门的理由。

## 这是一个开放方向，本包不指定机制

**成分股里哪一族信息带 alpha，本仓库没有量过。** 已关闭家族表里的每一行都是在旧的全市场池上关的，它们说明的是「那一族在那个池里不成形」，不等于在指数成分里也不成形：成分股的覆盖度、报表质量、分析师覆盖、流动性与那个池完全不同，中位流通市值 700–800 亿元，最薄的成分一天也有 0.53–0.83 亿元成交额。所以已关闭表在本包里的身份是**先验，不是禁令**——除了点名禁止的两条（见 `families.md`），任何一族都可以重开，条件是在跑完整研究期批次之前把假设、机制与证伪条件写进 `hypothesis`，并说明它在成分股里与在旧池里有什么不同。

日频量价截面排序器在本臂里**是允许的一族**，与别的族同等对待。它在别的开放包里被关掉，关的是「本轮另有专臂在跑同一条线、不要重复」，不是「这一族在指数成分里不成立」；本轮没有这样一条专臂。

起步包 `s_idx` 的四腿秩复合（现金流盈利质量 / 60 日残差低波 / 20 日反转 / 价值，等权、对规模中性）只是一个能跑的基线。**它作为一个方向已经在旧池里被关闭过**（共享基线 +6.75 %/年、3/4 年正、DD 29.2 %、IR 0.50），本包保留它只是为了让第一天就有一本真书可以读；离线普查已经量出它在成分股里会把 9/15 个座位压进银行一个行业（读数见 `sources.md`），**按门 5 它当场不可提名**。换掉它不需要理由。

## 两个必跑对照

每一轮、每一个候选，都必须同批、同跨度跑这两条腿，两条都不得被提名：

- **`c_rand`——与候选**同样只数**的等权随机成分书，固定种子。** 零技能基线。候选在信息比率上赢不过它、或赢的幅度小于预登记的裕度，就没有技能可言。
- **`c_index`——同一份抽签在本账户**能装下的最大只数**上的等权成分书。** 它量的是「等权持有这个指数在这个账户上值多少」，把「候选选得好」与「名字多就是好」分开。

两条对照用同一个固定种子的**按代码永久抽签**，所以 `c_rand` 恰好是 `c_index` 排队的前若干名，只数效应被干净地分离出来；抽签只在指数调整时才换名字。诚实的限制写在 `sources.md`：`c_index` 是指数的一个**样本**，不是指数本身，在这个座位数上它与「等权持有全部成分」之间有真实的抽样误差。

## 本臂的执行边界

执行合同——入口与订单、允许的 import、文件 I/O、`available_at` 与 PIT 读法、不写死宿主路径、沙箱无网络——以只读 `output/README.md` 与系统提示为准，本包不复述。本臂只在以下几点上更具体：

- **`gpu_count = 0`，纯 CPU**；任何训练都在容器 CPU 上完成，一次 `fit` 不超过 `budgets.strategy_fit_timeout_seconds`。
- 本臂不挂分钟域（运行事实 `execution_policy`），执行时点只有 09:30 与 15:00。
- **股票池必须是决策日当天可见的成分截面**，不得改成全市场池再事后筛，也不得把成分名单硬编码进代码。读法只在 `pit-field-map.md`。
- **科创板成分不在池内**：一手 200 股，在两个账户尺寸下都装不进一个座位。代价是每张截面少掉 1.7–4.8 pp 的指数权重，这个数每一轮都要报。
- 不要把 `refs/` 里的文件拷进 `output/`：整棵包是只读的，`cp` 会把权限一起带过去；会话开始时 `output/` 已经是 `starter/` 的内容。

## 账户与成本

研究期几何、预算、账户与费率、冻结门与毕业条件以运行事实为准，会话流程见系统提示，本包不复述；本臂以 `no_edge` 结束的条件见 `families.md` 的终止规则。**账户规模由本臂的运行事实 `broker_replay.initial_cash` 给定，篮子只数的可用区间由本臂的指令给定**——两条臂共用这一份包，读运行事实，不要照抄别人的数字。

本臂特有的一条账目必须先算清楚：**在指数成分里，一手常常比一个座位还贵。** 座位 = 权益 ÷ 只数，一手 = 100 股 × T-1 收盘。研究期五个年度锚点实测：10 万元账户 15 个座位（6,667 元/座）时 **11.0–22.9 %** 的成分买不起，30 个座位（3,333 元/座）时 **27.6–42.9 %** 买不起；100 万元账户 30 个座位时只有 **0.4–2.4 %**，50 个座位（20,000 元/座）时 **2.8–6.6 %**。5 元最低佣金在这四档上分别是 **7.5 / 15.0 / 1.5 / 2.5 bp 每边**（按 97 % 现金缓冲后的实际持仓是 7.7 / 15.5 / 1.5 / 2.6）。买单因此**按最近的整手四舍五入再按现金截断**，不向下取整；实际权重是每一轮都要汇报的读数，不是假设。

## 「没有边际」的读法

每个候选按 `families.md` 的提名硬门逐条读，不看整窗总收益；本文不复述判据。另外四点读法：

- **跟踪误差低不是成绩。** 把书建在指数里面本来就把跟踪误差从 15.3 % 降到 9 % 上下，这是机制**买来的**，不是候选挣来的。证据只有「对着零技能对照的信息比率增量」。
- **行业集中度这道门在本臂里会真的咬人。** 沪深 300 的单一申万一级行业按指数权重是 13–15 %（银行）、按名字数是 8–13 %，等权成分书舒舒服服在 0.30 以内；但便宜的那一端就是金融，而 10 万元账户的买得起筛子正是按价格切的。实测：起步包的四腿复合在 15 个座位上把 5–9 只压进同一个行业（0.20–0.60），50 个座位上仍有 0.14–0.34。**这道门要靠构造去满足，不要拿「指数本来就这样」去辩它**——指数本来不这样，是候选把它变成这样的。
- **门 7 的 `size_tilt` 界在这个池子上不可满足，这是已经量到的事实，不是候选的问题。** 成分按定义就是全市场最大的 300 只，等权持有它们读 0.906–0.929，冒烟九条腿（含两条零技能对照）读 0.893–0.954。门照写照读、只差这一条的候选仍不可提名，但**不得**仅因为它关闭本臂；细则与一个待裁的替代口径写在 `families.md`。
- **逐年读。** 研究期里指数有过一整年的大跌，也有过一次规模事件；只读整窗会把某一年撑起来的读数当成常态。
- **零技能对照也会有好年份。** 固定种子的一次抽签是一次抽样，不是一个分布。预登记的裕度就是为这件事设的，见 `families.md`。

没有候选证明边际时，不冻结是正当结果：按 `families.md` 的终止规则以 `no_edge` 携读数结束本臂。

## 本包的硬要求与留白

硬要求只有三条：**池是按时点读出来的指数成分**；**两个对照每一轮同批跑**；**每个完整研究期批次之前把假设与证伪条件写进 `hypothesis`**。除此之外，分数、筛子、构造、权重方案、复核节奏、只数（在指令给的区间内）全都是自由度。

同时把话说清楚：**`families.md` 的变体轴表是建议不是围栏。** 一个方向被证伪而预算还有余量时，换下一个预登记方向——先离线筛选，再一次完整研究期批次，不要就此收尾。证据没有关掉的事，本包不禁止。
