# 跟踪误差的底，和门落在哪里

自写笔记，把「为什么把书建在基准里面」这件事的算术写清楚。全部读数测在研究期 2021-07-01..2025-06-30 之内，口径见 `zero-skill-controls.md`。

## 恒等式

信息比率 = 中性化超额 ÷ 残差跟踪误差。抬分子和压分母是同一件事的两面，但它们的代价完全不同：分子要找新信息，分母只要换书的形状。

一本 N 只等权书的残差方差可以拆成两块：

```
TE²(N) = a + b / N
```

`a` 是与持有哪些名字无关的**共同成分**——池整体相对基准模型的那一段；`b/N` 是特异成分，靠分散化摊薄。这不是一个模型假设，是把随机抽样的书按只数排开之后实测出来的形状。

## 旧池的实测

从各包自己的股票池（非北交所与科创板、1 元 < 收盘 ≤ 30 元、20 日均成交额 ≥ 3,000 万元）里随机抽、季度换一批、零技能：

| N | 跟踪误差中位数 | IR 0.95 需要的中性化超额 |
|---|---|---|
| 15 | **15.34 %** | 14.57 %/年 |
| 20 | 14.26 | 13.55 |
| 30 | **13.33** | 12.66 |
| 50 | 12.59 | 11.96 |
| 100 | 11.99 | 11.39 |
| 300 | 11.55 | 10.98 |

拟合得 `TE² = 0.01273 + 0.1571 / N`，共同底 **`a` = 11.28 %/年**。15 只时特异部分只有 10.24 %，也就是说**四分之三的方差与选股无关**。

真实测过的十九本完整研究期的书读 12.3–15.7 %——**在同只数的随机书之下**（选股略微降波动），但离 11.3 % 的底还很远。而这些书的中性化超额是 7–12 %/年，所以 IR 卡在 0.5–0.9。**换排序器改变不了这个结论，因为分母不是排序器决定的。**

## 换池之后

同一套抽样、同一个口径，改从沪深 300 真实成分里抽等权：

| N | 跟踪误差 | IR 0.95 需要 |
|---|---|---|
| 15 | **8.94 %** | 8.5 %/年 |
| 30 | **6.91 %** | 6.6 |
| 50 | **5.82 %** | 5.5 |
| 100 | 4.76 | 4.5 |

β 1.01。门第一次落进本仓库实际量到过的 alpha 区间（非价量上限约 8.5 %/年，借来的日频量价分数读到过 9.6–13.6 %/年）。

**差别不在分散化，在共同成分。** 旧池是一个中小盘池，对沪深 300 加一条规模价差的两因子模型解释不了它；沪深 300 的成分本身就是那个基准，共同成分因此接近零。一个随机的中证 1000 成分书对沪深 300 读 TE 16.2 / 14.8 / 14.1 %（15 / 30 / 50 只），比旧池还高——**池越远离基准，底越高**。

## 一条不能走的捷径

把中性化的基准常数从沪深 300 换成中证 500 或中证 1000，同样能把 15 只书的跟踪误差压到 11.9 %。但同一批零技能书的 alpha 会从 **−3.5 %/年**（对沪深 300）变成 −1.6（中证 500）、**+1.9**（中证 1000）：换基准等于给每本书白送约 5 pp/年，同时缩小它的分母。那是把门调松了再说自己过了门，已被否决，而且基准常数是宿主的，不在会话的可达范围内。

**合法的那一版就是本臂：不动基准，把书建进基准里。** 代价写在 `zero-skill-controls.md`：等权持有基准成分这件事本身零技能就值 +2.5 %/年，所以本臂的每一条主张都要对着零技能对照量。

## 本臂的失败模式与旧池相反

旧池的每条臂都死在分母上。本臂把分母买下来了，问题因此回到分子：

- 可选名字从 2,400–3,500 掉到 280 上下（10 万元账户按买得起筛完只剩 164–252）。靠**广度**挣钱的信号在这里更薄。
- 沪深 300 是覆盖最密、做空工具最全、被动资金最多的那 300 个名字，是教科书意义上最难有 alpha 的地方。
- 剩下的余地在**深度**：极端估值、极端质量、事件、以及构造层（权重方案、节奏、筛子）。这些在成分池里一条都没有被量过。

这就是本臂是开放方向而不是固定方向的原因。
