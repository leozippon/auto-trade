# 裁决口径，和为什么要对着零技能对照量

自写笔记：流水线怎么算中性化超额与跟踪误差，`size_tilt` 与规模载荷为什么方向相反，以及本臂两条对照的意义与它们自己的误差。

## 裁决统计量

策略的日度收益对**两条腿**做 OLS：

```
r_t = α + β · r_CSI300,t + γ · r_size,t + ε_t
```

- `r_size` 是规模价差：全市场按**前一日**流通市值取最小 30 % 等权，减最大 30 % 等权。
- 中性化超额 = `α` 年化；残差跟踪误差 = `ε` 的标准差按 n−3 自由度、× √244 年化；信息比率 = 两者之比。
- 口径字符串写在每个结果的 `stats.benchmark.neutralized_excess_method` 里，会话可以自己读。

**它看不见行业、估值、换手。** 敞口预算（门 6、门 7）补的正是这块盲区，补不满。

## `size_tilt` 不是规模载荷

会话可读的 `stats.benchmark` 里有两个与规模有关的量，方向相反，不要混：

- **`size_tilt`** 是**持仓加权的截面市值秩位置**——这本书站在哪一档市值上。
- **`size_beta`** 是上面那个回归里的 `γ`——中性化真正除掉的那个载荷。

十九本完整研究期的书上 `size_beta ≈ 0.626 − 0.472 × size_tilt`，**r = −0.90**：站在小市值一端的书，规模载荷反而低。危机窗 26 个交易日里规模价差 −29.11 %，亏得最多的那本书 −12.50 % 中有 **−17.63 pp** 来自规模载荷，残差反而是 +5.61 pp，而它的 `size_tilt` 读 **−0.014**，正在对称预算的正中央。

所以门 7 的 `|size_tilt| ≤ 0.70` **不是回撤的防线**，收紧它只会赶走安全的一侧。`size_beta` 现在已经在会话可读的块里，本包要求把它与 `size_tilt` 一起报，但**不对它设门**——本仓库还没有量过它的合理界。

沪深 300 成分按定义就是全市场最大的那 300 只：研究期三个年度锚点上它们的全市场市值秩中位数 0.964 / 0.971 / 0.972，等权持有全部成分读 `size_tilt` **0.906 / 0.922 / 0.929**，沙箱冒烟的九条腿（含两条零技能对照）读 **0.893–0.954**。**所以 `|size_tilt| ≤ 0.70` 这道界在本臂里量的是股票池，不是候选**——它对候选与对照读同一个数。怎么处理写在 `families.md` 门 7 下面那一节，含一条待运营者裁定的替代口径；本包不擅自改门。

## 为什么对照是零技能书，不是零

在旧的中小盘池里，一本零技能的 15 只书对沪深 300 加规模中性化读 α **−2.9 %/年**：拿零当基线还算宽容。

在沪深 300 成分里不是。等权持有成分本身就是一个长期为正的主动仓位——相对市值加权的指数，等权是一个小市值 + 低价 + 再平衡的组合押注。实测：随机等权成分书零技能读 **α ≈ +2.5 %/年、IR 0.29（15 只）到 0.57（100 只）**，β 1.01。

**所以在这个池子里，「跑赢基准」几乎不说明任何事情。** 一个 15 只的成分书读 α +4 %、IR 0.45 看起来很像成绩，实际上它比零技能书还差。本臂因此把两条对照写成硬门：

- **`c_rand`**：与候选**同只数**的等权随机成分书，固定种子。候选减去它，剩下的才是技能。
- **`c_index`**：同一份抽签、本账户**最大只数**。它是一条会随只数上移的地板（15 只 IR 0.29 → 100 只 0.57），把「选得好」与「名字多」分开。

两条用同一个种子、同一份按代码的永久抽签，所以 `c_rand` 恰好是 `c_index` 队列的前若干名，只数效应之外没有第二个噪声源。

## 对照自己的误差，和预登记裕度

一次固定种子的抽签是**一个样本**，不是一个分布。15 只的等权成分书本身的 IR 在不同抽样之间会散开——已知的零技能读数从 0.29（15 只）到 0.57（100 只），这 0.28 的跨度全部来自只数与抽样，与技能无关。

因此本包要求裕度**在批次之前**写进 `hypothesis`，并且**不得小于 0.20**：比这还小的优势与「这一次恰好抽到一本差的对照」分不开。想要更强的证据就换第二个种子再跑一条对照——那是一次额外的回放年支出，值不值得由会话自己判断，但**不得**事后挑一个对自己有利的种子。

## 空对照为什么在这里只是诊断

`run_null_control` 比的是**原始**超额、只按流通市值分位给替身配对、而且会掉掉真实篮子 13–19 % 的回合。在一个所有名字都是大盘股的池子里，按市值分位配替身几乎就是随机配对，它判不了本包关心的事。照常给领先节点跑一次，三个数一起报，不据此提名或否决。
