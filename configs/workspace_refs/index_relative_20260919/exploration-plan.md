# 研究会话探索计划

目标：在本臂唯一的研究会话里，在**沪深 300 成分这个池子**上找到一个满足 `families.md` 提名硬门、并按预登记裕度赢过零技能对照的方向，或者诚实地以 `no_edge` 结束。判据只在 `families.md`，数据与单位只在 `pit-field-map.md`，本文只排顺序与预算。

**本臂最大的风险不是门太严，而是把回放预算花在筛选上。** 池换了，旧池上的每一条先验都要重新问一遍，可问的方向因此很多；筛选在离线做，回放只用来确认。

## 第 0 轮：不占回放预算的普查与离线筛选

用 `shell` 在研究期末的决策视图上跑，不启动回放。任一条不合格就在第 1 轮的 `hypothesis` 里声明，不要硬凑。

1. **成分面核对（本轮最先做的一件事）**：`macro.datasets` 里有没有 `index_weight`；在若干个决策日上读出的截面日期、成分只数、权重求和；`con_code` 与 `daily`/`universe` 的 join 命中率。再核对 `universe.l1_name` 在不在。缺任何一块都不得回退全市场池。
2. **池的普查，按研究年分别列**（跨决策日比较行业名单是错的）：可交易成分只数、科创板剔掉几只与多少指数权重、申万一级行业个数、最薄成分的 20 日均成交额、流通市值的分布。
3. **买得起的账（直接对着门 8 与门 2）**：用本臂运行事实的 `initial_cash`，在指令给的**每一个**只数上算——座位金额、一手占座位的比例、买不起的成分占比、5 元最低佣金的 bp/边、一次往返总成本、以及在当前 `cost_stress_multiplier` 下 α 要付掉多少。**这张表决定本臂真正可行的只数区间，必须在第 1 轮之前有。**
4. **零技能对照的离线读数**：把 `c_rand` 与 `c_index` 的选名规则在每个研究年的复核日上跑一遍，报两条对照的持仓只数、行业最大占比、指数权重覆盖、换手。它们是后面所有比较的地板，先知道地板在哪。
5. **离线筛选，最多三个方向。** 每个方向先写一句话的经济解释（`families.md`「一个方向算什么」），再用同一个函数构建历史截面，**在成分池里**读组合尺度的读数。下面这张表是进入回放的前置条件，缺一格就不进回放：

   | 读数 | 口径 |
   |---|---|
   | 最好 N 只相对**成分等权**的前向收益 | 在指令给的两端各读一次，与复核节奏同长，**按研究年分开**。注意基准是成分等权（零技能对照），不是零 |
   | 成本线 | 按复核节奏与换名数算出的年成本，从上一行里扣掉 |
   | 跟踪误差与回撤的先验 | 两端各一个。成分内的随机等权书跟踪误差读 8.94 / 6.91 / 5.82 %（15 / 30 / 50 只），一个方向的先验跟踪误差远高于同只数的这个数，说明它在把书推出指数 |
   | **敞口先验** | 篮子里最大的单一申万一级行业占多少只、占多少权重。**这一条在本臂特别容易破**：起步包的四腿复合在 15 个座位上实测 0.20–0.60。整窗集中度先验超过 0.30 的方向要么改构造，要么不进回放 |
   | 单腿与合成分开读 | 合成方向必做 |
   | 与起步包四条腿的逐日秩相关 | 相关度高说明它不是新信息 |

   筛子类方向的同一张表要读两遍——筛与不筛；构造类方向读成形与不成形。扣掉成本线后不高于成分等权、只在一个研究年里为正、或两端方向相反且说不出理由的方向，不进入回放。
6. **起步包跑一次 `smoke_backtest`**，读每次决策的秒数、订单、拒单与实际权重；参照 `sources.md` 的沙箱实测。

## 第 1 轮：一次完整研究期 `batch_validate`

| 候选 | 是什么 | 身份 |
|---|---|---|
| `d1` | 离线筛选里最强的方向，座位数取第 0 轮第 3 条算出来可行的那一端 | 主候选 |
| `c_rand` | 同只数等权随机成分书，固定种子 | 对照，不得提名 |
| `c_index` | 同一份抽签、本账户最大只数 | 对照，不得提名 |

三条腿共用同一份成分读法、同一复核日历、同一条整手规则，`main.py` 只差 `CANDIDATE` 一行。`hypothesis` 必须写清：方向的经济解释与证伪条件、座位数、复核节奏、保留带与换名上限、**对 `c_rand` 的预登记 IR 裕度（不得小于 0.20）**，以及 `families.md` 门 1–10 的判定规则。

起步包 `s_idx` **不必**作为第 1 轮的候选：它在旧池里作为一个方向已经关闭，离线普查也已经量出它当场过不了门 6。把它当成第 1 轮候选只在一种情况下合理——第 0 轮筛不出任何方向，那么它就是「这个池子里一本朴素的书长什么样」的真实读数，并且要在 `hypothesis` 里写明这一点。

一次三候选的完整研究期验证在四个研究年时花 12 个回放年。预算按臂计（以运行事实 `budgets` 为准；一次尝试失败后原地续跑，接着花同一份预算）。回放一旦开跑就计入预算，策略自身抛错的候选照样花掉，环境失败的候选退还。某一路因环境原因失败时不重跑、不压缩对照：把读数与待裁决的分支写进结果笔记。

**两条对照每一轮都要重跑**，不要用上一轮的读数顶替：它们与候选必须同批、同跨度、同一个 revision。只数变了 `c_rand` 就变了，这正是它存在的理由。

第 1 轮之后，对领先的完整研究期节点跑一次 `run_null_control`：不花回放年，会话时钟在它运行期间暂停，在本臂是**诊断**，三个数一起报，不作提名依据。

## 判定分支，逐条写死（判据本身见 `families.md`）

- **候选在 IR 上赢不过 `c_rand`，或赢的幅度小于预登记裕度** → 这个方向在成分池里没有可辨识的技能。换离线筛选里第二强的方向，不要先去调阈值。
- **候选赢过 `c_rand` 但赢不过 `c_index`** → 赢的是选名，输的是只数。先走轴 b 把座位数挪到指令区间的另一端一轮；仍然输就说明这个账户上「多持一些成分」比「选得好」更值钱，如实写进读数。
- **门 6（行业集中度）不成立** → 本臂最可能先撞上的一条。先看是哪一个行业、哪一条腿把它带上去的，再走轴 f（构造）；**不要**把它解释成「指数本来就这样」，指数的单一一级行业只有 13–15 %。两轮都不成立即按关闭条件 4 关掉这个方向。
- **门 8（成本）在每个可行只数上都不成立** → 先走轴 b 的另一端一轮；仍不成立即以「不可交易」关闭。第 0 轮第 3 条就应该给出预判。
- **门 4（逐年）不成立** → 不可提名；先看是哪一年、是不是指数自己那一年的行情，再决定走哪一轴。两轮都有负年即关闭这个方向。
- **门 1 差在 0.05 以内、其余门都过** → 走轴 c（截面逆波动加权）或轴 d（节奏），一轮一个。
- **门 9（活动量）不足** → 放宽保留带或换名上限，只在这一门不成立时开。
- **门 10 不成立** → 先修实现再复测，修完仍不成立则如实弃权。特别注意「每次复核座位填满」与买不起份额的汇报。

## 第 2 轮起：一次只改一个可分离组件

按 `families.md` 的变体轴取，每轮一个，与当轮基准同批比较（对照照样重跑）。一个方向在两轮里都没有满足提名条件的候选就关闭它，**换下一个预登记方向而不是换阈值**——新方向不限于第 0 轮筛过的那三个，照样先离线筛选、再进回放。子跨度验证（一个研究年，每个候选 1 个回放年）只用来复测实现与耗时，不用来在候选之间做选择。

## 收官轮

只做两件事之一：对已经满足全部提名硬门的最好候选补齐缺的读数（原始超额与 `size_tilt`/`beta`/`size_beta`、行业集中度、2 倍滑点与重算的佣金账、实际权重与买不起份额、两条对照的同批读数、空对照诊断）并冻结；或者以 `finish_session(outcome="no_edge")` 携读数结束本臂。**收官轮只在没有方向可换、或预算见底时才开始**；预算见底时不开新方向，也不要让预算耗尽（流水线记 `deadline`）代替这个结论。

## 计算预算

- 起步包形态（规则型、月度复核、不训练）：沙箱实测一次复核约几秒、非复核日只读交易日历（`sources.md`）；一个四年完整研究期验证在 1 小时量级。
- 学习型候选：CPU 上一次 `fit` 要控制在 10 分钟量级（上限 3,600 秒），整期批次之前先在研究期靠后的槽上量一次，留足并发余量。本臂 `gpu_count = 0`。
- 读取：每次读取都带 `columns=`、`filters=` 与日期窗口；成分截面读 120 个自然日，日线读到最长算子喂得满为止；非复核日在确认最新可见交易日之后直接返回 `[]`；不引入跨调用缓存，冷 worker 与热 worker 出单一致。
- 单日探针的秒数对宿主负载极敏感（同一条腿轻载与重载可以差三四倍），耗时结论按多日回放的**平均**读。

## 每个候选必须汇报的读数

除标准结果块外，写进结果笔记：经济解释与成本线；**信息比率与最大回撤**；**两条对照的同批 IR 与预登记裕度的对照结果**；逐年分块的中性化超额与原始超额；`top_industry_weight`、`size_tilt`、`beta` 与 `size_beta`；机制归因对照的同批读数；单腿读数（合成时）；换手、平均每年完成的回合数、年成本与 2 倍滑点下的超额、按本臂 `initial_cash` 重算的佣金账；拒单率与原因；`pnl_concentration`；空对照的三个数；一次决策的实测平均墙钟。**以及本臂特有的四项**：(1) 每次复核的 `unbuyable_share` 与整期均值；(2) 书的**指数权重覆盖**与科创板剔除掉的指数权重；(3) 实际权重与等权目标的偏离（`realized_weight` 对 `target_weight`）；(4) 候选与两条对照三份持仓名单的**重合度**。缺任何一项的结果不作为提名依据。

## Validation 否证（任何一条命中，结果无效，不讨论收益）

- 股票池不是按时点读出来的成分截面：硬编码名单、全市场池事后筛、或者用了 `index_weight` 里别的指数而仍按沪深 300 判定。
- 两条对照没有同批跑，或与候选用了不同的成分读法、不同的复核日历、不同的整手规则；对照被提名冻结。
- 用 `ann_date`/`trade_date` 而不是 `available_at` 判可见；把成分截面的日期当作调整生效日；`weight` 当成小数没有 ÷ 100。
- 成分的 `con_code` 没有改名就去 join，得到一张空表却按「池太小」处理。
- 买不起的**持仓**被当成离池强卖；或者买单向下取整而不是按最近整手四舍五入。
- 对照对自己的面做了中性化，或对照没有复现它的面；训练面板与决策截面不是同一个函数构建的。
- as-of 域读失败后回退了 `snapshot_dir`；读多数据集的域时没有先按 `dataset` 过滤；任何读取不带日期窗口。
- 复核节奏依赖模块级计数器或跨调用缓存。
- 没有第 0 轮的买得起账与逐研究年离线读数就开了回放。
- 把 `size_tilt` 当成中性化回归的规模载荷来论证，或者在 `stats.benchmark` 缺字段时仍然按「大概达标」提名。

## 收尾

冻结的是提名节点自己的不可变快照，提名前不必把它恢复到 `output/`；对照节点不得被提名。不要提交离线普查脚本；`models/` 只放静态资产。
