# 五个社区机制（转述，非收益证据）

以下是社区常见打板话术的 PIT 改写。一折内会有多个机制走完整 Validation，但每个候选仍然单独测：一次只改一个 cohort 定义或加一层已声明的门控。JoinQuant 当时 geo-blocked，本包没有拉回任何聚宽源码。不要把这些写成已验证 alpha。

公共脚手架：读 `context.asof_dir + "/events"` 后立刻按 `dataset` 过滤并再检查 `available_at`；日线与涨跌停约束走 `"/daily"`；竞价走 `"/auction"`。只保留本轮股票池内的有效 A 股代码。分数排序必须稳定（分数再 `ts_code`）。

## 1. 首板次日

**社区说法。** 昨日第一次收盘涨停，次日开盘跟。

**PIT。** T-1 `limit_list_d`：`limit=='U'` 且 `limit_times==1`。要求可见流动性（成交额/换手），排除停牌与 ST（用当时名称/清单，不回填今天）。
08:30 看不到今日低开，不能把「低开才买」写成过滤器。
09:29 可以用今日 `auction.price` 相对昨收（`auction.pre_close` 或 T-1 `daily.close`，先对 schema）作缺口代理：例如拒绝极端高开，或只保留竞价仍为正/温和缺口的首板。缺口规则是可选消融，不是默认必加。

**入场。** 当日 09:30，3–8 只等权或等风险。买不进就是买不进。

**出场。** 下一交易日 09:30：不再属于新鲜首板/续板队列，或持有满一个声明过的短周期。不要把亏的票改成趋势单留下。

**否证。** 含成本开盘对照不优于「同日同流动性全部首板」；或优势只存在于把 T-1 收盘当成交的版本。

## 2. 一进二

**社区说法。** 首板次日冲击二板，比普通首板更挑。

**PIT。** 仍是 T-1 首板（`U` 且 `limit_times==1`），但加可观察的封板质量：较少 `open_times`、较高的 `fd_amount/amount` 截面名次、足够成交额。这些字段都是 **T-1 日终描述**，只能说明昨天怎么封的，不能当今日队列深度。
09:29 可选：竞价仍靠近涨停价（相对今日 `stk_limit` 上限）则视为「竞价未烂」，否则视为弱开。

**入场。** 当日 09:30，最多 1–4 只，仓位低于首板篮子。

**出场。** 下一 09:30 若不再是高度领先的封板队列，清掉。

**否证。** 相对「全部首板次日」没有稳定增量；或挑中的票大量涨停开盘无法成交。

## 3. 炸板修复

**社区说法。** 昨日曾涨停但收盘打开，次日可能回补。

**PIT。** T-1 `limit=='Z'`，流动、收盘仍非跌停（不要混入 `D`），`open_times` 不过于极端。可加同行业仍有封板或 T-1 资金流入，但先测纯 Z 队列。
08:30/09:29 都看不到「今日已经回封」。09:29 最多用竞价是否继续崩坏作过滤，不能把未发生的回封当条件。

**入场。** 当日 09:30，小等权篮子。

**出场。** 事件生命周期一到两个交易日。没有新的独立信号就退出。

**否证。** 含成本 next-open 不优于按 T-1 收益/换手/市值/行业匹配但不是 Z 的对照；或利润只出现在 T-1 收盘价成交的幻想里。

## 4. 连板龙头

**社区说法。** 买最高板、封单强、开板少的龙头。

**PIT。** T-1 `limit=='U'`，`limit_times` 为当日可见最高或仅次于最高。偏好小的 `open_times`、强的 `fd_amount/amount` 与成交额名次。高度从可见 `limit_list_d` 计算，不要把 `limit_step` 当当日可买名单。
09:29 可选：竞价仍接近涨停则视为未烂板；竞价大幅低开则排除。这仍是次日跟龙头，不是盘中打板。

**入场。** 当日 09:30，最多 1–3 只，总暴露低于分散篮子。

**出场。** 不再是高度/封板队列，或市场炸板宽度恶化。不加仓摊平。

**否证。** 不优于同高度封板对照；`open_times`/封单比没有稳定排序；收益集中在涨停开盘买不进的日子；或尾部回撤吞掉组合。

## 5. 弱转强 / 情绪冰点

**社区说法。** 市场情绪冰点后修复；个股竞价弱转强。

**PIT 市场腿。** 用最近 5–10 个可见 `limit_list_d` 交易日：`up=count(U)`，`broken=count(Z)`，`down=count(D)`，封板成功率 `up/(up+broken)`，最高连板高度与首板数。修复态：成功率与首板宽度从近期低点回升，同时跌停/炸板宽度没有新高。这是 T-1 日终宽度，不是盘中情绪。

**PIT 个股腿（仅 09:29）。** 「弱转强」在本环境只能改写成：T-1 偏弱（炸板、低开或收益偏弱）且今日竞价相对昨收不再弱。这是竞价感知过滤，不是 09:15–09:25 逐笔弱转强。不要使用当日 `kpl_list` 的竞价标签冒充实时竞价（见字段图）。

**入场。** 仅在修复态买 3–8 只流动首板或修复队列；非修复态空仓。

**出场。** 修复态失效或个股离开队列。保持现金，不要发明均线托底。

**否证。** 去掉市场门控后的同队列一样好或更好；个股「竞价转强」过滤在对照后没有增量；或门控的增量只出现在 Validation 年的某一个子窗（见 `exploration-plan.md` 第 7 步）。

## 对照矩阵

| 机制 | 必要对照 |
| --- | --- |
| 首板次日 | 全部流动首板；有/无 09:29 缺口过滤；收盘成交 vs 开盘成交 |
| 一进二 | 相对首板次日的增量；涨停开盘拒单后是否还在 |
| 炸板修复 | 匹配的非 Z 队列；开盘对照 |
| 连板龙头 | 同高度封板，去掉 open_times/封单过滤 |
| 情绪/弱转强 | 无门控的同队列；仅市场腿 vs 市场+竞价腿 |

对照更好就留更简单的；两者难分时先看年内子窗一致性，仍分不出才留更简单的。不要用 MA/RSI 拯救失败的打板假说。
