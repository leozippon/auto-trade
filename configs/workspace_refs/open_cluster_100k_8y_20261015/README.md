# 开放臂·聚类内的信息扩散·全 A / 10 万 / 八年（open_cluster_100k_8y，20261015）

本目录是只读参考包，会话里挂在 `refs/`；`output/` 开局就是 `refs/starter/` 的一份可写副本。

按顺序读：本文（方向与数据）；`refs/references/open-rules.md`（六条开放臂共同的规则：账户、标准对照、预算与提名，与本文同为合同）；`refs/families.md`（这份记录上已经占用与关闭了什么）；`refs/starter/`（`lib/index.py` 读指数成分，`lib/titles.py` 与 `lib/fund.py` 读公告与财务，`lib/controls.py` 是标准对照）；运行记忆 `research-8y-data-surface` 的「universe」「宏观」「按时点读成分、行业与指数行情」三节。

## 方向

信息在一组相关的股票里怎样从先动的名字传到后动的名字：同一行业里从大市值到小市值，从指数成分到非成分，以及同行公告的外溢——一家公司的激励草案、业绩预告或报表，预示同行业里还没公告的公司随后的反应。要找的是跨名字的扩散（滞后的那只股票），不是给行业排名：行业动量与行业轮动在这份记录上已经关闭（`refs/families.md`），只买「领先的行业」不是本方向。

## 值得一看的（建议，不是菜单）

外部文献，不是宿主读数，都要在研究期上自己核对。

- **行业内大带小。** 美股上，行业内大公司的收益领先小公司，滞后来自小公司对行业信息的反应慢（Hou 2007，RFS）；更早的规模先后效应见 Lo 与 MacKinlay 1990。A 股的散户占比高、小盘换手高，方向不一定相同：先在前半段量「大市值同行昨天到上周的收益」对小市值同行下一周收益的截面斜率，按行业与年份分开看。
- **经济上相连的公司。** 客户的消息慢慢传到供应商（Cohen 与 Frazzini 2008）；湖里没有供应链表，申万行业是它最粗的近似。
- **业绩信息的行业内传递。** 先公告业绩的公司会带动同行业还没公告的公司（Foster 1981 以来的「行业内信息传递」文献）。A 股的业绩预告有披露期限（年报预告在次年 1 月底前，满足条件的才强制），`forecast_vip` 与 `disclosure_date` 可以排出谁先谁后；这里的检验是先公告者的预告方向与幅度，能否预测同行业后公告者从先公告日到自己公告日之间的收益。
- **指数成分到非成分。** 成分股被指数基金与期货的套利同时交易，信息先进入价格；同一行业里的非成分股可能滞后。成分只有月末截面，指数调整的生效日看不到。

## 血缘

没有。本臂不继承任何臂的试验；要重开 `refs/families.md` 里的一行（例如普查的相对本行业族、行业领先跟随），在第一次提交它的那一批照那一行申报。

## 本方向的对照要点

- 扩散的主张是「先动者的信息传给了后动者」，主对照把先后关系打乱、其余不变：`shuffled_assignment` 把同一天、同样多的「滞后名字」换成从可买池（或别的行业）里抽的名字；它问的是收益来自这条传递，还是来自「这一天买小盘」。
- 外溢事件书（同行公告之后进场）：`late_entry`，同一批事件晚进场。
- 一个聚类的定义（只用指数成分、只用某几个行业）本身是一次选择：几种定义都试过就都申报，主张对定义不敏感时才值得提名。
