# 同月收益季节性参考包（seasonality_csi500，20260926）

本目录是只读 refs。本包登记的是**一段从没有任何一条臂读过的价格历史**：每只股票过去 1–4 年**同一个日历月**里相对池子的超额收益。Heston 与 Sadka 在美股上发现它会在同一个月份重复，效应在 20 个年滞后上都在；本臂把它做成最透明的形态——每个月初按这个分数给中证 500 成分排名，持有前 50 只，等额现金，下个月初整本重排——由宿主的零技能面板裁决。它是一个**不训练的规则分数**，不叠在任何载体上。

## 为什么是这个形状

**这是一段没被读过的信息，不是算子堆的一个变种。** 登记册 §2 关掉的日频价量算子堆（Alpha158/360、WQ101、GTJA191、动量、反转、换手）里没有一个算子读 12–48 个月前同一日历月的收益；季节性的机制（资金流、盈利与分红的日历、机构行为）也与它们不同。市场层面的日历效应（年初、节前、财报季）在主动序列里按构造就对消，本臂卖的只是截面上的选名。

**为什么是中证 500、为什么 50 席。** 本轮是广度轮：一百万元的沪深 300 成分规则分数是登记册 §2 已关闭的形状；中证 500 的截面离散更大，50 席与已测过的同池形状（`csi500_shape_1m_20260923`、`fresh_book_csi500_1m_20260925`）同一个账户骨架，面板地板有读数可比。

**登记在先的限制。** 美股的水平一个都搬不过来（多空两头、等权、不扣成本）；A 股的三篇证据**只读到摘要**（全文 403），没有一篇覆盖 2021–2025；KLN 发现个股季节性约 68 % 是规模、股息率与行业的季节性，而宿主的中性化看不见行业与股息率；Broker 按税前入账红利。预期主动超额 +1…+3 %/年、主动 IR 0.15–0.45，远低于冻结门（`refs/families.md`）。月间几乎不相关的分数逼着书每月换掉约 43 只，年换手约 20 倍：成本面板照付，但前推的 F5 要多扣约 1 pp/年——预期量级的下限就压在这条线上。

**包作者在登记之后读到的是否定的。** 48 个月初（回放同口径的历史）的月度秩 IC 均值 −0.006（t −0.37），只有第一研究年为正；前 50 只的月度书对同池等权 −3.9 %/年；离线筛 Z1、Z2、Z4 命中，Z0、Z3 不命中（读数与先后时间在 `refs/sources.md`）。按 `refs/families.md`：唯一一批 `c_shuf` + `s1`（8 个回放年）照跑，因为 `no_edge` 本来就要它；`s1` 不过宿主线 H 就 `no_edge`，过了 H 也不开变体批（筛命中），只有冻结门本身能让它继续。**会话要自己重算能复核的那一段**（`/mnt/snapshot` 上只有 2023-08..2025-06 的 23 个月初，`refs/references/offline-screen.md`），一致就照登记执行，不得因为已经知道读数而改登记。

## 按以下顺序读

1. `refs/families.md`：分数、两条腿、符号 / 量级 / 换手的预登记、离线筛 Z0–Z4、验证计划与宿主线 H、变体 `s2`、已关闭家族、要求与关闭规则（**唯一权威表述**）。
2. `refs/pit-field-map.md`：逐回放年的输入窗与滞后覆盖（本臂最要紧的一张表）、月收益的列与口径、截面的读法与陷阱（唯一权威表述）。
3. `refs/exploration-plan.md`：第 0 轮核对、离线筛的重算、第一批的登记与分支。
4. `refs/references/`：五份自写笔记——**`seasonality.md`**（文献、折扣、它在本仓库里长什么样，**先读它**）、**`offline-screen.md`**（会话能复核哪一段、怎么算）、`zero-skill-panel.md`、`capital-arithmetic.md`（换手与 F5）、`index-membership.md`。挂载后它们都在 `refs/references/` 下。
5. `refs/sources.md`：本包在本轮种子上的全部读数（覆盖、月度 IC 序列、十分位、月度书、工具读数、起步包两路核对、宿主冒烟）与诚实的限制。
6. `refs/starter/`：合同内的最小可运行包，**会话开始时 `output/` 就是这份代码**；`s1` 与 `c_shuf` 只差 `lib/knobs.py` 里 `SHUFFLE` 一行，变体 `s2` 只差 `FIRST_LAG` 与 `MIN_LAGS` 两行。

## 你被评的是主动序列

宿主每次正式验证后按候选自己的成交骨架随机换名重放 20 份作为零技能面板，统计量都算在「候选减面板」上（`refs/references/zero-skill-panel.md`）。三条要记住：绝对超额说明不了事（本池 50 席月度书的面板自己就读 +3.1 %/年）；`c_shuf` 是同批的一次零技能抽样，`s1` 要越过的是登记的宿主线 H，不是 `c_shuf` 那一次读数；面板不对齐权重方案，本臂只有等额现金。

## 本臂的执行边界

执行合同以只读 `output/README.md` 与系统提示为准，本包不复述。更具体的几点：`s1` 与 `c_shuf` **不训练**（没有 `fit`），复核日与补座日读一次池内约 450 只 × 38 个月的复权收盘与一张截面；**`gpu_count = 0`**，策略容器 8 核 / 16 GiB；截面或滞后窗口读不到就报错，不回退；分数只读决策月之前至少 12 个月的价格；`models/` 只放静态资产；不要把 `refs/` 里的文件拷进 `output/`。

## 账户与成本

开工第一件事是读运行事实：`broker_replay.initial_cash`、`benchmark_index`、`acceptance_rules`（本臂创建时 `max_drawdown` 0.50、`active_max_drawdown` 0.30，不设跟踪授权）、`budgets` 与 `research_geometry.years[].input_window`（每个回放年 60 个月，四个滞后要 49 个月）。本包按 100 万元、50 席写成：座位约 19,400 元，买不起的成分 0–1 %。**年换手约 20 倍是本臂的结构**，不是实现问题：P3 的上限是 24 倍，`excess_at_2x_slippage` 必须为正（`refs/references/capital-arithmetic.md`）。

## 「没有边际」的读法

每一行按主动读数读，逐年地读，并把五至七月（除息月）与其余月份分开（P5）：只在除息月成立的读数更像税前红利的入账口径，不是季节性选名。`top_industry_weight`、`size_tilt` 与 `size_beta` 并排读（KLN：个股季节性大半是规模、股息率与行业的季节性）。**「同月季节性在中证 500 上与零技能分不开」本身就是登记册要的一行**，连同 Z0–Z4 与宿主读数一起写进 `no_edge` 的理由。
