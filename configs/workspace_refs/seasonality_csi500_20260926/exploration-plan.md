# 研究会话探索计划

目标：在本臂唯一的研究会话里，判定「同月收益季节性」这个不训练的分数在中证 500 上能不能选出与零技能可区分的主动收益；能就把它做成一本站得住的书，不能就诚实地以 `no_edge` 结束。判据、预登记与验证计划只在 `refs/families.md`，数据与单位只在 `refs/pit-field-map.md`，离线筛的做法只在 `refs/references/offline-screen.md`，本文只排顺序与预算。

## 第 0 轮：不占回放预算的核对

用 `shell` 在 `/mnt/snapshot` 上跑，不启动回放。任一条不合格就在第一批的 `hypothesis` 里声明，不要硬凑。

1. **运行事实核对（最先做）**：`broker_replay.initial_cash`（本包按 100 万元写）、**`benchmark_index`**（应为 `000905.SH`；与 `lib/knobs.py` 的 `INDEX` 不一致时改常量去对齐运行事实）、`acceptance_rules`（两个回撤上限应为 0.50 / 0.30，不设授权；`freeze_gate` 的阈值与试验数口径）、`budgets`、`max_replay_years`，以及 **`research_geometry.years[].input_window`**——每个回放年的日线输入窗要有 60 个月，四个滞后要 49 个月（`refs/pit-field-map.md`）。
2. **数据核对**：`macro` 里 `index_weight` 有 `000905.SH` 的截面；`daily` 带 `close`、`adj_factor`、`is_suspended`；`universe` 带 `name`、`l1_name`。
3. **覆盖（Z0，不读收益）**：在 `/mnt/snapshot` 上，2023-08..2025-06 每个月初可交易池里可打分的份额；与 `refs/sources.md` 的回放同口径覆盖对一遍（Y3 / Y4 应在 97–98 %）。
4. **离线筛重算**（`refs/references/offline-screen.md`）：会话能复核的只有 2023-08..2025-06 的 23 个月初——Z1 的月度 IC 序列、Z3 的月间秩相关、`screen.py` 的 `s1` 与随机各一次（Z2 / Z4 的那一段）、十分位与前 50 只的月度书。**这 23 个月的读数单独报，不要当成 48 个月的读数**；与包作者同一段的读数一致就照登记走，不一致先查分数的月份口径与池的取法。
5. **冒烟**：`smoke_backtest` 至多 5 天，只用来确认合同、`strategy` 秒数、第一天的 50 张买单（买不起份额、实际权重、滞后覆盖的买单元数据）；**换手、每月完成回合数、拒单率与平均总仓位读第一批完整期结果**，不要用冒烟外推。整个会话靠后窗口的探针只用一个 `start`。

**这一步不产生提名依据。** 离线读数只有秩与方向可信；筛只能否决。

## 第 1 轮：第一批完整研究期 `batch_validate`

腿与登记按 `refs/families.md`：**`c_shuf`（第一条，`control: true`）、`s1`（`control: false`）**，`span="full"`，8 个回放年，`offline_trials` = 0（会话若另筛了任何变体，每个加 1，如实申报）。

`hypothesis` 必须写清：逐行引用 `refs/families.md` 的分数表、腿表、符号 / 量级 / 换手表；Z0–Z4 的读数（包作者的 48 个月与会话自己的 23 个月分开）；宿主线 H 与它之后的分支；P2 / P3 / P5 的判定规则；本臂的 trial 账（M = 1、N_eff = 1、门槛约 0.98）。

**不要再加零技能对照腿**——宿主每次正式验证都会抽面板，`c_shuf` 已经是同批的那一次抽样。第一批之后对 `s1` 的完整期节点跑一次 `run_null_control`：不花回放年，它是诊断不是判据。

## 判定分支，逐条写死（判据本身见 `refs/families.md`）

- **`s1` 不过 H**（主动 IR < 0.50、主动为正的研究年 < 3、或主动回撤 > 0.30）→ `no_edge`。
- **`s1` 过了 H、冻结门也过**（第一批已有两条完整期验证）→ 先核 P2 / P3 / P5 与提名条件，满足就冻结。
- **`s1` 过了 H、冻结门不过** → Z1–Z4 无一命中时开那一次变体批 `s2`（`FIRST_LAG` 2、`MIN_LAGS` 2，4 个回放年，`control: false`），之后按冻结门冻结或 `no_edge`；**有一条命中就不开**，`no_edge`。
- **`s1` 与 `c_shuf` 读数相近** → 与零技能分不开，按 H 读，不要把两者之差当增量。
- **绝对超额高而主动超额低** → 赢的是池不是选名；看 `benchmark.panel_neutralized_excess`。
- **主动收益集中在五至七月** → 更像税前红利的入账口径（P5），如实写。
- **`top_industry_weight` 越过 0.30 或行业读数异常** → KLN 的行业季节性，如实写，不以选名的名义提名。
- **换手、成本或回合数越线**（年换手 > 24 倍、`excess_at_2x_slippage` ≤ 0）→ 不可交付，按杀死条件第 4 条关闭。
- **实现读数不对**（座位没填满、拒单率高、`c_shuf` 与 `s1` 的换手差得多）→ 先修实现再复测，不算证伪。

## 收官轮

只做两件事之一：对满足全部提名条件的候选补齐缺的读数并冻结；或者以 `finish_session(outcome="no_edge")` 携读数结束本臂，理由里写全 `refs/families.md` 臂级终止规则列出的读数。写一条 skill：同月季节性在回放同口径下的做法与 `/mnt/snapshot` 只能复核后 23 个月初这件事（引用节点 id 与读数）。

## 计算预算

- **决策**：复核日与补座日读池内约 450 只 × 38 个月的复权收盘与一张截面，容器内一两秒；非复核日只读 12 天的交易日列就返回 `[]`。实测读数在 `refs/sources.md`。
- **回放年**：离线筛与 `smoke_backtest` 都是 0 年；第一批 8 年，变体批 4 年；全臂至多 12 年、整期验证至多 3 条（对照计入）。
- **余量怎么花**：变体轴只有登记的那一格；每一个验证过的候选与每一个离线筛过而没提交的配置都是一个 trial，会抬高本臂自己的门槛。

## Validation 否证（任何一条命中，结果无效，不讨论收益）

- 股票池不是按时点读的：硬编码名单、或用后来的截面标注历史决策日。
- 分数用了决策月本身或之后的价格；把缺失的滞后当 0；在 `/mnt/snapshot` 上用被窗口截掉的滞后去算 2023-08 之前的月初并当作全期读数。
- `c_shuf` 的打乱依赖模块级状态或跨调用缓存；复核节奏依赖计数器。
- 买不起的**持仓**被当成离池强卖；或者买单向下取整而不是按最近整手四舍五入。
- `c_shuf` 登记成 `control: false`、`s1` 登记成 `control: true`，或 `offline_trials` 少报了会话另筛过的变体。
- 看过读数之后改了登记而没有重写 `hypothesis`；或在 Z1–Z4 命中之后开了变体批。
- 用绝对中性化超额或绝对信息比率去论证边际，而不看主动读数与面板。
