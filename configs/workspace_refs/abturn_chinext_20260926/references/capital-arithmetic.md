# 账户算术：座位、整手与成本

自写笔记，100 万元 / 20 席 / 创业板指这个账户形状上的钱。Broker 的费率以运行事实 `broker_replay` 为准；这里的数只用来判断量级，**换手、成本与回合数必须在第 0 轮与第一批里实测**（`refs/exploration-plan.md`），不引用本页的估算。

## 座位与整手

- **座位**：`book value × 0.97 / 20`，开局约 **48,500 元**。起步包的座位随账户走（`context.account`），不是常数：书涨了座位跟着变大（宿主冒烟在 2024-09 下旬的反弹之后读到 64,000–75,000 元）。
- **一手买不起**：研究期 48 个复核日上，池内一手超过一个座位的名字逐年均值 2.7 / 1.0 / 0 / 0 %（`refs/sources.md`）。买不起只影响买入：已持有的名字涨过一个座位**不强卖**。
- **最近整手**：创业板有少数高价股（一手可到半个座位），买单按最近整手取整再按剩余现金截断，一只名字的误差最多半手，排在后面的名字可能被现金截断——第四研究年容器探针的首日 20 笔买单实际权重 1.77–5.69 %（目标 5 %），宿主冒烟的平均总仓位 0.95。
- **现金**：0.97 的缓冲加卖出按 0.98 折算。

## 每笔的成本（`broker_replay` 的默认值）

| 项 | 费率 | 在 48,500 元一笔上 |
|---|---|---|
| 佣金 | 1 bp 双边，**最低 5 元** | 1 bp 是 4.85 元，最低佣金刚好约束：**约 1.0 bp / 边** |
| 过户费 | 0.1 bp 双边 | 0.1 bp |
| 印花税 | 卖出 10 bp，2023-08-28 起 5 bp | 5–10 bp |
| 滑点 | 5 bp 方向性（限价与竞价成交不计） | 0–5 bp / 边 |

一次往返约 **7–22 bp**。包作者三个月的宿主冒烟读年单边换手约 2.5 倍，对应成本约 0.2–0.6 %/年；**实测以第一批的 `turnover`、`fees_paid` 为准**。成本在面板里大半对消，它影响的是 P3 的 `excess_at_2x_slippage` 与前推期的成本压力判据 F5。

## 活动量

前推与 Held-out 要求每月至少 1 个完成回合（F6）、平均总仓位 ≥ 0.5（F7）。分数窗口 20 日、每月基本换一遍，但保留带 40 / 100 留住了一半以上：冒烟的三次复核各换 4–5 只，每月约 3.8 个完成回合（`refs/sources.md`）。
