# 本轮数据与 08:30 字段图

本文是本包可用数据、可见时点、单位与陷阱的**唯一权威表述**。数据集清单、行数、日期覆盖与单位以本轮 `data_summary.json`、snapshot manifest 与 `unit_reference.json` 为准：先核对它们，再写阈值或跨域组合。

**开工第一件事**：核对四件事——`macro.datasets` 里有没有 `index_weight`（没有它就没有这个臂的股票池）；`daily` 带不带 `turnover_rate`，`unit_reference.json` 是否把它登记为小数；`universe` 带不带 `l1_name`（行业配额与 P2）；以及运行事实里的 **`benchmark_index`** 是否为 `399006.SZ`、与 `lib/index.py` 的 `INDEX_CODE` 一致。**缺任何一块都不得静默回退**到别的池子或别的列——那是另一个登记；起步包在读不到截面或日线窗口不够 250 个交易日时直接报错。

## 本臂的数据集选择（创建参数）

与 `fresh_book_1m_20260925` 完全相同：20260919 轮的基本面 10 个、宏观 20 个（含 `index_weight`）、事件 17 个、文本 `report_rc`，不挂分钟域；预建视图种子 `data/pit_views_seed_research_20260919`。**本包只读 `daily`、`universe` 与 `macro.index_weight`**，其余域不进分数。

## 每个回放年自己的输入窗（运行事实 `research_geometry.years[].input_window`）

每个研究年的回放从**它自己的**决策视图起步，那张视图从该年开始前一天往回 60 个月；会话挂的 `/mnt/snapshot` 是研究期末那一张。

| 视图 | 输入窗 | 对本臂意味着什么 |
|---|---|---|
| Y1 回放（2021-07..2022-06） | 20160701..20210630 | 分数要 250 个交易日（约 410 个自然日的读取），任何一年都够；成分截面从 2020-01 起（数据湖本身的起点），第一个复核日已有截面 |
| Y2 / Y3 / Y4 回放 | 20170701..20220630 / 20180701..20230630 / 20190701..20240630 | 同上 |
| `/mnt/snapshot`（研究期末） | 20200701..20250630 | 离线重建研究期第一天时只有 243 个交易日：记在研究期最初 7 个交易日上的分数，250 日分母只用到 243–249 天（仍满足 200 天的下限）——离线侧的左截断，回放没有；成分截面从 2020-07 起 |

本臂不训练，所以没有「训练窗下限」；成分标签从 2020-01 才有这一条只意味着 2020-01 之前的日期没有池，而本臂的每个决策日都在它之后。

## 日线 `daily`（已并入 `daily_basic` 与 `stk_limit`）

| 列 | 含义 | 单位 | 用途 |
|---|---|---|---|
| `turnover_rate` | 当日换手率 = 成交股数 / 流通股本（`daily_basic`） | **小数**（0.05 = 5 %；原始层是百分数，快照 ×0.01） | `t1` 的分子与分母 |
| `close` | 收盘价 | 元/股，未复权 | 买单按 T-1 `close` 定价 |

- **可见性**：`daily` 行按交易日 17:30 盖章，其中 `daily_basic` 的列按 18:00；没有 `available_at` 列，as-of 视图里恰好是决策时可见的行，08:30 决策读到的最新一行是 T-1。不要按不存在的 `available_at` 过滤。
- **`turnover_rate` 与 `turnover_rate_f`**：前者按全部流通股本、后者按自由流通股本；本包登记前者（LSY 用的是流通股换手）。换成后者是一个新的候选配置。
- **停牌**：整天停牌的名字**没有行**；`is_suspended` 只标盘中临停。窗口里缺的交易日就是无效交易日，不是 0 换手：把它记成 0 会把刚复牌的名字的分母压低、分数抬高，是一次静默的错误押注。
- **两个窗口按市场交易日数**：最近 20 与 250 个**市场**交易日（面板的日期轴），不是名字自己的 20 与 250 根 K 线；有效交易日分别至少 15 与 200。
- **比值是无量纲的**：单位（小数还是百分数）不影响分数，但任何按换手率水平设的阈值都要先核对单位。

## 成分截面 `macro.index_weight`（与基准日线 `macro.index_daily`）

```text
sec = pd.read_parquet(
    context.asof_dir + "/macro",
    columns=["dataset", "available_at", "index_code", "con_code", "trade_date", "weight"],
    filters=[("dataset", "=", "index_weight"), ("index_code", "=", "399006.SZ"),
             ("trade_date", ">=", start)],
)
```

| 事项 | 规则 |
|---|---|
| 指数键 | `index_weight` 的指数在 `index_code`、成分在 **`con_code`**（`ts_code` 为空），跨域 join 要自己改名 |
| 可见性 | 行级 `available_at`，按自己那个交易日 17:30 盖章——08:30 决策看不到当天那张截面，读到的是上一张 |
| 频率与规模 | 每月一张，日期是当月最后一个交易日；研究期末视图 2020-07..2025-06 共 60 张、**每张正好 100 只**，权重和 100.00（`refs/sources.md`）。成分没有少于 100 只的月份 |
| 板块 | 全部是创业板（300 / 301 / 302 开头；研究期末视图里出现过 173 只），没有科创板与北交所 |
| `weight` | 百分数；本包只用成员资格，权重只用来报一本书覆盖了指数的多少 |
| `index_daily` | **本起步包不读它**。会话若要读基准日线，按 **`ts_code`** 过滤（`("ts_code", "=", "399006.SZ")`）：它的 `index_code` 整列为空，按 `index_code` 过滤会安静地返回 0 行，不过滤则七只指数的日线混在一起 |

**只有月末截面**：两张之间的真实调整看不见，复核日拿到的是上一张的名单（`refs/references/index-membership.md`）。每一个决策日都按那一天可见的最新截面判定成分。

## `universe`

`name`（ST/退过滤）与 `l1_name`（行业配额、`t1i` 与 P2）。申万一级行业按决策日取（2021-12-13 从 SW2014 切到 SW2021，一级行业的个数与名字会变，跨决策日比较行业名单是错的）；为空的落在 `未分类`，它自己算一个行业。

## `snapshot` 只有一个时点口径

`/mnt/snapshot` 是研究期末那一天的决策视图：`universe` 里的名称、ST 状态与行业都是那一天的。离线重建（`refs/references/offline-screen.md`）因此不按 ST 过滤、行业用研究期末的分类——两处已知的小偏差；成分与日线都按日期正确。**不要拿它原样当某个历史决策日的 as-of 视图**：它的日线一直到研究期末，读「最新一行」会读到未来。

## 陷阱

- **把停牌日记成 0 换手**：见上文；跳过，不填 0。
- **按名字自己的 K 线数取窗口**：长期停牌的名字会把一年前的换手当成「最近 20 天」。按市场交易日取。
- **成分的代码列是 `con_code`**；`index_daily` 按 `ts_code` 过滤。
- **一手与整手**：100 万元 20 席的座位约 48,500 元；创业板有少数高价股（研究期末 300750 收盘 252.22 元，一手约 25,200 元，约半个座位），最近整手会让单只名字的实际权重偏离 5 % 最多半手——第四研究年容器探针的首日实际权重 1.8–5.7 %。研究期里买不起一手的池内名字 0–2.7 %（`refs/sources.md`）；买不起只影响买入，**已持有的名字不得因此强卖**。
- **涨跌幅 ±20 %**：创业板 2020-08-24 起日涨跌幅限制 ±20 %；涨停开盘的买单会被 Broker 以 `daily_price_limit` 拒掉，起步包之后几天补座位。
- **印花税在研究期内切换**（卖出 10 bp → 5 bp，2023-08-28）。
- **复核节奏不得依赖模块级计数器或跨调用缓存**：到期判断拿最新可见交易日与决策日比自然月；`c_shuf` 的打乱只用决策日做种子。
