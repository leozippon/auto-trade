# 开放臂·表里的承诺·全 A / 10 万 / 五年（open_tables_100k_5y，20261015）

本目录是只读参考包，会话里挂在 `refs/`；`output/` 开局就是 `refs/starter/` 的一份可写副本。

按顺序读：本文（方向、研究几何与数据）；`refs/references/open-rules.md`（六条开放臂共同的规则：账户、标准对照、预算与提名，与本文同为合同）；`refs/families.md`（这份记录上已经占用与关闭了什么）；`refs/starter/`（`lib/events.py` 是事件域的按时点读取，`lib/fund.py` 与 `lib/titles.py` 读财务与标题，`lib/controls.py` 是标准对照）。运行记忆 `research-8y-data-surface` 写的是八年几何、没有事件域的臂：它关于日线、universe、宏观、财务与标题的单位与可见时间对本臂都成立，关于研究期、窗口与「没有事件域」的几句不成立，以本文为准。

## 方向

做多的信息在这份记录上只出现在一种地方：公司或它的内部人按一个披露出来的价格押上钱。到现在为止读到它的都是公告标题（激励计划草案、员工持股计划草案，都已在 Paper 上，`open-rules.md` §3 第 5 条）。本臂去事件域的表里找同一种承诺，那里记的是成交，不只是计划：

- 控股股东、公司与高管的增持（`stk_holdertrade`，`in_de` 为增、带成交均价 `avg_price` 与占总股本比例 `change_ratio`）：标题上的「增持计划」只是口头承诺、已被晚进场对照证伪，表里记的是已经买了多少、按什么价；
- 回购的执行：结构化的 `repurchase` 表约 3 % 的版本自相矛盾，从不进入沙箱，所以回购只能从标题（「回购股份进展」「实施结果」「注销」）与日线总股本 `total_share` 的下降读出；
- 溢价成交的大宗交易（`block_trade`：价格、量、额、买卖方营业部）：大宗多是折价、常是减持的通道，溢价成交的才是有人多付钱；
- 按披露价格认购的定增：没有结构化表，只能读标题（20261014 轮在八年标题里只数到 59 个锁价定增）；
- 提前预约的定期报告披露（`disclosure_date` 的首次预约日 `pre_date`）：公司按一个日期作出承诺，好消息早报、坏消息晚报是一个有文献的 A 股现象；
- 业绩预告与快报（`forecast_vip`、`express_vip`）作回应的一侧：它们是内部人的承诺被检验的地方（增持之后的预告是好是坏），单独作事件书已经关闭（下表）。

激励计划草案与员工持股计划草案被占用；用标题重建它们、或让超过 30 % 的买入落在它们之后 60 个交易日以内，都不算产出。

## 研究几何

五年：研究期 2020-07..2025-06（Y1..Y5），就是八年臂的 Y4..Y8；前面的年份事件域覆盖不到（湖里的事件表从 2020-01 起）。研究期末视图与每个研究年回放起点视图的窗口都是 72 个月。冻结门的正年数要 4/5，主动 IR 下限 0.75 不变；去膨胀门槛按五年的天数算，同样多的试验比八年高。两半是 Y1–Y2 与 Y3–Y5，最后两年是 Y4–Y5；探针与离线筛选只用 Y1–Y2（`open-rules.md` §4、§5）。

`lib/events.py` 的说明写了事件域的形状、每张表的可见时刻与不能用的列。本方向的几个细节：

- `stk_holdertrade` 一份公告常有多行（多个股东、多段成交），`ann_date` 当晚 19:00 可见；`holder_type` 是 `C`（公司或机构股东）、`G`（高管）、`P`（个人），`in_de` 是 `IN` / `DE`；增持远少于减持（2020 年上半年的一个月里约 1 : 10），`begin_date` / `close_date` 是成交区间，公告常在区间结束之后。
- `block_trade` 当日 21:00 可见；溢价要自己拿同日的收盘价算；同一自然键下的多行是多笔合法成交，先聚合；`buyer` / `seller` 是营业部名称（「机构专用」是机构席位）。
- `disclosure_date.actual_date` 是事后回填的实际披露日：只在它早于决策日时可用，预约日用 `pre_date`，改期看 `modify_date`。
- `forecast_vip` 与 `express_vip` 的每个版本按自己的 `ann_date` 18:00 可见；`express_vip.yoy_net_profit` 是去年同期的净利润金额，不是增长率。
- 单位以 `/mnt/artifacts/unit_reference.json` 为准（大宗与龙虎榜的量、额不是元与股）。

## 值得一看的（建议，不是菜单）

外部研究与市场规则，不是宿主读数，都要在研究期上自己核对。

- **谁在买、买多少、按什么价。** 美股的内部人交易文献里，信息集中在少数「非例行」的买入上（Cohen、Malloy 与 Pomorski 2012 区分了例行与非例行交易者），金额相对持股大、发生在下跌之后的买入更有信息。A 股的控股股东增持常伴随「稳定股价」的公告与监管窗口，要按是否紧跟在大跌或减持之后分开看。
- **大宗交易的折溢价。** 国内研究普遍读到折价大宗之后股价走弱（大宗是减持的通道）；溢价成交少，但它是有人为了拿到这笔股票多付钱。用同日收盘价算溢价，按买方是不是机构席位分开。
- **提前预约的披露。** 定期报告的预约日与改期是公司事先公布的；文献里「好消息早报、坏消息晚报」在 A 股年报上成立，预约提前、改期提前的公司随后的业绩更好。它在八年财务面上作单独的择时信号已经读零（上表），值得问的是它与内部人买入叠在一起时的样子。
- **回购的执行。** 只读到计划与完成标题时，计划被证伪、完成读负；可以问的是「执行中」：回购进展标题之间总股本或流通股的实际下降量（日线 `total_share`），按占市值的比例排。

没有。五年臂的研究期与此前任何一条臂都不同，宿主的 lineage 只能并入研究期相同的臂；要重开 `refs/families.md` 里的一行，在第一次提交它的那一批照那一行申报（重开的读数都是八年或四年研究期上的，五年是其中的一段）。

## 本方向的对照要点

- 事件书（增持公告、溢价大宗、预约提前之后进场）：`late_entry`，同一批事件晚进场，书的其余部分不变。
- 按承诺轻重挑出的子集（只买控股股东的、金额占比大的、溢价的）：要胜过同一批事件里随机抽出的同样大小的子集（`shuffled_assignment` 在事件名字里抽），不只胜过全体事件；再带一条阶段或方向的对照，例如同骨架建在减持或折价大宗上的书，它应该读负。
- 五年上的探针更吵：两年的主动 IR 零技能抽样误差约 0.7，探针只能淘汰。事件少的家族先在离线上数清每年有多少个能买进的事件，席位撑不满的书在事件少的年份握着现金。
