# output/ 只放正式产物

`output/` 是正式策略产物目录。任何残留文件都会让 `modification_check` 和回放直接失败：`__pycache__`、临时脚本、笔记、日志、数据导出都算残留。

## 做法

- 调试脚本、中间结论和笔记写在工作区根，不写进 `output/` 或 `models/`。
- 在 `output/` 里执行过 Python 就会留下 `__pycache__`；脚本放在工作区根执行，或在检查前删掉缓存目录。
- 调用 `modification_check` 与 `smoke_backtest` 之前先列一遍 `output/`，确认只剩正式文件。
- 正式策略是单文件入口，辅助模块也属于残留，逻辑要么内联要么留在工作区根。

## 教训

多个折在冒烟阶段被残留缓存目录挡下，每次都要多花一轮才发现问题出在目录内容而不是策略代码。
