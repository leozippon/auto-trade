# 提交前清掉死分支与过期注释

被开关关掉的旧尝试、失败方向留下的常量和函数、与当前常量矛盾的 docstring，都是残留。它们会跨 revision 一路带进冻结产物，每一轮还白占改动行预算。

## 做法

- `finish_fold` 前通读一遍 `output/`：恒为假的分支、只被它调用的函数、不再被引用的参数，删掉，而不是留着「以后也许再用」。
- 一轮候选被证伪后立刻拆掉落选变体的接线，不要把半截实现留在胜出候选里。
- 改了窗口、阈值或口径就同步改注释和 docstring：写着一个数、算着另一个数的注释比没有注释更糟。
- 关掉一条路径的正确做法是删掉它，需要时重写，产物里不留开关式残留。

## 教训

一处由常量关掉的旧机制活过了同一个实验里的每次改写和三代冻结产物，从未被执行，却每轮都占改动行数；同一批产物里还留着写着另一个窗口长度的 docstring。
