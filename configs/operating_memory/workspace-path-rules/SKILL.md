# 路径写成授权根下的相对路径

文件与搜索工具接收的是授权根加相对路径，不是宿主绝对路径。把 `/mnt/...` 之类的绝对路径传给 `read_file` / `grep` / `glob` 会被直接拒绝。

## 做法

- 写入用 `workspace` / `output` / `models` 三个根；读取还可用快照、父产物与结果根，路径都相对于所选根。
- 先用 `glob` 在授权根内定位，再用 `read_file` 分页读；大结果会落盘并返回路径，按路径续读而不是重读。
- 正式策略里不写死任何宿主路径，运行时只用 `context.snapshot_dir` / `context.asof_dir` 拼域名目录。
- 授权根之外的目录在本会话中不存在，遍历整个文件系统只会得到边界拒绝。

## 教训

绝对路径与根名写错在多个折里反复出现，单个折的路径与 schema 类错误一度达到两位数，全部是可以一次学会的固定用法。
