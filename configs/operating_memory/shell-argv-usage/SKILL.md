# shell 用 argv 数组

`shell` 接收 argv 数组，例如 `["python", "notes/check.py"]`，不是一整行命令字符串。参数有长度上限，长脚本必须先 `write_file` 再执行。

## 做法

- 不要把整段代码塞进 `-c`：超长参数会被拒绝，改成写文件再运行。
- 一次前台调用，不能后台执行，也没有 sleep 或等待类包装；轮询式命令在执行前就被拒绝。
- 输出有上限，超出会被截断或落盘。让脚本只打印结论性的少量行，完整结果写文件后再按需读取。
- 工作目录和可写范围限定在工作区，遍历工作区以外的路径会被边界拒绝。

## 教训

同一个会话里超长参数被拒绝过两次，都是把脚本正文当参数传；`find` 越界和等待类调用各浪费过一轮。
