# 按网格形态选参数，不选最高点

机制先确认存活，再谈参数点。对单个关键参数做预登记的小网格（相邻格点，通常不超过四点），取舍规则在看到任何结果之前写进预登记；否则「选一个好参数」就是一次用验证窗做的隐蔽拟合。

## 判读规则

- 高原：相邻若干格点的差异都落在事先声明的带宽内，取居中或成本更友好的一点。这是结论对该参数不敏感的证据，也是唯一可以直接交付的形态。
- 孤立尖峰：某点明显优于两侧邻居，先补邻居格点；两侧邻居都被证伪时，交付侧翼上的稳健点而不是尖峰本身。
- 断崖：越过某点后急剧变差，说明该方向已经越界；把边界写成机制结论，不贴着断崖选点。
- 符号翻转：相邻格点结果符号相反，信号对该参数脆弱；停止点选，回机制层修订，而不是扫更密的网格。
- 数值冠军与规则所选不一致时以预登记规则为准，并如实记录数值差；规则触发时退到哪一点也要事先写明。

## 配套纪律

- 阈值尽量写成同序列的自比分位，而不是绝对值：绝对阈值换一个窗口不是永不触发就是永远触发。
- 点选出的常数在汇报里与 `fit` 拟合出的参数分开计数，不包装成「调好的常数」。
- 最优点依赖窗口：换窗口就重跑网格与形态判读，不搬上一窗的取值。

单个格点的高低同时含机制与噪声，形态主要含机制：高原说明结论在参数邻域内成立，尖峰说明它只在这一点成立。
